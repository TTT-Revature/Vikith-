# UPDATE and DELETE Statements in SQL (MySQL)

## 1. Introduction

SQL provides two important DML (Data Manipulation Language) commands to manage existing records.

| Command | Purpose |
|---|---|
| UPDATE | Modifies existing records |
| DELETE | Removes existing records |

Both commands can use the `WHERE` clause to target specific records.

Let's understand them using a practical employee table.

### Sample Employees Table

| employee_id | name | department | salary | city |
|---:|---|---|---:|---|
| 101 | Rahul | IT | 45000 | Chennai |
| 102 | Priya | HR | 35000 | Bangalore |
| 103 | Aman | IT | 55000 | Chennai |
| 104 | Sneha | Finance | 40000 | Mumbai |
| 105 | Arjun | IT | 60000 | Bangalore |

---

# 2. UPDATE Statement

The `UPDATE` statement modifies existing records in a table.

For example:
- Changing an employee's salary.
- Updating an employee's department.
- Changing a customer's address.
- Updating a product's price.

### Syntax

```sql
UPDATE table_name
SET column1 = value1,
    column2 = value2
WHERE condition;
```

Explanation:

| Keyword | Purpose |
|---|---|
| UPDATE | Specifies the table to modify |
| SET | Specifies the new column values |
| WHERE | Identifies which records should be updated |

## 3. Updating a Single Column

Suppose Rahul receives a salary increase from 45000 to 50000.

```sql
UPDATE employees
SET salary = 50000
WHERE employee_id = 101;
```

Only Rahul's salary is updated.

### Table After UPDATE

| employee_id | name | department | salary | city |
|---:|---|---|---:|---|
| 101 | Rahul | IT | 50000 | Chennai |
| 102 | Priya | HR | 35000 | Bangalore |
| 103 | Aman | IT | 55000 | Chennai |
| 104 | Sneha | Finance | 40000 | Mumbai |
| 105 | Arjun | IT | 60000 | Bangalore |

Notice that only the salary of employee 101 changed.

## 4. Updating Multiple Columns

We can update multiple columns in a single UPDATE statement.

Example: Change Priya's salary and department.

```sql
UPDATE employees
SET salary = 40000,
    department = 'Finance'
WHERE employee_id = 102;
```

Both values are updated for Priya.

### Another Example

Change Sneha's city and salary.

```sql
UPDATE employees
SET city = 'Chennai',
    salary = 45000
WHERE employee_id = 104;
```

We can update as many columns as needed in the same statement.

## 5. UPDATE with Multiple Conditions

We can use logical operators to update records satisfying multiple conditions.

### Example 1: AND

Increase the salary of IT employees earning less than 55000.

```sql
UPDATE employees
SET salary = salary + 5000
WHERE department = 'IT'
AND salary < 55000;
```

Both conditions must be satisfied.

### Example 2: OR

Update employees who are from Chennai or Mumbai.

```sql
UPDATE employees
SET department = 'Operations'
WHERE city = 'Chennai'
OR city = 'Mumbai';
```

### Example 3: BETWEEN

Increase salaries between 30000 and 45000 by 10%.

```sql
UPDATE employees
SET salary = salary * 1.10
WHERE salary BETWEEN 30000 AND 45000;
```

## 6. UPDATE Without WHERE

This is extremely important.

Consider:

```sql
UPDATE employees
SET salary = 50000;
```

What happens?

**Every employee's salary becomes 50000.**

Before:

| name | salary |
|---|---:|
| Rahul | 45000 |
| Priya | 35000 |
| Aman | 55000 |

After:

| name | salary |
|---|---:|
| Rahul | 50000 |
| Priya | 50000 |
| Aman | 50000 |

Without WHERE, UPDATE affects every row in the table.

Always check your WHERE condition before executing an UPDATE statement.

# 7. DELETE Statement

The `DELETE` statement removes records from an existing table.

For example:
- Removing an employee who has left the company.
- Deleting a cancelled order.
- Removing an unwanted customer record.
- Deleting a product from a catalogue.

### Syntax

```sql
DELETE FROM table_name
WHERE condition;
```

Explanation:

| Keyword | Purpose |
|---|---|
| DELETE FROM | Specifies the table from which records should be removed |
| WHERE | Identifies which records should be deleted |

## 8. Deleting a Single Record

Suppose we want to remove employee 105.

```sql
DELETE FROM employees
WHERE employee_id = 105;
```

The employee with ID 105 is deleted.

### Table After DELETE

| employee_id | name | department | salary | city |
|---:|---|---|---:|---|
| 101 | Rahul | IT | 45000 | Chennai |
| 102 | Priya | HR | 35000 | Bangalore |
| 103 | Aman | IT | 55000 | Chennai |
| 104 | Sneha | Finance | 40000 | Mumbai |

Only Arjun's record is removed.

## 9. Deleting Multiple Records

We can delete multiple records using conditions.

### Example 1: Delete Employees from HR

```sql
DELETE FROM employees
WHERE department = 'HR';
```

All employees belonging to HR are deleted.

### Example 2: Delete Employees Earning Less Than 40000

```sql
DELETE FROM employees
WHERE salary < 40000;
```

### Example 3: Delete Employees from Chennai

```sql
DELETE FROM employees
WHERE city = 'Chennai';
```

Every employee matching the condition is removed.

## 10. DELETE with AND and OR

We can combine multiple conditions.

### AND Example

Delete IT employees earning more than 50000.

```sql
DELETE FROM employees
WHERE department = 'IT'
AND salary > 50000;
```

Both conditions must be true.

### OR Example

Delete employees who are from Chennai or Mumbai.

```sql
DELETE FROM employees
WHERE city = 'Chennai'
OR city = 'Mumbai';
```

At least one condition must be true.

## 11. DELETE Without WHERE

Consider:

```sql
DELETE FROM employees;
```

What happens?

**All records in the employees table are deleted.**

However, the table structure remains.

Before:

| employee_id | name | department |
|---:|---|---|
| 101 | Rahul | IT |
| 102 | Priya | HR |
| 103 | Aman | IT |

After:

| employee_id | name | department |
|---|---|---|
| No records | | |

The table still exists and can receive new records.

**Warning:** Never execute DELETE without WHERE unless you intentionally want to remove every record.

# 12. Difference Between DELETE, TRUNCATE and DROP

These three commands are often confused in interviews.

| Feature | DELETE | TRUNCATE | DROP |
|---|---|---|---|
| Category | DML | DDL | DDL |
| Removes records | Yes | Yes, all | Yes |
| Removes table structure | No | No | Yes |
| Supports WHERE | Yes | No | No |
| Can remove selected rows | Yes | No | No |
| Table remains afterward | Yes | Yes | No |

### DELETE Example

```sql
DELETE FROM employees
WHERE employee_id = 101;
```

Deletes only the selected employee.

### TRUNCATE Example

```sql
TRUNCATE TABLE employees;
```

Removes all records but keeps the table structure.

### DROP Example

```sql
DROP TABLE employees;
```

Removes the entire table, including its structure and records.

**MySQL note:** DELETE, TRUNCATE, and DROP have different transaction behavior. TRUNCATE and DROP cause implicit commits in MySQL, so they cannot generally be rolled back like transactional DELETE statements.

# 13. Using SELECT Before UPDATE or DELETE

A good database practice is to check which records will be affected before modifying or deleting them.

Suppose we want to delete employees earning less than 35000.

### Step 1: Preview the Records

```sql
SELECT *
FROM employees
WHERE salary < 35000;
```

### Step 2: Delete the Records

```sql
DELETE FROM employees
WHERE salary < 35000;
```

Similarly, before updating salaries:

### Step 1: Preview

```sql
SELECT *
FROM employees
WHERE department = 'IT';
```

### Step 2: Update

```sql
UPDATE employees
SET salary = salary + 5000
WHERE department = 'IT';
```

This helps prevent accidental changes.

# 14. Using Transactions for Safer Updates and Deletes

In MySQL, when using a transactional storage engine such as InnoDB, we can use transactions to review changes before committing them.

Example:

```sql
START TRANSACTION;

UPDATE employees
SET salary = 50000
WHERE employee_id = 101;

SELECT *
FROM employees
WHERE employee_id = 101;

ROLLBACK;
```

`ROLLBACK` cancels the uncommitted changes.

If the result is correct and you want to save the changes, use:

```sql
COMMIT;
```

### Important Transaction Commands

| Command | Purpose |
|---|---|
| START TRANSACTION | Begins a transaction |
| COMMIT | Permanently saves transaction changes |
| ROLLBACK | Cancels uncommitted transaction changes |

**Note:** Once a transaction is committed, a normal ROLLBACK cannot undo it.

# 15. Practical Example

Let's create a table and practise both commands.

### Create Table

```sql
CREATE TABLE products (
    product_id INT PRIMARY KEY,
    product_name VARCHAR(100),
    category VARCHAR(50),
    price DECIMAL(10,2),
    quantity INT
);
```

### Insert Records

```sql
INSERT INTO products VALUES
(1, 'Laptop', 'Electronics', 55000, 10),
(2, 'Mouse', 'Accessories', 500, 50),
(3, 'Keyboard', 'Accessories', 1200, 30),
(4, 'Monitor', 'Electronics', 15000, 15),
(5, 'Headphones', 'Accessories', 2500, 20);
```

### UPDATE Examples

Update the price of the mouse:

```sql
UPDATE products
SET price = 600
WHERE product_id = 2;
```

Increase all electronics prices by 5%:

```sql
UPDATE products
SET price = price * 1.05
WHERE category = 'Electronics';
```

Update the quantity of the keyboard:

```sql
UPDATE products
SET quantity = 40
WHERE product_id = 3;
```

### DELETE Examples

Delete the monitor:

```sql
DELETE FROM products
WHERE product_id = 4;
```

Delete products with a quantity below 15:

```sql
DELETE FROM products
WHERE quantity < 15;
```

Check the final table:

```sql
SELECT *
FROM products;
```

# 16. Interview Questions

**Q1. What is UPDATE in SQL?**

UPDATE is a DML command used to modify existing records in a database table.

**Q2. What is DELETE in SQL?**

DELETE is a DML command used to remove records from a database table.

**Q3. What happens if UPDATE is executed without WHERE?**

Every record in the table is updated.

**Q4. What happens if DELETE is executed without WHERE?**

Every record in the table is deleted, but the table structure remains.

**Q5. What is the difference between DELETE and DROP?**

DELETE removes records, while DROP removes the entire database object.

**Q6. Can we update multiple columns using one UPDATE statement?**

Yes. We can specify multiple column assignments in the SET clause.

**Q7. Can DELETE remove multiple records?**

Yes. It removes all records that satisfy its WHERE condition.

**Q8. Can we use AND and OR with UPDATE and DELETE?**

Yes. They can be used in WHERE conditions to target specific records.

**Q9. Can DELETE be rolled back?**

A DELETE operation can be rolled back if it is part of an uncommitted transaction using a transactional storage engine such as InnoDB.

**Q10. What is the safest practice before DELETE or UPDATE?**

Run a SELECT query using the same WHERE condition to preview the affected records.

# 18. Key Takeaways

- UPDATE modifies existing records.
- DELETE removes existing records.
- SET specifies the new values in UPDATE.
- WHERE identifies the records to modify or delete.
- Multiple columns can be updated in one statement.
- AND, OR, BETWEEN, and other conditions can be used with UPDATE and DELETE.
- UPDATE without WHERE modifies all records.
- DELETE without WHERE removes all records.
- SELECT can be used to preview affected records.
- Transactions help protect against accidental changes.

**Remember:**

UPDATE = Change existing data.

DELETE = Remove existing data.

Always verify your WHERE condition before executing either command.
