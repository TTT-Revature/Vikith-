# Types of SQL Statements – DDL vs. DML

## 1. Introduction

SQL (Structured Query Language) is used to communicate with relational databases such as MySQL, PostgreSQL, Oracle, and SQL Server.

SQL statements are divided into different categories based on their purpose.

Two important categories are:

1. **DDL – Data Definition Language**
2. **DML – Data Manipulation Language**

These categories help us understand whether we are defining the database structure or working with the data stored inside it.

---

## 2. DDL – Data Definition Language

DDL stands for **Data Definition Language**.

It is used to create, modify, and delete database structures such as:

- Databases
- Tables
- Columns
- Indexes
- Other database objects

In simple words:

**DDL is used to define or change the structure of a database.**

### Important DDL Commands

| Command | Purpose |
|---|---|
| `CREATE` | Creates a database object |
| `ALTER` | Modifies an existing database object |
| `DROP` | Deletes a database object |
| `TRUNCATE` | Removes all records from a table while keeping its structure |
| `RENAME` | Renames a database object |

### 2.1 CREATE

The `CREATE` command is used to create database objects.

Example:

```sql
CREATE DATABASE college;
```

This creates a database named `college`.

Creating a table:

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT,
    course VARCHAR(50)
);
```

This creates a table named `students` with four columns.

### 2.2 ALTER

The `ALTER` command modifies the structure of an existing table.

**Add a new column:**

```sql
ALTER TABLE students
ADD email VARCHAR(100);
```

**Modify an existing column:**

```sql
ALTER TABLE students
MODIFY name VARCHAR(100);
```

**Drop a column:**

```sql
ALTER TABLE students
DROP COLUMN email;
```

### 2.3 DROP

The `DROP` command permanently removes a database object.

Example:

```sql
DROP TABLE students;
```

This deletes the entire `students` table, including its structure and records.

To delete a database:

```sql
DROP DATABASE college;
```

### 2.4 TRUNCATE

The `TRUNCATE` command removes all records from a table but keeps the table structure.

Example:

```sql
TRUNCATE TABLE students;
```

Before:

| student_id | name | age |
|---|---|---|
| 1 | Rahul | 22 |
| 2 | Priya | 23 |
| 3 | Aman | 21 |

After:

| student_id | name | age |
|---|---|---|
| No records | | |

The table still exists, but all its records are removed.

### 2.5 RENAME

The `RENAME TABLE` command changes the name of a table in MySQL.

Example:

```sql
RENAME TABLE students TO college_students;
```

The table name changes from `students` to `college_students`.

## 3. DML – Data Manipulation Language

DML stands for **Data Manipulation Language**.

It is used to insert, update, delete, and retrieve data stored inside database tables.

In simple words:

**DML is used to work with the actual records stored in a table.**

### Important DML Commands

| Command | Purpose |
|---|---|
| `INSERT` | Adds new records |
| `UPDATE` | Modifies existing records |
| `DELETE` | Removes records |
| `SELECT` | Retrieves records (often classified separately as DQL) |

### 3.1 INSERT

The `INSERT` command adds new records into a table.

Example:

```sql
INSERT INTO students
(student_id, name, age, course)
VALUES
(1, 'Rahul', 22, 'MCA');
```

Another example:

```sql
INSERT INTO students
(student_id, name, age, course)
VALUES
(2, 'Priya', 23, 'BCA'),
(3, 'Aman', 21, 'MCA');
```

The records are added to the `students` table.

### 3.2 UPDATE

The `UPDATE` command modifies existing records.

Example:

```sql
UPDATE students
SET age = 24
WHERE student_id = 2;
```

This changes Priya's age to 24.

**Important:** Always use a `WHERE` condition when you intend to update specific records. Without it, every row in the table will be updated.

### 3.3 DELETE

The `DELETE` command removes records from a table.

Delete one specific record:

```sql
DELETE FROM students
WHERE student_id = 3;
```

This deletes the student whose ID is 3.

Delete all records:

```sql
DELETE FROM students;
```

This removes every record, but the table structure remains.

### 3.4 SELECT – Data Retrieval

The `SELECT` command retrieves data from a table.

Example:

```sql
SELECT * FROM students;
```

This retrieves all columns and records.

Retrieve selected columns:

```sql
SELECT name, age
FROM students;
```

**Note:** `SELECT` is commonly grouped under DQL (Data Query Language), rather than DML, in many SQL classifications. We will study DQL separately.

---

## 4. DDL vs. DML – Key Differences

| Feature | DDL | DML |
|---|---|---|
| Full form | Data Definition Language | Data Manipulation Language |
| Main purpose | Defines database structure | Manipulates table data |
| Works with | Tables and other database objects | Records inside tables |
| Examples | CREATE, ALTER, DROP, TRUNCATE | INSERT, UPDATE, DELETE |
| Changes | Database structure | Table records |

### Real-World Example

Imagine a college database.

First, we create a table to store student details:

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT
);
```

This is **DDL** because we are defining the table structure.

Next, we insert student details:

```sql
INSERT INTO students
VALUES (1, 'Rahul', 22);
```

This is **DML** because we are adding data to the table.

Finally, we update Rahul's age:

```sql
UPDATE students
SET age = 23
WHERE student_id = 1;
```

This is also **DML** because we are modifying an existing record.

## 5. Important Interview Questions

**Q1. What is DDL?**

DDL stands for Data Definition Language. It is used to define and modify database structures.

**Q2. What is DML?**

DML stands for Data Manipulation Language. It is used to insert, update, and delete records in database tables.

**Q3. What is the difference between DROP and TRUNCATE?**

- `DROP` removes the entire table, including its structure.
- `TRUNCATE` removes all records but keeps the table structure.

**Q4. What is the difference between DELETE and TRUNCATE?**

- `DELETE` removes selected records or all records. It supports a `WHERE` condition.
- `TRUNCATE` removes all records and does not support a `WHERE` condition.

**Q5. Is SELECT a DML command?**

In many SQL classifications, `SELECT` is categorized separately under DQL (Data Query Language), although some classifications group it under DML.

**Q6. Can we use UPDATE without WHERE?**

Yes. However, without `WHERE`, all records in the table will be updated.

**Q7. Which command is used to modify a table structure?**

`ALTER`.

---

## 7. Key Takeaways

- DDL defines and modifies database structures.
- DML manipulates records stored inside tables.
- `CREATE`, `ALTER`, `DROP`, and `TRUNCATE` are important DDL commands.
- `INSERT`, `UPDATE`, and `DELETE` are important DML commands.
- `SELECT` is commonly classified as DQL.
- `DROP` deletes the table itself, whereas `TRUNCATE` removes its records.
- Always be careful when using `UPDATE` and `DELETE` without a `WHERE` condition.

**Remember:**

DDL = Structure of the database.

DML = Data inside the database.
