# Sorting Result Sets in SQL (MySQL)

## 1. Introduction

Sorting means arranging the records returned by a SQL query in a particular order.

In SQL, we use the `ORDER BY` clause to sort result sets.

For example, we might want to:

- Display employees from highest salary to lowest salary.
- Arrange students alphabetically by name.
- Display products from cheapest to most expensive.
- Sort orders by their purchase date.
- Sort employees by department and salary.

The `ORDER BY` clause helps us organize query results.

---

## 2. ORDER BY Clause

The `ORDER BY` clause sorts records based on one or more columns.

### Syntax

```sql
SELECT column1, column2
FROM table_name
ORDER BY column_name;
```

Example:

```sql
SELECT *
FROM employees
ORDER BY salary;
```

By default, MySQL sorts records in ascending order.

## 3. ASC – Ascending Order

`ASC` stands for Ascending.

It arranges values from smallest to largest.

For text values, it generally arranges them alphabetically.

### Example 1: Sort Employees by Salary

```sql
SELECT *
FROM employees
ORDER BY salary ASC;
```

Output:

| employee_id | name | salary |
|---:|---|---:|
| 106 | Kiran | 30000 |
| 102 | Priya | 35000 |
| 104 | Sneha | 40000 |
| 101 | Rahul | 45000 |
| 107 | Ananya | 48000 |
| 108 | Rakesh | 52000 |
| 103 | Aman | 55000 |
| 105 | Arjun | 60000 |

The lowest salary appears first.

### Example 2: Sort Names Alphabetically

```sql
SELECT *
FROM employees
ORDER BY name ASC;
```

Output begins with:

| name |
|---|
| Aman |
| Ananya |
| Arjun |
| Kiran |
| Priya |
| Rahul |
| Rakesh |
| Sneha |

## 4. DESC – Descending Order

`DESC` stands for Descending.

It arranges values from largest to smallest.

For text values, it generally arranges them in reverse alphabetical order.

### Example 1: Sort Employees by Salary

```sql
SELECT *
FROM employees
ORDER BY salary DESC;
```

Output:

| employee_id | name | salary |
|---:|---|---:|
| 105 | Arjun | 60000 |
| 103 | Aman | 55000 |
| 108 | Rakesh | 52000 |
| 107 | Ananya | 48000 |
| 101 | Rahul | 45000 |
| 104 | Sneha | 40000 |
| 102 | Priya | 35000 |
| 106 | Kiran | 30000 |

The highest salary appears first.

### Example 2: Sort Names in Reverse Alphabetical Order

```sql
SELECT *
FROM employees
ORDER BY name DESC;
```

## 5. Sorting by Multiple Columns

Sometimes sorting by one column is not enough.

We can sort by multiple columns in a single query.

### Example

Sort employees by department and then by salary.

```sql
SELECT *
FROM employees
ORDER BY department ASC, salary DESC;
```

How does this work?

1. First, employees are grouped in alphabetical order by department in the result.
2. Within each department, employees are sorted by salary from highest to lowest.

### Example Output

| name | department | salary |
|---|---|---:|
| Sneha | Finance | 40000 |
| Ananya | Finance | 48000 |
| Priya | HR | 35000 |
| Kiran | HR | 30000 |
| Arjun | IT | 60000 |
| Aman | IT | 55000 |
| Rakesh | IT | 52000 |
| Rahul | IT | 45000 |

**Note:** The table above illustrates the sorting order. Within Finance, the correct descending salary order is Ananya followed by Sneha.

### Another Example

Sort employees by city in ascending order and salary in ascending order.

```sql
SELECT *
FROM employees
ORDER BY city ASC, salary ASC;
```

If multiple employees belong to the same city, their salaries determine their order within that city.

## 6. ORDER BY with WHERE

We can filter records first and then sort the returned results.

### Example 1

Find IT employees and sort them by salary in descending order.

```sql
SELECT *
FROM employees
WHERE department = 'IT'
ORDER BY salary DESC;
```

### Example 2

Find employees earning more than 40000 and sort them by salary in ascending order.

```sql
SELECT *
FROM employees
WHERE salary > 40000
ORDER BY salary ASC;
```

### Example 3

Find employees from Chennai and sort their names alphabetically.

```sql
SELECT *
FROM employees
WHERE city = 'Chennai'
ORDER BY name ASC;
```

---

## 7. ORDER BY with LIMIT

We can combine sorting and LIMIT to retrieve only a specific number of records.

### Example 1: Top Three Highest-Paid Employees

```sql
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 3;
```

Output:

| name | salary |
|---|---:|
| Arjun | 60000 |
| Aman | 55000 |
| Rakesh | 52000 |

### Example 2: Three Lowest-Paid Employees

```sql
SELECT *
FROM employees
ORDER BY salary ASC
LIMIT 3;
```

Output:

| name | salary |
|---|---:|
| Kiran | 30000 |
| Priya | 35000 |
| Sneha | 40000 |

### Example 3: Second and Third Highest-Paid Employees

```sql
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 2 OFFSET 1;
```

Explanation:

- `ORDER BY salary DESC` sorts salaries from highest to lowest.
- `OFFSET 1` skips the highest-paid employee.
- `LIMIT 2` returns the next two employees.

**Note:** If employees have equal salaries, add a second sorting column such as `employee_id` to make the result order predictable.

## 8. Sorting with Column Aliases

We can sort using an alias created in the SELECT statement.

Example:

```sql
SELECT
    name,
    salary,
    salary * 12 AS annual_salary
FROM employees
ORDER BY annual_salary DESC;
```

This sorts employees by calculated annual salary.

The alias exists only within the query result; it does not create a new table column.

---

## 9. Sorting with Expressions

We can also sort using calculations or expressions.

### Example: Sort by Annual Salary

```sql
SELECT name, salary
FROM employees
ORDER BY salary * 12 DESC;
```

### Example: Sort by Name Length

```sql
SELECT name
FROM employees
ORDER BY LENGTH(name) ASC;
```

This sorts employees by the number of characters in their names.

---

## 10. Sorting NULL Values

NULL represents a missing or unknown value.

In MySQL:

- NULL values appear first when sorting in ascending order.
- NULL values appear last when sorting in descending order.

Example:

```sql
SELECT *
FROM employees
ORDER BY salary ASC;
```

If some salary values are NULL, those rows appear before non-NULL salaries.

### Put NULL Values Last in Ascending Order

```sql
SELECT *
FROM employees
ORDER BY salary IS NULL ASC, salary ASC;
```

Explanation:

- `salary IS NULL` returns 1 for NULL and 0 otherwise.
- Sorting this expression in ascending order places non-NULL values first.
- The second sort arranges salaries in ascending order.

## 11. SQL Query Execution Order

When writing a SQL query, we usually follow this order:

```sql
SELECT column_name
FROM table_name
WHERE condition
GROUP BY column_name
HAVING condition
ORDER BY column_name
LIMIT number;
```

The logical processing order is:

1. FROM
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT
6. DISTINCT
7. ORDER BY
8. LIMIT

Understanding this order helps us understand how filtering, grouping, and sorting work together.

## 12. Common Mistakes

### Mistake 1: Forgetting ASC or DESC

```sql
SELECT *
FROM employees
ORDER BY salary;
```

This is valid SQL. If no direction is specified, MySQL uses ascending order.

### Mistake 2: Using WHERE After ORDER BY

Incorrect:

```sql
SELECT *
FROM employees
ORDER BY salary DESC
WHERE department = 'IT';
```

Correct:

```sql
SELECT *
FROM employees
WHERE department = 'IT'
ORDER BY salary DESC;
```

WHERE must come before ORDER BY.

### Mistake 3: Assuming ORDER BY Changes the Table

Sorting does not permanently rearrange records in the database.

```sql
SELECT *
FROM employees
ORDER BY salary DESC;
```

This only changes the order of the query result.

### Mistake 4: Forgetting Secondary Sorting

```sql
SELECT *
FROM employees
ORDER BY department;
```

Employees in the same department may appear in any order unless another sorting column is specified.

Use:

```sql
SELECT *
FROM employees
ORDER BY department ASC, salary DESC;
```

## 13. Interview Questions

**Q1. What is ORDER BY in SQL?**

ORDER BY is used to sort the result set based on one or more columns.

**Q2. What is the difference between ASC and DESC?**

ASC sorts in ascending order, while DESC sorts in descending order.

**Q3. What is the default sorting order in MySQL?**

Ascending order.

**Q4. Can we sort by multiple columns?**

Yes. We can specify multiple columns in the ORDER BY clause.

**Q5. Does ORDER BY permanently change the table?**

No. It only changes the order in which the query returns records.

**Q6. Can we use ORDER BY with WHERE?**

Yes. WHERE filters records, and ORDER BY sorts the filtered result.

**Q7. Can we use LIMIT with ORDER BY?**

Yes. It is commonly used to retrieve the top or bottom records.

**Q8. How are NULL values sorted in MySQL?**

NULL values appear first in ascending order and last in descending order.

**Q9. Can we sort using a calculated column?**

Yes. We can sort using expressions or aliases defined in the SELECT list.

**Q10. What is secondary sorting?**

It means using another column to determine the order of records when the first sorting column contains equal values.

## 15. Key Takeaways

- ORDER BY sorts query results.
- ASC sorts values in ascending order.
- DESC sorts values in descending order.
- ASC is the default sorting direction.
- Multiple columns can be used for sorting.
- ORDER BY can be combined with WHERE and LIMIT.
- Sorting can use aliases and expressions.
- Sorting does not permanently change the table.
- MySQL places NULL first in ascending order and last in descending order.

**Remember:**

- ASC = Smallest to largest.
- DESC = Largest to smallest.
- Multiple columns = Primary sorting followed by secondary sorting.
- ORDER BY + LIMIT = Retrieve top or bottom records.
