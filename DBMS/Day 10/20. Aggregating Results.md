# Aggregating Results in SQL (MySQL)

## 1. What Is Aggregation?

Aggregation is the process of performing calculations on multiple rows and returning a single summarized value.

Instead of displaying every record in a table, aggregate functions help us calculate useful information such as:

- Total number of employees
- Total sales amount
- Average salary
- Highest salary
- Lowest salary

### Example

Consider an `employees` table:

| employee_id | name | department | salary |
|---|---|---|---:|
| 1 | Rahul | IT | 50000 |
| 2 | Sneha | HR | 40000 |
| 3 | Arjun | IT | 60000 |
| 4 | Priya | Finance | 45000 |
| 5 | Kiran | HR | 35000 |

We can use aggregate functions to summarize this data.

---

## 2. Types of Aggregate Functions

MySQL provides several built-in aggregate functions.

| Function | Purpose |
|---|---|
| `COUNT()` | Counts rows or non-NULL values |
| `SUM()` | Calculates the total |
| `AVG()` | Calculates the average |
| `MIN()` | Finds the minimum value |
| `MAX()` | Finds the maximum value |

## 3. COUNT() Function

The `COUNT()` function counts records or non-NULL values.

### Syntax

```sql
SELECT COUNT(column_name)
FROM table_name;
```

### Example 1: Count all employees

```sql
SELECT COUNT(*)
FROM employees;
```

**Output:**

| COUNT(*) |
|---:|
| 5 |

`COUNT(*)` counts all rows, including rows containing NULL values.

### Example 2: Count non-NULL salaries

```sql
SELECT COUNT(salary)
FROM employees;
```

This counts only rows where `salary` is not NULL.

### Example 3: Count distinct departments

```sql
SELECT COUNT(DISTINCT department)
FROM employees;
```

**Output:**

| COUNT(DISTINCT department) |
|---:|
| 3 |

There are three unique departments: IT, HR, and Finance.

---

## 4. SUM() Function

The `SUM()` function calculates the total of a numeric column.

### Syntax

```sql
SELECT SUM(column_name)
FROM table_name;
```

### Example: Calculate total salary

```sql
SELECT SUM(salary)
FROM employees;
```

**Output:**

| SUM(salary) |
|---:|
| 230000 |

Calculation:

```text
50000 + 40000 + 60000 + 45000 + 35000
= 230000
```

### Example: Total salary of IT employees

```sql
SELECT SUM(salary)
FROM employees
WHERE department = 'IT';
```

**Output:**

| SUM(salary) |
|---:|
| 110000 |

---

## 5. AVG() Function

The `AVG()` function calculates the average of numeric values.

### Syntax

```sql
SELECT AVG(column_name)
FROM table_name;
```

### Example: Calculate average salary

```sql
SELECT AVG(salary)
FROM employees;
```

**Output:**

| AVG(salary) |
|---:|
| 46000.00 |

Calculation:

```text
Total Salary / Number of Employees

230000 / 5 = 46000
```

### Example: Average salary in HR

```sql
SELECT AVG(salary)
FROM employees
WHERE department = 'HR';
```

**Output:**

| AVG(salary) |
|---:|
| 37500.00 |

---

## 8. Using Multiple Aggregate Functions Together

We can use multiple aggregate functions in a single SELECT statement.

### Example

```sql
SELECT
    COUNT(*) AS total_employees,
    SUM(salary) AS total_salary,
    AVG(salary) AS average_salary,
    MIN(salary) AS lowest_salary,
    MAX(salary) AS highest_salary
FROM employees;
```

**Output:**

| total_employees | total_salary | average_salary | lowest_salary | highest_salary |
|---:|---:|---:|---:|---:|
| 5 | 230000 | 46000.00 | 35000 | 60000 |

This is useful when we want multiple summary statistics in one query.

---

## 9. Aggregate Functions with WHERE

The `WHERE` clause filters rows before aggregate functions calculate their results.

### Example: Calculate the average salary of employees earning more than ₹40,000

```sql
SELECT AVG(salary)
FROM employees
WHERE salary > 40000;
```

**Output:**

| AVG(salary) |
|---:|
| 51666.67 |

Only these employees are included:

| name | salary |
|---|---:|
| Rahul | 50000 |
| Arjun | 60000 |
| Priya | 45000 |

Calculation:

```text
(50000 + 60000 + 45000) / 3
= 51666.67
```

---

## 10. How Aggregate Functions Handle NULL

Aggregate functions generally ignore NULL values, except `COUNT(*)`, which counts rows regardless of NULL values.

Consider this table:

| employee_id | name | salary |
|---|---|---:|
| 1 | Rahul | 50000 |
| 2 | Sneha | 40000 |
| 3 | Arjun | NULL |
| 4 | Priya | 45000 |

### COUNT(*) vs COUNT(salary)

```sql
SELECT
    COUNT(*) AS total_rows,
    COUNT(salary) AS salary_count
FROM employees;
```

**Output:**

| total_rows | salary_count |
|---:|---:|
| 4 | 3 |

Explanation:

- `COUNT(*)` counts all four rows.
- `COUNT(salary)` counts only three non-NULL salary values.

### AVG() with NULL

```sql
SELECT AVG(salary)
FROM employees;
```

**Output:**

| AVG(salary) |
|---:|
| 45000.00 |

Calculation:

```text
(50000 + 40000 + 45000) / 3
= 45000
```

The NULL salary is ignored; it is not treated as zero.

### Important NULL behavior

| Function | NULL behavior |
|---|---|
| COUNT(*) | Counts every row |
| COUNT(column) | Ignores NULL |
| SUM(column) | Ignores NULL |
| AVG(column) | Ignores NULL |
| MIN(column) | Ignores NULL |
| MAX(column) | Ignores NULL |

If there are no non-NULL values to aggregate, `SUM()`, `AVG()`, `MIN()`, and `MAX()` return NULL. `COUNT()` returns 0.

---

## 11. Aggregate Functions with DISTINCT

The `DISTINCT` keyword can be used inside aggregate functions to consider only unique values.

### Example: Count unique salaries

```sql
SELECT COUNT(DISTINCT salary)
FROM employees;
```

### Example: Sum unique salary values

```sql
SELECT SUM(DISTINCT salary)
FROM employees;
```

This adds each distinct non-NULL salary only once.

**Important:** `DISTINCT` changes which values are included in the calculation. Use it only when that is what the question requires.

---

## 12. Important Difference: COUNT(*) vs COUNT(column)

| COUNT(*) | COUNT(column) |
|---|---|
| Counts all rows | Counts non-NULL values |
| Includes rows containing NULL | Ignores NULL values in that column |
| Useful for total record count | Useful for counting available values |

Example:

```sql
SELECT COUNT(*) FROM employees;

SELECT COUNT(salary) FROM employees;
```

If the table has five rows and one salary is NULL:

- `COUNT(*)` returns 5.
- `COUNT(salary)` returns 4.

## 13. Common Mistakes

### Mistake 1: Using aggregate functions directly in WHERE

Incorrect:

```sql
SELECT department, AVG(salary)
FROM employees
WHERE AVG(salary) > 40000;
```

Aggregate functions cannot normally be used directly in `WHERE`.

We will learn to filter aggregated results using `HAVING` in the next topic.

### Mistake 2: Assuming NULL is zero

```sql
SELECT AVG(salary)
FROM employees;
```

NULL values are ignored, not counted as zero.

### Mistake 3: Using SUM() on non-numeric data

`SUM()` and `AVG()` are intended for numeric expressions. Use them with appropriate numeric columns.

## 16. Key Takeaways

- Aggregate functions summarize multiple rows.
- `COUNT()` counts rows or non-NULL values.
- `SUM()` calculates totals.
- `AVG()` calculates averages.
- `MIN()` finds the smallest value.
- `MAX()` finds the largest value.
- Aggregate functions generally ignore NULL values.
- `WHERE` filters individual rows before aggregation.
- `DISTINCT` can be used to aggregate unique values.
- `HAVING` is used to filter grouped or aggregated results.
