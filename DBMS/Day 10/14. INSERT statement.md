# INSERT Statement in SQL (MySQL)

## 1. Introduction

The `INSERT` statement is used to add new records (rows) into an existing database table.

It is a DML (Data Manipulation Language) command.

For example, imagine we have a `students` table. We can use INSERT to add student details such as:

- Student ID
- Name
- Age
- Email
- Course

---

## 2. Basic INSERT Syntax

```sql
INSERT INTO table_name
VALUES (value1, value2, value3);
```

This inserts a new record into a table.

**Important:** When using this syntax, values must be provided in the same order as the table's columns, and values must be compatible with their data types.

---

## 3. Creating a Table for Practice

First, let's create a `students` table.

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INT,
    email VARCHAR(100) UNIQUE,
    course VARCHAR(50)
);
```

Our table has five columns.

| Column | Data Type | Constraint |
|---|---|---|
| student_id | INT | PRIMARY KEY |
| name | VARCHAR(100) | NOT NULL |
| age | INT | None |
| email | VARCHAR(100) | UNIQUE |
| course | VARCHAR(50) | None |

---

## 4. Inserting a Single Record

To insert one record, use `INSERT INTO`.

```sql
INSERT INTO students
VALUES (101, 'Rahul', 22, 'rahul@gmail.com', 'MCA');
```

This inserts one student into the table.

### Result

| student_id | name | age | email | course |
|---:|---|---:|---|---|
| 101 | Rahul | 22 | rahul@gmail.com | MCA |

---

## 5. INSERT with Column Names

This is a recommended way to insert records because we explicitly specify which columns receive values.

### Syntax

```sql
INSERT INTO table_name (column1, column2, column3)
VALUES (value1, value2, value3);
```

Example:

```sql
INSERT INTO students (student_id, name, age)
VALUES (102, 'Priya', 23);
```

### Result

| student_id | name | age | email | course |
|---:|---|---:|---|---|
| 101 | Rahul | 22 | rahul@gmail.com | MCA |
| 102 | Priya | 23 | NULL | NULL |

Why are email and course NULL?

Because we did not provide values for those columns, and they allow NULL values.

**Important:** If a column has a DEFAULT value, MySQL uses that default when the column is omitted. If it is NOT NULL without a default, the INSERT may fail.

---

## 6. Inserting Multiple Records

We can insert multiple records using a single INSERT statement.

### Syntax

```sql
INSERT INTO table_name
VALUES
(value1, value2, value3),
(value1, value2, value3),
(value1, value2, value3);
```

Example:

```sql
INSERT INTO students
VALUES
(103, 'Aman', 21, 'aman@gmail.com', 'MCA'),
(104, 'Sneha', 22, 'sneha@gmail.com', 'BCA'),
(105, 'Arjun', 24, 'arjun@gmail.com', 'MCA');
```

### Result

| student_id | name | age | email | course |
|---:|---|---:|---|---|
| 101 | Rahul | 22 | rahul@gmail.com | MCA |
| 102 | Priya | 23 | NULL | NULL |
| 103 | Aman | 21 | aman@gmail.com | MCA |
| 104 | Sneha | 22 | sneha@gmail.com | BCA |
| 105 | Arjun | 24 | arjun@gmail.com | MCA |

This approach is useful when inserting several records at once.

---

## 7. Inserting Data into Selected Columns

We do not always need to provide values for every column.

Example:

```sql
INSERT INTO students (student_id, name, course)
VALUES (106, 'Kiran', 'MCA');
```

Here, we insert values into only three columns.

The remaining columns receive their default values or NULL, provided their constraints allow it.

---

## 8. Inserting DEFAULT Values

The `DEFAULT` keyword tells MySQL to use a column's defined default value.

Let's create another table:

```sql
CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    department VARCHAR(50) DEFAULT 'IT',
    salary DECIMAL(10,2) DEFAULT 25000.00
);
```

Insert a record:

```sql
INSERT INTO employees
VALUES (1, 'Rahul', DEFAULT, DEFAULT);
```

### Result

| employee_id | name | department | salary |
|---:|---|---|---:|
| 1 | Rahul | IT | 25000.00 |

We can also omit the default columns:

```sql
INSERT INTO employees (employee_id, name)
VALUES (2, 'Priya');
```

MySQL automatically uses the defined defaults.

---

## 9. INSERT with NULL Values

NULL represents a missing or unknown value.

Example:

```sql
INSERT INTO students
(student_id, name, age, email, course)
VALUES
(107, 'Ravi', NULL, NULL, 'MCA');
```

Here, age and email are explicitly assigned NULL.

**Remember:**

- NULL means missing or unknown.
- Zero (`0`) is a numeric value.
- Empty string (`''`) is a string containing no characters.

A column must allow NULL for this insertion to succeed.

---

## 10. INSERT INTO ... SELECT

We can insert records into one table using the results of a SELECT query from another table.

This is useful when copying or transferring selected records.

### Example

Create another table:

```sql
CREATE TABLE mca_students (
    student_id INT,
    name VARCHAR(100),
    course VARCHAR(50)
);
```

Insert records from the `students` table:

```sql
INSERT INTO mca_students (student_id, name, course)
SELECT student_id, name, course
FROM students
WHERE course = 'MCA';
```

This copies all students whose course is MCA into the `mca_students` table.

**Important:** The number and order of selected columns must match the target columns, and their data types must be compatible.

---

## 11. Using AUTO_INCREMENT with INSERT

MySQL supports `AUTO_INCREMENT` to automatically generate numeric IDs.

Example:

```sql
CREATE TABLE customers (
    customer_id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    city VARCHAR(50)
);
```

Now insert records without specifying the ID:

```sql
INSERT INTO customers (name, city)
VALUES
('Rahul', 'Chennai'),
('Priya', 'Bangalore'),
('Aman', 'Mangalore');
```

### Result

| customer_id | name | city |
|---:|---|---|
| 1 | Rahul | Chennai |
| 2 | Priya | Bangalore |
| 3 | Aman | Mangalore |

MySQL automatically generates the IDs.

**Note:** AUTO_INCREMENT values are not guaranteed to be continuous. Deleted rows and failed insertions can leave gaps.

---

## 12. Viewing Inserted Records

After inserting records, use SELECT to retrieve them.

Display all columns:

```sql
SELECT * FROM students;
```

Display selected columns:

```sql
SELECT name, course
FROM students;
```

Display records with a condition:

```sql
SELECT *
FROM students
WHERE course = 'MCA';
```

## 13. Common INSERT Errors

### Error 1: Duplicate Primary Key

```sql
INSERT INTO students
VALUES (101, 'Aman', 21, 'aman@gmail.com', 'MCA');
```

If student ID 101 already exists, MySQL rejects the insertion because the primary key must be unique.

### Error 2: Duplicate UNIQUE Value

```sql
INSERT INTO students
VALUES (108, 'Kiran', 22, 'rahul@gmail.com', 'BCA');
```

If `rahul@gmail.com` already exists, the insertion fails because of the UNIQUE constraint.

### Error 3: Missing NOT NULL Value

```sql
INSERT INTO students (student_id, age)
VALUES (109, 22);
```

This fails because the `name` column is NOT NULL and has no default value.

### Error 4: Incorrect Number of Values

```sql
INSERT INTO students
VALUES (110, 'Ravi', 22);
```

This fails because the table has five columns, but only three values were supplied.

### Error 5: Incorrect Data Type

```sql
INSERT INTO students
(student_id, name, age)
VALUES (111, 'Ravi', 'twenty');
```

The age column expects an integer. Depending on MySQL's SQL mode, this may produce an error or a conversion warning.

## 14. Important INSERT Syntax Summary

| Requirement | SQL Syntax |
|---|---|
| Insert one record | `INSERT INTO table VALUES (...);` |
| Insert using columns | `INSERT INTO table (col1, col2) VALUES (...);` |
| Insert multiple records | `INSERT INTO table VALUES (...), (...);` |
| Insert default value | `INSERT INTO table VALUES (..., DEFAULT);` |
| Insert NULL | `INSERT INTO table VALUES (..., NULL);` |
| Insert from another table | `INSERT INTO table SELECT ...;` |
| Automatic ID | Use `AUTO_INCREMENT` |

## 15. Interview Questions

**Q1. What is the INSERT statement?**

INSERT is a DML command used to add new records into a database table.

**Q2. What is the difference between INSERT with and without column names?**

Without column names, values must be supplied in the table's column order. With column names, we specify exactly where the values should go.

**Q3. Can we insert multiple rows using one INSERT statement?**

Yes. We can provide multiple value groups separated by commas.

**Q4. What happens if we omit a column during INSERT?**

MySQL uses its DEFAULT value if defined; otherwise, it generally assigns NULL if permitted. If the column is NOT NULL without a default, the statement fails.

**Q5. What is INSERT INTO SELECT?**

It inserts the results of a SELECT query into another table.

**Q6. What is AUTO_INCREMENT?**

It automatically generates sequential numeric values for a column, commonly used for primary keys.

**Q7. Can we insert NULL into a primary key column?**

No. Primary key columns cannot contain NULL.

---

## 17. Key Takeaways

- INSERT is a DML command.
- INSERT INTO adds records to an existing table.
- We can insert a single row or multiple rows.
- Specifying column names makes INSERT statements easier to maintain.
- DEFAULT inserts a column's predefined default value.
- NULL represents a missing or unknown value.
- INSERT INTO SELECT copies query results into another table.
- AUTO_INCREMENT automatically generates numeric IDs.
- Constraints are checked when inserting records.

**Remember:** CREATE TABLE creates the structure. INSERT adds the actual records to that structure.
