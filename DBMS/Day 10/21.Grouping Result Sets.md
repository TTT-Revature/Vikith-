# Grouping Result Sets in SQL (MySQL)

## 1. What Is GROUP BY?

The `GROUP BY` clause is used to group rows that have the same values in one or more columns.

It is commonly used with aggregate functions such as:

- `COUNT()`
- `SUM()`
- `AVG()`
- `MIN()`
- `MAX()`

Instead of calculating one result for the entire table, `GROUP BY` allows us to calculate separate results for each group.

### Example

Consider an `employees` table:

| employee_id | name | department | salary |
|---|---|---|---:|
| 1 | Rahul | IT | 50000 |
| 2 | Sneha | HR | 40000 |
| 3 | Arjun | IT | 60000 |
| 4 | Priya | Finance | 45000 |
| 5 | Kiran | HR | 35000 |
| 6 | Meera | Finance | 55000 |

We have six employees working in three departments.

Without grouping, `SUM(salary)` returns one total for all employees.

With `GROUP BY department`, we can calculate a separate total for each department.

---

## 2. GROUP BY Syntax

```sql
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;
```

### Understanding the syntax

- `SELECT`: Specifies the columns and calculations to display.
- `FROM`: Specifies the source table.
- `GROUP BY`: Groups rows having the same value in the specified column.
- Aggregate function: Performs calculations for each group.

---

## 3. Group Employees by Department

```sql
SELECT department
FROM employees
GROUP BY department;
```

**Output:**

| department |
|---|
| Finance |
| HR |
| IT |

Each department appears only once.

Note: The order of rows is not guaranteed unless we use `ORDER BY`.

---

## 4. GROUP BY with COUNT()

We can count how many employees belong to each department.

```sql
SELECT
    department,
    COUNT(*) AS total_employees
FROM employees
GROUP BY department;
```

**Output:**

| department | total_employees |
|---|---:|
| Finance | 2 |
| HR | 2 |
| IT | 2 |

### How does it work?

MySQL conceptually creates groups:

**IT Group**

| name | salary |
|---|---:|
| Rahul | 50000 |
| Arjun | 60000 |

Count = 2

**HR Group**

| name | salary |
|---|---:|
| Sneha | 40000 |
| Kiran | 35000 |

Count = 2

**Finance Group**

| name | salary |
|---|---:|
| Priya | 45000 |
| Meera | 55000 |

Count = 2

Each group gets its own aggregate calculation.

---

## 5. GROUP BY with SUM()

Calculate the total salary paid by each department.

```sql
SELECT
    department,
    SUM(salary) AS total_salary
FROM employees
GROUP BY department;
```

**Output:**

| department | total_salary |
|---|---:|
| Finance | 100000 |
| HR | 75000 |
| IT | 110000 |

### Calculation

| Department | Calculation | Total |
|---|---|---:|
| IT | 50000 + 60000 | 110000 |
| HR | 40000 + 35000 | 75000 |
| Finance | 45000 + 55000 | 100000 |

---

## 6. GROUP BY with AVG()

Calculate the average salary for each department.

```sql
SELECT
    department,
    AVG(salary) AS average_salary
FROM employees
GROUP BY department;
```

**Output:**

| department | average_salary |
|---|---:|
| Finance | 50000.00 |
| HR | 37500.00 |
| IT | 55000.00 |

This helps us compare average salaries across departments.

---

## 7. GROUP BY with MIN() and MAX()

We can find the highest and lowest salary in every department.

```sql
SELECT
    department,
    MIN(salary) AS lowest_salary,
    MAX(salary) AS highest_salary
FROM employees
GROUP BY department;
```

**Output:**

| department | lowest_salary | highest_salary |
|---|---:|---:|
| Finance | 45000 | 55000 |
| HR | 35000 | 40000 |
| IT | 50000 | 60000 |

---

## 8. Using Multiple Aggregate Functions with GROUP BY

We can use several aggregate functions in one query.

```sql
SELECT
    department,
    COUNT(*) AS total_employees,
    SUM(salary) AS total_salary,
    AVG(salary) AS average_salary,
    MIN(salary) AS lowest_salary,
    MAX(salary) AS highest_salary
FROM employees
GROUP BY department;
```

**Output:**

| department | total_employees | total_salary | average_salary | lowest_salary | highest_salary |
|---|---:|---:|---:|---:|---:|
| Finance | 2 | 100000 | 50000 | 45000 | 55000 |
| HR | 2 | 75000 | 37500 | 35000 | 40000 |
| IT | 2 | 110000 | 55000 | 50000 | 60000 |

This is a common pattern in business reports and data analytics.

## 9. GROUP BY with WHERE

The `WHERE` clause filters individual rows before grouping takes place.

### Example: Consider only employees earning more than ₹40,000.

```sql
SELECT
    department,
    COUNT(*) AS total_employees,
    AVG(salary) AS average_salary
FROM employees
WHERE salary > 40000
GROUP BY department;
```

**Output:**

| department | total_employees | average_salary |
|---|---:|---:|
| Finance | 2 | 50000.00 |
| IT | 2 | 55000.00 |

### Explanation

First, MySQL filters employees using:

```sql
WHERE salary > 40000
```

Remaining employees:

| name | department | salary |
|---|---|---:|
| Rahul | IT | 50000 |
| Arjun | IT | 60000 |
| Priya | Finance | 45000 |
| Meera | Finance | 55000 |

Then MySQL groups these employees by department and calculates the aggregates.

Kiran and Sneha are excluded because their salaries do not satisfy the condition.

## 10. GROUP BY with Multiple Columns

We can group records using more than one column.

### Example

Consider an `employees` table:

| employee_id | name | department | city | salary |
|---|---|---|---|---:|
| 1 | Rahul | IT | Chennai | 50000 |
| 2 | Sneha | HR | Bangalore | 40000 |
| 3 | Arjun | IT | Chennai | 60000 |
| 4 | Priya | IT | Bangalore | 45000 |
| 5 | Kiran | HR | Bangalore | 35000 |
| 6 | Meera | IT | Chennai | 55000 |

Suppose we want to count employees in each department and city combination.

```sql
SELECT
    department,
    city,
    COUNT(*) AS total_employees
FROM employees
GROUP BY department, city;
```

**Output:**

| department | city | total_employees |
|---|---|---:|
| HR | Bangalore | 2 |
| IT | Bangalore | 1 |
| IT | Chennai | 3 |

### How does it work?

MySQL creates groups based on the combination of both columns.

For example:

- IT + Chennai
- IT + Bangalore
- HR + Bangalore

Each unique combination becomes a separate group.

**Important:** `GROUP BY department, city` is different from grouping by department alone.

---

## 11. GROUP BY with ORDER BY

We can sort grouped results using `ORDER BY`.

### Example: Display departments from highest total salary to lowest.

```sql
SELECT
    department,
    SUM(salary) AS total_salary
FROM employees
GROUP BY department
ORDER BY total_salary DESC;
```

**Output:**

| department | total_salary |
|---|---:|
| IT | 110000 |
| Finance | 100000 |
| HR | 75000 |

### Example: Sort by department name

```sql
SELECT
    department,
    COUNT(*) AS total_employees
FROM employees
GROUP BY department
ORDER BY department ASC;
```

---

## 12. GROUP BY with LIMIT

We can combine `GROUP BY`, `ORDER BY`, and `LIMIT`.

### Example: Find the department with the highest total salary.

```sql
SELECT
    department,
    SUM(salary) AS total_salary
FROM employees
GROUP BY department
ORDER BY total_salary DESC
LIMIT 1;
```

**Output:**

| department | total_salary |
|---|---:|
| IT | 110000 |

This returns the department with the highest total salary.

---

## 13. GROUP BY and NULL Values

When grouping by a column containing NULL values, MySQL places rows with NULL in that column into one group.

Consider:

| employee_id | name | department |
|---|---|---|
| 1 | Rahul | IT |
| 2 | Sneha | HR |
| 3 | Arjun | IT |
| 4 | Priya | NULL |
| 5 | Kiran | NULL |

Query:

```sql
SELECT
    department,
    COUNT(*) AS total_employees
FROM employees
GROUP BY department;
```

**Output:**

| department | total_employees |
|---|---:|
| HR | 1 |
| IT | 2 |
| NULL | 2 |

Both rows with NULL department values belong to the same group.

## 14. Important GROUP BY Rule in MySQL

When using `GROUP BY`, every selected expression should generally be either:

1. Included in the `GROUP BY` clause, or
2. Used inside an aggregate function.

### Incorrect example

```sql
SELECT
    department,
    name,
    AVG(salary)
FROM employees
GROUP BY department;
```

Why is this problematic?

A department can contain multiple employee names. MySQL cannot determine which single name should represent the group.

With MySQL's default `ONLY_FULL_GROUP_BY` SQL mode, this query is rejected.

### Correct example

```sql
SELECT
    department,
    AVG(salary) AS average_salary
FROM employees
GROUP BY department;
```

Here, `department` is grouped and `salary` is aggregated.

If you need individual employee names along with department averages, we will learn techniques such as window functions and joins later.

## 15. Difference Between DISTINCT and GROUP BY

Both can produce unique values, but they serve different purposes.

| DISTINCT | GROUP BY |
|---|---|
| Removes duplicate result rows | Groups rows based on column values |
| Commonly used to retrieve unique values | Commonly used with aggregate functions |
| Does not require aggregate functions | Often used with aggregate functions |

### Using DISTINCT

```sql
SELECT DISTINCT department
FROM employees;
```

### Using GROUP BY

```sql
SELECT department
FROM employees
GROUP BY department;
```

Both queries return unique department values.

But `GROUP BY` also allows us to calculate summaries:

```sql
SELECT
    department,
    COUNT(*) AS total_employees
FROM employees
GROUP BY department;
```

## 16. Logical Query Processing Order

A simplified logical processing order for a grouped query is:

1. `FROM` – Identify the source table.
2. `WHERE` – Filter individual rows.
3. `GROUP BY` – Create groups.
4. `HAVING` – Filter groups.
5. `SELECT` – Calculate and select output expressions.
6. `DISTINCT` – Remove duplicate result rows.
7. `ORDER BY` – Sort the results.
8. `LIMIT` – Restrict the number of returned rows.

We will explore `HAVING` in the next topic.

## 17. Common Mistakes

### Mistake 1: Forgetting GROUP BY

Incorrect:

```sql
SELECT department, COUNT(*)
FROM employees;
```

This does not correctly produce a count for each department. With `ONLY_FULL_GROUP_BY`, it is rejected.

Correct:

```sql
SELECT department, COUNT(*)
FROM employees
GROUP BY department;
```

### Mistake 2: Selecting an ungrouped column

Incorrect:

```sql
SELECT department, name, SUM(salary)
FROM employees
GROUP BY department;
```

The employee name is neither grouped nor aggregated.

### Mistake 3: Confusing WHERE and GROUP BY

- `WHERE` filters individual rows.
- `GROUP BY` combines rows into groups.

### Mistake 4: Assuming GROUP BY automatically sorts results

Do not depend on the order of grouped results. Use `ORDER BY` whenever a particular order is required.

## 20. Key Takeaways

- `GROUP BY` groups rows having the same values.
- It is commonly used with aggregate functions.
- We can group by one or multiple columns.
- `WHERE` filters rows before grouping.
- `ORDER BY` sorts grouped results.
- `LIMIT` restricts the number of returned groups.
- NULL values form their own group.
- MySQL's `ONLY_FULL_GROUP_BY` prevents ambiguous non-grouped columns in aggregate queries.
