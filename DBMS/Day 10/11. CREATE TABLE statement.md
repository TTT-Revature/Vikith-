# CREATE TABLE Statement in SQL

## 1. Introduction

The `CREATE TABLE` statement is a DDL (Data Definition Language) command used to create a new table inside a database.

A table consists of:

- **Columns:** Define what type of information will be stored.
- **Rows:** Store individual records.
- **Data Types:** Specify the kind of values a column can contain.
- **Constraints:** Apply rules to the data.

Example: A college database may contain a `students` table with student ID, name, age, and course.

---

## 2. Basic Syntax

```sql
CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    column3 datatype
);
```

Explanation:

| Component | Description |
|---|---|
| `CREATE TABLE` | SQL command to create a table |
| `table_name` | Name of the table |
| `column1` | Name of the first column |
| `datatype` | Type of data the column stores |

---

## 3. Creating Your First Table

Let's create a table named `students`.

```sql
CREATE TABLE students (
    student_id INT,
    name VARCHAR(50),
    age INT,
    course VARCHAR(50)
);
```

This creates a table with four columns.

### Understanding the Structure

| Column | Data Type | Description |
|---|---|---|
| student_id | INT | Stores student ID |
| name | VARCHAR(50) | Stores student name |
| age | INT | Stores age |
| course | VARCHAR(50) | Stores course name |

**Important:** Creating a table does not automatically insert records. It only creates the table structure.

---

## 4. SQL Data Types Used in CREATE TABLE

A data type specifies what kind of value can be stored in a column.

### 4.1 Numeric Data Types

| Data Type | Description | Example |
|---|---|---|
| `INT` | Integer values | 100 |
| `BIGINT` | Large integer values | 9876543210 |
| `DECIMAL(10,2)` | Exact decimal values | 45000.50 |
| `FLOAT` | Approximate decimal values | 45.67 |
| `DOUBLE` | Approximate decimal values with greater precision | 12345.6789 |

Example:

```sql
CREATE TABLE products (
    product_id INT,
    price DECIMAL(10,2),
    quantity INT
);
```

### 4.2 String Data Types

| Data Type | Description |
|---|---|
| `CHAR(n)` | Fixed-length character string |
| `VARCHAR(n)` | Variable-length character string |
| `TEXT` | Stores longer text |

Example:

```sql
CREATE TABLE employees (
    employee_id INT,
    name VARCHAR(100),
    gender CHAR(1),
    address TEXT
);
```

### CHAR vs VARCHAR

- `CHAR(10)` uses a fixed-length character field.
- `VARCHAR(10)` stores variable-length strings up to 10 characters.

For example, a name such as `Rahul` can be stored in either type, but `VARCHAR` is generally more suitable for names of varying lengths.

### 4.3 Date and Time Data Types

| Data Type | Description | Example |
|---|---|---|
| `DATE` | Stores date | '2026-11-27' |
| `TIME` | Stores time | '10:30:00' |
| `DATETIME` | Stores date and time | '2026-11-27 10:30:00' |
| `TIMESTAMP` | Stores a date and time value with timestamp-related behavior | '2026-11-27 10:30:00' |

Example:

```sql
CREATE TABLE events (
    event_id INT,
    event_name VARCHAR(100),
    event_date DATE,
    event_time TIME
);
```

## 5. CREATE TABLE with Constraints

Constraints are rules applied to columns to maintain data accuracy and integrity.

### 5.1 PRIMARY KEY

A primary key uniquely identifies each record in a table.

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT
);
```

Rules:

- Must contain unique values.
- Cannot contain NULL values.
- A table can have only one primary key constraint, which may consist of multiple columns.

### 5.2 NOT NULL

Ensures that a column cannot contain NULL values.

```sql
CREATE TABLE students (
    student_id INT,
    name VARCHAR(50) NOT NULL
);
```

The `name` column must have a value.

### 5.3 UNIQUE

Ensures that values in a column are unique.

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    email VARCHAR(100) UNIQUE
);
```

Two students cannot have the same non-NULL email address.

### 5.4 DEFAULT

Provides a default value when no value is supplied for a column.

```sql
CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    name VARCHAR(50),
    department VARCHAR(50) DEFAULT 'IT'
);
```

If a department is not specified during insertion, it defaults to `IT`.

### 5.5 CHECK

Ensures that values satisfy a specified condition.

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT CHECK (age >= 18)
);
```

The age must be at least 18.

### 5.6 FOREIGN KEY

Creates a relationship between two tables.

```sql
CREATE TABLE departments (
    department_id INT PRIMARY KEY,
    department_name VARCHAR(50)
);

CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    name VARCHAR(50),
    department_id INT,
    FOREIGN KEY (department_id)
        REFERENCES departments(department_id)
);
```

Here:

- `departments` is the parent table.
- `employees` is the child table.
- `department_id` in `employees` references the primary key in `departments`.

This prevents an employee from referencing a department that does not exist, unless the foreign key is NULL.

---

## 6. Creating a Table with Multiple Constraints

Let's create a practical student table.

```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE,
    age INT CHECK (age >= 18),
    course VARCHAR(50) DEFAULT 'MCA',
    admission_date DATE
);
```

### Understanding the Table

| Column | Constraint | Purpose |
|---|---|---|
| student_id | PRIMARY KEY | Unique student identification |
| name | NOT NULL | Name cannot be empty |
| email | UNIQUE | Prevents duplicate non-NULL emails |
| age | CHECK | Age must be at least 18 |
| course | DEFAULT | Defaults to MCA |
| admission_date | None | Stores admission date |

---

## 7. Creating a Table Using Another Table

SQL also supports creating a table using the structure and data returned by a query.

In MySQL, we can use `CREATE TABLE ... AS SELECT`.

Example:

```sql
CREATE TABLE mca_students AS
SELECT student_id, name, age
FROM students
WHERE course = 'MCA';
```

This creates a new table using the selected columns and rows from `students`.

**Important:** `CREATE TABLE ... AS SELECT` does not automatically copy all original constraints, indexes, or other table properties. Define those separately if needed.

---

## 8. Creating a Table Only If It Does Not Exist

The `IF NOT EXISTS` clause prevents an error if a table with the same name already exists.

```sql
CREATE TABLE IF NOT EXISTS students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50)
);
```

If the table already exists, MySQL does not create another one.

---

## 9. Viewing the Table Structure

After creating a table, we can inspect its structure.

### DESCRIBE

```sql
DESCRIBE students;
```

Or:

```sql
DESC students;
```

This displays column names, data types, NULL settings, key information, default values, and other details.

### SHOW CREATE TABLE

```sql
SHOW CREATE TABLE students;
```

This displays the SQL statement used to define the table, including its constraints and other table properties.

---

## 10. Important Points to Remember

1. `CREATE TABLE` is a DDL command.
2. Creating a table defines its structure, not its records.
3. Every column must have a name and a data type.
4. Constraints help maintain data integrity.
5. A primary key uniquely identifies records.
6. A foreign key establishes a relationship between tables.
7. `IF NOT EXISTS` avoids an error when the table already exists.
8. Use `DESCRIBE` to inspect a table's structure.
9. Use `SHOW CREATE TABLE` to inspect its complete definition.

## 11. Interview Questions

**Q1. What is the purpose of CREATE TABLE?**

It creates a new table with specified columns, data types, and constraints.

**Q2. Is CREATE TABLE a DDL or DML command?**

DDL – Data Definition Language.

**Q3. Can a table have multiple primary keys?**

A table can have only one primary key constraint, but that key can consist of multiple columns (composite primary key).

**Q4. What is the difference between CHAR and VARCHAR?**

CHAR is fixed-length, whereas VARCHAR is variable-length.

**Q5. What happens if we create a table that already exists?**

MySQL returns an error unless `IF NOT EXISTS` is used.

**Q6. How can we view the structure of a table?**

Using `DESCRIBE table_name;` or `DESC table_name;`.

**Q7. Can we create a table without a primary key?**

Yes. A primary key is not mandatory, although it is generally recommended for tables that store identifiable records.

## 13. Key Takeaway

The `CREATE TABLE` statement is the foundation of database design.

Before inserting data into a database, we first define the table structure by specifying:

- Column names
- Data types
- Primary keys
- Foreign keys
- Constraints

**Remember:** CREATE TABLE defines how your data will be organized and stored.
