# Filtering Data in SQL (MySQL)

## 1. Introduction to Filtering Data

Filtering data means retrieving only the records that satisfy specific conditions.

In SQL, we mainly use the `WHERE` clause to filter records.

For example, imagine an employee table:

| employee_id | name | department | salary | city |
|---:|---|---|---:|---|
| 101 | Rahul | IT | 45000 | Chennai |
| 102 | Priya | HR | 35000 | Bangalore |
| 103 | Aman | IT | 55000 | Chennai |
| 104 | Sneha | Finance | 40000 | Mumbai |
| 105 | Arjun | IT | 60000 | Bangalore |
| 106 | Kiran | HR | 30000 | Chennai |

Suppose we want to retrieve only employees working in the IT department.

Instead of retrieving all employees, we can filter the records.

```sql
SELECT *
FROM employees
WHERE department = 'IT';
```

Output:

| employee_id | name | department | salary | city |
|---:|---|---|---:|---|
| 101 | Rahul | IT | 45000 | Chennai |
| 103 | Aman | IT | 55000 | Chennai |
| 105 | Arjun | IT | 60000 | Bangalore |

Only employees belonging to IT are returned.

---

## 2. WHERE Clause

The `WHERE` clause specifies the condition that records must satisfy.

### Syntax

```sql
SELECT column1, column2
FROM table_name
WHERE condition;
```

Example:

```sql
SELECT *
FROM employees
WHERE salary > 40000;
```

This retrieves employees whose salary is greater than 40000.

### Common Comparison Operators

| Operator | Meaning | Example |
|---|---|---|
| `=` | Equal to | `salary = 40000` |
| `!=` | Not equal to | `salary != 40000` |
| `<>` | Not equal to | `salary <> 40000` |
| `>` | Greater than | `salary > 40000` |
| `<` | Less than | `salary < 40000` |
| `>=` | Greater than or equal to | `salary >= 40000` |
| `<=` | Less than or equal to | `salary <= 40000` |

### Examples

Find employees earning exactly 40000:

```sql
SELECT *
FROM employees
WHERE salary = 40000;
```

Find employees earning less than 40000:

```sql
SELECT *
FROM employees
WHERE salary < 40000;
```

Find employees who are not from Chennai:

```sql
SELECT *
FROM employees
WHERE city != 'Chennai';
```

---

## 3. AND Operator

The `AND` operator combines multiple conditions.

All conditions must be TRUE for a record to be returned.

### Example

Find employees who work in IT and earn more than 40000.

```sql
SELECT *
FROM employees
WHERE department = 'IT'
AND salary > 40000;
```

Output:

| employee_id | name | department | salary | city |
|---:|---|---|---:|---|
| 103 | Aman | IT | 55000 | Chennai |
| 105 | Arjun | IT | 60000 | Bangalore |

Both conditions must be satisfied.

### Another Example

Find employees from Chennai who earn at least 30000.

```sql
SELECT *
FROM employees
WHERE city = 'Chennai'
AND salary >= 30000;
```

---

## 4. OR Operator

The `OR` operator returns records when at least one condition is TRUE.

### Example

Find employees working in IT or HR.

```sql
SELECT *
FROM employees
WHERE department = 'IT'
OR department = 'HR';
```

This returns employees from both departments.

### Another Example

Find employees who are from Chennai or earn more than 50000.

```sql
SELECT *
FROM employees
WHERE city = 'Chennai'
OR salary > 50000;
```

A record only needs to satisfy one of these conditions.

---

## 5. NOT Operator

The `NOT` operator reverses a condition.

### Example

Find employees who are not working in IT.

```sql
SELECT *
FROM employees
WHERE NOT department = 'IT';
```

Another way:

```sql
SELECT *
FROM employees
WHERE department != 'IT';
```

Both queries return employees whose department is not IT.

---

## 6. Combining AND, OR and NOT

We can combine multiple logical operators in one query.

### Example

Find employees who work in IT and earn more than 40000, or employees who work in HR.

```sql
SELECT *
FROM employees
WHERE (department = 'IT' AND salary > 40000)
OR department = 'HR';
```

Parentheses make the intended condition grouping clear.

### Important: Operator Precedence

SQL evaluates `AND` before `OR` when parentheses are not used.

For example:

```sql
SELECT *
FROM employees
WHERE department = 'IT'
OR department = 'HR'
AND salary > 40000;
```

This is interpreted as:

```sql
WHERE department = 'IT'
OR (department = 'HR' AND salary > 40000);
```

Use parentheses whenever you want to make the grouping explicit.

## 7. BETWEEN Operator

The `BETWEEN` operator filters values within a specified range.

Both boundary values are included.

### Syntax

```sql
SELECT *
FROM table_name
WHERE column_name BETWEEN value1 AND value2;
```

### Example

Find employees earning between 35000 and 50000.

```sql
SELECT *
FROM employees
WHERE salary BETWEEN 35000 AND 50000;
```

Output:

| employee_id | name | salary |
|---:|---|---:|
| 101 | Rahul | 45000 |
| 102 | Priya | 35000 |
| 104 | Sneha | 40000 |

This is equivalent to:

```sql
SELECT *
FROM employees
WHERE salary >= 35000
AND salary <= 50000;
```

### NOT BETWEEN

Find employees whose salaries are outside the range of 35000 to 50000.

```sql
SELECT *
FROM employees
WHERE salary NOT BETWEEN 35000 AND 50000;
```

---

## 8. IN Operator

The `IN` operator checks whether a value matches any value in a specified list.

It is useful when filtering using multiple possible values.

### Example

Find employees working in IT or HR.

```sql
SELECT *
FROM employees
WHERE department IN ('IT', 'HR');
```

This is equivalent to:

```sql
SELECT *
FROM employees
WHERE department = 'IT'
OR department = 'HR';
```

### NOT IN

Find employees who are not working in IT or HR.

```sql
SELECT *
FROM employees
WHERE department NOT IN ('IT', 'HR');
```

This returns employees from other departments, such as Finance.

## 9. LIKE Operator – Pattern Matching

The `LIKE` operator is used to filter text values based on a pattern.

It supports two important wildcard characters.

| Wildcard | Meaning |
|---|---|
| `%` | Matches zero or more characters |
| `_` | Matches exactly one character |

### 9.1 Names Starting With a Character

Find employees whose names start with A.

```sql
SELECT *
FROM employees
WHERE name LIKE 'A%';
```

Result: Aman, Arjun.

### 9.2 Names Ending With a Character

Find employees whose names end with a.

```sql
SELECT *
FROM employees
WHERE name LIKE '%a';
```

Result: Priya, Sneha.

### 9.3 Names Containing a Character or Pattern

Find employees whose names contain the letter a.

```sql
SELECT *
FROM employees
WHERE name LIKE '%a%';
```

### 9.4 Names With a Specific Second Character

Find names whose second character is a.

```sql
SELECT *
FROM employees
WHERE name LIKE '_a%';
```

The underscore represents exactly one character.

### 9.5 Names With Exactly Five Characters

```sql
SELECT *
FROM employees
WHERE name LIKE '_____';
```

Five underscores represent five characters.

**Note:** MySQL's default string comparison behavior is often case-insensitive, depending on the column's collation.

## 10. IS NULL and IS NOT NULL

NULL represents a missing or unknown value.

We cannot reliably check NULL using the equality operator.

### IS NULL

Find employees whose city is missing.

```sql
SELECT *
FROM employees
WHERE city IS NULL;
```

### IS NOT NULL

Find employees whose city is available.

```sql
SELECT *
FROM employees
WHERE city IS NOT NULL;
```

**Important:** Use `IS NULL` instead of `= NULL`.

## 12. Filtering with ORDER BY and LIMIT

Filtering can be combined with sorting and limiting.

### Example 1: Highest-Paid IT Employee

```sql
SELECT *
FROM employees
WHERE department = 'IT'
ORDER BY salary DESC
LIMIT 1;
```

### Example 2: Two Lowest-Paid Employees

```sql
SELECT *
FROM employees
ORDER BY salary ASC
LIMIT 2;
```

### Example 3: Employees Earning More Than 35000, Sorted by Salary

```sql
SELECT *
FROM employees
WHERE salary > 35000
ORDER BY salary DESC;
```

The WHERE clause filters the records before ORDER BY sorts the qualifying records.

## 13. Common Mistakes While Filtering

### Mistake 1: Using = NULL

Incorrect:

```sql
SELECT *
FROM employees
WHERE city = NULL;
```

Correct:

```sql
SELECT *
FROM employees
WHERE city IS NULL;
```

### Mistake 2: Forgetting Quotes Around Text

Incorrect:

```sql
SELECT *
FROM employees
WHERE department = IT;
```

Correct:

```sql
SELECT *
FROM employees
WHERE department = 'IT';
```

### Mistake 3: Incorrect AND and OR Grouping

Always use parentheses when combining conditions with different logical operators if the intended grouping is not obvious.

### Mistake 4: Confusing BETWEEN Boundaries

`BETWEEN 30000 AND 50000` includes both 30000 and 50000.

### Mistake 5: Using LIKE Without Wildcards

`LIKE 'A'` matches the exact string A. Use `LIKE 'A%'` to find names starting with A.

## 14. Interview Questions

**Q1. What is filtering in SQL?**

Filtering means retrieving only records that satisfy specified conditions, usually using the WHERE clause.

**Q2. What is the difference between AND and OR?**

AND requires all conditions to be TRUE, whereas OR requires at least one condition to be TRUE.

**Q3. What is the difference between IN and BETWEEN?**

IN checks membership in a list of values. BETWEEN checks whether a value falls within a range, including its boundaries.

**Q4. What is the purpose of LIKE?**

LIKE performs pattern matching using `%` and `_` wildcards.

**Q5. What is the difference between IS NULL and IS NOT NULL?**

IS NULL finds missing values, while IS NOT NULL finds values that are not NULL.

**Q6. Does BETWEEN include its boundary values?**

Yes. Both the lower and upper boundary values are included.

**Q7. What happens when AND and OR are used together?**

AND has higher precedence than OR. Parentheses can be used to control the grouping.

**Q8. Can WHERE be used with ORDER BY?**

Yes. WHERE filters records, and ORDER BY sorts the resulting records.

## 16. Key Takeaways

- WHERE is used to filter records.
- Comparison operators compare values.
- AND requires all conditions to be true.
- OR requires at least one condition to be true.
- NOT reverses a condition.
- BETWEEN filters a range.
- IN matches values from a list.
- LIKE performs pattern matching.
- IS NULL checks missing values.
- ORDER BY sorts filtered records.
- LIMIT restricts the number of returned records.

**Remember:** Filtering helps you retrieve exactly the records you need instead of processing the entire table.
