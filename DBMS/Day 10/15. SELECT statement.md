# SELECT Statement in SQL (MySQL)

## 1. Introduction

The `SELECT` statement is used to retrieve data from one or more tables in a database.

It belongs to **DQL (Data Query Language)** in the commonly used SQL classification.

For example, imagine we have a `students` table containing:

| student_id | name | age | course |
|---:|---|---:|---|
| 101 | Rahul | 22 | MCA |
| 102 | Priya | 23 | BCA |
| 103 | Aman | 21 | MCA |
| 104 | Sneha | 22 | BCA |
| 105 | Arjun | 24 | MCA |

We can use SELECT to retrieve all students or only specific information.

---

## 2. Basic SELECT Syntax

```sql
SELECT column1, column2
FROM table_name;
```

Explanation:

| Keyword | Purpose |
|---|---|
| SELECT | Specifies which columns to retrieve |
| FROM | Specifies the table from which data is retrieved |

Example:

```sql
SELECT name, age
FROM students;
```

Output:

| name | age |
|---|---:|
| Rahul | 22 |
| Priya | 23 |
| Aman | 21 |
| Sneha | 22 |
| Arjun | 24 |

This query retrieves only the `name` and `age` columns.

---

## 3. SELECT * – Retrieve All Columns

The asterisk (`*`) means all columns.

Example:

```sql
SELECT *
FROM students;
```

Output:

| student_id | name | age | course |
|---:|---|---:|---|
| 101 | Rahul | 22 | MCA |
| 102 | Priya | 23 | BCA |
| 103 | Aman | 21 | MCA |
| 104 | Sneha | 22 | BCA |
| 105 | Arjun | 24 | MCA |

**Important:** In production applications, selecting only the required columns is often better than using `SELECT *`.

---

## 4. SELECT DISTINCT – Remove Duplicate Values

The `DISTINCT` keyword returns unique values and removes duplicate combinations from the result.

Example:

```sql
SELECT DISTINCT course
FROM students;
```

Output:

| course |
|---|
| MCA |
| BCA |

Why only two records?

Because three students belong to MCA and two belong to BCA. DISTINCT returns each course only once.

### DISTINCT on Multiple Columns

```sql
SELECT DISTINCT course, age
FROM students;
```

This returns unique combinations of course and age.

For example, if multiple students have the same course and age, that combination appears only once.

---

## 5. WHERE – Filter Records

The `WHERE` clause retrieves records that satisfy a specified condition.

Syntax:

```sql
SELECT column1, column2
FROM table_name
WHERE condition;
```

Example:

```sql
SELECT *
FROM students
WHERE age > 22;
```

Output:

| student_id | name | age | course |
|---:|---|---:|---|
| 102 | Priya | 23 | BCA |
| 105 | Arjun | 24 | MCA |

Only students older than 22 are returned.

### Common Comparison Operators

| Operator | Meaning |
|---|---|
| `=` | Equal to |
| `!=` or `<>` | Not equal to |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |

Examples:

```sql
SELECT * FROM students WHERE age = 22;

SELECT * FROM students WHERE age != 22;

SELECT * FROM students WHERE age >= 23;

SELECT * FROM students WHERE course = 'MCA';
```

---

## 6. AND, OR, NOT Operators

These operators help combine multiple conditions.

### 6.1 AND

Returns records when all conditions are true.

```sql
SELECT *
FROM students
WHERE age >= 22 AND course = 'MCA';
```

Output:

| student_id | name | age | course |
|---:|---|---:|---|
| 105 | Arjun | 24 | MCA |

Both conditions must be satisfied.

### 6.2 OR

Returns records when at least one condition is true.

```sql
SELECT *
FROM students
WHERE course = 'MCA' OR age = 23;
```

Output:

| student_id | name | age | course |
|---:|---|---:|---|
| 101 | Rahul | 22 | MCA |
| 102 | Priya | 23 | BCA |
| 103 | Aman | 21 | MCA |
| 105 | Arjun | 24 | MCA |

### 6.3 NOT

Reverses a condition.

```sql
SELECT *
FROM students
WHERE NOT course = 'MCA';
```

This returns students who are not enrolled in MCA.

---

## 7. BETWEEN – Filter Within a Range

The `BETWEEN` operator checks whether a value falls within a specified range.

It includes both boundary values.

Example:

```sql
SELECT *
FROM students
WHERE age BETWEEN 21 AND 23;
```

Output:

| student_id | name | age | course |
|---:|---|---:|---|
| 101 | Rahul | 22 | MCA |
| 102 | Priya | 23 | BCA |
| 103 | Aman | 21 | MCA |
| 104 | Sneha | 22 | BCA |

This is equivalent to:

```sql
SELECT *
FROM students
WHERE age >= 21 AND age <= 23;
```

---

## 8. IN – Match Multiple Values

The `IN` operator checks whether a value matches any value in a given list.

Example:

```sql
SELECT *
FROM students
WHERE course IN ('MCA', 'BCA');
```

This returns students belonging to either MCA or BCA.

It is equivalent to:

```sql
SELECT *
FROM students
WHERE course = 'MCA'
OR course = 'BCA';
```

### NOT IN

```sql
SELECT *
FROM students
WHERE course NOT IN ('MCA');
```

This returns students whose course is not MCA.

---

## 9. LIKE – Pattern Matching

The `LIKE` operator is used to search for a particular pattern in text.

It commonly uses two wildcards:

| Wildcard | Meaning |
|---|---|
| `%` | Matches zero or more characters |
| `_` | Matches exactly one character |

### Names Starting with a Letter

```sql
SELECT *
FROM students
WHERE name LIKE 'A%';
```

Returns names starting with A.

Example: Aman, Arjun.

### Names Ending with a Letter

```sql
SELECT *
FROM students
WHERE name LIKE '%a';
```

Returns names ending with a.

Example: Priya, Sneha.

### Names Containing a Pattern

```sql
SELECT *
FROM students
WHERE name LIKE '%an%';
```

Returns names containing the sequence `an`.

### Single Character Matching

```sql
SELECT *
FROM students
WHERE name LIKE '_a%';
```

Matches names whose second character is `a`.

---

## 10. IS NULL and IS NOT NULL

NULL represents a missing or unknown value.

We should use `IS NULL` or `IS NOT NULL` to check for NULL values.

### IS NULL

```sql
SELECT *
FROM students
WHERE email IS NULL;
```

Returns students whose email is missing.

### IS NOT NULL

```sql
SELECT *
FROM students
WHERE email IS NOT NULL;
```

Returns students whose email has a non-NULL value.

**Important:** Do not use `= NULL` or `!= NULL` to check for NULL values.

---

## 11. ORDER BY – Sort Records

The `ORDER BY` clause sorts query results.

It supports two main directions:

- ASC – Ascending order
- DESC – Descending order

### Ascending Order

```sql
SELECT *
FROM students
ORDER BY age ASC;
```

Output is sorted from the smallest age to the largest.

### Descending Order

```sql
SELECT *
FROM students
ORDER BY age DESC;
```

Output is sorted from the largest age to the smallest.

### Sorting by Multiple Columns

```sql
SELECT *
FROM students
ORDER BY course ASC, age DESC;
```

First, records are sorted by course in ascending order.

For students with the same course, age is sorted in descending order.

**Note:** ASC is the default direction when no direction is specified.

---

## 12. LIMIT – Restrict Number of Records

The `LIMIT` clause restricts how many rows are returned.

Example:

```sql
SELECT *
FROM students
LIMIT 3;
```

Returns at most three rows.

### LIMIT with ORDER BY

```sql
SELECT *
FROM students
ORDER BY age DESC
LIMIT 2;
```

Returns the two oldest students.

### LIMIT with OFFSET

OFFSET skips a specified number of rows before returning results.

```sql
SELECT *
FROM students
LIMIT 2 OFFSET 1;
```

This skips the first row and returns the next two rows.

An alternative MySQL syntax is:

```sql
SELECT *
FROM students
LIMIT 1, 2;
```

Here:
- 1 = Number of rows to skip.
- 2 = Number of rows to return.

This is useful for pagination.

---

## 13. AS – Column Aliases

An alias gives a temporary alternative name to a column in the query result.

Example:

```sql
SELECT
    name AS student_name,
    age AS student_age
FROM students;
```

Output:

| student_name | student_age |
|---|---:|
| Rahul | 22 |
| Priya | 23 |
| Aman | 21 |
| Sneha | 22 |
| Arjun | 24 |

The actual column names in the database are unchanged.

### Table Alias

Aliases can also be used for tables.

```sql
SELECT s.name, s.age
FROM students AS s;
```

Here, `s` is an alias for the `students` table.

The `AS` keyword is optional for table aliases in MySQL:

```sql
SELECT s.name, s.age
FROM students s;
```

## 14. SELECT with Expressions and Calculations

We can perform calculations directly inside SELECT statements.

Suppose we have an `employees` table:

| employee_id | name | salary |
|---:|---|---:|
| 101 | Rahul | 30000 |
| 102 | Priya | 40000 |
| 103 | Aman | 35000 |

### Calculate Annual Salary

```sql
SELECT
    name,
    salary,
    salary * 12 AS annual_salary
FROM employees;
```

Output:

| name | salary | annual_salary |
|---|---:|---:|
| Rahul | 30000 | 360000 |
| Priya | 40000 | 480000 |
| Aman | 35000 | 420000 |

### Calculate Salary After a 10% Increase

```sql
SELECT
    name,
    salary,
    salary * 1.10 AS increased_salary
FROM employees;
```

This calculates a new value for the result without modifying the original salary stored in the table.

---

## 15. SQL Query Execution Order

When writing a SELECT query, we usually write clauses in this order:

```sql
SELECT column_name
FROM table_name
WHERE condition
GROUP BY column_name
HAVING condition
ORDER BY column_name
LIMIT number;
```

However, the logical processing order is different:

1. FROM
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT
6. DISTINCT
7. ORDER BY
8. LIMIT

We will study GROUP BY and HAVING in detail in upcoming topics.

Understanding this order helps explain why certain aliases cannot be used in WHERE.

## 16. Complete Practical Example

Let's create and populate a table.

```sql
CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    name VARCHAR(100),
    department VARCHAR(50),
    salary DECIMAL(10,2),
    city VARCHAR(50)
);
```

Insert records:

```sql
INSERT INTO employees VALUES
(101, 'Rahul', 'IT', 45000, 'Chennai'),
(102, 'Priya', 'HR', 35000, 'Bangalore'),
(103, 'Aman', 'IT', 55000, 'Chennai'),
(104, 'Sneha', 'Finance', 40000, 'Mumbai'),
(105, 'Arjun', 'IT', 60000, 'Bangalore'),
(106, 'Kiran', 'HR', 30000, 'Chennai');
```

### Query 1: Display All Employees

```sql
SELECT * FROM employees;
```

### Query 2: Display Employees from IT

```sql
SELECT *
FROM employees
WHERE department = 'IT';
```

### Query 3: Employees Earning More Than 40000

```sql
SELECT name, salary
FROM employees
WHERE salary > 40000;
```

### Query 4: Employees from Chennai

```sql
SELECT *
FROM employees
WHERE city = 'Chennai';
```

### Query 5: Employees Sorted by Salary

```sql
SELECT *
FROM employees
ORDER BY salary DESC;
```

### Query 6: Top Three Highest-Paid Employees

```sql
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 3;
```

### Query 7: Employees from IT or HR

```sql
SELECT *
FROM employees
WHERE department IN ('IT', 'HR');
```

### Query 8: Employees Earning Between 30000 and 50000

```sql
SELECT *
FROM employees
WHERE salary BETWEEN 30000 AND 50000;
```

## 17. Interview Questions

**Q1. What is the SELECT statement?**

SELECT is used to retrieve data from one or more database tables.

**Q2. What is the difference between SELECT * and SELECT column_name?**

SELECT * retrieves all columns, while SELECT column_name retrieves only the specified columns.

**Q3. What is DISTINCT?**

DISTINCT removes duplicate rows from the query result.

**Q4. What is the difference between WHERE and ORDER BY?**

WHERE filters records, while ORDER BY sorts the returned records.

**Q5. What is the difference between ASC and DESC?**

ASC sorts in ascending order, while DESC sorts in descending order.

**Q6. What is LIMIT?**

LIMIT restricts the maximum number of rows returned by a query.

**Q7. What is an alias?**

An alias is a temporary name given to a column or table in a query.

**Q8. What is the difference between IN and BETWEEN?**

IN checks whether a value matches one of several specified values. BETWEEN checks whether a value falls within a range, including both boundaries.

**Q9. What is the difference between LIKE and =?**

`=` checks for equality, while LIKE supports pattern matching using wildcards.

**Q10. How do we check for NULL values?**

Use IS NULL or IS NOT NULL.

## 19. Key Takeaways

- SELECT retrieves data from database tables.
- SELECT * retrieves all columns.
- DISTINCT removes duplicate rows from the result.
- WHERE filters records.
- AND, OR, and NOT combine conditions.
- BETWEEN checks a range.
- IN checks multiple possible values.
- LIKE performs pattern matching.
- IS NULL checks for missing values.
- ORDER BY sorts results.
- LIMIT restricts returned rows.
- AS creates temporary aliases.
- SELECT can perform calculations without changing stored data.

**Remember:** SELECT is the foundation of SQL querying. Mastering it will make JOINs, GROUP BY, subqueries, and advanced SQL much easier.
