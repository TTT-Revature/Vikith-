# Python Logical, Membership and Identity Operators

## 1. Logical Operators

Logical operators are used to combine multiple conditions or reverse a condition. They return `True` or `False`.

Python has three logical operators:

| Operator | Meaning |
|---|---|
| `and` | True if both conditions are True |
| `or` | True if at least one condition is True |
| `not` | Reverses the Boolean result |

### A. AND Operator

Returns `True` only when both conditions are true.

```python
age = 23
has_id = True

print(age >= 18 and has_id)  # True
print(age >= 18 and False)   # False
```

**Common usage: Checking multiple conditions**

```python
username = "admin"
password = "12345"

if username == "admin" and password == "12345":
    print("Login successful")
else:
    print("Invalid credentials")
```

### B. OR Operator

Returns `True` if at least one condition is true.

```python
age = 17
has_permission = True

print(age >= 18 or has_permission)  # True
print(age >= 18 or False)           # False
```

**Common usage: Allowing multiple conditions**

```python
day = "Sunday"

if day == "Saturday" or day == "Sunday":
    print("Weekend")
else:
    print("Working day")
```

### C. NOT Operator

Reverses the Boolean value.

```python
is_logged_in = False

print(not is_logged_in)  # True
```

**Common usage: Checking whether something is not true**

```python
is_blocked = False

if not is_blocked:
    print("Access allowed")
```

### D. Combining Logical Operators

You can combine `and`, `or`, and `not` in one expression.

```python
age = 22
has_id = True
is_blocked = False

if age >= 18 and has_id and not is_blocked:
    print("Entry allowed")
```

**Operator precedence:** `not` is evaluated before `and`, and `and` before `or`. Use parentheses to make complex conditions easier to understand.

### E. Short-Circuit Evaluation

Python may stop evaluating a logical expression when the result is already determined.

**With `and`:**

```python
print(False and 10 / 0)
# False
```

The second expression is not evaluated because the first value is already `False`.

**With `or`:**

```python
print(True or 10 / 0)
# True
```

The second expression is not evaluated because the first value is already `True`.

### F. Logical Operators Return Values

Important: `and` and `or` do not always return Boolean values. They return one of their operands.

```python
print(10 and 20)       # 20
print(0 and 20)        # 0

print(10 or 20)        # 10
print(0 or 20)         # 20

print(not 10)          # False
print(not 0)           # True
```

- `and` returns the first falsy operand, or the last operand if all are truthy.
- `or` returns the first truthy operand, or the last operand if all are falsy.

## 2. Membership Operators

Membership operators check whether a value exists inside a sequence or collection.

Python has two membership operators:

| Operator | Meaning |
|---|---|
| `in` | Checks whether an element exists |
| `not in` | Checks whether an element does not exist |

### A. `in` Operator

Returns `True` if the specified value exists.

**Usage 1: With Lists**

```python
fruits = ["apple", "banana", "mango"]

print("apple" in fruits)   # True
print("orange" in fruits)  # False
```

**Usage 2: With Strings**

Checks whether a substring exists inside a string.

```python
message = "Welcome to Python"

print("Python" in message)  # True
print("Java" in message)    # False
```

**Usage 3: With Tuples**

```python
numbers = (10, 20, 30)

print(20 in numbers)  # True
```

**Usage 4: With Sets**

```python
numbers = {10, 20, 30}

print(10 in numbers)  # True
```

**Usage 5: With Dictionaries**

Membership checks dictionary keys, not values.

```python
student = {
    "name": "Vikith",
    "age": 23
}

print("name" in student)       # True
print("Vikith" in student)     # False
print("Vikith" in student.values())  # True
```

### B. `not in` Operator

Returns `True` if the specified value does not exist.

```python
fruits = ["apple", "banana", "mango"]

print("orange" not in fruits)  # True
print("apple" not in fruits)   # False
```

### C. Practical Usage: Checking User Input

```python
allowed_users = ["admin", "manager", "employee"]

username = "admin"

if username in allowed_users:
    print("User is authorized")
else:
    print("Access denied")
```

### D. Practical Usage: Checking Substrings

```python
email = "user@gmail.com"

if "@" in email and "." in email:
    print("Basic email format check passed")
else:
    print("Invalid format")
```

Note: This is only a basic check, not complete email validation.

## 3. Identity Operators

Identity operators check whether two variables refer to the same object in memory.

Python has two identity operators:

| Operator | Meaning |
|---|---|
| `is` | Checks whether both references point to the same object |
| `is not` | Checks whether they point to different objects |

### A. `is` Operator

Returns `True` when both variables refer to the same object.

```python
a = [10, 20, 30]
b = a

print(a is b)  # True
```

Both variables refer to the same list.

### B. `is not` Operator

Returns `True` when two variables refer to different objects.

```python
a = [10, 20, 30]
b = [10, 20, 30]

print(a is not b)  # True
```

Both lists contain the same values, but they are separate objects.

### C. Difference Between `is` and `==`

This is one of the most important concepts in Python.

- `==` checks whether values are equal.
- `is` checks whether objects are identical.

```python
a = [10, 20, 30]
b = [10, 20, 30]

print(a == b)  # True
print(a is b)  # False
```

### D. Identity with Assignment

```python
original = [1, 2, 3]
copied = original

print(original == copied)  # True
print(original is copied)  # True
```

Assignment does not create a new list. Both variables refer to the same object.

### E. Identity with `None`

A common Python practice is to check whether a variable contains `None` using `is`.

```python
result = None

if result is None:
    print("No result available")
```

Use `is None` rather than `== None`.

---

## 4. Difference Between All Three Categories

| Category | Operators | Purpose |
|---|---|---|
| Logical | `and`, `or`, `not` | Combine or reverse conditions |
| Membership | `in`, `not in` | Check whether a value exists |
| Identity | `is`, `is not` | Check whether references point to the same object |

## 5. Important Points to Remember

1. `and` requires both conditions to be true.
2. `or` requires at least one condition to be true.
3. `not` reverses a Boolean result.
4. `and` and `or` can return operands instead of Boolean values.
5. `in` checks for membership in collections and strings.
6. Dictionary membership checks keys by default.
7. `is` checks object identity, not value equality.
8. `==` checks value equality.
9. Use `is None` to check for `None`.
10. Python uses short-circuit evaluation for `and` and `or`.
