

# Python JSON Serialization and Deserialization

## 1. What Is JSON?

JSON stands for **JavaScript Object Notation**.

It is a lightweight text format used to store and exchange data between applications.

JSON is commonly used in:
- REST APIs
- Web applications
- Configuration files
- Data exchange between frontend and backend
- Storing structured data

### Example JSON

```json
{
    "name": "Vikith",
    "age": 24,
    "skills": ["Python", "Java"],
    "is_employed": true
}
```

JSON supports these data types:

| JSON Type | Example | Python Equivalent |
|---|---|---|
| String | `"Vikith"` | `str` |
| Number | `25`, `85.5` | `int`, `float` |
| Boolean | `true`, `false` | `True`, `False` |
| Array | `[10, 20, 30]` | `list` |
| Object | `{"name": "Vikith"}` | `dict` |
| Null | `null` | `None` |

**Important:** JSON uses lowercase `true`, `false`, and `null`. Python uses `True`, `False`, and `None`.

## 2. Python JSON Module

Python provides a built-in module called `json` to work with JSON data.

No external installation is required.

```python
import json
```

The module provides methods to convert Python objects into JSON and JSON data into Python objects.

## 3. What Is Serialization?

Serialization is the process of converting a Python object into a JSON-formatted string.

In simple terms:

**Python Object → JSON String**

Use `json.dumps()` to serialize Python data.

### Example

```python
import json

student = {
    "name": "Vikith",
    "age": 24,
    "course": "Python"
}

json_data = json.dumps(student)

print(json_data)
print(type(json_data))
```

**Output:**

```text
{"name": "Vikith", "age": 24, "course": "Python"}
<class 'str'>
```

`json.dumps()` returns a string, not a dictionary.

## 4. Understanding dumps() Formatting

The `dumps()` method supports formatting options.

### Using indent

The `indent` parameter makes JSON output easier to read.

```python
import json

student = {
    "name": "Vikith",
    "age": 24,
    "skills": ["Python", "Java"]
}

json_data = json.dumps(student, indent=4)

print(json_data)
```

**Output:**

```json
{
    "name": "Vikith",
    "age": 24,
    "skills": [
        "Python",
        "Java"
    ]
}
```

### Using sort_keys

The `sort_keys=True` parameter sorts dictionary keys alphabetically.

```python
import json

data = {
    "name": "Vikith",
    "age": 24,
    "city": "Chennai"
}

print(json.dumps(data, sort_keys=True))
```

**Output:**

```json
{"age": 24, "city": "Chennai", "name": "Vikith"}
```

### Using separators

The `separators` parameter controls the separators between JSON elements.

```python
import json

data = {"name": "Vikith", "age": 24}

print(json.dumps(data, separators=(",", ":")))
```

**Output:**

```json
{"name":"Vikith","age":24}
```

## 5. What Is Deserialization?

Deserialization is the process of converting a JSON-formatted string into a Python object.

In simple terms:

**JSON String → Python Object**

Use `json.loads()` to deserialize JSON data.

### Example

```python
import json

json_data = '{"name": "Vikith", "age": 24, "course": "Python"}'

student = json.loads(json_data)

print(student)
print(type(student))
```

**Output:**

```text
{'name': 'Vikith', 'age': 24, 'course': 'Python'}
<class 'dict'>
```

Now the JSON string has been converted into a Python dictionary.

### Accessing Deserialized Data

```python
import json

json_data = '{"name": "Vikith", "age": 24}'

student = json.loads(json_data)

print(student["name"])
print(student["age"])
```

**Output:**

```text
Vikith
24
```

## 6. dumps() vs loads()

| Method | Purpose | Input | Output |
|---|---|---|---|
| `json.dumps()` | Serialization | Python object | JSON string |
| `json.loads()` | Deserialization | JSON string | Python object |

Remember:

- `dumps()` converts Python data into a JSON string.
- `loads()` converts a JSON string into Python data.

## 7. Writing JSON into a File

Use `json.dump()` to serialize Python data directly into a JSON file.

### Example

```python
import json

student = {
    "name": "Vikith",
    "age": 24,
    "skills": ["Python", "Java"]
}

with open("student.json", "w", encoding="utf-8") as file:
    json.dump(student, file, indent=4)
```

This creates a file named `student.json`.

**File Content:**

```json
{
    "name": "Vikith",
    "age": 24,
    "skills": [
        "Python",
        "Java"
    ]
}
```

`json.dump()` writes JSON data directly into a file.

## 8. Reading JSON from a File

Use `json.load()` to read JSON data from a file and convert it into a Python object.

### Example

```python
import json

with open("student.json", "r", encoding="utf-8") as file:
    student = json.load(file)

print(student)
print(student["name"])
```

**Output:**

```text
{'name': 'Vikith', 'age': 24, 'skills': ['Python', 'Java']}
Vikith
```

## 9. dump() vs load()

| Method | Purpose | Input | Output |
|---|---|---|---|
| `json.dump()` | Write JSON to a file | Python object and file | Writes JSON |
| `json.load()` | Read JSON from a file | File object | Python object |

### All Four JSON Methods

| Method | Operation | Works With |
|---|---|---|
| `dumps()` | Python → JSON string | String |
| `loads()` | JSON string → Python | String |
| `dump()` | Python → JSON file | File |
| `load()` | JSON file → Python | File |

## 10. Python to JSON Data Type Conversion

Python objects are converted into corresponding JSON types.

| Python Type | JSON Type |
|---|---|
| `dict` | Object |
| `list` | Array |
| `tuple` | Array |
| `str` | String |
| `int` | Number |
| `float` | Number |
| `True` | `true` |
| `False` | `false` |
| `None` | `null` |

### Example

```python
import json

data = {
    "name": "Vikith",
    "marks": (85, 90, 95),
    "active": True,
    "address": None
}

json_data = json.dumps(data, indent=4)

print(json_data)
```

**Output:**

```json
{
    "name": "Vikith",
    "marks": [
        85,
        90,
        95
    ],
    "active": true,
    "address": null
}
```

Notice that a Python tuple becomes a JSON array. When converted back, it becomes a Python list.

## 11. Handling JSON Errors

Invalid JSON data can cause a `JSONDecodeError` during deserialization.

### Example

```python
import json

data = '{"name": "Vikith", "age": }'

try:
    result = json.loads(data)
    print(result)

except json.JSONDecodeError as error:
    print("Invalid JSON:", error)
```

**Output:**

```text
Invalid JSON: ...
```

The exact error message depends on the invalid JSON content.

### Common JSON Errors

| Error | Reason |
|---|---|
| `JSONDecodeError` | Invalid JSON syntax |
| `TypeError` | Unsupported Python object during serialization |
| `FileNotFoundError` | JSON file does not exist |
| `PermissionError` | Insufficient file permissions |

## 12. Handling Unsupported Python Objects

JSON supports a limited set of data types. Some Python objects, such as `set` and custom class instances, cannot be serialized directly.

### Example

```python
import json

data = {
    "name": "Vikith",
    "skills": {"Python", "Java"}
}

print(json.dumps(data))
```

This raises a `TypeError` because sets are not supported by default.

### Using default Parameter

The `default` parameter allows us to define how unsupported objects should be converted.

```python
import json

data = {
    "name": "Vikith",
    "skills": {"Python", "Java"}
}

json_data = json.dumps(data, default=list)

print(json_data)
```

**Possible Output:**

```json
{"name": "Vikith", "skills": ["Python", "Java"]}
```

Set order is not guaranteed.

## 13. Real-World Example: Student Data Management

```python
import json

student = {
    "id": 101,
    "name": "Vikith",
    "course": "MCA",
    "skills": ["Python", "Java", "SQL"],
    "is_active": True
}

# Serialization: Python dictionary to JSON string
json_data = json.dumps(student, indent=4)

print("JSON Data:")
print(json_data)

# Deserialization: JSON string to Python dictionary
python_data = json.loads(json_data)

print("\nStudent Name:", python_data["name"])
print("Course:", python_data["course"])
print("Skills:", python_data["skills"])
```

**Output:**

```text
JSON Data:
{
    "id": 101,
    "name": "Vikith",
    "course": "MCA",
    "skills": [
        "Python",
        "Java",
        "SQL"
    ],
    "is_active": true
}

Student Name: Vikith
Course: MCA
Skills: ['Python', 'Java', 'SQL']
```

## 14. Important Points

- JSON stands for JavaScript Object Notation.
- Python provides the built-in `json` module.
- Serialization converts Python objects into JSON.
- Deserialization converts JSON into Python objects.
- `dumps()` returns a JSON string.
- `loads()` converts a JSON string into a Python object.
- `dump()` writes JSON data into a file.
- `load()` reads JSON data from a file.
- `indent` improves JSON readability.
- `sort_keys=True` sorts dictionary keys.
- Invalid JSON can raise `JSONDecodeError`.
- JSON does not directly support every Python data type.
