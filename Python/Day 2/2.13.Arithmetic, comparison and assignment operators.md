# Python Operators

Operators are special symbols used to perform operations on variables and values.

## 1. Arithmetic Operators

Arithmetic operators perform mathematical operations.

| Operator | Name | Example | Result |
|---|---|---|---|
| `+` | Addition | `10 + 5` | `15` |
| `-` | Subtraction | `10 - 5` | `5` |
| `*` | Multiplication | `10 * 5` | `50` |
| `/` | Division | `10 / 5` | `2.0` |
| `//` | Floor Division | `10 // 3` | `3` |
| `%` | Modulus | `10 % 3` | `1` |
| `**` | Exponentiation | `2 ** 3` | `8` |

### Examples

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

### Important Concepts

**1. Division (`/`)**

Always returns a float.

```python
print(10 / 2)  # 5.0
```

**2. Floor Division (`//`)**

Returns the quotient rounded down to the nearest integer value (or an integral float if an operand is a float).

```python
print(10 // 3)    # 3
print(10.0 // 3)  # 3.0
print(-10 // 3)   # -4
```

**3. Modulus (`%`)**

Returns the remainder after division.

```python
print(10 % 3)  # 1
print(15 % 4)  # 3
```

**4. Exponentiation (`**`)**

Raises a number to a power.

```python
print(2 ** 3)  # 8
print(5 ** 2)  # 25
```

## 2. Comparison Operators

Comparison operators compare two values and return a Boolean result (`True` or `False`).

| Operator | Name | Example | Result |
|---|---|---|---|
| `==` | Equal to | `10 == 10` | `True` |
| `!=` | Not equal to | `10 != 5` | `True` |
| `>` | Greater than | `10 > 5` | `True` |
| `<` | Less than | `10 < 5` | `False` |
| `>=` | Greater than or equal to | `10 >= 10` | `True` |
| `<=` | Less than or equal to | `5 <= 10` | `True` |

### Examples

```python
a = 10
b = 5

print(a == b)  # False
print(a != b)  # True
print(a > b)   # True
print(a < b)   # False
print(a >= b)  # True
print(a <= b)  # False
```

### Important: `=` vs `==`

- `=` assigns a value to a variable.
- `==` compares two values.

```python
x = 10

print(x == 10)  # True
```

### Chained Comparisons

Python allows multiple comparisons in one expression.

```python
age = 23

print(18 <= age <= 60)  # True
```

This checks whether `age` is between 18 and 60, inclusive.

## 3. Assignment Operators

Assignment operators assign values to variables or update their existing values.

| Operator | Example | Equivalent Expression |
|---|---|---|
| `=` | `x = 10` | Assign 10 to x |
| `+=` | `x += 5` | `x = x + 5` |
| `-=` | `x -= 5` | `x = x - 5` |
| `*=` | `x *= 5` | `x = x * 5` |
| `/=` | `x /= 5` | `x = x / 5` |
| `//=` | `x //= 5` | `x = x // 5` |
| `%=` | `x %= 5` | `x = x % 5` |
| `**=` | `x **= 2` | `x = x ** 2` |

### Examples

```python
x = 10

x += 5
print(x)  # 15

x -= 3
print(x)  # 12

x *= 2
print(x)  # 24

x /= 4
print(x)  # 6.0

x //= 2
print(x)  # 3.0

x %= 2
print(x)  # 1.0

x **= 3
print(x)  # 1.0
```

### Multiple Assignment

Python allows assigning multiple variables in one statement.

```python
a, b, c = 10, 20, 30

print(a)  # 10
print(b)  # 20
print(c)  # 30
```

### Same Value Assignment

```python
a = b = c = 100

print(a, b, c)  # 100 100 100
```

### Swapping Variables

Python allows swapping values without using a temporary variable.

```python
a = 10
b = 20

a, b = b, a

print(a)  # 20
print(b)  # 10
```

## 4. Quick Revision

| Category | Purpose |
|---|---|
| Arithmetic | Performs mathematical operations |
| Comparison | Compares two values |
| Assignment | Assigns or updates variable values |
