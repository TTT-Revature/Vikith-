# Python While Loops

## 1. What is a While Loop?

A `while` loop repeatedly executes a block of code as long as the given condition is `True`.

It is useful when we do not know in advance how many times a loop needs to execute.

### Syntax

```python
while condition:
    # Code executes while condition is True
```

### Example

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Output:
```text
1
2
3
4
5
```

**Explanation:**
1. `count` starts at 1.
2. Python checks whether `count <= 5`.
3. If the condition is true, the loop executes.
4. `count += 1` increases the value.
5. The loop stops when the condition becomes false.

## 2. Different Types of While Loop Usage

### A. Print Numbers from 1 to 10

```python
i = 1

while i <= 10:
    print(i)
    i += 1
```

### B. Reverse Counting

```python
i = 10

while i >= 1:
    print(i)
    i -= 1
```

### C. Print Even Numbers

```python
i = 2

while i <= 20:
    print(i)
    i += 2
```

### D. Print Odd Numbers

```python
i = 1

while i < 20:
    print(i)
    i += 2
```

### E. Sum of Numbers

```python
i = 1
total = 0

while i <= 5:
    total += i
    i += 1

print(total)  # 15
```

## 3. While Loop with User Input

A while loop can repeatedly ask the user for input until a specific condition is met.

### Example: Password Validation

```python
password = ""

while password != "admin123":
    password = input("Enter password: ")

print("Login successful")
```

The loop continues until the correct password is entered.

### Example: Keep Asking Until Positive Number

```python
number = 0

while number <= 0:
    number = int(input("Enter a positive number: "))

print("Valid number:", number)
```

## 4. Infinite While Loop

An infinite loop runs continuously because its condition never becomes false.

### Example

```python
while True:
    print("Running...")
```

This loop continues until it is interrupted or terminated using `break`.

### Practical Example: Menu-Driven Program

```python
while True:
    print("1. Start")
    print("2. Exit")

    choice = input("Enter your choice: ")

    if choice == "1":
        print("Program started")
    elif choice == "2":
        print("Exiting...")
        break
    else:
        print("Invalid choice")
```

## 5. break Statement

The `break` statement immediately terminates the loop.

### Example

```python
i = 1

while i <= 10:
    if i == 5:
        break

    print(i)
    i += 1
```

Output:
```text
1
2
3
4
```

## 6. continue Statement

The `continue` statement skips the current iteration and moves to the next iteration.

### Example

```python
i = 0

while i < 5:
    i += 1

    if i == 3:
        continue

    print(i)
```

Output:
```text
1
2
4
5
```

**Important:** Update the loop variable before `continue` when necessary. Otherwise, you may accidentally create an infinite loop.

## 7. While Loop with else

Python supports an `else` block with a while loop.

The `else` block executes when the loop condition becomes false, but not when the loop is terminated using `break`.

### Example

```python
i = 1

while i <= 3:
    print(i)
    i += 1
else:
    print("Loop completed")
```

Output:
```text
1
2
3
Loop completed
```

### Example with break

```python
i = 1

while i <= 5:
    if i == 3:
        break

    print(i)
    i += 1
else:
    print("Loop completed")
```

Output:
```text
1
2
```

The `else` block does not execute because the loop was terminated using `break`.

## 8. Nested While Loops

A nested while loop means placing one while loop inside another.

### Example: Number Pattern

```python
i = 1

while i <= 3:
    j = 1

    while j <= 3:
        print(j, end=" ")

        j += 1

    print()
    i += 1
```

Output:
```text
1 2 3
1 2 3
1 2 3
```

### Example: Star Pattern

```python
i = 1

while i <= 4:
    j = 1

    while j <= i:
        print("*", end=" ")
        j += 1

    print()
    i += 1
```

Output:
```text
*
* *
* * *
* * * *
```

## 9. Difference Between for and while Loops

| For Loop | While Loop |
|---|---|
| Used to iterate over an iterable | Used to repeat while a condition is true |
| Commonly used when iterating through sequences | Commonly used when repetitions depend on a condition |
| Iteration is handled by the loop | Condition and updates are usually managed manually |
| Can use `range()` | Does not require `range()` |

### For Loop

```python
for i in range(1, 6):
    print(i)
```

### While Loop

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

Both produce the same output.

## 10. Important Points to Remember

1. A while loop executes as long as its condition is true.
2. Initialize the loop variable before the loop.
3. Update the loop variable to avoid accidental infinite loops.
4. `break` immediately terminates the loop.
5. `continue` skips the current iteration.
6. `while True` creates an infinite loop unless it is stopped.
7. A while loop can have an `else` block.
8. Nested while loops are used for patterns and repeated operations.
