# Python import vs from ... import

## 1. Using import

The `import` statement imports the complete module.

We use the module name followed by the dot (`.`) operator to access its functions and variables.

**Syntax:**

```python
import module_name
```

### Example

**File: `calculator.py`**

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

pi = 3.14
```

**File: `main.py`**

```python
import calculator

print(calculator.add(10, 20))
print(calculator.subtract(20, 5))
print(calculator.pi)
```

**Output:**

```text
30
15
3.14
```

Here, `calculator` is the module name. We access its members using `calculator.add()`, `calculator.subtract()`, and `calculator.pi`.

## 2. Using from ... import

The `from ... import` statement imports specific functions, variables, or classes from a module.

**Syntax:**

```python
from module_name import function_name
```

### Example

**File: `main.py`**

```python
from calculator import add, subtract

print(add(10, 20))
print(subtract(20, 5))
```

**Output:**

```text
30
15
```

We can call the imported functions directly without writing the module name.

## 3. Importing Multiple Members

We can import multiple functions or variables from the same module.

```python
from calculator import add, subtract, pi

print(add(5, 5))
print(subtract(10, 5))
print(pi)
```

**Output:**

```text
10
5
3.14
```

## 4. Using Aliases with as

The `as` keyword gives an imported module or member another name.

### Module Alias

```python
import calculator as calc

print(calc.add(10, 20))
```

**Output:**

```text
30
```

### Function Alias

```python
from calculator import multiply as mul

print(mul(5, 4))
```

**Output:**

```text
20
```

## 5. Importing Everything Using *

We can import all public names from a module using `*`.

```python
from calculator import *

print(add(10, 20))
print(subtract(20, 5))
print(pi)
```

**Output:**

```text
30
15
3.14
```

However, wildcard imports are generally discouraged because they can cause naming conflicts and make code harder to understand.

## 6. Importing Built-in Modules

Python provides standard library modules that we can import directly.

### Using import

```python
import math

print(math.sqrt(25))
print(math.factorial(5))
```

**Output:**

```text
5.0
120
```

### Using from ... import

```python
from math import sqrt, factorial

print(sqrt(25))
print(factorial(5))
```

**Output:**

```text
5.0
120
```

Both approaches produce the same result.

## 7. Main Differences

| Feature | import | from ... import |
|---|---|---|
| Imports | Module | Specific members |
| Access | Uses module name | Direct access |
| Syntax | `import math` | `from math import sqrt` |
| Function call | `math.sqrt(25)` | `sqrt(25)` |
| Naming conflicts | Less likely | More likely |
| Readability | Clear module origin | Shorter function calls |

## 8. Important Points

- `import` imports a module.
- `from ... import` imports selected members from a module.
- Use the dot operator to access members when using `import`.
- Use `as` to create aliases.
- `from module import *` imports public names and is generally discouraged.
- Both approaches allow code reuse.
- Python normally caches imported modules in `sys.modules`, so importing an already-loaded module does not normally execute it again.

## 9. When to Use What?

**Use `import` when:**
- You want to access multiple functions from a module.
- You want to clearly identify where a function comes from.
- You want to avoid accidental naming conflicts.

**Use `from ... import` when:**
- You need only a few specific functions or classes.
- You want shorter function calls.
- The imported names are clear and do not conflict with other names.
