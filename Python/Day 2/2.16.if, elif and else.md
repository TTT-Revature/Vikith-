# Python Conditional Statements – if, elif and else

## 1. What are Conditional Statements?

Conditional statements are used to execute different blocks of code depending on whether a condition is `True` or `False`.

Python provides:
- `if`
- `elif`
- `else`

## 2. if Statement

The `if` statement executes a block of code only when the condition is `True`.

### Syntax

```python
if condition:
    # Code executes if condition is True
```

### Example

```python
age = 20

if age >= 18:
    print("You are eligible to vote")
```

Output:
```text
You are eligible to vote
```

## 3. if-else Statement

The `else` block executes when the `if` condition is `False`.

### Syntax

```python
if condition:
    # Executes if True
else:
    # Executes if False
```

### Example

```python
age = 16

if age >= 18:
    print("Eligible to vote")
else:
    print("Not eligible to vote")
```

Output:
```text
Not eligible to vote
```

## 4. if-elif-else Statement

The `elif` keyword means "else if". It is used to check multiple conditions.

Python checks conditions from top to bottom. The first condition that is `True` executes its block, and the remaining conditions are skipped.

### Syntax

```python
if condition1:
    # Code for condition1
elif condition2:
    # Code for condition2
elif condition3:
    # Code for condition3
else:
    # Code if all conditions are False
```

### Example: Grade Calculation

```python
marks = 85

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Grade D")
```

Output:
```text
Grade B
```

## 5. Multiple Independent if Statements

You can use multiple `if` statements when more than one condition should be checked independently.

```python
age = 25

if age >= 18:
    print("Adult")

if age >= 21:
    print("Eligible for this age-restricted activity")

if age >= 25:
    print("Age is 25 or above")
```

All three conditions are checked separately.

**Important difference:**
- `if-elif-else`: Executes only the first matching branch.
- Multiple `if` statements: Every condition is checked independently.

## 6. Nested if Statements

An `if` statement inside another `if` statement is called a nested if.

### Example: Login Validation

```python
username = "admin"
password = "12345"

if username == "admin":
    if password == "12345":
        print("Login successful")
    else:
        print("Incorrect password")
else:
    print("Invalid username")
```

The inner condition is checked only if the outer condition is `True`.

## 7. Using Logical Operators in Conditions

Logical operators can combine multiple conditions.

### Using AND

Both conditions must be true.

```python
age = 22
has_id = True

if age >= 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")
```

### Using OR

At least one condition must be true.

```python
day = "Sunday"

if day == "Saturday" or day == "Sunday":
    print("Holiday")
else:
    print("Working day")
```

### Using NOT

Reverses the condition.

```python
is_blocked = False

if not is_blocked:
    print("Access allowed")
```

## 8. Checking Multiple Conditions with Membership Operators

Membership operators can be used inside conditional statements.

### Example: Checking User Roles

```python
role = "admin"

if role in ["admin", "manager"]:
    print("Access granted")
else:
    print("Access denied")
```

### Example: Checking a Character

```python
character = "a"

if character in "aeiou":
    print("Vowel")
else:
    print("Consonant")
```

## 9. Conditional Expression (Ternary Operator)

A conditional expression allows you to write a simple if-else in one line.

### Syntax

```python
value_if_true if condition else value_if_false
```

### Example

```python
age = 20

result = "Adult" if age >= 18 else "Minor"

print(result)
```

Output:
```text
Adult
```

### Another Example

```python
a = 10
b = 20

largest = a if a > b else b

print(largest)  # 20
```

## 10. Checking Empty Collections

Python treats empty collections as `False` and non-empty collections as `True`.

```python
fruits = []

if fruits:
    print("List contains elements")
else:
    print("List is empty")
```

Output:
```text
List is empty
```

This also works with empty strings, tuples, sets, and dictionaries.

## 11. Using pass Statement

The `pass` statement is used when a statement is syntactically required but you do not want to execute any code yet.

```python
age = 20

if age >= 18:
    pass
else:
    print("Minor")
```

`pass` does nothing. It is useful as a placeholder while developing code.

## 12. Important Rules

1. Use a colon (`:`) after `if`, `elif`, and `else`.
2. Indentation is mandatory in Python.
3. You can use multiple `elif` blocks.
4. Only one `else` block is allowed in an if-elif-else chain.
5. `else` is optional.
6. `elif` cannot be used without an initial `if`.
7. Python checks conditions from top to bottom.
8. Once a branch executes, the remaining branches in that chain are skipped.
9. Use logical operators to combine conditions.
10. Use parentheses to make complex conditions easier to understand.
