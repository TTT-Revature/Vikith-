# Nested Loops in Python

A **nested loop** is a loop inside another loop.

The inner loop executes completely for every single iteration of the outer loop.

## 1. Nested `for` Loop

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
```

**Output:**

```text
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3
```

**How it works:**

- Outer loop runs 3 times.
- For every outer iteration, the inner loop runs 3 times.
- Total executions: `3 × 3 = 9`.

## 2. Nested Loop with Patterns

```python
for i in range(1, 5):
    for j in range(i):
        print("*", end=" ")
    print()
```

**Output:**

```text
*
* *
* * *
* * * *
```

The outer loop controls the rows, and the inner loop controls the columns.

## 3. Nested `while` Loop

```python
i = 1

while i <= 3:
    j = 1

    while j <= 3:
        print(i, j)
        j += 1

    i += 1
```

The inner counter `j` must be reset for every outer iteration.

## 4. Using `break` in Nested Loops

`break` terminates only the nearest enclosing loop.

```python
for i in range(1, 4):
    for j in range(1, 4):
        if j == 2:
            break
        print(i, j)
```

**Output:**

```text
1 1
2 1
3 1
```

Here, `break` stops the inner loop, but the outer loop continues.

## 5. Using `continue` in Nested Loops

```python
for i in range(1, 4):
    for j in range(1, 4):
        if j == 2:
            continue
        print(i, j)
```

**Output:**

```text
1 1
1 3
2 1
2 3
3 1
3 3
```

When `j == 2`, that inner-loop iteration is skipped.
