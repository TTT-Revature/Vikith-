

# Python Nested Functions and Closures

## 1. What Is a Nested Function?

A nested function is a function defined inside another function.

The outer function contains the inner function, and the inner function can be called from within the outer function.

### Syntax

```python
def outer_function():

    def inner_function():
        print("Inside inner function")

    inner_function()


outer_function()
```

**Output:**

```text
Inside inner function
```

Here:
- `outer_function()` is the outer function.
- `inner_function()` is the nested function.
- The inner function is called from inside the outer function.

## 2. Understanding Nested Functions

A nested function can access variables defined in its outer function.

```python
def outer_function():

    message = "Hello Python"

    def inner_function():
        print(message)

    inner_function()


outer_function()
```

**Output:**

```text
Hello Python
```

The inner function can access `message` even though it is defined in the outer function.

This is possible because of Python's scope rules.

## 3. Returning a Nested Function

An outer function can return the inner function instead of calling it directly.

```python
def outer_function():

    def inner_function():
        print("Hello from inner function")

    return inner_function


result = outer_function()

result()
```

**Output:**

```text
Hello from inner function
```

Notice the difference:

```python
return inner_function
```

Returns the function object.

```python
return inner_function()
```

Calls the inner function and returns its result.

This distinction is important when working with closures and decorators.

## 4. What Is a Closure?

A closure is a function that remembers and can access variables from its enclosing scope, even after the outer function has finished executing.

In simple terms:

A closure allows an inner function to remember variables from the outer function.

### Example

```python
def outer_function():

    message = "Hello Python"

    def inner_function():
        print(message)

    return inner_function


result = outer_function()

result()
```

**Output:**

```text
Hello Python
```

### How It Works

1. `outer_function()` is called.
2. The variable `message` is created.
3. `inner_function` is defined.
4. The outer function returns the inner function.
5. The outer function finishes execution.
6. We call `result()`.
7. The inner function still accesses `message`.

The inner function remembers the variable even after the outer function has finished.

This is called a closure.

## 5. Closure with Parameters

Closures can remember values passed as arguments to the outer function.

```python
def multiplier(factor):

    def multiply(number):
        return number * factor

    return multiply


double = multiplier(2)
triple = multiplier(3)

print(double(10))
print(triple(10))
```

**Output:**

```text
20
30
```

### Understanding the Execution

```python
double = multiplier(2)
```

Creates a closure that remembers `factor = 2`.

```python
triple = multiplier(3)
```

Creates another closure that remembers `factor = 3`.

Both functions use the same nested function logic but remember different values.

## 6. Modifying Enclosing Variables Using nonlocal

By default, assigning a value to a variable inside a nested function creates a local variable.

To modify a variable from the enclosing function, use the `nonlocal` keyword.

### Example Without nonlocal

```python
def outer():

    count = 10

    def inner():
        count = 20
        print("Inner:", count)

    inner()

    print("Outer:", count)


outer()
```

**Output:**

```text
Inner: 20
Outer: 10
```

The inner function creates its own local `count`.

The outer variable remains unchanged.

### Example With nonlocal

```python
def outer():

    count = 10

    def inner():
        nonlocal count
        count = 20

    inner()

    print(count)


outer()
```

**Output:**

```text
20
```

`nonlocal` allows the inner function to modify the variable in its nearest enclosing function scope.

## 7. Closure Maintaining State

Closures can maintain state between function calls without using global variables.

### Example: Counter

```python
def create_counter():

    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment


counter = create_counter()

print(counter())
print(counter())
print(counter())
```

**Output:**

```text
1
2
3
```

### How It Works

- `create_counter()` initializes `count` to `0`.
- It returns the `increment` function.
- The returned function remembers `count`.
- Each call increases the same variable.
- The updated value is returned.

The variable remains available through the closure.

## 8. Multiple Closures with Independent State

Each call to an outer function can create a separate closure with its own state.

```python
def create_counter():

    count = 0

    def increment():
        nonlocal count
        count += 1
        return count

    return increment


counter1 = create_counter()
counter2 = create_counter()

print(counter1())
print(counter1())

print(counter2())
print(counter2())
```

**Output:**

```text
1
2
1
2
```

`counter1` and `counter2` maintain separate `count` variables.

Changing one does not affect the other.

## 9. Inspecting Closure Variables

Python provides the `__closure__` attribute to inspect the variables captured by a closure.

```python
def outer():

    message = "Hello"

    def inner():
        print(message)

    return inner


result = outer()

print(result.__closure__)
print(result.__closure__[0].cell_contents)
```

**Output:**

```text
(<cell at ...: str object at ...>,)
Hello
```

- `__closure__` contains closure cells.
- `cell_contents` accesses the value stored in a closure cell.

The exact memory addresses in the output depend on the execution.

## 10. Nested Functions vs Closures

| Feature | Nested Function | Closure |
|---|---|---|
| Definition | Function inside another function | Function that retains access to enclosing variables |
| Outer variables | Can access them while the outer scope is active | Can retain access after the outer function returns |
| Returning inner function | Not required | Commonly returned |
| State preservation | Not necessarily | Can maintain captured state |
| Example | Helper function inside another function | Counter or multiplier closure |

**Important:** Every closure involves a nested function or another callable with an enclosing scope, but not every nested function is necessarily a closure.

## 11. Real-World Example: Bank Account Balance

Closures can be used to maintain private state.

```python
def create_account(initial_balance):

    balance = initial_balance

    def deposit(amount):
        nonlocal balance

        balance += amount

        return balance

    return deposit


account = create_account(1000)

print(account(500))
print(account(200))
print(account(300))
```

**Output:**

```text
1500
1700
2000
```

The `balance` variable is maintained inside the closure and can be modified through the returned function.

The variable is not directly exposed as a global variable.

## 12. Real-World Use Cases

- **State management:** Maintain values between function calls.
- **Decorators:** Wrap functions and retain configuration.
- **Function factories:** Create customized functions using parameters.
- **Callbacks:** Remember data needed for later execution.
- **Encapsulation:** Keep state inside a closure instead of exposing it globally.
- **Configuration:** Create functions with predefined settings.

## 13. Important Points

- A nested function is defined inside another function.
- An inner function can access variables from its enclosing function.
- An outer function can return an inner function.
- A closure retains access to enclosing variables after the outer function returns.
- `nonlocal` allows modification of enclosing function variables.
- Each closure can maintain independent state.
- `__closure__` provides access to captured closure cells.
- Closures are commonly used in decorators and function factories.
