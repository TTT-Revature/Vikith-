# Python For Loops and Range()

## 1. What is a For Loop?

A `for` loop is used to iterate over a sequence or any iterable object and execute a block of code for each element.

Common iterables include:
- Lists
- Tuples
- Strings
- Dictionaries
- Sets
- Ranges

### Syntax

```python
for variable in iterable:
    # Code to execute
```

### Example

```python
fruits = ["Apple", "Banana", "Mango"]

for fruit in fruits:
    print(fruit)
```

Output:
```text
Apple
Banana
Mango
```

## 2. Using For Loop with Different Data Types

### A. Iterating Through a List

```python
numbers = [10, 20, 30, 40]

for number in numbers:
    print(number)
```

### B. Iterating Through a Tuple

```python
colors = ("Red", "Green", "Blue")

for color in colors:
    print(color)
```

### C. Iterating Through a String

A string is iterable, so a loop processes one character at a time.

```python
name = "Python"

for character in name:
    print(character)
```

### D. Iterating Through a Set

```python
numbers = {10, 20, 30, 40}

for number in numbers:
    print(number)
```

Note: Sets are unordered collections, so do not depend on a particular iteration order.

### E. Iterating Through a Dictionary

By default, a dictionary loop iterates through its keys.

```python
student = {
    "name": "Vikith",
    "age": 23,
    "course": "MCA"
}

for key in student:
    print(key)
```

**Using `values()`**

```python
for value in student.values():
    print(value)
```

**Using `items()`**

```python
for key, value in student.items():
    print(key, value)
```

## 3. The range() Function

The `range()` function generates a sequence of integers. It is commonly used with `for` loops.

### Three Types of range()

**A. range(stop)**

Starts from 0 and stops before the specified number.

```python
for i in range(5):
    print(i)
```

Output:
```text
0
1
2
3
4
```

**B. range(start, stop)**

Starts from the specified starting number and stops before the ending number.

```python
for i in range(2, 7):
    print(i)
```

Output:
```text
2
3
4
5
6
```

**C. range(start, stop, step)**

The step determines the increment or decrement between numbers.

```python
for i in range(1, 10, 2):
    print(i)
```

Output:
```text
1
3
5
7
9
```

### Using Negative Step

```python
for i in range(10, 0, -2):
    print(i)
```

Output:
```text
10
8
6
4
2
```

**Important:** The stop value is excluded from the generated sequence.

## 4. Practical Uses of range()

### A. Print Numbers from 1 to 10

```python
for i in range(1, 11):
    print(i)
```

### B. Print Even Numbers

```python
for i in range(2, 21, 2):
    print(i)
```

### C. Print Odd Numbers

```python
for i in range(1, 20, 2):
    print(i)
```

### D. Multiplication Table

```python
number = 5

for i in range(1, 11):
    print(number, "x", i, "=", number * i)
```

### E. Sum of Numbers

```python
total = 0

for i in range(1, 6):
    total += i

print(total)  # 15
```

### F. Reverse Counting

```python
for i in range(10, 0, -1):
    print(i)
```

## 5. Using `enumerate()` with For Loops

`enumerate()` provides both the index and value while iterating over an iterable.

```python
fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

Output:
```text
0 Apple
1 Banana
2 Mango
```

You can specify a starting index:

```python
for index, fruit in enumerate(fruits, start=1):
    print(index, fruit)
```

## 6. Using `zip()` with For Loops

`zip()` combines elements from multiple iterables based on their positions.

```python
names = ["Vikith", "Rahul", "Arun"]
ages = [23, 24, 22]

for name, age in zip(names, ages):
    print(name, age)
```

Output:
```text
Vikith 23
Rahul 24
Arun 22
```

By default, `zip()` stops when the shortest iterable is exhausted.

## 7. Nested For Loops

A nested `for` loop means placing one `for` loop inside another.

### Example: Multiplication Pattern

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
```

### Example: Star Pattern

```python
for i in range(1, 5):
    for j in range(i):
        print("*", end=" ")
    print()
```

Output:
```text
*
* *
* * *
* * * *
```

## 8. Using break and continue

### A. break

The `break` statement terminates the loop immediately.

```python
for i in range(1, 6):
    if i == 3:
        break
    print(i)
```

Output:
```text
1
2
```

### B. continue

The `continue` statement skips the current iteration and moves to the next iteration.

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

Output:
```text
1
2
4
5
```

## 9. For Loop with else

Python allows an `else` block with a `for` loop.

The `else` block executes when the loop finishes normally, without being terminated by `break`.

```python
for i in range(1, 4):
    print(i)
else:
    print("Loop completed")
```

Output:
```text
1
2
3
Loop completed
```

### Example with break

```python
for i in range(1, 5):
    if i == 3:
        break
    print(i)
else:
    print("Loop completed")
```

Output:
```text
1
2
```

The `else` block does not execute because the loop was terminated using `break`.

## 10. Important Points to Remember

1. A `for` loop iterates over an iterable.
2. Lists, tuples, strings, sets, and dictionaries are iterable.
3. `range()` generates a sequence of integers.
4. The stop value in `range()` is excluded.
5. `range(start, stop, step)` supports positive and negative steps.
6. `enumerate()` provides index and value.
7. `zip()` iterates through multiple iterables together.
8. Nested loops are loops inside other loops.
9. `break` terminates a loop.
10. `continue` skips the current iteration.
11. A loop's `else` block executes when the loop finishes normally without `break`.
