# Set and Dictionary Comprehensions in Python

Comprehensions provide a concise way to create collections from existing iterables.

Python supports different types of comprehensions:

- List comprehension
- Set comprehension
- Dictionary comprehension
- Generator expression

This topic focuses on **set comprehensions** and **dictionary comprehensions**.

## 1. Set Comprehension

Set comprehension creates a new set using a concise expression.

A set stores unique elements and does not maintain a guaranteed insertion order.

### Syntax

```python
new_set = {expression for item in iterable}
```

| Component | Description |
|---|---|
| `expression` | Value to add to the set |
| `item` | Variable representing each element |
| `iterable` | Collection to iterate over |

### Example 1: Creating a Set of Squares

```python
numbers = [1, 2, 3, 4, 5]

squares = {number ** 2 for number in numbers}

print(squares)
```

**Output:**

```text
{1, 4, 9, 16, 25}
```

The order of elements in a set is not guaranteed.

### Example 2: Removing Duplicates

```python
numbers = [1, 2, 2, 3, 3, 4, 5, 5]

unique_numbers = {number for number in numbers}

print(unique_numbers)
```

**Output:**

```text
{1, 2, 3, 4, 5}
```

Set comprehension automatically removes duplicate values.

## 2. Set Comprehension with Conditions

We can use `if` to filter elements.

### Syntax

```python
new_set = {
    expression
    for item in iterable
    if condition
}
```

### Example 1: Extracting Even Numbers

```python
numbers = range(1, 11)

even_numbers = {
    number
    for number in numbers
    if number % 2 == 0
}

print(even_numbers)
```

**Output:**

```text
{2, 4, 6, 8, 10}
```

### Example 2: Extracting Odd Numbers

```python
numbers = range(1, 11)

odd_numbers = {
    number
    for number in numbers
    if number % 2 != 0
}

print(odd_numbers)
```

**Output:**

```text
{1, 3, 5, 7, 9}
```

### Example 3: Extracting Unique Characters

```python
word = "programming"

characters = {
    character
    for character in word
}

print(characters)
```

**Output:** A set containing the unique characters of `"programming"`; their display order is not guaranteed.

## 3. Set Comprehension with if-else

We can use conditional expressions to decide which value should be added.

### Syntax

```python
new_set = {
    value_if_true if condition else value_if_false
    for item in iterable
}
```

### Example: Even or Odd Labels

```python
numbers = range(1, 6)

result = {
    "Even" if number % 2 == 0 else "Odd"
    for number in numbers
}

print(result)
```

**Output:**

```text
{'Even', 'Odd'}
```

Notice that duplicate values are automatically removed.

## 4. Dictionary Comprehension

Dictionary comprehension creates a dictionary using a concise expression.

It generates key-value pairs from an iterable.

### Syntax

```python
new_dict = {
    key_expression: value_expression
    for item in iterable
}
```

| Component | Description |
|---|---|
| `key_expression` | Generates dictionary keys |
| `value_expression` | Generates dictionary values |
| `item` | Current iterable element |
| `iterable` | Collection being processed |

### Example 1: Creating Squares

```python
numbers = range(1, 6)

squares = {
    number: number ** 2
    for number in numbers
}

print(squares)
```

**Output:**

```text
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

Here:
- Keys are the original numbers.
- Values are their squares.

### Example 2: Creating Cubes

```python
cubes = {
    number: number ** 3
    for number in range(1, 6)
}

print(cubes)
```

**Output:**

```text
{1: 1, 2: 8, 3: 27, 4: 64, 5: 125}
```

## 5. Dictionary Comprehension with Conditions

We can filter key-value pairs using `if`.

### Syntax

```python
new_dict = {
    key: value
    for item in iterable
    if condition
}
```

### Example 1: Extracting Even Number Squares

```python
numbers = range(1, 11)

result = {
    number: number ** 2
    for number in numbers
    if number % 2 == 0
}

print(result)
```

**Output:**

```text
{2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
```

### Example 2: Filtering Students Who Passed

```python
students = {
    "Rahul": 85,
    "Arun": 35,
    "Kiran": 90,
    "Priya": 28
}

passed_students = {
    name: marks
    for name, marks in students.items()
    if marks >= 40
}

print(passed_students)
```

**Output:**

```text
{'Rahul': 85, 'Kiran': 90}
```

## 6. Dictionary Comprehension with if-else

We can use `if-else` to transform values based on a condition.

### Syntax

```python
new_dict = {
    key: value_if_true if condition else value_if_false
    for item in iterable
}
```

### Example: Pass or Fail

```python
students = {
    "Rahul": 85,
    "Arun": 35,
    "Kiran": 90
}

results = {
    name: "Pass" if marks >= 40 else "Fail"
    for name, marks in students.items()
}

print(results)
```

**Output:**

```text
{'Rahul': 'Pass', 'Arun': 'Fail', 'Kiran': 'Pass'}
```

Unlike filtering with `if`, this includes every student and changes the value based on the condition.

## 7. Dictionary Comprehension with String Operations

We can transform strings while creating dictionaries.

### Example: Word and Length

```python
words = ["Python", "Java", "SQL"]

result = {
    word: len(word)
    for word in words
}

print(result)
```

**Output:**

```text
{'Python': 6, 'Java': 4, 'SQL': 3}
```

### Example: Converting Names to Uppercase

```python
names = ["rahul", "arun", "kiran"]

result = {
    name: name.upper()
    for name in names
}

print(result)
```

**Output:**

```text
{
    'rahul': 'RAHUL',
    'arun': 'ARUN',
    'kiran': 'KIRAN'
}
```

## 8. Nested Set Comprehension

We can use multiple `for` clauses to generate combinations.

### Example: Number Combinations

```python
result = {
    (x, y)
    for x in [1, 2, 3]
    for y in [4, 5]
}

print(result)
```

**Output:** A set containing:

```text
{
    (1, 4), (1, 5),
    (2, 4), (2, 5),
    (3, 4), (3, 5)
}
```

The order of elements is not guaranteed.

## 9. Nested Dictionary Comprehension

A dictionary comprehension can generate dictionaries containing other dictionaries.

### Example: Student Marks

```python
students = ["Rahul", "Arun", "Kiran"]
subjects = ["Python", "Java"]

result = {
    student: {
        subject: 0
        for subject in subjects
    }
    for student in students
}

print(result)
```

**Output:**

```text
{
    'Rahul': {'Python': 0, 'Java': 0},
    'Arun': {'Python': 0, 'Java': 0},
    'Kiran': {'Python': 0, 'Java': 0}
}
```

The outer comprehension creates a dictionary for each student. The inner comprehension creates the subject dictionary.

## 10. Converting Between Collections Using Comprehensions

### List to Set

```python
numbers = [1, 2, 2, 3, 4, 4]

result = {number for number in numbers}

print(result)
```

**Output:**

```text
{1, 2, 3, 4}
```

### List to Dictionary

```python
names = ["Rahul", "Arun", "Kiran"]

result = {
    index: name
    for index, name in enumerate(names)
}

print(result)
```

**Output:**

```text
{0: 'Rahul', 1: 'Arun', 2: 'Kiran'}
```

### Dictionary to List

```python
student = {
    "name": "Rahul",
    "age": 22,
    "city": "Chennai"
}

result = [
    key
    for key in student
]

print(result)
```

**Output:**

```text
['name', 'age', 'city']
```

## 11. Practical Example: Product Filtering

```python
products = {
    "Laptop": 55000,
    "Mouse": 500,
    "Keyboard": 1500,
    "Monitor": 12000
}

affordable_products = {
    name: price
    for name, price in products.items()
    if price < 10000
}

print(affordable_products)
```

**Output:**

```text
{'Mouse': 500, 'Keyboard': 1500}
```

This example filters products based on their prices.

## 12. Set vs Dictionary Comprehension

| Feature | Set Comprehension | Dictionary Comprehension |
|---|---|---|
| Syntax | `{expression for item in iterable}` | `{key: value for item in iterable}` |
| Result | Set | Dictionary |
| Stores | Unique elements | Key-value pairs |
| Duplicate handling | Duplicate elements removed | Duplicate keys overwritten |
| Access | Membership testing | Access values using keys |
| Conditions | Supported | Supported |
| Nested comprehensions | Supported | Supported |

## 13. Important Points to Remember

- Set comprehension uses `{}` with a single expression.
- Dictionary comprehension uses `{}` with a key-value pair separated by `:`.
- Sets automatically remove duplicate elements.
- Dictionary keys must be unique and hashable.
- If duplicate dictionary keys are generated, the last assigned value is retained.
- `if` after the `for` clause filters elements.
- `if-else` before the `for` clause transforms elements.
- Both comprehensions can contain nested loops.
- Comprehensions create new collections rather than modifying the original iterable.
