# Sets and Set Operations in Python

A set is an unordered collection of unique elements in Python.

Sets automatically remove duplicate values and are useful for membership testing, removing duplicates, and performing mathematical set operations.

## 1. Creating Sets

Sets are created using curly braces `{}` or the built-in `set()` function.

### Set with Elements

```python
numbers = {10, 20, 30, 40}

print(numbers)
print(type(numbers))
```

**Output:**

```text
{10, 20, 30, 40}
<class 'set'>
```

*Note: Sets are unordered, so their display order is not guaranteed.*

### Set with Duplicate Values

Duplicate elements are automatically removed.

```python
numbers = {10, 20, 10, 30, 20}

print(numbers)
```

**Output:**

```text
{10, 20, 30}
```

### Creating an Empty Set

Use `set()` to create an empty set.

```python
data = set()

print(data)
print(type(data))
```

**Output:**

```text
set()
<class 'set'>
```

Using `{}` creates an empty dictionary, not an empty set.

```python
data = {}

print(type(data))
```

**Output:**

```text
<class 'dict'>
```

## 2. Important Properties of Sets

- Sets contain unique elements.
- Sets are unordered collections.
- Sets do not support indexing or slicing.
- Sets are mutable.
- Set elements must be hashable.
- Sets can contain different types of hashable values.
- Sets can be modified after creation.

## 3. Adding Elements

### add()

Adds a single element to a set.

```python
fruits = {"Apple", "Banana"}

fruits.add("Mango")

print(fruits)
```

**Output:**

```text
{'Apple', 'Banana', 'Mango'}
```

Adding an existing element does not create a duplicate.

### update()

Adds multiple elements from an iterable.

```python
fruits = {"Apple", "Banana"}

fruits.update(["Mango", "Orange"])

print(fruits)
```

**Output:**

```text
{'Apple', 'Banana', 'Mango', 'Orange'}
```

`update()` accepts iterables such as lists, tuples, and other sets.

## 4. Removing Elements

### remove()

Removes a specified element.

```python
numbers = {10, 20, 30, 40}

numbers.remove(20)

print(numbers)
```

**Output:**

```text
{10, 30, 40}
```

If the element does not exist, `remove()` raises a `KeyError`.

### discard()

Removes a specified element without raising an error if it does not exist.

```python
numbers = {10, 20, 30}

numbers.discard(50)

print(numbers)
```

**Output:**

```text
{10, 20, 30}
```

### pop()

Removes and returns an arbitrary element from the set.

```python
numbers = {10, 20, 30}

result = numbers.pop()

print(result)
print(numbers)
```

**Output:**

```text
An arbitrary element is removed.
The remaining elements are displayed.
```

The removed element is not predictable because sets are unordered.

### clear()

Removes all elements from a set.

```python
numbers = {10, 20, 30}

numbers.clear()

print(numbers)
```

**Output:**

```text
set()
```

## 5. Set Operations

Python supports mathematical set operations such as union, intersection, difference, and symmetric difference.

Consider these two sets:

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
```

### Union (|)

Union combines all unique elements from both sets.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(A | B)
print(A.union(B))
```

**Output:**

```text
{1, 2, 3, 4, 5, 6}
{1, 2, 3, 4, 5, 6}
```

### Intersection (&)

Intersection returns only the elements common to both sets.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(A & B)
print(A.intersection(B))
```

**Output:**

```text
{3, 4}
{3, 4}
```

### Difference (-)

Difference returns elements present in the first set but not in the second set.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(A - B)
print(B - A)
```

**Output:**

```text
{1, 2}
{5, 6}
```

The order matters because `A - B` and `B - A` can produce different results.

### Symmetric Difference (^)

Returns elements present in either set, but not in both.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(A ^ B)
print(A.symmetric_difference(B))
```

**Output:**

```text
{1, 2, 5, 6}
{1, 2, 5, 6}
```

## 6. Set Comparison Operations

Python supports comparison operations to check relationships between sets.

### Subset (<=)

A set is a subset if all its elements are present in another set.

```python
A = {1, 2}
B = {1, 2, 3, 4}

print(A <= B)
print(A.issubset(B))
```

**Output:**

```text
True
True
```

### Proper Subset (<)

Checks whether one set is a subset of another and the two sets are not equal.

```python
A = {1, 2}
B = {1, 2, 3}

print(A < B)
```

**Output:**

```text
True
```

### Superset (>=)

A set is a superset if it contains every element of another set.

```python
A = {1, 2, 3, 4}
B = {1, 2}

print(A >= B)
print(A.issuperset(B))
```

**Output:**

```text
True
True
```

### Proper Superset (>)

Checks whether a set is a superset of another set and contains additional elements.

```python
A = {1, 2, 3}
B = {1, 2}

print(A > B)
```

**Output:**

```text
True
```

### Disjoint Sets

Two sets are disjoint if they have no common elements.

```python
A = {1, 2, 3}
B = {4, 5, 6}

print(A.isdisjoint(B))
```

**Output:**

```text
True
```

## 7. Updating Sets with Set Operations

These methods modify the original set.

### update()

Adds all unique elements from another iterable.

```python
A = {1, 2, 3}
B = {3, 4, 5}

A.update(B)

print(A)
```

**Output:**

```text
{1, 2, 3, 4, 5}
```

### intersection_update()

Keeps only elements common to both sets.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

A.intersection_update(B)

print(A)
```

**Output:**

```text
{3, 4}
```

### difference_update()

Removes elements found in another set.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

A.difference_update(B)

print(A)
```

**Output:**

```text
{1, 2}
```

### symmetric_difference_update()

Keeps elements present in either set, but not both.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

A.symmetric_difference_update(B)

print(A)
```

**Output:**

```text
{1, 2, 5, 6}
```

## 8. Membership Operators

Use `in` and `not in` to check whether an element exists in a set.

```python
fruits = {"Apple", "Banana", "Mango"}

print("Apple" in fruits)
print("Orange" not in fruits)
```

**Output:**

```text
True
True
```

## 9. Set Comprehension

Set comprehension provides a concise way to create sets using an expression and an iterable.

```python
numbers = {x * x for x in range(1, 6)}

print(numbers)
```

**Output:**

```text
{1, 4, 9, 16, 25}
```

### Removing Duplicates from a List

```python
numbers = [10, 20, 10, 30, 20, 40]

unique_numbers = set(numbers)

print(unique_numbers)
```

**Output:**

```text
{10, 20, 30, 40}
```

The resulting set contains only unique values.

## 10. Frozen Sets (frozenset)

A `frozenset` is an immutable version of a set.

Once created, its elements cannot be added or removed.

```python
numbers = frozenset([10, 20, 30, 20])

print(numbers)
print(type(numbers))
```

**Output:**

```text
frozenset({10, 20, 30})
<class 'frozenset'>
```

### Mutable Set vs Frozen Set

| Feature | set | frozenset |
|---|---|---|
| Mutable | Yes | No |
| Add elements | Yes | No |
| Remove elements | Yes | No |
| Set operations | Supported | Supported |
| Can be a dictionary key | No | Yes, if its elements are hashable |

## 11. Complete Set Method Reference

| Method | Purpose |
|---|---|
| `add(x)` | Adds one element |
| `update(iterable)` | Adds multiple elements |
| `remove(x)` | Removes an element; raises `KeyError` if missing |
| `discard(x)` | Removes an element without an error if missing |
| `pop()` | Removes and returns an arbitrary element |
| `clear()` | Removes all elements |
| `copy()` | Creates a shallow copy |
| `union()` | Combines unique elements |
| `intersection()` | Returns common elements |
| `difference()` | Returns elements in the first set only |
| `symmetric_difference()` | Returns elements in either set, but not both |
| `intersection_update()` | Keeps common elements in the original set |
| `difference_update()` | Removes elements found in another set |
| `symmetric_difference_update()` | Updates with elements present in either set, but not both |
| `issubset()` | Checks subset relationship |
| `issuperset()` | Checks superset relationship |
| `isdisjoint()` | Checks whether sets have no common elements |
