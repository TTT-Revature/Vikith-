# Escape Characters and Multiline Strings in Python

## 1. Escape Characters

Escape characters are special character sequences that begin with a backslash (`\`).

They are used to represent special characters inside strings, such as new lines, tabs and quotation marks.

### Common Escape Characters

| Escape character | Meaning |
|---|---|
| `\n` | New line |
| `\t` | Horizontal tab |
| `\\` | Backslash |
| `\'` | Single quote |
| `\"` | Double quote |
| `\r` | Carriage return |
| `\b` | Backspace |
| `\f` | Form feed |
| `\v` | Vertical tab |
| `\a` | Alert (bell) |
| `\0` | Null character |

## 2. Examples of Escape Characters

### New Line (`\n`)

Moves the text after it to a new line.

```python
text = "Hello\nWorld"

print(text)
```

**Output:**
```text
Hello
World
```

### Tab (`\t`)

Adds horizontal tab spacing.

```python
text = "Name\tAge\tCity"

print(text)
```

**Output:**
```text
Name    Age    City
```

### Backslash (`\\`)

Displays a backslash inside a string.

```python
path = "C:\\Users\\John\\Documents"

print(path)
```

**Output:**
```text
C:\Users\John\Documents
```

### Single Quote (`\'`)

Allows a single quote inside a single-quoted string.

```python
text = 'It\'s Python'

print(text)
```

**Output:**
```text
It's Python
```

### Double Quote (`\"`)

Allows double quotes inside a double-quoted string.

```python
text = "He said, \"Hello Python\""

print(text)
```

**Output:**
```text
He said, "Hello Python"
```

### Carriage Return (`\r`)

Moves the output position to the beginning of the current line. Subsequent output may overwrite earlier characters.

```python
print("Python\rJava")
```

A typical terminal displays:
```text
Javathon
```

### Backspace (`\b`)

Moves the output position back by one character. Its visible effect depends on the output environment.

```python
print("Helloo\b")
```

A typical terminal displays:
```text
Hello
```

### Null Character (`\0`)

Represents the null character, whose Unicode code point is zero.

```python
text = "Python\0Programming"

print(text)
print(len(text))
```

**Output:**
```text
Python Programming
18
```

The null character is part of the string; it does not terminate a Python string.

## 3. Raw Strings (`r`)

A raw string treats backslashes as literal characters instead of interpreting most escape sequences.

Use `r` or `R` before the opening quotation mark.

```python
normal = "C:\\Users\\John"
raw = r"C:\Users\John"

print(normal)
print(raw)
```

**Output:**
```text
C:\Users\John
C:\Users\John
```

### Difference Between Normal and Raw Strings

```python
normal = "Hello\nWorld"
raw = r"Hello\nWorld"

print(normal)
print(raw)
```

**Output:**
```text
Hello
World
Hello\nWorld
```

Raw strings are particularly useful when working with Windows file paths and regular expressions.

**Note:** Raw strings still have some syntax restrictions. For example, a raw string cannot end with an odd number of backslashes.

## 4. Multiline Strings

A multiline string contains text across multiple lines.

Python supports multiline strings using triple single quotes (`'''`) or triple double quotes (`"""`).

### Using Triple Double Quotes

```python
message = """Welcome to Python.
Python is easy to learn.
Python is powerful."""

print(message)
```

**Output:**
```text
Welcome to Python.
Python is easy to learn.
Python is powerful.
```

### Using Triple Single Quotes

```python
message = '''Python supports
multiple lines
inside a string.'''

print(message)
```

**Output:**
```text
Python supports
multiple lines
inside a string.
```

## 5. Preserving Line Breaks

Triple-quoted strings preserve line breaks and whitespace between the quotation marks.

```python
message = """Hello
    Welcome
        to Python"""

print(message)
```

**Output:**
```text
Hello
    Welcome
        to Python
```

Notice that the indentation spaces are also preserved.

## 6. Multiline Strings vs Escape Characters

You can create multiline text using either approach.

### Using `\n`

```python
message = "Hello\nWelcome to Python\nHappy Learning"

print(message)
```

### Using Triple Quotes

```python
message = """Hello
Welcome to Python
Happy Learning"""

print(message)
```

Both produce:

```text
Hello
Welcome to Python
Happy Learning
```

Use `\n` for short, controlled line breaks and triple quotes for longer multiline text.

## 7. Different Practical Use Cases

### Use Case 1: Displaying Formatted Information

```python
name = "John"
age = 25
city = "Chennai"

print("Name\tAge\tCity")
print(f"{name}\t{age}\t{city}")
```

**Output:**
```text
Name    Age    City
John    25     Chennai
```

### Use Case 2: Windows File Paths

```python
path = r"C:\Users\John\Documents\Python"

print(path)
```

**Output:**
```text
C:\Users\John\Documents\Python
```

### Use Case 3: Writing a Message

```python
message = """Dear John,

Welcome to Python Programming.

Happy Learning!"""

print(message)
```

**Output:**
```text
Dear John,

Welcome to Python Programming.

Happy Learning!
```

### Use Case 4: Creating a Simple SQL Query

```python
query = """SELECT name, age
FROM students
WHERE age > 20;"""

print(query)
```

**Output:**
```text
SELECT name, age
FROM students
WHERE age > 20;
```

### Use Case 5: Creating a Simple Text Banner

```python
banner = """
========================
     PYTHON PROGRAM
========================
"""

print(banner)
```

**Output:**
```text
========================
     PYTHON PROGRAM
========================
```

## 8. Important Points

- Escape sequences begin with a backslash (`\`).
- `\n` creates a new line.
- `\t` adds horizontal tab spacing.
- `\\` displays a backslash.
- Raw strings use the `r` prefix.
- Triple quotes create multiline strings.
- Multiline strings preserve line breaks and indentation.
- Triple-quoted strings can also be used for docstrings when placed in the appropriate location.
