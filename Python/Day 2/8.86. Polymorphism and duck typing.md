

# Python Polymorphism and Duck Typing

## 1. What is Polymorphism?

Polymorphism means **one interface, multiple forms**.

In Python, different objects can use the same method name but perform different actions.

### Example

```python
class Dog:
    def sound(self):
        print("Dog barks")


class Cat:
    def sound(self):
        print("Cat meows")


dog = Dog()
cat = Cat()

dog.sound()
cat.sound()
```

**Output:**
```text
Dog barks
Cat meows
```

Both classes have a `sound()` method, but each object behaves differently.

## 2. Polymorphism Through Inheritance

A child class can override a parent class method and provide its own implementation.

```python
class Animal:
    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):
    def sound(self):
        print("Dog barks")


class Cat(Animal):
    def sound(self):
        print("Cat meows")


animals = [Dog(), Cat(), Animal()]

for animal in animals:
    animal.sound()
```

**Output:**
```text
Dog barks
Cat meows
Animal makes a sound
```

The same method call, `animal.sound()`, produces different results depending on the actual object.

## 3. Polymorphism with Functions

A single function can work with different types of objects, provided they support the required operation.

```python
class Dog:
    def sound(self):
        return "Bark"


class Cat:
    def sound(self):
        return "Meow"


def make_sound(animal):
    print(animal.sound())


make_sound(Dog())
make_sound(Cat())
```

**Output:**
```text
Bark
Meow
```

The `make_sound()` function does not need to know whether it receives a `Dog` or `Cat` object.

## 4. Built-in Polymorphism

Python's built-in functions can work with different data types.

### Example: `len()`

```python
print(len("Python"))
print(len([10, 20, 30]))
print(len((1, 2, 3)))
print(len({"name": "Vikith", "age": 24}))
```

**Output:**
```text
6
3
3
2
```

The same `len()` function works with strings, lists, tuples, and dictionaries.

### Example: `+` Operator

```python
print(10 + 20)
print("Hello " + "Python")
print([1, 2] + [3, 4])
```

**Output:**
```text
30
Hello Python
[1, 2, 3, 4]
```

The `+` operator behaves differently depending on the operand types.

## 5. What is Duck Typing?

Duck typing is a Python programming concept where an object's suitability is determined by the methods and behavior it provides, rather than its actual class or type.

**The idea:** If an object behaves like a duck, Python can treat it like a duck.

For example, if an object has a `fly()` method, a function that calls `fly()` can work with that object without checking its class.

### Example

```python
class Bird:
    def fly(self):
        print("Bird is flying")


class Airplane:
    def fly(self):
        print("Airplane is flying")


def start_flying(obj):
    obj.fly()


bird = Bird()
plane = Airplane()

start_flying(bird)
start_flying(plane)
```

**Output:**
```text
Bird is flying
Airplane is flying
```

**Explanation:**
- `Bird` and `Airplane` are unrelated classes.
- Both provide a `fly()` method.
- `start_flying()` calls that method without checking the object's class.
- This is duck typing.

## 6. Duck Typing Without Inheritance

Duck typing does not require inheritance.

```python
class Laptop:
    def start(self):
        print("Laptop started")


class Mobile:
    def start(self):
        print("Mobile started")


def start_device(device):
    device.start()


start_device(Laptop())
start_device(Mobile())
```

**Output:**
```text
Laptop started
Mobile started
```

Both objects work with the same function even though they do not share a parent class.

## 7. Duck Typing with Different Objects

Consider a function that expects an object with a `read()` method.

```python
class File:
    def read(self):
        print("Reading from file")


class Database:
    def read(self):
        print("Reading from database")


class API:
    def read(self):
        print("Reading from API")


def read_data(source):
    source.read()


read_data(File())
read_data(Database())
read_data(API())
```

**Output:**
```text
Reading from file
Reading from database
Reading from API
```

The function works with different objects because they provide the expected behavior.

## 8. What Happens When a Required Method Is Missing?

Duck typing does not mean Python automatically creates missing methods.

If an object does not support the operation being requested, Python raises an exception.

```python
class Student:
    def study(self):
        print("Student is studying")


class Teacher:
    def teach(self):
        print("Teacher is teaching")


def perform_action(obj):
    obj.study()


perform_action(Student())
perform_action(Teacher())
```

**Output:**
```text
Student is studying
AttributeError: 'Teacher' object has no attribute 'study'
```

The `Teacher` object does not have a `study()` method, so the function fails when it tries to call it.

## 9. Polymorphism vs Duck Typing

| Polymorphism | Duck Typing |
|---|---|
| One interface can have multiple implementations | Objects are used based on their supported behavior |
| Broad OOP concept | A way of achieving polymorphic behavior |
| Can use inheritance and method overriding | Does not require inheritance |
| Focuses on different behaviors through a common interface | Focuses on available methods and operations |

## 10. Important Points

- Polymorphism means one interface with multiple forms.
- Method overriding is one way to achieve polymorphism.
- Python supports polymorphism through functions and built-in operators.
- Duck typing focuses on what an object can do, not what class it belongs to.
- Duck typing does not require inheritance.
- Missing required methods can cause `AttributeError`.
- Python is dynamically typed, which makes duck typing natural.

## 11. Real-World Use Cases

- **Payment systems:** Different payment classes can provide a common `pay()` method.
- **File processing:** Different objects can provide a common `read()` method.
- **Notification systems:** Email, SMS, and push notifications can implement a common `send()` method.
- **Device management:** Different devices can provide a common `start()` method.
- **API integrations:** Different data sources can expose common operations such as `fetch()` or `read()`.
