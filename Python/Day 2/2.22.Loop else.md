# Loop Else in Python

Python supports an `else` block with both `for` and `while` loops.

The `else` block executes when the loop completes normally, without encountering a `break`.

## 1. `for` Loop with `else`

```python
for i in range(1, 4):
    print(i)
else:
    print("Loop completed")
```

**Output:**

```text
1
2
3
Loop completed
```

The `else` block executes because the loop completed normally.

## 2. `for` Loop with `break`

```python
for i in range(1, 5):
    if i == 3:
        break
    print(i)
else:
    print("Loop completed")
```

**Output:**

```text
1
2
```

The `else` block does not execute because the loop encountered `break`.

## 3. `while` Loop with `else`

```python
i = 1

while i <= 3:
    print(i)
    i += 1
else:
    print("Loop completed")
```

**Output:**

```text
1
2
3
Loop completed
```

The `else` block executes because the condition eventually becomes false.

## 4. `while` Loop with `break`

```python
i = 1

while i <= 5:
    if i == 3:
        break
    print(i)
    i += 1
else:
    print("Loop completed")
```

**Output:**

```text
1
2
```

The `else` block is skipped because `break` terminates the loop.

## 5. Loop `else` with `continue`

```python
for i in range(1, 4):
    if i == 2:
        continue
    print(i)
else:
    print("Loop completed")
```

**Output:**

```text
1
3
Loop completed
```

`continue` skips only the current iteration. It does not stop the loop, so `else` still executes.

## 6. Practical Example: Search an Element

```python
numbers = [10, 20, 30, 40]
target = 50

for num in numbers:
    if num == target:
        print("Element found")
        break
else:
    print("Element not found")
```

**Output:**

```text
Element not found
```

The `else` block is useful when searching for an element because it runs only if the loop finishes without finding the target and executing `break`.

## 7. Important Rules

| Situation                       | Does `else` execute?                     |
| ------------------------------- | ---------------------------------------- |
| Loop completes normally         | Yes                                      |
| Loop encounters `break`         | No                                       |
| Loop uses `continue`            | Yes, if it eventually completes normally |
| `while` condition becomes false | Yes                                      |
| Loop has zero iterations        | Yes                                      |
