# Python File Handling: Opening, Reading and Writing Files

## 1. What Is File Handling?

File handling allows Python programs to create, open, read, write, and modify files.

Python supports working with different file types:

- `.txt` – Text files
- `.csv` – Comma-separated values
- `.json` – JSON data
- `.log` – Log files
- `.py` – Python files

## 2. Opening a File

Python uses the built-in `open()` function to open files.

**Syntax:**

```python
file = open("filename.txt", "mode")
```

- `filename.txt` – Name or path of the file.
- `mode` – Specifies how the file should be opened.

### Example

```python
file = open("sample.txt", "r")

print(file)

file.close()
```

The `close()` method closes the file after use.

## 3. File Opening Modes

| Mode | Description |
|---|---|
| `r` | Read an existing file |
| `w` | Write to a file, replacing existing content |
| `a` | Append content to the end of a file |
| `x` | Create a new file; raises an error if it already exists |
| `t` | Text mode (default) |
| `b` | Binary mode |
| `r+` | Read and write without truncating the file |
| `w+` | Read and write, replacing existing content |
| `a+` | Read and append |

## 4. Reading a File

Python provides different methods to read file contents.

### read()

The `read()` method reads the entire file content as a string by default.

**File: `sample.txt`**

```text
Hello Python
Welcome to File Handling
Learning Python is easy
```

**Python code:**

```python
file = open("sample.txt", "r")

content = file.read()

print(content)

file.close()
```

**Output:**

```text
Hello Python
Welcome to File Handling
Learning Python is easy
```

We can also specify how many characters to read.

```python
file = open("sample.txt", "r")

print(file.read(5))

file.close()
```

**Output:**

```text
Hello
```

### readline()

The `readline()` method reads one line at a time.

```python
file = open("sample.txt", "r")

print(file.readline())
print(file.readline())

file.close()
```

**Output:**

```text
Hello Python

Welcome to File Handling
```

Each `readline()` call reads the next line.

### readlines()

The `readlines()` method reads all lines and returns them as a list of strings.

```python
file = open("sample.txt", "r")

lines = file.readlines()

print(lines)

file.close()
```

**Output:**

```text
['Hello Python\n', 'Welcome to File Handling\n', 'Learning Python is easy']
```

## 5. Writing to a File

The `write()` method writes a string into a file.

When using `w` mode:
- A new file is created if it does not exist.
- Existing content is erased if the file already exists.

### Example

```python
file = open("output.txt", "w")

file.write("Hello Python\n")
file.write("Learning File Handling")

file.close()
```

**File: `output.txt`**

```text
Hello Python
Learning File Handling
```

### Important: write() Does Not Add New Lines Automatically

```python
file = open("output.txt", "w")

file.write("Python")
file.write("Java")

file.close()
```

**File content:**

```text
PythonJava
```

Use `\n` when you want to insert a new line.

## 6. Appending to a File

The `a` mode adds new content at the end of an existing file without removing its previous content.

**Existing file: `output.txt`**

```text
Hello Python
```

**Python code:**

```python
file = open("output.txt", "a")

file.write("\nWelcome to Python")

file.close()
```

**Updated file:**

```text
Hello Python
Welcome to Python
```

## 7. Creating a File Using x Mode

The `x` mode creates a new file.

If the file already exists, Python raises a `FileExistsError`.

```python
file = open("newfile.txt", "x")

file.write("New file created")

file.close()
```

## 8. Using with open()

The recommended way to work with files is using the `with` statement.

It automatically closes the file when the block finishes, even if an exception occurs.

**Syntax:**

```python
with open("filename.txt", "mode") as file:
    # Perform file operations
```

### Example: Reading a File

```python
with open("sample.txt", "r") as file:
    content = file.read()
    print(content)
```

### Example: Writing a File

```python
with open("output.txt", "w") as file:
    file.write("Python File Handling")
```

We do not need to call `file.close()` explicitly when using `with`.

## 9. Reading a File Using a Loop

We can read a file line by line using a `for` loop.

```python
with open("sample.txt", "r") as file:
    for line in file:
        print(line.strip())
```

**Output:**

```text
Hello Python
Welcome to File Handling
Learning Python is easy
```

`strip()` removes newline characters and surrounding whitespace from each line.

This approach is memory-efficient for large text files because it processes one line at a time.

## 10. File Pointer and tell()

Python maintains a file pointer that tracks the current position in a file.

### tell()

The `tell()` method returns the current file position.

```python
with open("sample.txt", "r") as file:
    print(file.tell())

    file.read(5)

    print(file.tell())
```

**Output:**

```text
0
5
```

### seek()

The `seek()` method moves the file pointer to a specified position.

```python
with open("sample.txt", "r") as file:
    file.read(5)

    file.seek(0)

    print(file.read())
```

**Output:**

```text
Hello Python
Welcome to File Handling
Learning Python is easy
```

`seek(0)` moves the file pointer back to the beginning.

## 11. Reading and Writing Together

The `r+` mode allows reading and writing without truncating the existing file.

```python
with open("sample.txt", "r+") as file:
    content = file.read()

    print(content)

    file.seek(0)

    file.write("Updated Content")
```

The existing file is not automatically cleared. Writing overwrites characters from the current file position, and any remaining old content can stay.

## 12. File Handling Methods

| Method | Description |
|---|---|
| `open()` | Opens a file |
| `read()` | Reads file content |
| `readline()` | Reads one line |
| `readlines()` | Reads all lines into a list |
| `write()` | Writes a string |
| `writelines()` | Writes an iterable of strings |
| `close()` | Closes the file |
| `seek()` | Changes file pointer position |
| `tell()` | Returns current file position |
| `flush()` | Flushes buffered data |
| `readable()` | Checks whether the file is readable |
| `writable()` | Checks whether the file is writable |

### Example: writelines()

```python
lines = [
    "Python\n",
    "Java\n",
    "SQL\n"
]

with open("languages.txt", "w") as file:
    file.writelines(lines)
```

**File: `languages.txt`**

```text
Python
Java
SQL
```

`writelines()` does not automatically insert newline characters.

## 13. Common File Handling Errors

| Error | Reason |
|---|---|
| `FileNotFoundError` | File does not exist |
| `PermissionError` | Insufficient permission |
| `FileExistsError` | File already exists when using `x` mode |
| `IsADirectoryError` | Attempted to open a directory as a file |
| `UnicodeDecodeError` | File bytes cannot be decoded using the selected encoding |

### Handling FileNotFoundError

```python
try:
    with open("missing.txt", "r") as file:
        print(file.read())

except FileNotFoundError:
    print("File does not exist")
```

**Output:**

```text
File does not exist
```

## 14. Real-World Example: Student Records

```python
students = [
    "Vikith - 90\n",
    "Anil - 85\n",
    "Ram - 95\n"
]

# Write student records
with open("students.txt", "w") as file:
    file.writelines(students)

# Read student records
with open("students.txt", "r") as file:
    for student in file:
        print(student.strip())
```

**Output:**

```text
Vikith - 90
Anil - 85
Ram - 95
```

## 15. Important Points

- Use `open()` to open files.
- Use `read()` to read content.
- Use `write()` to write content.
- Use `a` mode to append content.
- Use `w` mode carefully because it replaces existing content.
- Use `x` mode to create a new file without overwriting an existing one.
- Use `with open()` to automatically close files.
- Use `seek()` and `tell()` to control and inspect file positions.
- Use `try-except` to handle file-related errors.
- Specify an encoding such as `encoding="utf-8"` when working with text files.
