

# Python `super()` Function

## 1. What is `super()`?

The `super()` function is used to access methods and attributes from a parent class inside a child class.

It is commonly used in inheritance to reuse parent class functionality without directly referring to the parent class name.

## 2. Basic Syntax

```python
super().method_name()
```

## 3. Using `super()` with `__init__()`

It allows the child class to call the constructor of its parent class.

```python
class Parent:
    def __init__(self, name):
        self.name = name
        print("Parent constructor called")


class Child(Parent):
    def __init__(self, name, age):
        super().__init__(name)
        self.age = age
        print("Child constructor called")


obj = Child("Vikith", 24)

print(obj.name)
print(obj.age)
```

**Output:**
```text
Parent constructor called
Child constructor called
Vikith
24
```

**Explanation:**
- `Child` inherits from `Parent`.
- `super().__init__(name)` calls the parent constructor.
- The parent constructor initializes `self.name`.
- The child constructor initializes `self.age`.

## 4. Using `super()` to Call Parent Methods

```python
class Animal:
    def sound(self):
        print("Animals make sounds")


class Dog(Animal):
    def sound(self):
        super().sound()
        print("Dog barks")


obj = Dog()
obj.sound()
```

**Output:**
```text
Animals make sounds
Dog barks
```

Here, `super().sound()` calls the parent implementation before executing the child implementation.

## 5. `super()` with Method Overriding

When a child class overrides a parent method, it can still reuse the parent's implementation using `super()`.

```python
class Employee:
    def display(self):
        print("Employee details")


class Developer(Employee):
    def display(self):
        super().display()
        print("Role: Python Developer")


obj = Developer()
obj.display()
```

**Output:**
```text
Employee details
Role: Python Developer
```

## 6. `super()` in Multilevel Inheritance

`super()` can also be used in multilevel inheritance.

```python
class Grandparent:
    def show(self):
        print("Grandparent class")


class Parent(Grandparent):
    def show(self):
        super().show()
        print("Parent class")


class Child(Parent):
    def show(self):
        super().show()
        print("Child class")


obj = Child()
obj.show()
```

**Output:**
```text
Grandparent class
Parent class
Child class
```

Each `super()` call moves to the next class in the Method Resolution Order (MRO).

## 7. `super()` and Method Resolution Order (MRO)

MRO determines the order in which Python searches for methods in an inheritance hierarchy.

Use the `__mro__` attribute or `mro()` method to inspect it.

```python
class A:
    def show(self):
        print("Class A")


class B(A):
    pass


class C(B):
    pass


print(C.mro())
```

**Output:**
```text
[<class '__main__.C'>, <class '__main__.B'>, <class '__main__.A'>, <class 'object'>]
```

In this example, Python searches for methods in this order:

1. Class C
2. Class B
3. Class A
4. Object

## 8. `super()` in Multiple Inheritance

Python supports multiple inheritance. `super()` follows the MRO instead of simply calling a specifically named parent class.

```python
class A:
    def show(self):
        print("Class A")


class B(A):
    def show(self):
        print("Class B")
        super().show()


class C(A):
    def show(self):
        print("Class C")
        super().show()


class D(B, C):
    def show(self):
        print("Class D")
        super().show()


obj = D()
obj.show()

print([cls.__name__ for cls in D.mro()])
```

**Output:**
```text
Class D
Class B
Class C
Class A
['D', 'B', 'C', 'A', 'object']
```

The calls follow the MRO: `D → B → C → A`.

## 9. Important Points

| Concept | Explanation |
|---|---|
| `super()` | Accesses the next class in the MRO |
| `super().__init__()` | Calls the next class's constructor |
| `super().method()` | Calls the next class's method |
| MRO | Determines the method lookup order |
| Multiple inheritance | `super()` follows the MRO |

- `super()` does not always mean "call my immediate parent"; it follows the MRO.
- It is commonly used with constructors and overridden methods.
- It helps avoid directly hardcoding parent class names.
- In cooperative multiple inheritance, classes should use compatible method signatures and call `super()` consistently.

## 10. Real-World Use Cases

- Reusing parent class initialization in child classes.
- Extending existing methods without rewriting their functionality.
- Avoiding duplicate code in inheritance hierarchies.
- Supporting cooperative multiple inheritance.
- Extending framework classes while preserving their original behavior.
