# Dictionaries in Python: Keys, Values and Common Operations

A dictionary is a built-in Python data type used to store data in **key-value pairs**.

Each key is used to access its corresponding value.

```python
student = {
    "name": "Rahul",
    "age": 22,
    "course": "MCA"
}

print(student)
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'course': 'MCA'}
```

## 1. Creating Dictionaries

Dictionaries are created using curly braces `{}` or the `dict()` constructor.

### Using Curly Braces

```python
student = {
    "name": "Rahul",
    "age": 22,
    "marks": 85
}
```

### Using dict()

```python
student = dict(name="Rahul", age=22, marks=85)

print(student)
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'marks': 85}
```

### Creating an Empty Dictionary

```python
data = {}

# Or
data = dict()
```

**Important:** `{}` creates an empty dictionary, not an empty set.

## 2. Understanding Keys and Values

A dictionary contains two main components:

- **Key:** Identifies an item in the dictionary.
- **Value:** Data associated with that key.

```python
employee = {
    "id": 101,
    "name": "Arun",
    "salary": 30000
}
```

Here:

| Key | Value |
|---|---|
| `"id"` | `101` |
| `"name"` | `"Arun"` |
| `"salary"` | `30000` |

### Important Dictionary Properties

- Dictionaries are mutable.
- Keys must be unique.
- Values can be duplicated.
- Keys must be hashable (commonly strings, numbers and tuples containing hashable elements).
- Values can be of any data type.
- Dictionaries preserve insertion order in modern Python.

### Duplicate Keys

If the same key is added more than once, the latest value is retained.

```python
data = {
    "name": "Rahul",
    "name": "Arun"
}

print(data)
```

**Output:**

```text
{'name': 'Arun'}
```

## 3. Accessing Dictionary Values

### Using Square Brackets

```python
student = {
    "name": "Rahul",
    "age": 22
}

print(student["name"])
print(student["age"])
```

**Output:**

```text
Rahul
22
```

If the key does not exist, square bracket access raises a `KeyError`.

### Using get()

The `get()` method safely retrieves a value.

```python
student = {
    "name": "Rahul",
    "age": 22
}

print(student.get("name"))
print(student.get("city"))
print(student.get("city", "Not Available"))
```

**Output:**

```text
Rahul
None
Not Available
```

### Difference Between [] and get()

| Feature | `dict[key]` | `dict.get(key)` |
|---|---|---|
| Existing key | Returns value | Returns value |
| Missing key | Raises `KeyError` | Returns `None` |
| Default value | Not supported | Supported |

## 4. Adding and Updating Items

Dictionaries are mutable, so we can add new key-value pairs and update existing values.

### Adding a New Item

```python
student = {
    "name": "Rahul",
    "age": 22
}

student["city"] = "Chennai"

print(student)
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'city': 'Chennai'}
```

### Updating an Existing Value

```python
student["age"] = 23

print(student)
```

**Output:**

```text
{'name': 'Rahul', 'age': 23, 'city': 'Chennai'}
```

### Using update()

The `update()` method adds multiple items or updates existing keys.

```python
student = {
    "name": "Rahul",
    "age": 22
}

student.update({
    "age": 23,
    "city": "Chennai",
    "course": "MCA"
})

print(student)
```

**Output:**

```text
{'name': 'Rahul', 'age': 23, 'city': 'Chennai', 'course': 'MCA'}
```

## 5. Removing Dictionary Items

Python provides several methods to remove dictionary entries.

### pop()

Removes the specified key and returns its value.

```python
student = {
    "name": "Rahul",
    "age": 22,
    "city": "Chennai"
}

removed = student.pop("age")

print(removed)
print(student)
```

**Output:**

```text
22
{'name': 'Rahul', 'city': 'Chennai'}
```

If the key is missing, `pop()` raises `KeyError` unless a default value is provided.

### popitem()

Removes and returns the last inserted key-value pair.

```python
student = {
    "name": "Rahul",
    "age": 22
}

print(student.popitem())
print(student)
```

**Output:**

```text
('age', 22)
{'name': 'Rahul'}
```

### del

Deletes a specific key-value pair.

```python
student = {
    "name": "Rahul",
    "age": 22
}

del student["age"]

print(student)
```

**Output:**

```text
{'name': 'Rahul'}
```

### clear()

Removes all items from the dictionary.

```python
student = {
    "name": "Rahul",
    "age": 22
}

student.clear()

print(student)
```

**Output:**

```text
{}
```

## 6. Accessing Keys, Values and Items

Python provides three important dictionary methods.

### keys()

Returns a view of all dictionary keys.

```python
student = {
    "name": "Rahul",
    "age": 22,
    "course": "MCA"
}

print(student.keys())
```

**Output:**

```text
dict_keys(['name', 'age', 'course'])
```

### values()

Returns a view of all dictionary values.

```python
print(student.values())
```

**Output:**

```text
dict_values(['Rahul', 22, 'MCA'])
```

### items()

Returns a view containing key-value pairs as tuples.

```python
print(student.items())
```

**Output:**

```text
dict_items([('name', 'Rahul'), ('age', 22), ('course', 'MCA')])
```

## 7. Iterating Through Dictionaries

We can use `for` loops to access dictionary data.

### Iterating Through Keys

```python
student = {
    "name": "Rahul",
    "age": 22,
    "course": "MCA"
}

for key in student:
    print(key)
```

**Output:**

```text
name
age
course
```

### Iterating Through Values

```python
for value in student.values():
    print(value)
```

**Output:**

```text
Rahul
22
MCA
```

### Iterating Through Keys and Values

Use `items()` to access both keys and values.

```python
for key, value in student.items():
    print(key, ":", value)
```

**Output:**

```text
name : Rahul
age : 22
course : MCA
```

## 8. Checking Whether a Key Exists

The `in` operator checks whether a key exists in a dictionary.

```python
student = {
    "name": "Rahul",
    "age": 22
}

print("name" in student)
print("city" in student)
print("Rahul" in student)
```

**Output:**

```text
True
False
False
```

By default, membership checks dictionary keys, not values.

To check values, use:

```python
print("Rahul" in student.values())
```

**Output:**

```text
True
```

## 9. Dictionary Length

The `len()` function returns the number of key-value pairs.

```python
student = {
    "name": "Rahul",
    "age": 22,
    "course": "MCA"
}

print(len(student))
```

**Output:**

```text
3
```

## 10. Copying Dictionaries

The `copy()` method creates a shallow copy of a dictionary.

```python
original = {
    "name": "Rahul",
    "marks": 85
}

copied = original.copy()

copied["marks"] = 95

print(original)
print(copied)
```

**Output:**

```text
{'name': 'Rahul', 'marks': 85}
{'name': 'Rahul', 'marks': 95}
```

The outer dictionaries are separate objects. However, nested mutable values are shared in a shallow copy.

For nested dictionaries, use `copy.deepcopy()` when an independent recursive copy is required.

```python
import copy

original = {
    "student": {
        "name": "Rahul",
        "marks": 85
    }
}

copied = copy.deepcopy(original)

copied["student"]["marks"] = 95

print(original["student"]["marks"])
print(copied["student"]["marks"])
```

**Output:**

```text
85
95
```

## 11. Merging Dictionaries

Python supports multiple ways to combine dictionaries.

### Using update()

```python
first = {"name": "Rahul", "age": 22}
second = {"city": "Chennai", "age": 23}

first.update(second)

print(first)
```

**Output:**

```text
{'name': 'Rahul', 'age': 23, 'city': 'Chennai'}
```

The original `first` dictionary is modified.

### Using the | Operator

The `|` operator creates a new merged dictionary in Python 3.9 and later.

```python
first = {"name": "Rahul", "age": 22}
second = {"city": "Chennai", "age": 23}

result = first | second

print(result)
```

**Output:**

```text
{'name': 'Rahul', 'age': 23, 'city': 'Chennai'}
```

If both dictionaries contain the same key, the value from the right-hand dictionary takes priority.

## 12. Dictionary fromkeys()

The `fromkeys()` method creates a new dictionary using the given keys and a common value.

```python
subjects = ["Python", "Java", "SQL"]

result = dict.fromkeys(subjects, 0)

print(result)
```

**Output:**

```text
{'Python': 0, 'Java': 0, 'SQL': 0}
```

If the value is omitted, the default value is `None`.

**Important:** If a mutable value such as a list is supplied, all keys initially refer to the same value object.

## 13. Dictionary Comprehension

Dictionary comprehension provides a short way to create dictionaries.

### Example 1: Creating Squares

```python
squares = {
    number: number ** 2
    for number in range(1, 6)
}

print(squares)
```

**Output:**

```text
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

### Example 2: Conditional Dictionary

```python
numbers = range(1, 6)

even_squares = {
    number: number ** 2
    for number in numbers
    if number % 2 == 0
}

print(even_squares)
```

**Output:**

```text
{2: 4, 4: 16}
```

## 14. Nested Dictionaries

A dictionary can contain another dictionary as its value.

```python
students = {
    "student1": {
        "name": "Rahul",
        "age": 22
    },
    "student2": {
        "name": "Arun",
        "age": 23
    }
}

print(students["student1"]["name"])
print(students["student2"]["age"])
```

**Output:**

```text
Rahul
23
```

Nested dictionaries are useful for representing structured data.

## 15. Dictionary Methods Reference

| Method | Purpose |
|---|---|
| `get(key)` | Returns a value safely |
| `keys()` | Returns all keys |
| `values()` | Returns all values |
| `items()` | Returns key-value pairs |
| `update()` | Adds or updates items |
| `pop(key)` | Removes a key and returns its value |
| `popitem()` | Removes and returns the last inserted pair |
| `clear()` | Removes all items |
| `copy()` | Creates a shallow copy |
| `setdefault()` | Returns a value or inserts a default |
| `fromkeys()` | Creates a dictionary from given keys |

## 16. Important Differences

| Operation | Description |
|---|---|
| `student["name"]` | Accesses a value using its key |
| `student.get("name")` | Safely accesses a value |
| `"name" in student` | Checks whether a key exists |
| `"Rahul" in student.values()` | Checks whether a value exists |
| `student.update(data)` | Modifies the existing dictionary |
| `student \| data` | Creates a merged dictionary |
| `student.copy()` | Creates a shallow copy |
| `del student["name"]` | Deletes a specific item |

## 17. Real-World Use Cases

- **Student management:** Store student names, marks, grades and registration numbers.
- **Employee management:** Store employee IDs, names, salaries and departments.
- **API responses:** Represent JSON data returned by REST APIs.
- **Data analysis:** Count word frequencies, categories and repeated values.
- **Configuration settings:** Store application settings such as database details and environment options.
- **E-commerce:** Store product IDs, names, prices and stock quantities.

### Example: Counting Word Frequency

```python
sentence = "python java python sql java python"

words = sentence.split()

frequency = {}

for word in words:
    frequency[word] = frequency.get(word, 0) + 1

print(frequency)
```

**Output:**

```text
{'python': 3, 'java': 2, 'sql': 1}
```

The `get()` method returns the existing count or `0` when the word is not yet present. The count is then increased by one.
