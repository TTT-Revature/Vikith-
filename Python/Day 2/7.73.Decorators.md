

# Python Decorators

## 1. What Is a Decorator?

A decorator is a function that modifies or extends the behavior of another function without changing its original source code.

Decorators are commonly used for:
- Logging
- Authentication
- Execution time measurement
- Access control
- Input validation
- Caching

In Python, decorators use the `@` symbol.

## 2. Understanding Functions as Objects

In Python, functions are first-class objects. This means we can:
- Store functions in variables.
- Pass functions as arguments.
- Return functions from other functions.

### Example

```python
def greet():
    print("Hello Python")

message = greet

message()
```

**Output:**

```text
Hello Python
```

Here, `message` refers to the same function as `greet`.

Notice that we use `greet` without parentheses because we are assigning the function itself, not calling it.

## 3. Passing a Function as an Argument

A function can be passed as an argument to another function.

```python
def greet():
    print("Hello!")

def execute(func):
    func()

execute(greet)
```

**Output:**

```text
Hello!
```

Here:
- `greet` is passed as an argument.
- `execute()` receives the function.
- `func()` calls the received function.

This concept is important for understanding decorators.

## 4. Creating a Simple Decorator

A decorator is usually implemented using nested functions and closures.

### Example

```python
def my_decorator(func):

    def wrapper():
        print("Before function execution")

        func()

        print("After function execution")

    return wrapper


def greet():
    print("Hello Python")


result = my_decorator(greet)

result()
```

**Output:**

```text
Before function execution
Hello Python
After function execution
```

### Understanding the Execution

1. `greet` is passed to `my_decorator`.
2. The parameter `func` refers to `greet`.
3. The decorator defines the `wrapper` function.
4. It returns the `wrapper` function.
5. `result()` executes the wrapper.
6. The original function executes through `func()`.

The wrapper adds extra behavior before and after the original function.

## 5. Using the @ Decorator Syntax

Python provides a shorter way to apply decorators using `@`.

### Without @ Syntax

```python
def my_decorator(func):

    def wrapper():
        print("Before execution")
        func()
        print("After execution")

    return wrapper


def greet():
    print("Hello Python")


greet = my_decorator(greet)

greet()
```

### With @ Syntax

```python
def my_decorator(func):

    def wrapper():
        print("Before execution")
        func()
        print("After execution")

    return wrapper


@my_decorator
def greet():
    print("Hello Python")


greet()
```

**Output:**

```text
Before execution
Hello Python
After execution
```

The following syntax:

```python
@my_decorator
def greet():
    print("Hello Python")
```

Is equivalent to:

```python
def greet():
    print("Hello Python")

greet = my_decorator(greet)
```

## 6. Decorators with Function Arguments

The previous decorator works only with functions that take no arguments.

To support functions with different arguments, use `*args` and `**kwargs`.

```python
def my_decorator(func):

    def wrapper(*args, **kwargs):
        print("Function is starting")

        result = func(*args, **kwargs)

        print("Function is completed")

        return result

    return wrapper


@my_decorator
def add(a, b):
    return a + b


print(add(10, 20))
```

**Output:**

```text
Function is starting
Function is completed
30
```

### Understanding *args and **kwargs

- `*args` collects positional arguments into a tuple.
- `**kwargs` collects keyword arguments into a dictionary.
- `func(*args, **kwargs)` forwards those arguments to the original function.

This makes the decorator reusable with different function signatures.

## 7. Decorators with Return Values

A decorator should return the original function's result when the original function returns a value.

```python
def my_decorator(func):

    def wrapper(*args, **kwargs):

        result = func(*args, **kwargs)

        return result

    return wrapper


@my_decorator
def multiply(a, b):
    return a * b


print(multiply(5, 4))
```

**Output:**

```text
20
```

If the wrapper does not return `result`, the decorated function will return `None` in this example.

## 8. Decorators with Multiple Functions

The same decorator can be applied to multiple functions.

```python
def my_decorator(func):

    def wrapper():
        print("Executing function")

        func()

    return wrapper


@my_decorator
def greet():
    print("Hello!")


@my_decorator
def welcome():
    print("Welcome to Python!")


greet()
welcome()
```

**Output:**

```text
Executing function
Hello!
Executing function
Welcome to Python!
```

A single decorator can add common behavior to multiple functions.

## 9. Decorators with Parameters

Sometimes we need to pass configuration values to a decorator.

This requires an additional outer function.

### Example

```python
def repeat(times):

    def decorator(func):

        def wrapper(*args, **kwargs):

            for _ in range(times):
                func(*args, **kwargs)

        return wrapper

    return decorator


@repeat(3)
def greet():
    print("Hello Python")


greet()
```

**Output:**

```text
Hello Python
Hello Python
Hello Python
```

### Understanding the Structure

There are three levels:

1. `repeat(times)` receives the decorator configuration.
2. `decorator(func)` receives the function.
3. `wrapper()` executes the original function.

This structure allows us to configure how a decorator behaves.

## 10. Using functools.wraps

Decorators can change the metadata of the original function.

For example, the decorated function may display the wrapper's name instead of its original name.

Use `functools.wraps` to preserve important function metadata.

### Without wraps

```python
def my_decorator(func):

    def wrapper():
        func()

    return wrapper


@my_decorator
def greet():
    """Displays a greeting."""

    print("Hello Python")


print(greet.__name__)
```

**Output:**

```text
wrapper
```

### With wraps

```python
from functools import wraps


def my_decorator(func):

    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)

    return wrapper


@my_decorator
def greet():
    """Displays a greeting."""

    print("Hello Python")


print(greet.__name__)
print(greet.__doc__)
```

**Output:**

```text
greet
Displays a greeting.
```

`@wraps(func)` preserves metadata such as the original function's name and docstring.

## 11. Practical Example: Execution Time Decorator

Decorators can measure how long a function takes to execute.

```python
import time
from functools import wraps


def calculate_time(func):

    @wraps(func)
    def wrapper(*args, **kwargs):

        start = time.perf_counter()

        result = func(*args, **kwargs)

        end = time.perf_counter()

        print("Execution time:", end - start, "seconds")

        return result

    return wrapper


@calculate_time
def calculate_sum():
    return sum(range(1000000))


print(calculate_sum())
```

**Possible Output:**

```text
Execution time: 0.02 seconds
499999500000
```

The execution time depends on the computer and environment.

## 12. Practical Example: Authentication Decorator

A decorator can check whether a user is authorized before allowing a function to execute.

```python
from functools import wraps


def check_login(func):

    @wraps(func)
    def wrapper(is_logged_in):

        if not is_logged_in:
            print("Access denied")
            return

        return func(is_logged_in)

    return wrapper


@check_login
def dashboard(is_logged_in):
    print("Welcome to Dashboard")


dashboard(True)
dashboard(False)
```

**Output:**

```text
Welcome to Dashboard
Access denied
```

This is a simplified example. Real authentication systems require secure identity verification and proper authorization checks.

## 13. Built-in Python Decorators

Python provides several built-in decorators.

| Decorator | Purpose |
|---|---|
| `@staticmethod` | Defines a method that does not receive an automatic instance or class argument |
| `@classmethod` | Defines a method that receives the class as its first argument |
| `@property` | Allows a method to be accessed like an attribute |
| `@functools.wraps` | Preserves wrapped function metadata |
| `@functools.lru_cache` | Caches function results |

### Example: staticmethod

```python
class Calculator:

    @staticmethod
    def add(a, b):
        return a + b


print(Calculator.add(10, 20))
```

**Output:**

```text
30
```

### Example: classmethod

```python
class Student:

    college = "MIT"

    @classmethod
    def get_college(cls):
        return cls.college


print(Student.get_college())
```

**Output:**

```text
MIT
```

### Example: property

```python
class Student:

    def __init__(self, name):
        self.name = name

    @property
    def student_name(self):
        return self.name


student = Student("Vikith")

print(student.student_name)
```

**Output:**

```text
Vikith
```

## 14. Decorator Execution Order

Python allows multiple decorators to be applied to the same function.

```python
def decorator_one(func):

    def wrapper():
        print("Decorator One - Before")
        func()
        print("Decorator One - After")

    return wrapper


def decorator_two(func):

    def wrapper():
        print("Decorator Two - Before")
        func()
        print("Decorator Two - After")

    return wrapper


@decorator_one
@decorator_two
def greet():
    print("Hello Python")


greet()
```

**Output:**

```text
Decorator One - Before
Decorator Two - Before
Hello Python
Decorator Two - After
Decorator One - After
```

Decorators are applied from the bottom upwards.

The above is equivalent to:

```python
greet = decorator_one(decorator_two(greet))
```

## 15. Important Differences

| Concept | Purpose |
|---|---|
| Nested function | Defines a function inside another function |
| Closure | Retains access to variables from an enclosing scope |
| Decorator | Extends or modifies a function's behavior |
| Wrapper | Inner function that adds behavior around the original function |
| `@` syntax | Applies a decorator to a function or class |
