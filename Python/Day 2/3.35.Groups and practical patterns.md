# Groups and Practical Patterns in Python Regular Expressions

Groups allow you to combine parts of a regular expression, capture matched text, and apply operations to specific sections of a pattern.

Python supports groups through parentheses `()` in the `re` module.

```python
import re
```

## 1. Capturing Groups `()`

Parentheses create a capturing group. The matched content inside the parentheses can be extracted separately.

```python
import re

text = "My phone number is 9876543210"

result = re.search(r"(\d{10})", text)

if result:
    print(result.group(0))
    print(result.group(1))
```

**Output:**

```text
9876543210
9876543210
```

- `group(0)` returns the entire matched text.
- `group(1)` returns the first captured group.

## 2. Multiple Capturing Groups

You can create multiple groups to capture different parts of a pattern.

```python
import re

text = "Date: 17-11-2026"

result = re.search(r"(\d{2})-(\d{2})-(\d{4})", text)

if result:
    print(result.group(0))
    print(result.group(1))
    print(result.group(2))
    print(result.group(3))
```

**Output:**

```text
17-11-2026
17
11
2026
```

Each pair of parentheses creates a separate capturing group.

## 3. Using groups() Method

The `groups()` method returns all captured groups as a tuple.

```python
import re

text = "John-25"

result = re.search(r"([A-Za-z]+)-(\d+)", text)

if result:
    print(result.groups())
```

**Output:**

```text
('John', '25')
```

## 4. Named Capturing Groups

Named groups allow you to assign meaningful names to captured values.

Syntax:

```python
(?P<name>pattern)
```

Example:

```python
import re

text = "Name: John, Age: 25"

result = re.search(
    r"Name: (?P<name>[A-Za-z]+), Age: (?P<age>\d+)",
    text
)

if result:
    print(result.group("name"))
    print(result.group("age"))
```

**Output:**

```text
John
25
```

Named groups make complex patterns easier to understand.

## 5. Non-Capturing Groups `(?:)`

Sometimes you need to group parts of a pattern without storing the matched text as a separate group.

Use `(?:...)` for this purpose.

```python
import re

text = "Python Java JavaScript"

result = re.findall(r"(?:Python|Java)", text)

print(result)
```

**Output:**

```text
['Python', 'Java']
```

The group combines alternatives, but it does not capture them as a separate group.

## 6. Alternation Operator `|`

The `|` operator means OR. It matches either the pattern on the left or the pattern on the right.

```python
import re

text = "I use Python and Java"

result = re.findall(r"Python|Java", text)

print(result)
```

**Output:**

```text
['Python', 'Java']
```

You can combine alternation with groups.

```python
import re

text = "I like apple, banana and mango"

result = re.findall(r"(apple|banana|mango)", text)

print(result)
```

**Output:**

```text
['apple', 'banana', 'mango']
```

## 7. Backreferences

A backreference allows you to match the same text that was previously captured by a group.

Use `\1` to refer to the first capturing group, `\2` for the second, and so on.

Example: Finding repeated words.

```python
import re

text = "Python Python is easy"

result = re.findall(r"\b(\w+)\s+\1\b", text)

print(result)
```

**Output:**

```text
['Python']
```

Here:

- `(\w+)` captures a word.
- `\s+` matches one or more spaces.
- `\1` matches the same word again.

## 8. Practical Regex Patterns

These patterns demonstrate common text-processing tasks. They are useful starting points, not complete validation rules for every possible input.

### Email Address Pattern

```python
import re

text = "Contact: support@example.com"

pattern = r"[\w.-]+@[\w.-]+\.\w+"

result = re.findall(pattern, text)

print(result)
```

**Output:**

```text
['support@example.com']
```

### Indian Mobile Number (Basic Format)

```python
import re

phone = "9876543210"

pattern = r"[6-9]\d{9}"

result = re.fullmatch(pattern, phone)

print(result is not None)
```

**Output:**

```text
True
```

This checks for a ten-digit number beginning with 6, 7, 8, or 9. It does not verify whether the number is active or assigned.

### Date in DD-MM-YYYY Format

```python
import re

date = "17-11-2026"

pattern = r"(\d{2})-(\d{2})-(\d{4})"

result = re.fullmatch(pattern, date)

if result:
    day, month, year = result.groups()
    print("Day:", day)
    print("Month:", month)
    print("Year:", year)
```

**Output:**

```text
Day: 17
Month: 11
Year: 2026
```

This checks the date's structure, not whether the date is valid on a calendar.

### Extracting URLs

```python
import re

text = "Visit https://www.example.com for details"

pattern = r"https?://[^\s]+"

result = re.findall(pattern, text)

print(result)
```

**Output:**

```text
['https://www.example.com']
```

### Password Format Check

```python
import re

password = "Python@123"

pattern = r"(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[@#$%]).{8,}"

result = re.fullmatch(pattern, password)

print(result is not None)
```

**Output:**

```text
True
```

This pattern checks for:

- At least one uppercase letter.
- At least one lowercase letter.
- At least one digit.
- At least one character from `@#$%`.
- At least eight characters in total.

The `(?=...)` expressions are positive lookaheads. They check that a condition exists without consuming characters.

## 9. Important Regex Group Syntax

| Syntax | Purpose |
|---|---|
| `(pattern)` | Capturing group |
| `(?:pattern)` | Non-capturing group |
| `(?P<name>pattern)` | Named capturing group |
| `\1` | Backreference to the first group |
| `\2` | Backreference to the second group |
| `A\|B` | Matches A or B |
| `(?=pattern)` | Positive lookahead |
| `(?!pattern)` | Negative lookahead |

## 10. Real-World Applications

- **Data extraction:** Extract names, dates, phone numbers, and email addresses.
- **Form validation:** Check whether input follows a required format.
- **Log processing:** Capture timestamps, error codes, and user IDs.
- **Duplicate detection:** Find repeated words using backreferences.
- **Data cleaning:** Extract or replace specific portions of text.
- **Password checks:** Check whether a password contains required character types.
