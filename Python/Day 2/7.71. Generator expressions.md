

# Python Generator Expressions

## 1. What Is a Generator Expression?

A generator expression is a compact way to create a generator object.

It allows us to generate values one at a time instead of creating and storing an entire collection in memory.

Generator expressions are similar to list comprehensions, but they use parentheses `()` instead of square brackets `[]`.

### Syntax

```python
(expression for item in iterable)
```

### Example

```python
numbers = (x for x in range(5))

print(numbers)
print(type(numbers))
```

**Possible Output:**

```text
<generator object <genexpr> at ...>
<class 'generator'>
```

The expression creates a generator object, not a list.

## 2. Generator Expression vs List Comprehension

Both use a similar syntax, but their behavior is different.

### List Comprehension

```python
numbers = [x * 2 for x in range(5)]

print(numbers)
```

**Output:**

```text
[0, 2, 4, 6, 8]
```

A list comprehension evaluates all elements immediately and stores them in a list.

### Generator Expression

```python
numbers = (x * 2 for x in range(5))

print(next(numbers))
print(next(numbers))
print(next(numbers))
```

**Output:**

```text
0
2
4
```

A generator expression produces values only when requested.

### Comparison

| Feature | List Comprehension | Generator Expression |
|---|---|---|
| Syntax | `[]` | `()` |
| Result | List | Generator object |
| Execution | Eager | Lazy |
| Memory | Stores all elements | Produces elements on demand |
| Indexing | Supported | Not supported |
| Reusability | Can iterate repeatedly | Usually exhausted after one iteration |

## 3. Using next() with Generator Expressions

We can use `next()` to retrieve values individually.

```python
numbers = (x for x in range(1, 6))

print(next(numbers))
print(next(numbers))
print(next(numbers))
print(next(numbers))
print(next(numbers))
```

**Output:**

```text
1
2
3
4
5
```

Each call to `next()` retrieves the next value.

Calling `next()` again after all values are consumed raises `StopIteration`.

## 4. Using Generator Expressions with for Loops

We can directly use a generator expression inside a `for` loop.

```python
numbers = (x for x in range(1, 6))

for number in numbers:
    print(number)
```

**Output:**

```text
1
2
3
4
5
```

The `for` loop automatically retrieves values until the generator is exhausted.

## 5. Generator Expressions with Conditions

We can apply conditions to filter values.

### Example: Even Numbers

```python
even_numbers = (x for x in range(1, 11) if x % 2 == 0)

for number in even_numbers:
    print(number)
```

**Output:**

```text
2
4
6
8
10
```

### Example: Odd Numbers

```python
odd_numbers = (x for x in range(1, 11) if x % 2 != 0)

print(list(odd_numbers))
```

**Output:**

```text
[1, 3, 5, 7, 9]
```

`list()` consumes the generator and collects its generated values into a list.

## 6. Generator Expressions with Strings

Generator expressions can process strings character by character.

### Example: Convert Characters to Uppercase

```python
name = "python"

result = (char.upper() for char in name)

print(list(result))
```

**Output:**

```text
['P', 'Y', 'T', 'H', 'O', 'N']
```

### Example: Filter Vowels

```python
word = "programming"

vowels = (char for char in word if char in "aeiou")

print(list(vowels))
```

**Output:**

```text
['o', 'a', 'i']
```

## 7. Generator Expressions with Mathematical Operations

We can perform calculations while generating values.

### Example: Squares

```python
squares = (x ** 2 for x in range(1, 6))

print(list(squares))
```

**Output:**

```text
[1, 4, 9, 16, 25]
```

### Example: Cubes

```python
cubes = (x ** 3 for x in range(1, 6))

for value in cubes:
    print(value)
```

**Output:**

```text
1
8
27
64
125
```

## 8. Generator Expressions with Built-in Functions

Generator expressions work well with built-in functions such as `sum()`, `min()`, `max()`, and `any()`.

### sum()

Calculates the total of generated values.

```python
total = sum(x for x in range(1, 6))

print(total)
```

**Output:**

```text
15
```

### min()

Returns the smallest generated value.

```python
smallest = min(x for x in [10, 5, 30, 2, 15])

print(smallest)
```

**Output:**

```text
2
```

### max()

Returns the largest generated value.

```python
largest = max(x for x in [10, 5, 30, 2, 15])

print(largest)
```

**Output:**

```text
30
```

### any()

Returns `True` if at least one generated value is truthy.

```python
result = any(x > 10 for x in [2, 5, 15, 20])

print(result)
```

**Output:**

```text
True
```

### all()

Returns `True` if every generated value is truthy.

```python
result = all(x > 0 for x in [2, 5, 10])

print(result)
```

**Output:**

```text
True
```

## 9. Generator Expressions with Nested Loops

Generator expressions can also contain multiple `for` clauses.

### Example

```python
pairs = ((x, y) for x in [1, 2] for y in [10, 20])

print(list(pairs))
```

**Output:**

```text
[(1, 10), (1, 20), (2, 10), (2, 20)]
```

The order works like nested loops:

```python
for x in [1, 2]:
    for y in [10, 20]:
        print(x, y)
```

## 10. Generator Expressions with Dictionaries

We can generate values from dictionary data.

```python
students = {
    "Vikith": 90,
    "Anil": 85,
    "Ram": 95
}

high_scores = (
    name for name, marks in students.items()
    if marks >= 90
)

print(list(high_scores))
```

**Output:**

```text
['Vikith', 'Ram']
```

## 11. Lazy Evaluation

Lazy evaluation means values are generated only when they are requested.

Consider:

```python
numbers = (x * 2 for x in range(1, 6))
```

At this point, Python has created a generator object. It has not calculated and stored all the results.

When we call:

```python
print(next(numbers))
```

Python calculates and returns only the next value.

**Benefits:**

- Reduces memory usage for large sequences.
- Avoids unnecessary calculations.
- Supports processing data one element at a time.
- Useful for data pipelines and streaming operations.
