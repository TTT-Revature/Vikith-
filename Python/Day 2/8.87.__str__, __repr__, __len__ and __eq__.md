

# Python Special Methods: `__str__`, `__repr__`, `__len__` and `__eq__`

## 1. What are Special Methods?

Special methods are predefined methods in Python that have double underscores before and after their names. They are also called **dunder methods**.

They allow objects to define how they behave with built-in Python operations and functions.

Examples:

| Special Method | Purpose |
|---|---|
| `__str__()` | Provides a readable string representation |
| `__repr__()` | Provides a developer-oriented representation |
| `__len__()` | Defines the result of `len()` |
| `__eq__()` | Defines equality comparison using `==` |

## 2. `__str__()` Method

The `__str__()` method defines the user-friendly string representation of an object.

It is called automatically when using:
- `print(object)`
- `str(object)`

### Example

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"Student Name: {self.name}, Age: {self.age}"


student = Student("Vikith", 24)

print(student)
print(str(student))
```

**Output:**
```text
Student Name: Vikith, Age: 24
Student Name: Vikith, Age: 24
```

Without `__str__()`, printing an object normally displays a default representation containing its class name and identity information.

**Important:** `__str__()` must return a string. It should not use `print()` instead of `return`.

## 3. `__repr__()` Method

The `__repr__()` method defines a developer-oriented representation of an object.

It is commonly used for debugging and inspecting objects.

It is called automatically when using:
- `repr(object)`
- Interactive Python representation of an object
- Elements displayed inside lists and other containers

### Example

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Student(name={self.name!r}, age={self.age})"


student = Student("Vikith", 24)

print(repr(student))
```

**Output:**
```text
Student(name='Vikith', age=24)
```

The `!r` inside the f-string applies `repr()` to the value.

### `__str__()` and `__repr__()` Together

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"{self.name} is {self.age} years old"

    def __repr__(self):
        return f"Student(name={self.name!r}, age={self.age})"


student = Student("Vikith", 24)

print(str(student))
print(repr(student))
print(student)
```

**Output:**
```text
Vikith is 24 years old
Student(name='Vikith', age=24)
Vikith is 24 years old
```

### Difference Between `__str__()` and `__repr__()`

| `__str__()` | `__repr__()` |
|---|---|
| User-friendly representation | Developer-oriented representation |
| Used by `str()` | Used by `repr()` |
| Called by `print()` | Used when inspecting objects |
| Focuses on readability | Focuses on clarity and debugging |

**Important:** If `__str__()` is not defined, Python can fall back to `__repr__()` when one is available.

## 4. `__len__()` Method

The `__len__()` method defines what the built-in `len()` function returns for a custom object.

### Example

```python
class ShoppingCart:
    def __init__(self, items):
        self.items = items

    def __len__(self):
        return len(self.items)


cart = ShoppingCart(["Laptop", "Mouse", "Keyboard"])

print(len(cart))
```

**Output:**
```text
3
```

**Explanation:**
- `len(cart)` internally calls `cart.__len__()`.
- The method returns the number of items in the shopping cart.

### Another Example

```python
class Team:
    def __init__(self, members):
        self.members = members

    def __len__(self):
        return len(self.members)


team = Team(["John", "David", "Sam", "Alex"])

print(len(team))
```

**Output:**
```text
4
```

**Important:** `__len__()` must return a non-negative integer. Returning an invalid value raises `TypeError`.

## 5. `__eq__()` Method

The `__eq__()` method defines how two objects are compared using the equality operator (`==`).

By default, custom objects generally compare by identity rather than by their attribute values.

### Example Without `__eq__()`

```python
class Student:
    def __init__(self, name):
        self.name = name


s1 = Student("Vikith")
s2 = Student("Vikith")

print(s1 == s2)
```

**Output:**
```text
False
```

Although both objects contain the same name, they are different objects.

### Example With `__eq__()`

```python
class Student:
    def __init__(self, name):
        self.name = name

    def __eq__(self, other):
        if not isinstance(other, Student):
            return NotImplemented

        return self.name == other.name


s1 = Student("Vikith")
s2 = Student("Vikith")
s3 = Student("Rahul")

print(s1 == s2)
print(s1 == s3)
```

**Output:**
```text
True
False
```

**Explanation:**
- `s1 == s2` calls `s1.__eq__(s2)`.
- The method compares their `name` attributes.
- Both names are the same, so it returns `True`.
- Different names produce `False`.

### Using `NotImplemented`

```python
def __eq__(self, other):
    if not isinstance(other, Student):
        return NotImplemented

    return self.name == other.name
```

`NotImplemented` tells Python that this method does not handle the comparison with the given type. Python can then try the other object's comparison method or use its fallback behavior.

## 6. Combining All Four Methods

```python
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def __str__(self):
        return f"{self.name} - Rs.{self.price}"

    def __repr__(self):
        return f"Product(name={self.name!r}, price={self.price})"

    def __len__(self):
        return len(self.name)

    def __eq__(self, other):
        if not isinstance(other, Product):
            return NotImplemented

        return self.name == other.name and self.price == other.price


p1 = Product("Laptop", 50000)
p2 = Product("Laptop", 50000)
p3 = Product("Mouse", 1000)

print(p1)
print(repr(p1))
print(len(p1))
print(p1 == p2)
print(p1 == p3)
```

**Output:**
```text
Laptop - Rs.50000
Product(name='Laptop', price=50000)
6
True
False
```

## 7. Quick Reference

| Operation | Special Method | Example |
|---|---|---|
| `str(obj)` | `__str__()` | `str(student)` |
| `repr(obj)` | `__repr__()` | `repr(student)` |
| `len(obj)` | `__len__()` | `len(cart)` |
| `obj1 == obj2` | `__eq__()` | `s1 == s2` |

## 8. Real-World Use Cases

- `__str__()`: Displaying readable employee, student, or product information.
- `__repr__()`: Debugging objects and inspecting their internal values.
- `__len__()`: Counting items in shopping carts, collections, or custom containers.
- `__eq__()`: Comparing two products, students, employees, or other objects based on their attributes.
