# List Methods and Sorting in Python

Python provides several built-in list methods to add, remove, search, modify, and sort elements.

Lists are mutable, so most list methods modify the original list.

## 1. Adding Elements

### append()

Adds a single element to the end of the list.

```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

**Output:**

```text
[10, 20, 30, 40]
```

### extend()

Adds multiple elements from an iterable to the end of the list.

```python
numbers = [10, 20, 30]

numbers.extend([40, 50, 60])

print(numbers)
```

**Output:**

```text
[10, 20, 30, 40, 50, 60]
```

### insert()

Inserts an element at a specified index.

**Syntax:**

```python
list.insert(index, element)
```

```python
fruits = ["Apple", "Mango"]

fruits.insert(1, "Banana")

print(fruits)
```

**Output:**

```text
['Apple', 'Banana', 'Mango']
```

## 2. Removing Elements

### remove()

Removes the first occurrence of the specified value.

```python
numbers = [10, 20, 30, 20]

numbers.remove(20)

print(numbers)
```

**Output:**

```text
[10, 30, 20]
```

If the value does not exist, `remove()` raises a `ValueError`.

### pop()

Removes and returns an element from the list.

- Without an index, it removes the last element.
- With an index, it removes the element at that position.

```python
numbers = [10, 20, 30, 40]

result = numbers.pop()

print(result)
print(numbers)
```

**Output:**

```text
40
[10, 20, 30]
```

Using an index:

```python
numbers = [10, 20, 30, 40]

result = numbers.pop(1)

print(result)
print(numbers)
```

**Output:**

```text
20
[10, 30, 40]
```

### clear()

Removes all elements from the list.

```python
numbers = [10, 20, 30]

numbers.clear()

print(numbers)
```

**Output:**

```text
[]
```

## 3. Searching and Counting

### index()

Returns the index of the first occurrence of a specified value.

```python
fruits = ["Apple", "Banana", "Mango"]

print(fruits.index("Banana"))
```

**Output:**

```text
1
```

If the value is not found, it raises a `ValueError`.

### count()

Returns how many times a value occurs in the list.

```python
numbers = [10, 20, 10, 30, 10]

print(numbers.count(10))
```

**Output:**

```text
3
```

## 4. Sorting Lists

Python provides two common ways to sort lists:

1. `sort()` – Sorts the original list.
2. `sorted()` – Returns a new sorted list.

### sort()

Sorts the original list in ascending order by default.

```python
numbers = [40, 10, 30, 20]

numbers.sort()

print(numbers)
```

**Output:**

```text
[10, 20, 30, 40]
```

### Descending Order

Use `reverse=True` to sort in descending order.

```python
numbers = [40, 10, 30, 20]

numbers.sort(reverse=True)

print(numbers)
```

**Output:**

```text
[40, 30, 20, 10]
```

### Sorting Strings

Strings are sorted lexicographically (according to Unicode code points).

```python
names = ["David", "Alice", "John", "Bob"]

names.sort()

print(names)
```

**Output:**

```text
['Alice', 'Bob', 'David', 'John']
```

### Case-Insensitive Sorting

Use `key=str.lower` to sort strings without distinguishing uppercase and lowercase for comparison.

```python
names = ["banana", "Apple", "cherry", "Mango"]

names.sort(key=str.lower)

print(names)
```

**Output:**

```text
['Apple', 'banana', 'cherry', 'Mango']
```

### sorted()

Unlike `sort()`, the `sorted()` function does not modify the original list. It returns a new sorted list.

```python
numbers = [40, 10, 30, 20]

result = sorted(numbers)

print(result)
print(numbers)
```

**Output:**

```text
[10, 20, 30, 40]
[40, 10, 30, 20]
```

Descending order:

```python
numbers = [40, 10, 30, 20]

result = sorted(numbers, reverse=True)

print(result)
```

**Output:**

```text
[40, 30, 20, 10]
```

## 5. Custom Sorting with key

The `key` parameter allows you to specify which value should be used for sorting.

### Sorting by String Length

```python
words = ["Python", "Java", "C", "JavaScript"]

words.sort(key=len)

print(words)
```

**Output:**

```text
['C', 'Java', 'Python', 'JavaScript']
```

### Sorting Tuples by the Second Element

```python
students = [
    ("John", 85),
    ("Alice", 95),
    ("David", 75)
]

students.sort(key=lambda student: student[1])

print(students)
```

**Output:**

```text
[('David', 75), ('John', 85), ('Alice', 95)]
```

Here, `lambda student: student[1]` tells Python to sort using the marks.

### Sorting Dictionaries Inside a List

```python
students = [
    {"name": "John", "marks": 85},
    {"name": "Alice", "marks": 95},
    {"name": "David", "marks": 75}
]

students.sort(key=lambda student: student["marks"], reverse=True)

print(students)
```

**Output:**

```text
[{'name': 'Alice', 'marks': 95}, {'name': 'John', 'marks': 85}, {'name': 'David', 'marks': 75}]
```

## 6. Reversing a List

### reverse()

Reverses the order of elements in the original list. It does not sort the elements.

```python
numbers = [10, 30, 20, 40]

numbers.reverse()

print(numbers)
```

**Output:**

```text
[40, 20, 30, 10]
```

### Difference Between reverse() and sort(reverse=True)

```python
numbers = [30, 10, 40, 20]

numbers.reverse()
print(numbers)

numbers.sort(reverse=True)
print(numbers)
```

**Output:**

```text
[20, 40, 10, 30]
[40, 30, 20, 10]
```

- `reverse()` only reverses the current order.
- `sort(reverse=True)` sorts the values in descending order.

## 7. Copying Lists

### copy()

Creates a shallow copy of the list.

```python
original = [10, 20, 30]

copied = original.copy()

copied.append(40)

print(original)
print(copied)
```

**Output:**

```text
[10, 20, 30]
[10, 20, 30, 40]
```

The outer lists are separate objects.

## 8. Other Useful List Operations

### len()

Returns the number of elements.

```python
numbers = [10, 20, 30]

print(len(numbers))
```

**Output:**

```text
3
```

### min()

Returns the smallest element.

```python
numbers = [40, 10, 30, 20]

print(min(numbers))
```

**Output:**

```text
10
```

### max()

Returns the largest element.

```python
numbers = [40, 10, 30, 20]

print(max(numbers))
```

**Output:**

```text
40
```

### sum()

Returns the sum of numeric elements.

```python
numbers = [10, 20, 30]

print(sum(numbers))
```

**Output:**

```text
60
```

## 9. Complete List Method Reference

| Method             | Purpose                          |
| ------------------ | -------------------------------- |
| `append(x)`        | Adds one element at the end      |
| `extend(iterable)` | Adds elements from an iterable   |
| `insert(i, x)`     | Inserts an element at an index   |
| `remove(x)`        | Removes the first matching value |
| `pop(i)`           | Removes and returns an element   |
| `clear()`          | Removes all elements             |
| `index(x)`         | Returns the first matching index |
| `count(x)`         | Counts occurrences               |
| `sort()`           | Sorts the original list          |
| `reverse()`        | Reverses the original list       |
| `copy()`           | Creates a shallow copy           |

**Useful built-in functions:** `sorted()`, `len()`, `min()`, `max()`, and `sum()`.

## 10. Important Differences

| Operation        | Modifies Original List? | Returns          |
| ---------------- | ----------------------- | ---------------- |
| `list.sort()`    | Yes                     | `None`           |
| `sorted(list)`   | No                      | New sorted list  |
| `list.reverse()` | Yes                     | `None`           |
| `list.copy()`    | No                      | New shallow copy |
| `list.append()`  | Yes                     | `None`           |
| `list.extend()`  | Yes                     | `None`           |
| `list.pop()`     | Yes                     | Removed element  |
