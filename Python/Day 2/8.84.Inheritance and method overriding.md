# Python Inheritance and Method Overriding

## 1. What Is Inheritance?

Inheritance is one of the four main principles of Object-Oriented Programming (OOP).

It allows one class to acquire the attributes and methods of another class.

The main benefits are:
- Code reusability.
- Reduced code duplication.
- Easier maintenance.
- Better organization of related classes.

**Terminology:**

- Parent class: The class whose features are inherited.
- Child class: The class that inherits from another class.
- Base class: Another name for a parent class.
- Derived class: Another name for a child class.

## 2. Basic Inheritance

**Syntax:**

```python
class Parent:
    # Parent attributes and methods
    pass


class Child(Parent):
    # Child attributes and methods
    pass
```

**Example:**

```python
class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):
    pass


dog = Dog()

dog.eat()
```

**Output:**

```text
Animal is eating
```

Here:
- `Animal` is the parent class.
- `Dog` is the child class.
- `Dog` inherits the `eat()` method.
- The child object can use the parent's method.

## 3. Adding Methods to a Child Class

A child class can have its own methods in addition to inherited methods.

```python
class Animal:

    def eat(self):
        print("Animal is eating")


class Dog(Animal):

    def bark(self):
        print("Dog is barking")


dog = Dog()

dog.eat()
dog.bark()
```

**Output:**

```text
Animal is eating
Dog is barking
```

The child class can use both inherited and its own methods.

## 4. Inheritance with Attributes and __init__()

A child class can define its own initializer and attributes.

```python
class Animal:

    def __init__(self, name):
        self.name = name


class Dog(Animal):

    def __init__(self, name, breed):
        self.name = name
        self.breed = breed


dog = Dog("Tommy", "Labrador")

print(dog.name)
print(dog.breed)
```

**Output:**

```text
Tommy
Labrador
```

The child class has its own `__init__()` method.

However, we can reuse the parent class initializer using `super()`.

## 5. Understanding super()

`super()` provides access to methods from a parent class according to Python's method resolution order (MRO).

It is commonly used to call the parent class initializer or extend a parent method.

**Example:**

```python
class Animal:

    def __init__(self, name):
        self.name = name


class Dog(Animal):

    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed


dog = Dog("Tommy", "Labrador")

print(dog.name)
print(dog.breed)
```

**Output:**

```text
Tommy
Labrador
```

Here:

```python
super().__init__(name)
```

Calls the parent class initializer and initializes `self.name`.

The child class then initializes its own `breed` attribute.

## 6. What Is Method Overriding?

Method overriding occurs when a child class defines a method with the same name as a method in its parent class.

When that method is called on a child object, Python uses the child class implementation.

**Example:**

```python
class Animal:

    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):

    def sound(self):
        print("Dog barks")


dog = Dog()

dog.sound()
```

**Output:**

```text
Dog barks
```

Here:
- Both classes have a method named `sound()`.
- The child class provides its own implementation.
- The child implementation is used for the Dog object.

## 7. Why Do We Need Method Overriding?

Different child classes can provide different implementations of the same inherited method.

```python
class Animal:

    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):

    def sound(self):
        print("Dog barks")


class Cat(Animal):

    def sound(self):
        print("Cat meows")


dog = Dog()
cat = Cat()

dog.sound()
cat.sound()
```

**Output:**

```text
Dog barks
Cat meows
```

The same method name behaves differently depending on the object.

## 8. Using super() with Method Overriding

Sometimes we want to execute the parent method and then add extra functionality in the child method.

We can use `super()` for this.

```python
class Animal:

    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):

    def sound(self):
        super().sound()
        print("Dog barks")


dog = Dog()

dog.sound()
```

**Output:**

```text
Animal makes a sound
Dog barks
```

Here:
- `super().sound()` calls the parent implementation.
- The child method adds its own behavior.

## 9. Types of Inheritance

Python supports five commonly discussed inheritance structures.

### Single Inheritance

One child class inherits from one parent class.

```python
class Animal:
    def eat(self):
        print("Eating")


class Dog(Animal):
    def bark(self):
        print("Barking")


dog = Dog()

dog.eat()
dog.bark()
```

### Multiple Inheritance

One child class inherits from multiple parent classes.

```python
class Father:

    def skills(self):
        print("Gardening")


class Mother:

    def talent(self):
        print("Cooking")


class Child(Father, Mother):
    pass


child = Child()

child.skills()
child.talent()
```

**Output:**

```text
Gardening
Cooking
```

### Multilevel Inheritance

A class inherits from a child class, forming an inheritance chain.

```python
class Grandfather:

    def house(self):
        print("Grandfather's house")


class Father(Grandfather):

    def car(self):
        print("Father's car")


class Child(Father):

    def bike(self):
        print("Child's bike")


child = Child()

child.house()
child.car()
child.bike()
```

**Output:**

```text
Grandfather's house
Father's car
Child's bike
```

### Hierarchical Inheritance

Multiple child classes inherit from the same parent class.

```python
class Animal:

    def eat(self):
        print("Eating")


class Dog(Animal):
    pass


class Cat(Animal):
    pass


dog = Dog()
cat = Cat()

dog.eat()
cat.eat()
```

### Hybrid Inheritance

Hybrid inheritance combines two or more inheritance structures.

```python
class A:
    def method_a(self):
        print("Class A")


class B(A):
    def method_b(self):
        print("Class B")


class C(A):
    def method_c(self):
        print("Class C")


class D(B, C):
    def method_d(self):
        print("Class D")


obj = D()

obj.method_a()
obj.method_b()
obj.method_c()
obj.method_d()
```

**Output:**

```text
Class A
Class B
Class C
Class D
```

## 10. Method Resolution Order (MRO)

Method Resolution Order determines the order in which Python searches classes for a method or attribute.

This is especially important in multiple inheritance.

**Example:**

```python
class A:
    def show(self):
        print("Class A")


class B(A):
    def show(self):
        print("Class B")


class C(A):
    def show(self):
        print("Class C")


class D(B, C):
    pass


obj = D()

obj.show()

print(D.mro())
```

**Output:**

```text
Class B
[<class '__main__.D'>,
 <class '__main__.B'>,
 <class '__main__.C'>,
 <class '__main__.A'>,
 <class 'object'>]
```

Python searches in this order:

1. D
2. B
3. C
4. A
5. object

Since `B` defines `show()`, Python uses that implementation.

## 11. Checking Inheritance Relationships

Python provides built-in functions to inspect inheritance.

### isinstance()

Checks whether an object is an instance of a class or its subclass.

```python
class Animal:
    pass


class Dog(Animal):
    pass


dog = Dog()

print(isinstance(dog, Dog))
print(isinstance(dog, Animal))
```

**Output:**

```text
True
True
```

### issubclass()

Checks whether one class inherits from another class.

```python
class Animal:
    pass


class Dog(Animal):
    pass


print(issubclass(Dog, Animal))
```

**Output:**

```text
True
```

## 12. Real-World Example: Employee Management

```python
class Employee:

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def display_details(self):
        print("Name:", self.name)
        print("Salary:", self.salary)

    def calculate_bonus(self):
        return self.salary * 0.10


class Manager(Employee):

    def __init__(self, name, salary, department):
        super().__init__(name, salary)
        self.department = department

    def display_details(self):
        super().display_details()
        print("Department:", self.department)

    def calculate_bonus(self):
        return self.salary * 0.20


employee = Employee("Rahul", 30000)

manager = Manager("Vikith", 50000, "Development")

employee.display_details()
print("Employee Bonus:", employee.calculate_bonus())

print()

manager.display_details()
print("Manager Bonus:", manager.calculate_bonus())
```

**Output:**

```text
Name: Rahul
Salary: 30000
Employee Bonus: 3000.0

Name: Vikith
Salary: 50000
Department: Development
Manager Bonus: 10000.0
```

This example demonstrates:
- Inheritance: `Manager` inherits from `Employee`.
- `super()`: Reuses the parent initializer and display method.
- Method overriding: `Manager` provides its own `display_details()` and `calculate_bonus()` implementations.

## 13. Important Differences

| Inheritance | Method Overriding |
|---|---|
| Allows one class to acquire another class's features | Allows a child class to redefine an inherited method |
| Promotes code reuse | Allows specialized behavior |
| Uses parent-child relationships | Uses the same method name in parent and child |
| Example: `class Dog(Animal)` | Example: redefining `sound()` in `Dog` |

## 14. Important Points

- Inheritance allows code reuse.
- A child class inherits accessible attributes and methods from its parent.
- Python supports single, multiple, multilevel, hierarchical and hybrid inheritance.
- `super()` provides access to methods in the next class in the MRO.
- Method overriding allows a child class to provide its own method implementation.
- MRO determines the order in which Python searches classes.
- `isinstance()` checks object membership.
- `issubclass()` checks class inheritance.
- Every Python class ultimately inherits from `object` unless a different hierarchy is specified.

## Quick Summary

- **Inheritance:** Reusing functionality from another class.
- **Parent class:** Class being inherited from.
- **Child class:** Class that inherits.
- **`super()`:** Accesses the next implementation in the MRO.
- **Method overriding:** Redefining a parent method in a child class.
- **Single inheritance:** One parent, one child.
- **Multiple inheritance:** Multiple parents, one child.
- **Multilevel inheritance:** Inheritance across multiple levels.
- **Hierarchical inheritance:** Multiple children share one parent.
- **Hybrid inheritance:** Combination of inheritance structures.
- **MRO:** Determines method lookup order.
