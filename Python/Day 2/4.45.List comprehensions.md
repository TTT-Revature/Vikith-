# List Comprehensions in Python

List comprehension is a concise way to create a new list from an existing iterable, such as a list, tuple, string or range.

It allows us to write loops and conditions in a single expression.

## 1. Traditional Approach vs List Comprehension

### Using a for Loop

```python
numbers = [1, 2, 3, 4, 5]

squares = []

for number in numbers:
    squares.append(number ** 2)

print(squares)
```

**Output:**

```text
[1, 4, 9, 16, 25]
```

### Using List Comprehension

```python
numbers = [1, 2, 3, 4, 5]

squares = [number ** 2 for number in numbers]

print(squares)
```

**Output:**

```text
[1, 4, 9, 16, 25]
```

Both approaches produce the same result.

## 2. Basic Syntax

```python
new_list = [expression for item in iterable]
```

| Component | Description |
|---|---|
| `expression` | Value to add to the new list |
| `item` | Variable representing each element |
| `iterable` | Collection to iterate over |

The expression is evaluated for every item, and its result is added to the new list.

## 3. Creating Lists Using range()

```python
numbers = [number for number in range(1, 6)]

print(numbers)
```

**Output:**

```text
[1, 2, 3, 4, 5]
```

### Generating Squares

```python
squares = [number ** 2 for number in range(1, 6)]

print(squares)
```

**Output:**

```text
[1, 4, 9, 16, 25]
```

### Generating Cubes

```python
cubes = [number ** 3 for number in range(1, 6)]

print(cubes)
```

**Output:**

```text
[1, 8, 27, 64, 125]
```

## 4. List Comprehension with Conditions

We can use `if` to filter elements.

### Syntax

```python
new_list = [expression for item in iterable if condition]
```

Only elements that satisfy the condition are included in the new list.

### Example: Even Numbers

```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]

even_numbers = [
    number for number in numbers
    if number % 2 == 0
]

print(even_numbers)
```

**Output:**

```text
[2, 4, 6, 8]
```

### Example: Odd Numbers

```python
odd_numbers = [
    number for number in numbers
    if number % 2 != 0
]

print(odd_numbers)
```

**Output:**

```text
[1, 3, 5, 7]
```

### Example: Numbers Greater Than 5

```python
numbers = [2, 4, 6, 8, 10, 12]

result = [number for number in numbers if number > 5]

print(result)
```

**Output:**

```text
[6, 8, 10, 12]
```

## 5. List Comprehension with if-else

We can use `if-else` to choose which value should be added to the new list.

### Syntax

```python
new_list = [
    value_if_true if condition else value_if_false
    for item in iterable
]
```

**Important:** When using `if-else` as an expression, it appears before the `for` clause.

### Example: Even or Odd

```python
numbers = [1, 2, 3, 4, 5, 6]

result = [
    "Even" if number % 2 == 0 else "Odd"
    for number in numbers
]

print(result)
```

**Output:**

```text
['Odd', 'Even', 'Odd', 'Even', 'Odd', 'Even']
```

### Example: Pass or Fail

```python
marks = [35, 80, 25, 90, 45]

result = [
    "Pass" if mark >= 40 else "Fail"
    for mark in marks
]

print(result)
```

**Output:**

```text
['Fail', 'Pass', 'Fail', 'Pass', 'Pass']
```

## 6. Applying Operations to Strings

List comprehensions also work with strings.

### Converting Strings to Uppercase

```python
names = ["rahul", "arun", "kiran"]

result = [name.upper() for name in names]

print(result)
```

**Output:**

```text
['RAHUL', 'ARUN', 'KIRAN']
```

### Extracting First Characters

```python
names = ["Rahul", "Arun", "Kiran"]

result = [name[0] for name in names]

print(result)
```

**Output:**

```text
['R', 'A', 'K']
```

### Extracting Words with a Specific Length

```python
names = ["Ram", "Rahul", "Arun", "Vikith"]

result = [name for name in names if len(name) > 4]

print(result)
```

**Output:**

```text
['Rahul', 'Vikith']
```

## 7. Nested List Comprehensions

A nested list comprehension contains more than one `for` clause.

It is useful for working with nested lists and generating combinations.

### Syntax

```python
new_list = [
    expression
    for item1 in iterable1
    for item2 in iterable2
]
```

The second loop runs completely for each iteration of the first loop.

### Example: Flattening a Nested List

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

result = [
    number
    for row in matrix
    for number in row
]

print(result)
```

**Output:**

```text
[1, 2, 3, 4, 5, 6, 7, 8, 9]
```

Equivalent traditional approach:

```python
result = []

for row in matrix:
    for number in row:
        result.append(number)
```

### Example: Generating Combinations

```python
colors = ["Red", "Blue"]
sizes = ["S", "M", "L"]

combinations = [
    (color, size)
    for color in colors
    for size in sizes
]

print(combinations)
```

**Output:**

```text
[
    ('Red', 'S'),
    ('Red', 'M'),
    ('Red', 'L'),
    ('Blue', 'S'),
    ('Blue', 'M'),
    ('Blue', 'L')
]
```

## 8. Nested List Comprehension for a Matrix

We can use nested comprehensions to create a two-dimensional list.

```python
matrix = [
    [number for number in range(1, 4)]
    for row in range(3)
]

print(matrix)
```

**Output:**

```text
[
    [1, 2, 3],
    [1, 2, 3],
    [1, 2, 3]
]
```

Here:

- The inner comprehension creates each row.
- The outer comprehension creates three rows.

## 9. List Comprehension with Multiple Conditions

We can use multiple conditions to filter elements.

```python
numbers = range(1, 21)

result = [
    number
    for number in numbers
    if number % 2 == 0
    if number % 3 == 0
]

print(result)
```

**Output:**

```text
[6, 12, 18]
```

Both conditions must be satisfied.

The same logic can be written using `and`:

```python
result = [
    number
    for number in numbers
    if number % 2 == 0 and number % 3 == 0
]
```

## 10. Using Functions Inside List Comprehensions

We can call functions inside the expression.

```python
def square(number):
    return number ** 2

numbers = [1, 2, 3, 4, 5]

result = [square(number) for number in numbers]

print(result)
```

**Output:**

```text
[1, 4, 9, 16, 25]
```

## 11. List Comprehension with Dictionary Data

We can extract values from a list of dictionaries.

```python
students = [
    {"name": "Rahul", "marks": 85},
    {"name": "Arun", "marks": 35},
    {"name": "Kiran", "marks": 90}
]

passed_students = [
    student["name"]
    for student in students
    if student["marks"] >= 40
]

print(passed_students)
```

**Output:**

```text
['Rahul', 'Kiran']
```

This is useful when processing structured records.

## 12. Removing Duplicates Using List Comprehension

List comprehension can be combined with other techniques to filter duplicate values while preserving order.

```python
numbers = [1, 2, 2, 3, 4, 4, 5]

result = []
[result.append(number) for number in numbers if number not in result]

print(result)
```

**Output:**

```text
[1, 2, 3, 4, 5]
```

**Note:** This approach works, but it is not recommended because `append()` is being used for its side effect. A normal `for` loop or `dict.fromkeys()` is clearer for this task.

Recommended approach:

```python
numbers = [1, 2, 2, 3, 4, 4, 5]

result = list(dict.fromkeys(numbers))

print(result)
```

**Output:**

```text
[1, 2, 3, 4, 5]
```

## 13. List Comprehension vs Normal for Loop

| Feature | Normal for Loop | List Comprehension |
|---|---|---|
| Syntax | Multiple lines | Usually one expression |
| Readability | Better for complex logic | Better for simple transformations |
| Filtering | Uses `if` inside loop | Uses `if` in comprehension |
| Creating lists | Requires `append()` | Creates list directly |
| Complex operations | Easier to understand | Can become difficult to read |

## 14. Important Syntax Differences

### Filtering with if

```python
result = [x for x in numbers if x > 5]
```

Only values greater than 5 are included.

### Transforming with if-else

```python
result = ["Big" if x > 5 else "Small" for x in numbers]
```

Every item is included, but its output depends on the condition.

### Multiple for Clauses

```python
result = [(x, y) for x in [1, 2] for y in [3, 4]]
```

Generates combinations using nested iteration.

## 15. Important Points to Remember

- List comprehension creates a new list.
- It can work with any iterable.
- `if` after the `for` clause is used for filtering.
- `if-else` before the `for` clause is used for conditional expressions.
- Multiple `for` clauses can be used for nested iteration.
- List comprehensions can call functions and methods.
- Avoid making comprehensions too complicated.
- Use a normal loop when the logic involves many statements or side effects.

## 16. Real-World Use Cases

- **Data cleaning:** Remove unwanted values and filter records.
- **Data transformation:** Convert names to uppercase or calculate values.
- **Student management:** Extract students who passed an examination.
- **E-commerce:** Filter products based on price or availability.
- **Data analysis:** Extract numbers, calculate squares and process datasets.
- **Matrix processing:** Flatten nested lists and transform rows.

### Example: Filtering Products by Price

```python
products = [
    {"name": "Laptop", "price": 55000},
    {"name": "Mouse", "price": 500},
    {"name": "Keyboard", "price": 1500},
    {"name": "Monitor", "price": 12000}
]

affordable_products = [
    product["name"]
    for product in products
    if product["price"] < 10000
]

print(affordable_products)
```

**Output:**

```text
['Mouse', 'Keyboard']
```
