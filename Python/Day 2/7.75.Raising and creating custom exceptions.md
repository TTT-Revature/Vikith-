# Python Raising and Creating Custom Exceptions

## 1. What Is Raising an Exception?

In Python, the `raise` keyword is used to manually generate an exception when a specific condition occurs.

Instead of allowing invalid data to continue through a program, we can stop execution and report an appropriate error.

**Syntax:**

```python
raise ExceptionType("Error message")
```

**Example:**

```python
age = 15

if age < 18:
    raise ValueError("Age must be 18 or above")

print("Access granted")
```

**Output:**

```text
ValueError: Age must be 18 or above
```

The `print()` statement is not executed because the exception interrupts normal execution.

## 2. Raising Different Built-in Exceptions

Python provides several built-in exception types that we can raise.

### ValueError

Used when a value is inappropriate.

```python
age = -5

if age < 0:
    raise ValueError("Age cannot be negative")
```

### TypeError

Used when an operation receives an inappropriate type.

```python
name = 123

if not isinstance(name, str):
    raise TypeError("Name must be a string")
```

### ZeroDivisionError

Used when a division operation has a zero denominator.

```python
number = 0

if number == 0:
    raise ZeroDivisionError("Number cannot be zero")
```

### FileNotFoundError

Used when a required file cannot be found.

```python
import os

filename = "data.txt"

if not os.path.exists(filename):
    raise FileNotFoundError("Required file does not exist")
```

## 3. Raising an Exception Inside a Function

We can use `raise` inside functions to validate arguments.

```python
def calculate_square(number):
    if not isinstance(number, (int, float)):
        raise TypeError("Number must be numeric")

    return number ** 2

print(calculate_square(5))
```

**Output:**

```text
25
```

Invalid input:

```python
calculate_square("hello")
```

**Output:**

```text
TypeError: Number must be numeric
```

## 4. Handling a Raised Exception Using try and except

An exception raised using `raise` can be handled using `try` and `except`.

```python
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("Insufficient balance")

    return balance - amount

try:
    remaining = withdraw(5000, 6000)
    print("Remaining balance:", remaining)

except ValueError as error:
    print("Error:", error)
```

**Output:**

```text
Error: Insufficient balance
```

The function raises an exception, and the calling code handles it.

## 5. Re-raising an Exception

Sometimes we want to catch an exception temporarily, perform an action, and then raise the same exception again.

We can use `raise` without specifying an exception inside an `except` block.

```python
try:
    number = int("abc")

except ValueError:
    print("An error occurred")
    raise
```

**Output:**

```text
An error occurred
ValueError: invalid literal for int() with base 10: 'abc'
```

The original exception is raised again.

## 6. What Are Custom Exceptions?

Custom exceptions are user-defined exception classes created to represent application-specific errors.

Python allows us to create custom exceptions by inheriting from the built-in `Exception` class.

**Syntax:**

```python
class CustomError(Exception):
    pass
```

Here:
- `class` defines a new class.
- `CustomError` is our custom exception name.
- `Exception` is the parent class.
- `pass` indicates that the class has no additional implementation yet.

## 7. Creating and Raising a Custom Exception

```python
class InvalidAgeError(Exception):
    pass

age = 15

try:
    if age < 18:
        raise InvalidAgeError("Age must be 18 or above")

    print("Access granted")

except InvalidAgeError as error:
    print("Error:", error)
```

**Output:**

```text
Error: Age must be 18 or above
```

We created our own exception and raised it when the age validation failed.

## 8. Creating Multiple Custom Exceptions

A program can have multiple custom exceptions for different situations.

```python
class InvalidAgeError(Exception):
    pass

class InvalidNameError(Exception):
    pass

try:
    name = ""
    age = 20

    if not name:
        raise InvalidNameError("Name cannot be empty")

    if age < 18:
        raise InvalidAgeError("Age must be 18 or above")

except InvalidNameError as error:
    print("Name Error:", error)

except InvalidAgeError as error:
    print("Age Error:", error)
```

**Output:**

```text
Name Error: Name cannot be empty
```

Only the first raised exception is handled because execution stops at that point.

## 9. Custom Exceptions with Constructors

We can define an `__init__()` method to store additional information in a custom exception.

```python
class InsufficientBalanceError(Exception):

    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount

        message = f"Available balance: {balance}, Withdrawal amount: {amount}"

        super().__init__(message)


try:
    balance = 3000
    amount = 5000

    if amount > balance:
        raise InsufficientBalanceError(balance, amount)

except InsufficientBalanceError as error:
    print(error)
    print("Balance:", error.balance)
    print("Requested:", error.amount)
```

**Output:**

```text
Available balance: 3000, Withdrawal amount: 5000
Balance: 3000
Requested: 5000
```

**Important:**

- `__init__()` initializes the custom exception.
- `self.balance` and `self.amount` store additional information.
- `super().__init__(message)` initializes the parent `Exception` class with the error message.

## 10. Creating a Custom Exception Hierarchy

Custom exceptions can inherit from another custom exception.

This helps organize related errors.

```python
class ApplicationError(Exception):
    pass


class LoginError(ApplicationError):
    pass


class PaymentError(ApplicationError):
    pass


try:
    raise LoginError("Invalid username or password")

except ApplicationError as error:
    print("Application Error:", error)
```

**Output:**

```text
Application Error: Invalid username or password
```

Because `LoginError` inherits from `ApplicationError`, the parent exception can catch it.

## 11. Real-World Example: Bank Account Validation

```python
class InsufficientBalanceError(Exception):
    pass


class InvalidAmountError(Exception):
    pass


def withdraw(balance, amount):

    if amount <= 0:
        raise InvalidAmountError("Withdrawal amount must be positive")

    if amount > balance:
        raise InsufficientBalanceError("Insufficient account balance")

    return balance - amount


try:
    balance = 10000
    amount = 12000

    remaining = withdraw(balance, amount)

    print("Remaining balance:", remaining)

except InvalidAmountError as error:
    print("Invalid Amount:", error)

except InsufficientBalanceError as error:
    print("Transaction Failed:", error)
```

**Output:**

```text
Transaction Failed: Insufficient account balance
```

## 12. Important Differences

| Concept | Purpose |
|---|---|
| `raise` | Manually generates an exception |
| Built-in exception | Uses Python's existing exception classes |
| Custom exception | Defines an application-specific exception |
| `Exception` | Common base class for most application-level exceptions |
| `super()` | Calls the parent class implementation |
| `raise` alone | Re-raises the currently handled exception |
