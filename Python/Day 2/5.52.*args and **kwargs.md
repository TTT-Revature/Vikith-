# Python \*args and \*\*kwargs

## 1. What Are \*args and \*\*kwargs?

Python allows functions to accept a variable number of arguments using:

- `*args` – Accepts multiple positional arguments.
- `**kwargs` – Accepts multiple keyword arguments.

They are useful when we don't know in advance how many arguments a function will receive.

## 2. Understanding \*args

`*args` allows a function to accept any number of positional arguments.

The arguments are collected into a **tuple**.

### Example

```python
def add(*args):
    print(args)

add(10, 20, 30, 40)
```

**Output:**

```text
(10, 20, 30, 40)
```

### Using \*args to Calculate a Sum

```python
def add(*args):
    total = 0

    for num in args:
        total += num

    return total

print(add(10, 20))
print(add(10, 20, 30))
print(add(10, 20, 30, 40))
```

**Output:**

```text
30
60
100
```

### Accessing Individual Arguments

Since `args` is a tuple, we can use indexing and iteration.

```python
def display(*args):
    print("First:", args[0])
    print("Second:", args[1])

display("Python", "Java", "SQL")
```

**Output:**

```text
First: Python
Second: Java
```

## 3. Understanding \*\*kwargs

`**kwargs` allows a function to accept any number of keyword arguments.

The arguments are collected into a **dictionary**.

### Example

```python
def display(**kwargs):
    print(kwargs)

display(name="Vikith", age=24, course="Python")
```

**Output:**

```text
{'name': 'Vikith', 'age': 24, 'course': 'Python'}
```

### Accessing Dictionary Values

```python
def student(**kwargs):
    print("Name:", kwargs["name"])
    print("Age:", kwargs["age"])
    print("Course:", kwargs["course"])

student(name="Vikith", age=24, course="Python")
```

**Output:**

```text
Name: Vikith
Age: 24
Course: Python
```

### Iterating Through \*\*kwargs

```python
def student(**kwargs):
    for key, value in kwargs.items():
        print(key, ":", value)

student(name="Vikith", age=24, course="Python")
```

**Output:**

```text
name : Vikith
age : 24
course : Python
```

## 4. Using \*args and \*\*kwargs Together

A function can use both to accept positional and keyword arguments.

```python
def display(*args, **kwargs):
    print("Positional:", args)
    print("Keyword:", kwargs)

display(10, 20, 30, name="Vikith", age=24)
```

**Output:**

```text
Positional: (10, 20, 30)
Keyword: {'name': 'Vikith', 'age': 24}
```

### Important Parameter Order

When defining a function, the general order is:

```python
def example(required, *args, **kwargs):
    pass
```

A keyword-only parameter can also appear after `*args`:

```python
def example(name, *args, role="Student", **kwargs):
    print(name)
    print(args)
    print(role)
    print(kwargs)

example("Vikith", 10, 20, role="Developer", age=24)
```

**Output:**

```text
Vikith
(10, 20)
Developer
{'age': 24}
```

## 5. Normal Arguments with \*args

We can combine regular parameters and `*args`.

```python
def calculate(operation, *numbers):
    if operation == "sum":
        return sum(numbers)

    elif operation == "max":
        return max(numbers)

print(calculate("sum", 10, 20, 30))
print(calculate("max", 10, 20, 30))
```

**Output:**

```text
60
30
```

## 6. Unpacking Arguments Using \* and \*\*

The same symbols can unpack an iterable or dictionary when calling a function.

### Unpacking with \*

The `*` operator unpacks an iterable into positional arguments.

```python
def add(a, b, c):
    print(a + b + c)

numbers = [10, 20, 30]

add(*numbers)
```

**Output:**

```text
60
```

This is equivalent to:

```python
add(10, 20, 30)
```

### Unpacking with \*\*

The `**` operator unpacks a dictionary into keyword arguments.

```python
def student(name, age):
    print(name, age)

data = {"name": "Vikith", "age": 24}

student(**data)
```

**Output:**

```text
Vikith 24
```

The dictionary keys must match the function's parameter names when using this approach.

## 7. Difference Between \*args and \*\*kwargs

| Feature        | \*args               | \*\*kwargs            |
| -------------- | -------------------- | --------------------- |
| Accepts        | Positional arguments | Keyword arguments     |
| Stores data in | Tuple                | Dictionary            |
| Access         | Indexing / iteration | Keys / iteration      |
| Example        | `func(10, 20)`       | `func(name="Vikith")` |

## 8. Important Points

- `args` and `kwargs` are conventional names. The `*` and `**` symbols provide the functionality.
- `*args` collects extra positional arguments into a tuple.
- `**kwargs` collects extra keyword arguments into a dictionary.
- Both can be used in the same function.
- Regular parameters must come before `*args`.
- `**kwargs` comes after other parameter types in a function definition.
- Use `*iterable` and `**mapping` to unpack arguments during a function call.
