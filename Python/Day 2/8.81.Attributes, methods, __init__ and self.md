# Python Attributes, Methods, __init__() and self

## 1. What Are Attributes?

Attributes are variables associated with a class or an object. They store information about an object.

There are two main types:

1. Class attributes
2. Instance attributes

### Class Attributes

Class attributes are defined inside the class but outside its methods.

They are shared through the class and its instances unless overridden by an instance attribute.

```python
class Student:
    college = "MIT Manipal"
    course = "MCA"


student1 = Student()
student2 = Student()

print(student1.college)
print(student2.college)
print(Student.college)
```

**Output:**

```text
MIT Manipal
MIT Manipal
MIT Manipal
```

All three accesses refer to the same class attribute.

### Instance Attributes

Instance attributes belong to individual objects.

They are commonly created using `self`.

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age


student1 = Student("Vikith", 22)
student2 = Student("Rahul", 23)

print(student1.name)
print(student2.name)
```

**Output:**

```text
Vikith
Rahul
```

Each object has its own `name` and `age`.

### Difference Between Class and Instance Attributes

| Class Attributes | Instance Attributes |
|---|---|
| Defined in the class body | Usually defined using `self` |
| Shared through the class | Belong to individual objects |
| Can be accessed using class or instance | Accessed using the instance |
| Changes to the class attribute affect instances that haven't overridden it | Changes affect the particular instance |

## 2. What Are Methods?

Methods are functions defined inside a class.

They represent the actions or behaviors that objects can perform.

**Example:**

```python
class Student:
    def display(self):
        print("Welcome to Python OOP")


student1 = Student()

student1.display()
```

**Output:**

```text
Welcome to Python OOP
```

Here:
- `Student` is the class.
- `display()` is an instance method.
- `student1` is the object.
- `self` refers to the current object.

### Types of Methods

Python commonly uses three types of methods:

1. Instance methods
2. Class methods
3. Static methods

### Instance Method

An instance method works with the data of a particular object.

It receives `self` as its first parameter.

```python
class Student:
    def __init__(self, name):
        self.name = name

    def display(self):
        print("Name:", self.name)


student1 = Student("Vikith")

student1.display()
```

**Output:**

```text
Name: Vikith
```

### Class Method

A class method works with class-level data.

It uses the `@classmethod` decorator and receives `cls` as its first parameter.

```python
class Student:
    college = "MIT Manipal"

    @classmethod
    def change_college(cls, name):
        cls.college = name


Student.change_college("IIT Madras")

print(Student.college)
```

**Output:**

```text
IIT Madras
```

### Static Method

A static method does not automatically receive `self` or `cls`.

It uses the `@staticmethod` decorator.

```python
class Calculator:

    @staticmethod
    def add(a, b):
        return a + b


print(Calculator.add(10, 20))
```

**Output:**

```text
30
```

## 3. What Is __init__()?

`__init__()` is a special method that Python automatically calls when a new object is initialized.

It is commonly used to assign initial values to instance attributes.

**Syntax:**

```python
class ClassName:

    def __init__(self, parameters):
        self.attribute = parameters
```

**Example:**

```python
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age


student1 = Student("Vikith", 22)

print(student1.name)
print(student1.age)
```

**Output:**

```text
Vikith
22
```

### How Does __init__() Work?

Consider:

```python
student1 = Student("Vikith", 22)
```

Python performs these operations conceptually:

1. Creates a new object.
2. Calls `__init__()` to initialize that object.
3. Passes the object as `self`.
4. Passes `"Vikith"` as `name`.
5. Passes `22` as `age`.
6. Assigns the values to the object's attributes.

Conceptually, the initialization call behaves like:

```python
Student.__init__(student1, "Vikith", 22)
```

This is an explanation of the initialization step; normal object creation also involves `__new__()`.

### __init__() Without Parameters

We can also define an initializer without additional parameters.

```python
class Student:

    def __init__(self):
        self.name = "Vikith"
        self.age = 22


student1 = Student()

print(student1.name)
print(student1.age)
```

**Output:**

```text
Vikith
22
```

### __init__() With Default Parameters

We can provide default values to initializer parameters.

```python
class Student:

    def __init__(self, name, age=22):
        self.name = name
        self.age = age


student1 = Student("Vikith")
student2 = Student("Rahul", 23)

print(student1.name, student1.age)
print(student2.name, student2.age)
```

**Output:**

```text
Vikith 22
Rahul 23
```

## 4. What Is self?

`self` refers to the current object.

It allows instance methods to access and modify the attributes and other methods of that object.

**Example:**

```python
class Student:

    def __init__(self, name):
        self.name = name

    def display(self):
        print(self.name)


student1 = Student("Vikith")
student2 = Student("Rahul")

student1.display()
student2.display()
```

**Output:**

```text
Vikith
Rahul
```

When `student1.display()` is called, `self` refers to `student1`.

When `student2.display()` is called, `self` refers to `student2`.

### Is self a Keyword?

No. `self` is not a reserved Python keyword.

It is a widely followed naming convention.

Technically, we could use another name, but using `self` makes code consistent and readable.

### How Does self Work Internally?

Consider:

```python
class Student:

    def display(self):
        print("Hello")


student1 = Student()

student1.display()
```

Python automatically passes the object as the first argument.

The method call:

```python
student1.display()
```

Is equivalent to:

```python
Student.display(student1)
```

This is why instance methods normally define `self` as their first parameter.

## 5. Difference Between self.name and name

This is an important concept.

```python
class Student:

    def __init__(self, name):
        self.name = name


student1 = Student("Vikith")
```

Here:

- `name` is a local parameter received by `__init__()`.
- `self.name` is an attribute stored on the current object.

Think of it like this:

```text
name       → "Vikith" (parameter)
self.name  → "Vikith" (object attribute)
```

The assignment:

```python
self.name = name
```

Stores the parameter value in the object's attribute.

If we write only:

```python
name = name
```

It does not create an instance attribute.

## 6. Modifying Attributes Using self

Methods can modify the attributes of the current object.

```python
class Employee:

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def increase_salary(self, amount):
        self.salary += amount


emp1 = Employee("Vikith", 30000)

print(emp1.salary)

emp1.increase_salary(5000)

print(emp1.salary)
```

**Output:**

```text
30000
35000
```

The method modifies the salary belonging to `emp1`.

## 7. Accessing One Method From Another Method

We can call one instance method from another using `self`.

```python
class Calculator:

    def add(self, a, b):
        return a + b

    def display_result(self):
        result = self.add(10, 20)
        print("Result:", result)


calc = Calculator()

calc.display_result()
```

**Output:**

```text
Result: 30
```

Here, `self.add()` calls the `add()` method using the current object.

## 8. Multiple Objects and Separate Instance Data

Each object gets its own instance attributes.

```python
class Student:

    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def display(self):
        print(self.name, self.marks)


student1 = Student("Vikith", 90)
student2 = Student("Rahul", 85)
student3 = Student("Arun", 95)

student1.display()
student2.display()
student3.display()
```

**Output:**

```text
Vikith 90
Rahul 85
Arun 95
```

Conceptually:

```text
Student Class
     |
     |------ student1
     |          name = Vikith
     |          marks = 90
     |
     |------ student2
     |          name = Rahul
     |          marks = 85
     |
     |------ student3
                name = Arun
                marks = 95
```

Each object maintains its own instance data.

## 9. Important Differences

| Concept | Description |
|---|---|
| Attribute | Variable associated with a class or object |
| Method | Function defined inside a class |
| `__init__()` | Initializes a newly created object |
| `self` | Refers to the current instance |
| `cls` | Convention for the class reference in class methods |
| Class attribute | Data defined at class level |
| Instance attribute | Data stored on an individual object |

## 10. Real-World Example: Bank Account

```python
class BankAccount:

    bank_name = "Indian Bank"

    def __init__(self, account_holder, balance):
        self.account_holder = account_holder
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        print("Deposited:", amount)

    def withdraw(self, amount):
        if amount <= self.balance:
            self.balance -= amount
            print("Withdrawn:", amount)
        else:
            print("Insufficient balance")

    def display_balance(self):
        print("Account Holder:", self.account_holder)
        print("Bank:", self.bank_name)
        print("Balance:", self.balance)


account1 = BankAccount("Vikith", 10000)

account1.deposit(2000)
account1.withdraw(3000)
account1.display_balance()
```

**Output:**

```text
Deposited: 2000
Withdrawn: 3000
Account Holder: Vikith
Bank: Indian Bank
Balance: 9000
```
