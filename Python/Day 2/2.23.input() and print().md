# Input and Output in Python

Python uses `input()` to receive data from the user and `print()` to display output.

## 1. `print()` Function

The `print()` function displays information on the screen.

```python
print("Hello World")
print(100)
print(10 + 20)
```

**Output:**

```text
Hello World
100
30
```

### Printing Multiple Values

```python
name = "John"
age = 25

print(name, age)
```

**Output:**

```text
John 25
```

### `sep` Parameter

The `sep` parameter specifies the separator between multiple values.

```python
print("Python", "Java", "C++", sep=" | ")
```

**Output:**

```text
Python | Java | C++
```

### `end` Parameter

By default, `print()` adds a newline after displaying output.

The `end` parameter changes what is printed at the end.

```python
print("Hello", end=" ")
print("World")
```

**Output:**

```text
Hello World
```

### Escape Characters

```python
print("Hello\nWorld")
print("Python\tProgramming")
print("He said \"Hello\"")
```

**Output:**

```text
Hello
World
Python    Programming
He said "Hello"
```

- `\n` – New line
- `\t` – Tab space
- `\"` – Double quote
- `\\` – Backslash

## 2. `input()` Function

The `input()` function receives data from the user.

```python
name = input("Enter your name: ")
print("Hello", name)
```

**Example:**

```text
Enter your name: John
Hello John
```

### Important: `input()` Returns a String

Even if the user enters a number, `input()` returns it as a string.

```python
age = input("Enter your age: ")

print(type(age))
```

**Example output:**

```text
Enter your age: 25
<class 'str'>
```

### Converting Input into Other Data Types

Use type conversion when you need numeric input.

**Integer input:**

```python
age = int(input("Enter your age: "))
print(age + 5)
```

**Float input:**

```python
price = float(input("Enter price: "))
print(price)
```

**Example:**

```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print("Sum:", a + b)
```

**Example output:**

```text
Enter first number: 10
Enter second number: 20
Sum: 30
```

## 3. Taking Multiple Inputs

### Using `split()`

```python
a, b = input("Enter two numbers: ").split()

print(a)
print(b)
```

If the user enters `10 20`, both values are strings.

### Using `map()` with `int()`

```python
a, b = map(int, input("Enter two numbers: ").split())

print(a + b)
```

**Example output:**

```text
Enter two numbers: 10 20
30
```

## 4. Important Differences

| Function / Parameter | Purpose                             |
| -------------------- | ----------------------------------- |
| `print()`            | Displays output                     |
| `input()`            | Receives user input                 |
| `sep`                | Separates multiple printed values   |
| `end`                | Controls what is printed at the end |
| `split()`            | Splits a string into parts          |
| `map()`              | Applies a function to each item     |
