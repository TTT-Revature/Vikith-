# Python Creating and Importing Modules

## 1. What Is a Module?

A module is a Python file (`.py`) containing reusable code such as:

- Variables
- Functions
- Classes
- Statements

Modules help organize code into separate files and reuse functionality across projects.

For example, a file named `calculator.py` is a Python module.

## 2. Creating a Module

Let's create a module called `calculator.py`.

**File: `calculator.py`**

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

pi = 3.14159
```

This module contains three functions and one variable.

## 3. Importing a Module

Use the `import` keyword to import a module into another Python file.

**File: `main.py`**

```python
import calculator

print(calculator.add(10, 20))
print(calculator.subtract(20, 5))
print(calculator.multiply(5, 4))
print(calculator.pi)
```

**Output:**

```text
30
15
20
3.14159
```

To access members of a module, use the dot (`.`) operator.

**Syntax:**

```python
module_name.function_name()
module_name.variable_name
```

## 4. Importing Specific Functions

Instead of importing the entire module, we can import only the functions or variables we need.

```python
from calculator import add, subtract

print(add(10, 20))
print(subtract(20, 5))
```

**Output:**

```text
30
15
```

We can access imported functions directly without using the module name.

## 5. Importing Everything Using \*

We can import all public names from a module using `*`.

```python
from calculator import *

print(add(10, 20))
print(multiply(5, 4))
print(pi)
```

**Output:**

```text
30
20
3.14159
```

However, this approach is generally discouraged because it can cause naming conflicts and make it unclear where names came from.

## 6. Using Aliases with as

We can give a module or imported function a shorter name using `as`.

### Module Alias

```python
import calculator as calc

print(calc.add(10, 20))
```

**Output:**

```text
30
```

### Function Alias

```python
from calculator import multiply as mul

print(mul(5, 4))
```

**Output:**

```text
20
```

Aliases are useful when module or function names are long.

## 7. Importing Built-in Modules

Python provides many built-in modules that can be imported without installing additional packages.

### Example: math Module

```python
import math

print(math.sqrt(25))
print(math.factorial(5))
print(math.pi)
```

**Output:**

```text
5.0
120
3.141592653589793
```

### Example: random Module

```python
import random

print(random.randint(1, 10))
```

**Possible Output:**

```text
7
```

The output can change because the number is generated randomly.

### Example: datetime Module

```python
import datetime

today = datetime.date.today()

print(today)
```

**Possible Output:**

```text
2026-11-17
```

The date depends on the system date.

## 8. Understanding **name** and **main**

Python provides a special variable called `__name__`.

- When a Python file runs directly, its `__name__` value is `"__main__"`.
- When the file is imported as a module, its `__name__` value is usually the module's name.

### Example

**File: `calculator.py`**

```python
def add(a, b):
    return a + b

if __name__ == "__main__":
    print("Calculator module executed directly")
    print(add(10, 20))
```

**File: `main.py`**

```python
import calculator

print(calculator.add(5, 5))
```

If we execute `calculator.py` directly:

**Output:**

```text
Calculator module executed directly
30
```

If we execute `main.py`:

**Output:**

```text
10
```

The code inside the `if __name__ == "__main__":` block does not execute when `calculator.py` is imported.

This is useful for keeping testing or demonstration code separate from reusable module functionality.

## 9. Organizing Modules into Packages

A package is a way to organize related Python modules into directories.

Example project structure:

```text
project/
│
├── main.py
│
└── calculations/
    ├── __init__.py
    ├── addition.py
    └── subtraction.py
```

**File: `calculations/addition.py`**

```python
def add(a, b):
    return a + b
```

**File: `calculations/subtraction.py`**

```python
def subtract(a, b):
    return a - b
```

**File: `main.py`**

```python
from calculations.addition import add
from calculations.subtraction import subtract

print(add(10, 20))
print(subtract(20, 5))
```

**Output:**

```text
30
15
```

`__init__.py` is commonly used to mark a directory as a regular Python package and can also contain package initialization code. Modern Python also supports namespace packages without this file.
