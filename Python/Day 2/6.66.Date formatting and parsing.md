

# Python datetime, date, time and timedelta

## 1. Introduction to datetime

Python provides a built-in module called `datetime` to work with dates, times, and time differences.

It is commonly used in:
- Scheduling applications
- Attendance systems
- Employee management
- Booking systems
- Logging events
- Calculating deadlines and durations

### Importing datetime

```python
import datetime
```

We can also import individual classes:

```python
from datetime import datetime, date, time, timedelta
```

The `datetime` module provides four important classes:

| Class | Purpose |
|---|---|
| `datetime` | Works with both date and time |
| `date` | Works with dates only |
| `time` | Works with time only |
| `timedelta` | Represents a duration or difference between dates and times |

## 2. datetime Class

The `datetime` class represents both date and time.

It stores:
- Year
- Month
- Day
- Hour
- Minute
- Second
- Microsecond

### Getting the Current Date and Time

Use `datetime.now()` to get the current local date and time.

```python
from datetime import datetime

current = datetime.now()

print(current)
print(type(current))
```

**Possible Output:**

```text
2026-11-17 16:30:45.123456
<class 'datetime.datetime'>
```

The output depends on the current system date and time.

### Creating a Custom datetime Object

```python
from datetime import datetime

dt = datetime(2026, 11, 17, 10, 30, 45)

print(dt)
```

**Output:**

```text
2026-11-17 10:30:45
```

Syntax:

```python
datetime(year, month, day, hour, minute, second)
```

### Accessing datetime Attributes

```python
from datetime import datetime

dt = datetime(2026, 11, 17, 10, 30, 45)

print(dt.year)
print(dt.month)
print(dt.day)
print(dt.hour)
print(dt.minute)
print(dt.second)
```

**Output:**

```text
2026
11
17
10
30
45
```

### Getting Current Date and Time Separately

```python
from datetime import datetime

current = datetime.now()

print("Date:", current.date())
print("Time:", current.time())
```

**Possible Output:**

```text
Date: 2026-11-17
Time: 16:30:45.123456
```

## 3. date Class

The `date` class represents a date without storing time information.

It stores:
- Year
- Month
- Day

### Getting Today's Date

Use `date.today()`.

```python
from datetime import date

today = date.today()

print(today)
print(type(today))
```

**Possible Output:**

```text
2026-11-17
<class 'datetime.date'>
```

### Creating a Custom Date

```python
from datetime import date

birthday = date(2002, 5, 15)

print(birthday)
```

**Output:**

```text
2002-05-15
```

### Accessing Date Attributes

```python
from datetime import date

today = date.today()

print(today.year)
print(today.month)
print(today.day)
```

**Possible Output:**

```text
2026
11
17
```

### Getting Weekday Information

Use `weekday()` to get the weekday number.

- Monday = 0
- Tuesday = 1
- Wednesday = 2
- Thursday = 3
- Friday = 4
- Saturday = 5
- Sunday = 6

```python
from datetime import date

d = date(2026, 11, 17)

print(d.weekday())
```

**Output:**

```text
1
```

The date is a Tuesday.

Use `isoweekday()` for a different numbering system:

- Monday = 1
- Sunday = 7

```python
print(d.isoweekday())
```

**Output:**

```text
2
```

## 4. time Class

The `time` class represents time without storing a date.

It stores:
- Hour
- Minute
- Second
- Microsecond

### Creating a Time Object

```python
from datetime import time

t = time(10, 30, 45)

print(t)
print(type(t))
```

**Output:**

```text
10:30:45
<class 'datetime.time'>
```

### Accessing Time Attributes

```python
from datetime import time

t = time(14, 25, 30)

print(t.hour)
print(t.minute)
print(t.second)
```

**Output:**

```text
14
25
30
```

```python
from datetime import time

t = time(10, 30, 45, 500000)
```


## 5. timedelta Class

The `timedelta` class represents a duration or difference between two dates or times.

It can represent:
- Days
- Seconds
- Microseconds

It also accepts convenient arguments such as weeks, hours, minutes, and milliseconds.

### Creating a timedelta Object

```python
from datetime import timedelta

duration = timedelta(days=5)

print(duration)
```

**Output:**

```text
5 days, 0:00:00
```

### Using Multiple Time Units

```python
from datetime import timedelta

duration = timedelta(
    days=2,
    hours=5,
    minutes=30
)

print(duration)
```

**Output:**

```text
2 days, 5:30:00
```

### Adding Days to a Date

```python
from datetime import date, timedelta

today = date(2026, 11, 17)

future = today + timedelta(days=10)

print(future)
```

**Output:**

```text
2026-11-27
```

### Subtracting Days from a Date

```python
from datetime import date, timedelta

today = date(2026, 11, 17)

previous = today - timedelta(days=5)

print(previous)
```

**Output:**

```text
2026-11-12
```

### Calculating the Difference Between Two Dates

Subtracting two date objects returns a `timedelta` object.

```python
from datetime import date

start = date(2026, 11, 1)
end = date(2026, 11, 17)

difference = end - start

print(difference)
print(difference.days)
```

**Output:**

```text
16 days, 0:00:00
16
```

### Adding Hours and Minutes to datetime

```python
from datetime import datetime, timedelta

start = datetime(2026, 11, 17, 10, 0)

end = start + timedelta(hours=3, minutes=30)

print(end)
```

**Output:**

```text
2026-11-17 13:30:00
```

## 6. Comparing Dates and Times

Python allows us to compare date and datetime objects of the same kind.

```python
from datetime import date

date1 = date(2026, 11, 17)
date2 = date(2026, 12, 17)

print(date1 < date2)
print(date1 == date2)
print(date1 > date2)
```

**Output:**

```text
True
False
False
```

Comparison operators:
- `==` Equal to
- `!=` Not equal to
- `<` Less than
- `>` Greater than
- `<=` Less than or equal to
- `>=` Greater than or equal to

## 7. Formatting Dates and Times Using strftime()

`strftime()` converts a date or datetime object into a formatted string.

```python
from datetime import datetime

now = datetime(2026, 11, 17, 14, 30, 45)

formatted = now.strftime("%d-%m-%Y")

print(formatted)
```

**Output:**

```text
17-11-2026
```

### Common strftime() Directives

| Directive | Meaning | Example |
|---|---|---|
| `%Y` | Four-digit year | `2026` |
| `%y` | Two-digit year | `26` |
| `%m` | Month number | `11` |
| `%B` | Full month name | `November` |
| `%b` | Short month name | `Nov` |
| `%d` | Day of month | `17` |
| `%A` | Full weekday name | `Tuesday` |
| `%a` | Short weekday name | `Tue` |
| `%H` | Hour (24-hour format) | `14` |
| `%I` | Hour (12-hour format) | `02` |
| `%M` | Minute | `30` |
| `%S` | Second | `45` |
| `%p` | AM or PM | `PM` |

### Example: Formatting Date and Time

```python
from datetime import datetime

now = datetime(2026, 11, 17, 14, 30, 45)

print(now.strftime("%d/%m/%Y"))
print(now.strftime("%I:%M %p"))
print(now.strftime("%A, %B %d, %Y"))
```

**Output:**

```text
17/11/2026
02:30 PM
Tuesday, November 17, 2026
```

## 8. Converting Strings into Dates Using strptime()

`strptime()` converts a formatted string into a datetime object.

**String → datetime object**

```python
from datetime import datetime

date_string = "17-11-2026"

result = datetime.strptime(date_string, "%d-%m-%Y")

print(result)
print(type(result))
```

**Output:**

```text
2026-11-17 00:00:00
<class 'datetime.datetime'>
```

### Example with Date and Time

```python
from datetime import datetime

date_string = "17-11-2026 02:30 PM"

result = datetime.strptime(
    date_string,
    "%d-%m-%Y %I:%M %p"
)

print(result)
```

**Output:**

```text
2026-11-17 14:30:00
```

**Important Difference:**

| Method | Purpose |
|---|---|
| `strftime()` | datetime object → string |
| `strptime()` | string → datetime object |

## 9. ISO Format: isoformat() and fromisoformat()

ISO 8601 is a standard format for representing dates and times.

A common format is:

```text
YYYY-MM-DDTHH:MM:SS
```

### isoformat()

Converts a datetime object into an ISO-formatted string.

```python
from datetime import datetime

dt = datetime(2026, 11, 17, 14, 30)

print(dt.isoformat())
```

**Output:**

```text
2026-11-17T14:30:00
```

### fromisoformat()

Converts an ISO-formatted string into a datetime object.

```python
from datetime import datetime

value = "2026-11-17T14:30:00"

dt = datetime.fromisoformat(value)

print(dt)
```

**Output:**

```text
2026-11-17 14:30:00
```

## 10. Useful timedelta Attributes

A `timedelta` object provides three normalized attributes.

```python
from datetime import timedelta

duration = timedelta(days=2, hours=5, minutes=30)

print(duration.days)
print(duration.seconds)
print(duration.microseconds)
```

**Output:**

```text
2
19800
0
```

`seconds` contains the remaining seconds after complete days are separated. It does not represent the total duration in seconds.

### total_seconds()

Use `total_seconds()` to get the complete duration in seconds.

```python
from datetime import timedelta

duration = timedelta(days=2, hours=5, minutes=30)

print(duration.total_seconds())
```

**Output:**

```text
192600.0
```

## 11. Real-World Example: Calculating Employee Work Duration

```python
from datetime import datetime

login_time = datetime(2026, 11, 17, 9, 30)
logout_time = datetime(2026, 11, 17, 18, 0)

duration = logout_time - login_time

print("Login:", login_time.strftime("%I:%M %p"))
print("Logout:", logout_time.strftime("%I:%M %p"))
print("Working Duration:", duration)
print("Total Hours:", duration.total_seconds() / 3600)
```

**Output:**

```text
Login: 09:30 AM
Logout: 06:00 PM
Working Duration: 8:30:00
Total Hours: 8.5
```

## 12. Important Points

- `datetime` handles both date and time.
- `date` handles only year, month, and day.
- `time` handles only hour, minute, second, and microsecond.
- `timedelta` represents a duration or difference.
- `datetime.now()` returns the current local date and time.
- `date.today()` returns today's date.
- `strftime()` converts date/time objects into strings.
- `strptime()` converts formatted strings into datetime objects.
- `isoformat()` produces an ISO-formatted string.
- `fromisoformat()` parses an ISO-formatted string.
- Subtracting two dates or datetimes produces a `timedelta`.
- `total_seconds()` returns the complete duration in seconds.
