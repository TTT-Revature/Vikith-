

# Python Iterable vs Iterator

## 1. What Is an Iterable?

An **iterable** is an object that can be looped over using a `for` loop.

An iterable provides a way to access its elements one at a time.

Common examples:
- List
- Tuple
- String
- Set
- Dictionary
- Range

### Example

```python
numbers = [10, 20, 30, 40]

for number in numbers:
    print(number)
```

**Output:**

```text
10
20
30
40
```

Here, `numbers` is an iterable because we can loop through its elements.

## 2. What Is an Iterator?

An **iterator** is an object that allows us to access elements one at a time using `next()`.

An iterator maintains its current position while iterating.

We can create an iterator from an iterable using `iter()`.

### Example

```python
numbers = [10, 20, 30, 40]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

**Output:**

```text
10
20
30
```

Here:
- `iter()` converts the list into an iterator.
- `next()` retrieves the next element.
- The iterator remembers its current position.

## 3. Understanding iter() and next()

Python provides two important built-in functions for iteration.

### iter()

Returns an iterator from an iterable.

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(type(numbers))
print(type(iterator))
```

**Output:**

```text
<class 'list'>
<class 'list_iterator'>
```

### next()

Returns the next element from an iterator.

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

**Output:**

```text
10
20
30
```

### What Happens When Elements Are Finished?

When an iterator has no more elements, calling `next()` raises `StopIteration`.

```python
numbers = [10, 20]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

**Output:**

```text
10
20
Traceback (most recent call last):
    ...
StopIteration
```

`StopIteration` indicates that the iterator has no more elements.

## 4. Iterable vs Iterator

| Feature | Iterable | Iterator |
|---|---|---|
| Meaning | Object that can be iterated over | Object that produces elements one at a time |
| Function | `iter()` | `next()` |
| Maintains iteration state | Not necessarily | Yes |
| Can be used in a for loop | Yes | Yes |
| Can provide an iterator | Yes, through `iter()` | Yes, an iterator returns itself |
| Examples | List, tuple, string, set | `list_iterator`, `tuple_iterator` |

**Important:** Every iterator is also an iterable, but not every iterable is an iterator.

## 5. Understanding the Difference with an Example

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))

print("Remaining elements:")

for number in iterator:
    print(number)
```

**Output:**

```text
10
20
Remaining elements:
30
```

Notice that the iterator does not restart from the beginning.

It continues from its current position.

## 6. Creating a Custom Iterator

We can create our own iterator using a Python class.

A custom iterator must implement two methods:

- `__iter__()` returns the iterator object.
- `__next__()` returns the next value or raises `StopIteration` when finished.

### Example

```python
class NumberIterator:

    def __init__(self, limit):
        self.current = 1
        self.limit = limit

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= self.limit:
            value = self.current
            self.current += 1
            return value

        raise StopIteration


numbers = NumberIterator(3)

for number in numbers:
    print(number)
```

**Output:**

```text
1
2
3
```

### How It Works

1. `NumberIterator(3)` creates an iterator object.
2. The `for` loop calls `iter()` internally.
3. `__iter__()` returns the iterator itself.
4. The loop repeatedly calls `next()`.
5. `__next__()` returns the next number.
6. Once the limit is exceeded, `StopIteration` ends the loop.

## 7. How Does a for Loop Work Internally?

A `for` loop internally uses the iterator protocol.

Consider:

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

Conceptually, it works like this:

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

while True:
    try:
        number = next(iterator)
        print(number)

    except StopIteration:
        break
```

Both examples produce:

```text
10
20
30
```

This shows that Python uses `iter()` and `next()` internally when executing a `for` loop.

## 8. Reusing an Iterable vs an Iterator

An iterable can generally create a fresh iterator whenever `iter()` is called.

An iterator continues from its current position.

### Example: Iterable

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)

for number in numbers:
    print(number)
```

**Output:**

```text
10
20
30
10
20
30
```

### Example: Iterator

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))

for number in iterator:
    print(number)
```

**Output:**

```text
10
20
30
```

The iterator continues from where it stopped.
