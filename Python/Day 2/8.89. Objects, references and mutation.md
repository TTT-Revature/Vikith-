

# Python Objects, References and Mutation

## 1. Everything in Python Is an Object

In Python, almost everything is an object, including:
- Integers
- Strings
- Lists
- Tuples
- Dictionaries
- Functions
- Classes

Every object has three important characteristics:

| Characteristic | Meaning |
|---|---|
| Identity | Identifies an object in memory |
| Type | Defines what kind of object it is |
| Value | The data stored in the object |

Example:

```python
number = 100

print(type(number))
print(id(number))
print(number)
```

**Output:**
```text
<class 'int'>
140...
100
```

`id()` returns an object's identity. In CPython, it is typically related to its memory address, but this is an implementation detail.

## 2. Variables Are References to Objects

In Python, variables do not directly contain objects. They refer to objects.

```python
a = [10, 20, 30]

print(a)
```

Here:
- A list object is created.
- The variable `a` refers to that object.
- The variable stores a reference, not the list itself.

### Assigning One Variable to Another

```python
a = [10, 20, 30]

b = a

print(a)
print(b)
print(a is b)
```

**Output:**
```text
[10, 20, 30]
[10, 20, 30]
True
```

Both variables refer to the same list object.

Conceptually:

```text
a ─────┐
       ├────> [10, 20, 30]
b ─────┘
```

## 3. Object Identity Using `id()`

The `id()` function returns the identity of an object.

```python
a = [10, 20, 30]
b = a

print(id(a))
print(id(b))
print(id(a) == id(b))
```

**Output:**
```text
Same identity value
Same identity value
True
```

Both variables refer to the same object, so their identities are equal.

## 4. Difference Between `==` and `is`

These operators are different.

| Operator | Meaning |
|---|---|
| `==` | Compares values for equality |
| `is` | Checks whether two references point to the same object |

Example:

```python
a = [10, 20, 30]
b = [10, 20, 30]

print(a == b)
print(a is b)
```

**Output:**
```text
True
False
```

Explanation:
- Both lists contain the same values.
- They are two separate list objects.
- Therefore, `==` returns `True`, but `is` returns `False`.

## 5. What Is Mutation?

Mutation means changing an existing object's value or contents without creating a different object.

Objects that allow their contents or state to be changed are called **mutable objects**.

Examples:
- List
- Dictionary
- Set
- Bytearray

### Example: Mutating a List

```python
numbers = [10, 20, 30]

print(id(numbers))

numbers.append(40)

print(numbers)
print(id(numbers))
```

**Output:**
```text
Same identity value
[10, 20, 30, 40]
Same identity value
```

The list contents changed, but the object identity remained the same.

## 6. Mutable Objects and Shared References

When two variables refer to the same mutable object, a change through either variable is visible through both.

```python
a = [10, 20, 30]

b = a

b.append(40)

print(a)
print(b)
```

**Output:**
```text
[10, 20, 30, 40]
[10, 20, 30, 40]
```

Why?

Because `a` and `b` refer to the same list object.

## 7. Immutable Objects

Immutable objects cannot be changed after creation.

Examples:
- Integer
- Float
- Boolean
- String
- Tuple
- Frozenset
- Bytes

### Example: Integer Assignment

```python
a = 10

print(id(a))

a = a + 5

print(a)
print(id(a))
```

**Output:**
```text
Identity of original integer
15
Identity of resulting integer
```

The integer object `10` is not modified. The expression creates or obtains an integer object representing `15`, and `a` is rebound to it.

### Example: String

```python
name = "Python"

# name[0] = "J"  # TypeError

name = "Java"

print(name)
```

**Output:**
```text
Java
```

The original string was not modified. The variable was assigned a reference to another string object.

## 8. Mutable vs Immutable Objects

| Mutable | Immutable |
|---|---|
| Can change after creation | Cannot change after creation |
| Same object can be modified | Changes require another object or value |
| List | Integer |
| Dictionary | String |
| Set | Tuple |
| Bytearray | Float |
| | Boolean |

**Important:** A tuple is immutable, but it can contain mutable objects.

```python
data = ([10, 20], 30)

data[0].append(40)

print(data)
```

**Output:**
```text
([10, 20, 40], 30)
```

The tuple structure remains unchanged, but the list inside it is mutable.

## 9. Reassignment vs Mutation

These are two different operations.

### Reassignment

```python
a = [10, 20, 30]
b = a

a = [100, 200]

print(a)
print(b)
```

**Output:**
```text
[100, 200]
[10, 20, 30]
```

Reassignment makes `a` refer to a new list. It does not change the original list referenced by `b`.

### Mutation

```python
a = [10, 20, 30]
b = a

a.append(40)

print(a)
print(b)
```

**Output:**
```text
[10, 20, 30, 40]
[10, 20, 30, 40]
```

Mutation changes the shared list object, so both references observe the change.

## 10. Passing Objects to Functions

Python passes object references to functions. This behavior is often described as **call by object sharing**.

### Example: Mutating an Object Inside a Function

```python
def add_item(items):
    items.append(40)


numbers = [10, 20, 30]

add_item(numbers)

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40]
```

The function receives a reference to the same list and modifies it.

### Example: Reassigning a Parameter

```python
def change_list(items):
    items = [100, 200, 300]


numbers = [10, 20, 30]

change_list(numbers)

print(numbers)
```

**Output:**
```text
[10, 20, 30]
```

The parameter `items` is reassigned locally. The original variable `numbers` still refers to its original list.

## 11. Object References Inside Lists

A list can store references to other objects.

```python
a = [10, 20]
b = [30, 40]

data = [a, b]

data[0].append(50)

print(data)
print(a)
```

**Output:**
```text
[[10, 20, 50], [30, 40]]
[10, 20, 50]
```

The first element of `data` refers to the same list as `a`.

## 12. Shallow Copy and Deep Copy

Copying an object creates another object, but the type of copy matters.

### Shallow Copy

A shallow copy creates a new outer object but keeps references to the original nested objects.

```python
import copy

original = [[10, 20], [30, 40]]

copied = copy.copy(original)

copied.append([50, 60])
copied[0].append(100)

print(original)
print(copied)
```

**Output:**
```text
[[10, 20, 100], [30, 40]]
[[10, 20, 100], [30, 40], [50, 60]]
```

The outer lists are different, but their nested lists are shared.

### Deep Copy

A deep copy recursively copies nested objects.

```python
import copy

original = [[10, 20], [30, 40]]

copied = copy.deepcopy(original)

copied[0].append(100)

print(original)
print(copied)
```

**Output:**
```text
[[10, 20], [30, 40]]
[[10, 20, 100], [30, 40]]
```

The nested lists are copied too, so changing the copied nested list does not affect the original.

## 13. Important Differences

| Concept | Meaning |
|---|---|
| Reference | A variable refers to an object |
| Identity | Identifies an object |
| Mutation | Changes an existing mutable object |
| Reassignment | Makes a variable refer to another object |
| Aliasing | Multiple variables refer to the same object |
| Shallow copy | Copies the outer object only |
| Deep copy | Recursively copies nested objects |

## 14. Real-World Use Cases

- **Shared data:** Multiple variables can access and update the same list or dictionary.
- **Function arguments:** Functions can modify mutable objects passed to them.
- **Data processing:** Copying records prevents accidental changes to original data.
- **Nested structures:** Understanding shallow and deep copies helps avoid unexpected changes.
- **Debugging:** `id()` and `is` help investigate object identity and shared references.
