# Tuples in Python

A tuple is an ordered collection used to store multiple values in a single variable.

Tuples are similar to lists, but they are **immutable**, meaning their elements cannot be changed after creation.

## 1. Creating Tuples

Tuples are generally created using parentheses `()`.

### Empty Tuple

```python
data = ()

print(data)
print(type(data))
```

**Output:**

```text
()
<class 'tuple'>
```

### Tuple with Elements

```python
numbers = (10, 20, 30, 40)

print(numbers)
```

**Output:**

```text
(10, 20, 30, 40)
```

### Tuple with Different Data Types

```python
student = ("John", 25, 85.5, True)

print(student)
```

**Output:**

```text
('John', 25, 85.5, True)
```

### Tuple Without Parentheses

Python also allows tuple creation without parentheses. This is called tuple packing.

```python
numbers = 10, 20, 30

print(numbers)
print(type(numbers))
```

**Output:**

```text
(10, 20, 30)
<class 'tuple'>
```

## 2. Single-Element Tuple

To create a tuple with only one element, you must include a trailing comma.

```python
value = (10,)

print(value)
print(type(value))
```

**Output:**

```text
(10,)
<class 'tuple'>
```

Without the comma, Python treats the expression as an ordinary value inside parentheses.

```python
value = (10)

print(value)
print(type(value))
```

**Output:**

```text
10
<class 'int'>
```

## 3. Accessing Tuple Elements

Tuples support indexing just like lists.

### Positive Indexing

Indexing starts from `0`.

```python
fruits = ("Apple", "Banana", "Mango", "Orange")

print(fruits[0])
print(fruits[2])
```

**Output:**

```text
Apple
Mango
```

### Negative Indexing

Negative indexing starts from `-1` and moves from right to left.

```python
fruits = ("Apple", "Banana", "Mango", "Orange")

print(fruits[-1])
print(fruits[-2])
```

**Output:**

```text
Orange
Mango
```

## 4. Tuple Slicing

Slicing extracts a portion of a tuple.

**Syntax:**

```python
tuple[start:stop:step]
```

- `start`: Starting index (included).
- `stop`: Ending index (excluded).
- `step`: Number of positions to move.

```python
numbers = (10, 20, 30, 40, 50, 60)

print(numbers[1:4])
print(numbers[:3])
print(numbers[2:])
print(numbers[::2])
```

**Output:**

```text
(20, 30, 40)
(10, 20, 30)
(30, 40, 50, 60)
(10, 30, 50)
```

### Reversing a Tuple Using Slicing

```python
numbers = (10, 20, 30, 40, 50)

print(numbers[::-1])
```

**Output:**

```text
(50, 40, 30, 20, 10)
```

## 5. Tuple Packing and Unpacking

### Tuple Packing

Packing means combining multiple values into a single tuple.

```python
student = "John", 25, 85.5

print(student)
```

**Output:**

```text
('John', 25, 85.5)
```

### Tuple Unpacking

Unpacking means assigning tuple elements to separate variables.

```python
student = ("John", 25, 85.5)

name, age, marks = student

print(name)
print(age)
print(marks)
```

**Output:**

```text
John
25
85.5
```

The number of variables must normally match the number of tuple elements.

### Using the * Operator in Unpacking

The `*` operator collects multiple remaining elements into a list.

```python
numbers = (10, 20, 30, 40, 50)

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

**Output:**

```text
10
[20, 30, 40]
50
```

## 6. Tuple Immutability

Tuples are immutable. You cannot directly add, remove, or replace their elements after creation.

```python
numbers = (10, 20, 30)

numbers[0] = 100

print(numbers)
```

**Output:**

```text
TypeError: 'tuple' object does not support item assignment
```

### But What About Mutable Objects Inside Tuples?

A tuple can contain mutable objects such as lists.

Although you cannot replace the list element in the tuple, you can modify the contents of that list.

```python
data = ([10, 20], 30)

data[0].append(100)

print(data)
```

**Output:**

```text
([10, 20, 100], 30)
```

The tuple itself remains unchanged in structure, but the mutable list stored inside it is modified.

## 7. Tuple Methods

Tuples have only two built-in methods because they are immutable.

### count()

Returns the number of times a value occurs.

```python
numbers = (10, 20, 10, 30, 10)

print(numbers.count(10))
```

**Output:**

```text
3
```

### index()

Returns the index of the first occurrence of a value.

```python
fruits = ("Apple", "Banana", "Mango")

print(fruits.index("Banana"))
```

**Output:**

```text
1
```

If the value does not exist, `index()` raises a `ValueError`.

## 8. Useful Built-in Functions

Tuples support several built-in Python functions.

### len()

Returns the number of elements.

```python
numbers = (10, 20, 30, 40)

print(len(numbers))
```

**Output:**

```text
4
```

### min()

Returns the smallest element.

```python
numbers = (40, 10, 30, 20)

print(min(numbers))
```

**Output:**

```text
10
```

### max()

Returns the largest element.

```python
numbers = (40, 10, 30, 20)

print(max(numbers))
```

**Output:**

```text
40
```

### sum()

Returns the sum of numeric elements.

```python
numbers = (10, 20, 30)

print(sum(numbers))
```

**Output:**

```text
60
```

### sorted()

Returns a new sorted list. It does not return a tuple.

```python
numbers = (40, 10, 30, 20)

result = sorted(numbers)

print(result)
print(type(result))
```

**Output:**

```text
[10, 20, 30, 40]
<class 'list'>
```

To get a sorted tuple, convert the result back into a tuple.

```python
numbers = (40, 10, 30, 20)

result = tuple(sorted(numbers))

print(result)
```

**Output:**

```text
(10, 20, 30, 40)
```

## 9. Joining and Repeating Tuples

### Concatenation (+)

Combines two or more tuples into a new tuple.

```python
first = (10, 20)
second = (30, 40)

result = first + second

print(result)
```

**Output:**

```text
(10, 20, 30, 40)
```

### Repetition (*)

Repeats the elements of a tuple.

```python
numbers = (10, 20)

result = numbers * 3

print(result)
```

**Output:**

```text
(10, 20, 10, 20, 10, 20)
```

## 10. Membership Operators

Use `in` and `not in` to check whether an element exists in a tuple.

```python
fruits = ("Apple", "Banana", "Mango")

print("Apple" in fruits)
print("Orange" not in fruits)
```

**Output:**

```text
True
True
```

## 11. List vs Tuple

| Feature | List | Tuple |
|---|---|---|
| Syntax | `[]` | `()` |
| Ordered | Yes | Yes |
| Mutable | Yes | No |
| Allows duplicates | Yes | Yes |
| Indexing | Supported | Supported |
| Slicing | Supported | Supported |
| Methods | Many methods | `count()`, `index()` |
| Nested collections | Supported | Supported |

## 12. Converting Between Lists and Tuples

### Tuple to List

Use `list()` to convert a tuple into a list.

```python
numbers = (10, 20, 30)

result = list(numbers)

print(result)
print(type(result))
```

**Output:**

```text
[10, 20, 30]
<class 'list'>
```

### List to Tuple

Use `tuple()` to convert a list into a tuple.

```python
numbers = [10, 20, 30]

result = tuple(numbers)

print(result)
print(type(result))
```

**Output:**

```text
(10, 20, 30)
<class 'tuple'>
```

## 13. Real-World Use Cases

- **Coordinates:** Store fixed positions such as `(latitude, longitude)`.
- **Database records:** Represent a row of values returned from a database query.
- **Student information:** Store fixed records such as `(name, age, marks)`.
- **Returning multiple values:** Return multiple results from a function using a tuple.
- **Dictionary keys:** Use tuples containing hashable elements as dictionary keys.
- **Configuration data:** Store fixed settings that should not be changed accidentally.
