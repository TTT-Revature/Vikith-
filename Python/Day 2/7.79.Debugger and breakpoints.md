# Python Debugger and Breakpoints

## 1. What Is a Debugger?

A debugger is a tool used to inspect and control program execution step by step.

It helps developers:
- Find logical errors.
- Inspect variable values.
- Understand function execution.
- Identify where a problem occurs.
- Pause and resume program execution.

Python provides a built-in debugger called `pdb`.

## 2. What Is a Breakpoint?

A breakpoint is a point in the program where execution pauses temporarily.

It allows us to inspect the program before continuing execution.

**Example without a breakpoint:**

```python
def calculate():
    a = 10
    b = 20
    result = a + b
    print(result)

calculate()
```

**Output:**

```text
30
```

**Example with a breakpoint:**

```python
def calculate():
    a = 10
    b = 20

    breakpoint()

    result = a + b
    print(result)

calculate()
```

When Python reaches `breakpoint()`, execution pauses and opens the debugger.

## 3. What Is pdb?

`pdb` stands for Python Debugger.

It is a built-in Python module that allows us to:
- Pause execution.
- Execute code line by line.
- Inspect variables.
- Step into functions.
- Continue execution.
- Set and manage breakpoints.

**Example:**

```python
import pdb

def calculate(a, b):
    pdb.set_trace()

    result = a + b
    return result

print(calculate(10, 20))
```

When execution reaches `pdb.set_trace()`, the debugger starts.

## 4. Using breakpoint()

Python provides the built-in `breakpoint()` function to start debugging easily.

```python
def calculate_total(price, quantity):

    breakpoint()

    total = price * quantity

    return total

result = calculate_total(100, 5)

print(result)
```

Execution pauses at `breakpoint()` before calculating the total.

By default, `breakpoint()` starts `pdb`, but its behavior can be customized.

**Difference:**

```python
import pdb

pdb.set_trace()
```

```python
breakpoint()
```

Both can start debugging with the default Python debugger.

## 5. Important pdb Commands

When the debugger starts, Python displays a prompt:

```text
(Pdb)
```

We can enter debugger commands at this prompt.

| Command | Meaning |
|---|---|
| `n` | Execute the next line |
| `s` | Step into a function |
| `c` | Continue execution |
| `l` | Display nearby source code |
| `p variable` | Print a variable value |
| `pp variable` | Pretty-print a variable |
| `w` | Display the current stack |
| `u` | Move up one stack frame |
| `d` | Move down one stack frame |
| `r` | Continue until the current function returns |
| `q` | Quit debugging |
| `h` | Display help |

## 6. Understanding Step Over (n)

The `n` command executes the next line without entering a function called on that line.

**Example:**

```python
def add(a, b):
    result = a + b
    return result

def main():
    x = 10
    y = 20

    breakpoint()

    result = add(x, y)
    print(result)

main()
```

At the debugger prompt:

```text
(Pdb) n
(Pdb) p x
10
(Pdb) p y
20
(Pdb) n
(Pdb) n
(Pdb) p result
30
(Pdb) c
30
```

The exact number of `n` commands depends on the current line shown by the debugger.

## 7. Understanding Step Into (s)

The `s` command enters a function when execution reaches a function call.

```python
def multiply(a, b):
    result = a * b
    return result

def main():
    x = 10
    y = 5

    breakpoint()

    result = multiply(x, y)
    print(result)

main()
```

At the debugger prompt:

```text
(Pdb) s
```

Python enters the `multiply()` function.

We can inspect its parameters:

```text
(Pdb) p a
10
(Pdb) p b
5
```

Now we can execute the function line by line.

## 8. Understanding Continue (c)

The `c` command resumes normal execution until another breakpoint is reached or the program finishes.

```python
def calculate():
    a = 10
    b = 20

    breakpoint()

    result = a + b

    print(result)

calculate()
```

At the debugger prompt:

```text
(Pdb) c
30
```

The program continues and completes execution.

## 9. Inspecting Variables

We can inspect variable values while the program is paused.

**Example:**

```python
def student_details():
    name = "Vikith"
    age = 22
    marks = [85, 90, 95]

    breakpoint()

    print(name, age, marks)

student_details()
```

Debugger commands:

```text
(Pdb) p name
'Vikith'

(Pdb) p age
22

(Pdb) p marks
[85, 90, 95]
```

We can also inspect expressions:

```text
(Pdb) p sum(marks)
270

(Pdb) p len(marks)
3
```

## 10. Setting Breakpoints Using pdb

Instead of inserting `pdb.set_trace()` into the code, we can start a Python script with the debugger.

```bash
python -m pdb main.py
```

This starts the debugger before the script executes.

We can also set breakpoints using the `b` command.

```text
(Pdb) b 10
```

This sets a breakpoint at line 10 of the current file.

To list breakpoints:

```text
(Pdb) b
```

To clear a breakpoint:

```text
(Pdb) cl 1
```

Here, `1` is the breakpoint number shown by the debugger.

## 11. Debugging a Logical Error

A program can run successfully but still produce an incorrect result.

**Incorrect code:**

```python
def calculate_total(price, quantity):
    total = price + quantity
    return total

breakpoint()

result = calculate_total(100, 5)

print(result)
```

**Output:**

```text
105
```

Expected output:

```text
500
```

We can use the debugger to inspect the variables and identify that addition was used instead of multiplication.

**Correct code:**

```python
def calculate_total(price, quantity):
    total = price * quantity
    return total

result = calculate_total(100, 5)

print(result)
```

**Output:**

```text
500
```

## 12. Debugging with Conditional Breakpoints

Sometimes we only want to pause execution when a particular condition is satisfied.

We can use a conditional breakpoint in `pdb`.

**Syntax:**

```text
(Pdb) b line_number, condition
```

**Example:**

```python
for number in range(1, 11):
    print(number)
```

Start the program using:

```bash
python -m pdb main.py
```

Set a conditional breakpoint at line 2:

```text
(Pdb) b 2, number == 5
(Pdb) c
```

The debugger pauses when `number == 5`.

## 13. Debugging Nested Function Calls

The debugger helps us understand how functions call one another.

```python
def multiply(a, b):
    result = a * b
    return result

def calculate():
    x = 10
    y = 5

    return multiply(x, y)

def main():
    breakpoint()

    result = calculate()
    print(result)

main()
```

We can use:

- `s` to enter `calculate()`.
- `s` again to enter `multiply()`.
- `p a` and `p b` to inspect parameters.
- `n` to execute individual lines.
- `c` to continue execution.

## 14. Important Differences

| Concept | Meaning |
|---|---|
| Debugger | Tool for inspecting program execution |
| Breakpoint | Location where execution pauses |
| `pdb` | Python's built-in debugger |
| `breakpoint()` | Built-in function that starts debugging |
| `pdb.set_trace()` | Starts the debugger at a specific line |
| `n` | Executes the next line without stepping into a function |
| `s` | Steps into a function |
| `c` | Continues execution |
