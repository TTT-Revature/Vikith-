# Python Instance, Class and Static Methods

## 1. Introduction

Python supports three commonly used types of methods inside a class:

1. Instance methods
2. Class methods
3. Static methods

They differ in how they receive arguments and what kind of data they work with.

## 2. Instance Methods

An instance method works with the data of a particular object.

It uses `self` as its first parameter to access instance attributes and other instance methods.

**Syntax:**

```python
class ClassName:

    def method_name(self):
        # Method implementation
        pass
```

**Example:**

```python
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    def display(self):
        print("Name:", self.name)
        print("Age:", self.age)


student1 = Student("Vikith", 22)
student2 = Student("Rahul", 23)

student1.display()
student2.display()
```

**Output:**

```text
Name: Vikith
Age: 22
Name: Rahul
Age: 23
```

### How Does an Instance Method Work?

When we call:

```python
student1.display()
```

Python automatically passes `student1` as the first argument.

Conceptually, this is equivalent to:

```python
Student.display(student1)
```

Therefore, `self` refers to the object that calls the method.

### Modifying Instance Attributes

Instance methods can modify the data belonging to an individual object.

```python
class Employee:

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def increase_salary(self, amount):
        self.salary += amount


emp1 = Employee("Vikith", 30000)
emp2 = Employee("Rahul", 35000)

emp1.increase_salary(5000)

print(emp1.salary)
print(emp2.salary)
```

**Output:**

```text
35000
35000
```

Only `emp1`'s salary is modified.

## 3. Class Methods

A class method works with the class itself rather than a particular object's instance data.

It uses the `@classmethod` decorator and receives `cls` as its first parameter.

**Syntax:**

```python
class ClassName:

    @classmethod
    def method_name(cls):
        # Method implementation
        pass
```

**Example:**

```python
class Student:

    college = "MIT Manipal"

    @classmethod
    def display_college(cls):
        print(cls.college)


Student.display_college()
```

**Output:**

```text
MIT Manipal
```

Here:
- `@classmethod` defines a class method.
- `cls` refers to the class.
- `cls.college` accesses the class attribute.

### Modifying Class Attributes

Class methods can modify class-level data.

```python
class Student:

    college = "MIT Manipal"

    @classmethod
    def change_college(cls, new_college):
        cls.college = new_college


Student.change_college("IIT Madras")

print(Student.college)
```

**Output:**

```text
IIT Madras
```

### Calling Class Methods Using Objects

Class methods can also be called through objects.

```python
class Student:

    college = "MIT Manipal"

    @classmethod
    def display_college(cls):
        print(cls.college)


student1 = Student()

student1.display_college()
```

**Output:**

```text
MIT Manipal
```

Python passes the class as `cls`, even when the method is called through an instance.

### Class Method as an Alternative Constructor

Class methods are commonly used to create objects using different input formats.

```python
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_string(cls, data):
        name, age = data.split("-")
        return cls(name, int(age))


student1 = Student.from_string("Vikith-22")

print(student1.name)
print(student1.age)
```

**Output:**

```text
Vikith
22
```

Here, `from_string()` creates and returns a new Student object.

## 4. Static Methods

A static method is a method defined inside a class that does not automatically receive an instance or class reference.

It uses the `@staticmethod` decorator.

**Syntax:**

```python
class ClassName:

    @staticmethod
    def method_name():
        # Method implementation
        pass
```

**Example:**

```python
class Calculator:

    @staticmethod
    def add(a, b):
        return a + b


result = Calculator.add(10, 20)

print(result)
```

**Output:**

```text
30
```

Here:
- `@staticmethod` defines a static method.
- It does not automatically receive `self` or `cls`.
- It can be called using the class name.

### Calling Static Methods Using Objects

Static methods can also be called through objects.

```python
class Calculator:

    @staticmethod
    def multiply(a, b):
        return a * b


calc = Calculator()

print(calc.multiply(10, 5))
```

**Output:**

```text
50
```

No object reference is automatically passed to the method.

### Static Method for Validation

Static methods are useful for helper operations related to a class.

```python
class Student:

    @staticmethod
    def is_valid_age(age):
        return age >= 18


print(Student.is_valid_age(22))
print(Student.is_valid_age(15))
```

**Output:**

```text
True
False
```

The method does not need instance data or class data.

## 5. Comparing All Three Methods

```python
class Employee:

    company = "Revature"

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    # Instance method
    def display(self):
        print(self.name, self.salary)

    # Class method
    @classmethod
    def change_company(cls, company):
        cls.company = company

    # Static method
    @staticmethod
    def is_valid_salary(salary):
        return salary > 0


emp1 = Employee("Vikith", 30000)

emp1.display()

Employee.change_company("Google")

print(Employee.company)

print(Employee.is_valid_salary(30000))
```

**Output:**

```text
Vikith 30000
Google
True
```

## 6. Important Differences

| Feature | Instance Method | Class Method | Static Method |
|---|---|---|---|
| Decorator | None | `@classmethod` | `@staticmethod` |
| First parameter | `self` | `cls` | None automatically |
| Works with instance data | Yes | Not directly | Not automatically |
| Works with class data | Yes, through class | Yes | Not automatically |
| Can modify instance attributes | Yes | Only if given an instance | Only if given an instance |
| Can modify class attributes | Yes, through class | Yes | Yes, if given the class |
| Common use | Object-specific operations | Class-level operations | Utility operations |

## 7. Understanding self vs cls

Both `self` and `cls` are naming conventions, but they refer to different things.

### self

Refers to the current object.

```python
class Student:

    def display(self):
        print(self)


student1 = Student()

student1.display()
```

Here, `self` refers to `student1`.

### cls

Refers to the class.

```python
class Student:

    @classmethod
    def display(cls):
        print(cls)


Student.display()
```

**Output:**

```text
<class '__main__.Student'>
```

## 8. Real-World Example: Employee Management

```python
class Employee:

    company = "Revature"

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    # Instance method
    def display_details(self):
        print("Name:", self.name)
        print("Salary:", self.salary)

    # Class method
    @classmethod
    def change_company(cls, new_company):
        cls.company = new_company

    # Static method
    @staticmethod
    def is_valid_salary(salary):
        return salary >= 15000


emp1 = Employee("Vikith", 30000)

emp1.display_details()

Employee.change_company("TCS")

print("Company:", Employee.company)

print("Valid Salary:", Employee.is_valid_salary(30000))
```

**Output:**

```text
Name: Vikith
Salary: 30000
Company: TCS
Valid Salary: True
```

## 9. When Should We Use Each Method?

| Requirement | Recommended Method |
|---|---|
| Access object attributes | Instance method |
| Modify object-specific data | Instance method |
| Access or modify class attributes | Class method |
| Create alternative constructors | Class method |
| Perform a utility calculation | Static method |
| Validate data without object state | Static method |

## 10. Important Points

- Instance methods receive `self` automatically.
- Class methods receive `cls` automatically.
- Static methods receive neither automatically.
- `@classmethod` is used to define class methods.
- `@staticmethod` is used to define static methods.
- All three methods can be called through objects, but their behavior differs.
- Class methods are useful for alternative constructors.
- Static methods are useful for related utility functions.
- `self` and `cls` are conventions, not reserved keywords.

## Quick Summary

- **Instance Method:** Works with individual object data using `self`.
- **Class Method:** Works with class-level data using `cls`.
- **Static Method:** Performs related operations without automatically receiving `self` or `cls`.
- **`@classmethod`:** Decorator for class methods.
- **`@staticmethod`:** Decorator for static methods.
