# Return Values and Multiple Returns in Python

The `return` statement is used to send a result from a function back to the code that called it.

Return values allow us to reuse the result of a function in calculations, assignments and other function calls.

## 1. Understanding return

The `return` keyword terminates function execution and sends a value back to the caller.

### Example

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

**Output:**

```text
30
```

Execution:

1. The function receives `10` and `20`.
2. It calculates `10 + 20`.
3. `return` sends `30` back.
4. The returned value is stored in `result`.

## 2. Returning Different Data Types

A function can return different Python data types.

### Returning an Integer

```python
def get_age():
    return 22

print(get_age())
```

**Output:**

```text
22
```

### Returning a String

```python
def get_name():
    return "Rahul"

print(get_name())
```

**Output:**

```text
Rahul
```

### Returning a List

```python
def get_numbers():
    return [10, 20, 30, 40]

print(get_numbers())
```

**Output:**

```text
[10, 20, 30, 40]
```

### Returning a Dictionary

```python
def get_student():
    return {
        "name": "Rahul",
        "age": 22,
        "course": "MCA"
    }

print(get_student())
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'course': 'MCA'}
```

A function can return any Python object, including integers, strings, lists, tuples, dictionaries and sets.

## 3. Difference Between print() and return

### Using print()

```python
def add(a, b):
    print(a + b)

result = add(10, 20)

print(result)
```

**Output:**

```text
30
None
```

`print()` displays the result but does not return it to the caller.

### Using return

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

**Output:**

```text
30
```

`return` sends the result back, allowing it to be stored or reused.

| print() | return |
|---|---|
| Displays a value | Sends a value back |
| Does not make the displayed value the function result | Becomes the function result |
| Execution continues after printing | Function execution ends |
| Useful for displaying output | Useful for calculations and processing |

## 4. Function Without a return Statement

If a function does not explicitly return a value, Python automatically returns `None`.

```python
def greet():
    print("Hello Python")

result = greet()

print(result)
```

**Output:**

```text
Hello Python
None
```

The function displays a message and implicitly returns `None`.

## 5. Returning None Explicitly

We can also return `None` manually.

```python
def check_value():
    return None

result = check_value()

print(result)
print(type(result))
```

**Output:**

```text
None
<class 'NoneType'>
```

`None` represents the absence of a value.

## 6. Returning Multiple Values

Python allows a function to return multiple values separated by commas.

```python
def calculate(a, b):
    addition = a + b
    subtraction = a - b
    multiplication = a * b

    return addition, subtraction, multiplication

result = calculate(20, 10)

print(result)
```

**Output:**

```text
(30, 10, 200)
```

**Important:** Python actually packs these returned values into a tuple.

The following statements are equivalent:

```python
return addition, subtraction, multiplication
```

```python
return (addition, subtraction, multiplication)
```

## 7. Unpacking Multiple Return Values

We can assign each returned value to a separate variable using tuple unpacking.

```python
def calculate(a, b):
    return a + b, a - b, a * b

addition, subtraction, multiplication = calculate(20, 10)

print(addition)
print(subtraction)
print(multiplication)
```

**Output:**

```text
30
10
200
```

Here:

- `addition` receives `30`.
- `subtraction` receives `10`.
- `multiplication` receives `200`.

The number of variables must match the number of returned values unless extended unpacking is used.

## 8. Returning Multiple Values as a Tuple

We can store the returned tuple in one variable and access individual values using indexes.

```python
def student():
    return "Rahul", 22, "MCA"

result = student()

print(result)
print(result[0])
print(result[1])
print(result[2])
```

**Output:**

```text
('Rahul', 22, 'MCA')
Rahul
22
MCA
```

The returned tuple supports normal tuple operations such as indexing and unpacking.

## 9. Returning Multiple Values as a Dictionary

Sometimes returning a dictionary is more readable, especially when the results have meaningful names.

```python
def calculate(a, b):
    return {
        "addition": a + b,
        "subtraction": a - b,
        "multiplication": a * b
    }

result = calculate(20, 10)

print(result)
print(result["addition"])
print(result["multiplication"])
```

**Output:**

```text
{'addition': 30, 'subtraction': 10, 'multiplication': 200}
30
200
```

A dictionary makes each result identifiable by its key.

## 10. Returning Multiple Values as a List

A function can also return a list containing multiple results.

```python
def calculate(a, b):
    return [a + b, a - b, a * b]

result = calculate(20, 10)

print(result)
print(result[0])
```

**Output:**

```text
[30, 10, 200]
30
```

Unlike a tuple, a list is mutable.

## 11. Returning Early from a Function

A function can contain multiple `return` statements.

When Python executes a `return`, the function terminates immediately.

```python
def check_number(number):
    if number > 0:
        return "Positive"

    return "Zero or Negative"

print(check_number(10))
print(check_number(-5))
```

**Output:**

```text
Positive
Zero or Negative
```

The second `return` executes only if the first condition is false.

### Multiple Conditional Returns

```python
def check_marks(marks):
    if marks >= 90:
        return "Grade A"
    elif marks >= 75:
        return "Grade B"
    elif marks >= 40:
        return "Grade C"
    else:
        return "Fail"

print(check_marks(95))
print(check_marks(80))
print(check_marks(50))
print(check_marks(30))
```

**Output:**

```text
Grade A
Grade B
Grade C
Fail
```

## 12. Returning Results from Another Function

One function can return the result of another function.

```python
def square(number):
    return number ** 2

def calculate():
    return square(5)

print(calculate())
```

**Output:**

```text
25
```

We can also pass returned values directly into another function.

```python
def add(a, b):
    return a + b

def multiply(number):
    return number * 2

result = multiply(add(10, 20))

print(result)
```

**Output:**

```text
60
```

Execution:

1. `add(10, 20)` returns `30`.
2. `30` is passed to `multiply()`.
3. `multiply(30)` returns `60`.

## 13. Returning Boolean Values

Functions can return `True` or `False`.

```python
def is_even(number):
    return number % 2 == 0

print(is_even(10))
print(is_even(7))
```

**Output:**

```text
True
False
```

Boolean-returning functions are useful for validation and conditional checks.

## 14. Returning a Value from a Loop

A function can return a result after processing a loop.

```python
def find_number(numbers, target):
    for number in numbers:
        if number == target:
            return True

    return False

numbers = [10, 20, 30, 40]

print(find_number(numbers, 30))
print(find_number(numbers, 50))
```

**Output:**

```text
True
False
```

When the target is found, the function returns immediately. If the loop completes without finding it, the function returns `False`.

## 15. Returning from a Function with Multiple Conditions

Consider a simple login validation example.

```python
def login(username, password):
    if username == "":
        return "Username is required"

    if password == "":
        return "Password is required"

    if username == "admin" and password == "python123":
        return "Login successful"

    return "Invalid credentials"

print(login("admin", "python123"))
print(login("", "python123"))
print(login("admin", "wrong"))
```

**Output:**

```text
Login successful
Username is required
Invalid credentials
```

Each `return` handles a different condition and stops unnecessary execution.

## 16. Choosing Between Tuple, List and Dictionary Returns

| Return Type | Best Used When |
|---|---|
| Tuple | Returning a fixed group of related values |
| List | Returning a collection of values that may be modified |
| Dictionary | Returning named results with clear meanings |
| Single value | Returning one result |
| Boolean | Returning a condition or validation result |

## 17. Important Points to Remember

- `return` sends a result back to the caller.
- A function stops executing when it reaches `return`.
- A function without an explicit return statement returns `None`.
- `print()` and `return` have different purposes.
- Python supports returning multiple values.
- Multiple comma-separated return values are packed into a tuple.
- Returned values can be unpacked into separate variables.
- Functions can return lists, dictionaries, tuples and other objects.
- A function can contain multiple conditional return statements.
- A returned value can be passed directly into another function.

## 18. Real-World Use Cases

- **Calculations:** Return total, average and percentage from a function.
- **Data analysis:** Return minimum, maximum and average values.
- **Validation:** Return `True` or `False` based on input validation.
- **API development:** Return structured dictionaries containing status and data.
- **Student management:** Return student details and calculated grades.
- **Searching:** Return a matching record or a result indicating whether an item exists.

### Example: Student Result Calculator

```python
def calculate_result(marks):
    total = sum(marks)
    average = total / len(marks)
    highest = max(marks)
    lowest = min(marks)

    return total, average, highest, lowest

marks = [85, 90, 78, 95, 88]

total, average, highest, lowest = calculate_result(marks)

print("Total:", total)
print("Average:", round(average, 2))
print("Highest:", highest)
print("Lowest:", lowest)
```

**Output:**

```text
Total: 436
Average: 87.2
Highest: 95
Lowest: 78
```

This example demonstrates how a single function can calculate and return multiple related results.
