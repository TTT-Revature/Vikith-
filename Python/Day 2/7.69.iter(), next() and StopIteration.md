

# Python iter(), next() and StopIteration

## 1. Introduction

Python provides three important concepts for working with iterators:

- `iter()` – Creates or obtains an iterator from an iterable.
- `next()` – Retrieves the next element from an iterator.
- `StopIteration` – Indicates that the iterator has no more elements.

These are part of Python's **iterator protocol**.

## 2. Understanding iter()

The `iter()` function returns an iterator from an iterable object.

### Syntax

```python
iter(iterable)
```

### Example

```python
numbers = [10, 20, 30, 40]

iterator = iter(numbers)

print(iterator)
print(type(iterator))
```

**Possible Output:**

```text
<list_iterator object at ...>
<class 'list_iterator'>
```

Here:
- `numbers` is a list and an iterable.
- `iter(numbers)` creates a list iterator.
- `iterator` stores the iterator object.

### More Examples

```python
# List
numbers = [1, 2, 3]
print(type(iter(numbers)))

# Tuple
values = (10, 20, 30)
print(type(iter(values)))

# String
name = "Python"
print(type(iter(name)))

# Set
items = {1, 2, 3}
print(type(iter(items)))

# Dictionary
student = {"name": "Vikith", "age": 24}
print(type(iter(student)))
```

Each of these objects can provide an iterator.

**Important:** Iterating over a dictionary directly produces its keys.

## 3. Understanding next()

The `next()` function retrieves the next element from an iterator.

### Syntax

```python
next(iterator)
```

### Example

```python
numbers = [10, 20, 30, 40]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
print(next(iterator))
```

**Output:**

```text
10
20
30
40
```

Each call to `next()` retrieves one element and advances the iterator.

### Understanding the Internal Position

```python
numbers = [10, 20, 30, 40]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))

print("Next element:", next(iterator))
```

**Output:**

```text
10
20
Next element: 30
```

The iterator remembers its current position.

It does not start from the beginning with every `next()` call.

## 4. Understanding StopIteration

`StopIteration` is an exception raised when an iterator has no more elements to return.

### Example

```python
numbers = [10, 20]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

**Output:**

```text
10
20
Traceback (most recent call last):
    ...
StopIteration
```

Why does this happen?

1. First `next()` returns `10`.
2. Second `next()` returns `20`.
3. Third `next()` has no remaining element.
4. Python raises `StopIteration`.

## 5. Handling StopIteration Using try-except

We can handle the exception using `try-except`.

```python
numbers = [10, 20]

iterator = iter(numbers)

try:
    print(next(iterator))
    print(next(iterator))
    print(next(iterator))

except StopIteration:
    print("No more elements")
```

**Output:**

```text
10
20
No more elements
```

This prevents the program from terminating with an unhandled exception.

## 6. Using next() with a Default Value

The `next()` function supports an optional default value.

### Syntax

```python
next(iterator, default)
```

If the iterator is exhausted, Python returns the default value instead of raising `StopIteration`.

### Example

```python
numbers = [10, 20]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator, "Finished"))
```

**Output:**

```text
10
20
Finished
```

Another example:

```python
numbers = []

iterator = iter(numbers)

value = next(iterator, 0)

print(value)
```

**Output:**

```text
0
```

Here, the iterator is empty, so `next()` returns `0`.

**Important:** When a default value is supplied, `StopIteration` is not raised by that `next()` call when the iterator is exhausted.

## 7. Using iter() with a Callable and Sentinel

The `iter()` function has another form that accepts a callable and a sentinel value.

### Syntax

```python
iter(callable, sentinel)
```

Python repeatedly calls the function until its return value equals the sentinel.

### Example

```python
def get_number():
    return int(input("Enter a number: "))

iterator = iter(get_number, 0)

for number in iterator:
    print(number)
```

**Example Input:**

```text
Enter a number: 10
10
Enter a number: 20
20
Enter a number: 30
30
Enter a number: 0
```

When the function returns `0`, iteration stops.

The sentinel value itself is not included in the iteration results.

## 8. How a for Loop Uses iter() and next()

A `for` loop automatically uses the iterator protocol.

### Normal for Loop

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

### Conceptual Internal Working

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

while True:
    try:
        number = next(iterator)
        print(number)

    except StopIteration:
        break
```

**Output:**

```text
10
20
30
```

The `for` loop automatically handles `StopIteration`, so we do not normally need to write this logic ourselves.

## 9. Using iter() and next() with Different Data Types

### List

```python
numbers = [10, 20, 30]

it = iter(numbers)

print(next(it))
print(next(it))
```

**Output:**

```text
10
20
```

### Tuple

```python
values = (100, 200, 300)

it = iter(values)

print(next(it))
```

**Output:**

```text
100
```

### String

```python
name = "Python"

it = iter(name)

print(next(it))
print(next(it))
```

**Output:**

```text
P
y
```

### Dictionary

```python
student = {
    "name": "Vikith",
    "age": 24,
    "course": "MCA"
}

it = iter(student)

print(next(it))
print(next(it))
```

**Output:**

```text
name
age
```

Directly iterating over a dictionary returns its keys.

## 10. Important Differences

| Concept | Purpose |
|---|---|
| `iter()` | Obtains an iterator from an iterable |
| `next()` | Retrieves the next element |
| `StopIteration` | Signals that no more elements are available |
| `next(iterator, default)` | Returns a default value when exhausted |
| `iter(callable, sentinel)` | Calls a function repeatedly until its result matches the sentinel |
