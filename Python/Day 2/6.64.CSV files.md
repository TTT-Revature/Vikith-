

# Python CSV Files: Reading and Writing

## 1. What Is a CSV File?

CSV stands for **Comma-Separated Values**.

It is a file format used to store tabular data in rows and columns. Each row represents a record, and values are usually separated by commas.

CSV files commonly use the `.csv` extension.

### Example: students.csv

```csv
id,name,age,course
101,Vikith,24,MCA
102,Anil,23,BCA
103,Ram,25,MBA
```

This data can be represented as a table:

| id | name | age | course |
|---|---|---:|---|
| 101 | Vikith | 24 | MCA |
| 102 | Anil | 23 | BCA |
| 103 | Ram | 25 | MBA |

## 2. Python CSV Module

Python provides a built-in module called `csv` to read and write CSV files.

No external installation is required.

```python
import csv
```

The CSV module provides methods to handle CSV data easily.

## 3. Reading a CSV File

Use `csv.reader()` to read rows from a CSV file.

### Example

Assume `students.csv` contains:

```csv
id,name,age
101,Vikith,24
102,Anil,23
103,Ram,25
```

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)
```

**Output:**

```text
['id', 'name', 'age']
['101', 'Vikith', '24']
['102', 'Anil', '23']
['103', 'Ram', '25']
```

Each row is returned as a list of strings.

**Important:** CSV values are read as strings by default, even when they contain numbers.

## 4. Skipping the Header Row

The first row of a CSV file often contains column names.

Use `next()` to skip the header.

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file)

    next(reader)

    for row in reader:
        print(row)
```

**Output:**

```text
['101', 'Vikith', '24']
['102', 'Anil', '23']
['103', 'Ram', '25']
```

## 5. Accessing Individual Values

Since `csv.reader()` returns each row as a list, we can access values using indexes.

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file)

    next(reader)

    for row in reader:
        print("ID:", row[0])
        print("Name:", row[1])
        print("Age:", row[2])
```

**Output:**

```text
ID: 101
Name: Vikith
Age: 24
ID: 102
Name: Anil
Age: 23
ID: 103
Name: Ram
Age: 25
```

## 6. Writing Data into a CSV File

Use `csv.writer()` to write rows into a CSV file.

### writerow()

Writes a single row.

```python
import csv

with open("students.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)

    writer.writerow(["id", "name", "age"])
    writer.writerow([101, "Vikith", 24])
    writer.writerow([102, "Anil", 23])
```

**Generated students.csv:**

```csv
id,name,age
101,Vikith,24
102,Anil,23
```

### writerows()

Writes multiple rows at once.

```python
import csv

students = [
    ["id", "name", "age"],
    [101, "Vikith", 24],
    [102, "Anil", 23],
    [103, "Ram", 25]
]

with open("students.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)

    writer.writerows(students)
```

`writerows()` accepts an iterable containing multiple rows.

## 7. Appending Data to a CSV File

Use the `a` mode to add new records without deleting existing data.

```python
import csv

with open("students.csv", "a", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)

    writer.writerow([104, "Kiran", 22])
```

This adds a new row at the end of the file.

**Important:** Using `w` mode overwrites existing content, while `a` mode appends new content.

## 8. Reading CSV Files Using DictReader

`csv.DictReader()` reads each row as a dictionary instead of a list.

The column names are used as dictionary keys.

### Example

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(row)
```

**Output:**

```text
{'id': '101', 'name': 'Vikith', 'age': '24'}
{'id': '102', 'name': 'Anil', 'age': '23'}
{'id': '103', 'name': 'Ram', 'age': '25'}
```

### Accessing Values by Column Name

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(row["name"], row["age"])
```

**Output:**

```text
Vikith 24
Anil 23
Ram 25
```

Using `DictReader` is convenient when we want to access data by column name instead of index.

## 9. Writing CSV Files Using DictWriter

`csv.DictWriter()` writes dictionary data into a CSV file.

### Example

```python
import csv

students = [
    {"id": 101, "name": "Vikith", "age": 24},
    {"id": 102, "name": "Anil", "age": 23},
    {"id": 103, "name": "Ram", "age": 25}
]

with open("students.csv", "w", newline="", encoding="utf-8") as file:

    fieldnames = ["id", "name", "age"]

    writer = csv.DictWriter(file, fieldnames=fieldnames)

    writer.writeheader()
    writer.writerows(students)
```

**Generated students.csv:**

```csv
id,name,age
101,Vikith,24
102,Anil,23
103,Ram,25
```

- `fieldnames` defines the column names and their order.
- `writeheader()` writes the column names.
- `writerows()` writes multiple dictionary records.

## 10. Handling Different Delimiters

CSV files do not always use commas. Some files use semicolons, tabs, or other separators.

Use the `delimiter` parameter to specify the separator.

### Example: Semicolon-Separated File

```csv
id;name;age
101;Vikith;24
102;Anil;23
```

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file, delimiter=";")

    for row in reader:
        print(row)
```

**Output:**

```text
['id', 'name', 'age']
['101', 'Vikith', '24']
['102', 'Anil', '23']
```

## 11. Handling Quoted Values

CSV files can contain commas inside values.

Such values are usually enclosed in quotation marks.

### Example CSV

```csv
id,name,city
101,Vikith,"Chennai, India"
102,Anil,"Mangalore, India"
```

The CSV reader automatically handles quoted values.

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)
```

**Output:**

```text
['id', 'name', 'city']
['101', 'Vikith', 'Chennai, India']
['102', 'Anil', 'Mangalore, India']
```

## 12. Converting CSV Values into Numbers

The CSV module reads values as strings. Convert them when numerical operations are required.

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        name = row["name"]
        age = int(row["age"])

        print(name, age + 1)
```

**Output:**

```text
Vikith 25
Anil 24
Ram 26
```

## 13. CSV Module Methods Reference

| Method / Parameter | Purpose |
|---|---|
| `csv.reader()` | Reads rows as lists |
| `csv.writer()` | Writes rows using lists or other iterables |
| `csv.DictReader()` | Reads rows as dictionaries |
| `csv.DictWriter()` | Writes dictionary records |
| `writerow()` | Writes one row |
| `writerows()` | Writes multiple rows |
| `writeheader()` | Writes dictionary column names |
| `next()` | Retrieves the next row; useful for skipping a header |
| `delimiter` | Specifies the field separator |
| `quotechar` | Specifies the character used for quoting |
| `fieldnames` | Defines dictionary CSV column names |

## 14. Real-World Example: Student Marks Management

```python
import csv

students = [
    ["id", "name", "marks"],
    [101, "Vikith", 90],
    [102, "Anil", 85],
    [103, "Ram", 95]
]

# Write student records
with open("marks.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)
    writer.writerows(students)

# Read student records
with open("marks.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)

    for row in reader:
        name = row["name"]
        marks = int(row["marks"])

        print(f"{name} scored {marks} marks")
```

**Output:**

```text
Vikith scored 90 marks
Anil scored 85 marks
Ram scored 95 marks
```

## 15. Important Points

- CSV stands for Comma-Separated Values.
- Python provides a built-in `csv` module.
- `csv.reader()` reads rows as lists.
- `csv.writer()` writes rows into CSV files.
- `csv.DictReader()` reads rows as dictionaries.
- `csv.DictWriter()` writes dictionary records.
- `writerow()` writes one row.
- `writerows()` writes multiple rows.
- CSV values are read as strings by default.
- Use `newline=""` when opening CSV files for reading or writing.
- Use `encoding="utf-8"` for consistent text encoding.
- Use `delimiter` when the file uses a separator other than a comma.
