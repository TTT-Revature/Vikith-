# re.findall() and re.sub() in Python

Python's `re` module provides functions to find multiple pattern matches and replace matching text.

Two important functions are:

1. `re.findall()` – Finds all occurrences of a pattern.
2. `re.sub()` – Replaces occurrences of a pattern with another string.

## 1. re.findall()

The `re.findall()` function returns all non-overlapping matches of a pattern in a string as a list.

**Syntax:**

```python
re.findall(pattern, string, flags=0)
```

- `pattern`: Regular expression to search for.
- `string`: Text in which to search.
- `flags`: Optional regex flags.

### Example: Find All Numbers

```python
import re

text = "My marks are 85, 90 and 95"

result = re.findall(r"\d+", text)

print(result)
```

**Output:**

```text
['85', '90', '95']
```

### Example: Find All Words

```python
import re

text = "Python is easy and Python is powerful"

result = re.findall(r"\w+", text)

print(result)
```

**Output:**

```text
['Python', 'is', 'easy', 'and', 'Python', 'is', 'powerful']
```

### Example: Find All Vowels

```python
import re

text = "Regular Expressions"

result = re.findall(r"[aeiou]", text, re.IGNORECASE)

print(result)
```

**Output:**

```text
['e', 'u', 'a', 'E', 'e', 'i', 'o']
```

### Example: Find All Email-Like Text

```python
import re

text = "Contact: john@gmail.com, support@yahoo.com"

result = re.findall(r"[\w.-]+@[\w.-]+\.\w+", text)

print(result)
```

**Output:**

```text
['john@gmail.com', 'support@yahoo.com']
```

### Example: Find All Dates

```python
import re

text = "Dates: 17-11-2026 and 22-12-2026"

result = re.findall(r"\d{2}-\d{2}-\d{4}", text)

print(result)
```

**Output:**

```text
['17-11-2026', '22-12-2026']
```

## 2. re.findall() with Capturing Groups

When a pattern contains capturing groups, `findall()` returns the captured parts instead of the complete match.

### Single Capturing Group

```python
import re

text = "Price: 500, Price: 750"

result = re.findall(r"Price: (\d+)", text)

print(result)
```

**Output:**

```text
['500', '750']
```

### Multiple Capturing Groups

```python
import re

text = "John-25, David-30"

result = re.findall(r"([A-Za-z]+)-(\d+)", text)

print(result)
```

**Output:**

```text
[('John', '25'), ('David', '30')]
```

Each tuple contains the captured name and age.

## 3. re.sub()

The `re.sub()` function replaces all non-overlapping occurrences of a pattern with a replacement string.

**Syntax:**

```python
re.sub(pattern, replacement, string, count=0, flags=0)
```

- `pattern`: Pattern to search for.
- `replacement`: Text that replaces the matches.
- `string`: Original text.
- `count`: Maximum number of replacements. Default is `0`, meaning replace all matches.
- `flags`: Optional regex flags.

### Example: Replace a Word

```python
import re

text = "I like Java"

result = re.sub(r"Java", "Python", text)

print(result)
```

**Output:**

```text
I like Python
```

### Example: Replace All Numbers

```python
import re

text = "Product 123 costs 500"

result = re.sub(r"\d+", "X", text)

print(result)
```

**Output:**

```text
Product X costs X
```

### Example: Remove Special Characters

```python
import re

text = "Hello@Python#2026!"

result = re.sub(r"[^a-zA-Z0-9]", "", text)

print(result)
```

**Output:**

```text
HelloPython2026
```

### Example: Replace Multiple Spaces with One Space

```python
import re

text = "Python     is     easy"

result = re.sub(r"\s+", " ", text)

print(result)
```

**Output:**

```text
Python is easy
```

### Example: Limit the Number of Replacements

Use the `count` parameter to control how many matches are replaced.

```python
import re

text = "apple apple apple"

result = re.sub(r"apple", "mango", text, count=2)

print(result)
```

**Output:**

```text
mango mango apple
```

Only the first two occurrences are replaced.

## 4. Using a Function as the Replacement

`re.sub()` also accepts a function as its replacement argument.

The function receives a match object and returns the replacement text.

```python
import re

text = "Price: 100, Price: 200"

def double_price(match):
    number = int(match.group())
    return str(number * 2)

result = re.sub(r"\d+", double_price, text)

print(result)
```

**Output:**

```text
Price: 200, Price: 400
```

This is useful when the replacement depends on the matched value.

## 5. Important Differences

| Feature | `re.findall()` | `re.sub()` |
|---|---|---|
| Purpose | Find matching text | Replace matching text |
| Return type | List | String |
| Main use | Extract information | Modify text |
| Capturing groups | Returns captured values | Can use captured groups in replacement |
| Default behavior | Finds all non-overlapping matches | Replaces all non-overlapping matches |

## 6. Practical Use Cases

### Data Extraction
Use `findall()` to extract phone numbers, prices, dates, and email addresses from text.

### Data Cleaning
Use `sub()` to remove unwanted characters, extra spaces, or symbols.

### Text Replacement
Replace specific words or patterns in documents and messages.

### Log Processing
Extract error codes, timestamps, and numeric values from application logs.

### Data Transformation
Use a replacement function with `sub()` to calculate or transform matched values.
