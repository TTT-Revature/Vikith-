# Python Classes and Objects

## 1. What Is Object-Oriented Programming (OOP)?

Object-Oriented Programming (OOP) is a programming approach based on classes and objects.

It helps organize code by combining data and related functions into a single structure.

The four main principles of OOP are:

1. Encapsulation
2. Inheritance
3. Polymorphism
4. Abstraction

We will study these concepts separately.

## 2. What Is a Class?

A class is a blueprint or template used to create objects.

It defines the properties (data) and behaviors (methods) that its objects can have.

**Syntax:**

```python
class ClassName:
    # Attributes
    # Methods
    pass
```

**Example:**

```python
class Student:
    name = "Vikith"
    age = 22
```

Here:
- `class` is the keyword used to create a class.
- `Student` is the class name.
- `name` and `age` are class attributes.

## 3. What Is an Object?

An object is an instance of a class.

We create objects by calling the class name like a function.

**Syntax:**

```python
object_name = ClassName()
```

**Example:**

```python
class Student:
    name = "Vikith"
    age = 22


student1 = Student()

print(student1.name)
print(student1.age)
```

**Output:**

```text
Vikith
22
```

Here:
- `Student` is the class.
- `student1` is an object (instance) of the class.
- `student1.name` accesses the name attribute.
- `student1.age` accesses the age attribute.

## 4. Creating Multiple Objects

We can create multiple objects from the same class.

```python
class Student:
    name = "Vikith"
    age = 22


student1 = Student()
student2 = Student()

print(student1.name)
print(student2.name)
```

**Output:**

```text
Vikith
Vikith
```

Both objects access the same class attribute because we have not defined separate instance attributes yet.

## 5. What Are Attributes?

Attributes are variables associated with a class or an object.

Python has two common types of attributes:

### Class Attributes

Class attributes are defined inside the class but outside its methods.

They are shared through the class and its instances unless an instance overrides them.

```python
class Student:
    college = "MIT Manipal"
    course = "MCA"


student1 = Student()
student2 = Student()

print(student1.college)
print(student2.college)
```

**Output:**

```text
MIT Manipal
MIT Manipal
```

### Instance Attributes

Instance attributes belong to individual objects.

They are commonly created using `self` inside the `__init__()` method.

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age


student1 = Student("Vikith", 22)
student2 = Student("Rahul", 23)

print(student1.name)
print(student2.name)
```

**Output:**

```text
Vikith
Rahul
```

Each object stores its own name and age.

## 6. What Is the __init__() Method?

`__init__()` is a special method that Python automatically calls when a new object is created.

It is commonly used to initialize an object's attributes.

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age


student1 = Student("Vikith", 22)

print(student1.name)
print(student1.age)
```

**Output:**

```text
Vikith
22
```

Important points:
- `__init__()` is automatically called during object initialization.
- It receives the newly created object through `self`.
- It can accept additional arguments.
- It is commonly called the constructor, although technically `__new__()` creates the object and `__init__()` initializes it.

## 7. Understanding self

`self` refers to the current object on which an instance method is being called.

It allows us to access the attributes and methods belonging to that object.

```python
class Student:
    def __init__(self, name):
        self.name = name

    def display(self):
        print("Student Name:", self.name)


student1 = Student("Vikith")
student2 = Student("Rahul")

student1.display()
student2.display()
```

**Output:**

```text
Student Name: Vikith
Student Name: Rahul
```

When we write:

```python
student1.display()
```

Python internally passes `student1` as the first argument to the method.

Conceptually, it is equivalent to:

```python
Student.display(student1)
```

**Important:** `self` is not a Python keyword. It is a naming convention, but it should be used for the first parameter of instance methods.

## 8. What Are Methods?

Methods are functions defined inside a class.

They describe the behavior or actions that objects can perform.

```python
class Calculator:
    def add(self, a, b):
        return a + b

    def subtract(self, a, b):
        return a - b

    def multiply(self, a, b):
        return a * b


calc = Calculator()

print(calc.add(10, 5))
print(calc.subtract(10, 5))
print(calc.multiply(10, 5))
```

**Output:**

```text
15
5
50
```

Here, `add()`, `subtract()`, and `multiply()` are instance methods.

## 9. Modifying Object Attributes

We can change an object's instance attributes after creating it.

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age


student1 = Student("Vikith", 22)

print(student1.name)

student1.name = "Vikith Kotian"

print(student1.name)
```

**Output:**

```text
Vikith
Vikith Kotian
```

We can also create a new attribute dynamically:

```python
student1.city = "Chennai"

print(student1.city)
```

**Output:**

```text
Chennai
```

This creates an attribute on `student1`; it does not automatically add that attribute to other existing objects.

## 10. Class Attributes vs Instance Attributes

```python
class Employee:
    company = "Revature"

    def __init__(self, name, salary):
        self.name = name
        self.salary = salary


emp1 = Employee("Vikith", 30000)
emp2 = Employee("Rahul", 35000)

print(emp1.company)
print(emp2.company)

print(emp1.name)
print(emp2.name)
```

**Output:**

```text
Revature
Revature
Vikith
Rahul
```

| Class Attribute | Instance Attribute |
|---|---|
| Defined in the class body | Usually defined using `self` |
| Shared through the class | Belongs to an individual object |
| Accessed using class or instance | Accessed using the instance |
| Can be overridden by an instance attribute | Stored separately for each instance |

**Important:** If an instance has an attribute with the same name as a class attribute, the instance attribute takes precedence when accessed through that instance.

## 11. Class Methods

A class method works with the class itself rather than an individual instance.

It uses the `@classmethod` decorator and receives `cls` as its first parameter.

```python
class Student:
    college = "MIT Manipal"

    @classmethod
    def change_college(cls, new_college):
        cls.college = new_college


Student.change_college("IIT Madras")

print(Student.college)
```

**Output:**

```text
IIT Madras
```

Here:
- `@classmethod` defines a class method.
- `cls` refers to the class.
- `cls.college` accesses the class attribute.

## 12. Static Methods

A static method belongs to the class's namespace but does not automatically receive an instance or class reference.

It uses the `@staticmethod` decorator.

```python
class Calculator:

    @staticmethod
    def add(a, b):
        return a + b


print(Calculator.add(10, 20))
```

**Output:**

```text
30
```

Static methods are useful for helper operations related to a class that do not need instance or class state.

## 13. Instance Method vs Class Method vs Static Method

| Method | First Parameter | Decorator | Main Purpose |
|---|---|---|---|
| Instance method | `self` | None | Work with object data |
| Class method | `cls` | `@classmethod` | Work with class data |
| Static method | None automatically | `@staticmethod` | Related utility operations |

## 14. Checking Objects and Classes

Python provides built-in functions to inspect objects and their classes.

### type()

Returns the type of an object.

```python
class Student:
    pass


student1 = Student()

print(type(student1))
```

**Output:**

```text
<class '__main__.Student'>
```

### isinstance()

Checks whether an object is an instance of a particular class or its subclasses.

```python
class Student:
    pass


student1 = Student()

print(isinstance(student1, Student))
```

**Output:**

```text
True
```

### hasattr()

Checks whether an object has a particular attribute.

```python
class Student:
    name = "Vikith"


student1 = Student()

print(hasattr(student1, "name"))
```

**Output:**

```text
True
```

### getattr()

Gets an attribute value by its name.

```python
class Student:
    name = "Vikith"


student1 = Student()

print(getattr(student1, "name"))
```

**Output:**

```text
Vikith
```

### setattr()

Creates or modifies an attribute dynamically.

```python
class Student:
    pass


student1 = Student()

setattr(student1, "name", "Vikith")

print(student1.name)
```

**Output:**

```text
Vikith
```

## 15. Real-World Example: Employee Management

```python
class Employee:

    company = "Revature"

    def __init__(self, name, employee_id, salary):
        self.name = name
        self.employee_id = employee_id
        self.salary = salary

    def display_details(self):
        print("Name:", self.name)
        print("Employee ID:", self.employee_id)
        print("Salary:", self.salary)
        print("Company:", self.company)

    def increase_salary(self, amount):
        self.salary += amount


emp1 = Employee("Vikith", "RCS977", 30000)

emp1.display_details()

emp1.increase_salary(5000)

print("Updated Salary:", emp1.salary)
```

**Output:**

```text
Name: Vikith
Employee ID: RCS977
Salary: 30000
Company: Revature
Updated Salary: 35000
```
