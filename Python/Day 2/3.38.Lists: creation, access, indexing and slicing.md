# Lists in Python: Creation, Access, Indexing and Slicing

A list is an ordered, mutable collection used to store multiple values in a single variable.

Lists can contain different data types, allow duplicate values, and can be modified after creation.

## 1. Creating Lists

Lists are created using square brackets `[]`.

### Empty List

```python
numbers = []

print(numbers)
```

**Output:**
```text
[]
```

### List with Values

```python
numbers = [10, 20, 30, 40]

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40]
```

### List with Different Data Types

```python
data = ["John", 25, 85.5, True]

print(data)
```

**Output:**
```text
['John', 25, 85.5, True]
```

### List with Duplicate Values

```python
numbers = [10, 20, 10, 30, 20]

print(numbers)
```

**Output:**
```text
[10, 20, 10, 30, 20]
```

### Nested Lists

A list can contain other lists.

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(matrix)
```

**Output:**
```text
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```

## 2. Accessing List Elements

Each element in a list has an index. You can access an element using its index inside square brackets.

Python uses zero-based indexing.

```python
fruits = ["Apple", "Banana", "Mango", "Orange"]

print(fruits[0])
print(fruits[1])
print(fruits[2])
```

**Output:**
```text
Apple
Banana
Mango
```

| Element | Index |
|---|---:|
| Apple | 0 |
| Banana | 1 |
| Mango | 2 |
| Orange | 3 |

## 3. Positive Indexing

Positive indexing starts from `0` and moves from left to right.

```python
languages = ["Python", "Java", "C++", "JavaScript"]

print(languages[0])
print(languages[2])
print(languages[3])
```

**Output:**
```text
Python
C++
JavaScript
```

## 4. Negative Indexing

Negative indexing starts from `-1` and moves from right to left.

```python
languages = ["Python", "Java", "C++", "JavaScript"]

print(languages[-1])
print(languages[-2])
print(languages[-3])
```

**Output:**
```text
JavaScript
C++
Java
```

| Element | Positive Index | Negative Index |
|---|---:|---:|
| Python | 0 | -4 |
| Java | 1 | -3 |
| C++ | 2 | -2 |
| JavaScript | 3 | -1 |

## 5. Updating List Elements

Lists are mutable, meaning their elements can be changed after creation.

```python
fruits = ["Apple", "Banana", "Mango"]

fruits[1] = "Orange"

print(fruits)
```

**Output:**
```text
['Apple', 'Orange', 'Mango']
```

The element at index `1` is replaced with `"Orange"`.

## 6. List Slicing

Slicing is used to extract a portion of a list.

**Syntax:**

```python
list[start:stop:step]
```

| Parameter | Meaning |
|---|---|
| `start` | Starting index (included) |
| `stop` | Ending index (excluded) |
| `step` | Number of positions to move |

```python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[1:4])
```

**Output:**
```text
[20, 30, 40]
```

The slice starts at index `1` and stops before index `4`.

## 7. Slicing with Different Parameters

### Start and Stop

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
```

**Output:**
```text
[20, 30, 40]
```

### Start Only

When the stop value is omitted, slicing continues to the end.

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[2:])
```

**Output:**
```text
[30, 40, 50]
```

### Stop Only

When the start value is omitted, slicing begins at index `0`.

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[:3])
```

**Output:**
```text
[10, 20, 30]
```

### Copying an Entire List Using Slicing

```python
numbers = [10, 20, 30, 40]

copied = numbers[:]

print(copied)
```

**Output:**
```text
[10, 20, 30, 40]
```

`numbers[:]` creates a shallow copy of the list.

## 8. Slicing with Step

The step determines how many positions to skip between selected elements.

```python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[::2])
print(numbers[::3])
```

**Output:**
```text
[10, 30, 50]
[10, 40]
```

### Selecting Elements with a Specific Range and Step

```python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[1:5:2])
```

**Output:**
```text
[20, 40]
```

The slice starts at index `1`, stops before index `5`, and selects every second element.

## 9. Reversing a List Using Slicing

A negative step moves through the list in reverse order.

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[::-1])
```

**Output:**
```text
[50, 40, 30, 20, 10]
```

### Reverse with a Specific Range

```python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[4:1:-1])
```

**Output:**
```text
[50, 40, 30]
```

The slice starts at index `4` and moves backward, stopping before index `1`.

## 10. Accessing Elements in Nested Lists

Use multiple indexes to access elements inside nested lists.

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(matrix[0])
print(matrix[1][2])
print(matrix[2][0])
```

**Output:**
```text
[1, 2, 3]
6
7
```

- `matrix[0]` accesses the first inner list.
- `matrix[1][2]` accesses the third element of the second inner list.
- `matrix[2][0]` accesses the first element of the third inner list.

## 11. List Length

Use the built-in `len()` function to find the number of elements in a list.

```python
fruits = ["Apple", "Banana", "Mango", "Orange"]

print(len(fruits))
```

**Output:**
```text
4
```

## 12. IndexError

Accessing an index that does not exist raises an `IndexError`.

```python
numbers = [10, 20, 30]

print(numbers[5])
```

**Output:**
```text
IndexError: list index out of range
```

Always ensure the index is within the valid range.

## 13. Important Points

- Lists are ordered collections.
- Lists are mutable.
- Lists allow duplicate elements.
- Lists can contain different data types.
- Positive indexing starts at `0`.
- Negative indexing starts at `-1`.
- Slicing uses `[start:stop:step]`.
- The stop index is excluded.
- A negative step can be used to move backward.
- Slicing creates a new list (a shallow copy).
