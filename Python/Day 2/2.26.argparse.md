# Argparse in Python

`argparse` is a built-in Python module used to handle command-line arguments.

It allows users to pass information to a Python program through the terminal.

## 1. Basic Example

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("name")

args = parser.parse_args()

print(f"Hello, {args.name}!")
```

Run from the terminal:

```bash
python app.py John
```

**Output:**

```text
Hello, John!
```

**How it works:**

- `ArgumentParser()` creates an argument parser.
- `add_argument()` defines an argument.
- `parse_args()` reads the arguments provided through the terminal.
- `args.name` accesses the supplied value.

## 2. Positional Arguments

Positional arguments are required by default. Their values are assigned based on their position.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("name")
parser.add_argument("age", type=int)

args = parser.parse_args()

print("Name:", args.name)
print("Age:", args.age)
```

Run:

```bash
python app.py John 25
```

**Output:**

```text
Name: John
Age: 25
```

Here, `type=int` converts the age argument into an integer.

## 3. Optional Arguments

Optional arguments are generally written with `--` or `-` prefixes.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--name", required=True)
parser.add_argument("--age", type=int, default=18)

args = parser.parse_args()

print(args.name)
print(args.age)
```

Run:

```bash
python app.py --name John --age 25
```

**Output:**

```text
John
25
```

You can also omit the age:

```bash
python app.py --name John
```

**Output:**

```text
John
18
```

The default value is used when the optional argument is not supplied.

## 4. Short and Long Options

You can define both short and long forms for the same argument.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("-n", "--name")

args = parser.parse_args()

print(args.name)
```

Run:

```bash
python app.py -n John
```

Or:

```bash
python app.py --name John
```

Both commands work.

## 5. Help Messages

`argparse` automatically generates a help message.

```python
import argparse

parser = argparse.ArgumentParser(
    description="Student Information Program"
)

parser.add_argument("--name", help="Enter student name")
parser.add_argument("--age", type=int, help="Enter student age")

args = parser.parse_args()
```

Run:

```bash
python app.py --help
```

Example output:

```text
usage: app.py [-h] [--name NAME] [--age AGE]

Student Information Program

options:
  -h, --help   show this help message and exit
  --name NAME  Enter student name
  --age AGE    Enter student age
```

## 6. Boolean Flags with `action`

Use `action="store_true"` when an option should become `True` if provided and `False` otherwise.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--verbose", action="store_true")

args = parser.parse_args()

print(args.verbose)
```

Run:

```bash
python app.py --verbose
```

**Output:**

```text
True
```

Without the flag:

```bash
python app.py
```

**Output:**

```text
False
```

## 7. Restricting Allowed Values with `choices`

Use `choices` to restrict the values a user can provide.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument(
    "--mode",
    choices=["dev", "test", "prod"],
    default="dev"
)

args = parser.parse_args()

print("Mode:", args.mode)
```

Run:

```bash
python app.py --mode prod
```

**Output:**

```text
Mode: prod
```

If the user provides a value outside the allowed choices, argparse displays an error.

## 8. Multiple Values with `nargs`

Use `nargs` to accept multiple values for an argument.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--numbers", nargs="+", type=int)

args = parser.parse_args()

print(args.numbers)
```

Run:

```bash
python app.py --numbers 10 20 30 40
```

**Output:**

```text
[10, 20, 30, 40]
```

`nargs="+"` means one or more values are required when the option is provided.

## 9. Different Use Cases

### Use Case 1: Calculator

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("a", type=float)
parser.add_argument("b", type=float)
parser.add_argument("--operation", choices=["add", "sub", "mul", "div"], default="add")

args = parser.parse_args()

if args.operation == "add":
    print(args.a + args.b)
elif args.operation == "sub":
    print(args.a - args.b)
elif args.operation == "mul":
    print(args.a * args.b)
elif args.operation == "div":
    if args.b == 0:
        parser.error("Cannot divide by zero")
    print(args.a / args.b)
```

Run:

```bash
python calculator.py 10 5 --operation mul
```

**Output:**

```text
50.0
```

### Use Case 2: File Processing

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("filename")

args = parser.parse_args()

with open(args.filename, "r") as file:
    print(file.read())
```

Run:

```bash
python reader.py notes.txt
```

The program reads the filename provided by the user.

### Use Case 3: Application Configuration

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--host", default="localhost")
parser.add_argument("--port", type=int, default=8000)

args = parser.parse_args()

print(f"Server: {args.host}:{args.port}")
```

Run:

```bash
python server.py --host 127.0.0.1 --port 9000
```

**Output:**

```text
Server: 127.0.0.1:9000
```

### Use Case 4: Data Processing

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--input", required=True)
parser.add_argument("--output", required=True)

args = parser.parse_args()

print("Input file:", args.input)
print("Output file:", args.output)
```

Run:

```bash
python process.py --input data.csv --output result.csv.
```
