# Introduction to Regular Expressions in Python

Regular Expressions (RegEx) are patterns used to search, match, validate, and manipulate text.

Python provides the built-in `re` module to work with regular expressions.

## 1. Importing the re Module

```python
import re
```

The `re` module provides functions to work with text patterns.

## 2. What Is a Regular Expression?

A regular expression defines a pattern that Python can search for in a string.

```python
import re

text = "I am learning Python"

result = re.search("Python", text)

print(result)
```

**Output:**

```text
<re.Match object; ...>
```

`re.search()` searches for the first occurrence of the pattern in the string.

## 3. Common Regular Expression Functions

| Function | Purpose |
|---|---|
| `re.search()` | Finds the first match anywhere in the string |
| `re.match()` | Checks for a match at the beginning |
| `re.fullmatch()` | Checks whether the entire string matches |
| `re.findall()` | Returns all matches as a list |
| `re.finditer()` | Returns an iterator of match objects |
| `re.split()` | Splits a string using a pattern |
| `re.sub()` | Replaces matched text |

### search()

Searches for a pattern anywhere in the string.

```python
import re

text = "Python is easy to learn"

result = re.search("easy", text)

if result:
    print("Match found")
```

**Output:**

```text
Match found
```

### match()

Checks whether the pattern matches at the beginning of the string.

```python
import re

text = "Python is powerful"

result = re.match("Python", text)

print(result is not None)
```

**Output:**

```text
True
```

### fullmatch()

Checks whether the entire string matches the pattern.

```python
import re

text = "Python"

result = re.fullmatch("Python", text)

print(result is not None)
```

**Output:**

```text
True
```

### findall()

Returns all occurrences of a pattern as a list.

```python
import re

text = "I like Python and Python is easy"

result = re.findall("Python", text)

print(result)
```

**Output:**

```text
['Python', 'Python']
```

### sub()

Replaces matched text with another value.

```python
import re

text = "I like Java"

result = re.sub("Java", "Python", text)

print(result)
```

**Output:**

```text
I like Python
```

## 4. Basic Regex Characters

Regular expressions use special characters to define patterns.

| Pattern | Meaning |
|---|---|
| `.` | Matches any character except a newline by default |
| `^` | Matches the beginning of a string |
| `$` | Matches the end of a string |
| `*` | Matches zero or more repetitions |
| `+` | Matches one or more repetitions |
| `?` | Matches zero or one repetition |
| `{n}` | Matches exactly n repetitions |
| `{n,m}` | Matches between n and m repetitions |
| `[]` | Matches any one character inside the brackets |
| `()` | Groups expressions |
| `\` | Escapes a special character or introduces a special sequence |
| `|` | Matches either expression on its left or right |

## 5. Character Classes

Character classes help match specific types of characters.

| Pattern | Meaning |
|---|---|
| `[abc]` | Matches a, b, or c |
| `[a-z]` | Matches lowercase letters |
| `[A-Z]` | Matches uppercase letters |
| `[0-9]` | Matches digits |
| `[a-zA-Z]` | Matches uppercase or lowercase letters |
| `[^0-9]` | Matches any character except digits |

Example:

```python
import re

text = "Python123"

result = re.findall("[0-9]", text)

print(result)
```

**Output:**

```text
['1', '2', '3']
```

## 6. Special Sequences

Special sequences begin with a backslash.

| Pattern | Meaning |
|---|---|
| `\d` | Matches a digit |
| `\D` | Matches a non-digit |
| `\w` | Matches a word character (letters, digits, underscore) |
| `\W` | Matches a non-word character |
| `\s` | Matches whitespace |
| `\S` | Matches non-whitespace |
| `\b` | Matches a word boundary |
| `\B` | Matches a position that is not a word boundary |

Example:

```python
import re

text = "Python 123"

print(re.findall(r"\d", text))
print(re.findall(r"\w", text))
print(re.findall(r"\s", text))
```

**Output:**

```text
['1', '2', '3']
['P', 'y', 't', 'h', 'o', 'n', '1', '2', '3']
[' ']
```

## 7. Using Quantifiers

Quantifiers specify how many times a character or group can occur.

| Quantifier | Meaning |
|---|---|
| `*` | Zero or more |
| `+` | One or more |
| `?` | Zero or one |
| `{3}` | Exactly 3 times |
| `{2,5}` | Between 2 and 5 times |
| `{2,}` | At least 2 times |

Example:

```python
import re

text = "aa aaa aaaa"

print(re.findall("a+", text))
print(re.findall("a{3}", text))
```

**Output:**

```text
['aa', 'aaa', 'aaaa']
['aaa', 'aaa']
```

## 8. Why Use Raw Strings (r"")?

Regex patterns often contain backslashes. Python raw strings make these patterns easier to write.

```python
import re

text = "Order number: 12345"

result = re.findall(r"\d+", text)

print(result)
```

**Output:**

```text
['12345']
```

Using `r"\d+"` ensures that Python passes the backslash to the regex engine without interpreting it as a normal Python string escape.

## 9. Practical Use Cases

### Extracting Phone Numbers

```python
import re

text = "Contact: 9876543210"

result = re.findall(r"\d{10}", text)

print(result)
```

**Output:**

```text
['9876543210']
```

### Extracting Email-Like Text

```python
import re

text = "Contact us at support@example.com"

result = re.findall(r"[\w.-]+@[\w.-]+\.\w+", text)

print(result)
```

**Output:**

```text
['support@example.com']
```

This is a simple pattern for demonstration, not a complete email validator.

### Removing Extra Spaces

```python
import re

text = "Python    is     easy"

result = re.sub(r"\s+", " ", text)

print(result)
```

**Output:**

```text
Python is easy
```

### Extracting Numbers from Text

```python
import re

text = "Product price is 500 and quantity is 3"

result = re.findall(r"\d+", text)

print(result)
```

**Output:**

```text
['500', '3']
```

## 10. Important Points

- Import the `re` module before using regular expressions.
- `search()` finds the first match anywhere in the string.
- `match()` checks only from the beginning.
- `fullmatch()` checks the entire string.
- `findall()` returns all matches as a list.
- `sub()` replaces matched text.
- Raw strings (`r"..."`) are commonly used for regex patterns.
- Regex patterns are useful for searching, extracting, validating, and cleaning text.

## 11. Real-World Applications

- **Form validation:** Checking whether input follows a required format.
- **Data cleaning:** Removing unwanted spaces and characters.
- **Log analysis:** Extracting dates, error codes, and IP addresses.
- **Web scraping:** Extracting information from text.
- **Data extraction:** Finding phone numbers, email addresses, and numeric values.
- **Text processing:** Searching and replacing patterns in large text files.
