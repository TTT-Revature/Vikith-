# String Indexing and Slicing in Python

Indexing and slicing are used to access individual characters or extract portions of a string.

## 1. String Indexing

Indexing is used to access a single character from a string.

Python supports two types of indexing:

- Positive indexing
- Negative indexing

### Positive Indexing

Positive indexing starts from `0` (left to right).

```python
text = "PYTHON"

print(text[0])
print(text[1])
print(text[2])
print(text[5])
```

**Output:**
```text
P
Y
T
N
```

### Negative Indexing

Negative indexing starts from `-1` (right to left).

```python
text = "PYTHON"

print(text[-1])
print(text[-2])
print(text[-3])
print(text[-6])
```

**Output:**
```text
N
O
H
P
```

### Index Position Reference

For the string `"PYTHON"`:

| Character | P | Y | T | H | O | N |
|---|---|---|---|---|---|---|
| Positive index | 0 | 1 | 2 | 3 | 4 | 5 |
| Negative index | -6 | -5 | -4 | -3 | -2 | -1 |

**Important:** Accessing an invalid index raises `IndexError`.

```python
text = "Python"

print(text[10])  # IndexError
```

## 2. String Slicing

Slicing is used to extract a portion of a string.

**Syntax:**

```python
string[start:stop:step]
```

| Parameter | Meaning |
|---|---|
| `start` | Starting index (included) |
| `stop` | Ending index (excluded) |
| `step` | Number of positions to move |

### Basic Slicing

```python
text = "PYTHON"

print(text[0:3])
print(text[1:4])
print(text[2:6])
```

**Output:**
```text
PYT
YTH
THON
```

The stop index is always excluded.

## 3. Omitting Start and Stop

You can leave the start or stop value empty.

```python
text = "PYTHON"

print(text[:3])
print(text[2:])
print(text[:])
```

**Output:**
```text
PYT
THON
PYTHON
```

- `text[:3]` – Starts from the beginning.
- `text[2:]` – Goes until the end.
- `text[:]` – Creates a full string slice.

## 4. Using Step in Slicing

The step determines how many positions to move between selected characters.

```python
text = "PYTHON"

print(text[::1])
print(text[::2])
print(text[::3])
```

**Output:**
```text
PYTHON
PTO
PH
```

### Step with Start and Stop

```python
text = "PROGRAMMING"

print(text[0:8:2])
print(text[1:9:2])
```

**Output:**
```text
PORM
RGAM
```

## 5. Reverse a String

A negative step moves through the string backwards.

```python
text = "PYTHON"

print(text[::-1])
```

**Output:**
```text
NOHTYP
```

### Other Negative Step Examples

```python
text = "PYTHON"

print(text[::-2])
print(text[5:1:-1])
print(text[4:0:-1])
```

**Output:**
```text
NOTP
NOHT
OHTY
```

Remember:
- Positive step moves left to right.
- Negative step moves right to left.
- The stop index is excluded in both directions.

## 6. Indexing vs Slicing

| Indexing | Slicing |
|---|---|
| Accesses one character | Extracts multiple characters |
| Uses one index | Uses start, stop and step |
| Invalid index raises `IndexError` | Out-of-range slice boundaries are handled safely |
| Example: `text[0]` | Example: `text[0:3]` |

## 7. Strings Are Immutable

You cannot change an individual character using indexing.

```python
text = "PYTHON"

text[0] = "J"  # TypeError
```

Instead, create a new string using slicing.

```python
text = "PYTHON"

new_text = "J" + text[1:]

print(new_text)
```

**Output:**
```text
JYTHON
```

## 8. Different Practical Use Cases

### Use Case 1: Get the First and Last Character

```python
name = "Python"

first = name[0]
last = name[-1]

print(first)
print(last)
```

**Output:**
```text
P
n
```

### Use Case 2: Reverse a String

```python
word = "madam"

if word == word[::-1]:
    print("Palindrome")
else:
    print("Not a palindrome")
```

**Output:**
```text
Palindrome
```

### Use Case 3: Extract a File Extension

```python
filename = "report.pdf"

extension = filename[-3:]

print(extension)
```

**Output:**
```text
pdf
```

For filenames with variable-length extensions, use `split()` or `pathlib` instead of assuming a fixed number of characters.

### Use Case 4: Mask a Phone Number

```python
phone = "9876543210"

masked = "XXXXXX" + phone[-4:]

print(masked)
```

**Output:**
```text
XXXXXX3210
```

### Use Case 5: Extract a Username

```python
email = "john@gmail.com"

username = email[:email.index("@")]

print(username)
```

**Output:**
```text
john
```

### Use Case 6: Extract a Portion of Text

```python
text = "Python Programming"

result = text[7:18]

print(result)
```

**Output:**
```text
Programming
```

### Use Case 7: Select Every Second Character

```python
text = "ABCDEFGHIJ"

print(text[::2])
```

**Output:**
```text
ACEGI
```

## 9. Important Points to Remember

- Indexing starts at `0`.
- Negative indexing starts at `-1`.
- Slicing follows `[start:stop:step]`.
- The stop position is excluded.
- A positive step moves forward.
- A negative step moves backward.
- `[::-1]` reverses a string.
- Strings are immutable.
- Slicing does not raise `IndexError` when boundaries are outside the string.
