# Parameters and Arguments in Python

Parameters and arguments are used to pass information to functions.

They allow functions to receive different inputs and perform operations using those values.

## 1. Parameters vs Arguments

### Parameters

Parameters are variables declared in a function definition. They receive values when the function is called.

```python
def greet(name):
    print("Hello", name)
```

Here, `name` is a parameter.

### Arguments

Arguments are the actual values supplied when calling a function.

```python
greet("Rahul")
```

Here, `"Rahul"` is an argument.

**Output:**

```text
Hello Rahul
```

| Parameter | Argument |
|---|---|
| Variable in function definition | Value supplied during function call |
| Receives input | Provides input |
| Example: `name` | Example: `"Rahul"` |

## 2. Positional Arguments

Positional arguments are assigned to parameters based on their position.

```python
def student(name, age, course):
    print(name)
    print(age)
    print(course)

student("Rahul", 22, "MCA")
```

**Output:**

```text
Rahul
22
MCA
```

The first argument is assigned to `name`, the second to `age`, and the third to `course`.

### Changing Argument Order

```python
def display(a, b):
    print(a)
    print(b)

display(10, 20)
```

**Output:**

```text
10
20
```

Changing the order of positional arguments changes which parameter receives each value.

## 3. Keyword Arguments

Keyword arguments are passed using parameter names.

```python
def student(name, age, course):
    print(name)
    print(age)
    print(course)

student(course="MCA", name="Rahul", age=22)
```

**Output:**

```text
Rahul
22
MCA
```

Keyword arguments allow us to pass values without following the parameter order.

### Positional vs Keyword Arguments

| Positional | Keyword |
|---|---|
| Uses argument position | Uses parameter name |
| Order matters | Order can change |
| `student("Rahul", 22)` | `student(age=22, name="Rahul")` |

## 4. Default Arguments

A default argument is used when a caller does not provide a value for a parameter.

```python
def greet(name="Guest"):
    print("Hello", name)

greet()
greet("Rahul")
```

**Output:**

```text
Hello Guest
Hello Rahul
```

Here, `"Guest"` is the default value of `name`.

### Multiple Default Arguments

```python
def employee(name, department="IT", city="Chennai"):
    print(name, department, city)

employee("Rahul")
employee("Arun", "HR")
employee("Kiran", "Finance", "Bangalore")
```

**Output:**

```text
Rahul IT Chennai
Arun HR Chennai
Kiran Finance Bangalore
```

### Important Rule

Parameters without default values must come before parameters with default values.

Valid:

```python
def employee(name, department="IT"):
    print(name, department)
```

Invalid:

```python
# SyntaxError
def employee(department="IT", name):
    print(name, department)
```

## 5. Arbitrary Positional Arguments (*args)

Sometimes we do not know how many arguments a function will receive.

Python provides `*args` to accept a variable number of positional arguments.

```python
def add(*args):
    print(args)

add(10, 20, 30, 40)
```

**Output:**

```text
(10, 20, 30, 40)
```

`args` is a tuple containing all the extra positional arguments.

### Using *args for Calculations

```python
def add(*args):
    total = sum(args)
    return total

print(add(10, 20))
print(add(10, 20, 30))
print(add(10, 20, 30, 40))
```

**Output:**

```text
30
60
100
```

The function can accept any number of positional arguments.

### Iterating Through *args

```python
def display(*args):
    for value in args:
        print(value)

display("Python", "Java", "SQL")
```

**Output:**

```text
Python
Java
SQL
```

**Important:** The name `args` is a convention. The `*` is what makes it collect extra positional arguments.

## 6. Arbitrary Keyword Arguments (**kwargs)

Python provides `**kwargs` to accept a variable number of keyword arguments.

```python
def student(**kwargs):
    print(kwargs)

student(name="Rahul", age=22, course="MCA")
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'course': 'MCA'}
```

`kwargs` is a dictionary containing the extra keyword arguments.

### Accessing Values from **kwargs

```python
def student(**kwargs):
    print("Name:", kwargs["name"])
    print("Age:", kwargs["age"])
    print("Course:", kwargs["course"])

student(name="Rahul", age=22, course="MCA")
```

**Output:**

```text
Name: Rahul
Age: 22
Course: MCA
```

### Iterating Through **kwargs

```python
def display(**kwargs):
    for key, value in kwargs.items():
        print(key, ":", value)

display(name="Rahul", age=22, city="Chennai")
```

**Output:**

```text
name : Rahul
age : 22
city : Chennai
```

**Important:** The name `kwargs` is a convention. The `**` is what collects extra keyword arguments into a dictionary.

## 7. Difference Between *args and **kwargs

| Feature | `*args` | `**kwargs` |
|---|---|---|
| Accepts | Extra positional arguments | Extra keyword arguments |
| Stores data as | Tuple | Dictionary |
| Uses | One asterisk `*` | Two asterisks `**` |
| Example | `add(10, 20, 30)` | `student(name="Rahul")` |

## 8. Combining Different Types of Parameters

A function can accept regular parameters, default parameters, `*args` and `**kwargs`.

```python
def example(name, age=22, *args, **kwargs):
    print("Name:", name)
    print("Age:", age)
    print("Extra positional:", args)
    print("Extra keyword:", kwargs)

example(
    "Rahul",
    23,
    "Python",
    "Java",
    city="Chennai",
    course="MCA"
)
```

**Output:**

```text
Name: Rahul
Age: 23
Extra positional: ('Python', 'Java')
Extra keyword: {'city': 'Chennai', 'course': 'MCA'}
```

Here:
- `name` receives `"Rahul"`.
- `age` receives `23`.
- `*args` collects `"Python"` and `"Java"`.
- `**kwargs` collects `city` and `course`.

## 9. Keyword-Only Arguments

Keyword-only arguments must be passed using their parameter names.

We use `*` in the function definition to mark parameters as keyword-only.

```python
def employee(name, *, department):
    print(name, department)

employee("Rahul", department="IT")
```

**Output:**

```text
Rahul IT
```

This is invalid:

```python
# TypeError
employee("Rahul", "IT")
```

The `department` parameter must be supplied as a keyword argument.

### Multiple Keyword-Only Parameters

```python
def employee(name, *, department, city):
    print(name, department, city)

employee(
    "Rahul",
    department="IT",
    city="Chennai"
)
```

**Output:**

```text
Rahul IT Chennai
```

## 10. Positional-Only Arguments

Positional-only parameters must be passed by position, not by keyword.

We use `/` in the function definition to mark positional-only parameters.

```python
def divide(a, b, /):
    return a / b

print(divide(20, 5))
```

**Output:**

```text
4.0
```

This is invalid:

```python
# TypeError
divide(a=20, b=5)
```

Both `a` and `b` must be supplied positionally.

## 11. Parameter Order in Python

Python allows different parameter types, but they must follow specific ordering rules.

A common valid order is:

```python
def example(positional_only, /, normal, *args, keyword_only, **kwargs):
    pass
```

| Symbol | Purpose |
|---|---|
| `/` | Parameters before it are positional-only |
| `*args` | Collects extra positional arguments |
| `*` | Makes following parameters keyword-only |
| `**kwargs` | Collects extra keyword arguments |

Example:

```python
def employee(name, /, department, *skills, city, **details):
    print(name)
    print(department)
    print(skills)
    print(city)
    print(details)

employee(
    "Rahul",
    "IT",
    "Python",
    "Java",
    city="Chennai",
    experience=1
)
```

**Output:**

```text
Rahul
IT
('Python', 'Java')
Chennai
{'experience': 1}
```

## 12. Unpacking Arguments

Python allows us to unpack collections when calling functions.

### Unpacking a List or Tuple Using *

```python
def add(a, b, c):
    return a + b + c

numbers = [10, 20, 30]

print(add(*numbers))
```

**Output:**

```text
60
```

The `*` unpacks the list into three positional arguments.

### Unpacking a Dictionary Using **

```python
def student(name, age, course):
    print(name, age, course)

data = {
    "name": "Rahul",
    "age": 22,
    "course": "MCA"
}

student(**data)
```

**Output:**

```text
Rahul 22 MCA
```

The `**` unpacks dictionary entries into keyword arguments. The dictionary keys must match the function's parameter names.

## 13. Mutable Default Argument Problem

Be careful when using mutable objects such as lists and dictionaries as default parameter values.

Default values are evaluated once when the function is defined, not each time it is called.

### Problematic Example

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("Python"))
print(add_item("Java"))
print(add_item("SQL"))
```

**Output:**

```text
['Python']
['Python', 'Java']
['Python', 'Java', 'SQL']
```

Why does this happen?

The same default list is reused across function calls.

### Recommended Solution

Use `None` as the default and create a new list inside the function.

```python
def add_item(item, items=None):
    if items is None:
        items = []

    items.append(item)
    return items

print(add_item("Python"))
print(add_item("Java"))
print(add_item("SQL"))
```

**Output:**

```text
['Python']
['Java']
['SQL']
```

Each call gets a separate list when no list is supplied.

## 14. Argument Passing and Object References

Python passes object references to function parameters. This is often described as *call by object sharing*.

The effect depends on whether the object is mutable or immutable.

### Example 1: Immutable Object

```python
def change_value(number):
    number = 100

value = 10

change_value(value)

print(value)
```

**Output:**

```text
10
```

The function reassigns its local parameter. It does not change the caller's integer variable.

### Example 2: Mutable Object

```python
def add_item(items):
    items.append(40)

numbers = [10, 20, 30]

add_item(numbers)

print(numbers)
```

**Output:**

```text
[10, 20, 30, 40]
```

The function receives a reference to the same list object and modifies it.

## 15. Important Differences

| Concept | Description |
|---|---|
| Positional arguments | Values assigned based on position |
| Keyword arguments | Values assigned using parameter names |
| Default arguments | Values used when an argument is omitted |
| `*args` | Collects extra positional arguments into a tuple |
| `**kwargs` | Collects extra keyword arguments into a dictionary |
| Keyword-only parameters | Must be supplied by name |
| Positional-only parameters | Must be supplied by position |
| Argument unpacking `*` | Unpacks an iterable into positional arguments |
| Argument unpacking `**` | Unpacks a mapping into keyword arguments |

## 16. Real-World Use Cases

- **Flexible functions:** Accept different numbers of inputs using `*args`.
- **Configuration:** Accept optional settings using `**kwargs`.
- **API development:** Use keyword arguments to make function calls clearer.
- **Data processing:** Pass lists and dictionaries to reusable functions.
- **Reusable libraries:** Use positional-only and keyword-only parameters to control how functions are called.
- **Application development:** Use default arguments for optional settings and values.
