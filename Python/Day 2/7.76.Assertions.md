# Python Assertions

## 1. What Are Assertions?

Assertions are used to test whether a condition is true during program execution.

Python provides the `assert` keyword to check assumptions in code.

If the condition is `True`, the program continues normally.

If the condition is `False`, Python raises an `AssertionError`.

**Syntax:**

```python
assert condition
```

**Example:**

```python
age = 25

assert age >= 18

print("Eligible")
```

**Output:**

```text
Eligible
```

## 2. AssertionError

When an assertion condition is false, Python raises an `AssertionError`.

```python
age = 15

assert age >= 18

print("Eligible")
```

**Output:**

```text
AssertionError
```

The `print()` statement is not executed because the assertion fails.

## 3. Assertions with Error Messages

We can provide a custom message with an assertion.

**Syntax:**

```python
assert condition, "Error message"
```

**Example:**

```python
balance = -500

assert balance >= 0, "Balance cannot be negative"

print("Valid balance")
```

**Output:**

```text
AssertionError: Balance cannot be negative
```

The message explains why the assertion failed.

## 4. Assertions with Variables

Assertions can validate variable values.

```python
marks = 85

assert marks >= 0, "Marks cannot be negative"
assert marks <= 100, "Marks cannot exceed 100"

print("Valid marks:", marks)
```

**Output:**

```text
Valid marks: 85
```

## 5. Assertions Inside Functions

Assertions can check function arguments and internal assumptions.

```python
def calculate_square(number):
    assert isinstance(number, (int, float)), "Number must be numeric"

    return number ** 2


print(calculate_square(5))
```

**Output:**

```text
25
```

If a string is passed:

```python
calculate_square("hello")
```

**Output:**

```text
AssertionError: Number must be numeric
```

## 6. Multiple Assertions

We can write multiple assertions to validate different conditions.

```python
username = "vikith"
password = "python123"
age = 22

assert username != "", "Username cannot be empty"
assert len(password) >= 8, "Password must contain at least 8 characters"
assert age >= 18, "Age must be 18 or above"

print("All validations passed")
```

**Output:**

```text
All validations passed
```

If an assertion fails, execution stops at that assertion. Later assertions are not executed.

## 7. Assertions vs Exception Handling

Assertions and exception handling serve different purposes.

| Assertions | Exception Handling |
|---|---|
| Check assumptions during development | Handle expected runtime errors |
| Use the `assert` keyword | Use `try` and `except` |
| Failure raises `AssertionError` | Handles specific exception types |
| Can be disabled using optimized execution | Used for normal application error handling |
| Not suitable for user input validation | Suitable for user input validation |

**Example using assertion:**

```python
age = 15

assert age >= 18, "Age must be 18 or above"
```

**Example using exception handling:**

```python
age = 15

try:
    if age < 18:
        raise ValueError("Age must be 18 or above")

except ValueError as error:
    print(error)
```

**Output:**

```text
Age must be 18 or above
```

## 8. Disabling Assertions

Python assertions can be disabled when running Python in optimized mode using the `-O` option.

**Normal execution:**

```bash
python main.py
```

**Optimized execution:**

```bash
python -O main.py
```

When optimized mode is enabled, assertion statements are removed and are not evaluated.

Example:

```python
assert 10 > 20, "Condition failed"

print("Program continues")
```

Normal execution:

```text
AssertionError: Condition failed
```

Optimized execution:

```text
Program continues
```

**Important:** Never depend on assertions for essential application validation or security checks because they can be disabled.

## 9. Real-World Use Cases

| Situation | Assertion example |
|---|---|
| Mathematical calculations | Check expected results |
| Function development | Verify internal assumptions |
| Data processing | Check data structure assumptions |
| Algorithm development | Verify intermediate results |
| Testing | Check expected program behavior |

**Example: Checking a Calculation**

```python
def calculate_total(price, quantity):
    total = price * quantity

    assert total >= 0, "Total cannot be negative"

    return total


result = calculate_total(100, 5)

assert result == 500, "Unexpected calculation result"

print("Total:", result)
```

**Output:**

```text
Total: 500
```

## 10. Important Points

- `assert` is a Python keyword.
- Assertions check whether a condition is true.
- A failed assertion raises `AssertionError`.
- Custom messages can be provided after a comma.
- Multiple assertions can be used in a program.
- Assertions can be disabled using `python -O`.
- Do not use assertions for validating user input or enforcing security rules.
- Use `raise` and exception handling for errors that must be handled in normal application execution.

## Quick Summary

- `assert condition` checks whether a condition is true.
- If true, execution continues.
- If false, Python raises `AssertionError`.
- `assert condition, "message"` provides a custom error message.
- `python -O` disables assertions.
- Assertions are mainly useful for debugging and checking internal assumptions.
