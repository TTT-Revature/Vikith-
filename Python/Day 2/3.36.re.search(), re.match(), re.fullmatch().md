# re.search(), re.match(), and re.fullmatch() in Python

Python's `re` module provides three important functions to check whether a regular expression pattern matches a string.

1. `re.search()`
2. `re.match()`
3. `re.fullmatch()`

The main difference is **where the matching happens and how much of the string must match.**

## 1. re.search()

`re.search()` scans the entire string and returns the first match it finds, regardless of its position.

**Syntax:**

```python
re.search(pattern, string)
```

**Example:**

```python
import re

text = "I am learning Python programming"

result = re.search(r"Python", text)

if result:
    print("Match found")
    print(result.group())
else:
    print("No match")
```

**Output:**

```text
Match found
Python
```

Even though `Python` appears in the middle of the string, `re.search()` finds it.

### Finding a Pattern at Different Positions

```python
import re

text = "Hello, Python!"

print(re.search(r"Hello", text).group())
print(re.search(r"Python", text).group())
print(re.search(r"!$", text).group())
```

**Output:**

```text
Hello
Python
!
```

`$` matches the end of the string.

## 2. re.match()

`re.match()` checks for a match only at the beginning of the string.

**Syntax:**

```python
re.match(pattern, string)
```

**Example:**

```python
import re

text = "Python is easy"

result = re.match(r"Python", text)

if result:
    print("Match found")
    print(result.group())
else:
    print("No match")
```

**Output:**

```text
Match found
Python
```

### Pattern Not at the Beginning

```python
import re

text = "I am learning Python"

result = re.match(r"Python", text)

print(result)
```

**Output:**

```text
None
```

Although `Python` exists in the string, `re.match()` does not find it because it is not at the beginning.

## 3. re.fullmatch()

`re.fullmatch()` checks whether the entire string matches the given pattern.

Every character in the string must be covered by the pattern.

**Syntax:**

```python
re.fullmatch(pattern, string)
```

**Example:**

```python
import re

text = "Python"

result = re.fullmatch(r"Python", text)

if result:
    print("Entire string matched")
else:
    print("No complete match")
```

**Output:**

```text
Entire string matched
```

### When Extra Characters Exist

```python
import re

text = "Python programming"

result = re.fullmatch(r"Python", text)

print(result)
```

**Output:**

```text
None
```

The pattern matches only `Python`, but the input contains additional characters. Therefore, the entire string does not match.

## 4. Main Differences

Consider this string:

```python
text = "I love Python"
```

| Function | Pattern | Result | Reason |
|---|---|---|---|
| `re.search()` | `Python` | Match | Finds it anywhere |
| `re.match()` | `Python` | No match | Not at the beginning |
| `re.fullmatch()` | `Python` | No match | Entire string is not `Python` |
| `re.match()` | `I love` | Match | Matches at the beginning |
| `re.fullmatch()` | `I love Python` | Match | Entire string matches |

## 5. Practical Use Cases

### Use Case 1: Search for a Word in Text

Use `re.search()` when the pattern can appear anywhere.

```python
import re

message = "Your order number is 12345"

result = re.search(r"\d+", message)

if result:
    print("Order ID:", result.group())
```

**Output:**

```text
Order ID: 12345
```

### Use Case 2: Check the Beginning of a String

Use `re.match()` when the pattern must appear at the beginning.

```python
import re

filename = "report_2026.pdf"

result = re.match(r"report", filename)

print(result is not None)
```

**Output:**

```text
True
```

### Use Case 3: Validate a Phone Number

Use `re.fullmatch()` when the entire input must follow a specific format.

```python
import re

phone = "9876543210"

result = re.fullmatch(r"[6-9]\d{9}", phone)

if result:
    print("Valid format")
else:
    print("Invalid format")
```

**Output:**

```text
Valid format
```

This checks the basic ten-digit format, not whether the number is active.

## 6. Important Points to Remember

| Function | Matching Behavior |
|---|---|
| `re.search()` | Searches anywhere in the string |
| `re.match()` | Matches only at the beginning |
| `re.fullmatch()` | Requires the entire string to match |

- All three functions return a match object when successful.
- They return `None` when no match is found.
- Use `.group()` to retrieve the matched text.
- Use `.start()` to get the starting index.
- Use `.end()` to get the ending index.
- Use `.span()` to get the start and end indexes as a tuple.

### Match Object Example

```python
import re

text = "I love Python"

result = re.search(r"Python", text)

if result:
    print(result.group())
    print(result.start())
    print(result.end())
    print(result.span())
```

**Output:**

```text
Python
7
13
(7, 13)
```

## 7. When to Use Which Function?

- **`re.search()`** — Finding information anywhere in a paragraph, message, or document.
- **`re.match()`** — Checking whether a string starts with a particular pattern.
- **`re.fullmatch()`** — Validating an entire input such as a phone number, username, or fixed-format code.
