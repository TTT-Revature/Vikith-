# String Methods in Python

String methods are built-in functions used to manipulate, search, validate and format strings.

**Important:** Strings are immutable. String methods return new values instead of modifying the original string.

## 1. Case Conversion Methods

### `upper()`
Converts all characters into uppercase.

```python
text = "hello python"
print(text.upper())
```

Output:
```text
HELLO PYTHON
```

### `lower()`
Converts all characters into lowercase.

```python
text = "HELLO PYTHON"
print(text.lower())
```

Output:
```text
hello python
```

### `capitalize()`
Converts the first character to uppercase and the remaining characters to lowercase.

```python
text = "hello PYTHON"
print(text.capitalize())
```

Output:
```text
Hello python
```

### `title()`
Converts the first character of each word to uppercase.

```python
text = "welcome to python programming"
print(text.title())
```

Output:
```text
Welcome To Python Programming
```

### `swapcase()`
Converts uppercase characters to lowercase and lowercase characters to uppercase.

```python
text = "Hello PYTHON"
print(text.swapcase())
```

Output:
```text
hELLO python
```

## 2. Removing Whitespace

### `strip()`
Removes leading and trailing whitespace.

```python
text = "  Python  "
print(text.strip())
```

Output:
```text
Python
```

### `lstrip()`
Removes whitespace from the left side.

```python
text = "  Python  "
print(text.lstrip())
```

Output:
```text
Python  
```

### `rstrip()`
Removes whitespace from the right side.

```python
text = "  Python  "
print(text.rstrip())
```

Output:
```text
  Python
```

You can also provide specific characters to remove:

```python
text = "***Python***"

print(text.strip("*"))
```

Output:
```text
Python
```

## 3. Searching Methods

### `find()`
Returns the index of the first occurrence of a substring. Returns `-1` if not found.

```python
text = "Python Programming"

print(text.find("Pro"))
print(text.find("Java"))
```

Output:
```text
7
-1
```

### `index()`
Returns the index of the first occurrence of a substring. Raises `ValueError` if not found.

```python
text = "Python Programming"

print(text.index("Pro"))
```

Output:
```text
7
```

### `count()`
Counts how many times a substring occurs.

```python
text = "programming"

print(text.count("m"))
print(text.count("r"))
```

Output:
```text
2
2
```

### `startswith()`
Checks whether a string starts with a specified value.

```python
text = "Python Programming"

print(text.startswith("Python"))
print(text.startswith("Java"))
```

Output:
```text
True
False
```

### `endswith()`
Checks whether a string ends with a specified value.

```python
filename = "report.pdf"

print(filename.endswith(".pdf"))
```

Output:
```text
True
```

## 4. Replacing and Splitting Methods

### `replace()`
Replaces one substring with another.

```python
text = "I love Java"

new_text = text.replace("Java", "Python")

print(new_text)
```

Output:
```text
I love Python
```

You can limit the number of replacements:

```python
text = "apple apple apple"

print(text.replace("apple", "orange", 2))
```

Output:
```text
orange orange apple
```

### `split()`
Splits a string into a list.

```python
text = "Python Java C++"

print(text.split())
```

Output:
```text
['Python', 'Java', 'C++']
```

Using a separator:

```python
text = "apple,banana,mango"

print(text.split(","))
```

Output:
```text
['apple', 'banana', 'mango']
```

### `rsplit()`
Splits from the right side.

```python
text = "apple,banana,mango"

print(text.rsplit(",", 1))
```

Output:
```text
['apple,banana', 'mango']
```

### `partition()`
Splits a string into three parts: before the first separator, the separator itself and after it.

```python
email = "john@gmail.com"

print(email.partition("@"))
```

Output:
```text
('john', '@', 'gmail.com')
```

### `rpartition()`
Performs partitioning using the last occurrence of the separator.

```python
text = "one-two-three"

print(text.rpartition("-"))
```

Output:
```text
('one-two', '-', 'three')
```

### `join()`
Joins elements of an iterable into one string using a separator.

```python
words = ["Python", "is", "powerful"]

print(" ".join(words))
```

Output:
```text
Python is powerful
```

## 5. String Validation Methods

These methods return Boolean values (`True` or `False`).

### `isalpha()`
Returns `True` if all characters are alphabetic and the string is not empty.

```python
print("Python".isalpha())
print("Python123".isalpha())
```

Output:
```text
True
False
```

### `isdigit()`
Checks whether all characters are digits.

```python
print("12345".isdigit())
print("123abc".isdigit())
```

Output:
```text
True
False
```

### `isdecimal()`
Checks whether all characters are decimal characters.

```python
print("12345".isdecimal())
print("²".isdecimal())
```

Output:
```text
True
False
```

### `isnumeric()`
Checks whether all characters are numeric, including some Unicode numeric characters.

```python
print("12345".isnumeric())
print("²".isnumeric())
```

Output:
```text
True
True
```

### `isalnum()`
Checks whether all characters are alphabetic or numeric.

```python
print("Python123".isalnum())
print("Python 123".isalnum())
```

Output:
```text
True
False
```

### `isspace()`
Checks whether all characters are whitespace.

```python
print("   ".isspace())
print("Python".isspace())
```

Output:
```text
True
False
```

### `islower()`
Checks whether all cased characters are lowercase.

```python
print("python".islower())
print("Python".islower())
```

Output:
```text
True
False
```

### `isupper()`
Checks whether all cased characters are uppercase.

```python
print("PYTHON".isupper())
print("Python".isupper())
```

Output:
```text
True
False
```

### `istitle()`
Checks whether the string follows title-case formatting.

```python
print("Hello World".istitle())
print("hello world".istitle())
```

Output:
```text
True
False
```

## 6. Alignment and Formatting Methods

### `center()`
Centers a string within a specified width.

```python
text = "Python"

print(text.center(12, "*"))
```

Output:
```text
***Python***
```

### `ljust()`
Left-aligns a string within a specified width.

```python
text = "Python"

print(text.ljust(10, "-"))
```

Output:
```text
Python----
```

### `rjust()`
Right-aligns a string within a specified width.

```python
text = "Python"

print(text.rjust(10, "-"))
```

Output:
```text
----Python
```

### `zfill()`
Pads a string with zeros on the left.

```python
number = "42"

print(number.zfill(5))
```

Output:
```text
00042
```

## 7. Other Useful String Methods

### `expandtabs()`
Replaces tab characters with spaces.

```python
text = "Python\tJava"

print(text.expandtabs(4))
```

Output:
```text
Python  Java
```

### `removeprefix()`
Removes a specified prefix if the string starts with it.

```python
url = "https://example.com"

print(url.removeprefix("https://"))
```

Output:
```text
example.com
```

### `removesuffix()`
Removes a specified suffix if the string ends with it.

```python
filename = "report.pdf"

print(filename.removesuffix(".pdf"))
```

Output:
```text
report
```

### `encode()`
Converts a string into bytes using a specified encoding.

```python
text = "Python"

result = text.encode("utf-8")

print(result)
print(type(result))
```

Output:
```text
b'Python'
<class 'bytes'>
```

## 8. String Methods Summary

| Category | Methods |
|---|---|
| Case conversion | `upper()`, `lower()`, `capitalize()`, `title()`, `swapcase()` |
| Whitespace | `strip()`, `lstrip()`, `rstrip()` |
| Searching | `find()`, `index()`, `count()`, `startswith()`, `endswith()` |
| Replacing | `replace()` |
| Splitting and joining | `split()`, `rsplit()`, `partition()`, `rpartition()`, `join()` |
| Validation | `isalpha()`, `isdigit()`, `isdecimal()`, `isnumeric()`, `isalnum()`, `isspace()`, `islower()`, `isupper()`, `istitle()` |
| Alignment | `center()`, `ljust()`, `rjust()`, `zfill()` |
| Other | `expandtabs()`, `removeprefix()`, `removesuffix()`, `encode()` |

## 9. Different Practical Use Cases

### Use Case 1: Clean and Normalize User Input

```python
username = "  JOHN DOE  "

username = username.strip().lower()

print(username)
```

Output:
```text
john doe
```

### Use Case 2: Validate an Email's Basic Structure

```python
email = "john@gmail.com"

if "@" in email and email.endswith(".com"):
    print("Basic email format accepted")
else:
    print("Invalid format")
```

Output:
```text
Basic email format accepted
```

This is only a basic check, not complete email validation.

### Use Case 3: Extract Information from a URL

```python
url = "https://example.com"

domain = url.removeprefix("https://")

print(domain)
```

Output:
```text
example.com
```

### Use Case 4: Count Words in a Sentence

```python
sentence = "Python is easy to learn"

words = sentence.split()

print(len(words))
```

Output:
```text
5
```

### Use Case 5: Format a Simple Table

```python
name = "Python"
version = "3.14"

print(name.ljust(15), version.rjust(10))
```

Output:
```text
Python               3.14
```

### Use Case 6: Remove a File Extension

```python
filename = "report.pdf"

name = filename.removesuffix(".pdf")

print(name)
```

Output:
```text
report
```

### Use Case 7: Mask Sensitive Text

```python
phone = "9876543210"

masked = "*" * (len(phone) - 4) + phone[-4:]

print(masked)
```

Output:
```text
******3210
```
