# List Copying and Mutability in Python

Lists are mutable objects in Python. This means their elements can be modified after creation.

Understanding list copying is important because multiple variables can refer to the same list in memory.

## 1. Understanding Mutability

Mutability means an object's value or contents can be changed after it is created.

Lists are mutable.

```python
numbers = [10, 20, 30]

numbers[0] = 100

print(numbers)
```

**Output:**

```text
[100, 20, 30]
```

The original list is modified because lists support changes to their elements.

## 2. Understanding References

When you assign one list variable to another, Python does not create a new list.

Both variables refer to the same list object.

```python
original = [10, 20, 30]

copied = original

copied.append(40)

print(original)
print(copied)
```

**Output:**

```text
[10, 20, 30, 40]
[10, 20, 30, 40]
```

### How Does It Work?

```python
original = [10, 20, 30]
copied = original
```

Both variables point to the same list object.



Therefore, modifying the list through either variable affects the same object.

### Checking Object Identity with id()

The `id()` function returns an object's identity during its lifetime.

```python
original = [10, 20, 30]
copied = original

print(id(original))
print(id(copied))
print(original is copied)
```

**Output:**

```text
Same identity value
Same identity value
True
```

The actual identity values are runtime-dependent, but both calls return the same value because both variables refer to the same object.

## 3. Creating a Shallow Copy

A shallow copy creates a new outer list containing references to the same elements as the original list.

Python provides several ways to create a shallow copy.

### Method 1: Using copy()

```python
original = [10, 20, 30]

copied = original.copy()

copied.append(40)

print(original)
print(copied)
```

**Output:**

```text
[10, 20, 30]
[10, 20, 30, 40]
```

### Method 2: Using Slicing [:]

```python
original = [10, 20, 30]

copied = original[:]

copied.append(40)

print(original)
print(copied)
```

**Output:**

```text
[10, 20, 30]
[10, 20, 30, 40]
```

### Method 3: Using list()

```python
original = [10, 20, 30]

copied = list(original)

copied.append(40)

print(original)
print(copied)
```

**Output:**

```text
[10, 20, 30]
[10, 20, 30, 40]
```

All three methods create a new outer list.

## 4. Understanding Shallow Copy with Nested Lists

A shallow copy creates a new outer list, but nested mutable objects are still shared.

```python
import copy

original = [[1, 2], [3, 4]]

copied = original.copy()

copied[0].append(100)

print(original)
print(copied)
```

**Output:**

```text
[[1, 2, 100], [3, 4]]
[[1, 2, 100], [3, 4]]
```

Why did the original list also change?

Because both outer lists refer to the same inner list objects.



The outer lists are different, but their nested lists are shared.

## 5. Deep Copy

A deep copy creates a new outer list and recursively copies nested objects.

Python provides the `deepcopy()` function in the `copy` module.

```python
import copy

original = [[1, 2], [3, 4]]

copied = copy.deepcopy(original)

copied[0].append(100)

print(original)
print(copied)
```

**Output:**

```text
[[1, 2], [3, 4]]
[[1, 2, 100], [3, 4]]
```

The original list remains unchanged because the nested lists are also copied.

### Deep Copy Memory Concept

<escape>
original ─────> [[1, 2], [3, 4]]

copied ───────> [[1, 2], [3, 4]]
</escape>

The outer and nested lists are separate objects.

## 6. Shallow Copy vs Deep Copy

| Feature | Shallow Copy | Deep Copy |
|---|---|---|
| Outer list | New object | New object |
| Nested lists | Shared references | Recursively copied |
| Nested modifications | Can affect original | Do not affect original |
| Method | `copy()` | `copy.deepcopy()` |
| Performance | Generally faster | Generally more expensive |

## 7. Mutable vs Immutable Objects

Python objects can be classified as mutable or immutable.

### Mutable Objects

Their contents can be changed after creation.

Examples:

- `list`
- `dict`
- `set`
- `bytearray`

```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

**Output:**

```text
[10, 20, 30, 40]
```

### Immutable Objects

Their value cannot be changed after creation.

Examples:

- `int`
- `float`
- `str`
- `tuple`
- `bool`
- `frozenset`
- `bytes`

```python
name = "Python"

name = name + " Programming"

print(name)
```

**Output:**

```text
Python Programming
```

A new string is created and assigned to `name`; the original string object is not modified.

## 8. Assignment vs Shallow Copy vs Deep Copy

```python
import copy

original = [[10, 20], [30, 40]]

assignment = original
shallow = original.copy()
deep = copy.deepcopy(original)

original[0].append(100)

print("Original:", original)
print("Assignment:", assignment)
print("Shallow:", shallow)
print("Deep:", deep)
```

**Output:**

```text
Original: [[10, 20, 100], [30, 40]]
Assignment: [[10, 20, 100], [30, 40]]
Shallow: [[10, 20, 100], [30, 40]]
Deep: [[10, 20], [30, 40]]
```

Explanation:

- `assignment` refers to the same outer list.
- `shallow` has a separate outer list but shares the inner lists.
- `deep` has separate outer and nested lists.

## 9. Important Differences

| Operation | Creates New Outer List? | Nested Mutable Objects Shared? |
|---|---|---|
| `copied = original` | No | Same entire list |
| `original.copy()` | Yes | Yes |
| `original[:]` | Yes | Yes |
| `list(original)` | Yes | Yes |
| `copy.deepcopy(original)` | Yes | No, recursively copied |
