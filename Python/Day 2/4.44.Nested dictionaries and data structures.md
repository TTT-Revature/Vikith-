# Nested Dictionaries and Data Structures in Python

Python allows us to combine data structures such as lists, tuples, sets and dictionaries to organize complex information.

A data structure inside another data structure is called a **nested data structure**.

For example:

- Dictionary inside a dictionary
- List inside a dictionary
- Dictionary inside a list
- List inside a list
- Combinations of lists and dictionaries

These structures are useful for storing real-world data such as student records, employee details, product information and API responses.

## 1. Nested Dictionaries

A nested dictionary is a dictionary that contains another dictionary as its value.

```python
students = {
    "student1": {
        "name": "Rahul",
        "age": 22,
        "course": "MCA"
    },
    "student2": {
        "name": "Arun",
        "age": 23,
        "course": "BCA"
    }
}

print(students)
```

**Output:**

```text
{
    'student1': {'name': 'Rahul', 'age': 22, 'course': 'MCA'},
    'student2': {'name': 'Arun', 'age': 23, 'course': 'BCA'}
}
```

Each student has a separate dictionary containing their details.

### Accessing Nested Values

Use multiple keys to access values inside nested dictionaries.

```python
print(students["student1"]["name"])
print(students["student2"]["course"])
```

**Output:**

```text
Rahul
BCA
```

### Accessing a Complete Nested Dictionary

```python
print(students["student1"])
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'course': 'MCA'}
```

## 2. Adding Items to Nested Dictionaries

We can add new key-value pairs inside an existing nested dictionary.

```python
students = {
    "student1": {
        "name": "Rahul",
        "age": 22
    }
}

students["student1"]["city"] = "Chennai"

print(students)
```

**Output:**

```text
{'student1': {'name': 'Rahul', 'age': 22, 'city': 'Chennai'}}
```

### Adding a New Student

```python
students["student2"] = {
    "name": "Arun",
    "age": 23
}

print(students)
```

**Output:**

```text
{
    'student1': {'name': 'Rahul', 'age': 22, 'city': 'Chennai'},
    'student2': {'name': 'Arun', 'age': 23}
}
```

## 3. Updating Nested Dictionary Values

We can update values by accessing the required nested key.

```python
students = {
    "student1": {
        "name": "Rahul",
        "age": 22,
        "marks": 80
    }
}

students["student1"]["marks"] = 95

print(students["student1"])
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'marks': 95}
```

### Updating Multiple Values

```python
students["student1"].update({
    "age": 23,
    "city": "Chennai"
})

print(students["student1"])
```

**Output:**

```text
{'name': 'Rahul', 'age': 23, 'marks': 95, 'city': 'Chennai'}
```

## 4. Removing Items from Nested Dictionaries

We can delete a nested item using `del` or `pop()`.

### Using del

```python
del students["student1"]["city"]

print(students)
```

### Using pop()

```python
removed_marks = students["student1"].pop("marks")

print(removed_marks)
print(students)
```

**Output:**

```text
95
{'student1': {'name': 'Rahul', 'age': 23}}
```

## 5. Iterating Through Nested Dictionaries

Use nested `for` loops to access all keys and values.

```python
students = {
    "student1": {
        "name": "Rahul",
        "age": 22
    },
    "student2": {
        "name": "Arun",
        "age": 23
    }
}

for student_id, details in students.items():
    print(student_id)

    for key, value in details.items():
        print(key, ":", value)
```

**Output:**

```text
student1
name : Rahul
age : 22
student2
name : Arun
age : 23
```

The outer loop accesses each student, while the inner loop accesses that student's details.

## 6. List of Dictionaries

A list of dictionaries is a common way to store multiple records.

Each dictionary represents one record, and the list stores all records together.

```python
employees = [
    {
        "id": 101,
        "name": "Rahul",
        "salary": 30000
    },
    {
        "id": 102,
        "name": "Arun",
        "salary": 35000
    },
    {
        "id": 103,
        "name": "Kiran",
        "salary": 40000
    }
]

print(employees)
```

### Accessing Records

Use the list index to access a dictionary.

```python
print(employees[0])
print(employees[1]["name"])
print(employees[2]["salary"])
```

**Output:**

```text
{'id': 101, 'name': 'Rahul', 'salary': 30000}
Arun
40000
```

### Updating a Record

```python
employees[0]["salary"] = 45000

print(employees[0])
```

**Output:**

```text
{'id': 101, 'name': 'Rahul', 'salary': 45000}
```

### Adding a New Record

```python
employees.append({
    "id": 104,
    "name": "Priya",
    "salary": 42000
})

print(len(employees))
```

**Output:**

```text
4
```

### Iterating Through a List of Dictionaries

```python
for employee in employees:
    print(employee["name"], employee["salary"])
```

**Output:**

```text
Rahul 45000
Arun 35000
Kiran 40000
Priya 42000
```

## 7. Dictionary Containing Lists

A dictionary can store lists as its values.

```python
student = {
    "name": "Rahul",
    "subjects": ["Python", "Java", "SQL"],
    "marks": [85, 90, 88]
}

print(student["subjects"])
print(student["subjects"][0])
print(student["marks"][1])
```

**Output:**

```text
['Python', 'Java', 'SQL']
Python
90
```

### Adding Items to Nested Lists

```python
student["subjects"].append("R Programming")

print(student["subjects"])
```

**Output:**

```text
['Python', 'Java', 'SQL', 'R Programming']
```

We access the list through its dictionary key and then use normal list methods.

## 8. List Inside a List

A list can contain other lists. This is useful for storing tabular or grouped data.

```python
marks = [
    [85, 90, 88],
    [75, 80, 82],
    [92, 95, 90]
]

print(marks[0])
print(marks[1][2])
print(marks[2][0])
```

**Output:**

```text
[85, 90, 88]
82
92
```

### Iterating Through Nested Lists

```python
for row in marks:
    for mark in row:
        print(mark, end=" ")

    print()
```

**Output:**

```text
85 90 88
75 80 82
92 95 90
```

## 9. Combining Lists and Dictionaries

We can combine multiple data structures to represent more complex information.

```python
company = {
    "name": "Tech Solutions",
    "location": "Chennai",
    "departments": [
        {
            "name": "Development",
            "employees": ["Rahul", "Arun"]
        },
        {
            "name": "Testing",
            "employees": ["Priya", "Kiran"]
        }
    ]
}
```

### Accessing Combined Data

```python
print(company["name"])

print(company["departments"][0]["name"])

print(company["departments"][1]["employees"][0])
```

**Output:**

```text
Tech Solutions
Development
Priya
```

### Understanding the Access Path

```python
company["departments"][0]["employees"][1]
```

Access happens in this order:

1. Access the `departments` key.
2. Select the first department using index `0`.
3. Access its `employees` key.
4. Select the second employee using index `1`.

**Output:**

```text
Arun
```

## 10. Safely Accessing Nested Dictionaries

Directly accessing a missing key can raise a `KeyError`.

The `get()` method helps retrieve values safely.

```python
student = {
    "name": "Rahul",
    "details": {
        "age": 22,
        "city": "Chennai"
    }
}

print(student.get("name"))
print(student.get("details", {}).get("city"))
print(student.get("address", {}).get("city"))
```

**Output:**

```text
Rahul
Chennai
None
```

Here:

- `student.get("details", {})` returns the nested dictionary if it exists.
- If the key is missing, it returns an empty dictionary.
- The next `get()` safely accesses the nested value.

This approach works when the intermediate value is a dictionary or the default empty dictionary.

## 11. Searching in a List of Dictionaries

We can search records using a condition inside a loop.

```python
employees = [
    {"id": 101, "name": "Rahul", "salary": 30000},
    {"id": 102, "name": "Arun", "salary": 35000},
    {"id": 103, "name": "Kiran", "salary": 40000}
]

for employee in employees:
    if employee["id"] == 102:
        print(employee)
```

**Output:**

```text
{'id': 102, 'name': 'Arun', 'salary': 35000}
```

### Filtering Records

We can also retrieve multiple records that satisfy a condition.

```python
high_salary = [
    employee
    for employee in employees
    if employee["salary"] >= 35000
]

print(high_salary)
```

**Output:**

```text
[
    {'id': 102, 'name': 'Arun', 'salary': 35000},
    {'id': 103, 'name': 'Kiran', 'salary': 40000}
]
```

## 12. Sorting a List of Dictionaries

Use `sorted()` with a `key` function to sort records based on a dictionary value.

### Sorting by Salary

```python
employees = [
    {"name": "Rahul", "salary": 30000},
    {"name": "Arun", "salary": 40000},
    {"name": "Kiran", "salary": 35000}
]

result = sorted(
    employees,
    key=lambda employee: employee["salary"]
)

print(result)
```

**Output:**

```text
[
    {'name': 'Rahul', 'salary': 30000},
    {'name': 'Kiran', 'salary': 35000},
    {'name': 'Arun', 'salary': 40000}
]
```

Use `reverse=True` for descending order.

```python
result = sorted(
    employees,
    key=lambda employee: employee["salary"],
    reverse=True
)
```

## 13. Converting Between Data Structures

Python allows us to convert between lists, tuples and dictionaries when the data structure and input format support the conversion.

### Dictionary to List

```python
student = {
    "name": "Rahul",
    "age": 22
}

keys = list(student.keys())
values = list(student.values())
items = list(student.items())

print(keys)
print(values)
print(items)
```

**Output:**

```text
['name', 'age']
['Rahul', 22]
[('name', 'Rahul'), ('age', 22)]
```

### List of Pairs to Dictionary

```python
data = [
    ("name", "Rahul"),
    ("age", 22),
    ("city", "Chennai")
]

student = dict(data)

print(student)
```

**Output:**

```text
{'name': 'Rahul', 'age': 22, 'city': 'Chennai'}
```

## 14. Real-World Example: Student Management

```python
students = [
    {
        "id": 101,
        "name": "Rahul",
        "marks": {
            "Python": 85,
            "Java": 90,
            "SQL": 88
        }
    },
    {
        "id": 102,
        "name": "Arun",
        "marks": {
            "Python": 78,
            "Java": 82,
            "SQL": 80
        }
    }
]

for student in students:
    total = sum(student["marks"].values())
    average = total / len(student["marks"])

    print("Name:", student["name"])
    print("Total:", total)
    print("Average:", round(average, 2))
    print()
```

**Output:**

```text
Name: Rahul
Total: 263
Average: 87.67

Name: Arun
Total: 240
Average: 80.0
```

This example combines:

- A list to store multiple students.
- Dictionaries to store individual student records.
- Nested dictionaries to store subject-wise marks.
- A loop to process each student.
- `sum()` and `len()` to calculate totals and averages.

**Important:** Choose the data structure based on how you need to access and process the data. Use lists for ordered collections of records and dictionaries when you need to retrieve information using meaningful keys.
