# Python Variable Scope

## 1. What Is Variable Scope?

Variable scope defines where a variable can be accessed or used in a Python program.

Python has four main types of scope:

1. Local Scope
2. Enclosing Scope
3. Global Scope
4. Built-in Scope

Python follows the **LEGB rule** to search for variables.

## 2. Local Scope

A variable created inside a function is called a local variable. It can only be accessed inside that function.

```python
def greet():
    message = "Hello Python"
    print(message)

greet()
```

**Output:**

```text
Hello Python
```

Accessing a local variable outside its function causes a `NameError`.

```python
def greet():
    message = "Hello"

greet()
print(message)
```

## 3. Global Scope

A variable created outside all functions has global scope. It can be accessed inside functions and outside them.

```python
name = "Vikith"

def greet():
    print("Hello", name)

greet()
print(name)
```

**Output:**

```text
Hello Vikith
Vikith
```

### Modifying a Global Variable

To assign a new value to a global variable inside a function, use the `global` keyword.

```python
count = 10

def update():
    global count
    count = 20

update()
print(count)
```

**Output:**

```text
20
```

Without `global`, assigning to `count` inside the function creates a local variable instead.

## 4. Enclosing Scope

Enclosing scope occurs when a function is defined inside another function.

The inner function can access variables from the outer function.

```python
def outer():
    message = "Hello from outer"

    def inner():
        print(message)

    inner()

outer()
```

**Output:**

```text
Hello from outer
```

### The `nonlocal` Keyword

Use `nonlocal` to modify a variable belonging to the nearest enclosing function scope.

```python
def outer():
    count = 10

    def inner():
        nonlocal count
        count = 20

    inner()
    print(count)

outer()
```

**Output:**

```text
20
```

`nonlocal` does not refer to global variables. It refers to variables in an enclosing function.

## 5. Built-in Scope

Python provides built-in names that can be accessed without defining them.

Examples:

- `print()`
- `len()`
- `range()`
- `type()`
- `sum()`
- `max()`
- `min()`

```python
numbers = [10, 20, 30]

print(len(numbers))
print(max(numbers))
print(sum(numbers))
```

**Output:**

```text
3
30
60
```

## 6. LEGB Rule

When Python searches for a variable, it follows this order:

| Scope         | Meaning                     |
| ------------- | --------------------------- |
| L – Local     | Inside the current function |
| E – Enclosing | Inside the outer function   |
| G – Global    | At the module level         |
| B – Built-in  | Python's built-in names     |

### Example

```python
name = "Global"

def outer():
    name = "Enclosing"

    def inner():
        name = "Local"
        print(name)

    inner()

outer()
```

**Output:**

```text
Local
```

Python finds the variable in the local scope first, so it doesn't continue searching.

## 7. Local vs Global vs Nonlocal

| Keyword    | Purpose                                                          |
| ---------- | ---------------------------------------------------------------- |
| `global`   | Allows assignment to a global variable                           |
| `nonlocal` | Allows assignment to an enclosing function variable              |
| Neither    | Assignment inside a function creates a local variable by default |

## 8. Important Example: Local and Global Variables

```python
value = 100

def display():
    value = 50
    print("Inside:", value)

display()
print("Outside:", value)
```

**Output:**

```text
Inside: 50
Outside: 100
```

The local variable does not change the global variable because they are separate bindings.

## 9. Variable Scope and Mutable Objects

A function can modify a mutable object passed to it without using `global` or `nonlocal`.

```python
numbers = [10, 20, 30]

def update():
    numbers.append(40)

update()
print(numbers)
```

**Output:**

```text
[10, 20, 30, 40]
```

The function modifies the existing list object. It does not assign a new value to the global variable.

## 10. Common Errors

### Accessing a Local Variable Outside a Function

```python
def test():
    x = 10

print(x)
```

**Error:** `NameError`

### Using a Local Variable Before Assignment

```python
count = 10

def update():
    count = count + 1

update()
```

**Error:** `UnboundLocalError`

Python treats `count` as local because it is assigned inside the function. The local variable is read before it has been assigned.

**Correct approach:**

```python
count = 10

def update():
    global count
    count = count + 1

update()
print(count)
```

**Output:**

```text
11
```

## 11. Scope Reference

| Variable location | Where it can be accessed                      |
| ----------------- | --------------------------------------------- |
| Local             | Inside its function                           |
| Enclosing         | Inside nested functions                       |
| Global            | Throughout the module, subject to scope rules |
| Built-in          | Available through Python's built-in namespace |
