# F-Strings and Formatted Output in Python

Formatted output allows us to display variables and values inside strings in a readable format.

## 1. F-Strings

An **f-string** allows you to insert variables and expressions directly inside a string.

Use `f` before the opening quotation mark and `{}` around variables.

```python
name = "John"
age = 25

print(f"My name is {name} and I am {age} years old.")
```

**Output:**

```text
My name is John and I am 25 years old.
```

## 2. Expressions Inside F-Strings

You can perform calculations directly inside `{}`.

```python
a = 10
b = 20

print(f"Sum: {a + b}")
print(f"Product: {a * b}")
```

**Output:**

```text
Sum: 30
Product: 200
```

You can also use functions and methods.

```python
name = "python"

print(f"Uppercase: {name.upper()}")
print(f"Length: {len(name)}")
```

**Output:**

```text
Uppercase: PYTHON
Length: 6
```

## 3. Formatting Decimal Numbers

Use `.nf` to specify the number of digits after the decimal point.

```python
price = 123.45678

print(f"Price: {price:.2f}")
print(f"Price: {price:.3f}")
```

**Output:**

```text
Price: 123.46
Price: 123.457
```

## 4. Formatting Integers

Use `:d` to format an integer as a decimal integer.

```python
number = 100

print(f"Number: {number:d}")
```

**Output:**

```text
Number: 100
```

## 5. Percentage Formatting

Use `%` to display a decimal value as a percentage.

```python
percentage = 0.8567

print(f"Score: {percentage:.2%}")
```

**Output:**

```text
Score: 85.67%
```

## 6. Thousands Separator

Use `,` to separate thousands.

```python
salary = 1500000

print(f"Salary: {salary:,}")
```

**Output:**

```text
Salary: 1,500,000
```

You can combine formatting options:

```python
amount = 1234567.891

print(f"Amount: {amount:,.2f}")
```

**Output:**

```text
Amount: 1,234,567.89
```
