# sys.argv in Python
## Passing the ARGUMENTS WHILE RUNNING THE PROGRAM
`sys.argv` is a list in Python that stores command-line arguments passed to a Python program.

It is available through the built-in `sys` module.

```python
import sys

print(sys.argv)
```

## 1. Basic Example

Create a file named `app.py`.

```python
import sys

print(sys.argv)
```

Run it from the terminal:

```bash
python app.py
```

**Output:**

```text
['app.py']
```

The first element, `sys.argv[0]`, contains the script name.

## 2. Passing Arguments

You can pass additional values while running the program.

```bash
python app.py John 25
```

**Output:**

```text
['app.py', 'John', '25']
```

Here:

| Expression | Value |
|---|---|
| `sys.argv[0]` | `app.py` |
| `sys.argv[1]` | `John` |
| `sys.argv[2]` | `25` |

**Important:** All command-line arguments are stored as strings.

## 3. Accessing Individual Arguments

```python
import sys

name = sys.argv[1]
age = sys.argv[2]

print("Name:", name)
print("Age:", age)
```

Run:

```bash
python app.py John 25
```

Output:

```text
Name: John
Age: 25
```

## 4. Converting Arguments into Data Types

Since arguments are strings, convert them when performing calculations.

```python
import sys

a = int(sys.argv[1])
b = int(sys.argv[2])

print("Sum:", a + b)
```

Run:

```bash
python app.py 10 20
```

Output:

```text
Sum: 30
```

## 5. Checking the Number of Arguments

Use `len(sys.argv)` to find how many elements are present.

```python
import sys

print("Total arguments:", len(sys.argv))
```

Run:

```bash
python app.py John 25
```

Output:

```text
Total arguments: 3
```

Remember that the script name is also counted.

## 6. Handling Missing Arguments

Accessing an argument that was not provided causes an `IndexError`.

You can check the number of arguments before accessing them.

```python
import sys

if len(sys.argv) < 3:
    print("Please provide name and age")
else:
    name = sys.argv[1]
    age = sys.argv[2]

    print(f"Name: {name}, Age: {age}")
```

## 7. Different Use Cases

### Use Case 1: Simple Calculator

Pass two numbers and an operation through the terminal.

```python
import sys

a = float(sys.argv[1])
operator = sys.argv[2]
b = float(sys.argv[3])

if operator == "+":
    print(a + b)
elif operator == "-":
    print(a - b)
elif operator == "*":
    print(a * b)
elif operator == "/":
    print(a / b)
```

Run:

```bash
python calculator.py 10 + 5
```

Output:

```text
15.0
```

### Use Case 2: File Processing

Pass a filename to a program instead of hardcoding it.

```python
import sys

filename = sys.argv[1]

with open(filename, "r") as file:
    content = file.read()

print(content)
```

Run:

```bash
python read_file.py notes.txt
```

The program reads the file specified in the terminal.

### Use Case 3: Running a Program in Different Modes

Pass a mode to control how the program behaves.

```python
import sys

mode = sys.argv[1]

if mode == "dev":
    print("Development mode")
elif mode == "prod":
    print("Production mode")
else:
    print("Unknown mode")
```

Run:

```bash
python app.py dev
```

Output:

```text
Development mode
```

### Use Case 4: User Customization

Pass a username to personalize program output.

```python
import sys

username = sys.argv[1]

print(f"Welcome back, {username}!")
```

Run:

```bash
python welcome.py Vikith
```

Output:

```text
Welcome back, Vikith!
```

## 8. Important Points

- Import the `sys` module before using `sys.argv`.
- `sys.argv` stores command-line arguments in a list.
- `sys.argv[0]` is the script name.
- Arguments start from index `1`.
- All arguments are strings by default.
- `len(sys.argv)` includes the script name.
- Check argument availability before accessing indexes.
