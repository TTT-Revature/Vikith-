# Python __name__ and if __name__ == "__main__"

## 1. What Is __name__?

`__name__` is a special built-in variable in Python.

Its value depends on how a Python file is executed.

There are two important cases:

1. When a file is executed directly, `__name__` becomes `"__main__"`.
2. When a file is imported into another file, `__name__` usually becomes the module's name.

## 2. When a Python File Runs Directly

Create a file called `demo.py`.

**File: `demo.py`**

```python
print("Hello Python")

print(__name__)
```

Run the file:

```bash
python demo.py
```

**Output:**

```text
Hello Python
__main__
```

Since we executed `demo.py` directly, Python assigned `"__main__"` to `__name__`.

## 3. When a Python File Is Imported

Create two files in the same directory.

**File: `demo.py`**

```python
print("Demo module executed")

print(__name__)

def greet():
    print("Hello from demo")
```

**File: `main.py`**

```python
import demo

demo.greet()
```

Run:

```bash
python main.py
```

**Output:**

```text
Demo module executed
demo
Hello from demo
```

Explanation:

- `main.py` imports `demo`.
- The statements at the top level of `demo.py` execute during the first import.
- Inside `demo.py`, `__name__` is `"demo"` because it is imported as a module.
- The `greet()` function is called from `main.py`.

## 4. What Is if __name__ == "__main__"?

This condition checks whether a Python file is being executed directly.

**Syntax:**

```python
if __name__ == "__main__":
    # Code to execute only when the file runs directly
```

It prevents the code inside the condition from running when the file is imported.

## 5. Example Without the Main Guard

**File: `calculator.py`**

```python
def add(a, b):
    return a + b

print("Calculator started")
```

**File: `main.py`**

```python
import calculator

print(calculator.add(10, 20))
```

**Output:**

```text
Calculator started
30
```

The print statement executes during import.

## 6. Example With the Main Guard

**File: `calculator.py`**

```python
def add(a, b):
    return a + b

if __name__ == "__main__":
    print("Calculator started")
    print(add(10, 20))
```

**File: `main.py`**

```python
import calculator

print(calculator.add(10, 20))
```

Run `calculator.py` directly:

```bash
python calculator.py
```

**Output:**

```text
Calculator started
30
```

Run `main.py`:

```bash
python main.py
```

**Output:**

```text
30
```

Notice the difference:

- Direct execution runs the code inside the main guard.
- Importing the module does not run the code inside the main guard.

## 7. Real-World Example

Consider a project with separate modules for calculations and application execution.

**Project structure:**

```text
project/
│
├── main.py
└── calculator.py
```

**File: `calculator.py`**

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

if __name__ == "__main__":
    print("Testing Calculator")
    print(add(10, 20))
    print(subtract(20, 5))
```

**File: `main.py`**

```python
import calculator

result = calculator.add(100, 200)

print("Application Result:", result)
```

Run `calculator.py`:

**Output:**

```text
Testing Calculator
30
15
```

Run `main.py`:

**Output:**

```text
Application Result: 300
```

The calculator functions can be reused without executing the testing code.

## 8. Difference Between __name__ and __main__

| Term | Meaning |
|---|---|
| `__name__` | Special variable containing the current module's name |
| `"__main__"` | Special string assigned when a file runs as the main program |
| `if __name__ == "__main__":` | Checks whether the file is running as the main program |
