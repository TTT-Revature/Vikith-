# Creating and Working with Strings in Python

A **string** is a sequence of characters enclosed in single quotes, double quotes or triple quotes.

Strings are immutable, meaning their characters cannot be changed directly after creation.

## 1. Creating Strings

```python
# Single quotes
name = 'Python'

# Double quotes
language = "Python"

# Triple quotes
message = """Welcome to Python Programming"""

print(name)
print(language)
print(message)
```

**Output:**
```text
Python
Python
Welcome to Python Programming
```

### Multiline Strings

Triple quotes allow strings to span multiple lines.

```python
message = """Python is easy to learn.
Python is powerful.
Python is widely used."""

print(message)
```

## 2. Accessing Characters (Indexing)

Each character in a string has an index.

- Positive indexing starts from `0`.
- Negative indexing starts from `-1` (last character).

```python
text = "PYTHON"

print(text[0])
print(text[2])
print(text[-1])
print(text[-2])
```

**Output:**
```text
P
T
N
O
```

| Character | P | Y | T | H | O | N |
|---|---|---|---|---|---|---|
| Positive index | 0 | 1 | 2 | 3 | 4 | 5 |
| Negative index | -6 | -5 | -4 | -3 | -2 | -1 |

Accessing an index outside the valid range raises `IndexError`.

## 3. String Slicing

Slicing extracts a portion of a string.

**Syntax:**

```python
string[start:stop:step]
```

- `start`: Starting index (included).
- `stop`: Ending index (excluded).
- `step`: Number of positions to move each time.

```python
text = "PYTHON"

print(text[0:3])
print(text[2:5])
print(text[:4])
print(text[2:])
print(text[::2])
print(text[::-1])
```

**Output:**
```text
PYT
THO
PYTH
THON
PTO
NOHTYP
```

## 4. String Concatenation

Concatenation means joining two or more strings using `+`.

```python
first = "Hello"
second = "World"

result = first + " " + second

print(result)
```

**Output:**
```text
Hello World
```

## 5. String Repetition

Use `*` to repeat a string multiple times.

```python
text = "Python "

print(text * 3)
```

**Output:**
```text
Python Python Python
```

## 6. Checking String Membership

Use `in` and `not in` to check whether a substring exists.

```python
text = "Python Programming"

print("Python" in text)
print("Java" in text)
print("Java" not in text)
```

**Output:**
```text
True
False
True
```

## 7. String Length

Use `len()` to find the number of characters in a string, including spaces.

```python
text = "Hello World"

print(len(text))
```

**Output:**
```text
11
```

## 8. Strings Are Immutable

Strings cannot be modified directly using indexing.

```python
text = "Python"

# This causes TypeError:
text[0] = "J"
```

Instead, create a new string.

```python
text = "Python"

text = "J" + text[1:]

print(text)
```

**Output:**
```text
Jython
```

The original string was not modified. A new string was created and assigned to `text`.

## 9. Comparing Strings

Strings can be compared using comparison operators.

```python
print("Python" == "Python")
print("Python" != "Java")
print("apple" < "banana")
```

**Output:**
```text
True
True
True
```

String comparisons are lexicographical and case-sensitive, based on Unicode code points.

## 10. Iterating Through a String

You can use a `for` loop to access each character.

```python
text = "Python"

for char in text:
    print(char)
```

**Output:**
```text
P
y
t
h
o
n
```

## 11. Useful String Methods

| Method | Purpose |
|---|---|
| `upper()` | Converts to uppercase |
| `lower()` | Converts to lowercase |
| `title()` | Capitalizes each word |
| `capitalize()` | Capitalizes the first character |
| `swapcase()` | Reverses character casing |
| `strip()` | Removes leading and trailing whitespace |
| `lstrip()` | Removes leading whitespace |
| `rstrip()` | Removes trailing whitespace |
| `replace()` | Replaces a substring |
| `split()` | Splits a string into a list |
| `join()` | Joins iterable strings |
| `find()` | Returns the first matching index, or `-1` |
| `index()` | Returns the first matching index, or raises `ValueError` |
| `count()` | Counts occurrences |
| `startswith()` | Checks the starting substring |
| `endswith()` | Checks the ending substring |
| `isalpha()` | Checks whether all characters are alphabetic |
| `isdigit()` | Checks whether all characters are digits |
| `isalnum()` | Checks whether all characters are alphanumeric |
| `isspace()` | Checks whether all characters are whitespace |

### Examples

```python
text = "  python programming  "

print(text.upper())
print(text.lower())
print(text.title())
print(text.strip())
print(text.replace("python", "Java"))
```

**Output:**
```text
  PYTHON PROGRAMMING  
  python programming  
  Python Programming
python programming
  Java programming  
```

## 12. Different Practical Use Cases

### Use Case 1: Reverse a String

```python
name = "Python"

reversed_name = name[::-1]

print(reversed_name)
```

**Output:**
```text
nohtyP
```

### Use Case 2: Count Characters

```python
text = "programming"

print("Total characters:", len(text))
print("Occurrences of m:", text.count("m"))
```

**Output:**
```text
Total characters: 11
Occurrences of m: 2
```

### Use Case 3: Clean User Input

```python
email = "  john@gmail.com  "

email = email.strip().lower()

print(email)
```

**Output:**
```text
john@gmail.com
```

### Use Case 4: Extract Username from Email

```python
email = "john@gmail.com"

username = email.split("@")[0]

print(username)
```

**Output:**
```text
john
```

### Use Case 5: Check a File Extension

```python
filename = "report.pdf"

if filename.endswith(".pdf"):
    print("PDF file")
else:
    print("Other file")
```

**Output:**
```text
PDF file
```

### Use Case 6: Join List Elements into a String

```python
words = ["Python", "is", "powerful"]

sentence = " ".join(words)

print(sentence)
```

**Output:**
```text
Python is powerful
```

### Use Case 7: Count Words

```python
sentence = "Python is easy to learn"

words = sentence.split()

print("Word count:", len(words))
```

**Output:**
```text
Word count: 5
```
