

# Python Dataclasses

## 1. What are Dataclasses?

A dataclass is a special type of class provided by Python's built-in `dataclasses` module.

It reduces boilerplate code by automatically generating commonly used methods such as:

- `__init__()` – Initializes object attributes.
- `__repr__()` – Provides a readable object representation.
- `__eq__()` – Compares objects based on their fields.

Dataclasses are especially useful when a class mainly stores data.

## 2. Creating a Basic Dataclass

Use the `@dataclass` decorator.

```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    age: int
    course: str


student = Student("Vikith", 24, "MCA")

print(student)
print(student.name)
print(student.age)
```

**Output:**
```text
Student(name='Vikith', age=24, course='MCA')
Vikith
24
```

**Explanation:**
- `@dataclass` automatically generates the constructor.
- Type hints define the fields.
- Objects can be created without manually writing `__init__()`.
- Python automatically generates a useful representation.

## 3. Dataclass vs Normal Class

### Normal Class

```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary


emp = Employee("John", 50000)

print(emp.name)
```

### Dataclass

```python
from dataclasses import dataclass

@dataclass
class Employee:
    name: str
    salary: int


emp = Employee("John", 50000)

print(emp)
```

**Output:**
```text
Employee(name='John', salary=50000)
```

Dataclasses reduce repetitive code when creating classes that primarily hold data.

## 4. Default Values in Dataclasses

You can assign default values to fields.

```python
from dataclasses import dataclass

@dataclass
class Employee:
    name: str
    department: str = "IT"
    salary: int = 30000


emp1 = Employee("John")
emp2 = Employee("David", "HR", 40000)

print(emp1)
print(emp2)
```

**Output:**
```text
Employee(name='John', department='IT', salary=30000)
Employee(name='David', department='HR', salary=40000)
```

**Important:** Fields without default values must come before fields with default values.

## 5. Using `field()`

The `field()` function provides additional control over individual dataclass fields.

```python
from dataclasses import dataclass, field

@dataclass
class Student:
    name: str
    subjects: list = field(default_factory=list)


s1 = Student("John")
s2 = Student("David")

s1.subjects.append("Python")

print(s1.subjects)
print(s2.subjects)
```

**Output:**
```text
['Python']
[]
```

**Why use `default_factory`?**

Using a mutable object such as a list directly as a shared default is unsafe. `default_factory=list` creates a separate list for every object.

## 6. Automatically Generated Methods

By default, dataclasses generate several methods.

```python
from dataclasses import dataclass

@dataclass
class Product:
    name: str
    price: int


p1 = Product("Laptop", 50000)
p2 = Product("Laptop", 50000)

print(p1)
print(p1 == p2)
```

**Output:**
```text
Product(name='Laptop', price=50000)
True
```

| Method | Purpose |
|---|---|
| `__init__()` | Initializes fields |
| `__repr__()` | Displays object representation |
| `__eq__()` | Compares field values |

These methods are generated automatically unless configured otherwise.

## 7. Customizing Dataclass Behavior

The `@dataclass` decorator supports different options.

### `frozen=True`

Makes instances immutable through normal attribute assignment.

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Employee:
    name: str
    salary: int


emp = Employee("John", 50000)

# emp.salary = 60000
# Raises FrozenInstanceError
```

### `order=True`

Generates comparison methods such as `<`, `<=`, `>` and `>=`, comparing fields in their declaration order.

```python
from dataclasses import dataclass

@dataclass(order=True)
class Student:
    marks: int
    name: str


s1 = Student(80, "John")
s2 = Student(90, "David")

print(s1 < s2)
```

**Output:**
```text
True
```

The comparison starts with `marks`. If the first fields are equal, Python compares the next fields.

### `repr=False`

Excludes a field from the generated representation.

```python
from dataclasses import dataclass, field

@dataclass
class User:
    name: str
    password: str = field(repr=False)


user = User("John", "secret123")

print(user)
```

**Output:**
```text
User(name='John')
```

This only hides the field from the generated representation; it does not secure or encrypt the value.

## 8. `__post_init__()` Method

The `__post_init__()` method runs automatically after the generated `__init__()` method.

It is useful for additional initialization or validation.

```python
from dataclasses import dataclass

@dataclass
class Employee:
    name: str
    salary: int

    def __post_init__(self):
        if self.salary < 0:
            raise ValueError("Salary cannot be negative")


emp = Employee("John", 50000)

print(emp)
```

**Output:**
```text
Employee(name='John', salary=50000)
```

If a negative salary is provided, a `ValueError` is raised.

## 9. `asdict()` and `astuple()`

The `dataclasses` module provides functions to convert dataclass objects into dictionaries and tuples.

```python
from dataclasses import dataclass, asdict, astuple

@dataclass
class Student:
    name: str
    age: int
    course: str


student = Student("Vikith", 24, "MCA")

print(asdict(student))
print(astuple(student))
```

**Output:**
```text
{'name': 'Vikith', 'age': 24, 'course': 'MCA'}
('Vikith', 24, 'MCA')
```

- `asdict()` converts a dataclass instance into a dictionary.
- `astuple()` converts a dataclass instance into a tuple.

Both functions recursively convert nested dataclasses and supported containers.

## 10. `replace()` Function

The `replace()` function creates a new dataclass object with selected fields changed.

```python
from dataclasses import dataclass, replace

@dataclass
class Employee:
    name: str
    salary: int


emp1 = Employee("John", 50000)

emp2 = replace(emp1, salary=60000)

print(emp1)
print(emp2)
```

**Output:**
```text
Employee(name='John', salary=50000)
Employee(name='John', salary=60000)
```

The original object remains unchanged.

## 11. Important Dataclass Options

| Option | Purpose |
|---|---|
| `init=True` | Generates `__init__()` |
| `repr=True` | Generates `__repr__()` |
| `eq=True` | Generates `__eq__()` |
| `order=False` | Controls ordering methods |
| `frozen=False` | Controls normal attribute assignment |
| `slots=False` | Controls whether slots are generated |
| `kw_only=False` | Controls whether fields are keyword-only |

Example:

```python
@dataclass(frozen=True, order=True)
class Product:
    price: int
    name: str
```

## 12. Dataclass vs Normal Class

| Feature | Normal Class | Dataclass |
|---|---|---|
| Constructor | Usually written manually | Generated automatically |
| `__repr__()` | Usually written manually | Generated automatically |
| `__eq__()` | Usually written manually | Generated automatically |
| Default values | Supported | Supported |
| Type hints | Optional | Commonly used to declare fields |
| Best suited for | General object behavior | Primarily storing data |

**Note:** Dataclasses do not enforce type hints at runtime. They are mainly used for documentation, editor support, and static type checking.

## 13. Real-World Use Cases

- **Student records:** Store student names, ages, marks, and courses.
- **Employee management:** Store employee details and salary information.
- **API responses:** Represent structured data returned by APIs.
- **Configuration:** Store application settings.
- **Data processing:** Represent structured records before converting them into dictionaries or tuples.
