# Positional, Keyword and Default Arguments in Python

Arguments are values passed to a function when calling it. Python provides different ways to pass arguments to parameters.

The three commonly used types are:

1. Positional arguments
2. Keyword arguments
3. Default arguments

## 1. Positional Arguments

Positional arguments are assigned to function parameters based on their position.

### Example

```python
def student(name, age, course):
    print("Name:", name)
    print("Age:", age)
    print("Course:", course)

student("Rahul", 22, "MCA")
```

**Output:**

```text
Name: Rahul
Age: 22
Course: MCA
```

### How It Works

```python
def student(name, age, course):
    pass

student("Rahul", 22, "MCA")
```

| Parameter | Argument |
|---|---|
| `name` | `"Rahul"` |
| `age` | `22` |
| `course` | `"MCA"` |

Python assigns values according to their positions.

### Changing the Order

```python
def display(a, b):
    print("a:", a)
    print("b:", b)

display(100, 200)
display(200, 100)
```

**Output:**

```text
a: 100
b: 200
a: 200
b: 100
```

Changing the argument order changes the values received by the parameters.

### Too Many or Too Few Positional Arguments

```python
def add(a, b):
    print(a + b)

add(10, 20)
```

**Output:**

```text
30
```

Too few arguments:

```python
add(10)
```

**Error:**

```text
TypeError: missing required positional argument
```

Too many arguments:

```python
add(10, 20, 30)
```

**Error:**

```text
TypeError: takes 2 positional arguments but 3 were given
```

The function expects exactly two arguments.

## 2. Keyword Arguments

Keyword arguments are passed using parameter names.

They allow us to specify which value belongs to which parameter.

### Example

```python
def student(name, age, course):
    print("Name:", name)
    print("Age:", age)
    print("Course:", course)

student(name="Rahul", age=22, course="MCA")
```

**Output:**

```text
Name: Rahul
Age: 22
Course: MCA
```

### Changing the Order

Keyword arguments do not depend on their order.

```python
def student(name, age, course):
    print(name, age, course)

student(course="MCA", age=22, name="Rahul")
```

**Output:**

```text
Rahul 22 MCA
```

Python matches the values using parameter names.

### Using Keyword Arguments Partially

We can provide some arguments positionally and others using keywords.

```python
def employee(name, salary, city):
    print(name, salary, city)

employee("Rahul", salary=30000, city="Chennai")
```

**Output:**

```text
Rahul 30000 Chennai
```

Here:

- `"Rahul"` is assigned positionally.
- `salary=30000` is a keyword argument.
- `city="Chennai"` is a keyword argument.

### Important Rule

Positional arguments must come before keyword arguments.

Valid:

```python
employee("Rahul", salary=30000, city="Chennai")
```

Invalid:

```python
# SyntaxError
employee(name="Rahul", 30000, city="Chennai")
```

### Duplicate Argument Assignment

A parameter cannot receive two values.

```python
def student(name, age):
    print(name, age)

student("Rahul", name="Arun", age=22)
```

**Error:**

```text
TypeError: multiple values for argument 'name'
```

Here, `name` receives both `"Rahul"` and `"Arun"`.

## 3. Default Arguments

Default arguments allow us to define predefined values for parameters.

If an argument is not supplied, Python uses the default value.

### Example

```python
def greet(name="Guest"):
    print("Hello", name)

greet()
greet("Rahul")
```

**Output:**

```text
Hello Guest
Hello Rahul
```

Here:

- `"Guest"` is the default value.
- When no argument is passed, `"Guest"` is used.
- When `"Rahul"` is passed, it replaces the default value.

### Multiple Default Arguments

```python
def employee(name, department="IT", city="Chennai"):
    print("Name:", name)
    print("Department:", department)
    print("City:", city)

employee("Rahul")
```

**Output:**

```text
Name: Rahul
Department: IT
City: Chennai
```

### Overriding Default Values

We can override default values using positional or keyword arguments.

```python
def employee(name, department="IT", city="Chennai"):
    print(name, department, city)

employee("Rahul", "HR")
employee("Arun", city="Bangalore")
employee("Kiran", "Finance", "Mumbai")
```

**Output:**

```text
Rahul HR Chennai
Arun IT Bangalore
Kiran Finance Mumbai
```

## 4. Rules for Default Arguments

Parameters with default values must come after parameters without default values.

### Valid Function Definition

```python
def student(name, age, course="MCA"):
    print(name, age, course)

student("Rahul", 22)
```

**Output:**

```text
Rahul 22 MCA
```

### Invalid Function Definition

```python
# SyntaxError
def student(name="Rahul", age):
    print(name, age)
```

A required parameter cannot follow a default parameter in this type of function definition.

## 5. Combining Positional, Keyword and Default Arguments

All three can be used together.

```python
def student(name, age, course="MCA"):
    print("Name:", name)
    print("Age:", age)
    print("Course:", course)

student("Rahul", 22)
student("Arun", 23, "BCA")
student("Kiran", age=24)
student(name="Priya", age=22, course="MCA")
```

**Output:**

```text
Name: Rahul
Age: 22
Course: MCA

Name: Arun
Age: 23
Course: BCA

Name: Kiran
Age: 24
Course: MCA

Name: Priya
Age: 22
Course: MCA
```

Explanation:

| Function Call | Argument Types |
|---|---|
| `student("Rahul", 22)` | Positional + default |
| `student("Arun", 23, "BCA")` | Positional |
| `student("Kiran", age=24)` | Positional + keyword + default |
| `student(name="Priya", age=22, course="MCA")` | Keyword |

## 6. Real-World Example: Employee Details

```python
def employee(name, salary, department="IT", city="Chennai"):
    print("Employee:", name)
    print("Salary:", salary)
    print("Department:", department)
    print("City:", city)
    print()

employee("Rahul", 30000)

employee(
    "Arun",
    35000,
    department="HR"
)

employee(
    name="Kiran",
    salary=40000,
    department="Finance",
    city="Bangalore"
)
```

**Output:**

```text
Employee: Rahul
Salary: 30000
Department: IT
City: Chennai

Employee: Arun
Salary: 35000
Department: HR
City: Chennai

Employee: Kiran
Salary: 40000
Department: Finance
City: Bangalore
```

This example demonstrates how default values reduce the need to pass every argument during each function call.

## 7. Important Differences

| Feature | Positional | Keyword | Default |
|---|---|---|---|
| Assignment | Based on position | Based on parameter name | Used when argument is omitted |
| Order matters | Yes | No | Depends on supplied arguments |
| Required | Usually, unless parameter has a default | Usually, unless parameter has a default | No |
| Example | `greet("Rahul")` | `greet(name="Rahul")` | `greet()` |
