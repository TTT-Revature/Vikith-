

# Python Environment Variables

## 1. What Are Environment Variables?

Environment variables are key-value pairs stored outside a program that provide configuration information to applications.

They allow programs to access system-level or application-specific settings without hardcoding those values inside the source code.

Common examples include:

- Database connection details
- API keys
- Application configuration
- File paths
- Environment settings such as development and production

### Example

```text
API_KEY=abc123
DATABASE_HOST=localhost
APP_ENV=development
```

Here:
- `API_KEY` is the variable name.
- `abc123` is its value.

## 2. Why Do We Use Environment Variables?

Consider an application that connects to a database.

Hardcoding credentials is not recommended:

```python
database_password = "mypassword123"
```

Instead, we can store the password in an environment variable and retrieve it when needed.

```python
import os

database_password = os.getenv("DB_PASSWORD")
```

**Benefits:**

- Keeps sensitive configuration outside source code.
- Makes applications easier to configure.
- Allows different settings for development and production.
- Reduces the need to modify code when configuration changes.

**Important:** Environment variables help keep secrets out of source code, but they are not automatically encrypted. Access to the environment must still be protected.

## 3. Accessing Environment Variables Using os

Python provides the built-in `os` module to access environment variables.

```python
import os
```

Use `os.environ` or `os.getenv()` to retrieve environment variables.

### Using os.environ

```python
import os

username = os.environ["USERNAME"]

print(username)
```

**Possible Output:**

```text
Vikith
```

The output depends on the environment variable configured on the system.

**Important:** If the requested variable does not exist, `os.environ["USERNAME"]` raises a `KeyError`.

### Using os.getenv()

```python
import os

username = os.getenv("USERNAME")

print(username)
```

If the variable does not exist, `os.getenv()` returns `None` by default.

## 4. os.environ vs os.getenv()

| Feature | `os.environ` | `os.getenv()` |
|---|---|---|
| Type | Environment mapping | Function |
| Access | `os.environ["KEY"]` | `os.getenv("KEY")` |
| Missing variable | Raises `KeyError` | Returns `None` by default |
| Default value | Use `.get()` | Pass a default argument |
| Modify variables | Yes | No, retrieval only |

### Providing Default Values

Using `os.getenv()`:

```python
import os

app_env = os.getenv("APP_ENV", "development")

print(app_env)
```

If `APP_ENV` is not defined:

```text
development
```

Using `os.environ.get()`:

```python
import os

app_env = os.environ.get("APP_ENV", "development")

print(app_env)
```

Both approaches allow us to provide a fallback value.

## 5. Setting Environment Variables in Python

Use `os.environ` to set an environment variable for the current process.

```python
import os

os.environ["APP_ENV"] = "development"

print(os.getenv("APP_ENV"))
```

**Output:**

```text
development
```

**Important:** Variables set this way are available to the current Python process and its child processes. They do not permanently modify your operating system's environment variables.

### Updating an Environment Variable

```python
import os

os.environ["APP_ENV"] = "development"

os.environ["APP_ENV"] = "production"

print(os.getenv("APP_ENV"))
```

**Output:**

```text
production
```

### Deleting an Environment Variable

Use `del` to remove an environment variable from the current process environment.

```python
import os

os.environ["APP_ENV"] = "development"

del os.environ["APP_ENV"]

print(os.getenv("APP_ENV"))
```

**Output:**

```text
None
```

## 6. Environment Variables in Windows

Environment variables can also be configured outside Python.

### Using Command Prompt (Temporary)

```cmd
set APP_ENV=development
```

Run Python from the same Command Prompt session to access it.

```python
import os

print(os.getenv("APP_ENV"))
```

**Output:**

```text
development
```

The variable set using `set` is temporary and applies to that Command Prompt session and its child processes.

### Using PowerShell (Temporary)

```powershell
$env:APP_ENV = "development"
```

Access it in Python:

```python
import os

print(os.getenv("APP_ENV"))
```

**Output:**

```text
development
```

### Permanent Environment Variables

Windows also allows environment variables to be configured permanently through:

1. Open Start Menu.
2. Search for **Edit the system environment variables**.
3. Open Environment Variables.
4. Add a new User variable or System variable.
5. Save the changes.

Newly opened terminals and applications can access the updated variables.

## 7. Using .env Files

A `.env` file is a text file used to store application environment variables.

It is commonly used in Python projects to manage configuration.

### Example: .env

```env
APP_ENV=development
DATABASE_HOST=localhost
DATABASE_USER=root
DATABASE_PASSWORD=mysecretpassword
API_KEY=your_api_key
```

Python does not automatically load `.env` files.

A commonly used external package is `python-dotenv`.

### Installing python-dotenv

```bash
pip install python-dotenv
```

### Loading Environment Variables

```python
import os
from dotenv import load_dotenv

load_dotenv()

app_env = os.getenv("APP_ENV")
database_host = os.getenv("DATABASE_HOST")

print(app_env)
print(database_host)
```

**Output:**

```text
development
localhost
```

`load_dotenv()` reads the `.env` file and loads its values into the process environment.

## 8. Using Environment Variables for API Keys

API keys should not be hardcoded into application source code.

### Incorrect Approach

```python
api_key = "123456789abcdef"
```

### Recommended Approach

Store the key in an environment variable:

```env
API_KEY=your_secret_api_key
```

Retrieve it in Python:

```python
import os
from dotenv import load_dotenv

load_dotenv()

api_key = os.getenv("API_KEY")

if not api_key:
    raise ValueError("API_KEY is not configured")

print("API key loaded successfully")
```

**Important:**
- Never upload real API keys or passwords to public GitHub repositories.
- Add `.env` to `.gitignore`.
- Do not print secrets in application logs.
- Rotate exposed credentials if they are accidentally published.

### Example .gitignore

```gitignore
.env
```

This prevents Git from tracking the `.env` file when it is not already tracked.

## 9. Environment Variables in Development and Production

Applications often use different configurations depending on where they run.

### Development Environment

```env
APP_ENV=development
DEBUG=true
DATABASE_HOST=localhost
```

### Production Environment

```env
APP_ENV=production
DEBUG=false
DATABASE_HOST=production-db.example.com
```

Python can read the configuration:

```python
import os

environment = os.getenv("APP_ENV", "development")
debug = os.getenv("DEBUG", "false").lower() == "true"

print("Environment:", environment)
print("Debug:", debug)
```

**Possible Output:**

```text
Environment: development
Debug: True
```

Environment variable values are strings, so convert them when you need Boolean or numeric values.

## 10. Important Points

- Environment variables are key-value pairs used for application configuration.
- Python uses the built-in `os` module to access them.
- `os.environ["KEY"]` retrieves a variable and raises `KeyError` if missing.
- `os.getenv("KEY")` returns `None` if the variable is missing.
- `os.getenv("KEY", "default")` provides a fallback value.
- `os.environ["KEY"] = "value"` sets a variable for the current process.
- `del os.environ["KEY"]` removes a variable from the current process.
- `.env` files are commonly used to store local application configuration.
- `python-dotenv` is an external package used to load `.env` files.
- Environment variables are strings and may need type conversion.
- Keep `.env` files and secrets out of public repositories.
