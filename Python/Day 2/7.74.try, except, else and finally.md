# Python Exception Handling: try, except, else, and finally

## 1. What Is Exception Handling?

Exception handling is used to handle runtime errors without abruptly terminating the program.

An exception occurs when Python encounters an error during program execution.

Example without exception handling:

```python
a = 10
b = 0

result = a / b
print(result)
```

**Output:**
```text
ZeroDivisionError: division by zero
```

The program stops before executing the next statement.

## 2. try and except

- `try`: Contains code that might generate an exception.
- `except`: Handles the exception if it occurs.

**Syntax:**

```python
try:
    # Code that may cause an error
except:
    # Code to handle the error
```

**Example:**

```python
try:
    a = 10
    b = 0
    result = a / b
    print(result)

except:
    print("Something went wrong")
```

**Output:**
```text
Something went wrong
```

## 3. Handling Specific Exceptions

Instead of using a general `except`, we can handle specific exception types.

```python
try:
    number = int(input("Enter a number: "))
    result = 100 / number
    print(result)

except ValueError:
    print("Please enter a valid number")

except ZeroDivisionError:
    print("Cannot divide by zero")
```

**Possible outputs:**

```text
Enter a number: abc
Please enter a valid number
```

```text
Enter a number: 0
Cannot divide by zero
```

Common exception types:

| Exception | Meaning |
|---|---|
| `ValueError` | Invalid value |
| `TypeError` | Operation on an incompatible type |
| `ZeroDivisionError` | Division by zero |
| `IndexError` | List or sequence index out of range |
| `KeyError` | Dictionary key not found |
| `NameError` | Variable name not defined |
| `FileNotFoundError` | File does not exist |
| `AttributeError` | Attribute does not exist |
| `ImportError` | Import operation fails |

## 4. Using `as` to Access Exception Details

We can use `as` to store the exception object in a variable and display its message.

```python
try:
    result = 10 / 0

except ZeroDivisionError as error:
    print("Error:", error)
```

**Output:**
```text
Error: division by zero
```

## 5. Multiple Exceptions in One except Block

We can handle multiple exception types using a tuple.

```python
try:
    number = int(input("Enter a number: "))
    result = 100 / number
    print(result)

except (ValueError, ZeroDivisionError) as error:
    print("Error:", error)
```

## 6. The `else` Block

The `else` block executes only when the `try` block completes without an exception.

```python
try:
    number = int(input("Enter a number: "))
    result = 100 / number

except ValueError:
    print("Invalid input")

except ZeroDivisionError:
    print("Cannot divide by zero")

else:
    print("Result:", result)
    print("Operation completed successfully")
```

**Output:**
```text
Enter a number: 5
Result: 20.0
Operation completed successfully
```

If an exception occurs, the `else` block is skipped.

## 7. The `finally` Block

The `finally` block executes whether an exception occurs or not.

It is commonly used for cleanup operations, such as closing files or releasing resources.

```python
try:
    number = 10 / 2
    print(number)

except ZeroDivisionError:
    print("Cannot divide by zero")

finally:
    print("Execution completed")
```

**Output:**
```text
5.0
Execution completed
```

Even if an exception occurs, `finally` normally executes.

## 8. Using try, except, else, and finally Together

All four blocks can be used together.

**Syntax:**

```python
try:
    # Risky code

except ExceptionType:
    # Handle the exception

else:
    # Executes if no exception occurs

finally:
    # Executes whether an exception occurs or not
```

**Example:**

```python
try:
    number = int(input("Enter a number: "))
    result = 100 / number

except ValueError:
    print("Please enter a valid number")

except ZeroDivisionError:
    print("Cannot divide by zero")

else:
    print("Result:", result)

finally:
    print("Program execution finished")
```

**Output when input is 5:**
```text
Enter a number: 5
Result: 20.0
Program execution finished
```

**Output when input is 0:**
```text
Enter a number: 0
Cannot divide by zero
Program execution finished
```

**Output when input is abc:**
```text
Enter a number: abc
Please enter a valid number
Program execution finished
```

## 9. Nested try and except

A `try` block can be placed inside another `try` block.

```python
try:
    number = int(input("Enter a number: "))

    try:
        result = 100 / number
        print("Result:", result)

    except ZeroDivisionError:
        print("Cannot divide by zero")

except ValueError:
    print("Invalid input")
```

Here:
- The outer `try` handles invalid input.
- The inner `try` handles division by zero.

## 10. Raising Exceptions Using raise

The `raise` keyword is used to manually generate an exception.

```python
age = 15

if age < 18:
    raise ValueError("Age must be 18 or above")

print("Access granted")
```

**Output:**
```text
ValueError: Age must be 18 or above
```

We can also raise exceptions inside a function.

```python
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("Insufficient balance")

    return balance - amount

try:
    remaining = withdraw(5000, 6000)
    print("Remaining balance:", remaining)

except ValueError as error:
    print(error)
```

**Output:**
```text
Insufficient balance
```

## 11. Creating Custom Exceptions

We can create our own exception classes by inheriting from the built-in `Exception` class.

```python
class InvalidAgeError(Exception):
    pass

age = 15

try:
    if age < 18:
        raise InvalidAgeError("Age must be 18 or above")

except InvalidAgeError as error:
    print(error)
```

**Output:**
```text
Age must be 18 or above
```

Custom exceptions are useful when building applications with specific validation rules.

## 12. Important Differences

| Block | When does it execute? |
|---|---|
| `try` | Executes the code that may cause an exception |
| `except` | Executes when a matching exception occurs |
| `else` | Executes when no exception occurs in `try` |
| `finally` | Executes whether an exception occurs or not |

### Important Points

- A `try` block must be followed by at least one `except` or a `finally`.
- Multiple `except` blocks can be used.
- Handle specific exceptions before general exceptions.
- `else` executes only when no exception occurs in `try`.
- `finally` is generally used for cleanup operations.
- `raise` manually generates an exception.
- Custom exceptions are created by inheriting from `Exception`.
- Avoid using an empty or overly broad `except` because it can hide unexpected errors.

## 13. Real-World Use Cases

| Situation | Exception handling |
|---|---|
| User input | Handle `ValueError` |
| Calculator | Handle `ZeroDivisionError` |
| File operations | Handle `FileNotFoundError` |
| Dictionary access | Handle `KeyError` |
| List access | Handle `IndexError` |
| Database operations | Handle database-specific exceptions |
| API requests | Handle connection and request errors |
| Resource cleanup | Use `finally` or context managers |

**Example: Safe File Reading**

```python
try:
    file = open("data.txt", "r", encoding="utf-8")
    content = file.read()

except FileNotFoundError:
    print("File not found")

else:
    print(content)

finally:
    print("File reading operation completed")
```

For file handling, using `with open(...)` is generally preferred because it closes the file automatically, even if an exception occurs.
