# Defining and Calling Functions in Python

A function is a reusable block of code that performs a specific task.

Functions help us organize code, avoid repetition and make programs easier to maintain.

Python provides two types of functions:

- **Built-in functions:** Functions already provided by Python, such as `print()`, `len()`, `type()` and `sum()`.
- **User-defined functions:** Functions created by programmers using the `def` keyword.

## 1. Defining a Function

We use the `def` keyword to define a function.

### Syntax

```python
def function_name():
    # Function body
    statements
```

Example:

```python
def greet():
    print("Hello, welcome to Python!")

```

Here:

- `def` is the keyword used to define a function.
- `greet` is the function name.
- `()` contains parameters, if required.
- The indented statements form the function body.

**Important:** Defining a function does not execute its code. We must call the function to execute it.

## 2. Calling a Function

A function call executes the statements inside the function.

```python
def greet():
    print("Hello, welcome to Python!")

greet()
```

**Output:**

```text
Hello, welcome to Python!
```

We can call the same function multiple times.

```python
def greet():
    print("Hello!")

greet()
greet()
greet()
```

**Output:**

```text
Hello!
Hello!
Hello!
```

## 3. Function Without Parameters

A function does not always need parameters.

```python
def display_message():
    print("Learning Python Functions")

display_message()
```

**Output:**

```text
Learning Python Functions
```

## 4. Function with Parameters

Parameters are variables defined inside the function definition. They receive values when the function is called.

```python
def greet(name):
    print("Hello", name)

greet("Rahul")
greet("Arun")
```

**Output:**

```text
Hello Rahul
Hello Arun
```

Here:

- `name` is a parameter.
- `"Rahul"` and `"Arun"` are arguments.

### Multiple Parameters

A function can accept multiple parameters.

```python
def add(a, b):
    print(a + b)

add(10, 20)
```

**Output:**

```text
30
```

Here, `a` and `b` are parameters that receive the arguments `10` and `20`.

## 5. Parameters vs Arguments

These terms are related but have different meanings.

| Parameter                       | Argument                            |
| ------------------------------- | ----------------------------------- |
| Variable in function definition | Value supplied during function call |
| Receives input                  | Provides input                      |
| Example: `name`                 | Example: `"Rahul"`                  |

Example:

```python
def greet(name):  # name is a parameter
    print(name)

greet("Rahul")    # "Rahul" is an argument
```

## 6. Returning Values from a Function

The `return` statement sends a result back to the caller.

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

**Output:**

```text
30
```

Here:

1. The function receives `10` and `20`.
2. It calculates their sum.
3. `return` sends `30` back.
4. The returned value is stored in `result`.

### Returning Without Printing

```python
def multiply(a, b):
    return a * b

answer = multiply(5, 4)

print(answer)
```

**Output:**

```text
20
```

The function returns a value instead of directly displaying it.

## 7. Difference Between print() and return

This is an important concept in Python.

### Using print()

```python
def add(a, b):
    print(a + b)

result = add(10, 20)

print(result)
```

**Output:**

```text
30
None
```

Why does `result` contain `None`?

Because `print()` displays the result but does not send it back to the caller. A function without an explicit return value returns `None`.

### Using return

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

**Output:**

```text
30
```

| print()                                                      | return                                         |
| ------------------------------------------------------------ | ---------------------------------------------- |
| Displays a value                                             | Sends a value back                             |
| Does not provide that displayed value as the function result | Provides a function result                     |
| Useful for displaying information                            | Useful for calculations and further processing |

## 8. Default Parameters

A default parameter has a predefined value.

If the caller does not provide an argument for it, Python uses the default value.

```python
def greet(name="Guest"):
    print("Hello", name)

greet()
greet("Rahul")
```

**Output:**

```text
Hello Guest
Hello Rahul
```

### Multiple Default Parameters

```python
def student(name, course="MCA", city="Chennai"):
    print(name, course, city)

student("Rahul")
student("Arun", "BCA")
student("Kiran", "MCA", "Bangalore")
```

**Output:**

```text
Rahul MCA Chennai
Arun BCA Chennai
Kiran MCA Bangalore
```

**Important:** Parameters with default values must come after parameters without default values.

Valid:

```python
def student(name, course="MCA"):
    print(name, course)
```

Invalid:

```python
# SyntaxError
def student(course="MCA", name):
    print(name, course)
```

## 9. Positional Arguments

Positional arguments are assigned to parameters based on their position in the function call.

```python
def student(name, age):
    print("Name:", name)
    print("Age:", age)

student("Rahul", 22)
```

**Output:**

```text
Name: Rahul
Age: 22
```

The first argument goes to `name`, and the second goes to `age`.

## 10. Keyword Arguments

Keyword arguments specify parameter names during a function call.

```python
def student(name, age):
    print("Name:", name)
    print("Age:", age)

student(age=22, name="Rahul")
```

**Output:**

```text
Name: Rahul
Age: 22
```

Unlike positional arguments, keyword arguments do not depend on the order of parameters.

## 11. Mixing Positional and Keyword Arguments

We can combine positional and keyword arguments.

```python
def employee(name, salary, city):
    print(name, salary, city)

employee("Rahul", salary=30000, city="Chennai")
```

**Output:**

```text
Rahul 30000 Chennai
```

**Important:** Positional arguments must come before keyword arguments in a function call.

## 12. Returning Multiple Values

Python allows a function to return multiple values separated by commas.

```python
def calculate(a, b):
    addition = a + b
    subtraction = a - b

    return addition, subtraction

result = calculate(20, 10)

print(result)
```

**Output:**

```text
(30, 10)
```

Python actually returns these values as a tuple.

### Unpacking Returned Values

```python
addition, subtraction = calculate(20, 10)

print(addition)
print(subtraction)
```

**Output:**

```text
30
10
```

## 13. The pass Statement in Functions

The `pass` statement is used as a placeholder when a function body has not been implemented yet.

```python
def calculate():
    pass

calculate()
```

It does nothing and allows the function definition to remain syntactically valid.

## 14. Function Execution Flow

Consider this example:

```python
def add(a, b):
    result = a + b
    return result

answer = add(10, 20)

print(answer)
```

Execution flow:

1. Python defines the `add()` function.
2. Python reaches the function call `add(10, 20)`.
3. Arguments are assigned to parameters `a` and `b`.
4. The function body executes.
5. `result` stores `30`.
6. `return` sends `30` back to the caller.
7. `answer` receives `30`.
8. `print()` displays the result.

**Output:**

```text
30
```

## 15. Local Variables and Function Scope

A variable created inside a function is normally a local variable.

It can be accessed inside that function but not directly outside it.

```python
def calculate():
    result = 100
    print(result)

calculate()
```

**Output:**

```text
100
```

Trying to access `result` outside the function causes a `NameError`.

```python
def calculate():
    result = 100

calculate()

# print(result)  # NameError
```

### Global Variables

A variable defined outside a function is a global variable.

```python
name = "Rahul"

def greet():
    print("Hello", name)

greet()
```

**Output:**

```text
Hello Rahul
```

A function can read a global variable. To reassign a global variable from inside a function, use the `global` keyword.

```python
count = 10

def update():
    global count
    count = 20

update()

print(count)
```

**Output:**

```text
20
```

## 16. Functions Calling Other Functions

One function can call another function.

```python
def add(a, b):
    return a + b

def display_result():
    result = add(10, 20)
    print("Result:", result)

display_result()
```

**Output:**

```text
Result: 30
```

This helps divide a program into smaller reusable tasks.

## 17. Real-World Example: Simple Calculator

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "Cannot divide by zero"

    return a / b

print("Addition:", add(10, 5))
print("Subtraction:", subtract(10, 5))
print("Multiplication:", multiply(10, 5))
print("Division:", divide(10, 5))
```

**Output:**

```text
Addition: 15
Subtraction: 5
Multiplication: 50
Division: 2.0
```

Each function performs one specific operation, making the calculator easier to maintain and reuse.

## 18. Important Function Concepts

| Concept             | Meaning                              |
| ------------------- | ------------------------------------ |
| `def`               | Defines a function                   |
| Function call       | Executes a function                  |
| Parameter           | Variable in function definition      |
| Argument            | Value passed during function call    |
| `return`            | Sends a result back                  |
| Default parameter   | Uses a predefined value when omitted |
| Positional argument | Assigned based on position           |
| Keyword argument    | Assigned using parameter name        |
| `pass`              | Placeholder statement                |
| Local variable      | Variable defined inside a function   |
| Global variable     | Variable defined outside a function  |
