# split(), join(), replace() and strip() in Python

These four string methods are commonly used for cleaning, modifying and processing text.

## 1. `split()`

The `split()` method divides a string into a list of smaller strings.

**Syntax:**

```python
string.split(separator, maxsplit)
```

- `separator`: Character or string used to split.
- `maxsplit`: Maximum number of splits. Optional.

### Example 1: Basic Split

```python
text = "Python Java C++"

result = text.split()

print(result)
```

**Output:**

```text
['Python', 'Java', 'C++']
```

By default, `split()` separates using whitespace.

### Example 2: Split Using a Separator

```python
text = "apple,banana,mango"

result = text.split(",")

print(result)
```

**Output:**

```text
['apple', 'banana', 'mango']
```

### Example 3: Using `maxsplit`

```python
text = "Python Java C++ JavaScript"

print(text.split(" ", 1))
```

**Output:**

```text
['Python', 'Java C++ JavaScript']
```

Only one split is performed.

### Example 4: Split a Sentence into Words

```python
sentence = "Python is easy to learn"

words = sentence.split()

print(words)
print(len(words))
```

**Output:**

```text
['Python', 'is', 'easy', 'to', 'learn']
5
```

## 2. `join()`

The `join()` method combines elements of an iterable into a single string using a specified separator.

**Syntax:**

```python
separator.join(iterable)
```

### Example 1: Join Using Space

```python
words = ["Python", "is", "powerful"]

result = " ".join(words)

print(result)
```

**Output:**

```text
Python is powerful
```

### Example 2: Join Using Comma

```python
languages = ["Python", "Java", "C++"]

result = ", ".join(languages)

print(result)
```

**Output:**

```text
Python, Java, C++
```

### Example 3: Join Using Hyphen

```python
items = ["2026", "11", "17"]

result = "-".join(items)

print(result)
```

**Output:**

```text
2026-11-17
```

### Example 4: Join Characters

```python
text = "PYTHON"

result = "-".join(text)

print(result)
```

**Output:**

```text
P-Y-T-H-O-N
```

**Important:** All elements must be strings. Otherwise, `join()` raises `TypeError`.

```python
numbers = [10, 20, 30]

result = "-".join(map(str, numbers))

print(result)
```

**Output:**

```text
10-20-30
```

## 3. `replace()`

The `replace()` method replaces occurrences of one substring with another.

**Syntax:**

```python
string.replace(old, new, count)
```

- `old`: Substring to replace.
- `new`: Replacement substring.
- `count`: Maximum number of replacements. Optional.

### Example 1: Basic Replacement

```python
text = "I love Java"

result = text.replace("Java", "Python")

print(result)
```

**Output:**

```text
I love Python
```

### Example 2: Replace Multiple Occurrences

```python
text = "apple apple apple"

result = text.replace("apple", "mango")

print(result)
```

**Output:**

```text
mango mango mango
```

### Example 3: Limit Replacements

```python
text = "apple apple apple"

result = text.replace("apple", "mango", 2)

print(result)
```

**Output:**

```text
mango mango apple
```

Only the first two occurrences are replaced.

### Example 4: Remove a Substring

You can replace a substring with an empty string.

```python
text = "Python Programming"

result = text.replace("Python ", "")

print(result)
```

**Output:**

```text
Programming
```

## 4. `strip()`

The `strip()` method removes leading and trailing whitespace from a string.

**Syntax:**

```python
string.strip(chars)
```

- `chars`: Optional characters to remove from both ends.
- If omitted, whitespace is removed.

### Example 1: Remove Spaces

```python
text = "   Python   "

result = text.strip()

print(result)
```

**Output:**

```text
Python
```

### Example 2: `lstrip()`

Removes whitespace or specified characters from the left side.

```python
text = "   Python   "

print(text.lstrip())
```

**Output:**

```text
Python   
```

### Example 3: `rstrip()`

Removes whitespace or specified characters from the right side.

```python
text = "   Python   "

print(text.rstrip())
```

**Output:**

```text
   Python
```

### Example 4: Remove Specific Characters

```python
text = "***Python***"

print(text.strip("*"))
```

**Output:**

```text
Python
```

**Important:** `strip(chars)` removes any matching characters from the beginning and end. It does not remove an exact substring.

```python
text = "www.example.com"

print(text.strip("w.com"))
```

This removes matching characters from both ends, not the exact text `"www."` or `".com"`.

For exact prefix or suffix removal, use `removeprefix()` or `removesuffix()`.

## 5. Difference Between These Methods

| Method | Main purpose | Return type |
|---|---|---|
| `split()` | Divides a string | List |
| `join()` | Combines strings | String |
| `replace()` | Replaces substrings | String |
| `strip()` | Removes characters from both ends | String |

## 6. Different Practical Use Cases

### Use Case 1: Extract Username from Email

```python
email = "john@gmail.com"

username = email.split("@")[0]

print(username)
```

**Output:**

```text
john
```

### Use Case 2: Convert Comma-Separated Values into a List

```python
data = "Python,Java,C++,JavaScript"

languages = data.split(",")

print(languages)
```

**Output:**

```text
['Python', 'Java', 'C++', 'JavaScript']
```

### Use Case 3: Clean User Input

```python
name = "   JOHN   "

name = name.strip().title()

print(name)
```

**Output:**

```text
John
```

### Use Case 4: Remove Unwanted Symbols

```python
phone = "+91-98765-43210"

cleaned = phone.replace("+91-", "").replace("-", "")

print(cleaned)
```

**Output:**

```text
9876543210
```

### Use Case 5: Convert a List into a Sentence

```python
words = ["Python", "is", "easy", "to", "learn"]

sentence = " ".join(words)

print(sentence)
```

**Output:**

```text
Python is easy to learn
```

### Use Case 6: Process Multiple Spaces

```python
text = "Python    is    easy"

words = text.split()

result = " ".join(words)

print(result)
```

**Output:**

```text
Python is easy
```

This works because `split()` without a separator treats consecutive whitespace as a single separator and ignores leading and trailing whitespace.
