
# Python pathlib Module

## 1. What Is pathlib?

`pathlib` is a built-in Python module used to work with file system paths.

It provides an object-oriented way to create, access, modify, and manage file and directory paths.

Instead of manually joining strings, `pathlib` provides methods and operators for handling paths.

### Importing pathlib

```python
from pathlib import Path
```

`Path` is the main class used to create and work with paths.

## 2. Creating a Path

Use `Path()` to create a path object.

```python
from pathlib import Path

path = Path("sample.txt")

print(path)
print(type(path))
```

**Output:**

```text
sample.txt
<class 'pathlib.PosixPath'>
```

The exact path class depends on the operating system. On Windows, it will typically be `WindowsPath`.

## 3. Current Working Directory

The current working directory is the directory from which the Python program is running.

Use `Path.cwd()` to get it.

```python
from pathlib import Path

current = Path.cwd()

print(current)
```

**Possible Output:**

```text
C:\Users\Vikith\PyDirectorython
```

The output depends on your computer and working directory.

## 4. Getting the Home&#x20;

Use `Path.home()` to get the current user's home directory.

```python
from pathlib import Path

home = Path.home()

print(home)
```

**Possible Output:**

```text
C:\Users\Vikith
```

## 5. Joining Paths

Use the `/` operator to combine directory and file names.

```python
from pathlib import Path

folder = Path("documents")

file_path = folder / "notes.txt"

print(file_path)
```

**Output:**

```text
documents/notes.txt
```

The path separator is automatically selected for the operating system.

### Joining Multiple Paths

```python
from pathlib import Path

path = Path("project") / "data" / "students.txt"

print(path)
```

**Output:**

```text
project/data/students.txt
```

## 6. Getting File and Directory Information

`pathlib` provides several useful properties and methods.

Assume the following path:

```python
from pathlib import Path

path = Path("documents/report.txt")
```

| Property / Method | Description                             |
| ----------------- | --------------------------------------- |
| `path.name`       | Returns the file name                   |
| `path.stem`       | Returns the file name without extension |
| `path.suffix`     | Returns the file extension              |
| `path.parent`     | Returns the parent directory            |
| `path.parts`      | Returns path components as a tuple      |
| `path.suffixes`   | Returns all file extensions             |

### Example

```python
from pathlib import Path

path = Path("documents/report.txt")

print(path.name)
print(path.stem)
print(path.suffix)
print(path.parent)
print(path.parts)
```

**Output:**

```text
report.txt
report
.txt
documents
('documents', 'report.txt')
```

## 7. Checking Whether a Path Exists

Use `exists()` to check whether a file or directory exists.

```python
from pathlib import Path

path = Path("sample.txt")

if path.exists():
    print("Path exists")
else:
    print("Path does not exist")
```

**Possible Output:**

```text
Path does not exist
```

The output depends on whether the path exists.

### Checking Files and Directories

```python
from pathlib import Path

path = Path("sample.txt")

print(path.is_file())
print(path.is_dir())
```

- `is_file()` checks whether the path points to a file.
- `is_dir()` checks whether the path points to a directory.

## 8. Creating Directories

Use `mkdir()` to create a directory.

```python
from pathlib import Path

folder = Path("documents")

folder.mkdir(exist_ok=True)
```

`exist_ok=True` prevents an error if the directory already exists.

### Creating Nested Directories

Use `parents=True` to create missing parent directories.

```python
from pathlib import Path

folder = Path("project/data/files")

folder.mkdir(parents=True, exist_ok=True)
```

This creates the required directory structure.

## 9. Creating and Writing Files

`pathlib` provides methods to write directly to files.

### write_text()

Writes a string into a text file.

```python
from pathlib import Path

path = Path("sample.txt")

path.write_text("Hello Python", encoding="utf-8")
```

This creates the file if it does not exist and replaces its existing content if it does.

### read_text()

Reads the entire text file and returns a string.

```python
from pathlib import Path

path = Path("sample.txt")

content = path.read_text(encoding="utf-8")

print(content)
```

**Output:**

```text
Hello Python
```

### write_bytes()

Writes binary data into a file.

```python
from pathlib import Path

path = Path("data.bin")

path.write_bytes(b"Hello Python")
```

### read_bytes()

Reads binary data and returns a bytes object.

```python
from pathlib import Path

path = Path("data.bin")

content = path.read_bytes()

print(content)
```

**Output:**

```text
b'Hello Python'
```

## 10. Opening Files Using pathlib

We can also use `Path.open()` to open files.

It works similarly to the built-in `open()` function.

```python
from pathlib import Path

path = Path("sample.txt")

with path.open("r", encoding="utf-8") as file:
    print(file.read())
```

**Output:**

```text
Hello Python
```

We can use different file modes such as `r`, `w`, `a`, and `rb`.

## 11. Listing Files in a Directory

Use `iterdir()` to iterate through the contents of a directory.

```python
from pathlib import Path

folder = Path("documents")

for item in folder.iterdir():
    print(item)
```

**Possible Output:**

```text
documents/report.txt
documents/notes.txt
documents/data.csv
```

The output depends on the files present in the directory.

## 12. Searching for Files Using glob()

The `glob()` method searches for paths matching a pattern.

### Example: Find All Text Files

```python
from pathlib import Path

folder = Path("documents")

for file in folder.glob("*.txt"):
    print(file)
```

This finds files ending in `.txt` directly inside the directory.

### Example: Find All Python Files

```python
from pathlib import Path

folder = Path("project")

for file in folder.glob("*.py"):
    print(file)
```

### Using rglob()

`rglob()` searches recursively through subdirectories.

```python
from pathlib import Path

folder = Path("project")

for file in folder.rglob("*.py"):
    print(file)
```

This finds Python files in the directory and its nested folders.

## 13. Renaming and Deleting Files

### Renaming a File

Use `rename()` to change a file or directory name.

```python
from pathlib import Path

old_path = Path("old.txt")
new_path = Path("new.txt")

old_path.rename(new_path)
```

### Deleting a File

Use `unlink()` to delete a file.

```python
from pathlib import Path

path = Path("sample.txt")

path.unlink()
```

### Deleting an Empty Directory

Use `rmdir()` to remove an empty directory.

```python
from pathlib import Path

folder = Path("documents")

folder.rmdir()
```

**Important:** `rmdir()` only removes empty directories. `unlink()` removes files, not directories.

## 14. Resolving Absolute Paths

Use `resolve()` to obtain an absolute path.

```python
from pathlib import Path

path = Path("sample.txt")

print(path.resolve())
```

**Possible Output:**

```text
C:\Users\Vikith\Python\sample.txt
```

An absolute path specifies the complete location of a file or directory.

## 16. pathlib vs os.path

Both `pathlib` and `os.path` are used for file system path operations.

| Feature           | pathlib             | os.path              |
| ----------------- | ------------------- | -------------------- |
| Approach          | Object-oriented     | Function-based       |
| Path creation     | `Path("file.txt")`  | String paths         |
| Joining paths     | `path / "file.txt"` | `os.path.join()`     |
| Check existence   | `path.exists()`     | `os.path.exists()`   |
| Get extension     | `path.suffix`       | `os.path.splitext()` |
| Current directory | `Path.cwd()`        | `os.getcwd()`        |

`pathlib` is often preferred for modern Python code because its path objects provide a convenient interface.

## 17. Real-World Example: Organizing Files

```python
from pathlib import Path

# Create a project directory
folder = Path("student_records")
folder.mkdir(exist_ok=True)

# Create a file path
file_path = folder / "students.txt"

# Write student records
file_path.write_text(
    "Vikith - 90\nAnil - 85\nRam - 95",
    encoding="utf-8"
)

# Read student records
content = file_path.read_text(encoding="utf-8")

print(content)
```

**Output:**

```text
Vikith - 90
Anil - 85
Ram - 95
```

## 18. Important Points

- `pathlib` is a built-in Python module.
- Import `Path` using `from pathlib import Path`.
- `Path()` creates a path object.
- Use `/` to join paths.
- Use `exists()` to check whether a path exists.
- Use `mkdir()` to create directories.
- Use `read_text()` and `write_text()` for text files.
- Use `read_bytes()` and `write_bytes()` for binary files.
- Use `glob()` and `rglob()` to search for files.
- Use `unlink()` to delete files.
- Use `with path.open()` when you need more control over file operations.
