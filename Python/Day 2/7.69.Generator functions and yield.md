

# Python Generator Functions and yield

## 1. What Is a Generator?

A generator is a special type of iterator that produces values one at a time instead of storing all values in memory at once.

Generators are useful when working with:
- Large datasets
- Files containing many records
- Data processing pipelines
- Streaming data
- Memory-efficient operations

Python provides two ways to create generators:
1. Generator functions using `yield`.
2. Generator expressions.

## 2. What Is a Generator Function?

A generator function is a function that uses the `yield` keyword instead of relying only on `return` to produce values.

When called, a generator function returns a generator object.

It does not execute the entire function immediately.

### Example

```python
def numbers():
    yield 10
    yield 20
    yield 30

result = numbers()

print(result)
print(type(result))
```

**Possible Output:**

```text
<generator object numbers at ...>
<class 'generator'>
```

Notice that calling `numbers()` does not directly return `10`, `20`, and `30`.

It returns a generator object.

## 3. Understanding yield

The `yield` keyword produces a value and temporarily pauses the function.

When the generator is requested to produce another value, execution resumes from where it paused.

### Example

```python
def numbers():
    yield 10
    yield 20
    yield 30

gen = numbers()

print(next(gen))
print(next(gen))
print(next(gen))
```

**Output:**

```text
10
20
30
```

### How It Works

1. `numbers()` creates a generator object.
2. First `next()` starts execution and reaches `yield 10`.
3. The function pauses and returns `10`.
4. Second `next()` resumes execution and reaches `yield 20`.
5. The function pauses again.
6. Third `next()` resumes and returns `30`.

The generator remembers its execution state between calls.

## 4. What Happens After the Last yield?

After the generator produces its final value, the next request raises `StopIteration`.

```python
def numbers():
    yield 10
    yield 20

gen = numbers()

print(next(gen))
print(next(gen))
print(next(gen))
```

**Output:**

```text
10
20
Traceback (most recent call last):
    ...
StopIteration
```

This is how generators follow the iterator protocol.

## 5. Using Generators with for Loops

We can directly iterate over a generator using a `for` loop.

```python
def numbers():
    yield 10
    yield 20
    yield 30

for number in numbers():
    print(number)
```

**Output:**

```text
10
20
30
```

The `for` loop automatically requests the next value and handles `StopIteration`.

## 6. Difference Between return and yield

Both `return` and `yield` produce values, but their behavior is different.

### Using return

```python
def get_numbers():
    return [10, 20, 30]

result = get_numbers()

print(result)
```

**Output:**

```text
[10, 20, 30]
```

The function finishes execution and returns the complete list.

### Using yield

```python
def get_numbers():
    yield 10
    yield 20
    yield 30

result = get_numbers()

for number in result:
    print(number)
```

**Output:**

```text
10
20
30
```

The generator produces values one at a time.

### Comparison

| Feature | return | yield |
|---|---|---|
| Purpose | Returns a value and exits the function | Produces a value and pauses execution |
| Execution | Normal function execution | Resumes when the next value is requested |
| Output | Returns a value | Produces a generator object when called |
| State | Function finishes | Function state is preserved between yields |
| Multiple values | Can return a collection | Can yield multiple values individually |
| Memory | May require storing a collection | Can produce values lazily |

## 7. Generator with a Loop

Generators are especially useful when producing sequences.

```python
def count_numbers(limit):
    for number in range(1, limit + 1):
        yield number

for value in count_numbers(5):
    print(value)
```

**Output:**

```text
1
2
3
4
5
```

Instead of creating a complete list, the generator produces each number when requested.

## 8. Generator with Conditions

We can use conditions inside generator functions.

```python
def even_numbers(limit):
    for number in range(1, limit + 1):
        if number % 2 == 0:
            yield number

for number in even_numbers(10):
    print(number)
```

**Output:**

```text
2
4
6
8
10
```

Only even numbers are produced.

## 9. Generator State Preservation

A generator remembers local variables and its execution position when paused.

```python
def counter():
    count = 1

    yield count

    count += 1
    yield count

    count += 1
    yield count

gen = counter()

print(next(gen))
print(next(gen))
print(next(gen))
```

**Output:**

```text
1
2
3
```

The local variable `count` is preserved between `yield` statements.

## 10. Generator Expressions

A generator expression is a shorter way to create a generator.

Its syntax is similar to list comprehension, but it uses parentheses instead of square brackets.

### List Comprehension

```python
numbers = [x * 2 for x in range(5)]

print(numbers)
```

**Output:**

```text
[0, 2, 4, 6, 8]
```

This creates a complete list.

### Generator Expression

```python
numbers = (x * 2 for x in range(5))

print(numbers)
print(next(numbers))
print(next(numbers))
```

**Possible Output:**

```text
<generator object <genexpr> at ...>
0
2
```

The generator expression produces values only when requested.

## 11. Using yield with Multiple Values

A generator can produce values from different statements and loops.

```python
def student_details():
    yield "Vikith"
    yield 24
    yield "MCA"

for value in student_details():
    print(value)
```

**Output:**

```text
Vikith
24
MCA
```

Each `yield` produces one value.

## 12. Understanding yield from

The `yield from` keyword is used to delegate value production to another iterable or generator.

### Example

```python
def numbers():
    yield from [10, 20, 30]

for number in numbers():
    print(number)
```

**Output:**

```text
10
20
30
```

This is equivalent to:

```python
def numbers():
    for number in [10, 20, 30]:
        yield number
```

`yield from` is useful when one generator needs to produce values from another iterable or generator.

## 13. Memory Efficiency: List vs Generator

Consider generating a large sequence of numbers.

### Using a List

```python
numbers = [x for x in range(1000000)]
```

This creates and stores all one million elements in memory.

### Using a Generator

```python
numbers = (x for x in range(1000000))
```

This creates a generator that produces values when requested.

### Comparison

| Feature | List | Generator |
|---|---|---|
| Creation | Stores all elements | Creates a generator object |
| Memory | Uses memory for stored elements | Usually uses much less memory |
| Access | Supports indexing | Does not support indexing |
| Iteration | Can be repeated | Usually exhausted after one complete iteration |
| Evaluation | Eager | Lazy |

**Important:** Generators are memory-efficient when values can be processed one at a time. They are not automatically faster for every operation.

## 14. Real-World Example: Reading a Large File

A generator can read a file one line at a time.

```python
def read_file(filename):
    with open(filename, "r", encoding="utf-8") as file:
        for line in file:
            yield line.strip()

for line in read_file("students.txt"):
    print(line)
```

**Example students.txt:**

```text
Vikith
Anil
Ram
```

**Output:**

```text
Vikith
Anil
Ram
```

Instead of loading the entire file into a list, this generator produces one line at a time.

## 15. Important Points

- A generator is a special type of iterator.
- A generator function uses the `yield` keyword.
- Calling a generator function returns a generator object.
- The function executes when values are requested.
- `yield` produces a value and pauses execution.
- The generator preserves its local variables and execution position.
- `next()` retrieves the next generated value.
- An exhausted generator raises `StopIteration`.
- `for` loops automatically handle generator iteration.
- Generator expressions use parentheses.
- `yield from` delegates value production to another iterable.
- Generators are useful for memory-efficient processing.

## 16. Real-World Use Cases

- **Large file processing:** Read files one line at a time.
- **Data science:** Process large datasets incrementally.
- **API responses:** Process records as they are received.
- **Database processing:** Handle records sequentially.
- **Data pipelines:** Pass generated values between processing stages.
- **Streaming applications:** Produce data continuously without storing everything.
