# String Formatting in Python

String formatting is the process of inserting variables and values into strings in a readable and structured way.

Python provides three main string formatting techniques:

1. F-strings
2. `str.format()`
3. `%` formatting

## 1. F-Strings (Modern Formatting)

F-strings were introduced in Python 3.6.

Add `f` before the opening quotation mark and place variables inside `{}`.

```python
name = "John"
age = 25

print(f"My name is {name} and I am {age} years old.")
```

**Output:**

```text
My name is John and I am 25 years old.
```

### Expressions Inside F-Strings

You can perform calculations directly inside curly braces.

```python
a = 10
b = 20

print(f"Sum: {a + b}")
print(f"Product: {a * b}")
```

**Output:**

```text
Sum: 30
Product: 200
```

### Formatting Decimal Numbers

Use `.nf` to specify the number of decimal places.

```python
price = 123.45678

print(f"{price:.2f}")
print(f"{price:.3f}")
```

**Output:**

```text
123.46
123.457
```

### Formatting Percentages

Use `%` in the format specification to convert a decimal into a percentage.

```python
score = 0.8567

print(f"Score: {score:.2%}")
```

**Output:**

```text
Score: 85.67%
```

### Thousands Separator

Use `,` to separate thousands.

```python
salary = 1500000

print(f"Salary: {salary:,}")
```

**Output:**

```text
Salary: 1,500,000
```

### Combining Formatting Options

```python
amount = 1234567.891

print(f"Amount: {amount:,.2f}")
```

**Output:**

```text
Amount: 1,234,567.89
```

## 2. str.format() Method

The `format()` method inserts values into placeholders `{}`.

```python
name = "John"
age = 25

print("My name is {} and I am {} years old.".format(name, age))
```

**Output:**

```text
My name is John and I am 25 years old.
```

### Positional Arguments

You can specify the position of values using indexes.

```python
print("{1} is learning {0}".format("Python", "John"))
```

**Output:**

```text
John is learning Python
```

### Named Arguments

You can use names inside placeholders.

```python
print("Name: {name}, Age: {age}".format(name="John", age=25))
```

**Output:**

```text
Name: John, Age: 25
```

### Decimal Formatting with format()

```python
price = 99.9876

print("Price: {:.2f}".format(price))
```

**Output:**

```text
Price: 99.99
```

## 3. Old-Style Formatting (%)

Python also supports the older `%` formatting technique.

```python
name = "John"
age = 25

print("My name is %s and I am %d years old." % (name, age))
```

**Output:**

```text
My name is John and I am 25 years old.
```

### Common Format Specifiers

| Specifier | Meaning                     |
| --------- | --------------------------- |
| `%s`      | String                      |
| `%d`      | Integer                     |
| `%f`      | Floating-point number       |
| `%.2f`    | Float with 2 decimal places |
| `%x`      | Hexadecimal integer         |
| `%o`      | Octal integer               |

Example:

```python
name = "Python"
age = 10
price = 99.987

print("Name: %s" % name)
print("Age: %d" % age)
print("Price: %.2f" % price)
```

**Output:**

```text
Name: Python
Age: 10
Price: 99.99
```

## 4. Format Specifiers in Python

Format specifiers control how values are displayed.

| Format | Purpose                    | Example         |
| ------ | -------------------------- | --------------- |
| `.2f`  | 2 decimal places           | `12.35`         |
| `.3f`  | 3 decimal places           | `12.346`        |
| `,`    | Thousands separator        | `1,000,000`     |
| `%`    | Percentage                 | `75.00%`        |
| `>10`  | Right alignment            | Spaces on left  |
| `<10`  | Left alignment             | Spaces on right |
| `^10`  | Center alignment           | Centered text   |
| `05d`  | Zero-padded integer        | `00042`         |
| `b`    | Binary representation      | `1010`          |
| `x`    | Hexadecimal representation | `ff`            |

### Alignment Examples

```python
name = "Python"

print(f"|{name:<10}|")
print(f"|{name:>10}|")
print(f"|{name:^10}|")
```

**Output:**

```text
|Python    |
|    Python|
|  Python  |
```

### Binary, Octal and Hexadecimal

```python
number = 255

print(f"Binary: {number:b}")
print(f"Octal: {number:o}")
print(f"Hexadecimal: {number:x}")
```

**Output:**

```text
Binary: 11111111
Octal: 377
Hexadecimal: ff
```

## 5. Escaping Curly Braces in F-Strings

To display literal curly braces, use double braces.

```python
name = "John"

print(f"{{Hello, {name}}}")
```

**Output:**

```text
{Hello, John}
```
