# Nested Conditions and Conditional Expressions in Python

## 1. Nested if Statements

A nested `if` statement means placing one conditional statement inside another conditional statement.

The inner condition is checked only when the outer condition is satisfied.

### Syntax

```python
if condition1:
    if condition2:
        # Executes when both conditions are True
    else:
        # Inner condition is False
else:
    # Outer condition is False
```

### Example 1: Login Validation

```python
username = "admin"
password = "12345"

if username == "admin":
    if password == "12345":
        print("Login successful")
    else:
        print("Incorrect password")
else:
    print("Invalid username")
```

### Example 2: Student Eligibility

```python
attendance = 85
marks = 75

if attendance >= 75:
    if marks >= 50:
        print("Eligible for examination")
    else:
        print("Insufficient marks")
else:
    print("Attendance is too low")
```

### Example 3: Checking Positive, Negative and Zero

```python
number = 10

if number >= 0:
    if number == 0:
        print("Zero")
    else:
        print("Positive number")
else:
    print("Negative number")
```

### Example 4: Nested Conditions with Multiple Levels

```python
age = 25
has_license = True
has_vehicle = True

if age >= 18:
    if has_license:
        if has_vehicle:
            print("Ready to drive")
        else:
            print("You need a vehicle")
    else:
        print("You need a driving license")
else:
    print("You are underage")
```

## 2. Nested if vs Logical Operators

Sometimes nested conditions can be simplified using logical operators.

### Using Nested if

```python
age = 22
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")
```

### Using AND Operator

```python
age = 22
has_id = True

if age >= 18 and has_id:
    print("Entry allowed")
```

Both examples produce the same result.

**When to use:**

- Nested `if`: When conditions need separate decisions or different messages.
- Logical operators: When multiple conditions must be satisfied together.

## 3. Conditional Expressions (Ternary Operator)

A conditional expression is a shorter way of writing a simple `if-else` statement in one line.

### Syntax

```python
value_if_true if condition else value_if_false
```

### Example 1: Check Age

```python
age = 20

result = "Adult" if age >= 18 else "Minor"

print(result)  # Adult
```

### Example 2: Find the Largest Number

```python
a = 10
b = 20

largest = a if a > b else b

print(largest)  # 20
```

### Example 3: Even or Odd

```python
number = 7

result = "Even" if number % 2 == 0 else "Odd"

print(result)  # Odd
```

### Example 4: Positive or Negative

```python
number = -5

result = "Positive" if number > 0 else "Not positive"

print(result)  # Not positive
```

## 4. Nested Conditional Expressions

A conditional expression can be placed inside another conditional expression.

### Example 1: Find the Largest of Three Numbers

```python
a = 10
b = 25
c = 15

largest = a if a > b and a > c else (b if b > c else c)

print(largest)  # 25
```

### Example 2: Grade Calculation

```python
marks = 85

grade = (
    "A" if marks >= 90 else
    "B" if marks >= 75 else
    "C" if marks >= 50 else
    "Fail"
)

print(grade)  # B
```

Nested conditional expressions are useful for short conditions, but too many nested expressions can make code difficult to read. Use regular `if-elif-else` statements for complex logic.

## 5. Conditional Expressions with Function Calls

You can use conditional expressions when assigning the result of a function call.

```python
is_logged_in = True

message = print("Welcome") if is_logged_in else print("Please login")
```

A more practical approach is to select a value first:

```python
is_logged_in = True

message = "Welcome" if is_logged_in else "Please login"
print(message)
```

## 6. Conditional Expressions with Lists

```python
numbers = [10, 20, 30]

message = "List is not empty" if numbers else "List is empty"

print(message)
```

Python treats non-empty collections as `True` and empty collections as `False`.

## 7. Difference Between if-else and Conditional Expression

| if-else                               | Conditional Expression        |
| ------------------------------------- | ----------------------------- |
| Uses multiple lines                   | Usually uses one line         |
| Suitable for complex logic            | Suitable for simple decisions |
| Can execute multiple statements       | Produces one expression value |
| Easier to read for complex conditions | Concise for simple conditions |

### if-else

```python
age = 20

if age >= 18:
    result = "Adult"
else:
    result = "Minor"
```

### Conditional Expression

```python
age = 20

result = "Adult" if age >= 18 else "Minor"
```

Both produce the same result.
