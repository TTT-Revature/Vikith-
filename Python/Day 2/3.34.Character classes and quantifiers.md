# Character Classes and Quantifiers in Python Regular Expressions

Character classes and quantifiers are important parts of Regular Expressions (RegEx).

- **Character classes** specify which characters can match.
- **Quantifiers** specify how many times a character or pattern can occur.

Python provides these features through the built-in `re` module.

```python
import re
```

## 1. Character Classes

A character class is written inside square brackets `[]`. It matches any one character from the specified set.

### Common Character Classes

| Pattern | Meaning | Example Matches |
|---|---|---|
| `[abc]` | Matches a, b, or c | `a`, `b`, `c` |
| `[a-z]` | Matches lowercase letters | `a`, `m`, `z` |
| `[A-Z]` | Matches uppercase letters | `A`, `M`, `Z` |
| `[0-9]` | Matches digits | `1`, `5`, `9` |
| `[a-zA-Z]` | Matches any English letter | `a`, `B`, `Z` |
| `[a-zA-Z0-9]` | Matches letters and digits | `a`, `B`, `5` |
| `[^0-9]` | Matches anything except digits | `a`, `@`, ` ` |
| `[aeiou]` | Matches any lowercase vowel | `a`, `e`, `i`, `o`, `u` |

### Matching Specific Characters

```python
import re

text = "Python"

result = re.findall("[aeiou]", text)

print(result)
```

**Output:**

```text
['o']
```

### Matching a Range of Characters

```python
import re

text = "Hello123"

result = re.findall("[a-z]", text)

print(result)
```

**Output:**

```text
['e', 'l', 'l', 'o']
```

Only lowercase letters are matched.

### Matching Uppercase and Lowercase Letters

```python
import re

text = "Python PROGRAMMING"

result = re.findall("[a-zA-Z]", text)

print(result)
```

**Output:**

```text
['P', 'y', 't', 'h', 'o', 'n', 'P', 'R', 'O', 'G', 'R', 'A', 'M', 'M', 'I', 'N', 'G']
```

### Matching Digits

```python
import re

text = "Order12345"

result = re.findall("[0-9]", text)

print(result)
```

**Output:**

```text
['1', '2', '3', '4', '5']
```

### Negated Character Classes

Use `^` immediately after `[` to match characters that are not in the specified set.

```python
import re

text = "Python123!"

result = re.findall("[^0-9]", text)

print(result)
```

**Output:**

```text
['P', 'y', 't', 'h', 'o', 'n', '!']
```

The pattern `[^0-9]` matches every character except digits.

## 2. Quantifiers

Quantifiers specify how many times a character or group should occur.

### Common Quantifiers

| Quantifier | Meaning | Example |
|---|---|---|
| `*` | Zero or more occurrences | `a*` |
| `+` | One or more occurrences | `a+` |
| `?` | Zero or one occurrence | `a?` |
| `{n}` | Exactly n occurrences | `a{3}` |
| `{n,}` | At least n occurrences | `a{2,}` |
| `{n,m}` | Between n and m occurrences | `a{2,5}` |

### Asterisk (*)

Matches zero or more occurrences of the preceding character.

```python
import re

text = "a aa aaa b"

result = re.findall("a*", text)

print(result)
```

**Output:**

```text
['a', '', 'aa', '', 'aaa', '', '', '']
```

The empty strings appear because `*` also allows zero occurrences.

### Plus (+)

Matches one or more occurrences of the preceding character.

```python
import re

text = "a aa aaa b"

result = re.findall("a+", text)

print(result)
```

**Output:**

```text
['a', 'aa', 'aaa']
```

Unlike `*`, `+` does not match an empty string.

### Question Mark (?)

Matches zero or one occurrence of the preceding character.

```python
import re

text = "color colour"

result = re.findall("colou?r", text)

print(result)
```

**Output:**

```text
['color', 'colour']
```

Here, `u?` means the letter `u` is optional.

### Exact Repetitions {n}

Matches exactly the specified number of occurrences.

```python
import re

text = "a aa aaa aaaa"

result = re.findall("a{3}", text)

print(result)
```

**Output:**

```text
['aaa', 'aaa']
```

The pattern matches groups of exactly three consecutive `a` characters.

### Minimum Repetitions {n,}

Matches at least the specified number of occurrences.

```python
import re

text = "a aa aaa aaaa"

result = re.findall("a{2,}", text)

print(result)
```

**Output:**

```text
['aa', 'aaa', 'aaaa']
```

### Range of Repetitions {n,m}

Matches between the minimum and maximum number of occurrences.

```python
import re

text = "a aa aaa aaaa aaaaa"

result = re.findall("a{2,4}", text)

print(result)
```

**Output:**

```text
['aa', 'aaa', 'aaaa', 'aaaa']
```

The final five-character sequence produces a four-character match because the maximum allowed repetition is four.

## 3. Combining Character Classes and Quantifiers

You can combine character classes and quantifiers to create more useful patterns.

### Extracting Numbers

```python
import re

text = "Order 123, Product 456"

result = re.findall("[0-9]+", text)

print(result)
```

**Output:**

```text
['123', '456']
```

`[0-9]+` matches one or more consecutive digits.

### Extracting Words

```python
import re

text = "Python Java 123"

result = re.findall("[a-zA-Z]+", text)

print(result)
```

**Output:**

```text
['Python', 'Java']
```

### Matching a 10-Digit Phone Number

```python
import re

phone = "9876543210"

result = re.fullmatch("[0-9]{10}", phone)

print(result is not None)
```

**Output:**

```text
True
```

`[0-9]{10}` requires exactly ten digits.

### Matching an Alphanumeric Username

```python
import re

username = "Python123"

result = re.fullmatch("[a-zA-Z0-9]{5,12}", username)

print(result is not None)
```

**Output:**

```text
True
```

This pattern allows 5 to 12 letters or digits.

## 4. Greedy and Non-Greedy Quantifiers

By default, quantifiers are greedy. They match as much text as possible while still allowing the overall pattern to match.

Adding `?` after a quantifier makes it non-greedy (lazy), matching as little text as possible.

### Greedy Matching

```python
import re

text = "<h1>Title</h1><h2>Heading</h2>"

result = re.findall("<.*>", text)

print(result)
```

**Output:**

```text
['<h1>Title</h1><h2>Heading</h2>']
```

`.*` matches as much text as possible.

### Non-Greedy Matching

```python
import re

text = "<h1>Title</h1><h2>Heading</h2>"

result = re.findall("<.*?>", text)

print(result)
```

**Output:**

```text
['<h1>', '</h1>', '<h2>', '</h2>']
```

`.*?` matches as little text as possible.

## 5. Important Differences

| Pattern | Meaning |
|---|---|
| `*` | Zero or more |
| `+` | One or more |
| `?` | Zero or one |
| `{3}` | Exactly three |
| `{2,}` | At least two |
| `{2,5}` | Between two and five |
| `.*` | Any character, zero or more times (greedy) |
| `.*?` | Any character, zero or more times (non-greedy) |
| `[0-9]` | One digit |
| `[0-9]+` | One or more consecutive digits |
| `[^0-9]` | Any character except a digit |

## 6. Real-World Use Cases

- **Phone number matching:** Check whether a phone number contains exactly ten digits.
- **Username validation:** Allow only letters and digits within a specified length.
- **Data extraction:** Extract numbers, words, and specific character patterns from text.
- **Form validation:** Check whether input follows a required format.
- **Text processing:** Find repeated characters or sequences.
- **HTML-like text extraction:** Use greedy or non-greedy matching to capture specific portions of text.
