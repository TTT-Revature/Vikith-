## How Python Interpreter Works
It processes Python source code and executes the instructions using the Python runtime.

### Running a Python Program

Python programs are saved with the `.py` file extension.

**Example:**

Create a file named `hello.py`.

```python
print("Hello, Python!")
```

```bash
python hello.py
```

**Output:**

```text
Hello, Python!
```

---

### Python Program Execution Process

In CPython, Python source code goes through the following stages:

#### Step 1: Python Source Code

The programmer writes Python code and saves it in a `.py` file.

**Example:** `program.py`

```python
print("Hello, World!")
```

#### Step 2: Python Compiler

The compiler parses the source code, checks its syntax, and compiles it into bytecode.

#### Step 3: Bytecode

Bytecode is an intermediate representation of Python instructions.

It is generated by the compiler and is executed by the Python Virtual Machine.

#### Step 4: Python Virtual Machine (PVM)

The Python Virtual Machine executes the bytecode instructions using the Python runtime.

#### Step 5: Program Output

After successful execution, the program produces the expected output.

**Output:**

```text
Hello, World!
```

### Python Execution Flow Diagram

```text
       Python Source Code
           (program.py)
                |
                v
        Python Compiler
       (Parsing and Compilation)
                |
                v
             Bytecode
      (Intermediate Instructions)
                |
                v
     Python Virtual Machine
        (PVM Execution)
                |
                v
          Program Output
```

### Important Points to Remember

1. `.py` represents a Python source code file.
2. The Python compiler converts source code into bytecode in CPython.
3. Bytecode is an intermediate representation, not machine code.
4. PVM executes the bytecode instructions.
5. The `.pyc` extension is used for cached compiled bytecode.
