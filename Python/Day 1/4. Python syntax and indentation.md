# Python Syntax and Indentation

## 1. Python Syntax

Python syntax refers to the rules and structure used to write Python programs.

**Example:**

```python
name = "Vikith"
age = 23

print(name)
print(age)
```

## 2. Indentation

Indentation refers to the spaces 

**Example:**

```python
age = 20

if age >= 18:
    print("Eligible to vote")
    print("Adult")
```

**Output:**

```text
Eligible to vote
Adult
```

**Important:** Python commonly uses four spaces for indentation.

## 3. Incorrect Indentation

Incorrect indentation causes an `IndentationError`.

```python
if 10 > 5:
print("Hello")
```

**Error:**

```text
IndentationError: expected an indented block
```

## 5. Python is Case-Sensitive

Python treats uppercase and lowercase letters differently.

```python
name = "Python"
Name = "Java"

print(name)
print(Name)
```

**Output:**

```text
Python
Java
```

## 6. Python Line Continuation

Python allows long statements to continue across multiple lines using parentheses or a backslash.

**Using parentheses:**

```python
total = (
    10 + 20 +
    30 + 40
)

print(total)
```

**Using backslash:**

```python
total = 10 + 20 + \
        30 + 40

print(total)
```
