## 2. Dynamic Typing
Python automatically determines the data type at runtime. A variable can refer to objects of different types.

```python
x = 10
print(type(x))
```

## 3. Multiple Variable Assignment

```python
a, b, c = 10, 20, 30

print(a, b, c)
```

## 4. Variable Naming Rules

1. Must start with a letter or underscore (`_`).
2. Cannot start with a number.
3. Can contain letters, numbers, and underscores.
4. Cannot contain spaces or special characters.
5. Cannot use Python keywords.
6. Variable names are case-sensitive.

**Valid Names:**

```python
name = "Python"
_age = 23
student_marks = 90
number1 = 100
```

**Invalid Names:**

```python
2name = "Python"       # Starts with a number
student-name = "Ram"   # Contains hyphen
my name = "John"       # Contains space
class = 10             # Reserved keyword
```
