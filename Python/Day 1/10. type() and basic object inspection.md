# Type() and Basic Object Inspection in Python

## 1. `type()`

The `type()` function returns the data type (class) of an object.

```python
a = 100
b = 10.5
c = "Python"
d = [10, 20, 30]

print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>
print(type(c))  # <class 'str'>
print(type(d))  # <class 'list'>
```

## 2. `isinstance()`

Checks whether an object belongs to a particular type or class.

```python
age = 23

print(isinstance(age, int))    # True
print(isinstance(age, str))    # False
print(isinstance(age, (int, float)))  # True
```

## 3. `id()`

Returns the identity of an object. It is useful for checking whether two variables refer to the same object.

```python
a = [10, 20, 30]
b = a

print(id(a))
print(id(b))

print(a is b)  # True
```

Both variables refer to the same list object, so their identities are equal.

## 4. `dir()`

Returns a list of attributes and methods available for an object.

```python
numbers = [10, 20, 30]

print(dir(numbers))
```

To check available string methods:

```python
text = "Python"

print(dir(text))
```

## 5. `help()`

Displays documentation and information about an object, function, or class.

```python
help(str)
```

To get information about a specific method:

```python
help(list.append)
```

## 6. `callable()`

Checks whether an object can be called like a function.

```python
def greet():
    print("Hello!")

print(callable(greet))  # True
print(callable(100))    # False
```

## 7. `repr()`

Returns a developer-oriented string representation of an object.

```python
name = "Python"

print(str(name))   # Python
print(repr(name))  # 'Python'
```

Notice that `repr()` displays quotation marks around the string.

## 8. `vars()`

Returns an object's `__dict__` attribute, which usually contains its writable instance attributes. It works with objects that have such an attribute.

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student = Student("Vikith", 23)

print(vars(student))
# {'name': 'Vikith', 'age': 23}
```

## 9. `hasattr()`

Checks whether an object has a specified attribute.

```python
class Student:
    name = "Vikith"

student = Student()

print(hasattr(student, "name"))  # True
print(hasattr(student, "age"))   # False
```

## 10. `getattr()`

Gets the value of a specified attribute.

```python
class Student:
    name = "Vikith"

student = Student()

print(getattr(student, "name"))  # Vikith
print(getattr(student, "age", 0))  # 0
```

The third argument is an optional default value returned when the attribute does not exist.

## 11. `setattr()`

Creates or updates an object's attribute.

```python
class Student:
    pass

student = Student()

setattr(student, "name", "Vikith")

print(student.name)  # Vikith
```

## 12. `delattr()`

Deletes an object's specified attribute.

```python
class Student:
    name = "Vikith"

student = Student()

delattr(student, "name")

print(hasattr(student, "name"))  # False
```
