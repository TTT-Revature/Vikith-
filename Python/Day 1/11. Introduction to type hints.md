# Introduction to Type Hints in Python

## 1. What are Type Hints?

Type hints are used to indicate the expected data types of variables, function parameters, and return values.

They make code easier to read, understand, and maintain.

Python is dynamically typed, so type hints do not enforce types at runtime by themselves.

### Example Without Type Hints

```python
name = "Vikith"
age = 23

def add(a, b):
    return a + b
```

### Example With Type Hints

```python
name: str = "Vikith"
age: int = 23

def add(a: int, b: int) -> int:
    return a + b
```
