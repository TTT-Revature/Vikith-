## 2. Implicit Type Conversion

Python automatically converts one data type into another when required.

### Example

```python
a = 10
b = 2.5

result = a + b

print(result)        # 12.5
print(type(result))  # <class 'float'>
```

**Explanation:**
- `a` is an integer.
- `b` is a float.
- Python automatically converts the integer into a float during the operation.
- The result is a float.

### Another Example

```python
x = 5
y = 2

result = x / y

print(result)        # 2.5
print(type(result))  # <class 'float'>
```

The `/` operator returns a float, even when both operands are integers.

## 3. Explicit Type Conversion

Explicit conversion means manually converting a value using Python's built-in functions.

### A. `int()`

Converts a compatible value into an integer.

```python
a = 10.8
b = int(a)

print(b)        # 10
print(type(b))  # <class 'int'>
```

**Note:** `int()` removes the decimal part; it does not round the number.

```python
print(int(9.9))   # 9
print(int(-9.9))  # -9
print(int("100")) # 100
```

### B. `float()`

Converts a compatible value into a float.

```python
a = 10
b = float(a)

print(b)        # 10.0
print(type(b))  # <class 'float'>
```

```python
print(float("25.5"))  # 25.5
print(float(10))      # 10.0
```

### C. `str()`

Converts a value into a string.

```python
a = 100
b = str(a)

print(b)        # "100"
print(type(b))  # <class 'str'>
```

```python
age = 23
message = "My age is " + str(age)

print(message)
```

### D. `bool()`

Converts a value into a Boolean (`True` or `False`).

```python
print(bool(1))       # True
print(bool(0))       # False
print(bool("Hello")) # True
print(bool(""))      # False
```

**Important Boolean rules:**

| Value | Boolean Result |
|---|---|
| `0` | `False` |
| `1` | `True` |
| `""` | `False` |
| `"False"` | `True` |
| `[]` | `False` |
| `[0]` | `True` |
| `()` | `False` |
| `{}` | `False` |
| `None` | `False` |

### E. `list()`

Converts an iterable into a list.

```python
a = (10, 20, 30)
b = list(a)

print(b)        # [10, 20, 30]
print(type(b))  # <class 'list'>
```

```python
text = "Python"
print(list(text))
# ['P', 'y', 't', 'h', 'o', 'n']
```

### F. `tuple()`

Converts an iterable into a tuple.

```python
a = [10, 20, 30]
b = tuple(a)

print(b)        # (10, 20, 30)
print(type(b))  # <class 'tuple'>
```

### G. `set()`

Converts an iterable into a set. Duplicate elements are removed.

```python
a = [10, 20, 10, 30]
b = set(a)

print(b)  # {10, 20, 30}
```

### H. `frozenset()`

Creates an immutable set from an iterable.

```python
numbers = frozenset([10, 20, 30])

print(numbers)
print(type(numbers))
```

### I. `dict()`

Creates a dictionary from key-value pairs.

```python
student = dict([
    ("name", "Vikith"),
    ("age", 23)
])

print(student)
# {'name': 'Vikith', 'age': 23}
```

### J. `bytes()`

Creates an immutable sequence of bytes.

```python
data = bytes([65, 66, 67])

print(data)  # b'ABC'
```

### K. `bytearray()`

Creates a mutable sequence of bytes.

```python
data = bytearray([65, 66, 67])
data[0] = 68

print(data)  # bytearray(b'DBC')
```

## 4. Type Conversion Errors

Not every value can be converted into every data type.

### Example 1: Invalid Integer Conversion

```python
x = "Python"
print(int(x))
```

Output:
```text
ValueError: invalid literal for int()
```

### Example 2: Invalid Float Conversion

```python
x = "Hello"
print(float(x))
```

Output:
```text
ValueError
```

### Example 3: Invalid String Conversion for Arithmetic

```python
a = "10"
b = 5

print(a + b)
```

Output:
```text
TypeError
```

Correct approach:

```python
a = "10"
b = 5

print(int(a) + b)  # 15
```
