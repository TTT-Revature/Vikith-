- **Mutable:** Objects whose contents can be modified after creation.
- **Immutable:** Objects whose value cannot be modified after creation.

## 2. Mutable Objects

Mutable objects can be changed without creating a new object.

### Examples
- `list`
- `dict`
- `set`
- `bytearray`

## 3. Immutable Objects

Immutable objects cannot be modified after creation. Any operation that appears to change their value creates a new object instead.

### Examples
- `int`
- `float`
- `complex`
- `bool`
- `str`
- `tuple`
- `range`
- `frozenset`
- `bytes`

### Example: Integer

```python
x = 10
x = x + 5

print(x)  # 15
```

The integer object `10` is not changed. The variable `x` is assigned to the result, `15`.

### Example: String

```python
name = "Python"

name = name + " Programming"

print(name)  # Python Programming
```

A new string is created instead of modifying the original string.

### Example: Tuple

```python
numbers = (10, 20, 30)

# This will raise TypeError:
numbers[0] = 100
```

Tuple elements cannot be reassigned.

## 4. Difference Between Mutable and Immutable

| Mutable | Immutable |
|---|---|
| Can be modified | Cannot be modified |
| Contents can change | Value cannot change |
| Examples: list, dict, set | Examples: int, str, tuple |
| Supports item modification where applicable | Does not support item modification |

## 5. Understanding Variables and Memory References

In Python, variables refer to objects in memory.

### Example 1: Mutable Object

```python
original = [10, 20, 30]
copied = original

copied.append(40)

print(original)  # [10, 20, 30, 40]
print(copied)    # [10, 20, 30, 40]
```

**Why?**

Both variables refer to the same list object. Changing the list through one variable is visible through the other.

### Example 2: Immutable Object

```python
a = 10
b = a

b = b + 5

print(a)  # 10
print(b)  # 15
```

**Why?**

Integers are immutable. Assigning `b = b + 5` makes `b` refer to the result `15`. It does not change the integer object referenced by `a`.

## 6. Difference Between Assignment and Copying

### Assignment

```python
original = [1, 2, 3]
copied = original

copied.append(4)

print(original)  # [1, 2, 3, 4]
```

Both variables refer to the same list.

### Shallow Copy Using `copy()`

```python
original = [1, 2, 3]
copied = original.copy()

copied.append(4)

print(original)  # [1, 2, 3]
print(copied)    # [1, 2, 3, 4]
```

A new outer list is created. Changes to the outer list do not affect the original.

**Important:** A shallow copy does not independently copy nested mutable objects.

## 7. Checking Object Identity

Use `id()` to get an object's identity during its lifetime.

```python
a = [10, 20]
b = a

print(id(a))
print(id(b))
```

Both variables refer to the same object, so their IDs are equal.

Use `is` to check whether two variables refer to the same object.

```python
print(a is b)  # True
```
