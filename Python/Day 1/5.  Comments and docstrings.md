# Comments and Docstrings in Python

## 1. Single-Line Comments

Comments start with the `#` symbol and are ignored during execution.

```python
# This is a single-line comment
print("Hello Python")
```

## 2. Multi-Line Comments

Use multiple `#` symbols to write comments across multiple lines.

```python
# This is the first line
# This is the second line
# This is the third line
print("Python Programming")
```

## 3. Docstrings

Docstrings are used to document functions, classes, and modules. They are written using triple quotes.

```python
def greet():
    """This function displays a greeting."""
    print("Hello!")

greet()
```

## 4. Accessing Docstrings

Use the `__doc__` attribute to access a function's docstring.

```python
def add():
    """This function performs addition."""
    print(10 + 20)

print(add.__doc__)
```

**Output:**
```text
This function performs addition.
```
