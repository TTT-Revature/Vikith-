Text Type:	str
Numeric Types:	int, float, complex
Sequence Types:	list, tuple, range
Mapping Type:	dict
Set Types:	set, frozenset
Boolean Type:	bool
Binary Types:	bytes, bytearray, memoryview

# Python Data Types – Examples

## 1. Sequence Types

Sequence types store multiple values in an ordered collection.

### List
```python
fruits = ["Apple", "Banana", "Mango"]
print(fruits)
```

### Tuple
```python
numbers = (10, 20, 30)
print(numbers)
```

### Range
```python
numbers = range(1, 6)
print(list(numbers))  # [1, 2, 3, 4, 5]
```

## 2. Mapping Type

### Dictionary (`dict`)
Stores data in key-value pairs.

```python
student = {
    "name": "Vikith",
    "age": 23,
    "course": "MCA"
}
print(student)
```

## 3. Set Types

### Set (`set`)
Stores unique elements.

```python
numbers = {10, 20, 30, 20}
print(numbers)  # {10, 20, 30}
```

### Frozen Set (`frozenset`)
An immutable set whose elements cannot be added or removed.

```python
numbers = frozenset([10, 20, 30])
print(numbers)
```

## 4. Boolean Type

### Boolean (`bool`)
Represents either `True` or `False`.

```python
is_active = True
is_logged_in = False

print(is_active)
print(is_logged_in)
```

## 5. Binary Types

### Bytes (`bytes`)
Stores an immutable sequence of bytes.

```python
data = bytes([65, 66, 67])
print(data)  # b'ABC'
```

### Bytearray (`bytearray`)
Stores a mutable sequence of bytes.

```python
data = bytearray([65, 66, 67])
data[0] = 68

print(data)  # bytearray(b'DBC')
```

### Memoryview (`memoryview`)
Provides a memory-efficient view of binary data without copying it.

```python
data = bytes([65, 66, 67])
view = memoryview(data)

print(view[0])  # 65
```

## 6. None Type

### NoneType
Represents the absence of a value.

```python
result = None

print(result)       # None
print(type(result)) # <class 'NoneType'>
```
