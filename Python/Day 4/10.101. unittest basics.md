# 93. Python unittest Basics

## 1. What is unittest?

`unittest` is Python's built-in testing framework used to test individual functions, methods and components of a program.

It helps developers verify whether their code produces the expected results.

**Important:** `unittest` comes with Python. No separate pip installation is required.

```python
import unittest
```

## 2. Why Do We Use unittest?

- To identify bugs in code.
- To verify individual functions.
- To check expected and actual results.
- To automatically execute test cases.
- To ensure existing functionality works after code changes.

## 3. Understanding Test Cases

A test case is a specific condition or scenario used to verify a piece of code.

Example:

```python
def add(a, b):
    return a + b
```

Test case:

```python
assert add(10, 20) == 30
```

Here:

- Function: `add(10, 20)`
- Expected result: `30`
- Actual result: `30`

The test passes because both values match.

## 4. Creating Your First unittest Program

Consider a calculator application.

### Step 1: Create calculator.py

```python
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b
```

### Step 2: Create test_calculator.py

```python
import unittest

from calculator import add, subtract


class TestCalculator(unittest.TestCase):

    def test_add(self):
        self.assertEqual(add(10, 20), 30)

    def test_subtract(self):
        self.assertEqual(subtract(20, 10), 10)


if __name__ == "__main__":
    unittest.main()
```

### Step 3: Run the Test

```bash
python -m unittest -v
```

Output:

```text
test_add (test_calculator.TestCalculator) ... ok
test_subtract (test_calculator.TestCalculator) ... ok

----------------------------------------------------------------------
Ran 2 tests

OK
```

## 5. Understanding the unittest Structure

```python
import unittest

class TestCalculator(unittest.TestCase):

    def test_add(self):
        self.assertEqual(10 + 20, 30)


if __name__ == "__main__":
    unittest.main()
```

| Code | Meaning |
|---|---|
| `import unittest` | Imports the testing framework |
| `TestCalculator` | Test class |
| `unittest.TestCase` | Parent class providing testing methods |
| `test_add()` | Test method |
| `self.assertEqual()` | Compares expected and actual values |
| `unittest.main()` | Starts the test runner |

## 6. Understanding Test Method Naming

By default, unittest discovers test methods whose names start with `test`.

Correct:

```python
def test_add(self):
    pass

def test_string(self):
    pass

def test_subtract(self):
    pass
```

Not discovered by default:

```python
def add_test(self):
    pass

def teststring(self):
    pass

def string_test(self):
    pass
```

**Remember:** Use the `test_` prefix for test methods.
