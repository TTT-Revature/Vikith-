# Python asyncio and Basic Asynchronous Tasks

## 1. What is asyncio?

`asyncio` is Python's built-in library for writing asynchronous programs.

It allows multiple tasks to make progress concurrently without blocking while waiting for operations such as network requests, API responses, or database queries.

**Use cases:**
- Downloading multiple files
- Sending multiple API requests
- Database operations
- Network communication
- Handling multiple client connections

```python
import asyncio
```

## 2. What is an Asynchronous Function?

An asynchronous function is defined using the `async def` keyword.

```python
async def greet():
    print("Hello, Python!")
```

Calling an asynchronous function creates a coroutine object. It does not execute the function body immediately.

```python
result = greet()
print(result)
```

To execute the coroutine, we need to await it or schedule it as a task.

## 3. Running an Async Function with asyncio.run()

`asyncio.run()` executes the main coroutine and manages the event loop.

```python
import asyncio

async def greet():
    print("Hello, Python!")

asyncio.run(greet())
```

**Output:**
```text
Hello, Python!
```

## 4. Understanding await

`await` is used inside an asynchronous function to wait for an awaitable operation.

When a coroutine reaches an unfinished awaitable operation, it suspends. The event loop can then run other ready tasks.

```python
import asyncio

async def task():
    print("Task started")

    await asyncio.sleep(2)

    print("Task completed")

asyncio.run(task())
```

**Output:**
```text
Task started
(waiting for 2 seconds)
Task completed
```

## 5. Understanding asyncio.sleep()

`asyncio.sleep()` suspends the current coroutine for a specified duration without blocking the event-loop thread.

```python
import asyncio

async def cooking():
    print("Cooking started")

    await asyncio.sleep(3)

    print("Cooking completed")

asyncio.run(cooking())
```

**Important:** Use `asyncio.sleep()` instead of `time.sleep()` inside asynchronous code when you want other coroutines to continue running.

## 6. Running Multiple Tasks with asyncio.gather()

`asyncio.gather()` allows multiple awaitables to run concurrently.

```python
import asyncio

async def task1():
    print("Task 1 started")
    await asyncio.sleep(3)
    print("Task 1 completed")

async def task2():
    print("Task 2 started")
    await asyncio.sleep(2)
    print("Task 2 completed")

async def main():
    await asyncio.gather(task1(), task2())

asyncio.run(main())
```

**Possible output:**
```text
Task 1 started
Task 2 started
Task 2 completed
Task 1 completed
```

Both tasks make progress while the other is waiting.

Approximate total time: 3 seconds instead of 5 seconds.

## 7. Creating Tasks with asyncio.create_task()

`asyncio.create_task()` schedules a coroutine to run as an asyncio task.

```python
import asyncio

async def download_file():
    print("Download started")
    await asyncio.sleep(3)
    print("Download completed")

async def main():
    task = asyncio.create_task(download_file())

    print("Doing other work")

    await task

asyncio.run(main())
```

**Possible output:**
```text
Doing other work
Download started
(waiting for 3 seconds)
Download completed
```

The scheduled task can make progress while the main coroutine performs other work.

## 8. Difference Between gather() and create_task()

| asyncio.gather() | asyncio.create_task() |
|---|---|
| Runs multiple awaitables concurrently | Schedules a coroutine as a task |
| Returns results together | Returns a Task object |
| Useful for grouping multiple operations | Useful for scheduling individual tasks |

```python
# Run multiple awaitables together
await asyncio.gather(task1(), task2())

# Schedule an individual coroutine
task = asyncio.create_task(task1())
await task
```

## 9. What is an Event Loop?

An event loop manages and schedules asynchronous tasks.

Its responsibilities include:

1. Scheduling coroutines.
2. Running ready tasks.
3. Suspending coroutines when they await unfinished operations.
4. Resuming coroutines when their awaited operations are ready.

Think of the event loop as a manager that decides which task should run next.

## 10. Synchronous vs Asynchronous Execution

### Synchronous example

```python
import time

def task1():
    time.sleep(2)
    print("Task 1 completed")

def task2():
    time.sleep(2)
    print("Task 2 completed")

task1()
task2()
```

Approximate total time: 4 seconds.

### Asynchronous example

```python
import asyncio

async def task1():
    await asyncio.sleep(2)
    print("Task 1 completed")

async def task2():
    await asyncio.sleep(2)
    print("Task 2 completed")

async def main():
    await asyncio.gather(task1(), task2())

asyncio.run(main())
```

Approximate total time: 2 seconds.

## 11. Real-World Scenario: Downloading Multiple Files

Imagine downloading three files from a server.

- **Synchronous:** Download file 1 and wait until it finishes, then download file 2.
- **Asynchronous:** Start multiple downloads and allow them to make progress while waiting for network responses.

This makes asyncio useful for applications that handle many I/O operations.

## 12. Important asyncio Functions

| Function | Purpose |
|---|---|
| `asyncio.run()` | Runs the main coroutine |
| `asyncio.sleep()` | Suspends the current coroutine |
| `asyncio.gather()` | Runs multiple awaitables concurrently |
| `asyncio.create_task()` | Schedules a coroutine as a task |
| `asyncio.get_running_loop()` | Gets the currently running event loop |

## 13. Important Points to Remember

- `async def` defines a coroutine function.
- Calling an async function creates a coroutine object.
- `await` suspends the current coroutine while waiting.
- `asyncio.run()` starts and manages the event loop.
- `asyncio.gather()` runs multiple awaitables concurrently.
- `asyncio.create_task()` schedules a coroutine as a task.
- `asyncio.sleep()` does not block the event-loop thread.
- Asyncio is particularly useful for I/O-bound tasks.
- Asyncio concurrency does not mean multiple Python instructions execute simultaneously on a single event-loop thread.
