# 95. Introduction to pytest

## 1. What is pytest?

`pytest` is a popular Python testing framework used to write and run automated tests.

It makes testing easier with simple syntax and less boilerplate code.

**Main features:**
- Simple test functions.
- Automatic test discovery.
- Detailed failure reports.
- Supports fixtures.
- Supports parameterized testing.
- Works with both `unittest` and pytest-style tests.

## 2. Installing pytest

Unlike `unittest`, pytest is an external package and must be installed.

```bash
pip install pytest
```

Check the installed version:

```bash
pytest --version
```

## 3. First pytest Program

Create a file named `test_calculator.py`.

```python
def test_addition():
    assert 10 + 5 == 15

def test_subtraction():
    assert 10 - 5 == 5
```

**Explanation:**

- Test functions start with `test_`.
- Python's normal `assert` statement checks the condition.
- If the condition is True, the test passes.
- If the condition is False, the test fails.

Unlike unittest, we don't need to create a class or inherit from `unittest.TestCase`.

## 4. Running pytest

Run all discovered tests:

```bash
pytest
```

Run with detailed output:

```bash
pytest -v
```

Run a specific file:

```bash
pytest test_calculator.py
```

Run a specific test function:

```bash
pytest test_calculator.py::test_addition
```

## 5. Understanding pytest Output

Example:

```text
============================= test session starts =============================
collected 2 items

test_calculator.py ..                                                [100%]

============================== 2 passed ======================================
```

**Symbols:**

| Symbol | Meaning |
|---|---|
| `.` | Test passed |
| `F` | Test failed |
| `E` | Error occurred during test execution |

## 6. Testing Your Own Functions

Create a file named `calculator.py`.

```python
def add(a, b):
    return a + b

def divide(a, b):
    if b == 0:
        raise ValueError("Cannot divide by zero")

    return a / b
```

Create `test_calculator.py`.

```python
import pytest
from calculator import add, divide

def test_add():
    assert add(10, 5) == 15

def test_divide():
    assert divide(10, 2) == 5

def test_invalid_division():
    with pytest.raises(ValueError):
        divide(10, 0)
```

**Explanation:**

- `assert` checks the returned result.
- `pytest.raises()` checks whether the expected exception occurs.
- If the expected exception is raised, the test passes.

## 7. Custom Failure Messages

You can provide a custom message using Python's assert statement.

```python
def test_addition():
    result = 10 + 5

    assert result == 20, "Addition result is incorrect"
```

The custom message appears when the assertion fails.

## 8. pytest vs unittest

| Feature | unittest | pytest |
|---|---|---|
| Installation | Built into Python | Requires pip |
| Test structure | Usually classes | Simple functions |
| Assertion | `self.assertEqual()` | `assert` |
| Exception testing | `assertRaises()` | `pytest.raises()` |
| Test discovery | Built-in | Automatic |
| Fixtures | `setUp()` and `tearDown()` | `@pytest.fixture` |

## 9. Important Naming Rules

By default, pytest discovers:

- Files named `test_*.py` or `*_test.py`.
- Functions whose names start with `test`.
- Methods whose names start with `test` inside test classes named `Test...`.

Example:

```python
def test_login():
    assert True
```

## 10. Key Points

- pytest is a Python testing framework.
- Install it using `pip install pytest`.
- Use `assert` to verify expected results.
- Use `pytest.raises()` to test exceptions.
- Test files and functions follow naming conventions.
- Run tests using `pytest` or `pytest -v`.
- pytest supports fixtures and parameterized testing, which we will learn next.
