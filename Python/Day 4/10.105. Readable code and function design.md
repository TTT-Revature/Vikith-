# Readable Code and Function Design

## 1. What is Readable Code?

Readable code is code that is easy to understand, modify, debug, and maintain.

Good code should not only work correctly but should also be understandable to other developers.

### Example

**Bad:**
```python
x = 100
y = 5
z = x * y
print(z)
```

**Good:**
```python
product_price = 100
quantity = 5

total_price = product_price * quantity
print(total_price)
```

## 2. Principles of Readable Code

### A. Meaningful Naming

Use meaningful names for variables, functions, and classes.

| Element | Naming Convention | Example |
|---|---|---|
| Variable | snake_case | `total_price` |
| Function | snake_case | `calculate_total()` |
| Class | PascalCase | `ShoppingCart` |
| Constant | UPPER_CASE | `TAX_RATE` |

**Example:**
```python
# Bad
def calc(a, b):
    return a * b

# Good
def calculate_total_price(price, quantity):
    return price * quantity
```

### B. Keep Code Simple

Avoid unnecessarily complicated expressions.

```python
# Complicated
result = True if age >= 18 else False

# Simple
result = age >= 18
```

### C. Avoid Unnecessary Comments

Comments should explain why something is done instead of repeating what the code already says.

```python
# Include delivery charges in the final amount
final_amount = product_price + delivery_charge
```

### D. Proper Indentation and Spacing

Use 4 spaces for indentation and maintain consistent spacing.

```python
def calculate_total(price, quantity):
    total = price * quantity
    return total
```

## 3. Function Design

A function is a reusable block of code designed to perform a particular task.

A well-designed function should be simple, reusable, and easy to test.

### A. Single Responsibility Principle (SRP)

A function should have one main responsibility.

**Bad design:**
```python
def employee_details(name, salary):
    bonus = salary * 0.10
    total = salary + bonus

    print(name)
    print(bonus)
    print(total)
```

**Better design:**
```python
def calculate_bonus(salary):
    return salary * 0.10


def calculate_total_salary(salary, bonus):
    return salary + bonus


def display_employee(name, total_salary):
    print("Employee:", name)
    print("Total Salary:", total_salary)
```
