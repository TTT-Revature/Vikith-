# Multiprocessing in Python

## 1. What is Multiprocessing?

Multiprocessing means running multiple processes to perform tasks independently.

A process is an instance of a running program.

Multiprocessing allows multiple processes to execute simultaneously, potentially using different CPU cores.

### Real-world example

Imagine processing 100 wedding invitation images using 4 CPU cores.

- Process 1 processes images 1–25.
- Process 2 processes images 26–50.
- Process 3 processes images 51–75.
- Process 4 processes images 76–100.

Multiple processes can work simultaneously, reducing processing time for suitable workloads.

---

## 2. Process vs Thread

| Threading | Multiprocessing |
|---|---|
| Multiple threads | Multiple processes |
| Threads belong to one process | Each process has its own memory space |
| Threads share process memory | Processes have separate memory spaces by default |
| Lightweight | More resource-intensive |
| Useful for I/O-bound tasks | Useful for CPU-bound tasks |
| GIL limits Python bytecode parallelism in standard CPython | Can achieve CPU parallelism using multiple processes |

---

## 3. Importing the Multiprocessing Module

Python provides the `multiprocessing` module to create and manage processes.

```python
from multiprocessing import Process
```

The `Process` class is used to create a new process.

---

## 4. Creating Your First Process

```python
from multiprocessing import Process

def task():
    print("Task is running")

if __name__ == "__main__":
    p1 = Process(target=task)

    p1.start()
    p1.join()

    print("Main program completed")
```

Output:

```text
Task is running
Main program completed
```

### Explanation

- `Process()` creates a process object.
- `target=task` specifies the function to execute.
- `start()` starts the process.
- `join()` waits for the process to finish.
- `if __name__ == "__main__"` protects the process creation code from running again when the module is imported by a child process.

**Important:** The main guard is especially important on Windows.

---

## 5. Creating Multiple Processes

We can create multiple processes to execute different tasks.

```python
from multiprocessing import Process

def task(name):
    print(f"{name} is running")

if __name__ == "__main__":

    p1 = Process(target=task, args=("Process 1",))
    p2 = Process(target=task, args=("Process 2",))

    p1.start()
    p2.start()

    p1.join()
    p2.join()

    print("All processes completed")
```

Possible output:

```text
Process 1 is running
Process 2 is running
All processes completed
```

The order of the first two messages may vary because the processes execute independently.

### Understanding `args`

```python
p1 = Process(target=task, args=("Process 1",))
```

- `target` specifies the function.
- `args` passes arguments to that function.
- `args` must be a tuple.
- A single-element tuple requires a trailing comma.

## 6. Multiprocessing Methods

| Method / Attribute | Description |
|---|---|
| `Process()` | Creates a process |
| `start()` | Starts the process |
| `join()` | Waits for process completion |
| `is_alive()` | Checks whether a process is running |
| `terminate()` | Requests process termination |
| `pid` | Returns the process ID |
| `exitcode` | Returns the process exit status |

### Example: Getting Process ID

```python
from multiprocessing import Process
import os

def task():
    print("Child Process ID:", os.getpid())

if __name__ == "__main__":
    p1 = Process(target=task)

    p1.start()
    p1.join()

    print("Main Process ID:", os.getpid())
```

Each process has its own process ID.

## 7. Shared Data in Multiprocessing

In multiprocessing, each process has its own memory space.

Changes made to an ordinary variable in a child process do not automatically affect the parent's variable.

### Example

```python
from multiprocessing import Process

balance = 1000

def update_balance():
    global balance

    balance = 500

    print("Child balance:", balance)

if __name__ == "__main__":
    p1 = Process(target=update_balance)

    p1.start()
    p1.join()

    print("Main balance:", balance)
```

Output:

```text
Child balance: 500
Main balance: 1000
```

### Why?

1. The main process has its own `balance` variable.
2. The child process gets its own process memory.
3. The child changes its own copy to 500.
4. The parent's balance remains 1000.

### Sharing Data Between Processes

Python provides several mechanisms to share data between processes:

- `Value` – Shares a single value.
- `Array` – Shares an array of values.
- `Queue` – Exchanges data between processes.
- `Manager` – Provides shared objects such as lists and dictionaries through a manager process.

These mechanisms are useful when processes need to communicate or coordinate.

## 8. Practical Example: Processing Numbers

```python
from multiprocessing import Pool

def calculate_square(number):
    return number * number

if __name__ == "__main__":
    numbers = [10, 20, 30, 40, 50]

    with Pool(processes=4) as pool:
        results = pool.map(calculate_square, numbers)

    print(results)
```

Output:

```text
[100, 400, 900, 1600, 2500]
```

### Explanation

- `Pool(processes=4)` creates a pool with four worker processes.
- `map()` distributes input items among the workers.
- Each worker executes `calculate_square()`.
- Results are returned in the same order as the input.
- The `with` statement manages the pool lifecycle.

**Note:** For very small calculations, process creation and communication overhead may outweigh the performance benefit.

## 9. When Should We Use Multiprocessing?

Multiprocessing is commonly useful for CPU-bound tasks.

Examples:

- Image processing
- Video rendering
- Mathematical calculations
- Large data processing
- Scientific computations
- CPU-intensive machine learning tasks

For I/O-bound tasks, threading or asyncio may be more suitable.

## 11. Interview Questions and Answers

### Q1. What is multiprocessing in Python?

Multiprocessing allows multiple independent processes to execute tasks simultaneously, potentially using multiple CPU cores.

### Q2. Why do we use multiprocessing?

It is commonly used for CPU-intensive tasks to achieve parallel execution.

### Q3. What is the difference between threading and multiprocessing?

Threading uses multiple threads within one process, while multiprocessing uses separate processes with independent memory spaces.

### Q4. What does `join()` do?

It makes the calling process wait until the specified process finishes.

### Q5. Why do we use the main guard?

It prevents process creation code from executing again when a child process imports the main module, particularly on Windows.

### Q6. Can processes share data?

Yes. Python provides `Value`, `Array`, `Queue`, and `Manager` for inter-process communication and shared data.

### Q7. What is a process ID?

A process ID (PID) is a unique identifier assigned to a process by the operating system.

### Q8. What is a process pool?

A process pool manages multiple worker processes and distributes tasks among them.
