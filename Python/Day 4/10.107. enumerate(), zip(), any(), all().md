# Python Built-in Functions: enumerate(), zip(), any(), all()

## 1. enumerate()

### What is enumerate()?

`enumerate()` is used to loop through an iterable and get both the index and value of each element.

### Example 1: Basic Usage

```python
fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

**Output:**
```text
0 Apple
1 Banana
2 Mango
```

- `index` represents the position of the element.
- `fruit` represents the actual element.
- By default, indexing starts from `0`.

### Example 2: Changing the Starting Index

Use the `start` parameter to change the starting index.

```python
fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits, start=1):
    print(index, fruit)
```

**Output:**
```text
1 Apple
2 Banana
3 Mango
```

### Example 3: Converting enumerate() into a list

```python
fruits = ["Apple", "Banana", "Mango"]

result = list(enumerate(fruits))

print(result)
```

**Output:**
```python
[(0, 'Apple'), (1, 'Banana'), (2, 'Mango')]
```

Each element is a tuple containing `(index, value)`.

### Example 4: Using enumerate() with strings

```python
name = "Python"

for index, character in enumerate(name):
    print(index, character)
```

**Output:**
```text
0 P
1 y
2 t
3 h
4 o
5 n
```

### Important Points

- Returns an enumerate iterator.
- Provides both index and value.
- Supports lists, tuples, strings, and other iterables.
- Useful when both position and value are required.

## 2. zip()

### What is zip()?

`zip()` combines elements from multiple iterables based on their positions.

### Example 1: Combining Two Lists

```python
names = ["Rahul", "Amit", "Priya"]
marks = [85, 90, 95]

for name, mark in zip(names, marks):
    print(name, mark)
```

**Output:**
```text
Rahul 85
Amit 90
Priya 95
```

### Example 2: Converting zip() into a list

```python
names = ["Rahul", "Amit"]
marks = [85, 90]

result = list(zip(names, marks))

print(result)
```

**Output:**
```python
[('Rahul', 85), ('Amit', 90)]
```

### Example 3: Using zip() with Three Lists

```python
names = ["Rahul", "Amit", "Priya"]
marks = [85, 90, 95]
cities = ["Chennai", "Bangalore", "Mumbai"]

for name, mark, city in zip(names, marks, cities):
    print(name, mark, city)
```

**Output:**
```text
Rahul 85 Chennai
Amit 90 Bangalore
Priya 95 Mumbai
```

### Example 4: Different Lengths of Iterables

By default, `zip()` stops when the shortest iterable is exhausted.

```python
names = ["Rahul", "Amit", "Priya"]
marks = [85, 90]

print(list(zip(names, marks)))
```

**Output:**
```python
[('Rahul', 85), ('Amit', 90)]
```

`Priya` is not included because there is no corresponding mark.

### Example 5: Unzipping using zip(*)

The `*` operator unpacks an iterable into separate arguments.

```python
students = [
    ("Rahul", 85),
    ("Amit", 90),
    ("Priya", 95)
]

names, marks = zip(*students)

print(names)
print(marks)
```

**Output:**
```text
('Rahul', 'Amit', 'Priya')
(85, 90, 95)
```

### Important Points

- Combines multiple iterables element by element.
- Returns a zip iterator.
- Stops at the shortest iterable by default.
- Can combine two or more iterables.
- Useful for processing related data together.

## 3. any()

### What is any()?

`any()` checks whether at least one element in an iterable is truthy.

**Return behaviour:**

| Iterable | Result |
|---|---|
| `[True, True, True]` | True |
| `[False, True, False]` | True |
| `[False, False, False]` | False |
| `[]` | False |

### Example 1: Basic Usage

```python
values = [False, False, True, False]

print(any(values))
```

**Output:**
```text
True
```

At least one element is True.

### Example 2: Using any() with Numbers

In Python:
- `0` is falsy.
- Non-zero numbers are truthy.

```python
numbers = [0, 0, 10, 0]

print(any(numbers))
```

**Output:**
```text
True
```

Another example:

```python
numbers = [0, 0, 0]

print(any(numbers))
```

**Output:**
```text
False
```

### Example 3: Using any() with Conditions

Check whether any student scored above 90.

```python
marks = [45, 65, 78, 95, 82]

result = any(mark > 90 for mark in marks)

print(result)
```

**Output:**
```text
True
```

The condition is True for at least one student.

### Example 4: Real-World Example

Check whether any product is out of stock.

```python
stock = [True, True, False, True]

if any(item == False for item in stock):
    print("Some items are out of stock")
else:
    print("All items are available")
```

**Output:**
```text
Some items are out of stock
```

### How any() Works

Conceptually, `any()` works like this:

```python
values = [False, False, True, False]

for value in values:
    if value:
        print(True)
        break
```

It stops checking as soon as it finds a truthy element. This is called **short-circuit evaluation**.

### Important Points

- Returns True if at least one element is truthy.
- Returns False if all elements are falsy.
- Returns False for an empty iterable.
- Stops as soon as it finds a truthy element.

## 4. all()

### What is all()?

`all()` checks whether every element in an iterable is truthy.

**Return behaviour:**

| Iterable | Result |
|---|---|
| `[True, True, True]` | True |
| `[True, False, True]` | False |
| `[False, False, False]` | False |
| `[]` | True |

### Example 1: Basic Usage

```python
values = [True, True, True]

print(all(values))
```

**Output:**
```text
True
```

Every element is True.

### Example 2: One False Element

```python
values = [True, True, False, True]

print(all(values))
```

**Output:**
```text
False
```

Even one falsy element makes the result False.

### Example 3: Using all() with Numbers

```python
numbers = [10, 20, 30, 40]

print(all(numbers))
```

**Output:**
```text
True
```

But:

```python
numbers = [10, 20, 0, 40]

print(all(numbers))
```

**Output:**
```text
False
```

Zero is falsy.

### Example 4: Using all() with Conditions

Check whether every student passed an exam with a minimum score of 40.

```python
marks = [65, 80, 45, 90]

result = all(mark >= 40 for mark in marks)

print(result)
```

**Output:**
```text
True
```

Now consider:

```python
marks = [65, 80, 35, 90]

result = all(mark >= 40 for mark in marks)

print(result)
```

**Output:**
```text
False
```

One student scored below 40.

### Example 5: Real-World Example

Check whether all products are available.

```python
stock = [True, True, True, True]

if all(stock):
    print("All products are available")
else:
    print("Some products are unavailable")
```

**Output:**
```text
All products are available
```

### How all() Works

Conceptually:

```python
values = [True, True, False, True]

for value in values:
    if not value:
        print(False)
        break
```

It stops checking as soon as it finds a falsy element. This is also called **short-circuit evaluation**.

### Important Points

- Returns True if every element is truthy.
- Returns False if at least one element is falsy.
- Returns True for an empty iterable.
- Stops as soon as it finds a falsy element.

## 5. Difference Between enumerate(), zip(), any(), and all()

| Function | Purpose | Returns |
|---|---|---|
| `enumerate()` | Gets index and value while iterating | Enumerate iterator |
| `zip()` | Combines multiple iterables | Zip iterator |
| `any()` | Checks whether at least one element is truthy | Boolean |
| `all()` | Checks whether every element is truthy | Boolean |

## 6. Difference Between any() and all()

| Values | any() | all() |
|---|---|---|
| `[True, True, True]` | True | True |
| `[True, False, True]` | True | False |
| `[False, False, False]` | False | False |
| `[]` | False | True |

**Remember:**

- `any()` → At least ONE element must be True.
- `all()` → EVERY element must be True.

## 7. Combined Practical Example

Use `enumerate()`, `zip()`, `any()`, and `all()` in one student result program.

```python
names = ["Rahul", "Amit", "Priya"]
marks = [85, 35, 95]

# Using zip() and enumerate()
for index, (name, mark) in enumerate(zip(names, marks), start=1):
    print(index, name, mark)

# Check whether any student failed
any_failed = any(mark < 40 for mark in marks)

# Check whether all students passed
all_passed = all(mark >= 40 for mark in marks)

print("Any student failed:", any_failed)
print("All students passed:", all_passed)
```

**Output:**
```text
1 Rahul 85
2 Amit 35
3 Priya 95
Any student failed: True
All students passed: False
```

## 8. Key Takeaways

1. `enumerate()` provides index and value during iteration.
2. `zip()` combines multiple iterables based on their positions.
3. `any()` checks whether at least one element is truthy.
4. `all()` checks whether every element is truthy.
5. All four functions are useful for writing clean, readable Python code.
