# 92. Python Unit Testing Concepts and Examples

## 1. What is Unit Testing?

Unit Testing is a software testing technique in which individual units of code are tested separately to verify that they work correctly.

A unit is usually a small part of a program, such as:
- A function
- A method
- A small piece of logic

**Example:**

Suppose we have a function that adds two numbers.

```python
def add(a, b):
    return a + b
```

We need to verify whether this function returns the correct result.

```python
assert add(10, 20) == 30
```

If the result is correct, the assertion passes. Otherwise, Python raises an `AssertionError`.

## 2. Real-World Example: Swiggy

Consider a food delivery application like Swiggy.

It contains multiple functionalities:

- Search restaurants
- Add food to cart
- Calculate total price
- Apply discount coupons
- Calculate delivery charges
- Place orders

Developers test individual functionalities separately.

### Example: Apply Coupon

Suppose:
- Food price = ₹500
- Discount = 20%
- Final price = ₹400

Python function:

```python
def apply_coupon(price, discount):
    discount_amount = price * discount / 100
    return price - discount_amount


print(apply_coupon(500, 20))
```

Output:

```text
400.0
```

Unit test:

```python
assert apply_coupon(500, 20) == 400
```

Here, we are testing only the coupon calculation function.

We are not testing the entire food ordering process.

## 3. Unit Testing in Daily-Use Applications

### A. Swiggy

| Functionality | What We Test |
|---|---|
| Apply coupon | Correct discount calculation |
| Calculate total | Correct food bill |
| Delivery charges | Correct delivery fee |
| Restaurant search | Correct filtering logic |
| Cart quantity | Correct quantity update |

Example:

```python
def calculate_total(price, quantity):
    return price * quantity


assert calculate_total(100, 3) == 300
```

### B. WhatsApp

| Functionality | What We Test |
|---|---|
| Message length | Correct character count |
| Message formatting | Correct text formatting |
| Contact search | Correct contact matching |
| Time formatting | Correct time display |
| Message validation | Empty messages are rejected |

Example:

```python
def validate_message(message):
    return len(message.strip()) > 0


assert validate_message("Hello") == True
assert validate_message("") == False
```
