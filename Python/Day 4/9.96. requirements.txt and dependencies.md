# 89. Python Requirements.txt and Dependencies

## 1. What Are Dependencies?

Dependencies are external packages or libraries that a Python project needs to work properly.

Example:

Suppose your project uses:

```python
import requests
import pandas
import numpy
```

Your project depends on these three packages.

```text
MyProject
   |
   ├── requests
   ├── pandas
   └── numpy
```

These packages are called **project dependencies**.

## 2. Why Do We Need Dependencies?

Imagine you create a project on your laptop.

You have installed:
- requests 2.32.3
- pandas 2.2.3
- numpy 2.2.0

Now you share your project with another developer.

Their laptop has no required packages installed.

When they run your code, Python may show:

```text
ModuleNotFoundError: No module named 'requests'
```

This happens because the required package is missing.

We need a way to share the package requirements with other developers.

That is where `requirements.txt` helps.

## 3. What Is requirements.txt?

`requirements.txt` is a text file that contains the package dependencies required by a Python project.

Example:

```text
requests==2.32.3
pandas==2.2.3
numpy==2.2.0
```

Each line represents a package requirement.

The `==` operator specifies the exact package version.

## 4. How to Create requirements.txt?

First, activate your virtual environment.

Then execute:

```bash
pip freeze > requirements.txt
```

### Understanding the command

| Part | Meaning |
|---|---|
| `pip` | Package installer |
| `freeze` | Displays installed packages with versions |
| `>` | Redirects output into a file |
| `requirements.txt` | File where output is saved |

Example output inside the file:

```text
numpy==2.2.0
pandas==2.2.3
requests==2.32.3
```

**Note:** `pip freeze` lists installed distributions in the current environment, including transitive dependencies.

## 5. How to Install Dependencies?

Suppose another developer receives your project.

They can install all listed dependencies using:

```bash
pip install -r requirements.txt
```

### Understanding the command

- `pip install` installs packages.
- `-r` tells pip to read requirements from a file.
- `requirements.txt` contains the package list.

Instead of installing packages one by one, they can install them using a single command.

## 6. Complete Real-World Example

### Developer A: Creating the Project

Project structure:

```text
MyProject/
│
├── main.py
├── requirements.txt
└── .gitignore
```

Install packages:

```bash
pip install requests pandas
```

Generate the requirements file:

```bash
pip freeze > requirements.txt
```

Now share the project code and `requirements.txt`.

### Developer B: Receiving the Project

First, create a virtual environment:

```bash
python -m venv venv
```

Activate it:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Now the required packages are installed in Developer B's virtual environment.

## 7. Direct Dependencies vs Transitive Dependencies

### Direct Dependencies

Packages that your project directly uses.

Example:

```python
import pandas
```

Here, pandas is a direct dependency.

### Transitive Dependencies

Packages required by your direct dependencies.

Example:

```text
Your Project
     |
     v
   pandas
     |
     v
   numpy
```

If pandas requires NumPy, NumPy is a transitive dependency in this example.

pip normally installs required dependencies automatically.

## 8. What Happens If We Change Package Versions?

Suppose your project uses:

```text
requests==2.31.0
```

You update it to:

```text
requests==2.32.3
```

Now another developer installing from this updated file will request version 2.32.3 instead of 2.31.0.

This helps maintain consistent package versions across development environments.

## 9. Important Commands

| Command | Purpose |
|---|---|
| `pip freeze` | Display installed packages and versions |
| `pip freeze > requirements.txt` | Generate requirements file |
| `pip install -r requirements.txt` | Install listed dependencies |
| `pip install package` | Install a package |
| `pip uninstall package` | Remove a package |
| `pip check` | Check installed dependency compatibility |

## 10. Important Points

- Dependencies are packages required by a project.
- `requirements.txt` stores package requirements.
- `pip freeze` generates a list of installed package versions.
- `pip install -r requirements.txt` installs the listed requirements.
- Always use the correct virtual environment when managing project dependencies.
- Do not upload the `venv` folder to GitHub.
- Share your source code and dependency file instead.
- `requirements.txt` does not automatically install the required Python interpreter.
