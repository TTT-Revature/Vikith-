# 90. Python Standard Library Overview

## 1. What is the Python Standard Library?

Python Standard Library is a collection of pre-built modules and packages that come with Python.

It provides ready-made functionality for common programming tasks.

We don't need to install these modules separately using pip.

Examples:

- `math` - Mathematical operations
- `random` - Random values
- `datetime` - Date and time
- `os` - Operating system operations
- `json` - JSON data handling
- `re` - Regular expressions

Example:

```python
import math

print(math.sqrt(25))
print(math.factorial(5))
```

Output:

```text
5.0
120
```

Here:
- `math` is a Standard Library module.
- `sqrt()` and `factorial()` are functions provided by it.

## 2. Module, Package and Library

| Term | Meaning |
|---|---|
| Module | A Python file containing reusable code |
| Package | A collection of related Python modules |
| Library | A collection of reusable code and functionality |

Example:

```python
import math
import json
```

Here, `math` is a module and `json` is also a module.

The `email` package contains related modules for handling email messages.

## 3. Categories of Standard Library Modules

Python Standard Library provides modules for different purposes.

### A. Mathematical Modules

**1. math**

Used for mathematical operations.

```python
import math

print(math.sqrt(64))
print(math.factorial(5))
print(math.ceil(4.2))
print(math.floor(4.8))
```

Output:

```text
8.0
120
5
4
```

**2. statistics**

Used for statistical calculations.

```python
import statistics

numbers = [10, 20, 30, 40, 50]

print(statistics.mean(numbers))
print(statistics.median(numbers))
```

Output:

```text
30
30
```

**3. random**

Used to generate random values.

```python
import random

print(random.randint(1, 10))
print(random.choice(["Java", "Python", "R"]))
```

Output may change during each execution.

### B. Date and Time Modules

**1. datetime**

Used to work with dates and times.

```python
import datetime

today = datetime.date.today()

print(today)
```

**2. time**

Used for time-related operations.

```python
import time

print("Hello")

time.sleep(2)

print("World")
```

`time.sleep(2)` pauses program execution for 2 seconds.

### C. Operating System Modules

**1. os**

Used to interact with the operating system.

```python
import os

print(os.getcwd())
print(os.listdir())
```

- `getcwd()` - Returns the current working directory.
- `listdir()` - Lists files and directories.

**2. sys**

Used to interact with the Python interpreter and runtime environment.

```python
import sys

print(sys.version)
print(sys.platform)
print(sys.argv)
```

- `sys.version` - Python version information.
- `sys.platform` - Platform information.
- `sys.argv` - Command-line arguments.

**3. pathlib**

Used to work with file and directory paths.

```python
from pathlib import Path

file = Path("data.txt")

print(file.exists())
print(file.name)
```

### D. File and Data Handling Modules

**1. json**

Used to convert Python objects into JSON and JSON into Python objects.

```python
import json

student = {
    "name": "Rahul",
    "age": 22
}

data = json.dumps(student)

print(data)
```

Output:

```text
{"name": "Rahul", "age": 22}
```

**2. csv**

Used to read and write CSV files.

```python
import csv

with open("students.csv", "r", newline="") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)
```

**3. pickle**

Used to serialize and deserialize Python objects.

```python
import pickle

student = {"name": "Rahul", "age": 22}

with open("student.pkl", "wb") as file:
    pickle.dump(student, file)
```

Important: Never load pickle files from untrusted sources because loading them can execute malicious code.

## 4. Standard Library vs External Packages

Not every Python package comes with Python.

There are two main categories:

### Standard Library

Modules already available with a standard Python installation.

Examples:

```python
import math
import json
import datetime
import os
```

No separate pip installation is required.

### External Packages

Packages that are usually installed separately.

Examples:

- NumPy
- Pandas
- Requests
- Django
- Flask

Install an external package using pip:

```bash
pip install requests
```

Comparison:

| Standard Library | External Packages |
|---|---|
| Comes with Python | Installed separately |
| Usually no pip installation needed | Usually installed using pip |
| `math` | `numpy` |
| `json` | `pandas` |
| `datetime` | `requests` |

## 5. How to Explore Standard Library Modules?

Python provides useful functions to explore modules.

### Using help()

```python
import math

help(math)
```

Displays documentation about the module.

### Using dir()

```python
import math

print(dir(math))
```

Displays available names and attributes in the module.

### Checking Module Location

```python
import math

print(math.__file__)
```

Displays the module file location when the module has a `__file__` attribute.

Note: Some built-in modules, such as `sys`, do not have a normal Python file location.

## 6. Real-World Example

Suppose we are developing a Student Management Application.

We need different functionalities:

```python
import datetime
import json
import os
import statistics
import uuid
```

| Requirement | Module |
|---|---|
| Generate student ID | `uuid` |
| Store student records in JSON | `json` |
| Get current date | `datetime` |
| Manage directories | `os` |
| Calculate average marks | `statistics` |

These modules provide ready-made functionality without requiring separate pip installations.

## 7. Important Points

- Python Standard Library contains pre-built modules and packages.
- These modules provide reusable functionality.
- Most standard library modules are available without separate installation.
- `import` is used to access modules.
- `help()` displays module documentation.
- `dir()` displays available names and attributes.
- External packages usually need to be installed separately using pip.
- You don't need to memorize every module; learn their purpose and use them when required.
