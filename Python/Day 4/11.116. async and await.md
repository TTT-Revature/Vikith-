# Python Async and Await

## 1. What is Asynchronous Programming?

Asynchronous programming allows multiple tasks to make progress without waiting for each task to finish sequentially.

It is especially useful for I/O-bound operations such as:
- API requests
- Downloading files
- Database queries
- Reading and writing files

Python provides the `asyncio` module for asynchronous programming.

## 2. `async` Keyword

- `async` is used to define an asynchronous function.
- An asynchronous function is also called a coroutine function.
- Calling it creates a coroutine object; its body does not execute immediately.

```python
async def greet():
    print("Hello!")

result = greet()
print(result)
```

The output will show a coroutine object. The function body has not executed yet.

## 3. `await` Keyword

- `await` is used inside an asynchronous function.
- It waits for an awaitable operation to complete.
- While waiting, the current coroutine suspends, allowing the event loop to run other ready tasks.

```python
import asyncio

async def greet():
    print("Hello!")
    await asyncio.sleep(2)
    print("Welcome!")

asyncio.run(greet())
```

**Output:**
```text
Hello!
(waiting for 2 seconds)
Welcome!
```

## 4. What is `asyncio`?

`asyncio` is Python's built-in library for writing concurrent code using async and await.

Important functions:

| Function | Purpose |
|---|---|
| `asyncio.run()` | Starts and manages the event loop |
| `asyncio.sleep()` | Suspends a coroutine without blocking the event-loop thread |
| `asyncio.gather()` | Runs multiple awaitables concurrently |
| `asyncio.create_task()` | Schedules a coroutine as a task |

## 5. What is an Event Loop?

An event loop manages and schedules asynchronous tasks.

It:
1. Starts and schedules coroutines.
2. Runs a coroutine until it completes or reaches an `await` that suspends it.
3. Runs other ready tasks while a coroutine is waiting.
4. Resumes suspended coroutines when their awaited operations are ready.

## 6. Running Multiple Tasks with `asyncio.gather()`

```python
import asyncio

async def task1():
    print("Task 1 started")
    await asyncio.sleep(3)
    print("Task 1 completed")

async def task2():
    print("Task 2 started")
    await asyncio.sleep(2)
    print("Task 2 completed")

async def main():
    await asyncio.gather(task1(), task2())

asyncio.run(main())
```

**Possible output:**
```text
Task 1 started
Task 2 started
Task 2 completed
Task 1 completed
```

Both tasks make progress concurrently. The total waiting time is approximately 3 seconds instead of 5 seconds.

## 7. Synchronous vs Asynchronous

### Synchronous execution

Tasks execute one after another. Each task must finish before the next begins.

```python
import time

def task1():
    time.sleep(2)
    print("Task 1 completed")

def task2():
    time.sleep(2)
    print("Task 2 completed")

task1()
task2()
```

Approximate total time: 4 seconds.

### Asynchronous execution

Tasks can make progress while other tasks are waiting.

```python
import asyncio

async def task1():
    await asyncio.sleep(2)
    print("Task 1 completed")

async def task2():
    await asyncio.sleep(2)
    print("Task 2 completed")

async def main():
    await asyncio.gather(task1(), task2())

asyncio.run(main())
```

Approximate total time: 2 seconds.

## 8. `time.sleep()` vs `asyncio.sleep()`

| `time.sleep()` | `asyncio.sleep()` |
|---|---|
| Blocks the current thread | Suspends the current coroutine |
| Synchronous | Asynchronous |
| Other coroutines on the same event loop cannot run during the blocking sleep | Event loop can run other ready tasks |

## 9. Important Concepts

- **Coroutine:** An asynchronous function's execution object.
- **Event Loop:** Manages and schedules asynchronous tasks.
- **Await:** Suspends the current coroutine while waiting for an awaitable.
- **Task:** A coroutine scheduled to run by the event loop.
- **Concurrency:** Multiple tasks make progress during overlapping periods.
- **Parallelism:** Multiple tasks execute at the same time, typically on different CPU cores.

**Important:** Asyncio provides concurrency, not automatic parallel execution. In a typical single-threaded event loop, one coroutine's Python code runs at a time.

## 10. Real-World Example

Imagine downloading three files from the internet.

- Synchronous: Download the first file, then the second, then the third.
- Asynchronous: Start the downloads and allow other downloads to make progress while one is waiting for a network response.

Asynchronous programming is useful when applications spend a lot of time waiting for I/O operations.

## 11. Important Points to Remember

- Use `async def` to define a coroutine function.
- Use `await` inside an async function.
- Use `asyncio.run()` to run the main coroutine.
- Use `asyncio.gather()` to run multiple awaitables concurrently.
- Use `asyncio.sleep()` instead of `time.sleep()` inside async code.
- Async programming is particularly useful for I/O-bound tasks.
- Async code does not automatically make CPU-intensive operations faster.
