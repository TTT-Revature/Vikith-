# Python Built-in Functions: sum(), sorted(), min(), max(), reversed()

## 1. sum()

### What is sum()?

`sum()` calculates the total of numerical elements in an iterable.

**Syntax:**
```python
sum(iterable, start=0)
```

- `iterable`: Collection of numerical values.
- `start`: Optional starting value. Default is `0`.

### Example 1: Using sum() with a list

```python
numbers = [10, 20, 30, 40]

result = sum(numbers)

print(result)
```

**Output:**
```text
100
```

### Example 2: Using sum() with a tuple

```python
numbers = (5, 10, 15, 20)

print(sum(numbers))
```

**Output:**
```text
50
```

### Example 3: Using sum() with range()

```python
numbers = range(1, 6)

print(sum(numbers))
```

**Output:**
```text
15
```

### Example 4: Using the start parameter

```python
numbers = [10, 20, 30]

result = sum(numbers, 100)

print(result)
```

**Output:**
```text
160
```

Calculation: `100 + 10 + 20 + 30 = 160`.

### Example 5: Using sum() with conditions

Calculate the total of even numbers.

```python
numbers = [1, 2, 3, 4, 5, 6]

result = sum(num for num in numbers if num % 2 == 0)

print(result)
```

**Output:**
```text
12
```

### Important Points

- Works with numerical values such as integers and floats.
- Returns `0` for an empty iterable by default.
- Does not directly concatenate strings.
- Does not modify the original iterable.

## 2. sorted()

### What is sorted()?

`sorted()` arranges elements in ascending or descending order and returns a new list.

**Syntax:**
```python
sorted(iterable, key=None, reverse=False)
```

| Parameter | Meaning |
|---|---|
| `iterable` | Collection to sort |
| `key` | Function used to determine sorting criteria |
| `reverse` | `True` for descending order |

### Example 1: Sorting numbers

```python
numbers = [50, 10, 40, 20, 30]

result = sorted(numbers)

print(result)
```

**Output:**
```python
[10, 20, 30, 40, 50]
```

By default, sorting is ascending.

### Example 2: Descending order

```python
numbers = [50, 10, 40, 20, 30]

result = sorted(numbers, reverse=True)

print(result)
```

**Output:**
```python
[50, 40, 30, 20, 10]
```

### Example 3: Sorting strings

```python
names = ["Vikram", "Amit", "Rahul", "Priya"]

print(sorted(names))
```

**Output:**
```python
['Amit', 'Priya', 'Rahul', 'Vikram']
```

Strings are sorted lexicographically (based on character values).

### Example 4: Original list remains unchanged

```python
numbers = [40, 10, 30, 20]

result = sorted(numbers)

print("Original:", numbers)
print("Sorted:", result)
```

**Output:**
```text
Original: [40, 10, 30, 20]
Sorted: [10, 20, 30, 40]
```

`sorted()` creates a new list without modifying the original iterable.

### Example 5: Using the key parameter

Sort names based on their length.

```python
names = ["Rahul", "Amit", "Vikram", "Raj"]

result = sorted(names, key=len)

print(result)
```

**Output:**
```python
['Raj', 'Amit', 'Rahul', 'Vikram']
```

`key=len` tells Python to use the length of each string as the sorting criterion.

### Example 6: Sorting a list of dictionaries

```python
students = [
    {"name": "Rahul", "marks": 85},
    {"name": "Amit", "marks": 95},
    {"name": "Priya", "marks": 75}
]

result = sorted(students, key=lambda student: student["marks"])

print(result)
```

**Output:**
```python
[
    {'name': 'Priya', 'marks': 75},
    {'name': 'Rahul', 'marks': 85},
    {'name': 'Amit', 'marks': 95}
]
```

`lambda student: student["marks"]` tells Python to sort using the marks value.

### sorted() vs list.sort()

| `sorted()` | `.sort()` |
|---|---|
| Built-in function | List method |
| Returns a new list | Returns `None` |
| Does not modify original list | Modifies original list |
| Works with many iterables | Works only with lists |

Example:

```python
numbers = [30, 10, 20]

result = numbers.sort()

print(numbers)
print(result)
```

**Output:**
```text
[10, 20, 30]
None
```

## 3. min()

### What is min()?

`min()` returns the smallest element from an iterable or the smallest among multiple arguments.

**Syntax:**
```python
min(iterable, key=None)
min(value1, value2, ...)
```

### Example 1: Using min() with a list

```python
numbers = [50, 10, 40, 20, 30]

print(min(numbers))
```

**Output:**
```text
10
```

### Example 2: Using min() with multiple values

```python
result = min(50, 10, 40, 20, 30)

print(result)
```

**Output:**
```text
10
```

### Example 3: Using min() with strings

```python
names = ["Rahul", "Amit", "Vikram", "Priya"]

print(min(names))
```

**Output:**
```text
Amit
```

It compares strings lexicographically, not by length.

### Example 4: Using the key parameter

Find the shortest name.

```python
names = ["Rahul", "Amit", "Vikram", "Raj"]

result = min(names, key=len)

print(result)
```

**Output:**
```text
Raj
```

### Example 5: Using min() with dictionaries

```python
students = [
    {"name": "Rahul", "marks": 85},
    {"name": "Amit", "marks": 95},
    {"name": "Priya", "marks": 75}
]

result = min(students, key=lambda student: student["marks"])

print(result)
```

**Output:**
```python
{'name': 'Priya', 'marks': 75}
```

### Using the default parameter

```python
numbers = []

print(min(numbers, default=0))
```

**Output:**
```text
0
```

Without `default`, an empty iterable raises `ValueError`.

### Important Points

- Finds the smallest value.
- Works with comparable elements.
- Supports the `key` parameter.
- Supports `default` for empty iterables.

## 5. reversed()

### What is reversed()?

`reversed()` returns an iterator that accesses elements in reverse order.

**Syntax:**
```python
reversed(sequence)
```

It works with reversible sequences such as lists, tuples, and strings.

### Example 1: Using reversed() with a list

```python
numbers = [10, 20, 30, 40, 50]

result = reversed(numbers)

print(list(result))
```

**Output:**
```python
[50, 40, 30, 20, 10]
```

### Example 2: Using reversed() with a string

```python
name = "Python"

result = reversed(name)

print("".join(result))
```

**Output:**
```text
nohtyP
```

`"".join()` combines the reversed characters into a string.

### Example 3: Using reversed() with a tuple

```python
numbers = (10, 20, 30, 40)

result = reversed(numbers)

print(tuple(result))
```

**Output:**
```python
(40, 30, 20, 10)
```

### Example 4: Using reversed() in a loop

```python
fruits = ["Apple", "Banana", "Mango"]

for fruit in reversed(fruits):
    print(fruit)
```

**Output:**
```text
Mango
Banana
Apple
```

### Example 5: Original list remains unchanged

```python
numbers = [10, 20, 30, 40]

result = list(reversed(numbers))

print("Original:", numbers)
print("Reversed:", result)
```

**Output:**
```text
Original: [10, 20, 30, 40]
Reversed: [40, 30, 20, 10]
```

### reversed() vs reverse() vs slicing

| Method | Behaviour |
|---|---|
| `reversed(list)` | Returns a reverse iterator |
| `list.reverse()` | Reverses the original list in place |
| `list[::-1]` | Creates a reversed copy of the list |

Example:

```python
numbers = [10, 20, 30]

print(list(reversed(numbers)))
print(numbers[::-1])

numbers.reverse()
print(numbers)
```

**Output:**
```text
[30, 20, 10]
[30, 20, 10]
[30, 20, 10]
```

The first two do not modify the original list. The last one does.

## 6. Quick Comparison

| Function | Purpose | Return Value |
|---|---|---|
| `sum()` | Calculates total | Number |
| `sorted()` | Sorts elements | New list |
| `min()` | Finds smallest element | Element |
| `max()` | Finds largest element | Element |
| `reversed()` | Iterates in reverse order | Iterator |

## 7. Important Differences

### sorted() vs reversed()

- `sorted()` arranges elements according to sorting rules.
- `reversed()` reads elements from last to first.

Example:

```python
numbers = [40, 10, 30, 20]

print(sorted(numbers))
print(list(reversed(numbers)))
```

**Output:**
```python
[10, 20, 30, 40]
[20, 30, 10, 40]
```

### min(), max() vs sorted()

- `min()` finds only the smallest element.
- `max()` finds only the largest element.
- `sorted()` returns all elements in sorted order.

## 8. Real-World Combined Example

Use these functions in a student marks program.

```python
students = {
    "Rahul": 85,
    "Amit": 95,
    "Priya": 75,
    "Vikram": 90
}

marks = list(students.values())

print("Total Marks:", sum(marks))
print("Lowest Marks:", min(marks))
print("Highest Marks:", max(marks))

print("Sorted Marks:", sorted(marks))
print("Descending Marks:", sorted(marks, reverse=True))

print("Reverse Order:", list(reversed(marks)))
```

**Output:**
```text
Total Marks: 345
Lowest Marks: 75
Highest Marks: 95
Sorted Marks: [75, 85, 90, 95]
Descending Marks: [95, 90, 85, 75]
Reverse Order: [90, 75, 95, 85]
```

Notice that sorting and reversing are different operations.

---

## 9. Key Takeaways

1. `sum()` adds numerical values.
2. `sorted()` returns a new sorted list without modifying the original iterable.
3. `min()` finds the smallest element.
4. `max()` finds the largest element.
5. `reversed()` returns an iterator in reverse order.
6. `key` customizes how `sorted()`, `min()`, and `max()` compare elements.
7. `reverse=True` sorts in descending order; it does not simply reverse the original sequence.
