# Pythonic Programming and EAFP vs LBYL

## 1. Pythonic Programming

Pythonic programming means writing code in a simple, readable, clean, and natural Python style.

### Example 1: Checking an Element

**Non-Pythonic:**
```python
numbers = [10, 20, 30, 40]

found = False

for num in numbers:
    if num == 30:
        found = True
        break

print(found)
```

**Pythonic:**
```python
numbers = [10, 20, 30, 40]

print(30 in numbers)
```

Output:
```text
True
```

The `in` operator directly checks whether an element exists in a collection.

### Example 2: Swapping Variables

**Traditional approach:**
```python
a = 10
b = 20

temp = a
a = b
b = temp
```

**Pythonic approach:**
```python
a = 10
b = 20

a, b = b, a

print(a, b)
```

Output:
```text
20 10
```

Python supports multiple assignment, so a temporary variable is not required.

### Example 3: List Comprehension

**Traditional approach:**
```python
squares = []

for num in range(1, 6):
    squares.append(num ** 2)

print(squares)
```

**Pythonic approach:**
```python
squares = [num ** 2 for num in range(1, 6)]

print(squares)
```

Output:
```text
[1, 4, 9, 16, 25]
```

### Key Principles of Pythonic Programming

- Prefer readable and simple code.
- Avoid unnecessary complexity.
- Use Python built-in functions and features.
- Follow PEP 8 conventions.
- Write code that is easy to maintain.

## 2. EAFP – Easier to Ask for Forgiveness than Permission

EAFP means trying an operation directly and handling the exception if something goes wrong.

Instead of checking whether an operation will succeed, we perform it and handle possible errors.

### Example: Accessing a Dictionary

```python
student = {"name": "Rahul", "age": 22}

try:
    print(student["email"])
except KeyError:
    print("Email not found")
```

Output:
```text
Email not found
```

**How it works:**

1. Python tries to access the `email` key.
2. The key does not exist.
3. Python raises a `KeyError`.
4. The `except` block handles the error.

---

## 3. LBYL – Look Before You Leap

LBYL means checking whether a condition is satisfied before performing an operation.

### Example: Accessing a Dictionary

```python
student = {"name": "Rahul", "age": 22}

if "email" in student:
    print(student["email"])
else:
    print("Email not found")
```

Output:
```text
Email not found
```

**How it works:**

1. Check whether the `email` key exists.
2. If it exists, access its value.
3. Otherwise, display a message.

---

## 4. EAFP vs LBYL

| EAFP | LBYL |
|---|---|
| Easier to Ask for Forgiveness than Permission | Look Before You Leap |
| Try the operation first | Check the condition first |
| Uses `try-except` | Often uses `if-else` |
| Handles exceptions | Checks conditions before execution |

### Example: File Handling

**EAFP approach:**
```python
try:
    with open("data.txt", "r") as file:
        print(file.read())
except FileNotFoundError:
    print("File does not exist")
```

**LBYL approach:**
```python
import os

if os.path.exists("data.txt"):
    with open("data.txt", "r") as file:
        print(file.read())
else:
    print("File does not exist")
```

**Important:** LBYL file checks can have a race condition. A file might disappear after checking but before opening it.

### Best Practices

- Use specific exceptions such as `KeyError` and `FileNotFoundError`.
- Avoid catching every exception unnecessarily.
- Keep `try` blocks small.
- Use `with` when working with files.
- Choose EAFP or LBYL depending on the situation.

# 5. Practice Questions with Answers

## Q1. Rewrite the following code using Pythonic programming.

**Question:**
```python
numbers = [10, 20, 30, 40]

found = False

for num in numbers:
    if num == 20:
        found = True

print(found)
```

**Answer:**
```python
numbers = [10, 20, 30, 40]

found = 20 in numbers

print(found)
```

Output:
```text
True
```

**Explanation:** The `in` operator checks whether an element exists in a list.

---

## Q2. Identify whether the following code uses EAFP or LBYL.

**Question:**
```python
if "name" in student:
    print(student["name"])
```

**Answer: LBYL**

**Explanation:** The code checks whether the `name` key exists before accessing it.

---

## Q3. Convert the following LBYL code into EAFP.

**Question:**
```python
if "age" in student:
    print(student["age"])
else:
    print("Age not found")
```

**Answer:**
```python
try:
    print(student["age"])
except KeyError:
    print("Age not found")
```

**Explanation:** The code directly attempts to access the key. If it does not exist, Python raises `KeyError`, which is handled using `except`.

---

## 6. Quick Revision

- **Pythonic Programming:** Writing clean, simple, readable Python code.
- **EAFP:** Try first and handle exceptions if they occur.
- **LBYL:** Check first and then perform the operation.
- **`try`:** Contains code that might raise an exception.
- **`except`:** Handles a matching exception.
- **`in`:** Checks whether an element exists in a collection.

### Remember

**EAFP = Try first, handle error later.**

**LBYL = Check first, perform operation later.**
