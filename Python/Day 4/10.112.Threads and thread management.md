# Threads and Thread Management in Python

## 1. What is a Thread?

A thread is the smallest unit of execution within a process.

Multiple threads can execute within the same process and share its memory and resources.

### Real-world example

Imagine a music application:

- Thread 1: Plays music.
- Thread 2: Downloads the next song.
- Thread 3: Updates the user interface.

These tasks can make progress concurrently.

---

## 2. Creating a Thread in Python

Python provides the `threading` module to create and manage threads.

### Example

```python
import threading

def task():
    print("Task is running")

t1 = threading.Thread(target=task)

t1.start()
```

Output:

```text
Task is running
```

### Explanation

- `import threading`: Imports the threading module.
- `Thread()`: Creates a thread object.
- `target=task`: Specifies the function to execute.
- `start()`: Starts execution in a new thread.

**Important:** Calling `start()` creates and starts a new thread. Calling `run()` directly executes the target function in the current thread.

---

## 3. Creating Multiple Threads

We can create multiple threads to execute different tasks concurrently.

```python
import threading

def task(name):
    print(f"{name} is running")

t1 = threading.Thread(target=task, args=("Task 1",))
t2 = threading.Thread(target=task, args=("Task 2",))
t3 = threading.Thread(target=task, args=("Task 3",))

t1.start()
t2.start()
t3.start()
```

Possible output:

```text
Task 1 is running
Task 3 is running
Task 2 is running
```

**Note:** The execution order is not guaranteed because thread scheduling is managed by the operating system.

## 4. Thread Management Methods

Python provides several methods to manage threads.

| Method | Description |
|---|---|
| `start()` | Starts a new thread |
| `run()` | Executes the thread's target function |
| `join()` | Waits for a thread to finish |
| `is_alive()` | Checks whether a thread is running |
| `current_thread()` | Returns the current thread object |
| `active_count()` | Returns the number of active threads |

### A. join()

The `join()` method makes the calling thread wait until another thread finishes.

```python
import threading
import time

def task():
    print("Task started")
    time.sleep(2)
    print("Task completed")

t1 = threading.Thread(target=task)

t1.start()
t1.join()

print("Main program completed")
```

Output:

```text
Task started
Task completed
Main program completed
```

### B. is_alive()

Checks whether a thread is currently alive.

```python
import threading
import time

def task():
    time.sleep(3)

t1 = threading.Thread(target=task)

t1.start()

print(t1.is_alive())

t1.join()

print(t1.is_alive())
```

Output:

```text
True
False
```

### C. current_thread()

Returns information about the currently executing thread.

```python
import threading

def task():
    print(threading.current_thread().name)

t1 = threading.Thread(
    target=task,
    name="Download-Thread"
)

t1.start()
t1.join()
```

Output:

```text
Download-Thread
```

### D. active_count()

Returns the number of currently alive threads, including the calling thread.

```python
import threading
import time

def task():
    time.sleep(2)

t1 = threading.Thread(target=task)
t2 = threading.Thread(target=task)

t1.start()
t2.start()

print(threading.active_count())

t1.join()
t2.join()
```

Typical output:

```text
3
```

The count includes the main thread and two worker threads.

## 5. Daemon vs Non-Daemon Threads

Python supports daemon and non-daemon threads.

### Non-Daemon Thread

- Default type of thread.
- Keeps the Python process alive until it finishes.
- Useful for important operations.

### Daemon Thread

- Used for background operations.
- Does not keep the Python process alive.
- Can be stopped abruptly when the process exits.

### Example

```python
import threading
import time

def background_task():
    while True:
        print("Background task running")
        time.sleep(1)

t1 = threading.Thread(
    target=background_task,
    daemon=True
)

t1.start()

print("Main program completed")
```

**Important:** Avoid daemon threads for critical operations such as saving important data because they may stop without completing their work.

## 6. Thread Synchronization

Thread synchronization means coordinating multiple threads when they access shared resources.

Without synchronization, multiple threads may modify shared data at the same time, causing unexpected results.

### Race Condition

A race condition occurs when the result depends on the timing or order of concurrent operations.

### Example: Bank Account

Imagine two threads withdrawing money from the same bank account.

```python
import threading

balance = 1000

lock = threading.Lock()

def withdraw():
    global balance

    with lock:
        if balance >= 500:
            balance -= 500
            print("Withdrawal successful")
        else:
            print("Insufficient balance")

t1 = threading.Thread(target=withdraw)
t2 = threading.Thread(target=withdraw)

t1.start()
t2.start()

t1.join()
t2.join()

print("Final balance:", balance)
```

Output:

```text
Withdrawal successful
Withdrawal successful
Final balance: 0
```

### Understanding Lock

- `threading.Lock()` creates a lock.
- `with lock:` acquires the lock before executing the protected section.
- Other threads must wait until the lock is released.
- The lock is automatically released when the `with` block exits.

This helps prevent race conditions when accessing shared data.

## 7. Important Threading Concepts

| Concept | Meaning |
|---|---|
| Thread | Execution unit inside a process |
| Multithreading | Using multiple threads in one process |
| Thread scheduling | Deciding which thread gets execution time |
| Race condition | Unexpected result due to concurrent access |
| Lock | Protects shared resources |
| Deadlock | Threads wait indefinitely for each other |
| Daemon thread | Background thread that does not keep the process alive |

## 8. Practical Example: File Downloading

Imagine downloading three files simultaneously.

```python
import threading
import time

def download(name):
    print(f"{name} started")

    time.sleep(2)

    print(f"{name} completed")

t1 = threading.Thread(
    target=download,
    args=("File 1",)
)

t2 = threading.Thread(
    target=download,
    args=("File 2",)
)

t3 = threading.Thread(
    target=download,
    args=("File 3",)
)

t1.start()
t2.start()
t3.start()

t1.join()
t2.join()
t3.join()

print("All downloads completed")
```

Possible output:

```text
File 1 started
File 2 started
File 3 started
File 1 completed
File 2 completed
File 3 completed
All downloads completed
```

The order can vary. The three tasks can make progress concurrently while waiting.

## 9. Quick Revision

- `threading.Thread()` creates a thread.
- `start()` starts a new thread.
- `join()` waits for a thread to finish.
- `is_alive()` checks thread status.
- `current_thread()` returns the current thread.
- `active_count()` returns the number of active threads.
- `Lock()` protects shared resources.
- `daemon=True` creates a daemon thread.
- Thread execution order is not guaranteed.

### Remember

**Thread:** A unit of execution inside a process.

**Multithreading:** Multiple threads working within one process.

**Lock:** Protects shared data from unsafe concurrent access.

**join():** Waits for another thread to complete.
