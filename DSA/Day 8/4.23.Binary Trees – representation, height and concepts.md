# Binary Trees – Representation, Height and Concepts

## 1. What is a Binary Tree?

A **Binary Tree** is a non-linear hierarchical data structure in which each node can have at most two children:

1. Left Child
2. Right Child

Unlike arrays and linked lists, which store elements sequentially, a binary tree stores elements in a hierarchical structure.

### Real-World Examples

- File systems – folders and subfolders.
- Organization hierarchy – managers and employees.
- Decision-making systems – Yes/No decisions.
- Expression trees – mathematical expressions.
- Searching and sorting – Binary Search Trees.

### Example of a Binary Tree

```text
          10
         /  \
        20   30
       / \    \
      40  50   60
```

Here:

- 10 is the Root Node.
- 20 and 30 are children of 10.
- 40 and 50 are children of 20.
- 60 is the right child of 30.

## 2. Basic Terminologies of Binary Trees

Consider the following tree:

```text
           A
          / \
         B   C
        / \   \
       D   E   F
```

### Root Node

The topmost node of a binary tree.

Example: A

### Parent Node

A node that has one or more children.

Example: A is the parent of B and C.

### Child Node

A node directly connected below another node.

Example: B and C are children of A.

### Leaf Node

A node that does not have any children.

Example: D, E and F.

### Internal Node

A node that has at least one child.

Example: A, B and C.

### Sibling Nodes

Nodes that share the same parent.

Example: B and C are siblings.

### Edge

The connection between two nodes.

### Subtree

A smaller tree formed from any node and its descendants.

Example:

```text
       B
      / \
     D   E
```

This is a subtree of the original tree.

## 3. Representation of Binary Trees

There are two common ways to represent binary trees:

1. Linked Representation
2. Array Representation

### 3.1 Linked Representation

In linked representation, every node contains three parts:

- Data – Stores the value.
- Left – Reference to the left child.
- Right – Reference to the right child.

### Structure of a Node

```text
       +-------+
       | Data  |
       +-------+
       | Left  |
       +-------+
       | Right |
       +-------+
```

### Python Implementation

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None
```

Explanation:

- `self.data` stores the node value.
- `self.left` stores the reference to the left child.
- `self.right` stores the reference to the right child.
- `None` means that no child exists.

### Creating a Binary Tree

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None


root = Node(10)

root.left = Node(20)
root.right = Node(30)

root.left.left = Node(40)
root.left.right = Node(50)

print(root.data)
print(root.left.data)
print(root.right.data)
```

**Output:**

```text
10
20
30
```

### Tree Representation

```text
          10
         /  \
        20   30
       / \
      40  50
```

### Understanding the Code

```python
root = Node(10)
```

Creates the root node with value 10.

```python
root.left = Node(20)
```

Creates a new node with value 20 and connects it to the left of 10.

```python
root.right = Node(30)
```

Creates a new node with value 30 and connects it to the right of 10.

```python
root.left.left = Node(40)
```

Creates node 40 as the left child of node 20.

### 3.2 Array Representation

A binary tree can also be represented using an array.

For a binary tree stored using zero-based indexing:

- Root index = 0
- Left child index = `2 * i + 1`
- Right child index = `2 * i + 2`
- Parent index = `(i - 1) // 2`

Where `i` represents the current node's index.

### Example

```text
          10
         /  \
        20   30
       / \   /
      40 50 60
```

Array Representation:

```python
tree = [10, 20, 30, 40, 50, 60]
```

| Index | Value |
|---|---|
| 0 | 10 |
| 1 | 20 |
| 2 | 30 |
| 3 | 40 |
| 4 | 50 |
| 5 | 60 |

### Finding Children Using Index

```python
tree = [10, 20, 30, 40, 50, 60]

i = 0

left = 2 * i + 1
right = 2 * i + 2

print("Root:", tree[i])
print("Left Child:", tree[left])
print("Right Child:", tree[right])
```

**Output:**

```text
Root: 10
Left Child: 20
Right Child: 30
```

### When to Use Array Representation?

- Best suited for complete binary trees.
- Commonly used in Heap Data Structures.
- Less efficient for sparse trees because many array positions may remain empty.

## 4. Height of a Binary Tree

The **Height of a Binary Tree** is the number of edges in the longest path from the root node to a leaf node.

Consider this tree:

```text
          10
         /  \
        20   30
       /
      40
     /
    50
```

The longest path is:

```text
10 → 20 → 40 → 50
```

Number of edges = 3.

Therefore:

**Height = 3**

### Important Note

Some textbooks define height using the number of nodes instead of edges.

For the same tree:

- Height in edges = 3
- Height in nodes = 4

In this document, we use the edge-based definition.

### Height of an Empty Tree

```text
Height = -1
```

### Height of a Leaf Node

```text
Height = 0
```

---

## 5. Calculate Height Using Python

The height of a binary tree can be calculated recursively.

### Python Code

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None


def height(root):

    if root is None:
        return -1

    left_height = height(root.left)
    right_height = height(root.right)

    return 1 + max(left_height, right_height)


root = Node(10)

root.left = Node(20)
root.right = Node(30)

root.left.left = Node(40)
root.left.left.left = Node(50)

print("Height:", height(root))
```

**Output:**

```text
Height: 3
```

### Understanding the Logic

The height function works using three steps:

1. Check whether the current node is `None`.
2. Calculate the height of the left and right subtrees.
3. Return 1 plus the maximum of both heights.

```python
return 1 + max(left_height, right_height)
```

Why do we use `max()`?

Because the height of a tree depends on its longest path from the root to a leaf.

### Time and Space Complexity

| Complexity | Value | Explanation |
|---|---|---|
| Time | O(n) | Every node is visited once. |
| Space | O(h) | Recursive call stack depends on tree height. |

Here:
- `n` = Number of nodes.
- `h` = Height of the tree.

## 6. Types of Binary Trees

### 6.1 Full Binary Tree

A Full Binary Tree is a tree in which every node has either:

- Zero children
- Exactly two children

No node can have only one child.

```text
          10
         /  \
        20   30
       / \
      40  50
```

### 6.2 Complete Binary Tree

A Complete Binary Tree is a tree in which:

- Every level is completely filled except possibly the last level.
- The last level is filled from left to right.

```text
          10
         /  \
        20   30
       / \   /
      40 50 60
```

### 6.3 Perfect Binary Tree

A Perfect Binary Tree is a tree in which:

- Every internal node has exactly two children.
- All leaf nodes are at the same level.

```text
          10
         /  \
        20   30
       / \   / \
      40 50 60 70
```

### 6.4 Balanced Binary Tree

A height-balanced binary tree is one in which the heights of the left and right subtrees of every node differ by at most 1.

```text
          10
         /  \
        20   30
       / \
      40  50
```

### 6.5 Skewed Binary Tree

A Skewed Binary Tree is a tree in which every node has only one child.

**Left-Skewed:**

```text
       10
      /
     20
    /
   30
  /
 40
```

**Right-Skewed:**

```text
   10
     \
      20
        \
         30
           \
            40
```

A skewed binary tree behaves similarly to a linked list.

## 7. Important Binary Tree Properties

Assuming the root is at level 0 and height is measured in edges:

### Maximum Nodes at a Level

At level `L`, the maximum number of nodes is:

```text
2^L
```

Example:

| Level | Maximum Nodes |
|---|---:|
| 0 | 1 |
| 1 | 2 |
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |

### Maximum Nodes in a Binary Tree

For a binary tree of height `h`:

```text
Maximum Nodes = 2^(h+1) - 1
```

Example:

If height = 3:

```text
2^(3+1) - 1
= 16 - 1
= 15 nodes
```

### Minimum Nodes in a Binary Tree

For a binary tree of height `h`:

```text
Minimum Nodes = h + 1
```

This occurs in a completely skewed tree.

### Number of Edges

For a non-empty tree with `n` nodes:

```text
Edges = n - 1
```

## 8. Binary Tree vs Binary Search Tree

A Binary Tree and a Binary Search Tree (BST) are not the same.

| Binary Tree | Binary Search Tree |
|---|---|
| Each node has at most two children. | Each node has at most two children. |
| No fixed ordering rule. | Left values are smaller and right values are larger under the standard BST rule. |
| Searching may take O(n). | Searching takes O(log n) on a balanced BST. |
| Can store values in any arrangement. | Maintains an ordering of values. |

Example:

**Binary Tree:**

```text
        10
       /  \
      30   20
```

**Binary Search Tree:**

```text
        20
       /  \
      10   30
```

## 9. Advantages of Binary Trees

1. Represents hierarchical data efficiently.
2. Supports efficient searching when implemented as a balanced BST.
3. Useful for sorting and priority queue implementations.
4. Forms the foundation of advanced data structures.
5. Useful in expression evaluation and decision-making systems.

## 10. Disadvantages of Binary Trees

1. Requires additional memory for pointers/references.
2. Can become skewed and inefficient.
3. Implementation is more complex than arrays.
4. Searching is not necessarily efficient in an ordinary binary tree.

## 12. Interview Questions and Answers

**Q1. What is a binary tree?**

A binary tree is a hierarchical data structure in which each node can have at most two children.

**Q2. What is the maximum number of children a node can have?**

Two children: left and right.

**Q3. What is a leaf node?**

A node that does not have any children.

**Q4. What is the root node?**

The topmost node of a binary tree.

**Q5. What is the height of a binary tree?**

The number of edges in the longest path from the root to a leaf.

**Q6. What is the difference between height and depth?**

- Height: Longest downward path from a node to a leaf.
- Depth: Number of edges from the root to a particular node.

**Q7. What is the height of a single-node binary tree?**

0 edges.

**Q8. What is the maximum number of nodes at level 3?**

`2^3 = 8`.

**Q9. Which representation is commonly used for heaps?**

Array representation.

**Q10. What happens when a binary tree becomes skewed?**

It behaves like a linked list, and its height can become O(n).

## 13. Key Takeaways

- A binary tree allows at most two children per node.
- Every binary tree has a root node.
- Nodes without children are called leaf nodes.
- Binary trees can be represented using linked structures or arrays.
- Height measures the longest downward path in a tree.
- Full, Complete, Perfect, Balanced and Skewed are different binary tree structures.
- Binary Search Trees follow an ordering rule.
- Binary trees are the foundation for heaps, BSTs, AVL trees and other advanced structures.
