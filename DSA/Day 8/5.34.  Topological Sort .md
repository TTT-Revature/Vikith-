# Topological Sort – Implementation and Problem Solving

## 1. What is Topological Sorting?

**Topological Sorting** is a linear ordering of vertices in a Directed Acyclic Graph (DAG), such that for every directed edge `u → v`, vertex `u` appears before vertex `v` in the ordering.

In simple words:

If one task depends on another task, the task that must happen first should appear earlier in the ordering.

### Real-world examples

- Course prerequisite scheduling.
- Project task scheduling.
- Software package installation.
- Build systems and compilation.
- Job scheduling.
- Dependency management.

### Example

Consider the following directed graph:

```text
       A
      / \
     ↓   ↓
     B   C
      \ /
       ↓
       D
```

Dependencies:

```text
A → B
A → C
B → D
C → D
```

A valid topological ordering is:

```text
A → B → C → D
```

Another valid ordering is:

```text
A → C → B → D
```

Both are correct because A comes before B and C, and both B and C come before D.

**Important:** A graph can have multiple valid topological orderings.

---

## 2. What is a DAG?

DAG stands for **Directed Acyclic Graph**.

Let's understand each word:

- **Directed:** Every edge has a direction.
- **Acyclic:** The graph does not contain a directed cycle.
- **Graph:** A collection of vertices and edges.

Example of a DAG:

```text
A → B → D
 \       ↑
  → C ───┘
```

Example of a graph containing a directed cycle:

```text
A → B → C
↑       |
└───────┘
```

Here:

```text
A → B → C → A
```

This is a cycle.

### Why must topological sorting use a DAG?

Suppose:

```text
A → B
B → C
C → A
```

The dependencies mean:

- A must happen before B.
- B must happen before C.
- C must happen before A.

These requirements contradict each other.

There is no valid ordering.

Therefore:

**Topological sorting is possible only for a directed acyclic graph.**

---

## 3. Understanding Indegree and Outdegree

Before implementing topological sorting, we need to understand two important graph concepts.

### Indegree

Indegree is the number of incoming edges to a vertex.

### Outdegree

Outdegree is the number of outgoing edges from a vertex.

Example:

```text
       A
      / \
     ↓   ↓
     B   C
      \ /
       ↓
       D
```

| Vertex | Indegree | Outdegree |
|---|---:|---:|
| A | 0 | 2 |
| B | 1 | 1 |
| C | 1 | 1 |
| D | 2 | 0 |

### Important observation

A vertex with indegree `0` has no prerequisites.

It can be processed immediately.

This is the main idea behind Kahn's Algorithm.

# PART 1: TOPOLOGICAL SORTING USING DFS

## 4. DFS-Based Topological Sorting

We can use Depth First Search to perform topological sorting.

### Main idea

1. Start DFS from an unvisited vertex.
2. Visit all its unvisited neighbors.
3. Once all neighbors are processed, add the current vertex to a stack.
4. Continue until all vertices are processed.
5. Reverse the stack to get the topological ordering.

### Why do we add a vertex after exploring its neighbors?

Consider:

```text
A → B → C
```

DFS starts from A:

```text
DFS(A)
   |
   DFS(B)
      |
      DFS(C)
```

C has no unvisited neighbors, so C is added first.

Then B is added.

Finally A is added.

Stack:

```text
[C, B, A]
```

Reverse the stack:

```text
[A, B, C]
```

This gives the correct topological order.

---

## 5. DFS-Based Implementation in Python

### Complete code

```python
graph = {
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["D"],
    "D": []
}

visited = set()
stack = []

def dfs(vertex):

    visited.add(vertex)

    for neighbor in graph[vertex]:

        if neighbor not in visited:

            dfs(neighbor)

    stack.append(vertex)


for vertex in graph:

    if vertex not in visited:

        dfs(vertex)


stack.reverse()

print(stack)
```

Output:

```text
['A', 'C', 'B', 'D']
```

The exact valid ordering can vary depending on the order in which neighbors are explored.

### Understanding the code

**Step 1: Create a visited set**

```python
visited = set()
```

This stores vertices that have already been visited.

**Step 2: Create a stack**

```python
stack = []
```

We store each vertex after all its neighbors have been processed.

**Step 3: Define DFS**

```python
def dfs(vertex):

    visited.add(vertex)
```

Mark the current vertex as visited.

**Step 4: Explore neighbors**

```python
for neighbor in graph[vertex]:

    if neighbor not in visited:

        dfs(neighbor)
```

Continue exploring unvisited neighbors.

**Step 5: Add the vertex to the stack**

```python
stack.append(vertex)
```

This line is important.

We add the vertex only after exploring all its outgoing neighbors.

**Step 6: Process every disconnected component**

```python
for vertex in graph:

    if vertex not in visited:

        dfs(vertex)
```

This ensures that every vertex is included, even if the graph has disconnected components.

**Step 7: Reverse the stack**

```python
stack.reverse()
```

The vertices were added in reverse topological order, so we reverse them.

## 7. Detecting Cycles in DFS-Based Topological Sorting

The previous implementation assumes the graph is a DAG.

But what happens if the graph contains a cycle?

A simple `visited` set is not enough to detect a directed cycle correctly.

We need three states for every vertex:

| State | Meaning |
|---|---|
| 0 | Not visited |
| 1 | Currently being explored |
| 2 | Completely processed |

These states help us detect a back edge.

### What is a back edge?

A back edge is an edge from the current DFS path to a vertex that is still being explored.

For example:

```text
A → B → C
    ↑   |
    └───┘
```

If DFS reaches B again while B is still being explored, a cycle exists.

### Implementation

```python
def topological_sort_dfs(graph):

    state = {vertex: 0 for vertex in graph}

    stack = []

    def dfs(vertex):

        state[vertex] = 1

        for neighbor in graph[vertex]:

            if state[neighbor] == 1:
                return False

            if state[neighbor] == 0:

                if not dfs(neighbor):
                    return False

        state[vertex] = 2

        stack.append(vertex)

        return True

    for vertex in graph:

        if state[vertex] == 0:

            if not dfs(vertex):
                return None

    stack.reverse()

    return stack


graph = {
    "A": ["B"],
    "B": ["C"],
    "C": ["A"]
}

print(topological_sort_dfs(graph))
```

Output:

```text
None
```

`None` indicates that a topological ordering does not exist because the graph contains a directed cycle.

### Important

In a production implementation, the graph should include every vertex as a key, including vertices with no outgoing edges.

This implementation assumes all neighbor vertices are present as graph keys.

# PART 2: TOPOLOGICAL SORTING USING KAHN'S ALGORITHM

## 8. What is Kahn's Algorithm?

Kahn's Algorithm is another method of performing topological sorting.

It uses:

- Indegree
- Queue
- BFS-style processing

### Main idea

1. Calculate the indegree of every vertex.
2. Find all vertices with indegree `0`.
3. Add them to a queue.
4. Remove a vertex from the queue and add it to the result.
5. Reduce the indegree of all its outgoing neighbors by 1.
6. If a neighbor's indegree becomes `0`, add it to the queue.
7. Continue until the queue becomes empty.

If all vertices are processed, a topological ordering exists.

If some vertices remain unprocessed, the graph contains a directed cycle.

---

## 9. Understanding Kahn's Algorithm with an Example

Consider:

```text
       A
      / \
     ↓   ↓
     B   C
      \ /
       ↓
       D
```

Edges:

```text
A → B
A → C
B → D
C → D
```

### Step 1: Calculate indegree

| Vertex | Indegree |
|---|---:|
| A | 0 |
| B | 1 |
| C | 1 |
| D | 2 |

Initial queue:

```text
[A]
```

Because A has indegree zero.

### Step 2: Remove A

Add A to the result.

```text
Result = [A]
```

A points to B and C.

Reduce their indegrees:

```text
B: 1 → 0
C: 1 → 0
```

Add B and C to the queue.

```text
Queue = [B, C]
```

### Step 3: Remove B

Add B to the result.

```text
Result = [A, B]
```

B points to D.

Reduce D's indegree:

```text
D: 2 → 1
```

D is not added yet because its indegree is not zero.

### Step 4: Remove C

Add C to the result.

```text
Result = [A, B, C]
```

C points to D.

Reduce D's indegree:

```text
D: 1 → 0
```

Now add D to the queue.

### Step 5: Remove D

Add D to the result.

```text
Result = [A, B, C, D]
```

Queue becomes empty.

Final topological ordering:

```text
A → B → C → D
```

## 10. Kahn's Algorithm – Python Implementation

### Complete code

```python
from collections import deque

def topological_sort(graph):

    indegree = {vertex: 0 for vertex in graph}

    # Calculate indegree
    for vertex in graph:

        for neighbor in graph[vertex]:

            indegree[neighbor] += 1

    # Add all zero-indegree vertices
    queue = deque()

    for vertex in indegree:

        if indegree[vertex] == 0:

            queue.append(vertex)

    result = []

    # Process vertices
    while queue:

        current = queue.popleft()

        result.append(current)

        for neighbor in graph[current]:

            indegree[neighbor] -= 1

            if indegree[neighbor] == 0:

                queue.append(neighbor)

    # Cycle detection
    if len(result) != len(graph):

        return None

    return result


graph = {
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["D"],
    "D": []
}

print(topological_sort(graph))
```

Output:

```text
['A', 'B', 'C', 'D']
```

## 11. Understanding Kahn's Algorithm Line by Line

### Step 1: Initialize indegree

```python
indegree = {vertex: 0 for vertex in graph}
```

Initially, every vertex has indegree zero.

Example:

```python
{
    "A": 0,
    "B": 0,
    "C": 0,
    "D": 0
}
```

### Step 2: Calculate incoming edges

```python
for vertex in graph:

    for neighbor in graph[vertex]:

        indegree[neighbor] += 1
```

For every edge:

```text
A → B
```

We increase the indegree of B by one.

After processing all edges:

```python
{
    "A": 0,
    "B": 1,
    "C": 1,
    "D": 2
}
```

### Step 3: Create a queue

```python
queue = deque()
```

We use a queue to process vertices whose indegree is zero.

### Step 4: Add zero-indegree vertices

```python
for vertex in indegree:

    if indegree[vertex] == 0:

        queue.append(vertex)
```

A vertex with zero indegree has no prerequisites.

It can be processed immediately.

### Step 5: Process the queue

```python
while queue:

    current = queue.popleft()

    result.append(current)
```

Remove the first vertex and add it to the result.

### Step 6: Reduce the indegree of neighbors

```python
for neighbor in graph[current]:

    indegree[neighbor] -= 1
```

We have now processed the current vertex, so its outgoing dependency edges are removed from consideration.

Therefore, we decrease the indegree of its neighbors.

### Step 7: Add newly available vertices

```python
if indegree[neighbor] == 0:

    queue.append(neighbor)
```

When a vertex's indegree becomes zero, all its prerequisites have been processed.

It is now ready to be processed.

### Step 8: Detect a cycle

```python
if len(result) != len(graph):

    return None
```

If not all vertices were processed, at least one directed cycle exists.

No valid topological ordering is possible.

## 12. DFS vs Kahn's Algorithm

Both approaches produce valid topological orderings for DAGs.

| Feature | DFS Approach | Kahn's Algorithm |
|---|---|---|
| Technique | DFS | BFS-style processing |
| Main data structure | Stack | Queue |
| Uses indegree | No | Yes |
| Cycle detection | Three-state DFS | Processed vertex count |
| Ordering | Reverse finishing order | Zero-indegree order |
| Time complexity | O(V + E) | O(V + E) |
| Space complexity | O(V) | O(V) |

### Which one should you learn first?

Learn both, but understand Kahn's Algorithm particularly well.

It is easy to trace manually and its indegree-based approach is widely used in scheduling and dependency problems.

## 13. Problem 1 – Course Schedule

This is a popular LeetCode problem.

Imagine you want to complete several courses.

Some courses have prerequisites.

For example:

```text
Course 1 must be completed before Course 0.
Course 2 must be completed before Course 0.
```

You are given:

```python
numCourses = 4

prerequisites = [
    [1, 0],
    [2, 0],
    [3, 1],
    [3, 2]
]
```

Each pair:

```text
[a, b]
```

means:

```text
b → a
```

You must complete course `b` before course `a`.

### Question

Can all courses be completed?

Expected output:

```text
True
```

### Solution using Kahn's Algorithm

```python
from collections import deque

def can_finish(numCourses, prerequisites):

    graph = {i: [] for i in range(numCourses)}

    indegree = [0] * numCourses

    for course, prerequisite in prerequisites:

        graph[prerequisite].append(course)

        indegree[course] += 1

    queue = deque()

    for course in range(numCourses):

        if indegree[course] == 0:

            queue.append(course)

    completed = 0

    while queue:

        current = queue.popleft()

        completed += 1

        for neighbor in graph[current]:

            indegree[neighbor] -= 1

            if indegree[neighbor] == 0:

                queue.append(neighbor)

    return completed == numCourses


numCourses = 4

prerequisites = [
    [1, 0],
    [2, 0],
    [3, 1],
    [3, 2]
]

print(can_finish(numCourses, prerequisites))
```

Output:

```text
True
```

### What happens if there is a cycle?

Input:

```python
numCourses = 2

prerequisites = [
    [1, 0],
    [0, 1]
]
```

Dependencies:

```text
0 → 1
↑   |
└───┘
```

Both courses depend on each other.

Output:

```text
False
```

This is because neither course can be selected initially.

# PART 4: COMPLEXITY ANALYSIS

## 16. Time and Space Complexity

Let:

- V = Number of vertices.
- E = Number of edges.

Both DFS-based topological sorting and Kahn's Algorithm have the following complexity when using an adjacency list.

| Operation | Complexity |
|---|---|
| Initialize visited/indegree | O(V) |
| Explore all vertices | O(V) |
| Process all edges | O(E) |
| Total time | O(V + E) |
| Auxiliary space | O(V) |

### Why O(V + E)?

Every vertex is processed once.

Every edge is explored once during the traversal or indegree calculation.

Therefore:

```text
Time Complexity = O(V + E)
Space Complexity = O(V)
```

## 17. Common Mistakes

### Mistake 1: Using topological sorting on an undirected graph

Topological sorting is defined for directed acyclic graphs.

### Mistake 2: Ignoring directed cycles

A directed graph containing a cycle does not have a valid topological ordering.

### Mistake 3: Confusing indegree with outdegree

Indegree counts incoming edges.

Outdegree counts outgoing edges.

### Mistake 4: Adding a DFS vertex too early

In DFS-based topological sorting, a vertex must be pushed after all its neighbors have been processed.

### Mistake 5: Forgetting to reverse the DFS stack

DFS adds vertices in reverse topological order.

Reverse the finishing-order list before returning it.

### Mistake 6: Forgetting cycle detection

A topological sort implementation should verify that the graph is acyclic.

### Mistake 7: Reversing prerequisite edges incorrectly

For a prerequisite pair:

```python
[course, prerequisite]
```

The edge must be:

```text
prerequisite → course
```
