# Frequency Counting in Python (DSA)

## 1. Introduction to Frequency Counting

Frequency Counting is a technique used in programming to determine how many times an element appears in a collection.

It is commonly used with:

- Arrays
- Lists
- Strings
- Dictionaries
- Hash Maps
- Hash Sets

Frequency counting is especially useful when solving problems involving duplicate elements, repeated characters, most frequent elements, and anagrams.

### Example

Consider the following list:

```python
numbers = [1, 2, 2, 3, 1, 1, 4]
```

We need to count how many times each number appears.

**Expected Output:**

```text
1 appears 3 times
2 appears 2 times
3 appears 1 time
4 appears 1 time
```

The frequency table looks like this:

| Element | Frequency |
|---|---:|
| 1 | 3 |
| 2 | 2 |
| 3 | 1 |
| 4 | 1 |

We can solve this efficiently using a Hash Map (Python Dictionary).

---

## 2. Why Is Frequency Counting Important?

Frequency counting helps us solve problems without repeatedly scanning the entire collection.

Common applications:

1. Finding duplicate elements.
2. Finding the most frequent element.
3. Finding the least frequent element.
4. Counting characters in a string.
5. Checking whether two strings are anagrams.
6. Finding the first non-repeating character.
7. Solving Top K Frequent Elements.
8. Detecting repeated values in datasets.

---

## 3. Frequency Counting Using a Normal Loop

Before using dictionaries, let's understand how frequency counting works manually.

### Example

```python
numbers = [1, 2, 2, 3, 1, 1]

for num in numbers:
    count = 0

    for value in numbers:
        if value == num:
            count += 1

    print(num, "appears", count, "times")
```

**Output:**

```text
1 appears 3 times
2 appears 2 times
2 appears 2 times
3 appears 1 times
1 appears 3 times
1 appears 3 times
```

### Problem with This Approach

- The outer loop visits every element.
- The inner loop scans the entire list again.
- The same frequency is calculated multiple times.

Time Complexity: O(n²).

We need a more efficient approach.

---

## 4. Frequency Counting Using a Dictionary

A Python dictionary stores data in key-value pairs.

We can use:

- Key = Element
- Value = Frequency

### Example

```python
numbers = [1, 2, 2, 3, 1, 1, 4]

frequency = {}

for num in numbers:

    if num in frequency:
        frequency[num] += 1

    else:
        frequency[num] = 1

print(frequency)
```

**Output:**

```text
{1: 3, 2: 2, 3: 1, 4: 1}
```

### Step-by-Step Explanation

Initially:

```python
frequency = {}
```

First element: 1

```text
1 is not present.
Insert 1: 1
```

Dictionary:

```text
{1: 1}
```

Second element: 2

```text
2 is not present.
Insert 2: 1
```

Dictionary:

```text
{1: 1, 2: 1}
```

Third element: 2

```text
2 already exists.
Increase its frequency by 1.
```

Dictionary:

```text
{1: 1, 2: 2}
```

Fourth element: 3

```text
3 is not present.
Insert 3: 1
```

Dictionary:

```text
{1: 1, 2: 2, 3: 1}
```

Continue the same process for all elements.

Final dictionary:

```text
{1: 3, 2: 2, 3: 1, 4: 1}
```

### Time Complexity

- Time: O(n) average.
- Space: O(k), where k is the number of distinct elements.

## 5. Using Dictionary get() Method

Python provides a convenient method called `get()`.

Syntax:

```python
dictionary.get(key, default_value)
```

It returns the value associated with the key. If the key does not exist, it returns the default value.

### Example

```python
numbers = [1, 2, 2, 3, 1, 1]

frequency = {}

for num in numbers:

    frequency[num] = frequency.get(num, 0) + 1

print(frequency)
```

**Output:**

```text
{1: 3, 2: 2, 3: 1}
```

### How Does It Work?

Consider:

```python
frequency[num] = frequency.get(num, 0) + 1
```

For the first occurrence of 1:

```python
frequency.get(1, 0)
```

Since 1 does not exist, it returns 0.

Then:

```python
0 + 1 = 1
```

The dictionary becomes:

```python
{1: 1}
```

For the second occurrence of 1:

```python
frequency.get(1, 0)
```

It returns 1.

Then:

```python
1 + 1 = 2
```

The dictionary becomes:

```python
{1: 2}
```

This continues for every occurrence.

## 6. Frequency Counting in Strings

Frequency counting is not limited to numbers. We can also count characters in strings.

### Example

```python
text = "programming"

frequency = {}

for char in text:

    frequency[char] = frequency.get(char, 0) + 1

print(frequency)
```

**Output:**

```text
{'p': 1, 'r': 2, 'o': 1, 'g': 2, 'a': 1, 'm': 2, 'i': 1, 'n': 1}
```

### Explanation

Each character becomes a dictionary key.

Its corresponding value represents how many times that character appears.

| Character | Frequency |
|---|---:|
| p | 1 |
| r | 2 |
| o | 1 |
| g | 2 |
| a | 1 |
| m | 2 |
| i | 1 |
| n | 1 |

## 7. Counting Frequency Using collections.Counter

Python provides a built-in class called `Counter` from the `collections` module.

It is specifically designed for counting elements.

### Example

```python
from collections import Counter

numbers = [1, 2, 2, 3, 1, 1, 4]

frequency = Counter(numbers)

print(frequency)
```

**Output:**

```text
Counter({1: 3, 2: 2, 3: 1, 4: 1})
```

### Counting Characters

```python
from collections import Counter

text = "banana"

frequency = Counter(text)

print(frequency)
```

**Output:**

```text
Counter({'a': 3, 'n': 2, 'b': 1})
```

### Getting the Most Common Element

```python
from collections import Counter

numbers = [1, 2, 2, 3, 1, 1, 4]

frequency = Counter(numbers)

print(frequency.most_common(1))
```

**Output:**

```text
[(1, 3)]
```

This returns the element with its frequency.

**Important:** Understand how to implement frequency counting manually using a dictionary before relying on `Counter` in DSA interviews.

## 8. Problem 1: Count Frequency of Elements

**Question:**

Given a list of integers, count how many times each element appears.

Input:

```python
numbers = [10, 20, 10, 30, 20, 10]
```

Expected Output:

```text
{10: 3, 20: 2, 30: 1}
```

### Solution

```python
def frequency_count(numbers):

    frequency = {}

    for num in numbers:

        frequency[num] = frequency.get(num, 0) + 1

    return frequency


numbers = [10, 20, 10, 30, 20, 10]

print(frequency_count(numbers))
```

Time Complexity: O(n) average.

Space Complexity: O(k).

## 9. Problem 2: Find the Most Frequent Element

**Question:**

Given an array, find the element that appears the maximum number of times.

Input:

```python
numbers = [1, 2, 2, 3, 3, 3, 4]
```

Expected Output:

```text
3
```

### Solution

```python
def most_frequent(numbers):

    frequency = {}

    for num in numbers:
        frequency[num] = frequency.get(num, 0) + 1

    max_element = None
    max_count = 0

    for num, count in frequency.items():

        if count > max_count:
            max_count = count
            max_element = num

    return max_element


numbers = [1, 2, 2, 3, 3, 3, 4]

print(most_frequent(numbers))
```

**Explanation:**

1. Count the frequency of each element.
2. Traverse the dictionary.
3. Maintain the maximum frequency.
4. Return the corresponding element.

Time Complexity: O(n) average.

Space Complexity: O(k).

## 11. Problem 4: Find Duplicate Elements

**Question:**

Find all elements that appear more than once.

Input:

```python
numbers = [1, 2, 3, 2, 4, 1, 5]
```

Expected Output:

```text
[1, 2]
```

### Solution

```python
def find_duplicates(numbers):

    frequency = {}

    for num in numbers:
        frequency[num] = frequency.get(num, 0) + 1

    duplicates = []

    for num, count in frequency.items():

        if count > 1:
            duplicates.append(num)

    return duplicates


numbers = [1, 2, 3, 2, 4, 1, 5]

print(find_duplicates(numbers))
```

Time Complexity: O(n) average.

Space Complexity: O(k).

## 12. Problem 5: Find the First Non-Repeating Character

**Question:**

Given a string, find the first character that appears only once.

Input:

```python
text = "aabbcde"
```

Expected Output:

```text
c
```

### Solution

```python
def first_non_repeating(text):

    frequency = {}

    for char in text:
        frequency[char] = frequency.get(char, 0) + 1

    for char in text:

        if frequency[char] == 1:
            return char

    return None


text = "aabbcde"

print(first_non_repeating(text))
```

**Explanation:**

First pass:

```text
a: 2
b: 2
c: 1
d: 1
e: 1
```

Second pass:

- a has frequency 2.
- b has frequency 2.
- c has frequency 1.

Therefore, the answer is c.

Time Complexity: O(n) average.

Space Complexity: O(k).

## 13. Problem 6: Valid Anagram

**Question:**

Given two strings, determine whether they contain exactly the same characters with the same frequencies.

Input:

```python
s = "listen"
t = "silent"
```

Expected Output:

```text
True
```

### Solution

```python
def is_anagram(s, t):

    if len(s) != len(t):
        return False

    frequency = {}

    for char in s:
        frequency[char] = frequency.get(char, 0) + 1

    for char in t:

        if char not in frequency:
            return False

        frequency[char] -= 1

        if frequency[char] < 0:
            return False

    return True


print(is_anagram("listen", "silent"))
```

Time Complexity: O(n) average.

Space Complexity: O(k).

## 14. Problem 7: Top K Frequent Elements

**Question:**

Given an integer array and an integer k, return the k most frequent elements.

Input:

```python
numbers = [1, 1, 1, 2, 2, 3]
k = 2
```

Expected Output:

```text
[1, 2]
```

### Solution Using Dictionary and Sorting

```python
def top_k_frequent(numbers, k):

    frequency = {}

    for num in numbers:
        frequency[num] = frequency.get(num, 0) + 1

    sorted_items = sorted(
        frequency.items(),
        key=lambda item: item[1],
        reverse=True
    )

    result = []

    for num, count in sorted_items[:k]:
        result.append(num)

    return result


numbers = [1, 1, 1, 2, 2, 3]

print(top_k_frequent(numbers, 2))
```

Time Complexity: O(n + k log k), where k is the number of distinct elements (using sorting of distinct entries).

Space Complexity: O(k).

## 15. Important Patterns to Understand

| Pattern | Purpose |
|---|---|
| Element Frequency | Count occurrences of numbers |
| Character Frequency | Count characters in strings |
| Most Frequent | Find maximum occurrence |
| Least Frequent | Find minimum occurrence |
| Duplicate Detection | Find repeated elements |
| First Non-Repeating | Find the first unique element |
| Anagram Checking | Compare character frequencies |
| Top K Frequent | Find the most common elements |

## 16. Frequency Counting Using Nested Loops vs Hash Maps

| Feature | Nested Loops | Hash Map |
|---|---|---|
| Approach | Compare every element | Store element counts |
| Time Complexity | O(n²) | O(n) average |
| Space Complexity | O(1) auxiliary | O(k) |
| Performance | Slower for large input | Generally faster |
| Recommended | Learning basic logic | Efficient DSA solutions |

# PART 4: TIME COMPLEXITY

## 17. Complexity Analysis

For a list containing n elements and k distinct elements:

| Operation | Average Time Complexity |
|---|---|
| Traverse list | O(n) |
| Dictionary lookup | O(1) |
| Dictionary insertion | O(1) |
| Update frequency | O(1) |
| Traverse frequency map | O(k) |
| Find maximum frequency | O(k) |
| Find duplicates | O(n + k) |

### Overall Frequency Counting

```python
for num in numbers:
    frequency[num] = frequency.get(num, 0) + 1
```

The loop executes n times.

Each dictionary lookup and update takes O(1) average time.

Therefore:

Time Complexity = O(n).

Space Complexity = O(k).

# 21. Key Points to Remember

- Frequency counting determines how often an element appears.
- Dictionaries are commonly used for frequency counting.
- Dictionary keys represent elements.
- Dictionary values represent frequencies.
- `get()` helps simplify frequency updates.
- `Counter` is a built-in Python utility for counting.
- Frequency counting usually takes O(n) average time.
- Space complexity is O(k), where k is the number of distinct elements.
- Frequency counting is useful for anagrams, duplicate detection, and Top K Frequent Elements.

**Most Important Concept:**

Instead of repeatedly scanning an array to count how many times an element appears, use a Hash Map to store each element and its frequency.

This reduces the average time complexity from O(n²) to O(n).
