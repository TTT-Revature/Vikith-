# Two Pointers Technique in Python (DSA)

## 1. Introduction to Two Pointers

Two Pointers is an algorithmic technique used to solve problems involving arrays, lists, and strings by maintaining two positions (pointers) that move through the data.

Instead of repeatedly checking every possible combination using nested loops, we use two pointers to reduce unnecessary comparisons.

Two Pointers is commonly used for:

- Searching pairs in sorted arrays.
- Finding pairs with a given sum.
- Removing duplicates.
- Reversing arrays and strings.
- Checking palindromes.
- Finding intersections of sorted arrays.
- Solving sliding window problems.

### Example

Consider the following sorted array:

```python
numbers = [1, 2, 3, 4, 6]
target = 7
```

Find two numbers whose sum equals the target.

We can use two pointers:

```text
Left Pointer                 Right Pointer
     |                            |
     v                            v
    [1,  2,  3,  4,  6]
```

Calculate:

```text
1 + 6 = 7
```

We found the answer.

The indices are:

```text
[0, 4]
```

## 2. Why Do We Need Two Pointers?

Consider finding two numbers whose sum equals a target.

### Approach 1: Brute Force

```python
numbers = [1, 2, 3, 4, 6]
target = 7

for i in range(len(numbers)):

    for j in range(i + 1, len(numbers)):

        if numbers[i] + numbers[j] == target:
            print(i, j)
```

Output:

```text
0 4
```

This approach checks multiple combinations.

Time Complexity: O(n²).

### Approach 2: Two Pointers

```python
numbers = [1, 2, 3, 4, 6]
target = 7

left = 0
right = len(numbers) - 1

while left < right:

    total = numbers[left] + numbers[right]

    if total == target:
        print(left, right)
        break

    elif total < target:
        left += 1

    else:
        right -= 1
```

Output:

```text
0 4
```

Time Complexity: O(n).

### Comparison

| Feature | Brute Force | Two Pointers |
|---|---|---|
| Approach | Nested loops | Two moving pointers |
| Time Complexity | O(n²) | O(n) |
| Space Complexity | O(1) | O(1) |
| Efficiency | Slower | Faster |
| Common Usage | General pair checking | Sorted arrays and structured traversal |

## 3. How Does the Two Pointers Technique Work?

Two Pointers maintains two positions that move based on certain conditions.

Usually, the pointers are initialized at:

- Beginning of the array.
- End of the array.

### Example

```python
numbers = [1, 2, 3, 4, 6]
```

Initial positions:

```text
left = 0
right = 4

[1, 2, 3, 4, 6]
 ^
             ^
```

Compare the elements at both positions.

If the current sum is smaller than the target, move the left pointer forward.

If the current sum is greater than the target, move the right pointer backward.

Continue until the answer is found or the pointers meet.

# PART 1: TYPES OF TWO POINTERS

## 4. Opposite Direction Two Pointers

This is the most common Two Pointers pattern.

One pointer starts at the beginning, and another starts at the end.

Both move towards each other.

### Structure

```text
left -----------------> <----------------- right
```

### Example: Find Pair Sum

```python
numbers = [1, 2, 3, 4, 6]
target = 7

left = 0
right = len(numbers) - 1

while left < right:

    total = numbers[left] + numbers[right]

    if total == target:
        print("Pair Found:", numbers[left], numbers[right])
        break

    elif total < target:
        left += 1

    else:
        right -= 1
```

Output:

```text
Pair Found: 1 6
```

### When to Use?

- Pair sum problems in sorted arrays.
- Palindrome checking.
- Reversing an array.
- Container With Most Water.
- Three Sum (combined with another loop).

---

## 5. Same Direction Two Pointers

In this approach, both pointers move from left to right.

One pointer usually explores elements, while the other tracks the position where the next valid element should be placed.

### Example: Remove Duplicates from Sorted Array

Input:

```python
numbers = [1, 1, 2, 2, 3, 4, 4]
```

Expected Output:

```text
[1, 2, 3, 4]
```

### Python Implementation

```python
def remove_duplicates(numbers):

    if not numbers:
        return 0

    slow = 0

    for fast in range(1, len(numbers)):

        if numbers[fast] != numbers[slow]:

            slow += 1

            numbers[slow] = numbers[fast]

    return slow + 1


numbers = [1, 1, 2, 2, 3, 4, 4]

k = remove_duplicates(numbers)

print(numbers[:k])
```

Output:

```text
[1, 2, 3, 4]
```

### Understanding the Pointers

- `fast` explores every element.
- `slow` tracks the last unique element.
- When a new unique element is found, increment `slow`.
- Copy the new unique element into its correct position.

### When to Use?

- Removing duplicates.
- Moving zeroes.
- Removing specific elements.
- Partitioning arrays.
- In-place array modifications.

## 6. Fast and Slow Pointers

Fast and Slow Pointers use two pointers that move at different speeds.

Usually:

- Slow pointer moves one step.
- Fast pointer moves two steps.

This technique is particularly useful in linked lists.

### Example: Detect a Cycle in a Linked List

Imagine a linked list:

```text
1 -> 2 -> 3 -> 4 -> 5
          ^         |
          |_________|
```

The last node points back to an earlier node.

This creates a cycle.

We can detect it using Fast and Slow Pointers.

### Python Implementation

```python
def has_cycle(head):

    slow = head
    fast = head

    while fast and fast.next:

        slow = slow.next
        fast = fast.next.next

        if slow == fast:
            return True

    return False
```

### How Does It Work?

1. Both pointers start at the head.
2. Slow moves one step.
3. Fast moves two steps.
4. If there is a cycle, fast eventually catches slow.
5. If fast reaches `None`, there is no cycle.

### When to Use?

- Linked list cycle detection.
- Finding the middle of a linked list.
- Finding the starting point of a cycle.
- Detecting repeated states in certain sequences.

# PART 2: IMPORTANT TWO POINTER PROBLEMS

## 7. Problem 1: Reverse an Array

**Question:**

Reverse an array using Two Pointers without creating another array.

Input:

```python
numbers = [10, 20, 30, 40, 50]
```

Expected Output:

```text
[50, 40, 30, 20, 10]
```

### Solution

```python
def reverse_array(numbers):

    left = 0
    right = len(numbers) - 1

    while left < right:

        numbers[left], numbers[right] = numbers[right], numbers[left]

        left += 1
        right -= 1

    return numbers


numbers = [10, 20, 30, 40, 50]

print(reverse_array(numbers))
```

### Explanation

Initially:

```text
[10, 20, 30, 40, 50]
 ^
             ^
```

Swap 10 and 50:

```text
[50, 20, 30, 40, 10]
```

Move both pointers.

Swap 20 and 40:

```text
[50, 40, 30, 20, 10]
```

The pointers meet, so the process stops.

Time Complexity: O(n).

Space Complexity: O(1).

## 8. Problem 2: Valid Palindrome

**Question:**

Determine whether a string is a palindrome.

A palindrome reads the same forward and backward.

Input:

```python
text = "racecar"
```

Expected Output:

```text
True
```

### Solution

```python
def is_palindrome(text):

    left = 0
    right = len(text) - 1

    while left < right:

        if text[left] != text[right]:
            return False

        left += 1
        right -= 1

    return True


text = "racecar"

print(is_palindrome(text))
```

### Explanation

Compare:

```text
racecar

r == r
a == a
c == c
```

All corresponding characters match.

Therefore, it is a palindrome.

Time Complexity: O(n).

Space Complexity: O(1).

**Note:** This implementation is case-sensitive and does not ignore spaces or punctuation.

## 9. Problem 3: Two Sum II – Input Array Is Sorted

**Question:**

Given a sorted array, find two numbers whose sum equals the target.

Return their positions using 1-based indexing.

Input:

```python
numbers = [2, 7, 11, 15]
target = 9
```

Expected Output:

```text
[1, 2]
```

### Solution

```python
def two_sum(numbers, target):

    left = 0
    right = len(numbers) - 1

    while left < right:

        total = numbers[left] + numbers[right]

        if total == target:
            return [left + 1, right + 1]

        elif total < target:
            left += 1

        else:
            right -= 1

    return []


numbers = [2, 7, 11, 15]

print(two_sum(numbers, 9))
```

Time Complexity: O(n).

Space Complexity: O(1).

## 10. Problem 4: Move Zeroes

**Question:**

Move all zeroes to the end of an array while maintaining the relative order of non-zero elements.

Input:

```python
numbers = [0, 1, 0, 3, 12]
```

Expected Output:

```text
[1, 3, 12, 0, 0]
```

### Solution

```python
def move_zeroes(numbers):

    slow = 0

    for fast in range(len(numbers)):

        if numbers[fast] != 0:

            numbers[slow], numbers[fast] = numbers[fast], numbers[slow]

            slow += 1

    return numbers


numbers = [0, 1, 0, 3, 12]

print(move_zeroes(numbers))
```

### Explanation

- `fast` searches for non-zero elements.
- `slow` identifies where the next non-zero element belongs.
- When a non-zero element is found, swap it into the correct position.

Time Complexity: O(n).

Space Complexity: O(1).

## 11. Problem 5: Merge Two Sorted Arrays

**Question:**

Given two sorted arrays, merge them into one sorted array.

Input:

```python
a = [1, 3, 5]
b = [2, 4, 6]
```

Expected Output:

```text
[1, 2, 3, 4, 5, 6]
```

### Solution

```python
def merge_sorted_arrays(a, b):

    i = 0
    j = 0

    result = []

    while i < len(a) and j < len(b):

        if a[i] < b[j]:
            result.append(a[i])
            i += 1

        else:
            result.append(b[j])
            j += 1

    while i < len(a):
        result.append(a[i])
        i += 1

    while j < len(b):
        result.append(b[j])
        j += 1

    return result


a = [1, 3, 5]
b = [2, 4, 6]

print(merge_sorted_arrays(a, b))
```

Time Complexity: O(n + m).

Space Complexity: O(n + m).

## 12. Problem 6: Container With Most Water

**Question:**

Given an array representing the heights of vertical lines, find two lines that can contain the maximum amount of water.

Input:

```python
heights = [1, 8, 6, 2, 5, 4, 8, 3, 7]
```

Expected Output:

```text
49
```

### Solution

```python
def max_area(heights):

    left = 0
    right = len(heights) - 1

    maximum = 0

    while left < right:

        width = right - left

        height = min(heights[left], heights[right])

        area = width * height

        maximum = max(maximum, area)

        if heights[left] < heights[right]:
            left += 1

        else:
            right -= 1

    return maximum


heights = [1, 8, 6, 2, 5, 4, 8, 3, 7]

print(max_area(heights))
```

### Explanation

The formula is:

```text
Area = Width × Height
```

Where:

```text
Width = right - left

Height = min(left_height, right_height)
```

We move the pointer with the smaller height because keeping that smaller boundary cannot improve the area when moving the opposite pointer inward.

Time Complexity: O(n).

Space Complexity: O(1).

## 13. Problem 7: Three Sum

**Question:**

Given an integer array, find all unique triplets whose sum equals zero.

Input:

```python
numbers = [-1, 0, 1, 2, -1, -4]
```

Expected Output:

```text
[[-1, -1, 2], [-1, 0, 1]]
```

### Solution

```python
def three_sum(numbers):

    numbers.sort()

    result = []

    for i in range(len(numbers) - 2):

        if i > 0 and numbers[i] == numbers[i - 1]:
            continue

        left = i + 1
        right = len(numbers) - 1

        while left < right:

            total = numbers[i] + numbers[left] + numbers[right]

            if total == 0:

                result.append([
                    numbers[i],
                    numbers[left],
                    numbers[right]
                ])

                left += 1
                right -= 1

                while left < right and numbers[left] == numbers[left - 1]:
                    left += 1

                while left < right and numbers[right] == numbers[right + 1]:
                    right -= 1

            elif total < 0:
                left += 1

            else:
                right -= 1

    return result


numbers = [-1, 0, 1, 2, -1, -4]

print(three_sum(numbers))
```

### Explanation

1. Sort the array.
2. Fix one element using the outer loop.
3. Use two pointers for the remaining elements.
4. Calculate the sum of all three elements.
5. Move the pointers according to the sum.
6. Skip duplicates to avoid repeated triplets.

Time Complexity: O(n²).

Space Complexity: O(1) auxiliary space excluding the sorting implementation and output storage.

# PART 3: TWO POINTERS VS SLIDING WINDOW

## 14. Difference Between Two Pointers and Sliding Window

These techniques are related, but they are not exactly the same.

### Two Pointers

Uses two indexes to traverse or compare elements.

Example:

```python
numbers = [1, 2, 3, 4, 6]

left = 0
right = len(numbers) - 1
```

Common applications:

- Pair sum.
- Palindrome checking.
- Reversing arrays.
- Removing duplicates.

### Sliding Window

Uses two pointers to represent a continuous section (window) of an array or string.

Example:

```python
numbers = [1, 2, 3, 4, 5]

left = 0
right = 2

window = numbers[left:right + 1]

print(window)
```

Output:

```text
[1, 2, 3]
```

Common applications:

- Maximum sum of a subarray of size k.
- Longest substring without repeating characters.
- Minimum size subarray sum.
- Longest substring with a given condition.

### Comparison

| Feature | Two Pointers | Sliding Window |
|---|---|---|
| Main Idea | Two moving positions | Two boundaries of a window |
| Data | Arrays, strings, linked lists | Mostly arrays and strings |
| Movement | Can move independently | Maintains a continuous range |
| Common Usage | Pair sum, palindrome | Subarray and substring problems |
| Example | Two Sum II | Maximum Sum Subarray |

**Important:** Sliding Window is a specialized pattern that commonly uses two pointers.

## 15. Complexity Analysis

| Problem | Time Complexity | Space Complexity |
|---|---|---|
| Reverse Array | O(n) | O(1) |
| Valid Palindrome | O(n) | O(1) |
| Two Sum II | O(n) | O(1) |
| Move Zeroes | O(n) | O(1) |
| Merge Sorted Arrays | O(n + m) | O(n + m) |
| Container With Most Water | O(n) | O(1) |
| Three Sum | O(n²) | O(1) auxiliary, excluding output |

### Why Is Two Pointers Often O(n)?

Although there are two pointers, they do not necessarily cause two complete traversals.

For opposite-direction traversal:

- Left moves forward.
- Right moves backward.
- Each pointer moves at most n times.

Therefore, the total number of pointer movements is O(n).

# 19. Key Points to Remember

- Two Pointers uses two positions to process data efficiently.
- Opposite-direction pointers start at opposite ends.
- Same-direction pointers move through the collection together.
- Fast and Slow Pointers move at different speeds.
- Two Pointers can reduce O(n²) solutions to O(n).
- Sorted arrays are particularly useful for opposite-direction pointer problems.
- Two Pointers is useful for palindrome checking and duplicate removal.
- Sliding Window is a related technique for continuous subarrays and substrings.
- Always identify when and why each pointer should move.

## 20. Final Summary

Two Pointers is one of the most important DSA techniques because it helps solve many array, string, and linked list problems efficiently.

Instead of checking every possible combination, we move two pointers based on the problem's conditions.

**Most Important Interview Concept:**

Before writing code, identify:

1. Where should the first pointer start?
2. Where should the second pointer start?
3. Under what condition should the left pointer move?
4. Under what condition should the right pointer move?
5. When should the loop terminate?

Understanding these five questions makes Two Pointers problems much easier to solve.
