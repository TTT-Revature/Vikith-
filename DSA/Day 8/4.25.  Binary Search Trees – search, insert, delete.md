# Binary Search Trees (BST) – Search, Insert and Delete

## 1. What is a Binary Search Tree?

A **Binary Search Tree (BST)** is a special type of Binary Tree that follows a specific ordering rule.

For every node:

- All values in the left subtree are smaller than the node's value.
- All values in the right subtree are greater than the node's value.
- Both left and right subtrees must also follow the same BST property.

### Example

```text
             50
           /    \
         30      70
        /  \    /  \
       20  40  60  80
```

Understanding the structure:

- 30 is smaller than 50, so it is on the left.
- 70 is greater than 50, so it is on the right.
- 20 and 40 are smaller and greater than 30 respectively.
- 60 and 80 are smaller and greater than 70 respectively.

### Important Rule

```text
Left Child < Root < Right Child
```

**Note:** In this implementation, duplicate values are not allowed.

---

## 2. Creating a Binary Search Tree in Python

Before performing search, insertion and deletion, we need to create a Node class.

### Node Structure

Every node contains:

1. Data
2. Left child reference
3. Right child reference

### Python Code

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None
```

### Creating a BST Manually

```python
root = Node(50)

root.left = Node(30)
root.right = Node(70)

root.left.left = Node(20)
root.left.right = Node(40)

root.right.left = Node(60)
root.right.right = Node(80)
```

Tree Structure:

```text
             50
           /    \
         30      70
        /  \    /  \
       20  40  60  80
```

# 3. Searching in a Binary Search Tree

Searching means finding whether a particular value exists in the BST.

### Searching Logic

Suppose we want to search for 60.

Step 1: Start from the root (50).

Step 2: Compare 60 with 50.

Since 60 is greater than 50, move right.

Step 3: Compare 60 with 70.

Since 60 is smaller than 70, move left.

Step 4: We find 60.

### Search Visualization

```text
             50
           /    \
         30      70
                /
               60
```

Search path:

```text
50 → 70 → 60
```

### Python Implementation – Recursive Approach

```python
def search(root, key):

    if root is None:
        return False

    if root.data == key:
        return True

    elif key < root.data:
        return search(root.left, key)

    else:
        return search(root.right, key)
```

### Complete Example

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None


def search(root, key):

    if root is None:
        return False

    if root.data == key:
        return True

    elif key < root.data:
        return search(root.left, key)

    else:
        return search(root.right, key)


root = Node(50)

root.left = Node(30)
root.right = Node(70)

root.left.left = Node(20)
root.left.right = Node(40)

root.right.left = Node(60)
root.right.right = Node(80)


key = 60

if search(root, key):
    print("Element Found")
else:
    print("Element Not Found")
```

**Output:**

```text
Element Found
```

### Understanding the Recursive Calls

```python
return search(root.right, key)
```

This means:

- If the key is greater than the current node, search in the right subtree.
- The function calls itself with the right child as the new root.

Similarly:

```python
return search(root.left, key)
```

Searches in the left subtree.

### Time Complexity

| Case | Complexity |
|---|---|
| Best Case | O(1) |
| Average Case | O(log n) |
| Worst Case | O(n) |

Space Complexity: O(h), where h is the height of the tree, due to recursion.

# 4. Insertion in a Binary Search Tree

Insertion means adding a new node while maintaining the BST property.

### Insertion Rules

1. If the tree is empty, create a new root.
2. If the new value is smaller than the current node, move left.
3. If the new value is greater than the current node, move right.
4. Repeat until an empty position is found.
5. Insert the new node at that position.

### Example

Insert the following values:

```text
50, 30, 70, 20, 40, 60, 80
```

Final BST:

```text
             50
           /    \
         30      70
        /  \    /  \
       20  40  60  80
```

Now insert 35.

Step 1:

35 < 50 → Move Left.

Step 2:

35 > 30 → Move Right.

Step 3:

35 < 40 → Move Left.

Step 4:

Left position of 40 is empty. Insert 35.

### Final Tree

```text
             50
           /    \
         30      70
        /  \    /  \
       20  40  60  80
           /
          35
```

### Python Implementation

```python
def insert(root, key):

    if root is None:
        return Node(key)

    if key < root.data:
        root.left = insert(root.left, key)

    elif key > root.data:
        root.right = insert(root.right, key)

    return root
```

### Complete Example

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None


def insert(root, key):

    if root is None:
        return Node(key)

    if key < root.data:
        root.left = insert(root.left, key)

    elif key > root.data:
        root.right = insert(root.right, key)

    return root


root = None

values = [50, 30, 70, 20, 40, 60, 80]

for value in values:
    root = insert(root, value)
```

### Why Do We Return root?

```python
return root
```

We return the root reference so that the updated tree is maintained after every insertion.

When the tree is empty, a new node is created and returned.

When the tree already exists, the original root is returned after updating the appropriate child.

**Important:** Duplicate values are ignored in this implementation.

### Time Complexity

| Case | Complexity |
|---|---|
| Best Case | O(1) |
| Average Case | O(log n) |
| Worst Case | O(n) |

Space Complexity: O(h) due to recursive calls.

# 5. Deletion in a Binary Search Tree

Deletion is one of the most important BST operations.

Deleting a node is more complicated than searching and inserting because removing a node must maintain the BST property.

There are **three cases** to consider.

## Case 1: Deleting a Leaf Node

A leaf node has no children.

Example: Delete 20.

Before deletion:

```text
             50
           /    \
         30      70
        /  \
       20  40
```

Since 20 has no children, we can directly remove it.

After deletion:

```text
             50
           /    \
         30      70
           \
            40
```

Logic:

```python
if root.left is None and root.right is None:
    return None
```

## Case 2: Deleting a Node with One Child

Suppose we want to delete 30.

Before deletion:

```text
             50
           /    \
         30      70
           \
            40
```

Node 30 has only one child (40).

We can replace node 30 with its child (40).

After deletion:

```text
             50
           /    \
         40      70
```

Logic:

```python
if root.left is None:
    return root.right

if root.right is None:
    return root.left
```

## Case 3: Deleting a Node with Two Children

This is the most important case.

Suppose we want to delete 50.

Before deletion:

```text
             50
           /    \
         30      70
        /  \    /  \
       20  40  60  80
```

Node 50 has two children.

We cannot simply remove it because both subtrees must remain connected while preserving the BST property.

We have two common choices:

1. Inorder Successor
2. Inorder Predecessor

### What is an Inorder Successor?

The inorder successor is the smallest value in the right subtree.

For node 50:

Right subtree:

```text
        70
       /  \
      60   80
```

The smallest value is 60.

Therefore:

Inorder Successor = 60.

Replace 50 with 60.

Then delete the original 60 from the right subtree.

### Final Tree

```text
             60
           /    \
         30      70
        /  \       \
       20  40      80
```

The BST property is maintained.

## 6. Python Implementation – Delete Operation

First, create a helper function to find the minimum value in a subtree.

### Finding the Minimum Value

```python
def find_min(root):

    current = root

    while current.left is not None:
        current = current.left

    return current
```

Why do we move left?

In a BST, the smallest value is always present at the leftmost node of a subtree.

### Complete Delete Function

```python
def delete(root, key):

    if root is None:
        return None

    # Search for the node
    if key < root.data:
        root.left = delete(root.left, key)

    elif key > root.data:
        root.right = delete(root.right, key)

    else:

        # Case 1: No child
        if root.left is None and root.right is None:
            return None

        # Case 2: Only right child
        elif root.left is None:
            return root.right

        # Case 2: Only left child
        elif root.right is None:
            return root.left

        # Case 3: Two children
        successor = find_min(root.right)

        root.data = successor.data

        root.right = delete(root.right, successor.data)

    return root
```

### Complete BST Program

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None


def insert(root, key):

    if root is None:
        return Node(key)

    if key < root.data:
        root.left = insert(root.left, key)

    elif key > root.data:
        root.right = insert(root.right, key)

    return root


def search(root, key):

    if root is None:
        return False

    if root.data == key:
        return True

    if key < root.data:
        return search(root.left, key)

    return search(root.right, key)


def find_min(root):

    current = root

    while current.left is not None:
        current = current.left

    return current


def delete(root, key):

    if root is None:
        return None

    if key < root.data:
        root.left = delete(root.left, key)

    elif key > root.data:
        root.right = delete(root.right, key)

    else:

        if root.left is None:
            return root.right

        elif root.right is None:
            return root.left

        successor = find_min(root.right)

        root.data = successor.data

        root.right = delete(root.right, successor.data)

    return root


# Create BST
root = None

values = [50, 30, 70, 20, 40, 60, 80]

for value in values:
    root = insert(root, value)


# Search
print("Search 60:", search(root, 60))

# Insert
root = insert(root, 35)

# Delete
root = delete(root, 50)

print("Search 50:", search(root, 50))
```

**Output:**

```text
Search 60: True
Search 50: False
```

# 7. Inorder Traversal of a BST

Inorder traversal visits nodes in this order:

1. Left subtree
2. Root node
3. Right subtree

### Python Code

```python
def inorder(root):

    if root is None:
        return

    inorder(root.left)

    print(root.data, end=" ")

    inorder(root.right)
```

Example BST:

```text
             50
           /    \
         30      70
        /  \    /  \
       20  40  60  80
```

Output:

```text
20 30 40 50 60 70 80
```

**Important Interview Concept:**

Inorder traversal of a BST produces values in sorted ascending order when duplicate values are not present.

# 8. Time and Space Complexity of BST Operations

Let:
- n = Number of nodes.
- h = Height of the tree.

| Operation | Average Case | Worst Case |
|---|---|---|
| Search | O(log n) | O(n) |
| Insert | O(log n) | O(n) |
| Delete | O(log n) | O(n) |
| Find Minimum | O(log n) | O(n) |
| Inorder Traversal | O(n) | O(n) |

### Why Does the Worst Case Become O(n)?

Consider inserting sorted values:

```python
values = [10, 20, 30, 40, 50]
```

The resulting BST becomes:

```text
10
  \
   20
     \
      30
        \
         40
           \
            50
```

This is a right-skewed tree.

Searching for 50 may require visiting every node.

Therefore, the time complexity becomes O(n).

Balanced BSTs such as AVL Trees and Red-Black Trees help avoid this problem.

# 11. Key Takeaways

- A BST is a special type of binary tree.
- Left subtree values are smaller than the current node.
- Right subtree values are greater than the current node.
- Searching and insertion follow the BST ordering property.
- Deletion has three cases: leaf node, one child and two children.
- Inorder successor is the minimum value in the right subtree.
- Inorder traversal of a BST gives sorted values.
- Balanced BST operations generally take O(log n).
- Skewed BST operations can take O(n).
