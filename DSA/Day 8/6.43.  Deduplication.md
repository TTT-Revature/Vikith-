# Deduplication in Python (DSA)

## 1. Introduction to Deduplication

Deduplication is the process of identifying and removing duplicate elements from a collection of data.

A duplicate is an element that appears more than once in a collection.

Deduplication is commonly used with:

- Lists
- Arrays
- Strings
- Hash Sets
- Hash Maps
- Database records

### Example

Consider the following list:

```python
numbers = [10, 20, 30, 20, 40, 10, 50]
```

The elements 10 and 20 appear more than once.

After removing duplicates:

```text
[10, 20, 30, 40, 50]
```

The goal is to keep only one occurrence of each element.

---

## 2. Why Is Deduplication Important?

Deduplication is useful in many real-world applications.

1. Removing duplicate records from databases.
2. Cleaning datasets before data analysis.
3. Removing repeated usernames or email addresses.
4. Preventing duplicate transactions.
5. Removing repeated elements from arrays.
6. Processing unique search results.
7. Optimizing storage by eliminating repeated data.

## 3. Deduplication Using a Set

A Python set automatically stores only unique elements.

When duplicate elements are inserted, only one occurrence is retained.

### Example

```python
numbers = [10, 20, 30, 20, 40, 10]

unique_numbers = set(numbers)

print(unique_numbers)
```

**Output:**

```text
{10, 20, 30, 40}
```

### Converting Back to a List

```python
numbers = [10, 20, 30, 20, 40, 10]

unique_numbers = list(set(numbers))

print(unique_numbers)
```

**Possible Output:**

```text
[40, 10, 20, 30]
```

**Important:** Sets do not guarantee insertion order. If the original order matters, use another approach.

### Time Complexity

- Creating a set: O(n) average.
- Converting back to a list: O(n).
- Overall: O(n) average.

Space Complexity: O(n).

---

## 4. Deduplication Using a For Loop and Set

Sometimes we want to remove duplicates while preserving the original order.

We can use a set to check whether an element has already appeared and a list to store the unique elements.

### Example

```python
numbers = [10, 20, 30, 20, 40, 10]

seen = set()
result = []

for num in numbers:

    if num not in seen:
        result.append(num)
        seen.add(num)

print(result)
```

**Output:**

```text
[10, 20, 30, 40]
```

### Step-by-Step Explanation

Original list:

```text
[10, 20, 30, 20, 40, 10]
```

Initially:

```python
seen = set()
result = []
```

**Step 1: Element 10**

10 is not present in `seen`.

Add it to both collections.

```text
seen   = {10}
result = [10]
```

**Step 2: Element 20**

20 is not present.

```text
seen   = {10, 20}
result = [10, 20]
```

**Step 3: Element 30**

30 is not present.

```text
seen   = {10, 20, 30}
result = [10, 20, 30]
```

**Step 4: Element 20**

20 already exists in `seen`.

Skip it.

**Step 5: Element 40**

40 is not present.

```text
seen   = {10, 20, 30, 40}
result = [10, 20, 30, 40]
```

**Step 6: Element 10**

10 already exists.

Skip it.

Final output:

```text
[10, 20, 30, 40]
```

### Time Complexity

- Time: O(n) average.
- Space: O(n).

## 5. Deduplication Using Dictionary

Python dictionaries preserve insertion order.

We can use dictionary keys to store unique elements.

### Example

```python
numbers = [10, 20, 30, 20, 40, 10]

unique_numbers = list(dict.fromkeys(numbers))

print(unique_numbers)
```

**Output:**

```text
[10, 20, 30, 40]
```

### How Does It Work?

```python
dict.fromkeys(numbers)
```

Creates a dictionary where each element becomes a key.

Duplicate keys are automatically overwritten, while their original insertion position is retained.

Converting the dictionary back to a list gives the unique elements in their original order.

### Time Complexity

- Time: O(n) average.
- Space: O(n).

---

## 6. Deduplication Without Using Set or Dictionary

In interviews, you may be asked to remove duplicates without using built-in hash-based data structures.

We can solve this using nested loops.

### Example

```python
numbers = [10, 20, 30, 20, 40, 10]

result = []

for num in numbers:

    if num not in result:
        result.append(num)

print(result)
```

**Output:**

```text
[10, 20, 30, 40]
```

### Explanation

For every element:

1. Check whether it already exists in the result list.
2. If it does not exist, append it.
3. Otherwise, skip it.

### Time Complexity

- Searching in a list: O(n).
- Repeating this for n elements: O(n²).

Space Complexity: O(n).

**Important:** This approach is useful for understanding the logic but is slower for large datasets.

## 7. Deduplication in Strings

Deduplication can also be performed on strings.

### Example

```python
text = "programming"

seen = set()
result = ""

for char in text:

    if char not in seen:
        result += char
        seen.add(char)

print(result)
```

**Output:**

```text
progamin
```

### Explanation

Original string:

```text
programming
```

Repeated characters:

- r appears more than once.
- g appears more than once.
- m appears more than once.

The result contains only the first occurrence of each character.

**Note:** For very large strings, repeatedly concatenating strings can be inefficient. A list with `"".join()` is preferable.

### Optimized Version

```python
text = "programming"

seen = set()
result = []

for char in text:

    if char not in seen:
        result.append(char)
        seen.add(char)

print("".join(result))
```

## 8. Removing Duplicate Characters Using a Dictionary

A dictionary can also preserve the first occurrence of each character.

```python
text = "banana"

unique = "".join(dict.fromkeys(text))

print(unique)
```

**Output:**

```text
ban
```

Here:

- b appears first.
- a appears next.
- n appears next.
- The remaining repeated characters are ignored.

## 9. Deduplication in a Sorted Array

If an array is already sorted, duplicates appear next to each other.

We can use the Two Pointer technique to remove duplicates efficiently.

### Example

Input:

```python
numbers = [1, 1, 2, 2, 3, 3, 4, 5, 5]
```

Expected Output:

```text
[1, 2, 3, 4, 5]
```

### Python Implementation

```python
def remove_duplicates(numbers):

    if not numbers:
        return []

    result = [numbers[0]]

    for i in range(1, len(numbers)):

        if numbers[i] != numbers[i - 1]:
            result.append(numbers[i])

    return result


numbers = [1, 1, 2, 2, 3, 3, 4, 5, 5]

print(remove_duplicates(numbers))
```

### Explanation

Because the array is sorted, we only need to compare the current element with the previous element.

If both are different, the current element is unique.

### Time Complexity

- Time: O(n).
- Space: O(n) for the output list.

---

## 10. In-Place Deduplication Using Two Pointers

Sometimes the interviewer asks us to remove duplicates without creating another list.

This can be done using the Two Pointer technique on a sorted array.

### Example

```python
def remove_duplicates(numbers):

    if not numbers:
        return 0

    j = 0

    for i in range(1, len(numbers)):

        if numbers[i] != numbers[j]:

            j += 1
            numbers[j] = numbers[i]

    return j + 1


numbers = [1, 1, 2, 2, 3, 4, 4]

k = remove_duplicates(numbers)

print(numbers[:k])
```

**Output:**

```text
[1, 2, 3, 4]
```

### Understanding the Two Pointers

- `i` checks every element.
- `j` tracks the position of the last unique element.
- When a new unique element is found, increment `j`.
- Copy the unique element into position `j`.

Time Complexity: O(n).

Auxiliary Space Complexity: O(1).

**Important:** This solution modifies the original array and assumes the input is sorted.

## 12. Problem 2: Find Duplicate Elements

**Question:**

Find all elements that appear more than once.

Input:

```python
numbers = [1, 2, 3, 2, 4, 1, 5]
```

Expected Output:

```text
[2, 1]
```

### Solution

```python
def find_duplicates(numbers):

    seen = set()
    duplicates = []

    for num in numbers:

        if num in seen:

            if num not in duplicates:
                duplicates.append(num)

        else:
            seen.add(num)

    return duplicates


numbers = [1, 2, 3, 2, 4, 1, 5]

print(find_duplicates(numbers))
```

Time Complexity: O(n) average.

Space Complexity: O(n).

## 13. Problem 3: Remove Duplicate Characters

**Question:**

Given a string, remove repeated characters while maintaining the original order.

Input:

```python
text = "banana"
```

Expected Output:

```text
ban
```

### Solution

```python
def remove_duplicate_characters(text):

    seen = set()
    result = []

    for char in text:

        if char not in seen:
            result.append(char)
            seen.add(char)

    return "".join(result)


text = "banana"

print(remove_duplicate_characters(text))
```

Time Complexity: O(n) average.

Space Complexity: O(k), where k is the number of distinct characters.

## 14. Problem 4: Find the Intersection of Two Arrays

**Question:**

Given two arrays, return the unique elements that appear in both arrays.

Input:

```python
a = [1, 2, 2, 3, 4]
b = [2, 2, 4, 5, 6]
```

Expected Output:

```text
[2, 4]
```

### Solution

```python
def intersection(a, b):

    set_b = set(b)
    result = []

    for num in a:

        if num in set_b and num not in result:
            result.append(num)

    return result


a = [1, 2, 2, 3, 4]
b = [2, 2, 4, 5, 6]

print(intersection(a, b))
```

Time Complexity: O(n + m) average for building and checking the set, with this implementation's additional `num not in result` check potentially making the overall time O(n + m + n × k).

Space Complexity: O(m + k).

## 15. Problem 5: Find the First Repeating Element

**Question:**

Find the first element that repeats while scanning from left to right.

Input:

```python
numbers = [10, 20, 30, 20, 40, 10]
```

Expected Output:

```text
20
```

### Solution

```python
def first_repeating(numbers):

    seen = set()

    for num in numbers:

        if num in seen:
            return num

        seen.add(num)

    return None


numbers = [10, 20, 30, 20, 40, 10]

print(first_repeating(numbers))
```

Time Complexity: O(n) average.

Space Complexity: O(n).

# PART 3: COMPARISON OF TECHNIQUES

## 17. Deduplication Techniques

| Technique | Time Complexity | Extra Space | Preserves Order |
|---|---|---|---|
| Set conversion | O(n) average | O(n) | No guarantee |
| Set + Loop | O(n) average | O(n) | Yes |
| Dictionary | O(n) average | O(n) | Yes |
| Nested loops | O(n²) | O(n) output | Yes |
| Sorted array | O(n) | O(n) output | Yes |
| Two pointers | O(n) | O(1) auxiliary | Yes |

## 18. When Should You Use Each Technique?

| Requirement | Recommended Technique |
|---|---|
| Fast duplicate removal | Set |
| Preserve original order | Set + Loop |
| Short Python implementation | `dict.fromkeys()` |
| No hash-based structures | Nested loops |
| Already sorted array | Two Pointers |
| Modify sorted array in place | Two Pointers |

# PART 4: TIME AND SPACE COMPLEXITY

## 19. Understanding Complexity

Suppose we have:

```python
numbers = [10, 20, 10, 30, 20, 40]
```

There are six elements, but only four distinct elements.

Therefore:

- n = 6 total elements.
- k = 4 distinct elements.

For set-based deduplication:

```python
unique_numbers = set(numbers)
```

The set processes all n elements.

Each insertion takes O(1) average time.

Overall:

Time Complexity = O(n) average.

Space Complexity = O(k), which is O(n) in the worst case.

### Why Is Nested Loop Deduplication O(n²)?

```python
result = []

for num in numbers:

    if num not in result:
        result.append(num)
```

The expression `num not in result` may scan the result list.

In the worst case, the result list contains almost all original elements.

Therefore:

Time Complexity = O(n²).

# 23. Key Points to Remember

- Deduplication means removing repeated elements.
- Sets automatically maintain unique elements.
- Dictionaries can remove duplicates while preserving insertion order.
- A set combined with a loop preserves the original order.
- Nested loops can solve deduplication without hash-based structures.
- Two pointers are useful for sorted arrays.
- In-place deduplication can achieve O(1) auxiliary space.
- Hash-based deduplication takes O(n) average time.
- Always understand whether the problem requires preserving order.

**Most Important Interview Concept:**

Use a Hash Set when you need fast duplicate detection.

Use a Set + List approach when you need to remove duplicates while preserving the original order.

Use Two Pointers when the array is sorted and the problem requires in-place modification.
