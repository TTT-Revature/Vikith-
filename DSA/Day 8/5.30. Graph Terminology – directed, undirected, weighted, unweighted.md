# Graph Terminology – Directed, Undirected, Weighted and Unweighted Graphs

## 1. Introduction to Graphs

A **Graph** is a non-linear data structure consisting of a collection of vertices (nodes) and edges (connections between nodes).

Graphs are used to represent relationships and connections between different objects.

### Real-World Examples

1. Google Maps – Locations connected by roads.
2. Social Media – Users connected through friendships or followers.
3. Computer Networks – Computers connected through network links.
4. Flight Systems – Airports connected through flights.
5. Recommendation Systems – Users connected to products.
6. Web Pages – Pages connected through hyperlinks.

### Basic Graph Structure

```text
        A
       / \
      B   C
      |   |
      D---E
```

Here:

- A, B, C, D and E are vertices.
- The connecting lines are edges.

---

## 2. Basic Graph Terminologies

Consider this graph:

```text
        A
       / \
      B   C
      |   |
      D---E
```

### 2.1 Vertex (Node)

A vertex is an individual element or point in a graph.

Example:

A, B, C, D and E are vertices.

### 2.2 Edge

An edge represents a connection between two vertices.

Example:

- A – B
- A – C
- B – D
- D – E
- C – E

### 2.3 Adjacent Vertices

Two vertices are adjacent if there is a direct edge connecting them.

Example:

A and B are adjacent.

A and E are not adjacent because there is no direct edge between them.

### 2.4 Degree of a Vertex

The degree of a vertex is the number of edges connected to it in an undirected graph.

Example:

```text
        A
       / \
      B   C
      |
      D
```

Degree of A = 2

Degree of B = 2

Degree of C = 1

Degree of D = 1

**Important:**

In an undirected graph, the sum of all vertex degrees equals twice the number of edges.

```text
Sum of Degrees = 2 × Number of Edges
```

### 2.5 Path

A path is a sequence of vertices connected through edges.

Example:

```text
A → B → D → E
```

This is a path from A to E.

### 2.6 Cycle

A cycle is a path that starts and ends at the same vertex without repeating other vertices.

Example:

```text
       A
      / \
     B---C
```

Cycle:

A → B → C → A

### 2.7 Connected Graph

An undirected graph is connected if there is a path between every pair of vertices.

Example:

```text
A --- B --- C
      |
      D
```

Every vertex is reachable from every other vertex.

### 2.8 Disconnected Graph

A graph is disconnected if at least one pair of vertices has no path connecting them.

Example:

```text
A --- B       C --- D
```

There are two separate connected components.

### 2.9 Self-Loop

A self-loop is an edge that connects a vertex to itself.

Example:

```text
      A
     ↺
```

### 2.10 Subgraph

A subgraph is a smaller graph formed using some of the vertices and edges of another graph.

# 3. Types of Graphs

Graphs can be classified based on the direction and weight of their edges.

The four important types are:

1. Directed Graph
2. Undirected Graph
3. Weighted Graph
4. Unweighted Graph

---

## 4. Directed Graph

A **Directed Graph (Digraph)** is a graph in which every edge has a specific direction.

The edges are represented using arrows.

This means a connection from A to B does not automatically mean there is a connection from B to A.

### Example

```text
       A
       ↓
       B
       ↓
       C
```

Connections:

- A → B
- B → C

Here, we can travel from A to C.

However, we cannot automatically travel from C to A.

### Real-World Examples

1. Instagram – One user follows another user without necessarily being followed back.
2. Twitter/X – Following relationships.
3. Website Navigation – One webpage links to another webpage.
4. Task Dependencies – One task must finish before another begins.

### Python Representation

We can represent a directed graph using an adjacency list.

```python
graph = {
    'A': ['B'],
    'B': ['C'],
    'C': []
}

print(graph)
```

This means:

- A points to B.
- B points to C.
- C has no outgoing edges.

### Adding an Edge

```python
def add_edge(graph, u, v):

    graph[u].append(v)


graph = {
    'A': [],
    'B': [],
    'C': []
}

add_edge(graph, 'A', 'B')
add_edge(graph, 'B', 'C')

print(graph)
```

Output:

```text
{
    'A': ['B'],
    'B': ['C'],
    'C': []
}
```

Notice that we only add the connection in one direction.

---

## 5. Undirected Graph

An **Undirected Graph** is a graph in which edges do not have any direction.

If A is connected to B, then B is also connected to A.

The edges are represented using simple lines instead of arrows.

### Example

```text
        A
       / \
      B---C
```

Connections:

- A — B
- A — C
- B — C

We can travel in both directions.

For example:

A → B and B → A are both possible.

### Real-World Examples

1. Facebook – Mutual friendship relationships.
2. Road Networks – Roads that allow travel in both directions.
3. Computer Networks – Two computers connected through a bidirectional link.
4. Collaboration Networks – People working together.

### Python Representation

```python
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'C'],
    'C': ['A', 'B']
}

print(graph)
```

### Adding an Edge

```python
def add_edge(graph, u, v):

    graph[u].append(v)
    graph[v].append(u)


graph = {
    'A': [],
    'B': [],
    'C': []
}

add_edge(graph, 'A', 'B')
add_edge(graph, 'A', 'C')

print(graph)
```

Output:

```text
{
    'A': ['B', 'C'],
    'B': ['A'],
    'C': ['A']
}
```

Notice that we add the connection in both directions.

---

## 6. Directed Graph vs Undirected Graph

| Feature | Directed Graph | Undirected Graph |
|---|---|---|
| Direction | Has direction | No direction |
| Representation | Arrows | Lines |
| Connection | A → B | A — B |
| Reverse Connection | Not automatic | Always possible |
| Degree | In-degree and out-degree | Degree |
| Example | Instagram following | Facebook friendship |

# 7. Weighted Graph

A **Weighted Graph** is a graph in which every edge has an associated value called a weight.

Weights can represent:

- Distance
- Cost
- Time
- Price
- Network latency

### Example

Consider a road network:

```text
          10
      A ------- B
       \       /
      20\     /15
         \   /
           C
```

Here:

- A to B = 10 km
- A to C = 20 km
- B to C = 15 km

The numbers represent the weights of the edges.

### Real-World Examples

1. Google Maps – Distance between locations.
2. Flight Booking – Ticket prices between cities.
3. Computer Networks – Network latency.
4. Delivery Systems – Travel time between locations.

### Python Representation

A weighted graph can be represented using an adjacency list containing tuples.

```python
graph = {
    'A': [('B', 10), ('C', 20)],
    'B': [('A', 10), ('C', 15)],
    'C': [('A', 20), ('B', 15)]
}

print(graph)
```

Understanding the structure:

```python
'A': [('B', 10), ('C', 20)]
```

This means:

- A is connected to B with weight 10.
- A is connected to C with weight 20.

### Adding a Weighted Edge

```python
def add_edge(graph, u, v, weight):

    graph[u].append((v, weight))
    graph[v].append((u, weight))


graph = {
    'A': [],
    'B': [],
    'C': []
}

add_edge(graph, 'A', 'B', 10)
add_edge(graph, 'A', 'C', 20)

print(graph)
```

Output:

```text
{
    'A': [('B', 10), ('C', 20)],
    'B': [('A', 10)],
    'C': [('A', 20)]
}
```

This example represents an undirected weighted graph.

**Important:** For a directed weighted graph, add only one direction instead of adding both connections.

---

# 8. Unweighted Graph

An **Unweighted Graph** is a graph in which edges do not have associated weights.

All edges are treated equally in terms of edge cost.

### Example

```text
        A
       / \
      B   C
      |   |
      D---E
```

There are no numerical weights associated with the connections.

### Real-World Examples

1. Social networks – Friend connections.
2. Simple relationship networks.
3. Unweighted communication networks.
4. Basic connectivity problems.

### Python Representation

```python
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'E'],
    'D': ['B', 'E'],
    'E': ['C', 'D']
}

print(graph)
```

---

## 9. Weighted Graph vs Unweighted Graph

| Feature | Weighted Graph | Unweighted Graph |
|---|---|---|
| Edge Values | Has weights | No weights |
| Edge Cost | Can differ | Usually treated equally |
| Representation | Tuples or dictionaries | Lists |
| Example | Road distance | Basic connectivity |
| Common Algorithms | Dijkstra, Prim | BFS, DFS |

**Important:** BFS can find the shortest path in terms of the number of edges in an unweighted graph. For weighted graphs, algorithms such as Dijkstra's algorithm are used when edge weights are non-negative.

# 10. In-Degree and Out-Degree

These concepts are specifically important in directed graphs.

### In-Degree

The number of incoming edges connected to a vertex.

### Out-Degree

The number of outgoing edges from a vertex.

Example:

```text
       A
       ↓
       B → C
       ↑
       D
```

For vertex B:

- In-Degree = 2 (A and D)
- Out-Degree = 1 (C)

### Python Example

```python
graph = {
    'A': ['B'],
    'B': ['C'],
    'C': [],
    'D': ['B']
}

vertex = 'B'

in_degree = 0
out_degree = len(graph[vertex])

for node in graph:

    if vertex in graph[node]:
        in_degree += 1

print("In-Degree:", in_degree)
print("Out-Degree:", out_degree)
```

Output:

```text
In-Degree: 2
Out-Degree: 1
```

# 11. Graph Representation Methods

Graphs can be represented in different ways.

The two most common representations are:

1. Adjacency Matrix
2. Adjacency List

## 11.1 Adjacency Matrix

An adjacency matrix is a two-dimensional array used to represent connections between vertices.

Example:

```text
       A
      / \
     B---C
```

Adjacency Matrix:

|   | A | B | C |
|---|---|---|---|
| A | 0 | 1 | 1 |
| B | 1 | 0 | 1 |
| C | 1 | 1 | 0 |

Here:

- 1 means an edge exists.
- 0 means no edge exists.

### Python Implementation

```python
graph = [
    [0, 1, 1],
    [1, 0, 1],
    [1, 1, 0]
]

for row in graph:
    print(row)
```

Output:

```text
[0, 1, 1]
[1, 0, 1]
[1, 1, 0]
```

### Advantages

- Easy to check whether an edge exists.
- Simple implementation.
- Useful for dense graphs.

### Disadvantages

- Requires O(V²) memory.
- Wastes memory for sparse graphs.

## 11.2 Adjacency List

An adjacency list stores each vertex along with its neighboring vertices.

Example:

```text
       A
      / \
     B---C
```

Python Representation:

```python
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'C'],
    'C': ['A', 'B']
}
```

### Advantages

- Memory efficient for sparse graphs.
- Easy to iterate through neighboring vertices.
- Commonly used in graph algorithms.

### Disadvantages

- Checking whether a particular edge exists may take O(degree of vertex) time.

### Comparison

| Feature | Adjacency Matrix | Adjacency List |
|---|---|---|
| Space | O(V²) | O(V + E) |
| Check Edge | O(1) | O(degree of vertex) |
| Find Neighbors | O(V) | O(degree of vertex) |
| Best For | Dense Graphs | Sparse Graphs |

Where:

- V = Number of vertices.
- E = Number of edges.

# 12. Other Important Graph Types

### 12.1 Cyclic Graph

A graph containing at least one cycle.

```text
      A
     / \
    B---C
```

### 12.2 Acyclic Graph

A graph that does not contain any cycle.

```text
      A
     / \
    B   C
       /
      D
```

### 12.3 Connected Graph

A graph where every vertex can be reached from every other vertex.

### 12.4 Disconnected Graph

A graph containing multiple separate connected components.

### 12.5 Complete Graph

A simple graph in which every pair of distinct vertices is connected by an edge.

Example:

```text
       A
      /|\
     / | \
    B--|--C
     \   /
      \ /
       D
```

For an undirected complete graph with V vertices:

```text
Number of Edges = V × (V - 1) / 2
```

**Q10. What is a connected graph?**

A graph in which every pair of vertices has a connecting path.

An adjacency matrix uses a two-dimensional array, while an adjacency list stores neighboring vertices.

**Q12. What is a self-loop?**

An edge that connects a vertex to itself.

**Q13. What is the difference between cyclic and acyclic graphs?**

A cyclic graph contains at least one cycle, whereas an acyclic graph contains no cycles.
