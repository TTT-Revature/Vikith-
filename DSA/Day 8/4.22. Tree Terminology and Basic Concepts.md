# Tree – Terminology and Basic Concepts

## 1. What is a Tree?

A **Tree** is a non-linear data structure that organises data in a hierarchical manner.

Unlike arrays, linked lists, stacks, and queues, which store elements sequentially, a tree stores elements in a parent-child relationship.

Each element in a tree is called a **Node**, and nodes are connected using **Edges**.

### Real-World Examples

- File systems – folders and files.
- Organisation charts – manager and employee relationships.
- HTML DOM – parent and child elements.
- Database indexing – B-Trees and B+ Trees.
- Decision-making systems – decision trees.
- Computer networks – hierarchical structures.

## 2. Basic Structure of a Tree

Consider the following tree:

```text
              A
            /   \
           B     C
          / \     \
         D   E     F
```

Here:
- A is the root node.
- B and C are children of A.
- A is the parent of B and C.
- D, E, and F are leaf nodes.

## 3. Tree Terminologies

### 3.1 Node

A node is an individual element in a tree that stores data.

Example:

```text
    A
```

Here, A is a node.

### 3.2 Root Node

The root is the topmost node of a tree.

- Every tree has exactly one root node (for a non-empty tree).
- It does not have a parent.

Example:

```text
       A
      / \
     B   C
```

A is the root node.

### 3.3 Edge

An edge is a connection between two nodes.

Example:

```text
      A
     /
    B
```

The connection between A and B is an edge.

### 3.4 Parent Node

A node that has one or more child nodes is called a parent node.

Example:

```text
       A
      / \
     B   C
```

A is the parent of B and C.

### 3.5 Child Node

A node directly connected below another node is called its child.

Example:

```text
       A
      / \
     B   C
```

B and C are children of A.

### 3.6 Siblings

Nodes that share the same parent are called siblings.

Example:

```text
       A
      / \
     B   C
```

B and C are siblings because they have the same parent A.

### 3.7 Leaf Node (External Node)

A node that does not have any children is called a leaf node.

Example:

```text
       A
      / \
     B   C
        / \
       D   E
```

B, D, and E are leaf nodes.

### 3.8 Internal Node

A node that has at least one child is called an internal node.

Example:

```text
       A
      / \
     B   C
        / \
       D   E
```

A and C are internal nodes.

### 3.9 Ancestor

An ancestor of a node is any node that appears on the path from the root to that node, excluding the node itself.

Example:

```text
        A
       /
      B
     /
    C
```

For node C:
- A is an ancestor.
- B is an ancestor.

### 3.10 Descendant

A descendant is any node that exists below a particular node in its subtree.

Example:

```text
        A
       / \
      B   C
     /
    D
```

B and D are descendants of A.

### 3.11 Subtree

A subtree is a tree formed by a node and all its descendants.

Example:

```text
        A
       / \
      B   C
     / \
    D   E
```

The subtree rooted at B is:

```text
      B
     / \
    D   E
```

### 3.12 Degree of a Node

The degree of a node is the number of children it has.

Example:

```text
        A
      / | \
     B  C  D
```

- Degree of A = 3
- Degree of B = 0
- Degree of C = 0
- Degree of D = 0

### 3.13 Degree of a Tree

The degree of a tree is the maximum degree of any node in that tree.

Example:

```text
        A
      / | \
     B  C  D
```

Degree of the tree = 3.

### 3.14 Path

A path is a sequence of nodes connected through edges.

Example:

```text
       A
      /
     B
    /
   C
```

Path from A to C:

A → B → C

### 3.15 Path Length

Path length is the number of edges present in a path.

Example:

```text
       A
      /
     B
    /
   C
```

Path: A → B → C

Number of edges = 2.

Therefore, path length = 2.

### 3.16 Depth of a Node

Depth is the number of edges from the root node to a particular node.

- Root node depth = 0.
- Its children have depth = 1.
- The next level has depth = 2.

Example:

```text
          A          Depth 0
         / \
        B   C        Depth 1
       /
      D              Depth 2
```

Depth of D = 2.

### 3.17 Level of a Node

The level represents the position of a node in a tree.

In the convention used here:

**Level = Depth + 1**

Example:

```text
          A          Level 1
         / \
        B   C        Level 2
       /
      D              Level 3
```

Note: Some textbooks define the root as level 0. Always check the convention being used.

### 3.18 Height of a Node

Height of a node is the number of edges on the longest downward path from that node to a leaf node.

Example:

```text
          A
         / \
        B   C
       /
      D
```

- Height of D = 0
- Height of B = 1
- Height of C = 0
- Height of A = 2

### 3.19 Height of a Tree

The height of a tree is the height of its root node.

It is also the maximum depth of any node in the tree.

Example:

```text
          A
         / \
        B   C
       /
      D
```

Height of the tree = 2 edges.

## 4. Important Properties of Trees

1. A non-empty tree has exactly one root node.
2. Every node except the root has exactly one parent.
3. A tree with N nodes has exactly N - 1 edges.
4. There is exactly one path between any two nodes in a tree.
5. A tree does not contain cycles.
6. Removing an edge from a tree disconnects it.
7. Adding an edge between existing nodes creates a cycle.

## 5. Types of Trees

Some commonly used types of trees are:

| Tree Type | Description |
|---|---|
| General Tree | A node can have any number of children. |
| Binary Tree | Each node can have at most two children. |
| Binary Search Tree (BST) | Left subtree values are smaller and right subtree values are larger than the node, under the usual unique-key convention. |
| Full Binary Tree | Every node has either zero or two children. |
| Complete Binary Tree | All levels are completely filled except possibly the last, which is filled from left to right. |
| Perfect Binary Tree | All internal nodes have two children and all leaves are at the same level. |
| Balanced Binary Tree | A tree whose height is maintained within a specified balance condition. |
| AVL Tree | A self-balancing Binary Search Tree. |
| Heap | A complete binary tree that follows the min-heap or max-heap property. |

## 6. Tree vs Linear Data Structures

| Feature | Linear Data Structure | Tree Data Structure |
|---|---|---|
| Organisation | Sequential | Hierarchical |
| Relationship | Previous and next elements | Parent and child |
| Traversal | Usually sequential | Multiple traversal methods |
| Structure | Single sequence | Multiple branches |
| Examples | Array, Stack, Queue | Binary Tree, BST, AVL |

## 7. Python Representation of a Binary Tree Node

A basic binary tree node can be represented using a Python class.

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None
```

### Creating a Binary Tree

```python

    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None


# Creating nodes
root = Node("A")
root.left = Node("B")
root.right = Node("C")

root.left.left = Node("D")
root.left.right = Node("E")
