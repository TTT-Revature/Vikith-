# Sliding Window Technique in Python

## 1. What is Sliding Window?

**Sliding Window** is an algorithmic technique used to solve problems involving continuous portions of an array or string.

Instead of repeatedly calculating the result for every possible subarray or substring, we maintain a window and move it through the input.

A window represents a continuous range of elements.

### Example

Consider this array:

```python
arr = [2, 1, 5, 1, 3, 2]
```

Suppose we need to find the maximum sum of any subarray of size `3`.

The possible windows are:

```text
[2, 1, 5] = 8
[1, 5, 1] = 7
[5, 1, 3] = 9
[1, 3, 2] = 6
```

Maximum sum = `9`

Instead of calculating every window from scratch, we can reuse the previous window's sum.

```text
Initial window:

[2, 1, 5] 1 3 2
 Sum = 8

Slide one position:

2 [1, 5, 1] 3 2
 Sum = 8 - 2 + 1 = 7

Slide again:

2 1 [5, 1, 3] 2
 Sum = 7 - 1 + 3 = 9
```

We remove the element leaving the window and add the new element entering it.

This reduces unnecessary calculations.

---

## 2. Why Do We Need Sliding Window?

Consider an array of size `n`.

If we calculate the sum of every subarray of size `k` independently, we perform approximately:

```text
n * k operations
```

Time complexity:

```text
O(n * k)
```

Using Sliding Window, we calculate the first window and then update its sum in constant time for each next position.

Time complexity:

```text
O(n)
```

### Comparison

| Approach | Time Complexity |
|---|---|
| Brute Force | O(n * k) |
| Sliding Window | O(n) |

Sliding Window is especially useful when a problem asks about:

- Continuous subarrays
- Continuous substrings
- Maximum or minimum sum
- Longest or shortest substring
- Fixed-size ranges
- A condition that must be maintained inside a range

# 3. Types of Sliding Window

There are two major types:

1. Fixed Size Sliding Window
2. Variable Size Sliding Window

## 3.1 Fixed Size Sliding Window

In this approach, the window size remains constant.

For example:

```text
Find the maximum sum of 3 consecutive elements.
```

The window always contains exactly three elements.

### Visual Representation

```text
Array: [2, 1, 5, 1, 3, 2]

Window 1:
       [2, 1, 5] 1 3 2

Window 2:
        2 [1, 5, 1] 3 2

Window 3:
        2 1 [5, 1, 3] 2

Window 4:
        2 1 5 [1, 3, 2]
```

### Example 1: Maximum Sum of Subarray of Size K

**Problem:**

Given an array and an integer `k`, find the maximum sum of any continuous subarray of size `k`.

Input:

```python
arr = [2, 1, 5, 1, 3, 2]
k = 3
```

Expected Output:

```text
9
```

### Python Code

```python
def max_subarray_sum(arr, k):
    window_sum = 0
    max_sum = float('-inf')

    for right in range(len(arr)):
        window_sum += arr[right]

        if right >= k - 1:
            max_sum = max(max_sum, window_sum)

            window_sum -= arr[right - k + 1]

    return max_sum


arr = [2, 1, 5, 1, 3, 2]
k = 3

print(max_subarray_sum(arr, k))
```

Output:

```text
9
```

### Step-by-Step Execution

Initial values:

```text
window_sum = 0
max_sum = -infinity
k = 3
```

| Right | Element Added | Window Sum | Maximum Sum | Element Removed |
|---|---:|---:|---:|---:|
| 0 | 2 | 2 | -∞ | None |
| 1 | 1 | 3 | -∞ | None |
| 2 | 5 | 8 | 8 | 2 |
| 3 | 1 | 7 | 8 | 1 |
| 4 | 3 | 9 | 9 | 5 |
| 5 | 2 | 6 | 9 | 1 |

Final answer:

```text
9
```

**Complexity:**

- Time: O(n)
- Space: O(1)

---

## 3.2 Variable Size Sliding Window

In this approach, the window size changes depending on a condition.

The window expands when we need more elements and shrinks when the current window violates a condition.

Example:

```text
Find the smallest subarray whose sum is greater than or equal to 7.
```

Input:

```python
arr = [2, 3, 1, 2, 4, 3]
target = 7
```

Possible valid subarrays:

```text
[2, 3, 1, 2] = 8
[3, 1, 2, 4] = 10
[1, 2, 4] = 7
[4, 3] = 7
```

The smallest valid subarray is:

```text
[4, 3]
```

Answer:

```text
2
```

### How Does It Work?

We use two pointers:

- `left`: beginning of the window
- `right`: end of the window

We also maintain the current window sum.

Rules:

1. Expand the window by moving `right`.
2. Add the new element to the sum.
3. If the sum reaches the target, update the minimum length.
4. Shrink the window by moving `left`.
5. Repeat until all elements are processed.

### Python Code

```python
def min_subarray_length(target, arr):
    left = 0
    window_sum = 0
    min_length = float('inf')

    for right in range(len(arr)):
        window_sum += arr[right]

        while window_sum >= target:
            min_length = min(min_length, right - left + 1)

            window_sum -= arr[left]
            left += 1

    return 0 if min_length == float('inf') else min_length


arr = [2, 3, 1, 2, 4, 3]
target = 7

print(min_subarray_length(target, arr))
```

Output:

```text
2
```

**Important:** This particular sum-based shrinking technique assumes the array contains positive numbers (or otherwise has properties that make expanding and shrinking valid). It does not work generally with negative numbers.

**Complexity:**

- Time: O(n)
- Space: O(1)

# 4. Understanding Left and Right Pointers

Sliding Window commonly uses two pointers.

```python
left = 0
right = 0
```

Example:

```python
arr = [1, 2, 3, 4, 5]
```

Initially:

```text
left = 0
right = 0
```

Window:

```text
[1] 2 3 4 5
 ^
```

Expand:

```text
[1, 2] 3 4 5
 ^   ^
left right
```

Expand again:

```text
[1, 2, 3] 4 5
 ^      ^
left   right
```

Shrink:

```text
1 [2, 3] 4 5
  ^   ^
 left right
```

The important idea is that we do not restart the entire calculation when the window changes. We update the information we maintain.

# 5. Important Sliding Window Problems

## Problem 1: Average of Every Subarray of Size K

**Problem:**

Find the average of every continuous subarray of size `k`.

Input:

```python
arr = [1, 3, 2, 6, -1, 4, 1, 8, 2]
k = 5
```

Expected Output:

```text
[2.2, 2.8, 2.4, 3.6, 2.8]
```

### Python Code

```python
def find_averages(arr, k):
    result = []
    window_sum = 0
    left = 0

    for right in range(len(arr)):
        window_sum += arr[right]

        if right >= k - 1:
            result.append(window_sum / k)

            window_sum -= arr[left]
            left += 1

    return result


arr = [1, 3, 2, 6, -1, 4, 1, 8, 2]
print(find_averages(arr, 5))
```

Output:

```text
[2.2, 2.8, 2.4, 3.6, 2.8]
```

## Problem 2: Maximum Number of Vowels in a Substring

**Problem:**

Given a string and an integer `k`, find the maximum number of vowels in any substring of length `k`.

Input:

```python
s = "abciiidef"
k = 3
```

Expected Output:

```text
3
```

Explanation:

```text
Substring: "iii"
Vowels: i, i, i

Count = 3
```

### Python Code

```python
def max_vowels(s, k):
    vowels = set("aeiou")
    count = 0
    max_count = 0
    left = 0

    for right in range(len(s)):
        if s[right] in vowels:
            count += 1

        if right >= k - 1:
            max_count = max(max_count, count)

            if s[left] in vowels:
                count -= 1

            left += 1

    return max_count


s = "abciiidef"
k = 3

print(max_vowels(s, k))
```

Output:

```text
3
```

**Complexity:**

- Time: O(n)
- Space: O(1), because the vowel set has a fixed size.

## Problem 3: Longest Substring Without Repeating Characters

**Problem:**

Given a string, find the length of the longest substring without repeating characters.

Input:

```python
s = "abcabcbb"
```

Expected Output:

```text
3
```

Explanation:

```text
"abc" is the longest substring without repeating characters.

Length = 3
```

### Python Code

```python
def length_of_longest_substring(s):
    char_set = set()

    left = 0
    max_length = 0

    for right in range(len(s)):

        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1

        char_set.add(s[right])

        max_length = max(max_length, right - left + 1)

    return max_length


s = "abcabcbb"

print(length_of_longest_substring(s))
```

Output:

```text
3
```

### Explanation

When a duplicate character appears:

1. Remove characters from the left side.
2. Move the left pointer forward.
3. Continue until the duplicate is removed.
4. Add the current character.
5. Update the maximum window length.

**Complexity:**

- Time: O(n) average
- Space: O(min(n, alphabet size))

## Problem 4: Longest Substring with At Most K Distinct Characters

**Problem:**

Find the length of the longest substring containing at most `k` distinct characters.

Input:

```python
s = "araaci"
k = 2
```

Expected Output:

```text
4
```

Explanation:

```text
"araa"

Distinct characters:
a, r

Length = 4
```

### Python Code

```python
def longest_substring_k_distinct(s, k):
    left = 0
    max_length = 0

    frequency = {}

    for right in range(len(s)):
        char = s[right]

        frequency[char] = frequency.get(char, 0) + 1

        while len(frequency) > k:
            left_char = s[left]

            frequency[left_char] -= 1

            if frequency[left_char] == 0:
                del frequency[left_char]

            left += 1

        max_length = max(max_length, right - left + 1)

    return max_length


s = "araaci"
k = 2

print(longest_substring_k_distinct(s, k))
```

Output:

```text
4
```

**Complexity:**

- Time: O(n) average
- Space: O(k) for the frequency dictionary while the window is valid.

# 6. Sliding Window vs Two Pointers

These techniques are related, but they are not exactly the same.

| Feature | Two Pointers | Sliding Window |
|---|---|---|
| Main idea | Use two indices to solve a problem | Maintain a continuous range |
| Pointer movement | Can move independently | Usually defines a window |
| Common use | Pair sums, reversing, sorted arrays | Subarrays and substrings |
| Window | Not always required | Always maintains a window |
| Example | Two Sum II | Maximum sum of K elements |

**Remember:**

Sliding Window is a specialized use of the Two Pointers technique.

Not every Two Pointers problem is a Sliding Window problem.

# 7. Sliding Window Template

## Fixed Size Template

```python
def sliding_window(arr, k):
    left = 0
    window_value = 0
    result = []

    for right in range(len(arr)):
        # Add the new element
        window_value += arr[right]

        # Check whether window has reached size k
        if right - left + 1 == k:

            # Process the current window
            result.append(window_value)

            # Remove the element leaving the window
            window_value -= arr[left]
            left += 1

    return result
```

## Variable Size Template

```python
def sliding_window(arr):
    left = 0
    result = 0

    for right in range(len(arr)):

        # Expand the window
        # Update the current window information

        while condition_is_invalid:

            # Shrink the window
            # Update the current window information

            left += 1

        # Update the answer using the valid window

    return result
```

The variable-size template must be adapted to the exact problem. In some problems, the window is shrunk when a condition is invalid; in others, it is shrunk while a valid window can still be improved.

# 8. Common Mistakes in Sliding Window

### Mistake 1: Removing the Wrong Element

Incorrect:

```python
window_sum -= arr[right]
```

Correct:

```python
window_sum -= arr[left]
left += 1
```

We remove the element that leaves the window, not the element that just entered.

### Mistake 2: Incorrect Window Size

Window size is calculated as:

```python
right - left + 1
```

Why `+1`?

Because array indices start from zero.

For example:

```text
left = 2
right = 4

Window = [5, 6, 7]

Size = 4 - 2 + 1 = 3
```

### Mistake 3: Using `if` Instead of `while`

For variable-size windows, we often need to shrink the window multiple times.

Incorrect:

```python
if window_sum >= target:
    left += 1
```

Correct:

```python
while window_sum >= target:
    # Update answer
    # Remove arr[left]
    left += 1
```

### Mistake 4: Assuming Sliding Window Works for Every Array

Some sum-based variable-window approaches require positive numbers.

For arrays with negative numbers, expanding the window does not always increase the sum, and shrinking does not always decrease it.

Always check the problem's constraints before choosing the technique.

# 9. Time and Space Complexity

| Problem Pattern | Time Complexity | Auxiliary Space |
|---|---|---|
| Fixed size sum | O(n) | O(1) |
| Fixed size average | O(n) | O(1), excluding output |
| Maximum vowels | O(n) | O(1) |
| Longest unique substring | O(n) average | O(min(n, alphabet size)) |
| At most K distinct | O(n) average | O(k) |
| Minimum subarray sum (positive numbers) | O(n) | O(1) |

Why is Sliding Window often O(n)?

Because the `right` pointer moves forward at most `n` times, and the `left` pointer also moves forward at most `n` times.

Even if there is a nested `while` loop, each element enters and leaves the window at most once.

Therefore, total pointer movement is O(n), not O(n²).

# 13. Key Takeaways

1. Sliding Window is useful for continuous subarray and substring problems.
2. It avoids recalculating information for every possible window.
3. Fixed-size windows maintain a constant number of elements.
4. Variable-size windows expand and shrink based on conditions.
5. Two pointers are commonly used to maintain the window.
6. Many Sliding Window problems can be solved in O(n) time.
7. Always check whether the input constraints support the window strategy.

**The most important thing to understand:**

Instead of starting calculations again for every new subarray, reuse the information from the previous window.

That is the core idea behind Sliding Window.
