# Heaps – Min Heap, Max Heap and Operations

## 1. Introduction to Heaps

A **Heap** is a special type of Complete Binary Tree that satisfies a specific ordering property called the Heap Property.

There are two main types of heaps:

1. Min Heap
2. Max Heap

Heaps are commonly used in:

- Priority Queues
- Heap Sort
- Task Scheduling
- Finding the Kth Largest or Smallest Element
- Graph Algorithms such as Dijkstra's Algorithm and Prim's Algorithm

### Why Do We Need Heaps?

Suppose we have the following numbers:

```python
numbers = [40, 10, 30, 50, 20]
```

If we want to repeatedly retrieve the smallest element, sorting the entire array every time is unnecessary.

A Min Heap allows us to access the smallest element directly from the root.

Similarly, a Max Heap allows us to access the largest element directly.

---

## 2. Properties of a Heap

A heap follows two important properties.

### Property 1: Complete Binary Tree

A heap must always be a Complete Binary Tree.

This means:

- Every level must be completely filled except possibly the last level.
- The last level must be filled from left to right.

Example:

```text
             10
           /    \
         20      30
        /  \
       40   50
```

This is a Complete Binary Tree.

Invalid heap structure:

```text
             10
           /    \
         20      30
           \
            40
```

This is not complete because the last level is not filled from left to right.

### Property 2: Heap Order Property

The parent and child nodes must follow a specific ordering rule.

- Min Heap: Parent must be smaller than or equal to its children.
- Max Heap: Parent must be greater than or equal to its children.

---

## 3. Min Heap

A **Min Heap** is a Complete Binary Tree in which the parent node is always smaller than or equal to its children.

Therefore, the smallest element is always at the root.

### Example

```text
             10
           /    \
         20      30
        /  \
       40   50
```

Here:

- 10 is smaller than 20 and 30.
- 20 is smaller than 40 and 50.
- The minimum value is 10.

### Min Heap Array Representation

A heap is generally represented using an array.

```python
heap = [10, 20, 30, 40, 50]
```

| Index | Value |
|---|---:|
| 0 | 10 |
| 1 | 20 |
| 2 | 30 |
| 3 | 40 |
| 4 | 50 |

Tree representation:

```text
             10
           /    \
         20      30
        /  \
       40   50
```

---

## 4. Max Heap

A **Max Heap** is a Complete Binary Tree in which the parent node is always greater than or equal to its children.

Therefore, the largest element is always at the root.

### Example

```text
             50
           /    \
         40      30
        /  \
       10   20
```

Here:

- 50 is greater than 40 and 30.
- 40 is greater than 10 and 20.
- The maximum value is 50.

### Max Heap Array Representation

```python
heap = [50, 40, 30, 10, 20]
```

---

## 5. Min Heap vs Max Heap

| Feature | Min Heap | Max Heap |
|---|---|---|
| Root Node | Smallest element | Largest element |
| Parent | Smaller than children | Greater than children |
| Priority | Minimum priority value | Maximum priority value |
| Root Access | O(1) | O(1) |
| Insertion | O(log n) | O(log n) |
| Deletion of Root | O(log n) | O(log n) |

### Remember

- Min Heap → Minimum element at the top.
- Max Heap → Maximum element at the top.

# 6. Array Representation of a Heap

A heap is usually implemented using an array instead of linked nodes.

This is possible because a heap is a Complete Binary Tree.

For a zero-indexed array, the relationships are:

| Relationship | Formula |
|---|---|
| Parent | `(i - 1) // 2` |
| Left Child | `2 * i + 1` |
| Right Child | `2 * i + 2` |

Here, `i` represents the current node's index.

### Example

```python
heap = [10, 20, 30, 40, 50]
```

For index 1:

```python
i = 1

parent = (i - 1) // 2
left = 2 * i + 1
right = 2 * i + 2

print("Parent:", heap[parent])
print("Left:", heap[left])
print("Right:", heap[right])
```

Output:

```text
Parent: 10
Left: 40
Right: 50
```

### Important Note

Always check whether the calculated child index is within the array boundaries before accessing it.

# 8. Insertion in Min Heap

Insertion means adding a new element while maintaining the Complete Binary Tree and Min Heap properties.

The insertion process uses an operation called **Heapify Up** (also called Sift Up).

### Steps

1. Insert the new element at the end of the array.
2. Compare it with its parent.
3. If the new element is smaller than its parent, swap them.
4. Continue until the Min Heap property is satisfied.

### Example

Insert 5 into the following Min Heap:

Before insertion:

```text
             10
           /    \
         20      30
        /  \
       40   50
```

Array:

```python
[10, 20, 30, 40, 50]
```

Step 1: Insert 5 at the end.

```text
             10
           /    \
         20      30
        /  \    /
       40   50  5
```

Step 2: Compare 5 with its parent 30.

Since 5 is smaller, swap them.

```text
             10
           /    \
         20       5
        /  \     /
       40   50  30
```

Step 3: Compare 5 with its parent 10.

Swap again.

Final Min Heap:

```text
              5
           /    \
         20      10
        /  \    /
       40   50 30
```

Final Array:

```python
[5, 20, 10, 40, 50, 30]
```

### Python Implementation – Min Heap Insertion

```python
def insert(heap, value):

    heap.append(value)

    i = len(heap) - 1

    while i > 0:

        parent = (i - 1) // 2

        if heap[i] < heap[parent]:

            heap[i], heap[parent] = heap[parent], heap[i]

            i = parent

        else:
            break


heap = [10, 20, 30, 40, 50]

insert(heap, 5)

print(heap)
```

Output:

```text
[5, 20, 10, 40, 50, 30]
```

### Time Complexity

O(log n)

Space Complexity: O(1) auxiliary space.

# 9. Insertion in Max Heap

The insertion process is similar to Min Heap insertion.

The only difference is the comparison condition.

In a Max Heap, the new element moves upward when it is greater than its parent.

### Python Implementation

```python
def insert_max(heap, value):

    heap.append(value)

    i = len(heap) - 1

    while i > 0:

        parent = (i - 1) // 2

        if heap[i] > heap[parent]:

            heap[i], heap[parent] = heap[parent], heap[i]

            i = parent

        else:
            break


heap = [50, 40, 30, 10, 20]

insert_max(heap, 60)

print(heap)
```

Output:

```text
[60, 40, 50, 10, 20, 30]
```

Time Complexity: O(log n).

# 10. Deletion in Min Heap

In a Min Heap, deletion generally means removing the root element, which is the smallest value.

This operation is also called **Extract Min**.

### Steps

1. Store the root element.
2. Replace the root with the last element.
3. Remove the last element.
4. Compare the new root with its children.
5. Swap it with the smaller child if necessary.
6. Continue until the Min Heap property is restored.

This process is called **Heapify Down** (also called Sift Down).

### Example

Before deletion:

```text
             5
           /   \
         20     10
        /  \   /
       40  50 30
```

Array:

```python
[5, 20, 10, 40, 50, 30]
```

Step 1: Remove the root (5).

Step 2: Move the last element (30) to the root.

```text
             30
           /    \
         20      10
        /  \
       40   50
```

Step 3: Compare 30 with its children.

The smaller child is 10.

Swap 30 and 10.

Final Heap:

```text
             10
           /    \
         20      30
        /  \
       40   50
```

Final Array:

```python
[10, 20, 30, 40, 50]
```

### Python Implementation – Delete Min

```python
def delete_min(heap):

    if len(heap) == 0:
        return None

    if len(heap) == 1:
        return heap.pop()

    minimum = heap[0]

    heap[0] = heap.pop()

    i = 0
    n = len(heap)

    while True:

        left = 2 * i + 1
        right = 2 * i + 2

        smallest = i

        if left < n and heap[left] < heap[smallest]:
            smallest = left

        if right < n and heap[right] < heap[smallest]:
            smallest = right

        if smallest == i:
            break

        heap[i], heap[smallest] = heap[smallest], heap[i]

        i = smallest

    return minimum


heap = [5, 20, 10, 40, 50, 30]

removed = delete_min(heap)

print("Deleted:", removed)
print("Heap:", heap)
```

Output:

```text
Deleted: 5
Heap: [10, 20, 30, 40, 50]
```

Time Complexity: O(log n).

Space Complexity: O(1) auxiliary space.

# 11. Deletion in Max Heap

In a Max Heap, deletion generally means removing the root element, which is the largest value.

### Steps

1. Store the root element.
2. Replace the root with the last element.
3. Remove the last element.
4. Compare the new root with its children.
5. Swap it with the larger child if necessary.
6. Continue until the Max Heap property is restored.

### Python Implementation

```python
def delete_max(heap):

    if len(heap) == 0:
        return None

    if len(heap) == 1:
        return heap.pop()

    maximum = heap[0]

    heap[0] = heap.pop()

    i = 0
    n = len(heap)

    while True:

        left = 2 * i + 1
        right = 2 * i + 2

        largest = i

        if left < n and heap[left] > heap[largest]:
            largest = left

        if right < n and heap[right] > heap[largest]:
            largest = right

        if largest == i:
            break

        heap[i], heap[largest] = heap[largest], heap[i]

        i = largest

    return maximum


heap = [60, 40, 50, 10, 20, 30]

removed = delete_max(heap)

print("Deleted:", removed)
print("Heap:", heap)
```

Output:

```text
Deleted: 60
Heap: [50, 40, 30, 10, 20]
```

Time Complexity: O(log n).

Space Complexity: O(1) auxiliary space.

# 12. Peek Operation

Peek returns the root element without deleting it.

For a Min Heap, peek returns the smallest element.

For a Max Heap, peek returns the largest element.

### Python Code

```python
def peek_min(heap):

    if not heap:
        return None

    return heap[0]


def peek_max(heap):

    if not heap:
        return None

    return heap[0]


min_heap = [10, 20, 30, 40, 50]

max_heap = [50, 40, 30, 10, 20]

print("Minimum:", peek_min(min_heap))
print("Maximum:", peek_max(max_heap))
```

Output:

```text
Minimum: 10
Maximum: 50
```

Time Complexity: O(1).

Space Complexity: O(1).

# 13. Heapify

Heapify is the process of restoring the heap property in a tree or array.

There are two important operations:

- Heapify Up
- Heapify Down

### Heapify Up

Used mainly during insertion.

The newly inserted element moves upward until the heap property is satisfied.

### Heapify Down

Used mainly after deleting the root.

The replacement element moves downward until the heap property is satisfied.

### Difference

| Heapify Up | Heapify Down |
|---|---|
| Moves an element upward | Moves an element downward |
| Compares with parent | Compares with children |
| Used after insertion | Used after root deletion |
| O(log n) | O(log n) |

---

# 14. Build Heap

Build Heap means converting an unordered array into a valid heap.

Example:

```python
arr = [40, 10, 30, 50, 20]
```

We want to convert it into a Min Heap.

The Build Heap algorithm uses bottom-up heapification.

### Important Idea

Start from the last non-leaf node:

```text
Last Non-Leaf Index = (n // 2) - 1
```

Then heapify each node moving backwards to the root.

### Python Implementation – Build Min Heap

```python
def heapify(heap, n, i):

    smallest = i

    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and heap[left] < heap[smallest]:
        smallest = left

    if right < n and heap[right] < heap[smallest]:
        smallest = right

    if smallest != i:

        heap[i], heap[smallest] = heap[smallest], heap[i]

        heapify(heap, n, smallest)


def build_min_heap(arr):

    n = len(arr)

    for i in range(n // 2 - 1, -1, -1):

        heapify(arr, n, i)

    return arr


arr = [40, 10, 30, 50, 20]

print(build_min_heap(arr))
```

Output:

```text
[10, 20, 30, 50, 40]
```

Time Complexity: O(n).

Space Complexity: O(log n) auxiliary recursion stack space for this recursive implementation.

### Why Is Build Heap O(n) Instead of O(n log n)?

Although a single heapify operation can take O(log n), most nodes are close to the leaves and require very little work.

Only a small number of nodes are near the root and can require many swaps.

The total work across all nodes is O(n).

This is a very important interview concept.

# 15. Heap Sort

Heap Sort is a comparison-based sorting algorithm that uses a heap.

For ascending order, we generally use a Max Heap.

### Steps

1. Convert the array into a Max Heap.
2. The largest element will be at the root.
3. Swap the root with the last element.
4. Reduce the heap size by one.
5. Heapify the root again.
6. Repeat until the array is sorted.

### Python Implementation

```python
def heapify(arr, n, i):

    largest = i

    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    if largest != i:

        arr[i], arr[largest] = arr[largest], arr[i]

        heapify(arr, n, largest)


def heap_sort(arr):

    n = len(arr)

    # Build Max Heap
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # Extract maximum elements
    for i in range(n - 1, 0, -1):

        arr[0], arr[i] = arr[i], arr[0]

        heapify(arr, i, 0)

    return arr


numbers = [40, 10, 30, 50, 20]

print(heap_sort(numbers))
```

Output:

```text
[10, 20, 30, 40, 50]
```

### Heap Sort Complexity

| Case | Time Complexity |
|---|---|
| Best | O(n log n) |
| Average | O(n log n) |
| Worst | O(n log n) |

Space Complexity: O(log n) auxiliary recursion stack space for this implementation.

Heap Sort is an in-place sorting algorithm, but this recursive implementation uses additional call-stack memory.

# 16. Python Built-in Heap Module

Python provides a built-in module called `heapq` for heap operations.

It implements a Min Heap.

### Example

```python
import heapq

numbers = [40, 10, 30, 50, 20]

heapq.heapify(numbers)

print(numbers)

print("Smallest:", numbers[0])
```

Output:

```text
[10, 20, 30, 50, 40]
Smallest: 10
```

### Insertion

```python
heapq.heappush(numbers, 5)
```

### Deletion

```python
smallest = heapq.heappop(numbers)

print(smallest)
```

### Max Heap Using heapq

One common technique is to store negative values.

```python
import heapq

numbers = [40, 10, 30, 50, 20]

max_heap = [-x for x in numbers]

heapq.heapify(max_heap)

maximum = -heapq.heappop(max_heap)

print(maximum)
```

Output:

```text
50
```

This technique works for numeric values.

**Interview Tip:** Understand heap operations by implementing them manually before using `heapq`.

# 17. Time and Space Complexity Summary

Let n represent the number of elements.

| Operation | Time Complexity | Auxiliary Space |
|---|---|---|
| Peek | O(1) | O(1) |
| Insert | O(log n) | O(1) iterative |
| Delete Root | O(log n) | O(1) iterative |
| Heapify Up | O(log n) | O(1) iterative |
| Heapify Down | O(log n) | O(1) iterative |
| Build Heap | O(n) | O(1) iterative |
| Heap Sort | O(n log n) | O(1) iterative |

For recursive heapify, auxiliary stack space can be O(log n).

The heap itself requires O(n) storage.

# 18. Heap vs Binary Search Tree

| Feature | Heap | BST |
|---|---|---|
| Structure | Complete Binary Tree | General Binary Tree |
| Ordering | Parent-child ordering | Left-root-right ordering |
| Root | Minimum or maximum | Not necessarily minimum or maximum |
| Search | O(n) generally | O(log n) average |
| Insert | O(log n) | O(log n) average |
| Delete Root | O(log n) | Depends on operation |
| Minimum/Maximum | O(1) for the appropriate heap root | O(h) |
| Common Use | Priority Queues | Searching and ordered data |

Important: A heap does not maintain the entire array in sorted order.

For example, in a Min Heap:

```text
          10
         /  \
        20   30
       /  \
      40   50
```

We know 10 is the smallest, but we cannot directly determine the complete sorted order by simply reading the array.

# 19. Applications of Heaps

1. **Priority Queue:** Process tasks based on priority.
2. **CPU Scheduling:** Select tasks according to priority.
3. **Heap Sort:** Sort elements efficiently.
4. **Dijkstra's Algorithm:** Efficiently select the next closest vertex.
5. **Prim's Algorithm:** Select the minimum-weight edge.
6. **Top K Elements:** Find the K largest or smallest values.
7. **Median of a Stream:** Use two heaps to maintain the median.
8. **Event Scheduling:** Process events based on their scheduled time.

# 20. Common Mistakes

1. Confusing Min Heap and Max Heap.
2. Forgetting that a heap must be a Complete Binary Tree.
3. Assuming a heap array is completely sorted.
4. Using the wrong parent or child index formula.
5. Forgetting to compare both children during heapify down.
6. Removing the root without moving the last element.
7. Forgetting to check array boundaries.
8. Assuming Build Heap takes O(n log n).
9. Confusing heap operations with BST operations.
10. Forgetting to handle empty heaps.
