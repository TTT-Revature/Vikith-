# Union-Find / Disjoint Set Union (DSU)

## 1. What is Union-Find?

**Union-Find**, also known as **Disjoint Set Union (DSU)**, is a data structure used to manage a collection of non-overlapping groups or sets.

It helps us efficiently perform two important operations:

1. **Find:** Determine which group an element belongs to.
2. **Union:** Combine two different groups into one group.

In simple words:

Imagine you have several people. Initially, everyone belongs to their own group.

When two people become friends, their groups are combined.

Union-Find helps us track which people belong to the same group.

### Real-world applications

- Detecting cycles in an undirected graph.
- Finding connected components.
- Kruskal's Minimum Spanning Tree algorithm.
- Network connectivity.
- Grouping friends in social networks.
- Image segmentation.
- Managing connected computer networks.

---

## 2. Understanding Disjoint Sets

A disjoint set is a collection of sets where no element belongs to more than one set.

Initially, suppose we have five elements:

```python
elements = [0, 1, 2, 3, 4]
```

Every element belongs to its own set.

```text
{0}  {1}  {2}  {3}  {4}
```

There are five separate groups.

Now suppose we combine 0 and 1.

```text
{0, 1}  {2}  {3}  {4}
```

Then combine 2 and 3.

```text
{0, 1}  {2, 3}  {4}
```

Then combine the groups containing 1 and 3.

```text
{0, 1, 2, 3}  {4}
```

Now there are only two groups.

This is exactly what Union-Find manages.

---

## 3. The Two Main Operations

### Operation 1: Find

The Find operation identifies the representative (root) of the set containing an element.

Example:

```text
       0
      / \
     1   2
         |
         3
```

Suppose 0 is the root.

Then:

```text
Find(0) = 0
Find(1) = 0
Find(2) = 0
Find(3) = 0
```

All these elements belong to the same set.

### Operation 2: Union

The Union operation combines two different sets.

Suppose:

```text
Set 1: {0, 1}
Set 2: {2, 3}
```

After:

```python
union(0, 2)
```

The groups are combined:

```text
{0, 1, 2, 3}
```

Important: If both elements already belong to the same set, no combination is necessary.

The parent array stores the parent of every element.

# PART 1: BASIC UNION-FIND IMPLEMENTATION

## 5. Implementing Find Operation

The Find operation follows parent pointers until it reaches the root.

A root is an element whose parent is itself.

### Python implementation

```python
def find(parent, x):

    if parent[x] == x:
        return x

    return find(parent, parent[x])
```

### Complete example

```python
parent = [0, 0, 2, 2, 4]

print(find(parent, 0))
print(find(parent, 1))
print(find(parent, 2))
print(find(parent, 3))
print(find(parent, 4))
```

Output:

```text
0
0
2
2
4
```

### Understanding the code

```python
if parent[x] == x:
    return x
```

If the element is its own parent, it is the root.

Otherwise:

```python
return find(parent, parent[x])
```

We move to its parent and continue searching.

### Example: Find(1)

Parent array:

```python
parent = [0, 0, 2, 2, 4]
```

Check:

```text
parent[1] = 0
parent[0] = 0
```

Since 0 is its own parent:

```text
Find(1) = 0
```

Therefore, 1 belongs to the group represented by 0.

## 6. Implementing Union Operation

The Union operation combines two sets.

Steps:

1. Find the root of the first element.
2. Find the root of the second element.
3. If both roots are equal, they are already in the same set.
4. Otherwise, make one root the parent of the other.

### Python implementation

```python
def union(parent, x, y):

    root_x = find(parent, x)

    root_y = find(parent, y)

    if root_x != root_y:

        parent[root_y] = root_x
```

### Complete example

```python
def find(parent, x):

    if parent[x] == x:
        return x

    return find(parent, parent[x])


def union(parent, x, y):

    root_x = find(parent, x)

    root_y = find(parent, y)

    if root_x != root_y:

        parent[root_y] = root_x


parent = [0, 1, 2, 3, 4]

union(parent, 0, 1)
union(parent, 2, 3)

print(parent)
```

Output:

```text
[0, 0, 2, 2, 4]
```

Visual representation:

```text
0      2      4
|      |
1      3
```

### Combining two existing groups

```python
union(parent, 1, 3)

print(parent)
```

Output:

```text
[0, 0, 0, 2, 4]
```

Visual representation:

```text
      0      4
     / \
    1   2
        |
        3
```

Why?

- Find(1) returns 0.
- Find(3) returns 2.
- The root of 2 is attached to 0.

Now all four elements belong to the same group.

# PART 2: OPTIMIZING UNION-FIND

## 7. Why Do We Need Optimization?

The basic implementation works, but it can create a very deep tree.

Example:

```text
0
|
1
|
2
|
3
|
4
```

To find the root of 4, we must travel through:

```text
4 → 3 → 2 → 1 → 0
```

This takes O(n) time in the worst case.

We can improve performance using two important techniques:

1. Path Compression.
2. Union by Rank or Union by Size.

---

## 8. Path Compression

Path Compression is an optimization used in the Find operation.

It makes every visited node point directly to the root.

### Before path compression

```text
0
|
1
|
2
|
3
|
4
```

To find the root of 4, we travel through all the parent nodes.

### After path compression

```text
    0
  / | \
 1  2  3
    |
    4
```

Now the nodes visited during the Find operation point directly to the root.

### Python implementation

```python
def find(parent, x):

    if parent[x] != x:

        parent[x] = find(parent, parent[x])

    return parent[x]
```

### Understanding the important line

```python
parent[x] = find(parent, parent[x])
```

This recursively finds the root and updates the current node's parent to that root.

### Example

```python
parent = [0, 0, 1, 2, 3]
```

Tree:

```text
0
|
1
|
2
|
3
|
4
```

Now execute:

```python
print(find(parent, 4))
```

Output:

```text
0
```

Parent array after path compression:

```python
[0, 0, 0, 0, 0]
```

All elements now point directly to 0.

---

## 9. Union by Rank

Union by Rank is another optimization.

Instead of attaching one root randomly to another, we attach the smaller-rank tree below the larger-rank tree.

This helps keep the tree relatively shallow.

### What is Rank?

Rank is an upper-bound estimate of the tree's height.

Initially, every element has rank zero.

```python
rank = [0, 0, 0, 0, 0]
```

### Rules of Union by Rank

**Case 1: Different ranks**

Attach the root with the smaller rank below the root with the larger rank.

Example:

```text
Tree A:       Tree B:

  0             2
  |             |
  1             3
```

If the rank of 0 is larger, attach 2 below 0.

```text
      0
     / \
    1   2
        |
        3
```

**Case 2: Equal ranks**

If both roots have equal rank, attach one below the other and increase the rank of the new root by one.

### Python implementation

```python
def union(parent, rank, x, y):

    root_x = find(parent, x)

    root_y = find(parent, y)

    if root_x == root_y:
        return

    if rank[root_x] < rank[root_y]:

        parent[root_x] = root_y

    elif rank[root_x] > rank[root_y]:

        parent[root_y] = root_x

    else:

        parent[root_y] = root_x

        rank[root_x] += 1
```

## 10. Union by Size

Another alternative is Union by Size.

Instead of comparing ranks, we maintain the number of elements in each set.

Initially:

```python
size = [1, 1, 1, 1, 1]
```

Every element starts with a set size of 1.

### Rules

1. Find the root of both elements.
2. Compare the sizes of the two sets.
3. Attach the smaller set below the larger set.
4. Update the size of the new root.

### Implementation

```python
def union(parent, size, x, y):

    root_x = find(parent, x)

    root_y = find(parent, y)

    if root_x == root_y:
        return

    if size[root_x] < size[root_y]:

        parent[root_x] = root_y

        size[root_y] += size[root_x]

    else:

        parent[root_y] = root_x

        size[root_x] += size[root_y]
```

### Example

Suppose:

```text
Set 1: {0, 1, 2}
Set 2: {3, 4}
```

Sizes:

```text
Size of Set 1 = 3
Size of Set 2 = 2
```

When combining these sets, attach the smaller set below the larger set.

The resulting set is:

```text
{0, 1, 2, 3, 4}
```

New size:

```text
5
```

**Important:** When using size, only the root's size is meaningful. Sizes stored at non-root elements can be ignored.

## 11. Complete Optimized Union-Find Implementation

Now let's combine:

- Parent array.
- Rank array.
- Path compression.
- Union by rank.

```python
class DisjointSet:

    def __init__(self, n):

        self.parent = list(range(n))

        self.rank = [0] * n

    def find(self, x):

        if self.parent[x] != x:

            self.parent[x] = self.find(self.parent[x])

        return self.parent[x]

    def union(self, x, y):

        root_x = self.find(x)

        root_y = self.find(y)

        if root_x == root_y:

            return False

        if self.rank[root_x] < self.rank[root_y]:

            self.parent[root_x] = root_y

        elif self.rank[root_x] > self.rank[root_y]:

            self.parent[root_y] = root_x

        else:

            self.parent[root_y] = root_x

            self.rank[root_x] += 1

        return True

    def connected(self, x, y):

        return self.find(x) == self.find(y)


dsu = DisjointSet(5)

dsu.union(0, 1)
dsu.union(2, 3)
dsu.union(1, 3)

print(dsu.connected(0, 3))
print(dsu.connected(0, 4))
print(dsu.parent)
```

Output:

```text
True
False
[0, 0, 0, 2, 4]
```

### Explanation

```python
dsu = DisjointSet(5)
```

Creates five independent sets.

```python
dsu.union(0, 1)
```

Combines 0 and 1.

```python
dsu.union(2, 3)
```

Combines 2 and 3.

```python
dsu.union(1, 3)
```

Combines the groups containing 1 and 3.

Now:

```text
{0, 1, 2, 3}  {4}
```

Check:

```python
dsu.connected(0, 3)
```

Returns True because both belong to the same group.

```python
dsu.connected(0, 4)
```

Returns False because they belong to different groups.

# PART 3: UNION-FIND APPLICATIONS

## 12. Application 1 – Detect a Cycle in an Undirected Graph

Union-Find is commonly used to detect cycles in an undirected graph.

### Main idea

For every edge `(u, v)`:

1. Find the root of u.
2. Find the root of v.
3. If both roots are equal, a cycle exists.
4. Otherwise, combine the two sets.

### Example without a cycle

```text
0 ---- 1

2 ---- 3
```

Edges:

```python
edges = [
    (0, 1),
    (2, 3)
]
```

No cycle exists.

### Example with a cycle

```text
0 ---- 1
|      |
|      |
3 ---- 2
```

Edges:

```python
edges = [
    (0, 1),
    (1, 2),
    (2, 3),
    (3, 0)
]
```

When processing edge `(3, 0)`, both vertices already belong to the same set.

Therefore, a cycle exists.

### Implementation

```python
def has_cycle(n, edges):

    dsu = DisjointSet(n)

    for u, v in edges:

        if not dsu.union(u, v):

            return True

    return False


edges = [
    (0, 1),
    (1, 2),
    (2, 3),
    (3, 0)
]

print(has_cycle(4, edges))
```

Output:

```text
True
```

### Explanation

```python
if not dsu.union(u, v):
    return True
```

The `union()` method returns False if both vertices already belong to the same set.

That means adding the edge would create a cycle.

**Note:** This cycle-detection implementation assumes a simple undirected graph without self-loops or duplicate edges.

## 13. Application 2 – Count Connected Components

A connected component is a group of vertices where every vertex is reachable from every other vertex in that group.

Example:

```text
0 ---- 1

2 ---- 3

4
```

There are three connected components.

Using Union-Find, we can count the number of sets.

### Implementation

```python
def count_components(n, edges):

    dsu = DisjointSet(n)

    components = n

    for u, v in edges:

        if dsu.union(u, v):

            components -= 1

    return components


edges = [
    (0, 1),
    (2, 3)
]

print(count_components(5, edges))
```

Output:

```text
3
```

### Explanation

Initially:

```text
{0} {1} {2} {3} {4}
```

Number of components:

```text
5
```

After union(0, 1):

```text
{0
