# Hash Sets and Maps in Python

## 1. Introduction

Hash Sets and Hash Maps are important data structures used to store and manage data efficiently.

Both use hashing internally to provide fast insertion, deletion, and searching.

There are two major data structures:

1. **Hash Set:** Stores unique elements.
2. **Hash Map:** Stores data in key-value pairs.

In Python:

- `set` is used to implement a hash set.
- `dict` is used to implement a hash map.

---

# PART 1: HASH SETS

## 2. What Is a Hash Set?

A Hash Set is a data structure that stores only unique elements.

It does not allow duplicate values.

It uses a hash function to determine where elements should be stored.

### Example

```python
numbers = {10, 20, 30, 40, 10}

print(numbers)
```

**Output:**
```text
{10, 20, 30, 40}
```

Notice that 10 appears only once.

### Important Characteristics

- Stores unique elements.
- Does not store key-value pairs.
- Does not allow duplicate elements.
- Uses hashing internally.
- Provides average O(1) insertion, deletion, and membership checking.
- Sets are mutable, but their elements must be hashable.

**Note:** Python sets do not guarantee insertion order.

---

## 3. How Does a Hash Set Work?

A hash set uses a hash function to calculate the position of an element.

When an element is inserted:

1. The element is passed to a hash function.
2. The hash function generates a hash value.
3. The hash table determines the appropriate position.
4. If the element already exists, it is not inserted again.
5. If the element does not exist, it is inserted.

### Example

```python
numbers = {10, 20, 30}

numbers.add(40)

print(numbers)
```

**Output:**
```text
{10, 20, 30, 40}
```

If we try to insert 20 again:

```python
numbers.add(20)

print(numbers)
```

The set remains unchanged because 20 already exists.

## 5. Set Mathematical Operations

Python sets support mathematical operations such as union, intersection, difference, and symmetric difference.

Consider:

```python
A = {10, 20, 30, 40}
B = {30, 40, 50, 60}
```

### 5.1 Union

Union combines all unique elements from both sets.

Operator: `|`

```python
A = {10, 20, 30, 40}
B = {30, 40, 50, 60}

print(A | B)
```

Output:
```text
{10, 20, 30, 40, 50, 60}
```

### 5.2 Intersection

Intersection returns elements that are common to both sets.

Operator: `&`

```python
print(A & B)
```

Output:
```text
{30, 40}
```

### 5.3 Difference

Difference returns elements that exist in the first set but not in the second.

Operator: `-`

```python
print(A - B)
```

Output:
```text
{10, 20}
```

### 5.4 Symmetric Difference

Returns elements that exist in either set but not in both.

Operator: `^`

```python
print(A ^ B)
```

Output:
```text
{10, 20, 50, 60}
```

### 5.5 Subset

A set A is a subset of B if all elements of A exist in B.

```python
A = {10, 20}
B = {10, 20, 30, 40}

print(A.issubset(B))
```

Output:
```text
True
```

### 5.6 Superset

A set A is a superset of B if A contains all elements of B.

```python
A = {10, 20, 30, 40}
B = {10, 20}

print(A.issuperset(B))
```

Output:
```text
True
```

# PART 2: HASH MAPS

## 6. What Is a Hash Map?

A Hash Map is a data structure that stores information in key-value pairs.

Each key is associated with a value.

A hash function calculates the hash of the key to determine where the corresponding data should be stored.

In Python, dictionaries (`dict`) are used as hash maps.

### Example

```python
student = {
    "name": "Rahul",
    "age": 22,
    "course": "MCA"
}

print(student["name"])
```

Output:
```text
Rahul
```

Here:

| Key | Value |
|---|---|
| name | Rahul |
| age | 22 |
| course | MCA |

### Important Characteristics

- Stores key-value pairs.
- Keys must be unique.
- Values can be duplicated.
- Keys must be hashable.
- Values can be mutable or immutable.
- Provides average O(1) lookup, insertion, and deletion.
- Python dictionaries preserve insertion order.

---

## 7. How Does a Hash Map Work?

A hash map uses a hash function to locate the position of a key-value pair.

Consider:

```python
student = {
    "name": "Rahul"
}
```

When we execute:

```python
print(student["name"])
```

The internal process is conceptually:

1. Python receives the key `"name"`.
2. It calculates the hash of the key.
3. It uses the hash to locate a candidate position.
4. It checks the key to ensure it matches.
5. It retrieves the corresponding value.

**Important:** Hashing determines the location, but key equality checks ensure that the correct key is found even when collisions occur.

## 9. Difference Between Hash Sets and Hash Maps

| Feature | Hash Set | Hash Map |
|---|---|---|
| Storage | Individual elements | Key-value pairs |
| Duplicates | Not allowed | Keys cannot be duplicated |
| Values | Elements themselves | Associated values |
| Searching | By element | By key |
| Python | `set` | `dict` |
| Average Lookup | O(1) | O(1) |
| Ordering | No insertion-order guarantee | Insertion order preserved |

### Example

Hash Set:

```python
numbers = {10, 20, 30}
```

Hash Map:

```python
student = {
    "name": "Rahul",
    "age": 22
}
```

Use a set when you only need to store unique elements.

Use a dictionary when you need to associate one piece of information with another.

# PART 3: PRACTICAL DSA PROBLEMS

## 12. Problem 1: Contains Duplicate

**Question:**

Given an integer array, return `True` if any value appears more than once. Otherwise, return `False`.

Input:

```python
numbers = [1, 2, 3, 1]
```

Expected Output:

```text
True
```

### Solution Using Hash Set

```python
def contains_duplicate(numbers):

    seen = set()

    for num in numbers:

        if num in seen:
            return True

        seen.add(num)

    return False


numbers = [1, 2, 3, 1]

print(contains_duplicate(numbers))
```

**Explanation:**

- Create an empty set.
- Check whether each number already exists.
- If it exists, a duplicate is found.
- Otherwise, insert it into the set.

Time Complexity: O(n) average.

Space Complexity: O(n).

---

## 13. Problem 2: Two Sum

**Question:**

Given an array and a target value, find the indices of two numbers whose sum equals the target.

Input:

```python
numbers = [2, 7, 11, 15]
target = 9
```

Expected Output:

```text
[0, 1]
```

### Solution Using Hash Map

```python
def two_sum(numbers, target):

    seen = {}

    for i, num in enumerate(numbers):

        complement = target - num

        if complement in seen:
            return [seen[complement], i]

        seen[num] = i

    return []


numbers = [2, 7, 11, 15]
target = 9

print(two_sum(numbers, target))
```

**Explanation:**

- Create an empty dictionary.
- Calculate the complement of the current number.
- Check whether the complement already exists.
- If it exists, return both indices.
- Otherwise, store the current number and its index.

Time Complexity: O(n) average.

Space Complexity: O(n).

## 14. Problem 3: Valid Anagram

**Question:**

Given two strings, determine whether one string is an anagram of the other.

An anagram contains exactly the same characters with the same frequencies, but possibly in a different order.

Input:

```python
s = "listen"
t = "silent"
```

Expected Output:

```text
True
```

### Solution Using Hash Map

```python
def is_anagram(s, t):

    if len(s) != len(t):
        return False

    frequency = {}

    for char in s:
        frequency[char] = frequency.get(char, 0) + 1

    for char in t:

        if char not in frequency:
            return False

        frequency[char] -= 1

        if frequency[char] < 0:
            return False

    return True


print(is_anagram("listen", "silent"))
```

Time Complexity: O(n) average.

Space Complexity: O(k), where k is the number of distinct characters.

## 15. Problem 4: Find the First Repeating Element

**Question:**

Given an array, find the first element that appears more than once while scanning from left to right.

Input:

```python
numbers = [10, 20, 30, 20, 40, 10]
```

Expected Output:

```text
20
```

### Solution

```python
def first_repeating(numbers):

    seen = set()

    for num in numbers:

        if num in seen:
            return num

        seen.add(num)

    return None


numbers = [10, 20, 30, 20, 40, 10]

print(first_repeating(numbers))
```

Time Complexity: O(n) average.

Space Complexity: O(n).

## 16. Problem 5: Frequency Counter

**Question:**

Count how many times each element appears in an array.

Input:

```python
numbers = [1, 2, 2, 3, 1, 1, 4]
```

Expected Output:

```text
{1: 3, 2: 2, 3: 1, 4: 1}
```

### Solution

```python
def frequency_counter(numbers):

    frequency = {}

    for num in numbers:

        frequency[num] = frequency.get(num, 0) + 1

    return frequency


numbers = [1, 2, 2, 3, 1, 1, 4]

print(frequency_counter(numbers))
```

Time Complexity: O(n) average.

Space Complexity: O(k), where k is the number of distinct elements.

# PART 5: IMPORTANT CONCEPTS

## 19. Hashable Objects

An object is hashable if it has a hash value that remains stable during its lifetime and supports equality comparisons consistently.

Hashable objects can be used as:

- Set elements.
- Dictionary keys.

Examples:

```python
numbers = {10, 20, 30}

student = {
    "name": "Rahul",
    101: "MCA"
}
```

Lists cannot be used as set elements or dictionary keys because they are mutable and unhashable.

```python
# Invalid
numbers = {[1, 2, 3]}
```

This raises:

```text
TypeError: unhashable type: 'list'
```

Tuples containing only hashable elements can be used as dictionary keys.

```python
coordinates = {
    (10, 20): "Point A",
    (30, 40): "Point B"
}
```

## 20. Hashing and Equality

Python uses both hashing and equality checks when working with sets and dictionaries.

Two important methods are:

- `__hash__()`
- `__eq__()`

Important rules:

1. If two objects are equal, they must have the same hash value.
2. Two objects with the same hash value are not necessarily equal.
3. Hash collisions are resolved using equality checks.

Example:

```python
a = "Python"
b = "Python"

print(hash(a) == hash(b))
print(a == b)
```

Output:

```text
True
True
```

# 24. Key Points to Remember

- A Hash Set stores unique elements.
- A Hash Map stores key-value pairs.
- Python uses `set` for Hash Sets.
- Python uses `dict` for Hash Maps.
- Both use hashing internally.
- Hash Set does not support indexing.
- Dictionary keys must be unique and hashable.
- Set elements must be hashable.
- Both provide O(1) average lookup.
- Both can experience hash collisions.
- Sets are useful for duplicate detection.
- Dictionaries are useful for frequency counting and fast key-based lookups.

**Most Important Interview Concept:**

Use a Hash Set when you need to check whether an element exists or detect duplicates.

Use a Hash Map when you need to associate values with keys, count frequencies, or remember additional information such as indexes.

Both are essential for solving efficient DSA problems in Python.
