# Divide and Conquer in Python – DSA Notes

## 1. What is Divide and Conquer?

**Divide and Conquer** is an algorithm design technique in which we divide a large problem into smaller subproblems, solve those subproblems, and combine their results to obtain the final answer.

In simple words:

1. **Divide:** Break the original problem into smaller subproblems.
2. **Conquer:** Solve each smaller problem, usually using recursion.
3. **Combine:** Combine the results to get the final solution.

### Real-Life Example

Imagine you have 100 documents and need to sort them alphabetically.

Instead of sorting all 100 documents at once:

- Divide them into smaller groups.
- Sort each group separately.
- Combine the sorted groups.

This makes a large problem easier to manage.

### Divide and Conquer Structure

```text
                  Original Problem
                         |
                       Divide
                    /         \
             Subproblem 1   Subproblem 2
                 |               |
               Solve           Solve
                 |               |
                 +-------+-------+
                         |
                       Combine
                         |
                   Final Solution
```

---

## 2. Three Main Steps of Divide and Conquer

### Step 1: Divide

Break the original problem into smaller subproblems.

Example:

```python
arr = [8, 4, 2, 9, 1, 5]
```

Divide:

```text
[8, 4, 2]       [9, 1, 5]
```

Divide again:

```text
[8] [4, 2]      [9] [1, 5]
```

Continue until the subproblems are small enough to solve directly.

### Step 2: Conquer

Solve each smaller subproblem.

For example:

```text
[8] [4] [2] [9] [1] [5]
```

A single-element array is already sorted.

### Step 3: Combine

Combine the smaller solutions into a final solution.

```text
[4] + [2]       → [2, 4]
[1] + [5]       → [1, 5]

[8] + [2, 4]    → [2, 4, 8]
[9] + [1, 5]    → [1, 5, 9]

[2, 4, 8] + [1, 5, 9]
                → [1, 2, 4, 5, 8, 9]
```

Final output:

```python
[1, 2, 4, 5, 8, 9]
```

# 3. Understanding Recursion in Divide and Conquer

Divide and Conquer commonly uses recursion.

A recursive function calls itself to solve smaller versions of the same problem.

### Example: Find the Sum of an Array

```python
def array_sum(arr):

    if len(arr) == 0:
        return 0

    if len(arr) == 1:
        return arr[0]

    mid = len(arr) // 2

    left_sum = array_sum(arr[:mid])
    right_sum = array_sum(arr[mid:])

    return left_sum + right_sum


arr = [1, 2, 3, 4, 5]

print(array_sum(arr))
```

Output:

```text
15
```

### Explanation

Original array:

```text
[1, 2, 3, 4, 5]
```

Divide:

```text
Left:  [1, 2]
Right: [3, 4, 5]
```

Divide further:

```text
[1] [2]       [3] [4, 5]
```

Solve:

```text
1 + 2 = 3
3 + (4 + 5) = 12
```

Combine:

```text
3 + 12 = 15
```

**Complexity:**

- Time: O(n)
- Auxiliary space: O(n) for recursive calls and the array slices used by this implementation.

Note: Python slicing creates new lists. More memory-efficient implementations can use index boundaries instead.

# 5. Merge Sort

## What is Merge Sort?

Merge Sort is a sorting algorithm based on Divide and Conquer.

It divides an array into two halves, recursively sorts both halves, and merges them into one sorted array.

### Example

Input:

```python
arr = [8, 4, 2, 9, 1, 5]
```

### Step 1: Divide

```text
              [8, 4, 2, 9, 1, 5]
                    /      \
              [8, 4, 2]   [9, 1, 5]
               /    \       /    \
            [8]   [4, 2]  [9]   [1, 5]
                   / \           / \
                 [4] [2]       [1] [5]
```

Continue until every subarray contains one element.

### Step 2: Conquer and Combine

Merge the sorted subarrays:

```text
[4] + [2] = [2, 4]

[1] + [5] = [1, 5]

[8] + [2, 4] = [2, 4, 8]

[9] + [1, 5] = [1, 5, 9]
```

Final merge:

```text
[2, 4, 8] + [1, 5, 9]

= [1, 2, 4, 5, 8, 9]
```

### Python Implementation

```python
def merge_sort(arr):

    if len(arr) <= 1:
        return arr

    # Divide
    mid = len(arr) // 2

    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    # Combine
    return merge(left, right)


def merge(left, right):

    result = []

    i = 0
    j = 0

    while i < len(left) and j < len(right):

        if left[i] <= right[j]:

            result.append(left[i])
            i += 1

        else:

            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])

    return result


arr = [8, 4, 2, 9, 1, 5]

print(merge_sort(arr))
```

Output:

```text
[1, 2, 4, 5, 8, 9]
```

### Understanding the Merge Function

Suppose:

```python
left = [2, 4, 8]
right = [1, 5, 9]
```

We compare the first available elements.

| Left | Right | Selected |
|---:|---:|---:|
| 2 | 1 | 1 |
| 2 | 5 | 2 |
| 4 | 5 | 4 |
| 8 | 5 | 5 |
| 8 | 9 | 8 |
| Remaining | 9 | 9 |

Result:

```text
[1, 2, 4, 5, 8, 9]
```

### Merge Sort Complexity

| Case | Time Complexity |
|---|---|
| Best | O(n log n) |
| Average | O(n log n) |
| Worst | O(n log n) |

Space Complexity:

- O(n) auxiliary space for a typical array-based implementation.
- Recursive stack depth: O(log n).

**Important:** Merge Sort is stable when equal elements are taken from the left half first, as in the implementation above.

# 6. Quick Sort

## What is Quick Sort?

Quick Sort is another sorting algorithm based on Divide and Conquer.

It selects an element called a **pivot**, partitions the array around that pivot, and recursively sorts the resulting sections.

### What is a Pivot?

A pivot is the element used to divide the array.

For example:

```python
arr = [8, 4, 2, 9, 1, 5]
```

Choose the last element as the pivot:

```text
Pivot = 5
```

Partition the array so that:

- Elements less than or equal to the pivot go to the left.
- Elements greater than the pivot go to the right.

One possible partition result:

```text
[4, 2, 1]  5  [8, 9]
```

The pivot is now in its correct sorted position.

Then recursively sort the left and right sections.

### Python Implementation

```python
def quick_sort(arr):

    if len(arr) <= 1:
        return arr

    pivot = arr[-1]

    left = []
    right = []

    for element in arr[:-1]:

        if element <= pivot:
            left.append(element)

        else:
            right.append(element)

    return quick_sort(left) + [pivot] + quick_sort(right)


arr = [8, 4, 2, 9, 1, 5]

print(quick_sort(arr))
```

Output:

```text
[1, 2, 4, 5, 8, 9]
```

### Quick Sort Complexity

| Case | Time Complexity |
|---|---|
| Best | O(n log n) |
| Average | O(n log n) |
| Worst | O(n²) |

Why can the worst case be O(n²)?

If the pivot repeatedly produces highly unbalanced partitions, such as one element on one side and all remaining elements on the other, the algorithm performs many comparisons.

Space Complexity:

- O(log n) average recursive stack depth for balanced partitions.
- O(n) worst-case recursive stack depth.
- The Python implementation above also creates additional lists, so its total auxiliary memory can be larger.

**Note:** This is a simple educational implementation. In-place partitioning versions reduce additional array allocations.

# 7. Binary Search

## What is Binary Search?

Binary Search is an efficient searching algorithm that repeatedly divides a sorted search range into two halves.

At each step:

1. Find the middle element.
2. Compare it with the target.
3. If equal, return its index.
4. If the target is smaller, search the left half.
5. If the target is larger, search the right half.

**Important:** Standard Binary Search requires sorted data or another structure that supports the same monotonic decision process.

### Example

Input:

```python
arr = [2, 4, 6, 8, 10, 12, 14]
target = 10
```

Initial search range:

```text
[2, 4, 6, 8, 10, 12, 14]
```

Middle element:

```text
8
```

Since:

```text
10 > 8
```

Search the right half:

```text
[10, 12, 14]
```

Middle element:

```text
12
```

Since:

```text
10 < 12
```

Search the left half:

```text
[10]
```

Target found at index `4`.

### Recursive Python Implementation

```python
def binary_search(arr, target, left, right):

    if left > right:
        return -1

    mid = (left + right) // 2

    if arr[mid] == target:
        return mid

    elif target < arr[mid]:
        return binary_search(arr, target, left, mid - 1)

    else:
        return binary_search(arr, target, mid + 1, right)


arr = [2, 4, 6, 8, 10, 12, 14]
target = 10

result = binary_search(arr, target, 0, len(arr) - 1)

print(result)
```

Output:

```text
4
```

### Binary Search Complexity

| Case | Time Complexity |
|---|---|
| Best | O(1) |
| Average | O(log n) |
| Worst | O(log n) |

Space Complexity:

- Recursive implementation: O(log n) stack space.
- Iterative implementation: O(1) auxiliary space.

# 8. Divide and Conquer vs Greedy vs Backtracking

These are three important algorithmic techniques.

| Feature | Divide and Conquer | Greedy | Backtracking |
|---|---|---|---|
| Main idea | Divide into smaller problems | Make locally best choices | Explore different choices |
| Recursion | Commonly used | Optional | Commonly used |
| Undo decisions | Usually not needed | Usually not needed | Often required |
| Search strategy | Solve subproblems | Select a choice | Explore possible paths |
| Example | Merge Sort | Activity Selection | N-Queens |

### Simple Understanding

**Divide and Conquer:**

Break a large problem into smaller problems.

**Greedy:**

Choose the best available option at each step.

**Backtracking:**

Try a choice, explore it, and undo it to try another choice.

# 9. Recurrence Relations in Divide and Conquer

A recurrence relation describes the running time of a recursive algorithm.

A common form is:

\[
T(n) = aT(n/b) + f(n)
\]

Where:

- `a` = Number of subproblems.
- `n/b` = Size of each subproblem.
- `f(n)` = Work performed outside recursive calls.

### Example 1: Merge Sort

Merge Sort divides an array into two halves.

It makes two recursive calls and performs O(n) work to merge the results.

\[
T(n) = 2T(n/2) + O(n)
\]

Result:

\[
T(n) = O(n\log n)
\]

### Example 2: Binary Search

Binary Search divides the search range into two halves but explores only one half.

\[
T(n) = T(n/2) + O(1)
\]

Result:

\[
T(n) = O(\log n)
\]

### Example 3: Simple Recursive Sum

If we divide an array into two halves, solve both halves, and combine their sums in constant time:

\[
T(n) = 2T(n/2) + O(1)
\]

Result:

\[
T(n) = O(n)
\]

# 10. Master Theorem

The Master Theorem helps us solve many recurrence relations of the form:

\[
T(n) = aT(n/b) + O(n^d)
\]

Compare:

\[
n^{\log_b a}
\]

with:

\[
n^d
\]

There are three common cases.

### Case 1

If:

\[
d < \log_b a
\]

Then:

\[
T(n) = \Theta(n^{\log_b a})
\]

Example:

\[
T(n) = 4T(n/2) + O(n)
\]

Here:

```text
a = 4
b = 2
d = 1
```

Since:

\[
\log_2 4 = 2
\]

And:

\[
1 < 2
\]

Therefore:

\[
T(n) = \Theta(n^2)
\]

### Case 2

If:

\[
d = \log_b a
\]

Then:

\[
T(n) = \Theta(n^d \log n)
\]

Example:

\[
T(n) = 2T(n/2) + O(n)
\]

Therefore:

\[
T(n) = \Theta(n\log n)
\]

This is the recurrence for Merge Sort.

### Case 3

If:

\[
d > \log_b a
\]

Then, under the regularity condition:

\[
T(n) = \Theta(n^d)
\]

Example:

\[
T(n) = 2T(n/2) + O(n^2)
\]

Therefore:

\[
T(n) = \Theta(n^2)
\]

**Note:** The basic Master Theorem does not apply to every recurrence. More advanced forms or other methods may be needed for unequal subproblems or non-polynomial functions.
