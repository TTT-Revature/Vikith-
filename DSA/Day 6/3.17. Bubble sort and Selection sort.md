**# Bubble Sort and Selection Sort

# Part 1: Bubble Sort

## 1. What is Bubble Sort?

**Bubble Sort** is a simple sorting algorithm that repeatedly compares two adjacent elements and swaps them if they are in the wrong order.

This process continues until the entire array is sorted.

**Key Idea:** The largest element gradually moves towards the end of the array after each pass.

### Example

```python
arr = [5, 3, 8, 4, 2]
```

We want to sort the array in ascending order.

```text
Initial:  [5, 3, 8, 4, 2]

Pass 1:   [3, 5, 4, 2, 8]
Pass 2:   [3, 4, 2, 5, 8]
Pass 3:   [3, 2, 4, 5, 8]
Pass 4:   [2, 3, 4, 5, 8]

Sorted:   [2, 3, 4, 5, 8]
```

## 2. How Bubble Sort Works

1. Start from the first element.
2. Compare the current element with the next element.
3. If the current element is greater, swap them.
4. Move to the next pair.
5. Continue until the end of the unsorted portion.
6. Repeat the process until the array is sorted.

## 3. Bubble Sort Implementation in Python

```python
def bubble_sort(arr):

    n = len(arr)

    for i in range(n):

        for j in range(0, n - i - 1):

            if arr[j] > arr[j + 1]:

                arr[j], arr[j + 1] = arr[j + 1], arr[j]

    return arr


numbers = [5, 3, 8, 4, 2]

print(bubble_sort(numbers))
```

**Output:**

```text
[2, 3, 4, 5, 8]
```

## 4. Understanding the Code

### Step 1: Find the array length

```python
n = len(arr)
```

Stores the total number of elements.

### Step 2: Outer loop

```python
for i in range(n):
```

Controls how many passes are performed.

### Step 3: Inner loop

```python
for j in range(0, n - i - 1):
```

Compares adjacent elements.

Why `n - i - 1`?

- After every pass, the largest remaining element reaches its correct position at the end.
- Therefore, we don't need to compare the already sorted elements again.
- `-1` ensures that `arr[j + 1]` stays within the array.

### Step 4: Compare and swap

```python
if arr[j] > arr[j + 1]:

    arr[j], arr[j + 1] = arr[j + 1], arr[j]
```

If the left element is greater than the right element, their positions are exchanged.

## 5. Bubble Sort Dry Run

Consider:

```python
arr = [5, 3, 8, 4, 2]
```

### Pass 1

| Comparison | Condition | Result |
|---|---|---|
| 5 and 3 | 5 > 3 | Swap |
| 5 and 8 | 5 > 8 | No swap |
| 8 and 4 | 8 > 4 | Swap |
| 8 and 2 | 8 > 2 | Swap |

After Pass 1:

```text
[3, 5, 4, 2, 8]
```

Largest element `8` reaches the last position.

### Pass 2

```text
[3, 5, 4, 2, 8]
    Compare 5 and 4 -> Swap
    Compare 5 and 2 -> Swap

Result: [3, 4, 2, 5, 8]
```

### Pass 3

```text
[3, 4, 2, 5, 8]
    Compare 3 and 4 -> No swap
    Compare 4 and 2 -> Swap

Result: [3, 2, 4, 5, 8]
```

### Pass 4

```text
[3, 2, 4, 5, 8]
    Compare 3 and 2 -> Swap

Result: [2, 3, 4, 5, 8]
```

The array is now sorted.

## 6. Optimized Bubble Sort

The basic Bubble Sort performs all passes even when the array is already sorted.

We can optimize it using a Boolean variable called `swapped`.

If no swaps happen during a complete pass, the array is already sorted, so we can stop early.

```python
def bubble_sort(arr):

    n = len(arr)

    for i in range(n):

        swapped = False

        for j in range(0, n - i - 1):

            if arr[j] > arr[j + 1]:

                arr[j], arr[j + 1] = arr[j + 1], arr[j]

                swapped = True

        if not swapped:
            break

    return arr


numbers = [1, 2, 3, 4, 5]

print(bubble_sort(numbers))
```

**Output:**

```text
[1, 2, 3, 4, 5]
```

Since the array is already sorted, the algorithm stops after the first pass.

## 7. Bubble Sort Complexity

| Case | Time Complexity | Explanation |
|---|---|---|
| Best Case (Optimized) | O(n) | Array is already sorted |
| Average Case | O(n²) | Multiple comparisons and swaps |
| Worst Case | O(n²) | Array is sorted in reverse order |

**Space Complexity:** O(1)

Bubble Sort sorts the array in place and uses constant additional space.

### Properties

- Stable: Yes, when equal elements are not swapped.
- In-place: Yes.
- Adaptive: Yes, with the optimized version.
- Comparison-based: Yes.

# Part 2: Selection Sort

## 8. What is Selection Sort?

**Selection Sort** is a sorting algorithm that repeatedly finds the smallest element from the unsorted portion of the array and places it at the beginning of that portion.

**Key Idea:** Find the minimum element and move it to its correct position.

### Example

```python
arr = [5, 3, 8, 4, 2]
```

We want to sort the array in ascending order.

```text
Initial:  [5, 3, 8, 4, 2]

Pass 1:   [2, 3, 8, 4, 5]
Pass 2:   [2, 3, 8, 4, 5]
Pass 3:   [2, 3, 4, 8, 5]
Pass 4:   [2, 3, 4, 5, 8]

Sorted:   [2, 3, 4, 5, 8]
```

## 9. How Selection Sort Works

1. Start from the first element.
2. Assume the current element is the minimum.
3. Search the remaining unsorted elements.
4. Find the smallest element.
5. Swap it with the first element of the unsorted portion.
6. Move to the next position.
7. Repeat until the array is sorted.

## 10. Selection Sort Implementation in Python

```python
def selection_sort(arr):

    n = len(arr)

    for i in range(n):

        min_index = i

        for j in range(i + 1, n):

            if arr[j] < arr[min_index]:

                min_index = j

        arr[i], arr[min_index] = arr[min_index], arr[i]

    return arr


numbers = [5, 3, 8, 4, 2]

print(selection_sort(numbers))
```

**Output:**

```text
[2, 3, 4, 5, 8]
```

## 11. Understanding the Code

### Step 1: Find array length

```python
n = len(arr)
```

Stores the total number of elements.

### Step 2: Outer loop

```python
for i in range(n):
```

Represents the position where the next smallest element should be placed.

### Step 3: Assume the current element is minimum

```python
min_index = i
```

Initially, we assume the element at index `i` is the smallest.

### Step 4: Search for the smallest element

```python
for j in range(i + 1, n):
```

Checks all remaining unsorted elements.

### Step 5: Update minimum index

```python
if arr[j] < arr[min_index]:

    min_index = j
```

If a smaller element is found, update its index.

### Step 6: Swap elements

```python
arr[i], arr[min_index] = arr[min_index], arr[i]
```

Move the smallest element to its correct position.

## 12. Selection Sort Dry Run

Consider:

```python
arr = [5, 3, 8, 4, 2]
```

### Pass 1

Find the smallest element from the entire array.

```text
[5, 3, 8, 4, 2]
             |
          Minimum = 2
```

Swap `5` and `2`.

```text
[2, 3, 8, 4, 5]
```

### Pass 2

Search from index 1 onwards.

```text
[2, 3, 8, 4, 5]
    |
Minimum = 3
```

No swap is needed.

### Pass 3

Search from index 2 onwards.

```text
[2, 3, 8, 4, 5]
        |       |
    Minimum = 4
```

Swap `8` and `4`.

```text
[2, 3, 4, 8, 5]
```

### Pass 4

Search from index 3 onwards.

```text
[2, 3, 4, 8, 5]
           |
       Minimum = 5
```

Swap `8` and `5`.

```text
[2, 3, 4, 5, 8]
```

The array is now sorted.

## 13. Selection Sort Complexity

| Case | Time Complexity | Explanation |
|---|---|---|
| Best Case | O(n²) | Still searches the remaining elements |
| Average Case | O(n²) | Performs repeated minimum searches |
| Worst Case | O(n²) | Performs repeated minimum searches |

**Space Complexity:** O(1)

Selection Sort sorts the array in place and uses constant additional space.

### Properties

- Stable: No, in its standard implementation.
- In-place: Yes.
- Adaptive: No.
- Comparison-based: Yes.
- Number of swaps: At most n - 1.

# Part 3: Bubble Sort vs Selection Sort

## 14. Difference Between Bubble Sort and Selection Sort

| Feature | Bubble Sort | Selection Sort |
|---|---|---|
| Working principle | Compares adjacent elements | Finds minimum element |
| Swapping | May swap many times | At most n - 1 swaps |
| Best Case | O(n) with optimization | O(n²) |
| Average Case | O(n²) | O(n²) |
| Worst Case | O(n²) | O(n²) |
| Space Complexity | O(1) | O(1) |
| Stable | Yes | No (standard version) |
| In-place | Yes | Yes |
| Adaptive | Yes, when optimized | No |

## 15. When Should We Use Them?

### Bubble Sort

- Useful for understanding sorting fundamentals.
- Suitable for very small datasets.
- Can detect an already sorted array efficiently with its optimized version.

### Selection Sort

- Useful when minimizing the number of swaps is important.
- Suitable for small datasets.
- Performs a predictable number of comparisons.

**Note:** Both algorithms are generally inefficient for large datasets. Python's built-in `sort()` and `sorted()` use Timsort and are preferred for practical sorting.

# 18. Key Takeaways

### Bubble Sort

- Compares adjacent elements.
- Swaps elements when they are in the wrong order.
- Largest element moves to the end after every pass.
- Optimized best-case complexity is O(n).
- Average and worst-case complexity are O(n²).

### Selection Sort

- Finds the smallest element in the unsorted portion.
- Places it in the correct position.
- Performs at most n - 1 swaps.
- Best, average, and worst-case complexity are O(n²).

### Remember

- Bubble Sort = Compare adjacent elements and swap.
- Selection Sort = Find minimum and swap.
- Both use O(1) auxiliary space.
- Both are comparison-based sorting algorithms.**
