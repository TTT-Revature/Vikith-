# Binary Search

## 1. What is Binary Search?

**Binary Search** is an efficient searching algorithm that finds an element by repeatedly dividing the search space into two halves.

Instead of checking every element one by one, it eliminates half of the remaining elements in each iteration.

**Important:** Binary Search requires the input data to be sorted.

### Example

Consider the sorted array:

```python
numbers = [10, 20, 30, 40, 50, 60, 70]
target = 50
```

We want to find the position of `50`.

Binary Search works by checking the middle element.

```text
Index:    0    1    2    3    4    5    6
        [10] [20] [30] [40] [50] [60] [70]
                       MID
```

- Middle element = 40
- Target = 50
- Since 50 > 40, search the right half.
- The next middle element is 60.
- Since 50 < 60, search the left half.
- Element 50 is found.

**Result:** Index `4`.

## 2. How Binary Search Works

Binary Search uses three important variables:

| Variable | Description |
|---|---|
| `low` | Starting index of the search range |
| `high` | Ending index of the search range |
| `mid` | Middle index of the search range |

### Steps

1. Set `low = 0`.
2. Set `high = len(arr) - 1`.
3. Calculate the middle index.
4. Compare the middle element with the target.
5. If equal, return the middle index.
6. If the target is smaller, search the left half.
7. If the target is larger, search the right half.
8. Repeat until the element is found or the search range becomes empty.

### Middle Index Formula

```python
mid = (low + high) // 2
```

The `//` operator performs integer division.

## 3. Binary Search Implementation Using a While Loop

This is the most common iterative implementation.

```python
def binary_search(arr, target):

    low = 0
    high = len(arr) - 1

    while low <= high:

        mid = (low + high) // 2

        if arr[mid] == target:
            return mid

        elif target < arr[mid]:
            high = mid - 1

        else:
            low = mid + 1

    return -1


numbers = [10, 20, 30, 40, 50, 60, 70]

result = binary_search(numbers, 50)

print("Element found at index:", result)
```

**Output:**

```text
Element found at index: 4
```

## 4. Understanding the Code

### Step 1: Initialize low and high

```python
low = 0
high = len(arr) - 1
```

For this array:

```python
arr = [10, 20, 30, 40, 50, 60, 70]
```

- `low = 0`
- `high = 6`

### Step 2: Calculate the middle index

```python
mid = (low + high) // 2
```

Initially:

```text
mid = (0 + 6) // 2
mid = 3
```

The element at index 3 is `40`.

### Step 3: Compare the target

```python
if arr[mid] == target:
    return mid
```

If the middle element matches the target, return its index.

### Step 4: Search the left half

```python
elif target < arr[mid]:
    high = mid - 1
```

If the target is smaller than the middle element, eliminate the middle element and everything to its right.

### Step 5: Search the right half

```python
else:
    low = mid + 1
```

If the target is greater than the middle element, eliminate the middle element and everything to its left.

### Step 6: Element not found

```python
return -1
```

If `low` becomes greater than `high`, the search range is empty. The target is not present.

## 7. Binary Search Using Recursion

Binary Search can also be implemented using recursion.

In recursion, the function calls itself with a smaller search range.

```python
def binary_search(arr, low, high, target):

    if low > high:
        return -1

    mid = (low + high) // 2

    if arr[mid] == target:
        return mid

    elif target < arr[mid]:
        return binary_search(arr, low, mid - 1, target)

    else:
        return binary_search(arr, mid + 1, high, target)


numbers = [10, 20, 30, 40, 50, 60, 70]

result = binary_search(
    numbers,
    0,
    len(numbers) - 1,
    50
)

print("Element found at index:", result)
```

**Output:**

```text
Element found at index: 4
```

### How Recursion Works

Each recursive call reduces the search range by half.

The recursion stops when:

- The target is found.
- `low > high`, meaning the search range is empty.

**Note:** Recursive Binary Search uses O(log n) auxiliary space because of the recursion call stack. The iterative version uses O(1) auxiliary space.

## 8. Finding the First Occurrence of a Duplicate Element

Normal Binary Search may return any matching occurrence when duplicates exist.

To find the first occurrence, continue searching the left half even after finding the target.

```python
def first_occurrence(arr, target):

    low = 0
    high = len(arr) - 1
    result = -1

    while low <= high:

        mid = (low + high) // 2

        if arr[mid] == target:
            result = mid
            high = mid - 1

        elif target < arr[mid]:
            high = mid - 1

        else:
            low = mid + 1

    return result


numbers = [10, 20, 30, 30, 30, 40, 50]

print(first_occurrence(numbers, 30))
```

**Output:**

```text
2
```

## 9. Finding the Last Occurrence of a Duplicate Element

To find the last occurrence, continue searching the right half after finding the target.

```python
def last_occurrence(arr, target):

    low = 0
    high = len(arr) - 1
    result = -1

    while low <= high:

        mid = (low + high) // 2

        if arr[mid] == target:
            result = mid
            low = mid + 1

        elif target < arr[mid]:
            high = mid - 1

        else:
            low = mid + 1

    return result


numbers = [10, 20, 30, 30, 30, 40, 50]

print(last_occurrence(numbers, 30))
```

**Output:**

```text
4
```

## 10. Time and Space Complexity

Binary Search eliminates half of the remaining elements after every comparison.

| Case | Description | Time Complexity |
|---|---|---|
| Best Case | Target is at the middle position | O(1) |
| Average Case | Target is found after multiple divisions | O(log n) |
| Worst Case | Target is absent or found after maximum divisions | O(log n) |

### Space Complexity

| Implementation | Space Complexity |
|---|---|
| Iterative Binary Search | O(1) |
| Recursive Binary Search | O(log n) |

### Why is Binary Search O(log n)?

Suppose an array contains 16 elements.

```text
16 -> 8 -> 4 -> 2 -> 1
```

The search space is divided by 2 each time.

For 16 elements, it takes at most 5 middle-element checks to reach a single remaining element.

In general:

\[
\text{Number of divisions} \approx \log_2(n)
\]

This is why Binary Search has O(log n) time complexity.

## 11. Linear Search vs Binary Search

| Feature | Linear Search | Binary Search |
|---|---|---|
| Method | Checks one by one | Divides into halves |
| Sorted data required | No | Yes |
| Best Case | O(1) | O(1) |
| Average Case | O(n) | O(log n) |
| Worst Case | O(n) | O(log n) |
| Space (iterative) | O(1) | O(1) |
| Suitable for | Small or unsorted data | Large sorted data |

## 12. Common Mistakes in Binary Search

### 1. Forgetting to Sort the Array

Binary Search requires sorted data.

### 2. Incorrect Loop Condition

```python
while low <= high:
```

Using `low < high` can cause the algorithm to miss the final remaining element.

### 3. Incorrect Middle Calculation

Correct:

```python
mid = (low + high) // 2
```

### 4. Incorrect Boundary Updates

Correct:

```python
high = mid - 1
low = mid + 1
```

Do not use `high = mid` or `low = mid` in this standard implementation, because it can cause an infinite loop.

## 13. Advantages of Binary Search

1. Efficient for large sorted datasets.
2. Reduces the search space by half in each iteration.
3. Has O(log n) time complexity.
4. Iterative implementation requires O(1) extra space.
5. Useful in many advanced searching problems.

## 14. Disadvantages of Binary Search

1. Requires sorted data.
2. Sorting an unsorted collection may require additional time.
3. Not suitable for linked lists when efficient random access is unavailable.
4. More complex to implement correctly than Linear Search.

## 17. Key Takeaways

- Binary Search repeatedly divides the search space into two halves.
- It requires sorted input.
- `low` represents the starting index.
- `high` represents the ending index.
- `mid` represents the middle index.
- Best-case time complexity is O(1).
- Average and worst-case time complexity are O(log n).
- Iterative implementation uses O(1) auxiliary space.
- Recursive implementation uses O(log n) auxiliary space.
- Binary Search is one of the most important algorithms for coding interviews.
