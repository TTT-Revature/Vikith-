# Linked List – Singly, Doubly and Circular Linked Lists

## 1. What is a Linked List?

A Linked List is a linear data structure in which elements are stored in separate objects called **Nodes**.

Each node contains:
1. Data – The actual value.
2. Pointer/Reference – A reference to another node.

Unlike arrays, linked list elements are not required to occupy consecutive memory locations.

### Node Structure

A basic node contains:

```text
+-------+---------+
| Data  |  Next   |
+-------+---------+
```

Example:

```text
Head
 |
 v
+------+------+
|  10  |  o---|---->
+------+------+
              |
              v
        +------+------+
        |  20  |  o---|---->
        +------+------+
                     |
                     v
               +------+------+
               |  30  | None |
               +------+------+
```

Here:
- Head points to the first node.
- Each node stores a value.
- Next points to the next node.
- The last node points to `None`.

---

## 2. Why Do We Need Linked Lists?

Arrays and Python lists store elements in a sequential collection, while linked lists connect independently allocated nodes using references.

### Advantages

- Dynamic size.
- Efficient insertion and deletion when the required node or position is already known.
- No need to shift elements after insertion or deletion.
- Useful for implementing stacks, queues and other data structures.

### Disadvantages

- No direct indexing.
- Extra memory is required for references.
- Searching takes O(n).
- Pointer management makes implementation more complex.

---

## 3. Types of Linked Lists

There are three commonly studied types:

1. Singly Linked List
2. Doubly Linked List
3. Circular Linked List

# 4. Singly Linked List

A Singly Linked List is a linked list in which each node contains data and a reference to the next node.

The last node points to `None`.

### Structure

```text
Head
 |
 v
+------+------+
|  10  | Next |---->
+------+------+
                 |
                 v
           +------+------+
           |  20  | Next |---->
           +------+------+
                            |
                            v
                      +------+------+
                      |  30  | None |
                      +------+------+
```

### Creating a Node in Python

```python
class Node:

    def __init__(self, data):
        self.data = data
        self.next = None
```

Explanation:

- `self.data` stores the node's value.
- `self.next` stores the reference to the next node.
- Initially, `next` is `None` because the node is not connected to another node yet.

### Creating a Linked List

```python
class LinkedList:

    def __init__(self):
        self.head = None
```

`head` stores the reference to the first node.

Initially, the linked list is empty, so `head = None`.

---

## 5. Singly Linked List Operations

### A. Insertion at the Beginning – O(1)

```python
def insert_at_beginning(self, data):

    new_node = Node(data)

    new_node.next = self.head

    self.head = new_node
```

Explanation:

1. Create a new node.
2. Make the new node point to the current first node.
3. Update head to the new node.

Example:

Before:

```text
Head → 10 → 20 → 30 → None
```

Insert 5:

```text
Head → 5 → 10 → 20 → 30 → None
```

Time Complexity: O(1)

### B. Insertion at the End – O(n)

```python
def insert_at_end(self, data):

    new_node = Node(data)

    if self.head is None:
        self.head = new_node
        return

    last_node = self.head

    while last_node.next:
        last_node = last_node.next

    last_node.next = new_node
```

Explanation:

1. Create a new node.
2. Check whether the list is empty.
3. If empty, make the new node the head.
4. Otherwise, start from the head.
5. Follow the next references until the last node.
6. Connect the last node to the new node.

Time Complexity: O(n)

Note: If the linked list maintains a tail reference, insertion at the end can be O(1).

### C. Insertion at a Specific Position – O(n)

```python
def insert_at_position(self, data, position):

    new_node = Node(data)

    if position == 0:
        new_node.next = self.head
        self.head = new_node
        return

    current = self.head

    for _ in range(position - 1):

        if current is None:
            raise IndexError("Invalid position")

        current = current.next

    if current is None:
        raise IndexError("Invalid position")

    new_node.next = current.next

    current.next = new_node
```

Example:

Before:

```text
10 → 20 → 40 → None
```

Insert 30 at position 2:

```text
10 → 20 → 30 → 40 → None
```

Time Complexity: O(n)

---

## 6. Deletion in Singly Linked List

### A. Delete from Beginning – O(1)

```python
def delete_from_beginning(self):

    if self.head is None:
        return

    self.head = self.head.next
```

Explanation:

- Move head to the second node.
- The previous first node is no longer part of the list.

Before:

```text
Head → 10 → 20 → 30 → None
```

After:

```text
Head → 20 → 30 → None
```

Time Complexity: O(1)

### B. Delete from End – O(n)

```python
def delete_from_end(self):

    if self.head is None:
        return

    if self.head.next is None:
        self.head = None
        return

    current = self.head

    while current.next.next:
        current = current.next

    current.next = None
```

Explanation:

1. Check whether the list is empty.
2. Handle the single-node case.
3. Traverse until the second-last node.
4. Set its next reference to `None`.

Time Complexity: O(n)

### C. Delete by Value – O(n)

```python
def delete_by_value(self, value):

    if self.head is None:
        return

    if self.head.data == value:
        self.head = self.head.next
        return

    current = self.head

    while current.next:

        if current.next.data == value:
            current.next = current.next.next
            return

        current = current.next
```

Example:

Before:

```text
10 → 20 → 30 → 40 → None
```

Delete 30:

```text
10 → 20 → 40 → None
```

Time Complexity: O(n)

---

## 7. Traversal in Singly Linked List – O(n)

Traversal means visiting every node in the linked list.

```python
def display(self):

    current = self.head

    while current:

        print(current.data, end=" → ")

        current = current.next

    print("None")
```

Explanation:

1. Start from the head.
2. Access the current node's data.
3. Move to the next node.
4. Continue until the current node becomes `None`.

Time Complexity: O(n)

---

## 8. Complete Singly Linked List Implementation

```python
class Node:

    def __init__(self, data):
        self.data = data
        self.next = None


class LinkedList:

    def __init__(self):
        self.head = None

    def insert_at_beginning(self, data):

        new_node = Node(data)

        new_node.next = self.head

        self.head = new_node

    def insert_at_end(self, data):

        new_node = Node(data)

        if self.head is None:
            self.head = new_node
            return

        current = self.head

        while current.next:
            current = current.next

        current.next = new_node

    def delete_by_value(self, value):

        if self.head is None:
            return

        if self.head.data == value:
            self.head = self.head.next
            return

        current = self.head

        while current.next:

            if current.next.data == value:
                current.next = current.next.next
                return

            current = current.next

    def display(self):

        current = self.head

        while current:

            print(current.data, end=" → ")

            current = current.next

        print("None")


ll = LinkedList()

ll.insert_at_end(10)
ll.insert_at_end(20)
ll.insert_at_end(30)

ll.insert_at_beginning(5)

ll.display()

ll.delete_by_value(20)

ll.display()
```

Output:

```text
5 → 10 → 20 → 30 → None
5 → 10 → 30 → None
```

# 9. Doubly Linked List

A Doubly Linked List is a linked list in which each node contains three parts:

1. Previous – Reference to the previous node.
2. Data – Actual value.
3. Next – Reference to the next node.

Unlike a singly linked list, traversal is possible in both directions.

### Structure

```text
None ← 10 ⇄ 20 ⇄ 30 → None
        ↑
       Head
```

### Node Structure

```text
+----------+------+----------+
| Previous | Data | Next     |
+----------+------+----------+
```

### Creating a Node

```python
class Node:

    def __init__(self, data):
        self.data = data
        self.prev = None
        self.next = None
```

Here:
- `prev` points to the previous node.
- `data` stores the value.
- `next` points to the next node.

---

## 10. Doubly Linked List Operations

### A. Insertion at Beginning – O(1)

```python
def insert_at_beginning(self, data):

    new_node = Node(data)

    if self.head is not None:

        new_node.next = self.head

        self.head.prev = new_node

    self.head = new_node
```

Explanation:

1. Create a new node.
2. Connect its next reference to the current head.
3. Update the previous reference of the old head.
4. Update head to the new node.

### B. Insertion at End – O(n)

```python
def insert_at_end(self, data):

    new_node = Node(data)

    if self.head is None:
        self.head = new_node
        return

    current = self.head

    while current.next:
        current = current.next

    current.next = new_node

    new_node.prev = current
```

Time Complexity: O(n)

With a maintained tail reference, this operation can be O(1).

### C. Deletion from Beginning – O(1)

```python
def delete_from_beginning(self):

    if self.head is None:
        return

    self.head = self.head.next

    if self.head is not None:
        self.head.prev = None
```

### D. Traversal Forward

```python
def display_forward(self):

    current = self.head

    while current:

        print(current.data, end=" ⇄ ")

        current = current.next

    print("None")
```

### E. Traversal Backward

```python
def display_backward(self):

    current = self.head

    if current is None:
        return

    while current.next:
        current = current.next

    while current:

        print(current.data, end=" ⇄ ")

        current = current.prev

    print("None")
```

# 11. Circular Linked List

A Circular Linked List is a linked list in which the last node points back to the first node instead of pointing to `None`.

There is no `None` at the end of a non-empty circular linked list.

### Structure

```text
       ┌─────────────────────┐
       ↓                     |
Head → 10 → 20 → 30 → 40 ────┘
```

The last node connects back to the head.

### Types of Circular Linked Lists

1. Singly Circular Linked List
2. Doubly Circular Linked List

### A. Singly Circular Linked List

Each node points to the next node, and the last node points to the first node.

```text
Head → 10 → 20 → 30
  ↑              |
  └──────────────┘
```

### B. Doubly Circular Linked List

Each node contains previous and next references.

The last node points to the first node, and the first node points back to the last node.

```text
       ⇄ 10 ⇄ 20 ⇄ 30 ⇄
       ↑              ↓
       └──────────────┘
```

---

## 12. Singly Circular Linked List Implementation

### Creating a Node

```python
class Node:

    def __init__(self, data):
        self.data = data
        self.next = None
```

### Insertion at End

```python
def insert_at_end(self, data):

    new_node = Node(data)

    if self.head is None:

        self.head = new_node

        new_node.next = self.head

        return

    current = self.head

    while current.next != self.head:
        current = current.next

    current.next = new_node

    new_node.next = self.head
```

### Traversal

```python
def display(self):

    if self.head is None:
        return

    current = self.head

    while True:

        print(current.data, end=" → ")

        current = current.next

        if current == self.head:
            break

    print("(Back to Head)")
```

Example output:

```text
10 → 20 → 30 → (Back to Head)
```

Important: We use a `while True` loop and explicitly stop when we reach the head again. Otherwise, traversal can continue forever.

# 13. Comparison of Linked Lists

| Feature | Singly | Doubly | Circular |
|---|---|---|---|
| References per node | 1 | 2 | 1 or 2 |
| Forward traversal | Yes | Yes | Yes |
| Backward traversal | No | Yes | Depends on type |
| Last node points to | None | None | Head |
| Memory usage | Lower | Higher | Depends on type |
| Implementation | Simple | More complex | Requires careful traversal |

---

# 14. Time Complexity Comparison

Assume a linked list without a tail pointer unless specified.

| Operation | Singly | Doubly | Circular Singly |
|---|---:|---:|---:|
| Access by position | O(n) | O(n) | O(n) |
| Search | O(n) | O(n) | O(n) |
| Insert at beginning | O(1) | O(1) | O(1) |
| Insert at end | O(n) | O(n) | O(n) |
| Delete beginning | O(1) | O(1) | O(1) |
| Delete end | O(n) | O(n) | O(n) |
| Traversal | O(n) | O(n) | O(n) |

Note:
- Maintaining a tail pointer makes insertion at the end O(1).
- In a doubly linked list, deletion of a known node is O(1), provided its references are updated correctly.
- In a circular singly linked list, a tail pointer also makes insertion at the end O(1).

# 15. Linked List vs Array

| Feature | Array / Python List | Linked List |
|---|---|---|
| Memory | Dynamic contiguous storage | Separate node objects |
| Index access | O(1) | O(n) |
| Searching | O(n) | O(n) |
| Insertion at beginning | O(n) | O(1) |
| Deletion at beginning | O(n) | O(1) |
| Extra pointer memory | No explicit node pointers | Yes |
| Cache performance | Generally better | Generally poorer |

# 18. Key Takeaways

- A linked list consists of connected nodes.
- Each node stores data and references.
- Singly linked lists support forward traversal.
- Doubly linked lists support forward and backward traversal.
- Circular linked lists connect the last node back to the first node.
- Accessing a node by position takes O(n).
- Insertion at the beginning takes O(1).
- Linked lists are useful for implementing stacks, queues and other data structures.
- Understanding references and node connections is essential for solving linked list problems.
