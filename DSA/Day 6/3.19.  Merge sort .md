
# Merge Sort

## 1. Introduction to Merge Sort

Merge Sort is a sorting algorithm based on the **Divide and Conquer** technique.

It divides an array into smaller subarrays, sorts them individually, and then merges them to produce a completely sorted array.

### Main Steps

1. Divide - Divide the array into two halves.
2. Conquer - Recursively sort both halves.
3. Combine - Merge the sorted halves into one sorted array.

### Example

Unsorted Array:

```text
[38, 27, 43, 3, 9, 82, 10]
```

Sorted Array:

```text
[3, 9, 10, 27, 38, 43, 82]
```

---

## 2. Divide and Conquer Technique

Divide and Conquer is an algorithm design technique that solves a problem by breaking it into smaller subproblems.

It consists of three stages:

| Stage | Description |
|---|---|
| Divide | Break the problem into smaller parts |
| Conquer | Solve each smaller problem recursively |
| Combine | Combine the solutions |

Merge Sort uses this technique to efficiently sort elements.

---

## 3. How Merge Sort Works

Consider the following array:

```python
arr = [38, 27, 43, 3, 9, 82, 10]
```

### Step 1: Divide the Array

The array is divided into two halves.

```text
[38, 27, 43, 3, 9, 82, 10]

          /             \
 [38, 27, 43, 3]      [9, 82, 10]
```

Continue dividing until each subarray contains only one element.

```text
          [38, 27, 43, 3, 9, 82, 10]
                  /       \
          [38, 27, 43, 3]  [9, 82, 10]
             /      \        /     \
          [38, 27] [43, 3] [9, 82] [10]
           /  \     /  \    /  \
         [38][27] [43][3] [9][82] [10]
```

A single-element array is already sorted.

### Step 2: Merge Smaller Arrays

Now compare elements and merge them in sorted order.

```text
[38] [27]  -> [27, 38]

[43] [3]   -> [3, 43]

[9] [82]   -> [9, 82]
```

### Step 3: Merge Larger Arrays

```text
[27, 38] and [3, 43]

Result:
[3, 27, 38, 43]
```

Similarly:

```text
[9, 82] and [10]

Result:
[9, 10, 82]
```

### Step 4: Final Merge

Merge:

```text
[3, 27, 38, 43]

[9, 10, 82]
```

Final sorted array:

```text
[3, 9, 10, 27, 38, 43, 82]
```

## 4. Merge Sort Algorithm

### Pseudocode

```text
MERGE_SORT(arr):

    if length of arr <= 1:
        return arr

    find the middle index

    left = first half of arr
    right = second half of arr

    left = MERGE_SORT(left)
    right = MERGE_SORT(right)

    return MERGE(left, right)
```

### Merge Function Pseudocode

```text
MERGE(left, right):

    create an empty result array

    i = 0
    j = 0

    while i < length(left) AND j < length(right):

        if left[i] <= right[j]:
            add left[i] to result
            i = i + 1

        else:
            add right[j] to result
            j = j + 1

    add remaining elements of left
    add remaining elements of right

    return result
```

## 5. Python Implementation of Merge Sort

### 5.1 Complete Code

```python
def merge_sort(arr):

    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2

    left = arr[:mid]
    right = arr[mid:]

    left = merge_sort(left)
    right = merge_sort(right)

    return merge(left, right)


def merge(left, right):

    result = []

    i = 0
    j = 0

    while i < len(left) and j < len(right):

        if left[i] <= right[j]:
            result.append(left[i])
            i += 1

        else:
            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])

    return result


arr = [38, 27, 43, 3, 9, 82, 10]

sorted_arr = merge_sort(arr)

print("Original Array:", arr)
print("Sorted Array:", sorted_arr)
```

**Output:**

```text
Original Array: [38, 27, 43, 3, 9, 82, 10]
Sorted Array: [3, 9, 10, 27, 38, 43, 82]
```

## 6. Understanding the Code Line by Line

### 6.1 Base Condition

```python
if len(arr) <= 1:
    return arr
```

If the array contains zero or one element, it is already sorted.

This condition stops the recursive calls.

### 6.2 Finding the Middle

```python
mid = len(arr) // 2
```

Finds the middle index using integer division.

For example:

```python
arr = [38, 27, 43, 3, 9]

mid = len(arr) // 2

print(mid)
```

Output:

```text
2
```

### 6.3 Dividing the Array

```python
left = arr[:mid]
right = arr[mid:]
```

Creates two separate subarrays.

Example:

```python
arr = [38, 27, 43, 3]

left = arr[:2]
right = arr[2:]

print(left)
print(right)
```

Output:

```text
[38, 27]
[43, 3]
```

### 6.4 Recursive Calls

```python
left = merge_sort(left)
right = merge_sort(right)
```

Both halves are recursively divided and sorted.

The recursive calls continue until each subarray contains one element or becomes empty.

### 6.5 Merging

```python
return merge(left, right)
```

Calls the merge function to combine the two sorted halves.

## 7. Understanding the Merge Function

The merge function is the most important part of Merge Sort.

It combines two already sorted arrays into one sorted array.

Example:

```python
left = [10, 30, 50]
right = [20, 40, 60]
```

### Step 1: Initialize Variables

```python
result = []

i = 0
j = 0
```

- `result` stores the sorted elements.
- `i` tracks the current position in the left array.
- `j` tracks the current position in the right array.

### Step 2: Compare Elements

```python
while i < len(left) and j < len(right):

    if left[i] <= right[j]:
        result.append(left[i])
        i += 1

    else:
        result.append(right[j])
        j += 1
```

Let's trace the comparisons.

| Comparison | Selected Element | Result |
|---|---|---|
| 10 vs 20 | 10 | [10] |
| 30 vs 20 | 20 | [10, 20] |
| 30 vs 40 | 30 | [10, 20, 30] |
| 50 vs 40 | 40 | [10, 20, 30, 40] |
| 50 vs 60 | 50 | [10, 20, 30, 40, 50] |

Now the left array is exhausted.

The right array still contains 60.

### Step 3: Add Remaining Elements

```python
result.extend(left[i:])
result.extend(right[j:])
```

This adds all remaining elements.

Final result:

```text
[10, 20, 30, 40, 50, 60]
```

**Important:** We need these statements because one array may still contain elements after the comparison loop finishes.

## 8. Dry Run of Merge Sort

Consider:

```python
arr = [8, 4, 2, 6]
```

### Division Phase

```text
             [8, 4, 2, 6]
               /       \
           [8, 4]      [2, 6]
            / \         / \
          [8] [4]     [2] [6]
```

### Merging Phase

First merge:

```text
[8] + [4] = [4, 8]

[2] + [6] = [2, 6]
```

Second merge:

```text
[4, 8] + [2, 6]
```

Comparisons:

```text
4 vs 2  -> 2
4 vs 6  -> 4
8 vs 6  -> 6
Remaining -> 8
```

Final result:

```text
[2, 4, 6, 8]
```

## 9. Time Complexity of Merge Sort

Merge Sort has the same time complexity in the best, average, and worst cases.

| Case | Time Complexity |
|---|---|
| Best Case | O(n log n) |
| Average Case | O(n log n) |
| Worst Case | O(n log n) |

### Why O(n log n)?

Merge Sort divides the array into halves repeatedly.

The number of division levels is approximately:

```text
log₂(n)
```

At each level, merging processes all `n` elements.

Therefore:

```text
O(n) × O(log n) = O(n log n)
```

### Example

For an array of 8 elements:

```text
Level 0: 1 array
Level 1: 2 arrays
Level 2: 4 arrays
Level 3: 8 arrays
```

The number of levels is log₂(8) = 3.

Each level performs O(n) merging work.

Total complexity: O(n log n).

---

## 10. Space Complexity

Standard Merge Sort using additional arrays requires O(n) auxiliary space for merging.

The recursive implementation also uses O(log n) recursion stack space.

Therefore, the overall auxiliary space complexity is:

**O(n)**

Note: The implementation above uses Python slicing, which creates additional subarrays. It is not an in-place sorting algorithm.

## 11. Properties of Merge Sort

| Property | Description |
|---|---|
| Algorithm Type | Divide and Conquer |
| Best Time | O(n log n) |
| Average Time | O(n log n) |
| Worst Time | O(n log n) |
| Auxiliary Space | O(n) |
| Stable | Yes, when equal elements are handled using `<=` |
| In-place | No, in the standard implementation |
| Recursive | Yes |

### What is a Stable Sorting Algorithm?

A stable sorting algorithm preserves the original relative order of elements with equal keys.

Merge Sort is stable when the merge operation selects the left element first when two elements are equal.

This is why we use:

```python
if left[i] <= right[j]:
```

instead of:

```python
if left[i] < right[j]:
```

## 12. Advantages of Merge Sort

1. Guaranteed O(n log n) time complexity.
2. Performs consistently on different input arrangements.
3. Stable sorting algorithm.
4. Suitable for sorting large datasets.
5. Useful for linked-list sorting.
6. Can be used for external sorting when data does not fit into memory.

## 13. Disadvantages of Merge Sort

1. Requires additional memory.
2. Standard array implementation is not in-place.
3. Recursive calls introduce function-call overhead.
4. For small arrays, simpler algorithms like Insertion Sort can be faster.

## 17. Key Takeaways

- Merge Sort is based on Divide and Conquer.
- It repeatedly divides an array into smaller halves.
- Each subarray is sorted recursively.
- The merge function combines sorted subarrays.
- Best, average, and worst time complexity is O(n log n).

- Merge Sort is stable when equal elements are merged in the correct order.
- It is particularly useful for linked lists and large datasets.
