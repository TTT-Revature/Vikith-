# Stacks – Concepts, Operations and Implementation

## 1. What is a Stack?

A **Stack** is a linear data structure that follows the **LIFO (Last In, First Out)** principle.

This means the element inserted last will be removed first.

**Real-life example:** A stack of plates. You place a new plate on top and also remove the topmost plate first.

### Example

```text
        TOP
         |
       [30]  <- Removed first
       [20]
       [10]  <- Removed last
```

Here:
- `10` was inserted first.
- `20` was inserted second.
- `30` was inserted last.
- When removing elements, `30` comes out first.

## 2. Basic Stack Operations

A stack mainly supports the following operations:

| Operation | Description |
|---|---|
| `push()` | Adds an element to the top |
| `pop()` | Removes the top element |
| `peek()` / `top()` | Returns the top element without removing it |
| `is_empty()` | Checks whether the stack is empty |
| `size()` | Returns the number of elements |

### 2.1 Push Operation

Adds a new element to the top of the stack.

```python
stack = []

stack.append(10)
stack.append(20)
stack.append(30)

print(stack)
```

**Output:**
```text
[10, 20, 30]
```

### 2.2 Pop Operation

Removes and returns the topmost element.

```python
stack = [10, 20, 30]

removed = stack.pop()

print("Removed:", removed)
print("Stack:", stack)
```

**Output:**
```text
Removed: 30
Stack: [10, 20]
```

### 2.3 Peek Operation

Returns the top element without removing it.

```python
stack = [10, 20, 30]

print("Top element:", stack[-1])
print("Stack:", stack)
```

**Output:**
```text
Top element: 30
Stack: [10, 20, 30]
```

### 2.4 Check if Stack is Empty

```python
stack = []

if len(stack) == 0:
    print("Stack is empty")
else:
    print("Stack is not empty")
```

**Output:**
```text
Stack is empty
```

### 2.5 Find Stack Size

```python
stack = [10, 20, 30]

print("Stack size:", len(stack))
```

**Output:**
```text
Stack size: 3
```

## 3. Stack Implementation Using Python List

Python lists can be used to implement a stack.

- `append()` adds elements to the top.
- `pop()` removes elements from the top.
- `stack[-1]` accesses the top element.

```python
stack = []

# Push
stack.append(10)
stack.append(20)
stack.append(30)

print("Stack:", stack)

# Peek
print("Top:", stack[-1])

# Pop
print("Removed:", stack.pop())

print("Updated Stack:", stack)
```

**Output:**
```text
Stack: [10, 20, 30]
Top: 30
Removed: 30
Updated Stack: [10, 20]
```

## 4. Stack Implementation Using a Class

We can create a Stack class to organize all stack operations.

```python
class Stack:

    def __init__(self):
        self.items = []

    def push(self, data):
        self.items.append(data)

    def pop(self):
        if self.is_empty():
            return "Stack is empty"

        return self.items.pop()

    def peek(self):
        if self.is_empty():
            return "Stack is empty"

        return self.items[-1]

    def is_empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)


stack = Stack()

stack.push(10)
stack.push(20)
stack.push(30)

print("Top:", stack.peek())
print("Removed:", stack.pop())
print("Size:", stack.size())
print("Stack:", stack.items)
```

**Output:**
```text
Top: 30
Removed: 30
Size: 2
Stack: [10, 20]
```

## 5. Stack Implementation Using a Linked List

A stack can also be implemented using a linked list.

In this implementation, we use a `top` pointer to keep track of the topmost node.

### Push Operation

A new node is inserted at the beginning of the linked list.

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


class Stack:

    def __init__(self):
        self.top = None

    def push(self, data):
        new_node = Node(data)

        new_node.next = self.top
        self.top = new_node
```

### Pop Operation

Removes the topmost node by moving the `top` pointer to the next node.

```python
def pop(self):

    if self.top is None:
        return "Stack is empty"

    removed = self.top.data
    self.top = self.top.next

    return removed
```

### Complete Implementation

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


class Stack:

    def __init__(self):
        self.top = None

    def push(self, data):
        new_node = Node(data)

        new_node.next = self.top
        self.top = new_node

    def pop(self):
        if self.top is None:
            return "Stack is empty"

        removed = self.top.data
        self.top = self.top.next

        return removed

    def peek(self):
        if self.top is None:
            return "Stack is empty"

        return self.top.data

    def is_empty(self):
        return self.top is None


stack = Stack()

stack.push(10)
stack.push(20)
stack.push(30)

print("Top:", stack.peek())
print("Removed:", stack.pop())
print("Top after pop:", stack.peek())
```

**Output:**
```text
Top: 30
Removed: 30
Top after pop: 20
```

## 6. Time and Space Complexity

| Operation | Python List | Linked List |
|---|---:|---:|
| Push | O(1) amortized | O(1) |
| Pop | O(1) | O(1) |
| Peek | O(1) | O(1) |
| is_empty | O(1) | O(1) |
| Size | O(1) with maintained size / O(n) if counted manually | O(1) with maintained size / O(n) if counted manually |

**Space Complexity:** O(n), where `n` is the number of elements stored in the stack.

## 7. Applications of Stack

Stacks are used in many real-world applications:

1. **Undo and Redo:** Stores previous actions in applications.
2. **Browser History:** Helps navigate backward through visited pages.
3. **Function Calls:** Programming languages use a call stack to manage function execution.
4. **Expression Evaluation:** Used to evaluate mathematical expressions.
5. **Parentheses Matching:** Checks whether brackets are correctly balanced.
6. **Backtracking:** Used in maze solving and depth-first search (DFS).

## 10. Key Takeaways

- Stack follows the **LIFO (Last In, First Out)** principle.
- Insertion and deletion happen at the top.
- `push()` inserts an element.
- `pop()` removes the top element.
- `peek()` returns the top element without removing it.
- Python lists and linked lists can both implement stacks.
- Stack operations at the top take O(1) time.
- Stacks are useful in recursion, backtracking, expression evaluation, and DFS.
