# Insertion Sort

## 1. What is Insertion Sort?

**Insertion Sort** is a simple sorting algorithm that builds a sorted array one element at a time.

It takes each element and inserts it into its correct position within the already sorted portion of the array.

**Real-life example:** Imagine arranging playing cards in your hand. You pick one card at a time and insert it into the correct position among the cards you are already holding.

### Example

```python
arr = [5, 3, 8, 4, 2]
```

We want to sort the array in ascending order.

```text
Initial:  [5, 3, 8, 4, 2]

Pass 1:   [3, 5, 8, 4, 2]
Pass 2:   [3, 5, 8, 4, 2]
Pass 3:   [3, 4, 5, 8, 2]
Pass 4:   [2, 3, 4, 5, 8]

Sorted:   [2, 3, 4, 5, 8]
```

## 2. How Insertion Sort Works

1. Consider the first element as already sorted.
2. Pick the next element. This is called the `key`.
3. Compare the key with the elements before it.
4. Shift elements greater than the key one position to the right.
5. Insert the key into its correct position.
6. Repeat until all elements are sorted.

## 3. Important Variables

| Variable | Description |
|---|---|
| `i` | Selects the current element |
| `key` | Stores the element being inserted |
| `j` | Moves backwards through the sorted portion |

## 4. Insertion Sort Implementation in Python

```python
def insertion_sort(arr):

    n = len(arr)

    for i in range(1, n):

        key = arr[i]

        j = i - 1

        while j >= 0 and arr[j] > key:

            arr[j + 1] = arr[j]

            j -= 1

        arr[j + 1] = key

    return arr


numbers = [5, 3, 8, 4, 2]

print(insertion_sort(numbers))
```

**Output:**

```text
[2, 3, 4, 5, 8]
```

## 5. Understanding the Code

### Step 1: Start from the second element

```python
for i in range(1, n):
```

Why start from index 1?

Because the first element is considered sorted.

### Step 2: Store the current element

```python
key = arr[i]
```

The `key` stores the element that we want to insert into the correct position.

### Step 3: Start comparing from the previous element

```python
j = i - 1
```

We start from the element immediately before the key.

### Step 4: Compare and shift elements

```python
while j >= 0 and arr[j] > key:

    arr[j + 1] = arr[j]

    j -= 1
```

If the previous element is greater than the key:

- Move the previous element one position to the right.
- Decrease `j` to check the next element on the left.
- Continue until the correct position is found.

### Step 5: Insert the key

```python
arr[j + 1] = key
```

Once the correct position is found, insert the key there.

**Important:** We use `j + 1` because `j` moves one position beyond the correct insertion position when the loop stops.

## 6. Insertion Sort Dry Run

Consider:

```python
arr = [5, 3, 8, 4, 2]
```

### Initial Array

```text
[5, 3, 8, 4, 2]
```

The first element `5` is considered sorted.

### Pass 1

```python
key = 3
j = 0
```

Compare `5` with `3`.

Since `5 > 3`, shift `5` to the right and insert `3`.

```text
Before: [5, 3, 8, 4, 2]
After:  [3, 5, 8, 4, 2]
```

### Pass 2

```python
key = 8
j = 1
```

Compare `5` with `8`.

Since `5 < 8`, no shifting is required.

```text
[3, 5, 8, 4, 2]
```

### Pass 3

```python
key = 4
j = 2
```

Compare `8` with `4`. Shift `8`.

Compare `5` with `4`. Shift `5`.

Compare `3` with `4`. Stop.

Insert `4`.

```text
Before: [3, 5, 8, 4, 2]
After:  [3, 4, 5, 8, 2]
```

### Pass 4

```python
key = 2
j = 3
```

Compare `8`, `5`, `4`, and `3` with `2`.

All are greater than `2`, so shift them right.

Insert `2` at index `0`.

```text
Before: [3, 4, 5, 8, 2]
After:  [2, 3, 4, 5, 8]
```

**Final Sorted Array:**

```text
[2, 3, 4, 5, 8]
```

## 7. Insertion Sort Using a While Loop

The complete algorithm uses a `for` loop for selecting the key and a `while` loop for shifting elements.

Here is another implementation using a `while` loop for both operations.

```python
def insertion_sort(arr):

    i = 1

    while i < len(arr):

        key = arr[i]

        j = i - 1

        while j >= 0 and arr[j] > key:

            arr[j + 1] = arr[j]

            j -= 1

        arr[j + 1] = key

        i += 1

    return arr


numbers = [9, 5, 1, 4, 3]

print(insertion_sort(numbers))
```

**Output:**

```text
[1, 3, 4, 5, 9]
```

## 8. Insertion Sort in Descending Order

To sort in descending order, change the comparison condition.

Ascending:

```python
arr[j] > key
```

Descending:

```python
arr[j] < key
```

### Implementation

```python
def insertion_sort_desc(arr):

    for i in range(1, len(arr)):

        key = arr[i]

        j = i - 1

        while j >= 0 and arr[j] < key:

            arr[j + 1] = arr[j]

            j -= 1

        arr[j + 1] = key

    return arr


numbers = [5, 3, 8, 4, 2]

print(insertion_sort_desc(numbers))
```

**Output:**

```text
[8, 5, 4, 3, 2]
```

## 9. Time and Space Complexity

| Case | Time Complexity | Explanation |
|---|---|---|
| Best Case | O(n) | Array is already sorted |
| Average Case | O(n²) | Elements need multiple shifts |
| Worst Case | O(n²) | Array is sorted in reverse order |

### Space Complexity

**O(1)** – Insertion Sort sorts the array in place and uses constant additional space.

### Properties

- Stable: Yes.
- In-place: Yes.
- Adaptive: Yes.
- Comparison-based: Yes.
- Online: Yes (can process elements as they arrive).

## 10. Why is Insertion Sort O(n) in the Best Case?

Consider an already sorted array:

```python
arr = [1, 2, 3, 4, 5]
```

For each element, the algorithm checks the previous element.

Since the previous element is already smaller, the `while` loop stops immediately.

There is approximately one comparison per element.

Therefore, the best-case time complexity is O(n).

## 11. Why is Insertion Sort O(n²) in the Worst Case?

Consider a reverse-sorted array:

```python
arr = [5, 4, 3, 2, 1]
```

Each new element must be compared with all the elements before it and shifted to the beginning.

The number of comparisons and shifts grows approximately as:

```text
1 + 2 + 3 + 4 + ... + (n - 1)
```

Therefore, the worst-case time complexity is O(n²).

## 12. Advantages of Insertion Sort

1. Easy to understand and implement.
2. Efficient for small datasets.
3. Performs well on nearly sorted arrays.
4. Requires only O(1) additional space.
5. Stable sorting algorithm.
6. Can sort elements as they arrive.

## 13. Disadvantages of Insertion Sort

1. Inefficient for large datasets.
2. Worst-case time complexity is O(n²).
3. Requires many shifts for reverse-sorted arrays.
4. Generally slower than advanced sorting algorithms for large inputs.

## 14. Bubble Sort vs Selection Sort vs Insertion Sort

| Feature | Bubble Sort | Selection Sort | Insertion Sort |
|---|---|---|---|
| Working principle | Compares adjacent elements | Finds minimum element | Inserts element into sorted portion |
| Best Case | O(n) optimized | O(n²) | O(n) |
| Average Case | O(n²) | O(n²) | O(n²) |
| Worst Case | O(n²) | O(n²) | O(n²) |
| Space | O(1) | O(1) | O(1) |
| Stable | Yes | No (standard) | Yes |
| Adaptive | Yes, optimized | No | Yes |
| In-place | Yes | Yes | Yes |

## 15. When Should We Use Insertion Sort?

Insertion Sort is useful when:

- The dataset is small.
- The array is already nearly sorted.
- New elements arrive gradually.
- A simple in-place stable sorting algorithm is required.

For large datasets, algorithms such as Merge Sort, Quick Sort, and Python's built-in Timsort are generally more suitable.

## 18. Key Takeaways

- Insertion Sort builds a sorted portion one element at a time.
- `key` stores the current element.
- `j` moves backwards through the sorted portion.
- Larger elements are shifted to the right.
- The key is inserted into its correct position.
- Best-case complexity is O(n).
- Average and worst-case complexity are O(n²).
- Space complexity is O(1).
- Insertion Sort is stable, adaptive, and in-place.
