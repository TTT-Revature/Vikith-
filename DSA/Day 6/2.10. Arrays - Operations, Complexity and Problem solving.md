# Arrays – Operations, Complexity and Problem Solving in Python

## 1. What is an Array?

An array is a linear data structure used to store multiple elements in an ordered collection.

Each element can be accessed using an index.

Example:

```python
numbers = [10, 20, 30, 40, 50]
```

Array representation:

| Index | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Value | 10 | 20 | 30 | 40 | 50 |

Important points:

- Indexing starts from 0 in Python lists.
- Elements maintain their order.
- Python lists are dynamic and can grow or shrink.
- Python lists can contain different data types.
- Accessing an element by index takes O(1) time.

**Important:** Python does not have a built-in fixed-size array as its primary collection. Python lists are dynamic arrays, while the `array` module provides typed arrays.

## 2. Creating Arrays in Python

### Using a List

```python
numbers = [10, 20, 30, 40, 50]

print(numbers)
print(type(numbers))
```

Output:

```text

<class 'list'>
```

```python

```

```python
numbers = [0] * 5
```

Output:



## 3. Array Operations

The most common array operations are:

1. Traversal
2. Accessing
3. Insertion
4. Deletion
5. Searching
6. Updating
7. Sorting
8. Reversing

## 4. Traversal – O(n)

Traversal means visiting every element in an array.

```python
numbers = [10, 20, 30, 40, 50]

for num in numbers:
    print(num)
```

Output:

```text
10
20
30
40
50
```

Using index:

```python
for i in range(len(numbers)):
    print(numbers[i])
```

Time Complexity: O(n)

---

## 5. Accessing Elements – O(1)

Accessing means retrieving an element using its index.

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[2])
```

Output:

```text
30
```

The index directly identifies the element.

Time Complexity: O(1)

---

## 6. Insertion – O(n)

Insertion means adding a new element to an array.

### A. Append – Add at the End

```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

Output:

```text
[10, 20, 30, 40]
```

Time Complexity:
- Amortized: O(1)
- Worst case: O(n), when resizing is required.

### B. Insert – Add at a Specific Position

```python
numbers = [10, 20, 40, 50]

numbers.insert(2, 30)

print(numbers)
```

Output:

```text
[10, 20, 30, 40, 50]
```

Elements after the insertion position need to shift.

Time Complexity: O(n)

### C. Extend – Add Multiple Elements

```python
numbers = [10, 20, 30]

numbers.extend([40, 50, 60])

print(numbers)
```

Output:

```text
[10, 20, 30, 40, 50, 60]
```

Time Complexity: O(k) for adding k elements, excluding occasional resizing costs.

---

## 7. Deletion – O(n)

Deletion means removing an element from an array.

### A. Remove – Delete by Value

```python
numbers = [10, 20, 30, 40]

numbers.remove(30)

print(numbers)
```

Output:

```text
[10, 20, 40]
```

Time Complexity: O(n)

### B. Pop – Delete by Index

```python
numbers = [10, 20, 30, 40]

numbers.pop(1)

print(numbers)
```

Output:

```text
[10, 30, 40]
```

Time Complexity:
- Last element: O(1)
- Arbitrary index: O(n)

### C. Clear – Remove All Elements

```python
numbers = [10, 20, 30]

numbers.clear()

print(numbers)
```

Output:

```text
[]
```

Time Complexity: O(n)

---

## 8. Searching – O(n)

Searching means finding whether an element exists in an array.

### Linear Search

```python
numbers = [10, 20, 30, 40, 50]

target = 30

for i in range(len(numbers)):

    if numbers[i] == target:
        print("Found at index:", i)
        break
```

Output:

```text
Found at index: 2
```

Time Complexity:
- Best case: O(1)
- Average case: O(n)
- Worst case: O(n)

### Using the in Operator

```python
numbers = [10, 20, 30, 40]

print(30 in numbers)
```

Output:

```text
True
```

Average and worst-case time complexity: O(n).

---

## 9. Updating Elements – O(1)

Updating means changing the value at a particular index.

```python
numbers = [10, 20, 30, 40]

numbers[2] = 100

print(numbers)
```

Output:

```text
[10, 20, 100, 40]
```

Time Complexity: O(1)

---

## 10. Sorting – O(n log n)

Sorting means arranging elements in ascending or descending order.

### Ascending Order

```python
numbers = [50, 10, 40, 20, 30]

numbers.sort()

print(numbers)
```

Output:

```text
[10, 20, 30, 40, 50]
```

### Descending Order

```python
numbers.sort(reverse=True)

print(numbers)
```

Output:

```text
[50, 40, 30, 20, 10]
```

Python's built-in sorting uses Timsort.

Time Complexity:
- Best case: O(n)
- Average case: O(n log n)
- Worst case: O(n log n)

Note: `sort()` modifies the original list. `sorted()` creates a new sorted list.

---

## 11. Reversing an Array – O(n)

Reversing means changing the order of elements.

### Using reverse()

```python
numbers = [10, 20, 30, 40, 50]

numbers.reverse()

print(numbers)
```

Output:

```text
[50, 40, 30, 20, 10]
```

### Using Slicing

```python
numbers = [10, 20, 30, 40, 50]

reversed_numbers = numbers[::-1]

print(reversed_numbers)
```

Output:

```text
[50, 40, 30, 20, 10]
```

Note:
- `reverse()` modifies the original list.
- Slicing creates a new list.

Time Complexity: O(n)

## 13. Common Array Problem-Solving Techniques

Understanding these patterns will help you solve many LeetCode problems.

### A. Two Pointer Technique

Two pointers are used to traverse an array from different positions.

Example: Reverse an array.

```python
def reverse_array(numbers):

    left = 0
    right = len(numbers) - 1

    while left < right:

        numbers[left], numbers[right] = numbers[right], numbers[left]

        left += 1
        right -= 1

    return numbers


print(reverse_array([10, 20, 30, 40, 50]))
```

Output:

```text
[50, 40, 30, 20, 10]
```

Time Complexity: O(n)

Space Complexity: O(1) auxiliary space.

### B. Hashing Technique

Hashing helps perform efficient lookups using dictionaries or sets.

Example: Find duplicates.

```python
def contains_duplicate(numbers):

    seen = set()

    for num in numbers:

        if num in seen:
            return True

        seen.add(num)

    return False


print(contains_duplicate([1, 2, 3, 1]))
```

Output:

```text
True
```

Time Complexity: O(n) average.

Space Complexity: O(n).

### C. Prefix Sum

Prefix Sum stores cumulative sums to answer range-sum queries efficiently.

Example:

```python
numbers = [2, 4, 6, 8]

prefix = [0]

for num in numbers:
    prefix.append(prefix[-1] + num)

print(prefix)
```

Output:

```text
[0, 2, 6, 12, 20]
```

To find the sum from index `left` to index `right`:

```python
left = 1
right = 3

result = prefix[right + 1] - prefix[left]

print(result)
```

Output:

```text
18
```

Prefix construction: O(n)

Each range-sum query: O(1)

## 16. Key Takeaways

- Python lists are dynamic arrays.
- Array indexing takes O(1).
- Traversal and linear searching take O(n).
- Insertion and deletion at arbitrary positions generally take O(n).
- Appending is O(1) amortized.
- Sorting generally takes O(n log n).
- Two Pointers help solve many array problems efficiently.
- Hashing helps with fast average-case lookups.
- Prefix Sum helps answer range-sum queries efficiently.
- Understanding time and space complexity is essential for writing optimized solutions.
