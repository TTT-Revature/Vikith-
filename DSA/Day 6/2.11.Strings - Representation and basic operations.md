
# Strings - Representation and Basic Operations

## 1. Introduction to Strings

A string is a sequence of characters enclosed within single, double, or triple quotation marks.

In Python, strings are represented using the `str` data type.

```python
name = "Python"
language = 'Java'
message = """Welcome to Python"""

print(name)
print(type(name))
```

**Output:**
```text
Python
<class 'str'>
```

Strings can contain:
- Alphabets: `"Python"`
- Numbers: `"12345"`
- Special characters: `"@#$%"`
- Spaces: `"Hello World"`
- Empty strings: `""`

**Important:** Even if a string contains only numbers, Python treats it as a string.

```python
a = "123"
b = 123

print(type(a))  # str
print(type(b))  # int
```

---

## 2. String Representation and Indexing

A string is an ordered sequence of characters. Each character has an index.

### Positive Indexing

Positive indexing starts from `0` and moves from left to right.

```python
text = "PYTHON"

print(text[0])  # P
print(text[1])  # Y
print(text[2])  # T
print(text[5])  # N
```

### Negative Indexing

Negative indexing starts from `-1` and moves from right to left.

```python
text = "PYTHON"

print(text[-1])  # N
print(text[-2])  # O
print(text[-3])  # H
print(text[-6])  # P
```

### Indexing Table

| Character | P | Y | T | H | O | N |
|---|---|---|---|---|---|---|
| Positive Index | 0 | 1 | 2 | 3 | 4 | 5 |
| Negative Index | -6 | -5 | -4 | -3 | -2 | -1 |

**Important Points:**
- Positive indexing starts at `0`.
- Negative indexing starts at `-1`.
- Accessing an invalid index raises `IndexError`.
- Indexing takes O(1) time.

---

## 3. String Immutability

Strings in Python are immutable.

Immutable means that once a string is created, its individual characters cannot be modified.

```python
text = "Python"

text[0] = "J"  # TypeError
```

**Output:**
```text
TypeError: 'str' object does not support item assignment
```

However, we can create a new string and assign it to the same variable.

```python
text = "Python"

text = "J" + text[1:]

print(text)
```

**Output:**
```text
Jython
```

**Important Points:**
- Individual characters cannot be modified.
- String methods generally return new strings.
- String operations create new string objects when producing modified content.
- Immutability makes strings safer to share and use as dictionary keys.

## 4. Accessing Characters in a String

Characters can be accessed using indexing, loops, and the `enumerate()` function.

### Using For Loop

```python
text = "Python"

for char in text:
    print(char)
```

**Output:**
```text
P
y
t
h
o
n
```

### Using Index

```python
text = "Python"

for i in range(len(text)):
    print(i, text[i])
```

### Using enumerate()

```python
text = "Python"

for index, char in enumerate(text):
    print(index, char)
```

**Output:**
```text
0 P
1 y
2 t
3 h
4 o
5 n
```

### len() Function

The `len()` function returns the total number of characters in a string, including spaces.

```python
text = "Hello World"

print(len(text))
```

**Output:**
```text
11
```

Time Complexity: O(1) for `len()`.

## 5. String Slicing

Slicing is used to extract a portion of a string.

### Syntax

```python
string[start:stop:step]
```

| Parameter | Description |
|---|---|
| start | Starting index (included) |
| stop | Ending index (excluded) |
| step | Number of positions to move |

### Examples

```python
text = "PYTHON"

print(text[0:3])   # PYT
print(text[2:5])   # THO
print(text[:4])    # PYTH
print(text[2:])    # THON
print(text[:])     # PYTHON
print(text[::2])   # PTO
print(text[::-1])  # NOHTYP
```

### Reverse a String Using Slicing

```python
text = "PYTHON"

reverse = text[::-1]

print(reverse)
```

**Output:**
```text
NOHTYP
```

**Important Points:**
- The starting index is included.
- The ending index is excluded.
- Default start and stop depend on the step direction.
- A negative step moves backwards.
- Slicing creates a new string.

Time Complexity: O(k), where k is the length of the resulting substring.

## 6. Basic String Operations

### 6.1 Concatenation (+)

Combines two or more strings.

```python
first = "Hello"
second = "Python"

result = first + " " + second

print(result)
```

**Output:**
```text
Hello Python
```

### 6.2 Repetition (*)

Repeats a string multiple times.

```python
text = "Hi "

print(text * 3)
```

**Output:**
```text
Hi Hi Hi
```

### 6.3 Membership (in and not in)

Checks whether a substring exists inside another string.

```python
text = "Python Programming"

print("Python" in text)
print("Java" in text)
print("Java" not in text)
```

**Output:**
```text
True
False
True
```

### 6.4 String Comparison

Strings can be compared using comparison operators.

- `==` Equal
- `!=` Not equal
- `<` Less than
- `>` Greater than
- `<=` Less than or equal
- `>=` Greater than or equal

```python
a = "apple"
b = "banana"

print(a == b)  # False
print(a != b)  # True
print(a < b)   # True
```

Python compares strings lexicographically using Unicode code points.

## 7. Iterating Through Strings

Iteration means accessing each character of a string one by one.

### Using For Loop

```python
text = "Python"

for char in text:
    print(char)
```

### Using While Loop

```python
text = "Python"

i = 0

while i < len(text):
    print(text[i])
    i += 1
```

### Using enumerate()

```python
text = "Python"

for index, char in enumerate(text):
    print(index, char)
```

`enumerate()` provides both the index and character.

Time Complexity: O(n).

## 8. Escape Characters

Escape characters are special characters represented using a backslash (`\`).

| Escape Sequence | Meaning |
|---|---|
| `\n` | New line |
| `\t` | Tab space |
| `\\` | Backslash |
| `\'` | Single quote |
| `\"` | Double quote |

### New Line

```python
print("Hello\nWorld")
```

**Output:**
```text
Hello
World
```

### Tab Space

```python
print("Name:\tPython")
```

### Raw Strings

Raw strings treat backslashes as literal characters instead of interpreting most escape sequences.

```python
path = r"C:\Users\Python\Documents"

print(path)
```

Useful for Windows file paths and regular expressions.

## 10. Important String Methods

| Method | Description | Example |
|---|---|---|
| `upper()` | Converts to uppercase | `"hello".upper()` |
| `lower()` | Converts to lowercase | `"HELLO".lower()` |
| `capitalize()` | Capitalizes first character | `"python".capitalize()` |
| `title()` | Capitalizes each word | `"hello world".title()` |
| `strip()` | Removes surrounding whitespace | `" hi ".strip()` |
| `lstrip()` | Removes leading whitespace | `" hi".lstrip()` |
| `rstrip()` | Removes trailing whitespace | `"hi ".rstrip()` |
| `replace()` | Replaces a substring | `"cat".replace("c","b")` |
| `find()` | Returns first occurrence index | `"python".find("t")` |
| `index()` | Returns index or raises ValueError | `"python".index("t")` |
| `count()` | Counts occurrences | `"banana".count("a")` |
| `startswith()` | Checks beginning | `"python".startswith("py")` |
| `endswith()` | Checks ending | `"python".endswith("on")` |
| `split()` | Splits into a list | `"a b".split()` |
| `join()` | Joins strings | `"-".join(["a","b"])` |
| `isalpha()` | Checks alphabetic characters | `"Hello".isalpha()` |
| `isdigit()` | Checks digit characters | `"123".isdigit()` |
| `isalnum()` | Checks letters or digits | `"abc123".isalnum()` |
| `isspace()` | Checks whitespace | `"   ".isspace()` |

### Example

```python
text = "  python programming  "

print(text.upper())
print(text.lower())
print(text.strip())
print(text.replace("python", "Java"))
print(text.find("programming"))
```

**Important:** Strings are immutable. These methods return results without modifying the original string.

## 11. Unicode and Internal String Representation

Python strings support Unicode, allowing text from different languages and symbol systems.

```python
a = "Hello"
b = "नमस्ते"
c = "こんにちは"
d = "😊"
```

In CPython, strings use a flexible Unicode representation.

Depending on the largest code point in a string, CPython may use 1, 2, or 4 bytes per code point.

### Example

```python
text = "Hello"

print(len(text))
```

**Output:**
```text
5
```

**Important:**
- `len()` counts Unicode code points.
- It does not always count user-perceived characters.
- Some emoji sequences contain multiple code points.

```python
text = "😊"

print(len(text))  # 1
```

## 12. Time Complexity of String Operations

Let `n` represent the string length.

| Operation | Time Complexity |
|---|---|
| Indexing `s[i]` | O(1) |
| `len(s)` | O(1) |
| Slicing `s[a:b]` | O(k) |
| Concatenation `s1 + s2` | O(n + m) |
| Repetition `s * k` | O(n * k) |
| Membership `x in s` | O(n) worst case |
| Iteration | O(n) |
| String comparison | O(n) worst case |
| `find()` | O(n * m) worst case |
| `count()` | O(n * m) worst case |

Here:
- `n` = Length of the original string.
- `m` = Length of the search pattern.
- `k` = Length of the resulting substring.

### Performance Tip

Avoid repeated string concatenation inside large loops when performance matters.

**Less efficient approach:**

```python
result = ""

for word in ["Python", "is", "awesome"]:
    result += word + " "
```

**Better approach:**

```python
words = ["Python", "is", "awesome"]

result = " ".join(words)

print(result)
```

**Output:**
```text
Python is awesome
```

## 13. Practical String Programs

### 13.1 Reverse a String

```python
text = "Python"

reverse = text[::-1]

print(reverse)
```

**Output:**
```text
nohtyP
```

### 13.2 Count Vowels

```python
text = "programming"

count = 0

for char in text:
    if char in "aeiou":
        count += 1

print(count)
```

**Output:**
```text
3
```

### 13.3 Count Character Frequency

```python
text = "banana"

for char in set(text):
    print(char, text.count(char))
```

**Possible Output:**
```text
b 1
a 3
n 2
```

### 13.4 Check Palindrome

A palindrome reads the same forward and backward.

```python
text = "madam"

if text == text[::-1]:
    print("Palindrome")
else:
    print("Not a palindrome")
```

**Output:**
```text
Palindrome
```

### 13.5 Remove Spaces

```python
text = "Python is awesome"

result = text.replace(" ", "")

print(result)
```

**Output:**
```text
Pythonisawesome
```
