# Quick Sort

## 1. What is Quick Sort?

**Quick Sort** is a sorting algorithm based on the **Divide and Conquer** technique.

It works by selecting an element called a **pivot**, partitioning the array around the pivot, and recursively sorting the smaller subarrays.

### Key Idea

1. Select a pivot element.
2. Place the pivot in its correct sorted position.
3. Move smaller elements to its left.
4. Move larger elements to its right.
5. Recursively sort the left and right portions.

### Example

```python
arr = [8, 3, 1, 7, 0, 10, 2]
```

After sorting:

```text
[0, 1, 2, 3, 7, 8, 10]
```

## 2. Important Terms

| Term | Description |
|---|---|
| Pivot | Element selected for partitioning |
| Partition | Process of arranging elements around the pivot |
| Left Subarray | Elements smaller than or equal to the pivot |
| Right Subarray | Elements greater than the pivot |
| Recursion | Function calling itself to sort smaller subarrays |

## 3. How Quick Sort Works

Consider:

```python
arr = [8, 3, 1, 7, 0, 10, 2]
```

Let's select the last element as the pivot.

```text
Array:  [8, 3, 1, 7, 0, 10, 2]
                              |
                         Pivot = 2
```

After partitioning:

```text
[1, 0]  [2]  [7, 8, 10, 3]
```

The pivot `2` is now in its correct sorted position.

Next:
- Sort the left portion `[1, 0]`.
- Sort the right portion `[7, 8, 10, 3]`.
- Continue until every portion contains zero or one element.

Final result:

```text
[0, 1, 2, 3, 7, 8, 10]
```

**Important:** Partitioning does not necessarily sort the left and right portions. It only places the pivot in its correct position and separates the elements according to the partition rule.

## 4. Quick Sort Implementation Using Python

We will use the Lomuto partition scheme, selecting the last element as the pivot.

```python
def partition(arr, low, high):

    pivot = arr[high]

    i = low - 1

    for j in range(low, high):

        if arr[j] <= pivot:

            i += 1

            arr[i], arr[j] = arr[j], arr[i]

    arr[i + 1], arr[high] = arr[high], arr[i + 1]

    return i + 1


def quick_sort(arr, low, high):

    if low < high:

        pivot_index = partition(arr, low, high)

        quick_sort(arr, low, pivot_index - 1)

        quick_sort(arr, pivot_index + 1, high)


numbers = [8, 3, 1, 7, 0, 10, 2]

quick_sort(numbers, 0, len(numbers) - 1)

print(numbers)
```

**Output:**

```text
[0, 1, 2, 3, 7, 8, 10]
```
