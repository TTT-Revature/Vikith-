# Linear Search

## 1. What is Linear Search?

**Linear Search** is a simple searching algorithm that checks each element in a collection one by one until the required element is found or the collection ends.

It works on both sorted and unsorted arrays/lists.

### Example

Consider the following array:

```python
numbers = [10, 25, 30, 45, 50]
target = 30
```

We want to find the position of `30`.

Linear Search checks each element from left to right.

```text
Index:    0    1    2    3    4
        [10] [25] [30] [45] [50]
          |    |    |
        Check Check Found!
```

**Result:** Element `30` is found at index `2`.

## 2. How Linear Search Works

1. Start from the first element.
2. Compare the current element with the target.
3. If both are equal, return the index.
4. Otherwise, move to the next element.
5. Repeat until the element is found or the list ends.
6. If the element is not found, return `-1`.

## 3. Linear Search Implementation in Python

### Basic Implementation

```python
numbers = [10, 25, 30, 45, 50]

target = 30

for i in range(len(numbers)):

    if numbers[i] == target:
        print("Element found at index:", i)
        break
else:
    print("Element not found")
```

**Output:**

```text
Element found at index: 2
```

### Explanation

- `range(len(numbers))` generates the valid indexes.
- `numbers[i]` accesses the current element.
- `if numbers[i] == target` checks whether the current element matches the target.
- `break` stops the loop when the element is found.
- The `else` after the loop executes only if the loop finishes without encountering `break`.

## 4. Linear Search Using a Function

```python
def linear_search(arr, target):

    for i in range(len(arr)):

        if arr[i] == target:
            return i

    return -1


numbers = [10, 25, 30, 45, 50]

result = linear_search(numbers, 30)

if result != -1:
    print("Element found at index:", result)
else:
    print("Element not found")
```

**Output:**

```text
Element found at index: 2
```

## 5. Dry Run – Step-by-Step Execution

Consider:

```python
arr = [5, 12, 18, 25, 40]
target = 25
```

| Iteration | Index | Current Element | Comparison | Result |
|---|---:|---:|---|---|
| 1 | 0 | 5 | 5 == 25 | False |
| 2 | 1 | 12 | 12 == 25 | False |
| 3 | 2 | 18 | 18 == 25 | False |
| 4 | 3 | 25 | 25 == 25 | True |

The algorithm stops at index `3`.

**Output:** `3`

## 6. Linear Search When Element Is Not Found

```python
def linear_search(arr, target):

    for i in range(len(arr)):

        if arr[i] == target:
            return i

    return -1


numbers = [10, 20, 30, 40]

print(linear_search(numbers, 100))
```

**Output:**

```text
-1
```

Here, `100` is not present in the list, so the function returns `-1`.

## 7. Finding All Occurrences of an Element

Linear Search can also find every occurrence of a target element.

```python
def find_all(arr, target):

    positions = []

    for i in range(len(arr)):

        if arr[i] == target:
            positions.append(i)

    return positions


numbers = [10, 20, 10, 30, 10, 40]

print(find_all(numbers, 10))
```

**Output:**

```text
[0, 2, 4]
```

## 8. Linear Search Using While Loop

Linear Search can also be implemented using a `while` loop.

```python
def linear_search(arr, target):

    i = 0

    while i < len(arr):

        if arr[i] == target:
            return i

        i += 1

    return -1


numbers = [10, 20, 30, 40]

print(linear_search(numbers, 30))
```

**Output:**

```text
2
```

## 9. Time and Space Complexity

Linear Search checks elements one by one.

| Case | Description | Time Complexity |
|---|---|---|
| Best Case | Target is at the first position | O(1) |
| Average Case | Target is somewhere in the middle | O(n) |
| Worst Case | Target is at the end or not present | O(n) |

### Space Complexity

**O(1)** – Linear Search uses a constant amount of additional space when searching for a single occurrence.

For the version that stores all matching indexes, additional space is O(k), where k is the number of matches.

### Why is the Worst Case O(n)?

Suppose an array contains 1,000 elements.

If the target is not present, the algorithm must check all 1,000 elements.

Therefore, the number of comparisons grows proportionally with the input size.

## 10. Advantages of Linear Search

1. Easy to understand and implement.
2. Works on sorted and unsorted collections.
3. Does not require additional memory for basic searching.
4. Suitable for small datasets.
5. Works with arrays, lists, and other iterable collections.

## 11. Disadvantages of Linear Search

1. Slow for large datasets.
2. May require checking every element.
3. Less efficient than Binary Search on large sorted arrays.

## 12. Linear Search vs Binary Search

| Feature | Linear Search | Binary Search |
|---|---|---|
| Searching method | Checks one by one | Divides search space in half |
| Data requirement | Sorted or unsorted | Must be sorted |
| Best Case | O(1) | O(1) |
| Average Case | O(n) | O(log n) |
| Worst Case | O(n) | O(log n) |
| Implementation | Simple | More complex |

## 15. Key Takeaways

- Linear Search checks elements one by one.
- It works on both sorted and unsorted data.
- Best-case time complexity is O(1).
- Average and worst-case time complexity are O(n).
- Basic search uses O(1) auxiliary space.
- It is useful for small datasets and simple searching problems.
- Binary Search is generally more efficient for large sorted datasets.
