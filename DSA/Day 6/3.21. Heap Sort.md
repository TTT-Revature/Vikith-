
# Heap Sort – Concept, Operations and Implementation

## 1. What is Heap Sort?

Heap Sort is a comparison-based sorting algorithm that uses a special tree-based data structure called a **Heap**.

It follows these steps:

1. Convert the given array into a Max Heap.
2. The largest element will be at the root of the heap.
3. Swap the root element with the last element.
4. Reduce the heap size by one.
5. Heapify the remaining elements.
6. Repeat until the array is sorted.

Heap Sort uses the concept of a Binary Heap to efficiently find the largest element.

---

## 2. What is a Heap?

A Heap is a complete binary tree that satisfies a special ordering property.

A complete binary tree is a binary tree in which:

- Every level is completely filled except possibly the last level.
- The last level is filled from left to right.

There are two types of heaps:

### A. Max Heap

In a Max Heap, every parent node must be greater than or equal to its child nodes.

Example:

```text
          50
         /  \
        30   40
       / \   /
      10 20 35
```

Here:

- 50 is greater than 30 and 40.
- 30 is greater than 10 and 20.
- 40 is greater than 35.

The largest element is always at the root.

### B. Min Heap

In a Min Heap, every parent node must be smaller than or equal to its child nodes.

Example:

```text
          10
         /  \
        20   15
       / \   /
      40 30 35
```

The smallest element is always at the root.

### Difference Between Max Heap and Min Heap

| Max Heap | Min Heap |
|---|---|
| Parent >= Children | Parent <= Children |
| Largest element at root | Smallest element at root |
| Used in ascending Heap Sort | Useful for descending Heap Sort |
| Root contains maximum value | Root contains minimum value |

## 3. How is a Heap Represented in an Array?

A Binary Heap is usually implemented using an array instead of creating separate tree nodes.

Consider this Max Heap:

```text
          50
         /  \
        30   40
       / \   /
      10 20 35
```

Its array representation is:

```python
heap = [50, 30, 40, 10, 20, 35]
```

Each element is accessed using its index.

For a node at index `i`, the formulas are:

| Node | Formula |
|---|---|
| Parent | `(i - 1) // 2` |
| Left Child | `2 * i + 1` |
| Right Child | `2 * i + 2` |

### Example

Consider:

```python
heap = [50, 30, 40, 10, 20, 35]
```

For the element `30` at index `1`:

```python
left_child = 2 * 1 + 1
right_child = 2 * 1 + 2
```

Result:

```text
Left Child  = heap[3] = 10
Right Child = heap[4] = 20
```

## 4. What is Heapify?

Heapify is the process of adjusting a binary tree or a subtree to satisfy the heap property.

In a Max Heap:

- The parent should be greater than or equal to its children.
- If a child is greater than its parent, swap them.
- Continue moving the element downward until the Max Heap property is satisfied.

### Example

Before Heapify:

```text
          10
         /  \
        30   20
```

The parent `10` is smaller than its child `30`.

After Heapify:

```text
          30
         /  \
        10   20
```

Now the Max Heap property is satisfied.

### Python Implementation of Heapify

```python
def heapify(arr, n, i):

    largest = i

    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    if largest != i:

        arr[i], arr[largest] = arr[largest], arr[i]

        heapify(arr, n, largest)
```

### Explanation

**1. Initialize largest**

```python
largest = i
```

Assume the current parent is the largest element.

**2. Calculate child indexes**

```python
left = 2 * i + 1
right = 2 * i + 2
```

Find the left and right child positions.

**3. Compare the left child**

```python
if left < n and arr[left] > arr[largest]:
    largest = left
```

If the left child is greater, update the largest index.

**4. Compare the right child**

```python
if right < n and arr[right] > arr[largest]:
    largest = right
```

If the right child is greater, update the largest index.

**5. Swap if necessary**

```python
if largest != i:
    arr[i], arr[largest] = arr[largest], arr[i]
```

If the largest element is not the parent, swap them.

**6. Continue heapifying**

```python
heapify(arr, n, largest)
```

After swapping, the element moved downward may violate the heap property in its new subtree. So we continue heapifying.

## 5. Building a Max Heap

Before performing Heap Sort, we must convert the given array into a Max Heap.

Consider:

```python
arr = [4, 10, 3, 5, 1]
```

Initial tree:

```text
          4
         / \
        10  3
       / \
      5   1
```

We start heapifying from the last non-leaf node.

Formula:

```python
last_non_leaf = n // 2 - 1
```

For an array of 5 elements:

```python
last_non_leaf = 5 // 2 - 1
last_non_leaf = 1
```

So we heapify indexes 1 and 0.

### Step-by-Step

**Step 1: Heapify index 1**

Element `10` has children `5` and `1`.

10 is already greater than both children.

No swap is required.

**Step 2: Heapify index 0**

Element `4` has children `10` and `3`.

10 is the largest, so swap 4 and 10.

Array becomes:

```python
[10, 4, 3, 5, 1]
```

But now 4 has children 5 and 1.

Since 5 is greater than 4, swap them.

Final Max Heap:

```text
          10
         /  \
        5    3
       / \
      4   1
```

Array:

```python
[10, 5, 3, 4, 1]
```

### Python Code to Build a Max Heap

```python
def build_max_heap(arr):

    n = len(arr)

    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
```

## 6. Heap Sort Algorithm

Now that we understand Heapify and Max Heap construction, let's implement Heap Sort.

### Main Steps

1. Build a Max Heap.
2. Swap the root (largest element) with the last element.
3. Reduce the heap size.
4. Heapify the root again.
5. Repeat until the heap contains only one element.

### Python Implementation

```python
def heapify(arr, n, i):

    largest = i

    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    if largest != i:

        arr[i], arr[largest] = arr[largest], arr[i]

        heapify(arr, n, largest)


def heap_sort(arr):

    n = len(arr)

    # Step 1: Build Max Heap
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # Step 2: Extract maximum element
    for i in range(n - 1, 0, -1):

        arr[0], arr[i] = arr[i], arr[0]

        # Step 3: Restore Max Heap
        heapify(arr, i, 0)


arr = [4, 10, 3, 5, 1]

heap_sort(arr)

print("Sorted Array:", arr)
```

Output:

```text
Sorted Array: [1, 3, 4, 5, 10]
```

## 7. Complete Dry Run of Heap Sort

Consider:

```python
arr = [4, 10, 3, 5, 1]
```

### Step 1: Build Max Heap

Original array:

```text
[4, 10, 3, 5, 1]
```

After building the Max Heap:

```text
          10
         /  \
        5    3
       / \
      4   1
```

Array:

```text
[10, 5, 3, 4, 1]
```

### Step 2: Move the Largest Element to the End

Swap the root with the last element.

```python
arr[0], arr[4] = arr[4], arr[0]
```

Array:

```text
[1, 5, 3, 4, 10]
```

The element `10` is now in its correct sorted position.

The remaining heap size is 4.

### Step 3: Heapify the Remaining Elements

Heapify the first four elements:

```text
[1, 5, 3, 4 | 10]
```

After heapify:

```text
[5, 4, 3, 1 | 10]
```

The largest remaining element is now at the root.

### Step 4: Extract the Next Largest Element

Swap 5 with the last element of the active heap.

```text
[1, 4, 3, 5 | 10]
```

Heapify the remaining three elements:

```text
[4, 1, 3 | 5, 10]
```

### Step 5: Extract Again

Swap 4 with the last element of the active heap.

```text
[3, 1, 4 | 5, 10]
```

Heapify the remaining two elements:

```text
[3, 1 | 4, 5, 10]
```

### Step 6: Final Extraction

Swap 3 and 1:

```text
[1, 3, 4, 5, 10]
```

The array is now sorted in ascending order.

### Complete Sorting Progress

| Stage | Array |
|---|---|
| Original | `[4, 10, 3, 5, 1]` |
| Max Heap | `[10, 5, 3, 4, 1]` |
| First extraction | `[5, 4, 3, 1, 10]` |
| Second extraction | `[4, 1, 3, 5, 10]` |
| Third extraction | `[3, 1, 4, 5, 10]` |
| Final extraction | `[1, 3, 4, 5, 10]` |

The sorted elements are collected from right to left.

## 8. Time and Space Complexity

| Operation | Time Complexity |
|---|---|
| Building Max Heap | O(n) |
| Heapify | O(log n) |
| Extract Maximum | O(log n) |
| Heap Sort | O(n log n) |

### Best Case

```text
O(n log n)
```

### Average Case

```text
O(n log n)
```

### Worst Case

```text
O(n log n)
```

Heap Sort maintains O(n log n) time complexity regardless of the initial ordering of the elements.

### Space Complexity

For the recursive `heapify()` implementation:

```text
O(log n) auxiliary recursion stack
```

Heap Sort itself sorts the array in place and does not require another array of size n.

An iterative Heapify implementation can achieve O(1) auxiliary space.

## 9. Properties of Heap Sort

| Property | Heap Sort |
|---|---|
| Algorithm Type | Comparison-based |
| Data Structure | Binary Heap |
| Sorting Order | Ascending using Max Heap |
| Best Case | O(n log n) |
| Average Case | O(n log n) |
| Worst Case | O(n log n) |
| Auxiliary Space | O(log n) for recursive Heapify |
| Stable | No |
| In-place | Yes |

### Is Heap Sort Stable?

No.

A stable sorting algorithm preserves the relative order of elements having equal values.

Heap Sort does not guarantee this because swapping the root with the last element can change the relative order of equal elements.

|---|---|---|---|
| Best Time | O(n log n) | O(n log n) | O(n log n) |

| Worst Time | O(n log n) | O(n log n) | O(n²) |
| Stable | No | Yes | No |
| In-place | Yes | No (standard array version) | Usually yes |
| Main Concept | Heap | Divide and Conquer | Partitioning |

---

## 11. Advantages of Heap Sort

1. Guaranteed O(n log n) time complexity.
2. Does not require an additional array of size n.
3. Works well when predictable worst-case performance is important.
4. Efficiently extracts the largest element using a Max Heap.

## 12. Disadvantages of Heap Sort

1. It is not a stable sorting algorithm.
2. Heap Sort often has poorer cache locality than Quick Sort.
3. The implementation is more complex than simple sorting algorithms.
4. It may be slower in practice than optimized Quick Sort or Timsort implementations.

---

## 13. Real-World Applications

Heap-based data structures are useful in:

- Priority Queue implementations.
- Task scheduling systems.
- Operating system process scheduling.
- Event-driven simulations.
- Finding the K largest or K smallest elements.
- Graph algorithms such as Dijkstra's and Prim's algorithms.

**Important:** These applications commonly use heaps and priority queues. They do not necessarily use Heap Sort itself.

## 16. Key Takeaways

- Heap Sort is a comparison-based sorting algorithm.
- It uses a Binary Heap data structure.
- A Max Heap places the largest element at the root.
- Heapify maintains the heap property.
- Building a Max Heap takes O(n) time.
- Repeated extraction and heapification sort the array.
- Best, average and worst-case time complexity is O(n log n).
- Heap Sort is in-place but not stable.

**Remember the main process:**

```text
Unsorted Array
      |
      v
Build Max Heap
      |
      v
Extract Maximum
      |
      v
Move Maximum to End
      |
      v
Heapify Remaining Elements
      |
      v
Repeat Until Sorted
      |
      v
Sorted Array
```
