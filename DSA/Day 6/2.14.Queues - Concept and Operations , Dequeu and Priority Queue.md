# Queues – Concepts, Operations, Deque and Priority Queue

## 1. What is a Queue?

A **Queue** is a linear data structure that follows the **FIFO (First In, First Out)** principle.

This means the element inserted first will be removed first.

**Real-life example:** People standing in a ticket counter queue. The person who arrives first gets the ticket first.

### Example

```text
FRONT                    REAR
  |                        |
[10]  ->  [20]  ->  [30]  -> [40]

First element removed: 10
Last element removed: 40
```

- `10` was inserted first.
- `40` was inserted last.
- `10` will be removed first.

## 2. Basic Queue Operations

| Operation | Description |
|---|---|
| `enqueue()` | Adds an element to the rear |
| `dequeue()` | Removes an element from the front |
| `front()` / `peek()` | Returns the first element |
| `is_empty()` | Checks whether the queue is empty |
| `size()` | Returns the number of elements |

### 2.1 Enqueue Operation

Adds an element to the rear of the queue.

```python
queue = []

queue.append(10)
queue.append(20)
queue.append(30)

print(queue)
```

**Output:**
```text
[10, 20, 30]
```

### 2.2 Dequeue Operation

Removes the first element from the queue.

For learning purposes, Python's `pop(0)` can demonstrate this operation.

```python
queue = [10, 20, 30]

removed = queue.pop(0)

print("Removed:", removed)
print("Queue:", queue)
```

**Output:**
```text
Removed: 10
Queue: [20, 30]
```

**Note:** `pop(0)` takes O(n) time because the remaining elements must shift. For efficient queues, use `collections.deque`.

### 2.3 Front Operation

Returns the first element without removing it.

```python
queue = [10, 20, 30]

print("Front:", queue[0])
print("Queue:", queue)
```

**Output:**
```text
Front: 10
Queue: [10, 20, 30]
```

### 2.4 Check if Queue is Empty

```python
queue = []

if len(queue) == 0:
    print("Queue is empty")
else:
    print("Queue is not empty")
```

**Output:**
```text
Queue is empty
```

## 3. Queue Implementation Using collections.deque

Python provides `collections.deque`, which is a double-ended queue.

It supports efficient insertion and deletion at both ends.

```python
from collections import deque

queue = deque()

# Enqueue
queue.append(10)
queue.append(20)
queue.append(30)

print("Queue:", queue)

# Dequeue
print("Removed:", queue.popleft())

print("Updated Queue:", queue)
```

**Output:**
```text
Queue: deque([10, 20, 30])
Removed: 10
Updated Queue: deque([20, 30])
```

### Why use deque instead of a list?

| Operation | Python List | Deque |
|---|---:|---:|
| Add at rear | O(1) amortized | O(1) |
| Remove from front | O(n) | O(1) |
| Add at front | O(n) | O(1) |
| Remove from rear | O(1) | O(1) |

**Important:** For implementing a normal queue in Python, prefer `collections.deque`.

## 4. Queue Implementation Using a Class

```python
from collections import deque

class Queue:

    def __init__(self):
        self.items = deque()

    def enqueue(self, data):
        self.items.append(data)

    def dequeue(self):
        if self.is_empty():
            return "Queue is empty"

        return self.items.popleft()

    def front(self):
        if self.is_empty():
            return "Queue is empty"

        return self.items[0]

    def is_empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)


queue = Queue()

queue.enqueue(10)
queue.enqueue(20)
queue.enqueue(30)

print("Queue:", queue.items)
print("Front:", queue.front())
print("Removed:", queue.dequeue())
print("Updated Queue:", queue.items)
```

**Output:**
```text
Queue: deque([10, 20, 30])
Front: 10
Removed: 10
Updated Queue: deque([20, 30])
```

# 5. Deque (Double-Ended Queue)

A **Deque** stands for Double-Ended Queue.

Unlike a normal queue, a deque allows insertion and deletion from both the front and rear ends.

### Example

```text
FRONT                    REAR
  |                        |
[10]  <->  [20]  <->  [30]

Insert at front: 5
Insert at rear: 40

[5] <-> [10] <-> [20] <-> [30] <-> [40]
```

### 5.1 Deque Operations

| Operation | Description |
|---|---|
| `append()` | Adds an element at the rear |
| `appendleft()` | Adds an element at the front |
| `pop()` | Removes an element from the rear |
| `popleft()` | Removes an element from the front |
| `clear()` | Removes all elements |
| `count()` | Counts occurrences of an element |
| `reverse()` | Reverses the deque |

### 5.2 Deque Implementation in Python

```python
from collections import deque

dq = deque()

# Insert at rear
dq.append(10)
dq.append(20)

# Insert at front
dq.appendleft(5)

print("Deque:", dq)

# Remove from rear
dq.pop()

# Remove from front
dq.popleft()

print("Updated Deque:", dq)
```

**Output:**
```text
Deque: deque([5, 10, 20])
Updated Deque: deque([10])
```

### 5.3 Accessing Elements

```python
from collections import deque

dq = deque([10, 20, 30, 40])

print("First:", dq[0])
print("Last:", dq[-1])
print("Size:", len(dq))
```

**Output:**
```text
First: 10
Last: 40
Size: 4
```

### 5.4 Types of Deque

**1. Input-Restricted Deque**

- Insertion is allowed at only one end.
- Deletion is allowed at both ends.

**2. Output-Restricted Deque**

- Insertion is allowed at both ends.
- Deletion is allowed at only one end.

### Applications of Deque

1. Sliding Window problems.
2. Palindrome checking.
3. Browser history.
4. Implementing queues and stacks.
5. Task scheduling.

# 6. Priority Queue

A **Priority Queue** is a special type of queue where each element is associated with a priority.

Elements are removed based on their priority rather than their insertion order.

**Real-life example:** In a hospital emergency room, patients with more serious conditions are treated before patients with less serious conditions.

### Example

Suppose we have the following tasks:

| Task | Priority |
|---|---:|
| Task A | 3 |
| Task B | 1 |
| Task C | 2 |

If a smaller number represents a higher priority, the removal order will be:

```text
Task B -> Task C -> Task A
```

**Important:** Priority queues do not necessarily follow FIFO order. If two elements have equal priority, their removal order depends on the implementation.

## 7. Priority Queue Implementation Using heapq

Python provides the `heapq` module to implement a priority queue using a min-heap.

In a min-heap, the smallest element is always at the top.

```python
import heapq

pq = []

heapq.heappush(pq, 30)
heapq.heappush(pq, 10)
heapq.heappush(pq, 20)

print("Priority Queue:", pq)

print("Removed:", heapq.heappop(pq))

print("Updated Queue:", pq)
```

**Output:**
```text
Priority Queue: [10, 30, 20]
Removed: 10
Updated Queue: [20, 30]
```

**Note:** The internal list representation of a heap is not necessarily fully sorted. Only the smallest element is guaranteed to be at index `0`.

## 8. Priority Queue with Custom Priorities

We can store priorities and values as tuples.

The first value determines the priority.

```python
import heapq

pq = []

heapq.heappush(pq, (3, "Task A"))
heapq.heappush(pq, (1, "Task B"))
heapq.heappush(pq, (2, "Task C"))

while pq:
    priority, task = heapq.heappop(pq)
    print(priority, task)
```

**Output:**
```text
1 Task B
2 Task C
3 Task A
```

### Max-Priority Queue

By default, `heapq` implements a min-heap.

To process the largest priority value first, use negative priorities.

```python
import heapq

pq = []

heapq.heappush(pq, (-3, "Task A"))
heapq.heappush(pq, (-1, "Task B"))
heapq.heappush(pq, (-2, "Task C"))

while pq:
    priority, task = heapq.heappop(pq)
    print(-priority, task)
```

**Output:**
```text
3 Task A
2 Task C
1 Task B
```

### Priority Queue Time Complexity

| Operation | Time Complexity |
|---|---:|
| Insert (`heappush`) | O(log n) |
| Remove (`heappop`) | O(log n) |
| Peek (`pq[0]`) | O(1) |
| Build heap (`heapify`) | O(n) |

### Applications of Priority Queue

1. CPU scheduling.
2. Dijkstra's shortest path algorithm.
3. A* search algorithm.
4. Network packet scheduling.
5. Hospital emergency systems.
6. Event-driven simulations.

# 9. Difference Between Queue, Deque and Priority Queue

| Feature | Queue | Deque | Priority Queue |
|---|---|---|---|
| Principle | FIFO | Insertion/deletion at both ends | Priority-based |
| Insertion | Rear only | Front and rear | Based on heap structure |
| Deletion | Front only | Front and rear | Highest-priority element |
| Python implementation | `collections.deque` | `collections.deque` | `heapq` |
| Common use | Task processing | Sliding window | Scheduling |

# 10. Time Complexity Comparison

| Operation | Queue (`deque`) | Deque | Priority Queue (`heapq`) |
|---|---:|---:|---:|
| Insert | O(1) | O(1) at either end | O(log n) |
| Delete | O(1) | O(1) at either end | O(log n) |
| Peek | O(1) | O(1) at either end | O(1) |
| Search | O(n) | O(n) | O(n) |

**Space Complexity:** O(n) for storing `n` elements.
