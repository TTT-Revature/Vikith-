# Big Omega (Ω) and Big Theta (Θ) – Basic Understanding

## 1. Introduction

Asymptotic notations are mathematical tools used to describe how an algorithm's time or space requirements grow as input size increases.

There are three important asymptotic notations:

| Notation | Meaning |
|---|---|
| Big O – O() | Asymptotic upper bound |
| Big Omega – Ω() | Asymptotic lower bound |
| Big Theta – Θ() | Asymptotic tight bound |

These notations help us compare algorithm efficiency independently of hardware and programming languages.

---

## 2. Big Omega Notation – Ω()

Big Omega describes the **asymptotic lower bound** of an algorithm.

It represents a growth rate that an algorithm takes at least, for sufficiently large input sizes.

In simple words, it describes a lower bound on how fast the resource usage grows.

### Example 1: Linear Search

```python
def linear_search(numbers, target):

    for num in numbers:
        if num == target:
            return True

    return False
```

Consider the following list:

```python
numbers = [10, 20, 30, 40, 50]
```

If the target is `10`, the algorithm finds it in the first comparison.

Best-case time complexity: **Ω(1)**

If we analyze the worst-case input, the algorithm checks all elements, which grows linearly.

Worst-case time complexity: **O(n)**

Note: Big Omega is a general lower-bound notation, not automatically synonymous with best-case complexity. The best-case complexity is often expressed using Omega in introductory examples.

### Example 2: Constant Time

```python
def get_first(numbers):
    return numbers[0]
```

The operation takes constant time regardless of list size.

Lower bound: **Ω(1)**

---

## 3. Big Theta Notation – Θ()

Big Theta describes the **asymptotic tight bound** of an algorithm.

It means the algorithm's growth rate is bounded both above and below by the same asymptotic function.

In simple words, the algorithm grows at the same rate represented by the given function.

### Example 1: Single Loop

```python
def print_numbers(n):

    for i in range(n):
        print(i)
```

For every input size `n`, the loop executes exactly `n` times.

- Upper bound: O(n)
- Lower bound: Ω(n)
- Tight bound: Θ(n)

### Example 2: Nested Loops

```python
def print_pairs(n):

    for i in range(n):
        for j in range(n):
            print(i, j)
```

The outer loop executes `n` times.

The inner loop executes `n` times for each outer iteration.

Total operations = `n × n = n²`

- Upper bound: O(n²)
- Lower bound: Ω(n²)
- Tight bound: Θ(n²)

---

## 4. Difference Between Big O, Omega and Theta

| Feature | Big O | Big Omega | Big Theta |
|---|---|---|---|
| Symbol | O() | Ω() | Θ() |
| Meaning | Upper bound | Lower bound | Tight bound |
| Describes | At most this growth rate | At least this growth rate | Same asymptotic growth rate |
| Common use | Worst-case upper bound | Best-case lower bound in introductory analysis | Exact asymptotic order |

Remember:

- Big O = Upper Bound
- Big Omega = Lower Bound
- Big Theta = Tight Bound

---

## 5. Understanding With a Simple Example

Consider this algorithm:

```python
def example(n):

    for i in range(n):
        print(i)
```

The number of operations grows linearly with `n`.

Therefore:

- O(n) – Upper bound
- Ω(n) – Lower bound
- Θ(n) – Tight bound

All three notations describe different types of bounds on the same algorithm.

## 6. Important Mathematical Definitions

Let `f(n)` represent an algorithm's resource usage and `g(n)` represent a comparison function.

### Big O

There exist positive constants `c` and `n₀` such that:

`0 ≤ f(n) ≤ c × g(n)` for all `n ≥ n₀`.

### Big Omega

There exist positive constants `c` and `n₀` such that:

`0 ≤ c × g(n) ≤ f(n)` for all `n ≥ n₀`.

### Big Theta

There exist positive constants `c₁`, `c₂` and `n₀` such that:

`0 ≤ c₁ × g(n) ≤ f(n) ≤ c₂ × g(n)` for all `n ≥ n₀`.

You do not need to memorize the mathematical definitions immediately. First understand the upper, lower and tight bounds.

## 8. Key Takeaways

- Big O describes an asymptotic upper bound.
- Big Omega describes an asymptotic lower bound.
- Big Theta describes an asymptotic tight bound.
- These notations help evaluate algorithm growth.
- Best, average and worst cases are different from the mathematical definitions of upper, lower and tight bounds.
- An algorithm can be described using all three notations.
