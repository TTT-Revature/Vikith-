# Analyzing Code Complexity – Loops, Nested Loops and Conditionals

## 1. Introduction

Code Complexity Analysis is the process of examining source code to determine how its execution time grows with input size.

When analyzing Python code, we mainly look at:

- Number of loops.
- Number of loop iterations.
- Nested loops.
- Conditional statements.
- Input size.
- Operations performed inside loops.

The goal is to identify the Big O time complexity of a program.

---

## 2. Single Loop – O(n)

A single loop generally has linear time complexity when it processes `n` elements.

### Example

```python
def example(n):

    for i in range(n):
        print(i)

example(5)
```

**Output:**
```text
0
1
2
3
4
```

### Analysis

- The loop starts at 0.
- It executes until `n - 1`.
- Total iterations = n.

For `n = 5`, there are 5 iterations.

For `n = 100`, there are 100 iterations.

**Time Complexity: O(n)**

---

## 3. Nested Loops – O(n²)

A nested loop occurs when one loop is placed inside another loop.

When both loops execute `n` times, the complexity becomes quadratic.

### Example

```python
def example(n):

    for i in range(n):

        for j in range(n):
            print(i, j)

example(3)
```

**Output:**
```text
0 0
0 1
0 2
1 0
1 1
1 2
2 0
2 1
2 2
```

### Analysis

- Outer loop executes 3 times.
- Inner loop executes 3 times for each outer iteration.
- Total iterations = 3 × 3 = 9.

For `n` elements:

Total iterations = n × n = n².

**Time Complexity: O(n²)**

---

## 4. Independent Loops – O(n)

Two independent loops are added, not multiplied.

### Example

```python
def example(n):

    for i in range(n):
        print(i)

    for j in range(n):
        print(j)

example(5)
```

### Analysis

First loop = n iterations.

Second loop = n iterations.

Total = n + n = 2n.

We ignore constants in Big O.

**Time Complexity: O(n)**

Important: Two separate loops do not automatically mean O(n²).

---

## 5. Different Input Sizes – O(n + m)

When two loops depend on different input sizes, we keep both variables.

### Example

```python
def example(n, m):

    for i in range(n):
        print(i)

    for j in range(m):
        print(j)
```

### Analysis

First loop = n iterations.

Second loop = m iterations.

Total = n + m.

**Time Complexity: O(n + m)**

We cannot simplify this to O(n) unless we know a relationship between `n` and `m`.

---

## 6. Nested Loops with Different Input Sizes – O(n × m)

### Example

```python
def example(n, m):

    for i in range(n):

        for j in range(m):
            print(i, j)
```

### Analysis

Outer loop = n iterations.

Inner loop = m iterations.

Total = n × m.

**Time Complexity: O(n × m)**

---

## 7. Loop with a Conditional Statement

A conditional statement (`if`, `elif`, `else`) does not automatically increase time complexity.

### Example

```python
def example(numbers):

    for num in numbers:

        if num > 10:
            print("Greater")

        else:
            print("Smaller")
```

### Analysis

- The loop executes n times.
- The condition is checked once per iteration.
- Either branch performs a constant amount of work.

Total operations grow proportionally with n.

**Time Complexity: O(n)**

---

## 8. Conditional Statements with Different Complexities

When different branches have different complexities, analyze each branch separately.

For worst-case analysis, consider the branch with the highest growth rate.

### Example

```python
def example(n):

    if n > 10:

        for i in range(n):
            print(i)

    else:

        for i in range(n):
            for j in range(n):
                print(i, j)
```

### Analysis

First branch:
- One loop.
- Complexity = O(n).

Second branch:
- Two nested loops.
- Complexity = O(n²).

Worst-case complexity:

O(n²) dominates O(n).

**Time Complexity: O(n²)**

---

## 9. Nested Loops with Different Conditions

A nested loop does not always mean O(n²). We must examine how many times the inner loop actually executes.

### Example 1: Inner Loop Runs Fewer Times

```python
def example(n):

    for i in range(n):

        for j in range(i):
            print(i, j)
```

### Analysis

The inner loop runs:

- When i = 0 → 0 times.
- When i = 1 → 1 time.
- When i = 2 → 2 times.
- When i = 3 → 3 times.

Total iterations:

`0 + 1 + 2 + ... + (n - 1)`

Using the arithmetic series formula:

`n(n - 1) / 2`

After removing constants and lower-order terms:

**Time Complexity: O(n²)**

### Example 2: Inner Loop Halves Its Value

```python
def example(n):

    for i in range(n):

        j = n

        while j > 1:
            j //= 2
```

### Analysis

- Outer loop executes n times.
- Inner loop divides j by 2 each iteration.
- Inner loop complexity = O(log n).

Total complexity:

**O(n log n)**

---

## 10. Logarithmic Loops – O(log n)

When a loop repeatedly multiplies or divides its controlling variable by a constant factor, it often has logarithmic complexity.

### Example 1

```python
def example(n):

    i = 1

    while i < n:
        print(i)
        i *= 2
```

Values:

`1 → 2 → 4 → 8 → 16 → 32`

The variable doubles every iteration.

**Time Complexity: O(log n)**

### Example 2

```python
def example(n):

    while n > 1:
        n //= 2
```

The input is halved in every iteration.

**Time Complexity: O(log n)**

---

## 11. Three Nested Loops – O(n³)

### Example

```python
def example(n):

    for i in range(n):

        for j in range(n):

            for k in range(n):
                print(i, j, k)
```

### Analysis

- First loop = n.
- Second loop = n.
- Third loop = n.

Total iterations:

`n × n × n = n³`

**Time Complexity: O(n³)**

---

## 12. Combining Different Complexity Patterns

### Example 1: Linear Loop + Nested Loop

```python
def example(n):

    for i in range(n):
        print(i)

    for i in range(n):

        for j in range(n):
            print(i, j)
```

Analysis:

- First loop = O(n).
- Nested loops = O(n²).

Total:

`O(n + n²)`

Dominant term = n².

**Time Complexity: O(n²)**

### Example 2: Two Nested Loops with an Independent Loop

```python
def example(n):

    for i in range(n):
        print(i)

    for i in range(n):

        for j in range(n):
            print(i, j)

    for k in range(n):
        print(k)
```

Analysis:

- First loop = O(n).
- Nested loops = O(n²).
- Third loop = O(n).

Total:

`O(n + n² + n)`

**Time Complexity: O(n²)**

---

## 13. Common Mistakes in Complexity Analysis

| Mistake | Correct Understanding |
|---|---|
| Two loops always mean O(n²) | Independent loops can be O(n) |
| Every nested loop means O(n²) | Check actual iteration counts |
| Every if statement adds O(n) | A constant-time condition is O(1) |
| Ignore different input sizes | Keep n and m separate |
| O(2n) is different from O(n) | Constants are ignored |
| All branches execute | Usually only one conditional branch executes |
| A loop that halves n is O(n) | It is usually O(log n) |

---

## 14. Step-by-Step Method to Analyze Code

Follow these steps whenever you receive a code complexity question:

1. Identify the input size (`n`, `m`, etc.).
2. Count the number of loops.
3. Check whether loops are independent or nested.
4. Identify how loop variables change.
5. Check conditional statements and their branches.
6. Calculate the total number of operations.
7. Remove constants and lower-order terms.
8. Write the final Big O complexity.

## Key Takeaways

- Single loop: Usually O(n).
- Two independent loops: Usually O(n).
- Two nested loops: Often O(n²).
- Three nested loops: Often O(n³).
- A loop that doubles or halves its variable: Usually O(log n).
- Nested linear and logarithmic loops: O(n log n).
- Conditional statements do not automatically increase complexity.
- Always calculate actual iterations rather than simply counting loops.
