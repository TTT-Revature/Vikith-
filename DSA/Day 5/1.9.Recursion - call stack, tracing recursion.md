# Recursion – Call Stack and Tracing Recursion

## 1. What is Recursion?

Recursion is a programming technique in which a function calls itself to solve a problem.

Instead of solving the entire problem at once, recursion breaks it into smaller versions of the same problem.

Every recursive function needs two important components:

1. **Base Case:** The condition that stops recursion.
2. **Recursive Case:** The part where the function calls itself with a smaller or simpler input.

### Example

```python
def countdown(n):

    if n == 0:
        return

    print(n)

    countdown(n - 1)


countdown(5)
```

**Output:**

```text
5
4
3
2
1
```

Here:
- `countdown(5)` calls `countdown(4)`.
- `countdown(4)` calls `countdown(3)`.
- This continues until `n == 0`.
- The base case stops further function calls.

---

## 2. Base Case and Recursive Case

### A. Base Case

The base case is the stopping condition of recursion.

Without a base case, a recursive function may continue calling itself until Python raises a `RecursionError`.

Example:

```python
def print_number(n):

    if n == 0:
        return

    print(n)

    print_number(n - 1)
```

Here, `n == 0` is the base case.

### B. Recursive Case

The recursive case contains the function call itself.

```python
print_number(n - 1)
```

Each call reduces `n` until the base case is reached.

---

## 3. What is a Call Stack?

The call stack is a memory structure used by a program to manage function calls.

Whenever a function is called, Python creates a stack frame containing information such as:
- Function arguments.
- Local variables.
- Execution state.
- Where execution should resume after the function returns.

Each new function call creates a new stack frame.

The call stack follows the **LIFO (Last In, First Out)** principle.

The last function called is the first one to finish.

### Example

```python
def first():
    second()
    print("First")


def second():
    third()
    print("Second")


def third():
    print("Third")


first()
```

**Output:**

```text
Third
Second
First
```

### How the Call Stack Works

1. `first()` is called.
2. `second()` is called inside `first()`.
3. `third()` is called inside `second()`.
4. `third()` finishes first.
5. `second()` resumes and finishes.
6. `first()` resumes and finishes.

This is how function calls are managed internally.

## 4. Understanding Recursion Through the Call Stack

Consider:

```python
def calculate(n):

    if n == 0:
        return

    print(n)

    calculate(n - 1)


calculate(3)
```

### Step 1: Function Calls

```text
calculate(3)
    calculate(2)
        calculate(1)
            calculate(0)
```

### Step 2: Reaching the Base Case

When `calculate(0)` executes, the condition is true.

It returns without making another recursive call.

### Step 3: Returning from Recursion

The function calls now finish in reverse order.

```text
calculate(0) → returns
calculate(1) → returns
calculate(2) → returns
calculate(3) → returns
```

This process is called **unwinding the call stack**.

## 5. Tracing Recursion – Step by Step

Tracing recursion means manually following each function call and understanding what happens during execution.

### Example 1: Print Numbers from 1 to N

```python
def print_numbers(n):

    if n == 0:
        return

    print_numbers(n - 1)

    print(n)


print_numbers(5)
```

**Output:**

```text
1
2
3
4
5
```

### Understanding the Execution

Notice that `print(n)` is written after the recursive call.

Therefore, printing happens while the function calls return.

**Calling Phase:**

```text
print_numbers(5)
print_numbers(4)
print_numbers(3)
print_numbers(2)
print_numbers(1)
print_numbers(0)
```

**Returning Phase:**

```text
print(1)
print(2)
print(3)
print(4)
print(5)
```

This is why the output is in ascending order.

## 6. Printing Before and After Recursive Calls

The position of a statement relative to the recursive call changes the output.

### Example A: Print Before Recursion

```python
def example(n):

    if n == 0:
        return

    print(n)

    example(n - 1)


example(4)
```

**Output:**

```text
4
3
2
1
```

Printing happens during the calling phase.

### Example B: Print After Recursion

```python
def example(n):

    if n == 0:
        return

    example(n - 1)

    print(n)


example(4)
```

**Output:**

```text
1
2
3
4
```

Printing happens during the returning phase.

## 7. Recursion Example – Factorial

Factorial of a number is the product of all positive integers from 1 to that number.

For example:

`5! = 5 × 4 × 3 × 2 × 1 = 120`

### Python Implementation

```python
def factorial(n):

    if n == 0 or n == 1:
        return 1

    return n * factorial(n - 1)


print(factorial(5))
```

**Output:**

```text
120
```

### Tracing Factorial(5)

**Calling Phase:**

```text
factorial(5)
    5 * factorial(4)
        4 * factorial(3)
            3 * factorial(2)
                2 * factorial(1)
                    return 1
```

**Returning Phase:**

```text
factorial(1) = 1

factorial(2) = 2 * 1 = 2

factorial(3) = 3 * 2 = 6

factorial(4) = 4 * 6 = 24

factorial(5) = 5 * 24 = 120
```

Each function call waits for the result of the next recursive call.

## 8. Recursion Example – Sum of N Numbers

Find the sum of numbers from 1 to N.

### Python Implementation

```python
def sum_numbers(n):

    if n == 0:
        return 0

    return n + sum_numbers(n - 1)


print(sum_numbers(5))
```

**Output:**

```text
15
```

### Tracing

```text
sum_numbers(5)
= 5 + sum_numbers(4)
= 5 + 4 + sum_numbers(3)
= 5 + 4 + 3 + sum_numbers(2)
= 5 + 4 + 3 + 2 + sum_numbers(1)
= 5 + 4 + 3 + 2 + 1 + sum_numbers(0)
= 5 + 4 + 3 + 2 + 1 + 0
= 15
```

## 9. Recursion Example – Fibonacci Series

The Fibonacci sequence is a series where each number is the sum of the previous two numbers.

Example:

`0, 1, 1, 2, 3, 5, 8, 13...`

### Python Implementation

```python
def fibonacci(n):

    if n <= 1:
        return n

    return fibonacci(n - 1) + fibonacci(n - 2)


for i in range(7):
    print(fibonacci(i), end=" ")
```

**Output:**

```text
0 1 1 2 3 5 8
```

### Understanding the Recursive Calls

For `fibonacci(4)`:

```text
             fibonacci(4)
             /          \
       fibonacci(3)   fibonacci(2)
        /      \        /     \
   fib(2)    fib(1)  fib(1)  fib(0)
    /   \
fib(1) fib(0)
```

Each function call may generate additional function calls.

This creates a recursion tree.

Note: This simple recursive Fibonacci implementation has exponential time complexity, approximately O(2ⁿ).

## 10. Types of Recursion

### 1. Direct Recursion

A function directly calls itself.

```python
def example(n):

    if n == 0:
        return

    example(n - 1)
```

### 2. Indirect Recursion

One function calls another function, which eventually calls the first function.

```python
def function_a(n):

    if n <= 0:
        return

    print("A")
    function_b(n - 1)


def function_b(n):

    if n <= 0:
        return

    print("B")
    function_a(n - 1)


function_a(4)
```

### 3. Tail Recursion

The recursive call is the final operation performed by the function.

```python
def countdown(n):

    if n == 0:
        return

    print(n)

    return countdown(n - 1)
```

Python does not perform tail-call optimization, so tail recursion still consumes stack frames.

### 4. Non-Tail Recursion

Some operations remain after the recursive call returns.

```python
def factorial(n):

    if n <= 1:
        return 1

    return n * factorial(n - 1)
```

Multiplication happens after the recursive call returns.

---

## 11. Time and Space Complexity of Recursion

Recursion consumes memory because each function call creates a stack frame.

| Example | Time Complexity | Auxiliary Stack Space |
|---|---|---|
| Countdown | O(n) | O(n) |
| Factorial | O(n) | O(n) |
| Sum of N numbers | O(n) | O(n) |
| Recursive Fibonacci | O(2ⁿ) | O(n) |

The simple recursive Fibonacci function has exponential time complexity but only linear maximum call-stack depth.

## 12. Common Recursion Errors

### Missing Base Case

```python
def example(n):
    print(n)
    example(n - 1)
```

This eventually raises `RecursionError`.

### Incorrect Recursive Progress

```python
def example(n):

    if n == 0:
        return

    example(n)
```

The input never changes, so the base case is never reached.

### Incorrect Base Case

A wrong stopping condition can produce incorrect results or infinite recursion.

Always verify that the recursive input moves toward the base case.
